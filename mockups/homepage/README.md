### Макет 04 — что внутри

- **Шапка:** маскот + «Вселенная IT», «Энциклопедия», поиск (как в макете 3), угол — светлая/тёмная + выбор дизайна. «О проекте», «Манифест», «Поддержать» — в футере.
- **Hero:** логотип, метрики, **второе** поле поиска (акцент на главной; в шапке поиск не убираем).
- **CTA:** «Начать с основ» + «Витрина интерактива»; APK — ссылка внизу карточки.
- **Карта:** орбита из макета 2 (свечение, градиентное кольцо).
- **С чего начать:** карточки с номером вместо эмодзи.
- **Интерактив:** панель с тремя превью.
- **Случайная статья:** заголовок «Не знаете…», ссылка, кнопка **«Ещё» снизу**.
- **Форматы:** широкие карточки Энциклопедия/Инструменты + сетка, как сейчас на сайте.

Общее для всех макетов (условно):

- Бренд: фиолетовый `#7B68EE`, без рекламного APK-блока — ссылка в подвале героя.
- Порядок смысла: **ценность → карта → вход → интерактив → открытие → форматы**.
- Интерактив и «случайная статья» — как отдельные блоки, не конкурируют с главным CTA.

Цифры в макетах **иллюстративные** (для ощущения масштаба), не из реального индекса.
