## Циклы C++

C++ поддерживает стандартные циклы, как и большинство языков.

for:
```cpp
for (int i = 0; i < 5; i++) {
    cout << i << endl;
}
```

while:
```cpp
int i = 0;
while (i < 5) {
    cout << i++ << endl;
}
```

do-while:
```cpp
int j = 0;
do {
    cout << j++ << endl;
} while (j < 5);
```

Range-based for loop (начиная с C++11):
```cpp
vector<int> numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    cout << num << endl;
}
```
