## Основы C++

★ **C++** стал логическим продолжением C, добавив объектно-ориентированные возможности, шаблоны и другие современные средства, сохранив совместимость с Си. Расширение C стало самостоятельным гигантом, который до сих пор остаётся востребованным в разработке игр и высоконагруженных систем.

C++ предоставляет разработчику полный контроль над железом: память, регистры, потоки, оптимизации, благодаря чему и обеспечивается максимальная скорость работы программ – это операционные системы, игры, браузеры, базы данных, торговые алгоритмы. Большинство AAA-игр создано на C++, многие движки на нём написаны, так как имеется высокая производительность, контроль ресурсов и возможность оптимизации под конкретную платформу. По той же причине на этом языке пишут и драйвера, микрокоды и прочий софт для работы с железом.

Причем, C++ — это не только ООП, на самом деле он поддерживает и процедурное программирование (как C), шаблоны (метапрограммирование), функциональное программирование. Но у этого языка был и минус – управление памятью. К примеру, если забыть delete, можно получить утечку памяти – сборщика мусора тут нет.

Однако со временем сложность C++ и необходимость ручного управления памятью стали его слабыми местами, после чего Microsoft представила C# (произносится как «си шарп») - современный, безопасный и удобный язык, работающий на платформе .NET. Синтаксис у них похожий, но многие архаические особенности остались в прошлом, а библиотека теперь крайне богатая. Хочу отметить, что C++ не устарел, и нельзя его обесценивать, существуют целые поколения специалистов, а в университетах еще много лет будут ему обучать. Но нам важно понять, что C# удобнее для большинства современных задач, поэтому будем изучать именно его.

Какие возможности предоставляет C++?
	- *создавать программы, максимально эффективно использующие ресурсы процессора, памяти и устройства*;
	- *напрямую работать с адресами памяти, управлять выделением и освобождением ресурсов*;
	- *оптимизировать использование памяти под конкретную задачу*;
	- *вести разработку операционных систем, драйверов, интерфейсов взаимодействия с оборудованием*;
	- *обеспечивает прямой доступ к процессору, регистрам, портам ввода-вывода*;
	- *поддерживает модульное программирование, абстракцию, инкапсуляцию, наследование, полиморфизм*;
	- *благодаря компиляции в машинный код и минимальному уровню абстракции, обеспечивает высокую скорость выполнения*;
	- *одновременно выполнять несколько задач, использовать все ядра процессора*;
	- *можно писать как высокоуровневый код (через STL, ООП), так и низкоуровневый (через указатели, inline-ассемблер)*;
	- *может быть скомпилирован на разных архитектурах и операционных системах*;
	- *императивное, объектно-ориентированное, функциональное, обобщённое и метапрограммирование*;
	- *создание игровых движков, AAA-игр, VR/AR приложений*.

Первое, с чем можно столкнуться после перехода с Java-подобных языков к C++, это совершенно другой синтаксис. К примеру, операторы `<<` и `>>` - они изначально предназначены для битовых сдвигов, но в стандартной библиотеке C++ они перегружены (overloaded) для работы с потоками ввода-вывода:
```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl; // Вывод
    int x;
    std::cin >> x; // Ввод
}
```
`<<` — выводит данные в поток (`std::cout`, файловый поток и т.д.)

`>>` — считывает данные из потока (`std::cin`, файловый поток и т.д.)

Это перегрузка операторов , один из ключевых механизмов C++. То есть, для классов (`std::ostream`, `std::istream`) эти операторы переопределены для удобства ввода/вывода.

В C++ `std::` — это пространство имён (namespace) , которое используется для группировки стандартных библиотечных функций, классов и объектов. Это часть стандартной библиотеки C++ .

Пространства имён нужны, чтобы избежать конфликтов имён. То есть, если у нас есть функция `print()`, а в какой-то библиотеке тоже есть функция `print()`, то компилятор не запутается, если они находятся в разных пространствах имён. 

Пример:
```cpp
namespace myspace {
    void print() {
        std::cout << "Hello from myspace!" << std::endl;
    }
}

int main() {
    myspace::print(); // Вызов функции из пространства myspace
}
```
`std` — это сокращение от `standard`, и оно зарезервировано для стандартной библиотеки C++ .

| Имя | Описание |
|-----|---------|
|`std::cout`	|Объект для вывода на экран
|`std::cin`	|Объект для ввода с клавиатуры
|`std::endl`	|Специальный манипулятор, добавляет символ новой строки и очищает буфер
|`std::string`	|Класс для работы со строками
|`std::vector`	|Контейнер — динамический массив
|`std::map`, `std::set` и т.д.	|Контейнеры STL

Пример использования std::
```cpp
#include <iostream>  // Заголовочный файл, содержащий определения std::cout и std::endl

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```
Здесь:
	- `std::cout` — стандартный поток вывода
	- `<<` — перегруженный оператор вывода
	- `std::endl` — вставляет символ перевода строки и сбрасывает буфер

Почему нельзя просто писать cout вместо `std::cout`? Потому что `cout` находится внутри пространства имён `std`. Если не указывать, то компилятор скажет: «Не знаю, что такое `cout`».

Есть спорное решение - в начале кода добавить using namespace `std:`
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```
Но за это можно получить критику — это не рекомендуется, ведь если использовать namespace `std` в заголовочных файлах или больших проектах, то это может вызвать конфликты имён. Поэтому лучше явно указывать `std::`.

C++ — компилируемый язык . Программа превращается в машинный код на этапе компиляции. Нет интерпретатора или виртуальной машины (кроме специфических случаев).

Этапы выполнения программы:
	- **Компиляция** - исходный код (.cpp) → объектный код (.o / .obj);
	- **Линковка** - объектные файлы `+` библиотеки → исполняемый файл;
	- **Запуск** - исполняемый файл запускается напрямую процессором;

C++ позволяет очень низкоуровневый доступ к памяти и железу, что делает его быстрым, но и сложным.

**Как компилируется C++?**

Обычно используется компилятор, например:
	- GCC (g++)
	- Clang
	- MSVC (Microsoft Visual C++)

Каждый .cpp файл компилируется отдельно в объектный файл. Затем линкер связывает все объектные файлы и библиотеки в один исполняемый файл.
C++ наследует большинство синтаксиса от C, добавляя свои элементы ООП, шаблонов и STL.

C++ поддерживает широкий набор операторов.

Сравнение: `==` `!=` `<` `>` `<=` `>=`

Логические: `&&` `||` `!`

Побитовые: `&` `|` `^` `~` `<<` `>>`

Присваивание: `=` `+=` `-=` `*=` `/=` `%=` `&=` `|=` `^=` `<<=` `>>=`

Условный (тернарный): 
```cpp
result = condition ? valueIfTrue : valueIfFalse;
```
sizeof: 
```cpp
sizeof(int); // размер типа или переменной в байтах
```

Используется для определения типа во время выполнения (RTTI).

```cpp

```

## ООП

C++ полностью поддерживает ООП: инкапсуляция, наследование, полиморфизм, абстракция.

Объявление класса:
```cpp
class Person {
private:
    string name;

public:
    Person(string n) : name(n) {}

    void greet() const {
        cout << "Hello, my name is " << name << endl;
    }
};
```
Создание экземпляра:
```cpp
Person p("Alice");
p.greet();
```
Наследование:
```cpp
class Student : public Person {
public:
    Student(string n) : Person(n) {}
};
```
Инкапсуляция:

Доступ к членам класса контролируется модификаторами:

	- private
	- protected
	- public

Полиморфизм:

Поддерживается через виртуальные функции и переопределение:
```cpp
class Animal {
public:
    virtual void speak() { cout << "Animal sound" << endl; }
};

class Dog : public Animal {
public:
    void speak() override { cout << "Woof!" << endl; }
};
```
Конструкторы / деструкторы:
```cpp
class MyClass {
public:
    MyClass() { cout << "Constructor" << endl; }
    ~MyClass() { cout << "Destructor" << endl; }
};
```
Перегрузка функций и операторов:
```cpp
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }

// Перегрузка оператора
class Point {
public:
    int x, y;
    Point operator+(const Point& other) {
        return Point{x + other.x, y + other.y};
    }
};
```
Управление памятью:

Ручное управление через new / delete

Поддержка умных указателей (unique_ptr, shared_ptr) начиная с C++11

```cpp

```
Шаблоны (Templates):

Поддерживают обобщённое программирование.
```cpp

cout << max(3, 5);      // вызов с int
```

Мощная библиотека, содержащая контейнеры, алгоритмы и итераторы.

Примеры:

`list<T>` — двусвязный список

C++ — один из самых мощных и гибких языков программирования. Он используется в разработке игр, системном ПО, высоконагруженных серверах, embedded-системах и многом другом. Хотя он сложнее по сравнению с языками вроде Python или Kotlin, он предоставляет максимальный контроль над производительностью и ресурсами.

Давайте рассмотрим его особенности

1. Управление памятью.

В Java и C# есть сборщик мусора (GC) – не нужно думать о выделении и освобождении памяти. Объекты создаются в куче через new, но освобождаются автоматически.

В C++ нет сборщика мусора. Память управляется вручную. Объекты можно создавать локально (на стеке) и динамически (на куче):
```cpp
Person p;                    // Локальный объект (стек)
Person* p = new Person();    // Объект на куче
delete p;                    // Нужно вручную удалить
```
В C++ программист отвечает за память, это сложно, но позволяет писать более быстрый и компактный код.

2. Указатели и ссылки.

В Java нет указателей, только ссылки на объекты, которые нельзя арифметически изменять. В C++ есть указатели (`*`) и ссылки (`&`). Можно работать с адресами памяти, изменять значения напрямую.
```cpp
int x = 10;
int* ptr = &x;     // указатель на x
*ptr = 20;         // меняем значение через указатель

int& ref = x;      // ссылка на x
ref = 30;          // тоже меняется x
```

C++ даёт прямой доступ к памяти, но и ответственность за ошибки тоже на программисте.

3. Структуры и классы.

В Java только классы, struct отсутствует, все объекты – ссылочные типы.

В C++ есть class, и struct. Разница в уровне доступа по умолчанию, class - приватные члены по умолчанию, struct – публичные.
```cpp
struct Point {
    int x, y;  // public по умолчанию
};

class Circle {
    int radius;  // private по умолчанию
public:
    void setRadius(int r) { radius = r; }
};
```
В C++ struct и class – почти одно и то же, но struct часто используется для данных без логики.

4. Перегрузка операторов.

В Java операторы нельзя перегружать. Исключение `+` для строк.

В C++ полная свобода – можно переопределять операторы.
```cpp
Point operator+(const Point& a, const Point& b) {
    return Point{a.x + b.x, a.y + b.y};
}
```

C++ поддерживает операторную перегрузку, что делает математические классы удобными.

5. Шаблоны (Templates) и Generics.

В Java и C# Generics реализуются через типы-заполнители, но тип стирается во время выполнения.
```cpp
List<int> list = new List<int>();
```
В C++ шаблоны – это метапрограммирование: шаблон компилируется для каждого типа отдельно.
```cpp
template <typename T>
T max(T a, T b) {
    return (a > b) ? a : b;
}

int i = max(3, 5);      // инстанцирование для int
float f = max(3.1f, 5.6f); // инстанцирование для float
```
В C++ шаблоны – это часть компиляции, а не выполнения. Они мощнее, но сложнее в отладке.

6. Конструкторы и деструкторы.

В Java есть конструкторы, есть финализатор finalize(), но его вызов не гарантирован.
```cpp
public class MyClass {
    public MyClass() { ... }
}
```

В C++ есть деструкторы, которые вызываются при выходе из области видимости:
```cpp
class FileHandler {
    public:
        FileHandler(const char* name) { /* открываем файл */ }
        ~FileHandler() { /* закрываем файл */ }
    };
    
    {
        FileHandler file("data.txt");  // при выходе из блока вызывается ~FileHandler()
    }
```
Отличие в том, что в C++ есть RAII (Resource Acquisition Is Initialization) – управление ресурсами через деструкторы.

7. Модификаторы доступа и уровни видимости.

В Java есть модификаторы: private, protected, public, package-private.

В C++ то же самое, но уровень доступа задаётся для групп членов класса:
```cpp
class MyClass {
    private:
        int secret;
    public:
        void doSomething();
    protected:
        float internalData;
    };
```
В C++ уровень доступа задаётся до члена класса, а не рядом с каждым.

8. SLT (Standard Template Library).

C++ предоставляет мощную стандартную библиотеку, аналогичную Collections в Java или коллекциям в C#.

| Java | C# | C++ |
|------|-----|-----|
| `ArrayList<T>` | `List<T>` | `std::vector<T>` |
| `HashMap<K,V>` | `Dictionary<K,V>` | `std::map<K,V>` |
| `HashSet<T>` | `HashSet<T>` | `std::unordered_set<T>` |
| `Queue<T>` | `Queue<T>` | `std::queue<T>` |

SLT – шаблонная библиотека, очень гибка и эффективная, но требует понимания итераторов.

9. Поддержка многопоточности.

| Язык | Поддержка потоков |
|------|-------------------|
| Java | `Thread`, `Runnable`, `ExecutorService` |
| C#   | `Task`, `async/await`, `Thread` |
| C++  | `std::thread`, `std::mutex`, `std::future` |

Пример:

```cpp
#include <thread>
void threadFunc() {
    std::cout << "Hello from thread";
}

int main() {
    std::thread t(threadFunc);
    t.join();
    return 0;
}
```

В C++ нет встроенной поддержки async/await. Но можно использовать `std::future`, `std::promise`.

C++ это низкоуровневый, производительный и гибкий язык, который:
	- даёт контроль над памятью и процессором;
	- подходит для системного программирования, игр, embedded-систем;
	- требует больше внимания к деталям, чем Java или C#.

Если мы знаем Java и C#, то работа с циклами, условиями, классами нам будет понятна, однако придётся научиться управлять памятью, понимать указатели, научиться работать с STL.
