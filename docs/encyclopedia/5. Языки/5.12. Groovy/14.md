# 5.12. Циклы

# Раздел в разработке

## Циклы

Groovy предоставляет стандартные циклы, но также добавляет удобные DSL-подобные конструкции.

for:
```
for (i in 1..5) {
    println i
}
```
while:
```
int i = 0
while (i < 5) {
    println i++
}
```
each (итерация по спискам/диапазонам):
```
[1, 2, 3].each { num ->
    println num
}
```
