## Экосистема Go-приложений

```
1. Прикладные фреймворки и клиентские приложения
Стандартная библиотека net/http
Gin, Echo, Fiber
Fyne, Wails, Gio
TUI (Terminal User Interface) — Bubble Tea, TermUI

2. Серверные и фоновые службы
HTTP-серверы и микросервисы
Worker-паттерны и фоновые задачи
gRPC-сервисы
Cron-задачи и планировщики

3. Тестовые и вспомогательные проекты
Встроенная система тестирования (go test)
Ginkgo / Gomega
Testify
End-to-end тестирование — Terratest, Playwright для Go

4. Интеграционные и специализированные платформы
Работа с базами данных — database/sql, GORM, Ent
Kafka, RabbitMQ, NATS — клиентские библиотеки
Облачные SDK — AWS SDK for Go, Google Cloud Client Libraries
WebAssembly (WASM)

5. Расширения и инструменты разработки
Go Modules
go build, go run, go install
go generate
Инструменты анализа — go vet, golint (устар.), staticcheck, golangci-lint
Delve

6. Экспериментальные и нишевые направления
eBPF и системное программирование
Pixie, Cilium
Встраиваемые системы и IoT — TinyGo
Игровые движки — Ebiten
Языковые серверы и LSP
```
