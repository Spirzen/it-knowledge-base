# 5.07. Функции

## Функции

Функции

Объявление функции:
```php
function greet(string $name): string {
    return "Привет, $name!";
}
echo greet("Иван");
```

Анонимные функции:
```php
$greet = function($name) {
    return "Здравствуй, $name";
};
echo $greet("Ольга");
```
