# 5.07. Переменные и типы данных

## Переменные и типы данных

PHP – динамически типизированный язык, поэтому переменные не требуют указания типа при объявлении:
```php
$name = "Алексей";     // string
$age = 25;             // integer
$balance = 99.99;      // float
$isStudent = true;     // boolean
$nothing = null;       // null
```

В PHP есть проверка и преобразование типов:
```php
gettype($var);         // Получить тип
is_string($var);       // Проверить тип
settype($var, 'int');  // Изменить тип
(int)$var;             // Приведение через кастинг
```
