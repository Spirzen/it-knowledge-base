## Условные операторы и циклы

Условия:
```php
if ($age > 18) {
    echo "Взрослый";
} elseif ($age == 18) {
    echo "Полных 18";
} else {
    echo "Малыш";
}
```
Циклы
```php
for:

for ($i = 0; $i < 5; $i++) {
    echo $i;
}
```


while:
```php
$i = 0;
while ($i < 5) {
    echo $i++;
}
```

foreach (для массивов):
```php
$fruits = ['яблоко', 'банан', 'вишня'];
foreach ($fruits as $fruit) {
    echo $fruit . "<br>";
}
```

match:
```php
$status = match($role) {
    'admin' => 'Администратор',
    'editor' => 'Редактор',
    default => 'Гость'
};
```
