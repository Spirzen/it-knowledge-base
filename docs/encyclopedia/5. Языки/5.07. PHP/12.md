# 5.07. Фреймворки

# Фреймворки

## Фреймворки

| Фреймворк | Описание |
|-----|---------|
|Laravel	|Современный, мощный фреймворк с ORM Eloquent, маршрутизацией, Blade и многим другим.
|Symfony	|Мощный, гибкий фреймворк, часто используется для enterprise-решений.
|CodeIgniter	|Лёгкий и быстрый фреймворк, подходит для небольших проектов.
|Yii / Yii2	|Высокопроизводительный фреймворк с Gii (генератор кода).
|Zend Framework (Laminas)	|Более формальный, enterprise-ориентированный подход.
