# 5.07. Знаки препинания

## Знаки препинания

Два важных вопроса, которые мучают начинающих программистов:
1. Когда использовать кавычки двойные (`"`), одинарные (`'`), а когда апострофы (`’`)?
2. Когда использовать точки (`.`), запятые (`,`) и точку с запятой (`;`)?

Двойные (`"`) — интерполируемые строки:
```php
$name = "Alice";
echo "Hello, $name"; // Hello, Alice
```
Одинарные (`'`) — без интерполяции:
```php
echo 'Hello, $name'; // Hello, $name
```
Апострофы (`’`) — не поддерживаются в синтаксисе.

Точка (`.`) используется для конкатенации строк:
```php
echo "Hello, " . $name;
```
Запятая (,) для разделения аргументов, элементов массива:
```php
function greet($name, $age) {}
$arr = [1, 2, 3];
```
Точка с запятой (;) обязательна после каждой инструкции:
```php
echo "Hello";
$x = 5;
```
