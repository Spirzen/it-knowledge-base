# 5.09. Циклы

# Раздел в разработке

## Циклы

Kotlin предоставляет удобные и понятные конструкции циклов.

for:
```kotlin
for (i in 1..5) {
    println(i)
}

for (c in "Kotlin") {
    println(c)
}
```
while:
```kotlin
var i = 0
while (i < 5) {
    println(i++)
}
```
do-while:
```kotlin
var j = 0
do {
    println(j++)
} while (j < 5)
```
forEach (для коллекций):
```kotlin
val list = listOf("a", "b", "c")
list.forEach { item ->
    println(item)
}
```
