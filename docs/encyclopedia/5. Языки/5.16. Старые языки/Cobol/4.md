# Типы данных Cobol

## Типы данных

```
Типы данных
PIC (PICTURE) — описание формата данных: цифры, символы, десятичные.
Пример: PIC 9(5) — целое из 5 цифр, PIC X(20) — строка из 20 символов.
Групповые записи (GROUP ITEM).

```
