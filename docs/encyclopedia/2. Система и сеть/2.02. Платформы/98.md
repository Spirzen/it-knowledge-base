# 2.02. Итоги 

Основные категории платформ:
	- Аппаратная часть;
	- Программная среда;
	- Среда выполнения.
  
Три основных правила работы с платформами:
1. Учитывайте аппаратные требования целевой платформы.
2. Выбирайте подходящую среду выполнения.
3. Тестируйте приложения на всех целевых платформах.

Три фундаментальных момента:
	- Каждая платформа имеет свои особенности и ограничения;
	- Выбор платформы влияет на производительность и совместимость;
	- Мультиплатформенность расширяет доступность приложений.
