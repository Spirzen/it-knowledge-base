# Практикум — проекты по ИИ

<div class="article-tags">
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

<span class="complexity-badge">Разработчику</span>

Энциклопедия даёт **теорию, архитектуру и паттерны**; длинный код — в [lab](/lab/Примеры/1149) и на [code.spirzen.ru](https://code.spirzen.ru/). Для закрепления "руками" удобен внешний сборник **[Hands-On-AI-Engineering](https://github.com/Sumanth077/Hands-On-AI-Engineering)** — ~40 проектов с README, `requirements.txt` и `.env.example` — RAG, агенты, OCR, мультимодальность. Лицензия MIT; язык инструкций — английский.

Ниже — **карта обучения** — сначала прочитайте главу энциклопедии, затем клонируйте проект и запустите по README. Не обязательно проходить всё подряд — выберите ветку под свою цель.

Для **классического глубокого обучения** (CNN, LSTM, обучение своих весов) начните с [ветки DL в Colab](#vetka-dl--glubokoe-obuchenie-v-colab); для LLM, RAG и агентов — с этапа 0 и веток 1–4.

<div class="callout callout--info">
  <div class="callout-title">Что не копируем</div>

  <div class="callout-body">
  Туториалы из репозитория не дублируются в энциклопедии. Здесь — только <strong>маршрут</strong> и связь "навык ↔ проект". Конкретные имена моделей в репо меняются быстрее, чем паттерны — ориентируйтесь на архитектуру, а не на чекпоинт.
  </div>
</div>

## Как пользоваться картой

1. Пройдите **базовый маршрут** из [раздела "ИИ"](/encyclopedia/6-ai/ai) хотя бы до [RAG, MCP и агентов](/encyclopedia/6-ai/6-04-modeli-i-instrumenty/121).
2. Выберите **ветку** (RAG, агенты, OCR, мультимодальность).
3. Клонируйте репозиторий: `git clone https://github.com/Sumanth077/Hands-On-AI-Engineering.git`
4. Перейдите в папку проекта, скопируйте `.env.example` → `.env`, заполните API-ключи.
5. После запуска сравните код с теорией в указанной главе и зафиксируйте, что изменили бы для prod ([AgentOps](/encyclopedia/6-ai/6-08-agentops/intro)).

Базовый URL проекта: `https://github.com/Sumanth077/Hands-On-AI-Engineering/tree/main/<путь>`.

## Ветка DL — глубокое обучение в Colab

Среда: [Google Colab](https://colab.research.google.com/) (**Runtime → GPU**). Теория и код Keras/TensorBoard — [Keras и TensorFlow](/encyclopedia/6-ai/6-03-neyroseti/114); выбор Dense/CNN/LSTM — [Архитектуры](/encyclopedia/6-ai/6-03-neyroseti/113). Подготовка данных (нормализация, split, аугментация) — [Data Science](/encyclopedia/3-data-markup/3-11-analiz-dannyh/12).

| Сначала в энциклопедии | Навык | Практика в Colab / локально |
|------------------------|-------|-----------------------------|
| [Keras и TensorFlow — нейросети — MNIST, CNN](/encyclopedia/6-ai/6-03-neyroseti/114) | `Conv2D`, compile, fit, callbacks | Ноутбук: MNIST или CIFAR-10 на Keras; кривые loss/accuracy через matplotlib или TensorBoard |
| [Практикум — распознавание цифр на PyTorch — практикум PyTorch](/encyclopedia/5-languages/5-02-python/335) | CNN end-to-end, сохранение весов | Локальный [TestPyTorch](/encyclopedia/5-languages/5-02-python/335) или порт архитектуры в Colab |
| [Архитектуры нейронных сетей — CNN](/encyclopedia/6-ai/6-03-neyroseti/113) + [Распознавание лиц, объектов и текста — лица](/encyclopedia/6-ai/6-06-primenenie-ii/120) | Классификация изображений, метрики | Датасет **FER2013** или **CK+**: grayscale 48×48, 7 классов эмоций; CNN + `ImageDataGenerator` только на train |
| [Архитектуры нейронных сетей — LSTM](/encyclopedia/6-ai/6-03-neyroseti/113) + [ML — пример 2](/encyclopedia/6-ai/6-02-mashinnoe-obuchenie/1) | Последовательности, char-level RNN | Корпус текста (например "Война и мир" с [Project Gutenberg](https://www.gutenberg.org/)): посимвольная LSTM, генерация по seed-строке |
| [Разбиение данных и кросс-валидация — разбиение выборки](/encyclopedia/6-ai/6-02-mashinnoe-obuchenie/6) + [Смещение, дисперсия и переобучение — переобучение](/encyclopedia/6-ai/6-02-mashinnoe-obuchenie/8) | train/val/test, EarlyStopping | В каждом ноутбуке: hold-out test не трогать до финала; validation — для callbacks |

```mermaid
flowchart LR
  E1[114 Keras + TensorBoard] --> P1[MNIST / CIFAR]
  P1 --> P2[FER2013 — эмоции]
  E2[113 LSTM] --> P3[Char-RNN — генерация текста]
  P2 --> E3[120 — распознавание в проде]
```

<div class="callout callout--warning">
  <div class="callout-title">Аугментация и утечка</div>

  <div class="callout-body">
  Повороты, отражения и сдвиги яркости применяйте <strong>только к train</strong>, после разбиения выборки. Иначе test "видит" варианты тех же кадров — метрики завышены. Подробнее — <a href="/encyclopedia/6-ai/6-06-primenenie-ii/120">распознавание лиц и объектов</a>.
  </div>
</div>

Минимальный шаблон аугментации в Keras:

```python
from tensorflow.keras.preprocessing.image import ImageDataGenerator

train_datagen = ImageDataGenerator(
    rescale=1.0 / 255,
    rotation_range=15,
    horizontal_flip=True,
    validation_split=0.2,
)
train_flow = train_datagen.flow_from_directory(
    "data/train", target_size=(48, 48), batch_size=32, subset="training"
)
val_flow = train_datagen.flow_from_directory(
    "data/train", target_size=(48, 48), batch_size=32, subset="validation"
)
```
