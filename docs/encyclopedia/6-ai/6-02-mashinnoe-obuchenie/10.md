**Scikit-learn** — стандартная библиотека для **табличного** машинного обучения на Python — регрессия, классификация, кластеризация, предобработка и оценка моделей в едином API. Данные в sklearn — массивы NumPy; базовые операции — [NumPy — массивы и матрицы](/lab/Примеры/1129). Для изображений, длинных текстов и больших нейросетей обычно переходят к TensorFlow или PyTorch — см. [Keras и TensorFlow](/encyclopedia/6-ai/6-03-neyroseti/114). Обзор всех типов обучения — в [Машинное обучение](/encyclopedia/6-ai/6-02-mashinnoe-obuchenie/1); практический end-to-end пример — [проект Melbourne](/encyclopedia/6-ai/6-02-mashinnoe-obuchenie/7).

## Когда достаточно scikit-learn

| Задача | Типичные алгоритмы sklearn |
|--------|----------------------------|
| Прогноз числа (цена, спрос) | `LinearRegression`, `GradientBoostingRegressor`, `RandomForestRegressor` |
| Категория (спам, отток) | `LogisticRegression`, `RandomForestClassifier`, `SVC` |
| Группы без меток | `KMeans`, `DBSCAN` |
| Сжатие признаков | `PCA`, `TruncatedSVD` |

Данные — таблица: строки — объекты, столбцы — признаки. Перед обучением нужны [кодирование категорий](/encyclopedia/6-ai/6-02-mashinnoe-obuchenie/4) и [честное разбиение train/test](/encyclopedia/6-ai/6-02-mashinnoe-obuchenie/6).

## Единый контракт API

Почти все модели sklearn поддерживают три метода:

- `fit(X, y)` — обучение;
- `predict(X)` — прогноз;
- `score(X, y)` — быстрая оценка (для классификаторов — accuracy по умолчанию).

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

clf = RandomForestClassifier(n_estimators=100, random_state=42)
clf.fit(X_train, y_train)
print(clf.score(X_test, y_test))
```

## Классификация — прогноз категории

**Классификация** предсказывает метку класса — 0/1, "кошка"/"собака", один из нескольких видов.

```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, confusion_matrix

clf = LogisticRegression(max_iter=500)
clf.fit(X_train, y_train)
y_pred = clf.predict(X_test)

print(classification_report(y_test, y_pred))
print(confusion_matrix(y_test, y_pred))
```

При **дисбалансе классов** (99% "не спам", 1% "спам") accuracy вводит в заблуждение. Смотрите **precision**, **recall**, **F1** и матрицу ошибок — подробнее в разделе метрик [Машинное обучение](/encyclopedia/6-ai/6-02-mashinnoe-obuchenie/1).

`predict_proba(X)` возвращает вероятности по классам — удобно для порога "срабатывания" в проде.

## Pipeline — без утечки данных

Ошибка новичка: сначала `StandardScaler` на **всей** таблице, потом `train_test_split`. Статистики scaler "видят" test — метрики завышаются.

**Pipeline** объединяет предобработку и модель; `fit` на train применяет scaler только к train.

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("clf", SVC(kernel="rbf", probability=True)),
])
pipe.fit(X_train, y_train)
print(pipe.score(X_test, y_test))
```

Тот же pipeline можно передать в **GridSearchCV** — перебор гиперпараметров внутри кросс-валидации на train.

## Сохранение модели

```python

import joblib

joblib.dump(pipe, "model.joblib")
loaded = joblib.load("model.joblib")
loaded.predict(X_test[:1])
```

В проде версионируйте и **модель**, и **схему признаков** (имена и типы столбцов), иначе после переобучения API сломается.
