## Что обычно разрешено и запрещено

Правила задаёт **школа или вуз** — читайте локальный регламент. Если неясно — спросите преподавателя **до** сдачи.

| Действие | Обычно разрешено | Обычно запрещено |
|----------|------------------|------------------|
| Объяснение темы простыми словами | Да | — |
| Идеи плана с вашей доработкой | Да | Сдавать план без понимания |
| Черновик кода с разбором (если курс разрешает) | Да | Сдать код без понимания и тестов |
| Готовая курсовая или реферат целиком | — | Да (плагиат) |
| Экзамен / контрольная в реальном времени | — | Да |
| Скрыть использование ИИ, если требуют раскрыть | — | Да |
| Проверка грамматики своего текста | Часто да | Перевод чужого текста и сдача |
| Генерация картинок для презентации | По регламенту | Выдача за своё авторство без указания |

**Важно** — слово "обычно". MIT, HSE, МГУ и школа №N могут формулировать по-разному. Ниже — примеры политик вузов; ваш регламент важнее.

## Академическая честность

Вы сдаёте **свою** работу и **своё** понимание.

**Проблемно**

- скопировать ответ модели без указания источника;
- не уметь объяснить сданный текст на защите;
- использовать ИИ на экзамене вместо себя;
- подставлять одногруппникам готовые ответы на оцениваемые работы.

**Допустимая схема**

1. Сами читаете материалы (учебник, лекция, статья).
2. ИИ **объясняет** непонятное.
3. Пишете **своими словами**, прогоняете через свою структуру аргумента.
4. Указываете использование ChatGPT / Copilot, если регламент требует.
5. Проверяете факты и (для кода) запускаете тесты.

**Правило:** если без ИИ не можете ответить на устный вопрос по теме — материал ещё не усвоен.

См. [ответственное использование](/encyclopedia/6-ai/6-06-primenenie-ii/3).

## Как учиться с ИИ — общие принципы

| Цель | Хороший промпт | Плохой подход |
|------|----------------|---------------|
| Понять тему | "Объясни X простыми словами, пример из …" | "Реши за меня" |
| Практика | "Дай задачу без ответа, потом проверь мой" | "Дай ответ сразу" |
| Код | "Подскажи направление, не полное решение" | Вставить код без запуска |
| Язык | "Исправь грамматику, сохрани смысл" | Перевести чужой текст и сдать |
| Эссе | "Покритикуй мой черновик, не переписывай целиком" | "Напиши реферат на 10 страниц" |

Шаблоны — [Prompt engineering — библиотека](/lab/Примеры/1150). Теория контекста — [113](/encyclopedia/6-ai/6-01-vvedenie-v-ii/113).

**Педагогика "Socratic"**

Просите модель **не давать ответ**, а задавать наводящие вопросы:

- "Я решаю задачу по интегралам. Задавай мне по одному вопросу, не показывая решение."
- "Проверь мой шаг 3 — где ошибка, но не исправляй за меня."

## ИИ по предметам — математика

Математика — область, где модель **уверенно ошибается** в многошаговых выкладках.

**Разрешённое использование**

- объяснение определения (группа, предел, матрица);
- аналогии ("производная — скорость изменения");
- генерация **дополнительных** задач того же типа;
- проверка **вашего** решения с указанием возможной ошибки.

**Риски**

- неверный шаг в середине доказательства;
- "теорема" без названия, которой нет;
- правильный ответ при неверном обосновании.

**Как работать**

1. Решаете сами на бумаге.
2. ИИ проверяет — вы сверяете с учебником / Wolfram / преподавателем.
3. На экзамене — только калькулятор там, где разрешено регламентом.

**Промпты из библиотеки** (адаптируйте под [1150](/lab/Примеры/1150)):

- "Объясни метод подстановки для этого интеграла, без полного решения."
- "Есть ошибка в шаге: … — укажи тип ошибки, не решай заново."
- "Сгенерируй 5 задач уровня ЕГЭ по теме логарифмы, без ответов."

**Школа и вуз**

- Школа — часто строже к полным решениям из чата.
- Вуз — допустим CAS (Computer Algebra System) по правилам кафедры.

## ИИ по предметам — программирование и IT

Курсы по [коду](/encyclopedia/4-code-dev/code-dev) — одни из первых, где Copilot стал нормой, но правила **различаются**.

**Часто разрешено**

- объяснение ошибки компилятора;
- подсказка структуры алгоритма;
- генерация **тестов** к вашему коду;
- рефакторинг с вашим ревью;
- документация к **вашему** API.

**Часто запрещено на экзамене**

- любой ИИ в live coding;
- автогенерация лабы целиком.

**Хорошая практика**

- Коммиты в git с вашими промежуточными шагами — [Git](/encyclopedia/4-code-dev/4-13-osnovy-raboty-s-git/intro).
- README: "Used Copilot for boilerplate tests."
- Понимание каждой строки перед сдачей.

**Промпты**

- "Объясни, почему segfault на строке 42, не переписывая весь файл."
- "Напиши unit-тесты для моей функции sortList — только тесты."
- "Какой паттерн подойдёт для этой задачи — без кода."

**Курсы алгоритмов**

Преподаватели проверяют **асимптотику и доказательство корректности** — Copilot может дать O(n²) вместо O(n log n). Всегда доказывайте сами.

См. [разработка и отладка](/encyclopedia/4-code-dev/4-14-razrabotka-i-otladka/intro).

## ИИ по предметам — гуманитарные дисциплины

История, философия, литература, право (учебный уровень), социология.

**Польза**

- структура эссе (тезис — аргумент — контрпример);
- список **направлений** для литобзора (потом проверить источники);
- объяснение термина ("структuralism в лингвистике");
- языковая правка **вашего** текста.

**Риски**

- выдуманные источники и цитаты;
- анахронизмы в истории;
- "юридические" советы без статей закона.

**Как работать**

- Каждая ссылка — открыть и прочитать.
- Цитаты — только из проверенного PDF или библиотеки.
- Аргument — ваш; ИИ не автор мысли.

**Промпты**

- "Покритикуй слабые места аргумента в моём абзаце …"
- "Какие 3 школы мысли по теме X — кратко, без выдуманных имён?"
- "Помоги составить план эссе на 5 разделов — без текста разделов."

Для права РФ на учебном уровне — учебник и [консультант](https://www.consultant.ru/), не чат. Продакшен-право — [115](/encyclopedia/6-ai/6-06-primenenie-ii/115).

## ИИ по предметам — естественные науки

Физика, химия, биология, география.

**Польза**

- визуализация концепций ("объясни дифракцию на примере");
- разбор формулы размерности;
- карточки для запоминания (с проверкой по учебнику).

**Риски**

- неверные константы и единицы;
- устаревшие модели (планета-девять в старых данных);
- биология — опасные "life hack" советы.

**Лабораторные работы**

- ИИ **не заменяет** эксперiment и протокол.
- Расчёты — сверка с калькулятором и формулами из методички.

---

## ИИ по предметам — иностранные языки

**Польза**

- диалог-практика с исправлением ошибок;
- объяснение grammar point на русском;
- варианты формулировок (register formal/informal).

**Риски**

- сдать essay на English целиком от GPT — плагиат и нулевой speaking skill;
- модель учит редкие или неверные идиомы.

**Практика**

- Пишете абзац сами → ИИ правит → вы переписываете ещё раз **без** подсказок.
- Speaking — tutor, не только чат.

**Промпты** (см. раздел Languages в [1150](/lab/Примеры/1150)):

- "Исправь только grammar, не меняй стиль."
- "Задай мне 10 вопросов на уровне B1 по теме travel."

## Проверка фактов и галлюцинации

Модель может **уверенно ошибаться** — выдуманные статьи, даты, теоремы.

| Тип работы | Как проверять |
|------------|---------------|
| История, право | Учебник, первоисточник, библиотека |
| Медицина, психология | Не лечиться и не диагностировать по чату |
| Программирование | Запуск, тесты, [документация](/encyclopedia/4-code-dev/code-dev) |
| Математика | Вручную или Wolfram / калькулятор |
| Ссылки | Открыть URL — часто 404 |
| Статистика | Первичный датасет, не "цифра из чата" |

**Красные флаги**

- слишком гладкий текст без конкретных источников;
- DOI и ISBN, которых нет в CrossRef;
- "Исследование 2023 года доказало" без названия.

## Детекторы ИИ и антиплагиат

Преподаватели используют антиплагиат и детекторы ИИ. Оба **ненадёжны**:

- детектор может пометить **ваш** текст как ИИ;
- ИИ-текст можно переписать и обойти детектор;
- важнее **понимание на защите**, чем "процент AI".

**Студенту**

- сохраняйте черновики, git history, заметки (доказательство процесса);
- ведите learning journal по курсу.

**Преподавателю**

- оценивать понимание (устный опрос, live coding, защита);
- не ставить "0" только по детектору без беседы.

## Этика в группах и проектах

- не генерируйте **готовые** ответы одногруппникам на оцениваемые задания;
- в учебных open source проектах указывайте помощь ИИ в README;
- ИИ может помочь при дислексии или языковом барьере — **допустимое вспомогательное использование**, если регламент не запрещает;
- групповой проект — заранее договоритесь, кто и как использует Copilot.

## Набор преподавателя (teacher toolkit)

### 1. Политика курса на первой лекции

Один слайд или PDF:

- что можно (explain, grammar, ideation);
- что нельзя (exam, full draft);
- формат disclosure ("В конце работы: использованные инструменты");
- санкции и возможность консультации.

### 2. Задания, устойчивые к читерству

- защита с вопросами по каждому абзацу;
- in-class writing без телефона;
- уникальный кейс по локальным данным (модель не видела);
- поэтапная сдача (outline → draft → final);
- peer review **до** финала.

### 3. Обучение промптам, а не только запрет

Мини-воркshop 45 мин:

- разбор [библиотеки промптов](/lab/Примеры/1150);
- упражнение "плохой и хороший промпт";
- демо галлюцинации на выдуманных ссылках.

### 4. Rubric с критерием "process evidence"

- черновики;
- список источников, которые реально открывали;
- устная часть 10 минут.

### 5. Коммуникация с деканатом

Единый шаблон политики факультета лучше 15 противоречивых устных правил.

## Примеры политик вузов (обобщённо)

Реальные документы меняются; ниже **типы** формулировок, которые встречаются в открытых policy MIT, Stanford, HSE и др.

### Модель "полный запрет на оцениваемых работах"

- ИИ нельзя на homework, essay, exam.
- Допустимо только с письменным разрешением instructor.

**Для студента** — уточняйте исключения (grammar-only иногда разрешают).

### Модель " disclosure + ответственность студента"

- ИИ можно как инструмент.
- Обязательно указать, что использовали и как.
- Студент отвечает за факты и плагиат.

**Пример фразы для работы**

> "При подготовке использовал ChatGPT 4 для структуры раздела 2 и проверки grammar; все факты проверены по …"

### Модель "уровни по курсу"

- Course A (программирование): Copilot разрешён с git history.
- Course B (philosophy): только spell-check.
- Указано в syllabus.

### Модель "анalog AI"

- Разрешён калькулятор и spell-checker — по аналогии разрешён и ИИ для X.

**Российский контекст**

- Многие вузы ещё формулируют политику; **ваш** локальный акт в LMS главнее этой статьи.
- Школьники — часто stricter; родитель + классный руководитель.

## Диплом, магистерская, исследование

**Высокий риск**

- закрытые данные компании в промпте;
- co-authored text без указания;
- fabricated literature review.

**Практика**

- Согласование с научным руководителем **до** использования ИИ.
- ИИ для LaTeX-вёрстки и grammar — часто ok; для results section — нет.
- Raw data only in [local LLM](/encyclopedia/6-ai/6-05-razrabotka-ii/113).

## Школьникам и родителям

**Школьнику**

- ИИ — репетitor, не автор сочинения.
- Олимпиады и ЕГЭ в аудитории — правила ЦИК/организаторов, не чат.

**Родителям**

- обсудите правила класса;
- не делайте за ребёнка проект "с ChatGPT" — он не научится;
- следите за приватностью (не фото документов в бота).

## Доступность (accessibility)

ИИ может быть **reasonable accommodation**:

- краткое пересказывание длинного текста;
- помощь с формулировками при дислексии;
- субтитры и перевод.

Нужно согласование со школьной/вузовской службой поддержки и регламентом.

## ИИ в школьной программе — предметные нюансы

### Алгебра и геометрия (7–11 класс)

- ИИ для **проверки** вашего решения после урока — ok с осторожностью.
- Олимпиадные задачи — модель часто даёт нетиповой метод; учитель заметит.
- Графики и GeoGebra — строите сами; ИИ только объясняет концепцию.

### Обществознание и история

- Факты (даты, договоры) — только учебник.
- ИИ помогает составить **план** сочинения ЕГЭ, не текст целиком.
- Спорные темы — несколько источников, не один чат.

### Информатика (Python, 8–11)

- Часто разрешён IDE с Copilot на проектах — читайте условие олимпиады.
- На экзамене ОГЭ/ЕГЭ информатика — только разрешённые материалы.


## Университетские политики — разбор формулировок

### "Permitted with attribution"

Разрешено с указанием инструмента в footnote или appendix. Студент пишет:

> "Sections 2–3 drafted with assistance of Claude 3.5; all citations verified by author."

### "AI-free exams"

Любой ИИ на proctored exam = academic misconduct. Подготовка с ИИ до exam — по syllabus.

### "Instructor discretion"

По умолчанию запрет; преподаватель может разрешить в email. **Сохраняйте** письмо.

### "Allowed for code documentation only"

Copilot для docstrings — ok; алгоритм core — руками.

### Российские вузы (типовые тренды 2024–2026)

- Приказы о академической честности дополняют пунктом про генеративный ИИ.
- LMS ( Moodle / custom ) — checkbox "работа моя, ИИ указан".
- Некоторые кафедры IT **поощряют** Copilot как industry skill с отчётом.

Всегда проверяйте PDF на сайте деканата.

## ИИ в образовании на уровне государства

Большинство материалов этой главы — про **локальные правила**: syllabus вуза, регламент школы, академическую честность. Отдельный тренд — когда компетенции в области ИИ закрепляют **на уровне национальной программы**.

В **июле 2026 года** Китай объявил о масштабной интеграции ИИ во все уровни системы образования. Государственный совет КНР опубликовал **пятилетний план**, в котором навыки работы с искусственным интеллектом должны стать одним из **базовых** для учащихся — наряду с традиционной грамотностью, а не только опцией на факультетах STEM.

По документу образовательные учреждения обязаны:

- внедрять обучение технологиям ИИ;
- развивать **ИИ-грамотность** — понимание возможностей, ограничений и рисков моделей;
- формировать навыки решения **практических** задач с интеллектуальными системами.

Реализацию поручили **региональным** администрациям — типичная для КНР схема: центральная политика + местное исполнение. Инициатива вписана в более широкую стратегию технологического лидерства и подготовки кадров под суверенный стек (Qwen, DeepSeek и др. — см. [роль ИИ в трансформации профессий](/encyclopedia/6-ai/6-06-primenenie-ii/2)).

Для сравнения: в большинстве стран (включая РФ) политика пока фрагментирована — отдельные курсы в вузах, рекомендации министерств, локальные запреты на чат-боты на экзаменах ([ИИ и право в РФ](/encyclopedia/6-ai/6-06-primenenie-ii/115)). Китайский план — один из первых явных шагов к тому, чтобы **ИИ-грамотность** стала системным требованием, а не добровольным навыком «для продвинутых».

### Начальная школа (1–4)

### Бакалавриат

- Разные курсы — разные правила; syllabus каждый семестр.
- Стажировка — NDA компании важнее campus policy.

### Магистратура и аспирантура

- Research integrity — no fabricated data; ИИ для prose edit после advisor ok.
- Публикации — journal policy on AI authorship.

## Работа с источниками — пошагово

## FAQ

**Можно ли Grammarly / встроенную проверку орфографии?**

Обычно да; это borderline "ИИ" — смотрите syllabus.

**Преподаватель запретил, но все пользуются — что делать?**

Formal запрет важен для академической честности; обсудите на курсе инициативу изменить policy.

**ИИ для перевода статьи для себя?**

Для личного понимания — ok; цитировать перевод как первоисточник — нет.

**Можно ли использовать ИИ для презентации PowerPoint?**

Если регламент разрешает assistive design — да с маркировкой слайдов "layout suggested by AI"; текст выступления — ваш.

**Как указать ИИ в bibliography?**

Отдельная строка: "OpenAI ChatGPT (2026). Used for grammar check on 2026-03-01."

**Помогает ли ИИ при написании мотивационного письма в магистратуру?**

Draft структуры — ok; финальный текст и правда о вашем опыте — только ваши; приёмная комиссия ценит authenticity.
