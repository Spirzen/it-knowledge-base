## FAQ — Часто задаваемые вопросы

Типичные сбои и ситуации, с которыми сталкиваются новички после раздела. Здесь — **что делать и где копать в главах**; определения терминов — в [оглавлении](./intro) и профильных статьях.

<div class="faq-list">

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `julia` не находится после установки с julialang.org.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> На Windows отметьте "Add Julia to PATH" в установщике; на Linux/macOS добавьте `bin` в PATH. Проверьте <strong>`julia --version`</strong> (1.9+). Подробнее здесь — [первая программа](./7.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Первый запуск функции занимает секунды, повторный — мгновенный.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Это <strong>JIT-компиляция</strong> через LLVM: первый вызов с данным набором типов компилирует метод. Для бенчмарков прогрейте вызов или используйте `@time` после warmup. Подробнее здесь — [основы](./2.md), [архитектура](./3.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `] add CSV` в скрипте `.jl` — синтаксическая ошибка.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Режим пакетов <strong>только в REPL</strong> после ввода `]`. В скрипте используйте `using Pkg; Pkg.add("CSV")` один раз, затем `using CSV` в проекте с `Project.toml`. Подробнее здесь — [основы](./2.md), [первая программа](./7.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `using DataFrames` — "Package DataFrames not found".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Пакет не установлен в текущем окружении. В REPL: <strong>`] add DataFrames`</strong>, проверьте `] st`. Активируйте проект: `] activate .`. Подробнее здесь — [простые приложения](./103.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `A * B` для матриц дал ошибку размерности — в Python `*` умножал поэлементно.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> В Julia <strong>`*` — матричное умножение</strong>, поэлементное — `.*` (broadcasting). Подробнее здесь — [основы](./2.md), [управляющие конструкции](./5.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `sin(x)` работает, `sin.(x)` — "method not defined" для моего типа.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Точка включает <strong>broadcast</strong> по элементам; тип должен поддерживать `sin` для скаляра. Для своих структур определите метод или используйте `@. sin(x)`. Подробнее здесь — [управляющие конструкции](./5.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `1:10` и `[1:10]` — разные вещи, off-by-one в цикле.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>`1:10`</strong> — range (ленивый); <strong>`[1:10]`</strong> — вектор. В `for i in 1:n` верхняя граница включительна. Подробнее здесь — [управляющие конструкции](./5.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `mean(df.price)` вернул `NaN` — в колонке есть пропуски.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Значение <strong>`missing`</strong> распространяется как NA в R. Используйте `mean(skipmissing(df.price))` или `dropmissing` перед агрегацией. Подробнее здесь — [простые приложения](./103.md), [типы](./4.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `CSV.read("data.csv", DataFrame)` — "ArgumentError: column :price not found".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Проверьте имена через <strong>`names(df)`</strong>, регистр и BOM в UTF-8. Разделитель может быть `;` — параметр `delim`. Подробнее здесь — [простые приложения](./103.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Глобальная переменная в цикле — код в 100 раз медленнее, чем в функции.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> JIT плохо оптимизирует код с <strong>нестабильными глобалами</strong>. Оберните логику в функцию, передавайте аргументы, проверьте `@code_warntype`. Подробнее здесь — [архитектура](./3.md), [функции](./6.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `MethodError: no method matching foo(::Float64, ::Int64)` — функция "есть".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> У функции нет метода для <strong>этой комбинации типов</strong> (multiple dispatch). Добавьте метод или приведите типы. Подробнее здесь — [типы и диспетчеризация](./4.md), [функции](./6.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Добавил метод к функции из Base — "invalid redefinition".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Расширять чужие функции можно через <strong>import Base: sin; sin(x::MyType)</strong> в своём модуле, не копируя исходник. Следуйте правилам type piracy. Подробнее здесь — [функции и макросы](./6.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `struct` vs `mutable struct` — изменил поле, получил ошибку.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Обычный <strong>`struct` неизменяем</strong>; для мутаций — `mutable struct` или пересоздание объекта. Immutable struct быстрее в hot loop. Подробнее здесь — [типы](./4.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `{1, 2, 3}` в Julia — не список, а что-то другое.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Фигурные скобки — <strong>словарь `Dict`</strong> (или множество для символов). Вектор — `[1, 2, 3]`. Подробнее здесь — [основы](./2.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `include("other.jl")` дважды — дублирование определений.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `include` выполняет файл в текущем модуле. Для библиотек используйте <strong>`module` + `using`</strong> и проект с `Project.toml`. Подробнее здесь — [функции](./6.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> REPL в VS Code: изменения в файле не видны без перезапуска.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> После правки выполните <strong>`include("file.jl")`</strong> или используйте Revise.jl в dev-режиме. Подробнее здесь — [первая программа](./7.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `@time` показывает огромные allocations на простом цикле.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Типично при <strong>росте вектора в цикле</strong> (`push!` без `sizehint!`) или boxing. Preallocate массив, используйте `@views`, `@inbounds` только после проверок. Подробнее здесь — [функции](./6.md), [архитектура](./3.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `Random.seed!(42)` — другой Julia version, другие случайные числа.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Поток RNG зависит от версии и алгоритма. Для воспроизводимости фиксируйте <strong>версию Julia в Project.toml</strong> и документируйте seed. Подробнее здесь — [архитектура](./3.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> HTTP.jl сервер — порт занят после Ctrl+C.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Процесс Julia мог остаться в фоне. Завершите его в диспетчере задач или смените порт в <strong>`HTTP.serve`</strong>. Подробнее здесь — [простые приложения](./103.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> JSON3.write для struct — поля не сериализуются.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Нужен <strong>`@derive JSON3.StructTypes`</strong> или ручная конвертация в Dict. Проверьте имена полей и типы. Подробнее здесь — [простые приложения](./103.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `using Plots` — долгая установка и precompile на каждом запуске.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Первый `using` после `add` компилирует пакет — это норма. Используйте <strong>системный image</strong> (`PackageCompiler`) только когда pipeline стабилен. Подробнее здесь — [архитектура](./3.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Unicode-имя `α(x) = x^2` — редактор ругается на кодировку файла.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Julia поддерживает Unicode в идентификаторах; файл сохраните в <strong>UTF-8</strong>. В команде договоритесь о стиле (ASCII vs греческие буквы). Подробнее здесь — [основы](./2.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `1/2` дало `0.5`, а `1//2` — `1//2` — зачем два деления?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>`//`</strong> — рациональное число `Rational{Int}` без потери точности; `/` — всегда float для int. Для символьной математики удобны рационали. Подробнее здесь — [типы](./4.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Пришёл из MATLAB — индексация с 1, но `A[0]` не работает.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Julia, как MATLAB/R, <strong>1-based</strong>; индекс 0 — ошибка. End — `lastindex(A)` или `A[end]`. Подробнее здесь — [типы](./4.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `try/catch` в hot loop замедляет код.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Исключения в Julia дороги; в численном коде <strong>валидируйте вход</strong> и возвращайте `Union`/`Result`-подобные типы. `try` — для I/O и границ. Подробнее здесь — [управляющие конструкции](./5.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Два окружения на одном ПК — пакеты "перепутались".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Активируйте проект: <strong>`] activate /path/to/project`</strong>. Пакеты живут в `.julia/environments/`, не глобально смешивайте dev и prod. Подробнее здесь — [основы](./2.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> После раздела — Flux, DifferentialEquations или углубить DataFrames?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Закрепите [простые приложения](./103.md) и CSV-pipeline. ML — после уверенного broadcasting и типов; DE — после [функций](./6.md). Подробнее здесь — [оглавление](./intro).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Julia vs Python speed — правда ли Julia быстрее?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> В численных циклах после JIT Julia часто близка к C; Python выигрывает экосистемой, а не raw speed. Первый вызов в Julia медленнее из-за компиляции. Подробнее здесь — [основы](./2.md), [архитектура](./3.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Julia vs R для статистики — что выбрать?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> R — зрелая статистика и CRAN; Julia — скорость и один язык для симуляций и HPC. Подробнее здесь — [оглавление](./intro), [R](../5-23-r/intro).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Julia vs MATLAB — можно ли заменить MATLAB?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Julia бесплатна и open source, синтаксис близок к математической записи; лицензии MATLAB не нужны. Миграция — постепенная. Подробнее здесь — [история](./1.md), [основы](./2.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Как установить Julia на Windows 11?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Установщик с julialang.org, галочка PATH; проверка `julia --version`. IDE — VS Code + Julia extension. Подробнее здесь — [первая программа](./7.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Julia slow first run JIT — это нормально?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Да: первый вызов функции <strong>компилируется в LLVM</strong>, повторные — быстрые. Прогрейте код перед бенчмарком. Подробнее здесь — [основы](./2.md), [архитектура](./3.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Julia broadcasting dot syntax — что значит точка в .*?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Точка включает <strong>поэлементную</strong> операцию; `*` — матричное умножение, `.*` — по ячейкам. Макрос `@.` распространяет точку. Подробнее здесь — [управляющие конструкции](./5.md), [основы](./2.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Julia multiple dispatch explained — один function много методов?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Выбор реализации по <strong>типам всех аргументов</strong>, не только первого. Подробнее здесь — [типы и диспетчеризация](./4.md), [функции](./6.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Julia add package Pkg — как установить DataFrames?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> В REPL введите `]`, затем `add DataFrames`; в скрипте — `using Pkg; Pkg.add("DataFrames")`. Подробнее здесь — [основы](./2.md), [простые приложения](./103.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Julia read CSV DataFrame example?</p>

<div class="faq-item">

  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>`missing`</strong> — пропуск в данных; <strong>`NaN`</strong> — результат недопустимой math-операции. Обрабатывают через `skipmissing`, `isnan`. Подробнее здесь — [типы](./4.md).</p>

## Что запомнить

Julia — язык для научных и технических вычислений: динамический синтаксис в REPL, производительность за счёт JIT (LLVM) и multiple dispatch.

Основные особенности Julia:

- **Multiple dispatch** — выбор метода по всем аргументам, не только по первому.
- **Broadcasting** — `.*`, `@.`, поэлементные операции над массивами.
- **Типы и struct** — immutable по умолчанию; parametric types для обобщений.
- **Pkg** — окружения проекта, `] add`, `Project.toml` / `Manifest.toml`.
- **missing** — пропуски данных; `skipmissing`, `dropmissing`.

Маршрут: [первая программа](./7.md) → [основы](./2.md) → [типы](./4.md) → [управление](./5.md) → [функции](./6.md) → [простые приложения](./103.md) → [архитектура](./3.md).

Три практических правила:

1. Hot path — внутри функций с стабильными типами, не в глобальном scope.
2. `*` vs `.*` — проверяйте перед матричными формулами.
3. Первый `@time` — после warmup JIT.
