# О разделе

Раздел про **Julia** — язык для научных и технических вычислений: динамический синтаксис в REPL и скриптах, производительность за счёт JIT-компиляции и специализации по типам.

**Рекомендуемый порядок:**

1. [История](./1.md) — контекст и экосистема  
2. [Основы](./2.md) — REPL, синтаксис, массивы, пакеты  
3. [Архитектура](./3.md) — типы, dispatch, LLVM, GC  
4. [Типы и диспетчеризация](./4.md) — `struct`, `Bool`, примеры методов  
5. [Управляющие конструкции](./5.md) — `if`, циклы, broadcasting  
6. [Функции и макросы](./6.md) — методы, `@time`, интроспекция  
7. [Первая программа](./7.md) — установка и `hello.jl`

Для практики нужна установленная Julia ([julialang.org](https://julialang.org/downloads/)) и по желанию VS Code с расширением Julia или Jupyter + `IJulia`.
