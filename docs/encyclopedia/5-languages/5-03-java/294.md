В энциклопедии Java разобраны **язык, JVM и экосистема** ([основы](./1.md), [сборки](./12.md), [первая программа](./13.md), [Spring](./27.md)). **Microsoft** не владеет Java (торговые марки Oracle), но публикует **сборку OpenJDK**, интеграции с **VS Code**, **Azure** и **GitHub Actions** — удобный путь, если вы уже в экосистеме Microsoft или разворачиваете сервисы в облаке.

Тексты Learn сюда не копируются — только структура, ссылки и привязка к главам проекта.

## Microsoft Build of OpenJDK

| Тема | Ссылка |
|------|--------|
| Скачивание | [openjdk/download](https://learn.microsoft.com/ru-ru/java/openjdk/download) |
| Установка (exe, Homebrew, Ubuntu и др.) | [openjdk/install](https://learn.microsoft.com/ru-ru/java/openjdk/install?tabs=exe%2Chomebrew%2Cubuntu) |

Используйте после понимания HTTP и аутентификации в облаке ([8.01 Облако](/encyclopedia/8-infra-security/8-01-oblachnye-tehnologii/intro)).

См. [экосистему Java](./110.md) (Jakarta EE) и [Spring](./27.md) как альтернативный стек.

## CI/CD: GitHub Actions

**[setup-java-jdk](https://github.com/marketplace/actions/setup-java-jdk)** — официальное действие для workflow: выбор дистрибутива (в том числе **microsoft**), версии Java, кэш Maven/Gradle.

Пример использования — после [сборок Maven/Gradle](./12.md) и основ [DevOps](/encyclopedia/8-infra-security/8-04-devops-ci-cd/intro):

```yaml
- uses: actions/setup-java@v4
  with:
    distribution: microsoft
    java-version: '21'
    cache: maven
```

## Типичные ошибки

- **Только Oracle JDK в голове** — на CI и в Azure часто проще единый **Microsoft** или **temurin** дистрибутив через `setup-java`.
- **VS Code без JDK** — сначала OpenJDK, потом Coding Pack; иначе расширения не подхватят `JAVA_HOME`.
- **Сразу Azure SDK** без [HTTP и REST](/encyclopedia/2-system-network/2-04-kak-rabotayut-sayty-i-veb-sayty/1) — сложно отлаживать аутентификацию и ретраи.
- **Путать Jakarta EE и Spring** — разные дорожки; для старта веба чаще [Spring Boot](./271.md), для legacy EE — раздел [ee в Azure](https://learn.microsoft.com/ru-ru/azure/developer/java/ee/).
