## Как пользоваться (JavaFX)

1. В `start(Stage stage)` создайте корневой контейнер (`VBox`, `GridPane` или `BorderPane`).
2. Скопируйте рецепт элемента и добавьте узел в контейнер: `box.getChildren().add(node)` или `grid.add(node, col, row)`.
3. Прикрепите сцену: `stage.setScene(new Scene(root, w, h)); stage.show();`

UI меняют только в **JavaFX Application Thread**; из фона — `Platform.runLater(() -> { ... })`.

## Label (метка)

```java
import javafx.scene.control.Label;

Label label = new Label("Имя пользователя:");
label.setStyle("-fx-font-weight: bold;");

Label dynamic = new Label();
dynamic.setText("Готово");
// или label.textProperty().bind(otherProperty);
box.getChildren().add(label);
```

## TextBox — однострочный (TextField)

```java
import javafx.scene.control.TextField;

TextField field = new TextField();
field.setPromptText("Введите имя");
field.setPrefColumnCount(24);
String value = field.getText().trim();
field.clear();
field.setText("по умолчанию");

field.setOnAction(e -> submit());  // Enter
grid.add(field, 1, 0);
```

## Timeline (анимация свойств)

```java
import javafx.animation.KeyFrame;
import javafx.animation.KeyValue;
import javafx.animation.Timeline;
import javafx.util.Duration;

Timeline timeline = new Timeline(
        new KeyFrame(Duration.ZERO, e -> slider.setValue(0)),
        new KeyFrame(Duration.seconds(2.5), new KeyValue(slider.valueProperty(), 1))
);
timeline.setOnFinished(e -> statusLabel.setText("Готово"));
timeline.play();
```

Анимация выполняется в **JavaFX Application Thread**; для длительной работы без блокировки UI используйте `Task` + `Platform.runLater`. Пример в контексте `ProgressBar` — [Первая программа на JavaFX — вкладка "Прогресс"](./3111.md#вкладка-прогресс).

## Вкладки (TabPane)

```java

import javafx.scene.control.TabPane;

TabPane tabs = new TabPane();
```

# Swing

Каркас — [Простые приложения на Java — Swing](./131.md). Полные программы с разбором строк — [Lab — Java Swing](/lab/Примеры/1143). Все изменения UI — в **EDT**: `SwingUtilities.invokeLater(() -> { ... })`.

## Как пользоваться (Swing)

1. Скопируйте [обязательный каркас](/lab/Примеры/1143#karkas) в файл `ИмяКласса.java`.
2. Добавьте рецепт элемента из раздела ниже (`JButton`, `JTextField`…).
3. Для лабораторной возьмите готовый пример из Lab ([кнопка](/lab/Примеры/1143#button), [форма](/lab/Примеры/1143#form), [список задач](/lab/Примеры/1143#todo)) и сверьте таблицу «Разбор построчно».
4. Долгие операции не кладите в `ActionListener` — см. [Особенности разработки десктопных приложений](/encyclopedia/4-code-dev/4-11-desktopnye-prilozheniya/112.md) и `SwingWorker` в [JavaFX и GUI](./311.md#swing-и-потоки).

## Частые ошибки

| Симптом | JavaFX | Swing |
|---------|--------|-------|
| `package javafx… does not exist` | Нет `javafx.version` в `pom` — [Первая программа на JavaFX](./3111.md#чеклист-pomxml-перед-первым-run) | — |
| `runtime components are missing` | Запуск без `--module-path` — [Первая программа на JavaFX](./3111.md#запуск-maven-idea-и-module-path) | — |
| UI не обновляется из потока | `Platform.runLater` | `SwingUtilities.invokeLater` |
| Окно пустое | Нет `stage.show()` | Нет `setVisible(true)` |
| Module not found | OpenJFX в Maven / module path | — |
