## FAQ — Часто задаваемые вопросы

Типичные сбои и ситуации, с которыми сталкиваются новички после раздела. Здесь — **что делать и где копать в главах**; определения для зачёта — в [чек-листе](./999).

<div class="faq-list">

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `java` в терминале не найден, хотя JDK "установлен".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Установлен только JRE или <strong>PATH не содержит `bin` JDK</strong>. Проверьте `java -version` и `javac -version`; для разработки нужен JDK. Подробнее здесь — [основы и JDK](./1.md), [первая программа](./13.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `javac` компилирует, а `java Main` — "Could not find or load main class".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Класс с `main` должен называться как файл, пакет должен совпадать со структурой каталогов, запуск — <strong>из корня пакета</strong> с полным именем `com.example.Main`. Подробнее здесь — [первая программа](./13.md), [структура проекта](./12.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> В IDE всё зелёное, из терминала Maven — "package does not exist".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> IDE подхватила classpath, а <strong>Maven не собрал зависимости</strong> или вы запускаете не из корня `pom.xml`. Выполните `mvn compile` или `mvnw clean install`. Подробнее здесь — [Maven и сборки](./12.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `NullPointerException` на строке, где "ничего null нет".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Падает <strong>цепочка вызовов</strong>: `a.getB().getC()` — null может быть у `getB()`. Разбейте на шаги, используйте `Optional` или проверки. Подробнее здесь — [исключения](./21.md), [современный синтаксис](./300.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Добавил объект в `HashSet`, потом изменил поле — элемент "пропал" из множества.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `HashSet` опирается на <strong>неизменный `hashCode`</strong>. Не меняйте поля, участвующие в `equals`/`hashCode`, после вставки в Set/Map. Подробнее здесь — [коллекции](./24.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `ConcurrentModificationException` при удалении из списка в цикле `for`.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Нельзя менять коллекцию <strong>во время итерации</strong> обычным for-each. Используйте `Iterator.remove()`, `removeIf` или соберите новый список. Подробнее здесь — [коллекции](./24.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Сравниваю строки через `==` — иногда работает, иногда нет.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `==` сравнивает <strong>ссылки</strong>, для содержимого — `equals()`. Литералы в пуле могут совпасть по ссылке случайно — это ловушка для новичка. Подробнее здесь — [строки](./296.md), [типы](./15.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> IDE предлагает "Unhandled exception" — можно просто добавить `throws Exception`?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `throws` на всё — <strong>маскирует обработку</strong>. Для checked exceptions обрабатывайте осмысленно или оборачивайте; не глотайте пустой catch. Подробнее здесь — [исключения](./21.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Spring Boot стартует, но REST возвращает 404 на все URL.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Контроллер не в пакете <strong>сканирования `@SpringBootApplication`</strong>, опечатка в `@RequestMapping` или конфликт context-path. Проверьте логи mapped endpoints. Подробнее здесь — [Spring Boot](./271.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `@Autowired` поле null — Spring "не видит" бин.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Класс создан через <strong>`new` вне контекста</strong> — DI не сработает. Пометьте класс `@Component`/`@Service` и инжектируйте через конструктор. Подробнее здесь — [Spring Boot](./271.md), [Spring — обзор](./27.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> JPA сохраняет сущность, но в БД пусто — транзакция откатилась молча.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Метод без <strong>`@Transactional`</strong> или исключение после save без commit. Включите лог SQL, проверьте rollback и границы транзакций. Подробнее здесь — [JPA](./293.md), [работа с БД](./22.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `LazyInitializationException` при обращении к полю сущности в JSON-ответе.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Сессия Hibernate уже <strong>закрыта</strong> вне транзакции. Используйте DTO, `@Transactional` на сервисе, fetch join или `@EntityGraph`. Подробнее здесь — [JPA](./293.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Приложение на Java 21, а на сервере — Java 8: "Unsupported class file major version".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Байт-код <strong>новее runtime</strong> на сервере. Соберите с `--release 8` или обновите JDK на сервере до нужной LTS. Подробнее здесь — [основы и JVM](./1.md), [JVM в проде](./23.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Память растёт, приложение тормозит — "OutOfMemoryError: Java heap space".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Утечка ссылок, слишком маленький heap или <strong>кэш без лимита</strong>. Снимите heap dump (`jcmd`, VisualVM), проверьте `-Xmx`. Подробнее здесь — [JVM и диагностика](./302.md), [JVM и потоки](./23.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Многопоточный код "иногда" портит данные — баг не воспроизводится.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Гонка данных без <strong>`synchronized`, lock или atomic</strong>. Воспроизведите под нагрузкой, используйте thread-safe коллекции. Подробнее здесь — [многопоточность](./23.md), [асинхронность](./298.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `Stream` уже использован — "stream has already been operated upon or closed".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Stream в Java <strong>одноразовый</strong>. Сохраните результат в коллекцию или создайте новый stream из источника. Подробнее здесь — [Stream API](./295.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Lombok `@Data` в tutorial, а у меня "cannot find symbol" для getter.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Нужен <strong>annotation processor</strong> в Maven/Gradle и плагин IDE. Без Lombok пишите getter/setter вручную или record. Подробнее здесь — [структура и сборки](./12.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Тесты проходят в IDE, в CI падают из-за локали или часового пояса.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Формат дат и чисел зависит от <strong>Locale и ZoneId</strong>. В тестах фиксируйте `Locale.US`, `Clock.fixed` или явные ISO-строки. Подробнее здесь — [строки и даты](./296.md), [Testcontainers](./273.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> JWT в Spring Security — 401 на каждый запрос после логина.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Проверьте заголовок <strong>`Authorization: Bearer &lt;token&gt;`</strong>, секрет подписи, срок жизни и порядок фильтров в Security chain. Подробнее здесь — [JWT](./274.md), [Security Basic](./272.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Пошёл сразу в Spring Boot, не понимаю `List`, `Map` и исключения — нормально?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Spring опирается на те же <strong>Core Java конструкции</strong>. Вернитесь к коллекциям, ООП и Maven, затем снова [271](./271.md). Подробнее здесь — [оглавление](./intro), [коллекции](./24.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `record` vs класс — когда IDE ругается на изменение поля?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `record` — <strong>неизменяемый носитель данных</strong>; поля final по смыслу. Для изменяемого состояния используйте обычный класс. Подробнее здесь — [современный синтаксис](./300.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Gradle и Maven в одном проекте — какой выбрать?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Для учебного маршрута раздела достаточно <strong>одной системы сборки</strong> — чаще Maven в первых главах. Не смешивайте оба в одном репозитории без причины. Подробнее здесь — [структура и сборки](./12.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Android Studio и backend Java — это "один Java"?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Общий язык и JVM-идеи, но <strong>разные API и runtime</strong> (Android SDK vs серверный JDK). Материалы раздела про Spring и JPA — для backend; мобильная ветка — отдельный маршрут. Подробнее здесь — [основы](./1.md), [оглавление](./intro).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `Integer` кэширует -128..127 — `Integer.valueOf(200) == Integer.valueOf(200)` false, а для 100 true.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Для малых значений JVM использует <strong>пул объектов</strong>. Для сравнения содержимого — `equals`, не `==`. Подробнее здесь — [типы и autoboxing](./15.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Virtual Threads (Java 21) — потоки "бесплатные", можно создать миллион?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Virtual threads дешевле platform threads для <strong>I/O-bound</strong>, но память и блокировки synchronized на carrier thread всё ещё ограничивают. Не заменяют профилирование. Подробнее здесь — [Virtual Threads](./308.md), [асинхронность](./298.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Собеседование спрашивает про `equals`/`hashCode`, а я их не переопределял — в чём риск?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> В `HashMap`/`HashSet` объекты с одинаковым смыслом <strong>не найдутся</strong> или дублируются. Переопределяйте парой, соблюдайте контракт. Подробнее здесь — [коллекции](./24.md), [вопросы на собеседование](./301.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Логи Spring забиты SQL — как понять, где реальная ошибка?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Временно поднимите уровень <strong>вашего пакета на DEBUG</strong>, SQL — на WARN. Ищите stack trace и correlation id; для REST — [ошибки REST](./303.md). Подробнее здесь — [Spring Boot](./271.md).</p>
</div>

### Частые поисковые запросы

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Как начать учить Java с нуля — пошаговый план?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> JDK → первая программа и Maven → синтаксис и ООП → коллекции → исключения → Stream API → Spring Boot для веба. Подробнее здесь — [маршрут intro](./intro), [основы](./1.md), [первая программа](./13.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> JDK, JRE и JVM — в чём разница простыми словами?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>JDK</strong> — компилятор и инструменты разработки; <strong>JRE</strong> — среда только для запуска (устаревает); <strong>JVM</strong> — виртуальная машина, исполняющая байт-код. Разработчику нужен JDK. Подробнее здесь — [основы Java](./1.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Spring Boot — что это и зачем нужен?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Spring Boot — <strong>стартовый каркас для Java-сервисов</strong>: встроенный Tomcat, autoconfig, REST, Security, JPA. Стандарт для нового backend на Java. Подробнее здесь — [Spring Boot](./271.md), [Spring — обзор](./27.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Java или Kotlin — что учить для Android и backend?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Android официально на Kotlin; backend enterprise — чаще Java + Spring. Kotlin совместим с JVM; Java даёт больше учебных материалов в этом разделе. Подробнее здесь — [основы](./1.md), [оглавление](./intro).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Java для backend-разработки — актуально ли?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Да: банки, финтех, крупный e-commerce и микросервисы на <strong>Spring Boot</strong> — стабильный спрос. Плюс зрелая экосистема и LTS JDK. Подробнее здесь — [Spring Boot](./271.md), [JPA](./293.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Maven или Gradle — что выбрать новичку?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> В разделе старт с <strong>Maven</strong> (`pom.xml`) — проще найти учебные примеры. Gradle гибче в больших монорепо; оба востребованы. Подробнее здесь — [структура и сборки](./12.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> ArrayList или LinkedList — когда что использовать?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>ArrayList</strong> — по умолчанию для списков (быстрый доступ по индексу); <strong>LinkedList</strong> — редко, когда много вставок в середину и мало random access. Подробнее здесь — [коллекции](./24.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Java 8 или Java 21 — какую версию учить?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Учите <strong>современную LTS</strong> (17 или 21): records, var, pattern matching, virtual threads. На собеседованиях спрашивают и Java 8 (лямбды, Stream). Подробнее здесь — [современный синтаксис](./300.md), [Virtual Threads](./308.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> NullPointerException — как избежать в Java?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Проверки, <strong>`Optional`</strong>, аннотации `@NonNull`, избегайте цепочек без null-safe. В новых API — явные контракты. Подробнее здесь — [исключения](./21.md), [современный синтаксис](./300.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Stream API Java — что это и зачем?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Декларативная обработка коллекций: <strong>filter, map, reduce</strong> без явных циклов. Удобен для трансформаций и агрегаций; не заменяет простой for там, где он читаемее. Подробнее здесь — [Stream API](./295.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> JPA и Hibernate — что это простыми словами?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>ORM</strong>: Java-классы ↔ таблицы БД, запросы через JPQL/репозитории. Hibernate — популярная реализация JPA в Spring. Подробнее здесь — [JPA](./293.md), [работа с БД](./22.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Как подготовиться к собеседованию Java junior?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Core: коллекции, OOP, исключения, Stream, многопоточность базово; плюс один pet-проект Spring Boot. Карта тем — в шпаргалке раздела. Подробнее здесь — [вопросы на собеседование](./301.md), [чек-лист](./999.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Java record — что это?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Компактный <strong>неизменяемый data-класс</strong> с автогенерацией equals/hashCode/toString. Для DTO и value objects вместо boilerplate. Подробнее здесь — [современный синтаксис](./300.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Virtual threads Java 21 — что это?</p>

## Что запомнить

Java — это строго типизированный, объектно-ориентированный, платформонезависимый язык программирования, разработанный компанией Sun Microsystems и в настоящее время поддерживаемый Oracle. Его ключевая особенность — выполнение байт-кода на виртуальной машине Java (JVM), что обеспечивает "записал один раз — запускай где угодно".

Основные категории применения Java:
- **Корпоративные приложения**: благодаря стабильности, безопасности и зрелой экосистеме;
- **Android-разработка**: до появления Kotlin Java была основным языком для мобильной платформы;
- **Серверная логика**: Spring Boot, Jakarta EE, Quarkus и другие фреймворки позволяют быстро создавать масштабируемые сервисы;
- **Большие системы**: банковские, страховые, логистические и государственные информационные системы;
- **Инструменты и утилиты**: компиляторы, IDE, билд-системы (Maven, Gradle) часто написаны на Java.

Ключевые особенности языка:
- **Строгая статическая типизация**: ошибки типов выявляются на этапе компиляции;
- **Автоматическое управление памятью**: сборка мусора освобождает разработчика от ручного управления выделением и освобождением памяти;
- **Многоуровневая модель исключений**: проверяемые (`checked`) и непроверяемые (`unchecked`) исключения;
- **Богатая стандартная библиотека**: коллекции, многопоточность, работа с сетью, файлами, датами, регулярными выражениями;
- **Поддержка функционального программирования**: лямбда-выражения, [Stream API](./295.md), ссылки на методы;
- **Строки, файлы, асинхронность, метаданные**: [296](./296.md)–[300](./300.md);
- **Модульность**: начиная с Java 9, проекты могут быть организованы в модули через JPMS (Java Platform Module System).

Экосистема Java включает:
- **JDK** — набор инструментов для разработки;
- **JRE** — среда выполнения;
- **JVM** — виртуальная машина, исполняющая байт-код;
- **Maven/Gradle** — системы сборки и управления зависимостями;
- **Spring**, **Hibernate**, **Jakarta EE** — фреймворки для бизнес-логики, ORM и веб-разработки;
- **JUnit**, **TestNG** — инструменты тестирования;
- **OpenJDK**, **Adoptium**, **Amazon Corretto**, **Azul Zulu** — реализации JDK.

Три основных правила эффективной работы с Java:
1. Следовать принципам SOLID и использовать шаблоны проектирования;
2. Писать читаемый, тестируемый код с минимальной связанностью;
3. Использовать современные возможности языка (начиная с Java 8 и выше): лямбды, `Optional`, `var`, записи (`record`), паттерн-матчинг.

Три фундаментальных момента:
- Java — это не просто язык, а целая платформа с мощной инфраструктурой;
- Успех Java основан на её стабильности, обратной совместимости и сообществе;
- Знание JVM (сборка мусора, JIT-компиляция, память) критически важно для производительности.
