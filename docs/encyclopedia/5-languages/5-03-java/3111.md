## Первая программа на JavaFX

### Где применяют JavaFX

**JavaFX** (OpenJFX) — рекомендуемый стек для новых desktop-приложений на Java: CSS, FXML, анимации, `TableView`, диалоги. С Java 11 библиотека подключается через Maven или Gradle; в JDK «из коробки» её уже нет.

Мы соберём «Конвертер °C → °F» и разберём **`Application.launch()`** — без него окно не останется на экране, как `mainloop()` в Tkinter или `SwingUtilities.invokeLater` + видимое окно в Swing.

Теория: [311.md](./311.md). **Элементы UI по рецептам:** [3112.md](./3112.md). Swing без Maven — [Lab — окна и кнопки](/lab/Примеры/1143) (построчный разбор для лабораторной) или кратко в [131.md — Swing](./131.md#первое-десктопное-приложение-на-swing).

---

### Что получится

Поле ввода, кнопки «Перевести» и «Выход», метка результата; Enter в поле вызывает расчёт.

## Подготовка проекта (Maven)

Минимальный `pom.xml` для Java 17 и OpenJFX 21:

```xml
<project>
    <modelVersion>4.0.0</modelVersion>
    <groupId>com.example</groupId>
    <artifactId>fx-demo</artifactId>
    <version>1.0.0</version>

    <properties>
        <maven.compiler.release>17</maven.compiler.release>
        <javafx.version>21.0.2</javafx.version>
    </properties>

    <dependencies>
        <dependency>
            <groupId>org.openjfx</groupId>
            <artifactId>javafx-controls</artifactId>
            <version>${javafx.version}</version>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.openjfx</groupId>
                <artifactId>javafx-maven-plugin</artifactId>
                <version>0.0.8</version>
                <configuration>
                    <mainClass>com.example.HelloFx</mainClass>
                </configuration>
            </plugin>
        </plugins>
    </build>
</project>
```

Запуск из каталога проекта:

```bash
mvn javafx:run
```

Подробнее о структуре каталогов — [Структуры проекта](./12.md).

### Чеклист pom.xml перед первым Run

| Проверка | Должно быть |
|----------|-------------|
| Свойство версии | `<javafx.version>21.0.7</javafx.version>` (или другая стабильная 21.x) |
| Зависимость | `org.openjfx:javafx-controls` с той же версией, без красного `&#36;&#123;javafx.version&#125;` |
| Версия Java | `maven.compiler.source` / `target` (или `release`) **совпадают** с Project SDK в IDEA — не 25, если установлен JDK 21/24 |
| `mainClass` в `javafx-maven-plugin` | Реальный класс с `public static void main`, например `ru.example.Main`, а не шаблон `com.example.app.Main` |
| После правок | Правый клик по `pom.xml` → **Maven → Reload Project** |

С JDK 11+ **JavaFX нет в стандартном JDK** (в Oracle JDK до 10 он был внутри). Фраза «Java установлена» не означает «JavaFX доступен» — нужны зависимости OpenJFX и корректный запуск.

### Две точки входа: Main и класс Application

В учебных Maven-проектах удобно разделить роли:

- **`HelloApp extends Application`** — только UI: `start(Stage)`, виджеты, обработчики;
- **`Main`** — одна строка запуска, какой экран открыть.

```java
package ru.example;

import javafx.application.Application;

public class Main {
    public static void main(String[] args) {
        Application.launch(HelloApp.class, args);
        // Application.launch(DemoApp.class, args);
    }
}
```

Переключение между «приветствием» и большим демо — комментарием одной строки, без копирования `launch` в каждый класс. Альтернатива: `public static void main` прямо в `HelloApp` с вызовом `launch(args)` — тогда Run в IDEA можно повесить на этот класс.

В `javafx-maven-plugin` укажите тот класс, у которого есть **`main`** (часто это `Main`, а не `HelloApp`).

### Запуск: Maven, IDEA и module-path

**Через Maven** (плагин сам подставляет module path):

```text
Maven → Plugins → javafx → javafx:run
```

**Через Run в IntelliJ IDEA** после Java 11 недостаточно «просто classpath»: без module path появляется:

```text
Error: JavaFX runtime components are missing, and application needs to be terminated
```

В логе видно, что JAR JavaFX лежат на **classpath**, а runtime ждёт **`--module-path`** с платформенными JAR (`javafx-controls-*-win.jar` на Windows).

Минимальные **VM options** для конфигурации Application (после сборки проекта):

```text
--module-path "$PROJECT_DIR$/target/javafx-lib"
--add-modules javafx.controls,javafx.graphics
--enable-native-access=javafx.graphics
```

Чтобы папка `target/javafx-lib` появилась при `mvn compile`, в `pom.xml` можно добавить копирование нативных JAR OpenJFX (классификатор `win` / `linux` / `mac` под вашу ОС):

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-dependency-plugin</artifactId>
    <version>3.7.1</version>
    <executions>
        <execution>
            <id>copy-javafx</id>
            <phase>process-resources</phase>
            <goals><goal>copy-dependencies</goal></goals>
            <configuration>
                <outputDirectory>${project.build.directory}/javafx-lib</outputDirectory>
                <includeGroupIds>org.openjfx</includeGroupIds>
                <includeClassifiers>win</includeClassifiers>
            </configuration>
        </execution>
    </executions>
</plugin>
```

Порядок в IDEA: **Build Project** (или `mvn compile`) → выбрать сохранённую конфигурацию **Main** / **DemoApp** с VM options → **Run**. Временная конфигурация «Run Main.java» без VM options снова даст `runtime components are missing`.

Предупреждения JDK 24 про `sun.misc.Unsafe` из JavaFX в консоли обычно **не мешают** работе окна — их можно игнорировать на этапе обучения.

### Поэтапное расширение одного проекта

Логичный маршрут «от нуля к наглядной галерее» (как в учебном HelloApp):

| Шаг | Класс | Что добавляете |
|-----|--------|----------------|
| 1 | `HelloApp` | `TextField`, `Button`, `Label`, `VBox`, `setOnAction` — одно окно 320×180 |
| 2 | `DemoApp` | `TabPane` (формы, список, прогресс), `BorderPane`, `Slider` + привязка к label, `Timeline`, строка статуса — [подробный разбор](#demoapp--галерея-контролов) |
| 3 | `ButtonDemo` | `StackPane`, стили кнопки, `Alert` со стилизацией через `getDialogPane()` |

На шаге 2 полезно увидеть **привязку свойств** вместо ручного `setText` в каждом обработчике:

```java
volumeLabel.textProperty().bind(
    Bindings.format("Громкость: %.0f%%", volumeSlider.valueProperty())
);
```

Стили можно подключить inline (`setStyle`), через CSS-файл в `resources` или строкой в `scene.getStylesheets().add("data:text/css,...")` — для демо без отдельного файла.

## Минимальное окно

```java

package com.example;

import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.stage.Stage;

public class HelloFx extends Application {

    @Override
    public void start(Stage stage) {
        stage.setTitle("Привет, JavaFX");
        stage.setScene(new Scene(new Label("Окно работает"), 320, 120));
        stage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

Разбор:

- `Application` — точка входа JavaFX; платформа вызывает `start(Stage)`.
- `Stage` — окно; `Scene` — содержимое с корневым узлом и размером.
- `launch(args)` запускает UI-поток и цикл событий; без `show()` окно не видно.

## Конвертер температуры

```java

package com.example;

import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.Alert;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.TextField;
import javafx.scene.input.KeyCode;
import javafx.scene.layout.GridPane;
import javafx.scene.layout.HBox;
import javafx.stage.Stage;

public class ConverterApp extends Application {

    private TextField celsiusField;
    private Label resultLabel;

    private void convert() {
        String raw = celsiusField.getText().trim().replace(',', '.');
        try {
            double celsius = Double.parseDouble(raw);
            double fahrenheit = celsius * 9 / 5 + 32;
            resultLabel.setText(String.format("%.1f °C = %.1f °F", celsius, fahrenheit));
        } catch (NumberFormatException ex) {
            Alert alert = new Alert(Alert.AlertType.ERROR);
            alert.setTitle("Ошибка");
            alert.setHeaderText(null);
            alert.setContentText("Введите число, например 25");
            alert.showAndWait();
        }
    }

    @Override
    public void start(Stage stage) {
        GridPane grid = new GridPane();
        grid.setHgap(10);
        grid.setVgap(10);
        grid.setPadding(new Insets(16));
        grid.setAlignment(Pos.CENTER);

        grid.add(new Label("Температура (°C):"), 0, 0);
        celsiusField = new TextField();
        celsiusField.setPromptText("25");
        celsiusField.setPrefColumnCount(8);
        grid.add(celsiusField, 1, 0);

        resultLabel = new Label("—");
        grid.add(resultLabel, 0, 1, 2, 1);

        Button convertBtn = new Button("Перевести");
        convertBtn.setOnAction(e -> convert());
        Button exitBtn = new Button("Выход");
        exitBtn.setOnAction(e -> stage.close());

        HBox buttons = new HBox(8, convertBtn, exitBtn);
        buttons.setAlignment(Pos.CENTER);
        grid.add(buttons, 0, 2, 2, 1);

        celsiusField.setOnKeyPressed(e -> {
            if (e.getCode() == KeyCode.ENTER) {
                convert();
            }
        });

        Scene scene = new Scene(grid, 340, 160);
        stage.setTitle("Конвертер температуры");
        stage.setResizable(false);
        stage.setScene(scene);
        stage.show();
        celsiusField.requestFocus();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

Разбор:

- `convert()` читает текст поля, парсит число и обновляет `resultLabel`.
- `NumberFormatException` перехватывает нечисловой ввод; `Alert` показывает сообщение об ошибке.
- `GridPane` выравнивает метки и поля в сетке; `HBox` группирует кнопки в ряд.
- `setOnAction` и `setOnKeyPressed` с `KeyCode.ENTER` — два способа вызвать одну логику.

## DemoApp — галерея контролов

После конвертера логичный **шаг 2** — класс `DemoApp` с тремя вкладками: форма, список и прогресс. Один и тот же `Label` внизу окна показывает, что произошло на любой вкладке. В `Main` переключение:

```java
Application.launch(DemoApp.class, args);
// Application.launch(HelloApp.class, args);
```

Полный исходник удобно держать в пакете `ru.timur.crm` (или своём) рядом с `HelloApp`. Ниже — **как добавляется каждый блок**, а не переписывание всего файла. Краткие рецепты по API — [3112.md](./3112.md).

### Каркас: BorderPane, заголовок, вкладки, статус

Корень сцены — **`BorderPane`**: сверху заголовок, по центру вкладки, снизу строка состояния.

```java
Label statusLabel = new Label("Готово — выберите вкладку и поиграйте с элементами");
statusLabel.getStyleClass().add("status-bar");
statusLabel.setMaxWidth(Double.MAX_VALUE);

TabPane tabs = new TabPane(
        formTab(statusLabel),
        listTab(statusLabel),
        progressTab(statusLabel)
);
tabs.setTabClosingPolicy(TabPane.TabClosingPolicy.UNAVAILABLE);

VBox header = new VBox(4,
        styledLabel("JavaFX Demo", "header-title"),
        styledLabel("Наглядные контролы, привязки и простая анимация", "header-subtitle")
);
header.setPadding(new Insets(20, 20, 8, 20));

BorderPane root = new BorderPane();
root.setTop(header);
root.setCenter(tabs);
root.setBottom(statusLabel);
BorderPane.setMargin(tabs, new Insets(0, 16, 12, 16));
```

| Узел | Зачем |
|------|--------|
| `statusLabel` | Одна «строка состояния» на всё приложение; вкладки получают ссылку на неё и вызывают `status.setText(...)` |
| `TabPane` | Три независимых экрана без отдельных окон; `UNAVAILABLE` — вкладки нельзя закрыть крестиком |
| `VBox header` | Заголовок и подзаголовок отдельно от вкладок |
| `BorderPane.setMargin` | Отступы только у центра, не у всего окна |

`setMaxWidth(Double.MAX_VALUE)` у нижней метки заставляет её **растянуться на всю ширину** — иначе `Label` по умолчанию узкий и «плавает» слева.

### CSS без файла в resources

Стили заданы константой `STYLESHEET` (text block `"""…"""`) и подключены как data-URL:

```java
scene.getStylesheets().add("data:text/css," + STYLESHEET.replace("\n", ""));
```

Классы `.header-title`, `.card`, `.status-bar` навешиваются через `getStyleClass().add("…")`. Для продакшена удобнее файл `app.css` в `src/main/resources` — см. [стилизацию ниже](#стилизация-окно-кнопка-и-alert). В учебном демо строка в коде избавляет от лишнего файла.

Вспомогательные методы повторяют разметку:

```java
private VBox card(Node content) {
    VBox box = new VBox(content);
    box.getStyleClass().add("card");
    VBox.setVgrow(content, Priority.ALWAYS);
    return box;
}

private Label styledLabel(String text, String styleClass) {
    Label label = new Label(text);
    label.getStyleClass().add(styleClass);
    return label;
}
```

`card()` оборачивает содержимое вкладки в «карточку» с белым фоном и рамкой по CSS.

### Вкладка «Формы» — поля, выбор, привязки

Метод `formTab(Label status)` собирает типичную **форму в `GridPane`**: метка в столбце 0, контрол в столбце 1.

#### TextField и PasswordField

```java
TextField nameField = new TextField();
nameField.setPromptText("Имя");
nameField.setMaxWidth(Double.MAX_VALUE);

PasswordField passwordField = new PasswordField();
passwordField.setPromptText("Пароль");
passwordField.setMaxWidth(Double.MAX_VALUE);
```

`setPromptText` — серый placeholder, пока поле пустое. `setMaxWidth(Double.MAX_VALUE)` вместе с `GridPane.setHgrow(..., Priority.ALWAYS)` даёт полям **ширину ячейки**, а не минимум по символам.

#### ComboBox

```java
ComboBox<String> roleBox = new ComboBox<>();
roleBox.getItems().addAll("Гость", "Пользователь", "Администратор");
roleBox.setValue("Пользователь");
```

Список вариантов — `getItems()`; выбранное значение читают через `getValue()`, не через `getText()` (у нередактируемого списка).

#### DatePicker

```java
DatePicker datePicker = new DatePicker(LocalDate.now());
```

Значение — `LocalDate` из `java.time`. В обработчике кнопки дату форматируют в строку:

```java
String date = datePicker.getValue() != null
        ? datePicker.getValue().format(DateTimeFormatter.ofPattern("dd.MM.yyyy"))
        : "—";
```

#### Slider и привязка к Label (Bindings)

```java
Slider volumeSlider = new Slider(0, 100, 40);
volumeSlider.setShowTickLabels(true);
volumeSlider.setShowTickMarks(true);

Label volumeLabel = new Label();
volumeLabel.textProperty().bind(
        Bindings.format("Громкость: %.0f%%", volumeSlider.valueProperty())
);
```

Здесь **не** пишут `setOnAction` на каждое движение ползунка: `textProperty()` метки **привязана** к `valueProperty()` слайдера. При изменении значения подпись обновляется автоматически в UI-потоке. Импорт: `javafx.beans.binding.Bindings`.

#### CheckBox и RadioButton

```java
CheckBox notifyCheck = new CheckBox("Уведомления");
notifyCheck.setSelected(true);

ToggleGroup themeGroup = new ToggleGroup();
RadioButton lightTheme = new RadioButton("Светлая");
RadioButton darkTheme = new RadioButton("Тёмная");
lightTheme.setToggleGroup(themeGroup);
darkTheme.setToggleGroup(themeGroup);
lightTheme.setSelected(true);
```

`ToggleGroup` гарантирует **один** выбранный `RadioButton`. Состояние чекбокса — `isSelected()`.

#### Кнопка «Применить» и сбор данных

```java
Button applyButton = new Button("Применить");
applyButton.setDefaultButton(true);
applyButton.setOnAction(e -> {
    status.setText(String.format(
            "Форма: %s | роль %s | дата %s | …",
            nameField.getText().isBlank() ? "(без имени)" : nameField.getText(),
            roleBox.getValue(),
            date, /* … */
    ));
});
```

`setDefaultButton(true)` — нажатие **Enter** в форме активирует эту кнопку (пока фокус в контроле формы).

#### Размещение в GridPane

```java
GridPane grid = new GridPane(12, 10);
grid.add(new Label("Имя:"), 0, 0);
grid.add(nameField, 1, 0);
// …
grid.add(volumeLabel, 0, 4, 2, 1);   // colspan = 2
grid.add(new HBox(12, lightTheme, darkTheme), 1, 7);

GridPane.setHgrow(nameField, Priority.ALWAYS);
GridPane.setHgrow(passwordField, Priority.ALWAYS);
GridPane.setHgrow(roleBox, Priority.ALWAYS);
```

Конструктор `GridPane(12, 10)` задаёт **hgap** и **vgap** между ячейками. Четвёртый и пятый аргументы `grid.add(node, col, row, colspan, rowspan)` растягивают слайдер на две колонки. Радиокнопки в **`HBox(12, …)`** — горизонтальный ряд с промежутком 12 px.

Вкладка возвращается так: `return new Tab("Формы", card(grid));`

### Вкладка «Список» — ListView и действия

```java
ListView<String> listView = new ListView<>();
listView.getItems().addAll("Java", "Kotlin", "Scala", "Groovy");
listView.getSelectionModel().selectFirst();
```

`getItems()` — **живая** коллекция: `add`, `remove`, `clear` сразу меняют экран.

Добавление с проверкой дубликатов:

```java
addButton.setOnAction(e -> {
    String text = itemField.getText().trim();
    if (!text.isEmpty() && !listView.getItems().contains(text)) {
        listView.getItems().add(text);
        listView.getSelectionModel().select(text);
        itemField.clear();
        status.setText("Добавлено: " + text);
    }
});
```

Удаление выбранного:

```java
removeButton.setOnAction(e -> {
    String selected = listView.getSelectionModel().getSelectedItem();
    if (selected != null) {
        listView.getItems().remove(selected);
        status.setText("Удалено: " + selected);
    }
});
```

Реакция на **смену выделения** (не на клик по кнопке):

```java
listView.getSelectionModel().selectedItemProperty().addListener((obs, oldVal, newVal) -> {
    if (newVal != null) {
        status.setText("Выбрано: " + newVal);
    }
});
```

Компоновка: `VBox` — список сверху, `HBox` с полем и кнопками снизу. `VBox.setVgrow(listView, Priority.ALWAYS)` отдаёт списку свободную высоту; `HBox.setHgrow(itemField, Priority.ALWAYS)` растягивает поле ввода.

### Вкладка «Прогресс» — ProgressBar, Slider и Timeline

`ProgressBar` принимает значение **от 0.0 до 1.0**, не проценты:

```java
ProgressBar progressBar = new ProgressBar(0);
progressBar.setMaxWidth(Double.MAX_VALUE);

manualSlider.valueProperty().addListener((obs, oldVal, newVal) -> {
    progressBar.setProgress(newVal.doubleValue());
    percentLabel.setText(String.format("%.0f%%", newVal.doubleValue() * 100));
});
```

Ручной слайдер `0…1` синхронизирует и полосу, и подпись «42%».

**Имитация загрузки** — анимация `Timeline` в UI-потоке (долгий цикл в `setOnAction` заморозил бы окно):

```java
startButton.setOnAction(e -> {
    startButton.setDisable(true);
    manualSlider.setDisable(true);
    status.setText("Идёт имитация загрузки…");

    Timeline timeline = new Timeline(
            new KeyFrame(Duration.ZERO, ev -> manualSlider.setValue(0)),
            new KeyFrame(Duration.seconds(2.5),
                    new KeyValue(manualSlider.valueProperty(), 1))
    );
    timeline.setOnFinished(ev -> {
        startButton.setDisable(false);
        manualSlider.setDisable(false);
        status.setText("Загрузка завершена");
    });
    timeline.play();
});
```

`KeyFrame` с `Duration.ZERO` сбрасывает слайдер в 0; второй кадр за 2,5 с **интерполирует** `valueProperty` до 1. Слушатель слайдера обновляет `ProgressBar` без отдельного кода в анимации. Импорты: `javafx.animation.*`, `javafx.util.Duration`.

На время анимации кнопки и слайдер отключают (`setDisable(true)`), чтобы пользователь не сломал сценарий.

### GridPane и VBox

- **`GridPane`** — таблица строк и столбцов; удобен для форм «метка | поле».
- **`VBox` / `HBox`** — вертикальный или горизонтальный стек элементов.

В одном `Parent` у каждого дочернего узла одна позиция; для сложных форм вкладывают панели друг в друга.

### Позиционирование и компоновка — что путает новичка

JavaFX **не** расставляет виджеты «как в HTML по умолчанию» и **не** использует абсолютные `x/y` на сцене в обычных формах. Положение задаёт **контейнер** (`VBox`, `HBox`, `GridPane`, `BorderPane`, `StackPane`):

| Ожидание | Как в JavaFX |
|----------|----------------|
| «Кнопка по центру окна» | `StackPane` + кнопка, или `VBox`/`HBox` с `setAlignment(Pos.CENTER)` |
| «Поле на всю ширину» | `setMaxWidth(Double.MAX_VALUE)` у поля и `VBox.setVgrow(field, Priority.ALWAYS)` при необходимости |
| «Меню сверху, таблица в центре, статус снизу» | `BorderPane`: `setTop` / `setCenter` / `setBottom` |
| «Вкладки с разным содержимым» | `TabPane`, каждая `Tab` со своим корнем (`VBox`, `GridPane`…) |

Типичная ошибка — положить всё в `VBox` без отступов и выравнивания: элементы «прилипают» к левому краю. Помогают `setPadding(new Insets(20))`, `setSpacing(10)`, `setAlignment(Pos.CENTER)`.

Один узел **нельзя** одновременно быть в двух родителях. Для сложного экрана вкладывают панели: внешний `BorderPane`, внутри центра — `VBox` с формой, рядом — `HBox` с кнопками.

### Стилизация: окно, кнопка и Alert

**Inline** (быстро для эксперимента):

```java
button.setStyle("-fx-background-color: #e53935; -fx-text-fill: white; -fx-padding: 10 20;");
root.setStyle("-fx-padding: 20; -fx-background-color: #2d3436;");
```

**CSS-классы** на сцене (удобнее для нескольких виджетов):

```java
button.getStyleClass().add("primary-button");
scene.getStylesheets().add(getClass().getResource("/app.css").toExternalForm());
```

**`Alert`** — не системный MessageBox Windows: внешний вид ограничен темой JavaFX, но **шапку, текст и кнопки** можно переопределить через `DialogPane`:

```java
Alert alert = new Alert(Alert.AlertType.INFORMATION);
DialogPane pane = alert.getDialogPane();
pane.getStylesheets().add("data:text/css," + css.replace("\n", ""));
pane.getStyleClass().add("custom-alert");
alert.showAndWait();
```

Селекторы вроде `.custom-alert .header-panel` и `.button-bar .button` меняют фон диалога и кнопку OK; иконку типа (`INFORMATION`, `ERROR`) полностью «перекрасить» сложнее — для полного контроля используют `Dialog<>` с кастомным содержимым ([311.md — CSS и диалоги](./311.md#стилизация-окна-и-диалогов)).

### Частые ошибки

| Симптом | Причина | Что сделать |
|---------|---------|-------------|
| `package javafx.application does not exist` | Нет свойства `javafx.version` или Maven не перезагружен | Добавить `<javafx.version>…</javafx.version>`, **Reload Project** |
| `&#36;&#123;javafx.version&#125;` красный в IDEA | Свойство не объявлено | См. чеклист выше |
| `invalid target release: 24` (или 25) | В `pom` другая версия, чем установленный JDK | Выровнять `source`/`target`/`release` с Project SDK |
| Окно «мигает» и закрывается | Нет `launch()` или `show()` | `Application.launch(...)` и `stage.show()` |
| `Module javafx.controls not found` | OpenJFX не подтянулся / неверный module path | Maven Reload, `javafx:run` или VM options |
| `IllegalStateException: Not on FX application thread` | UI меняют из фонового потока | `Platform.runLater(() -> …)` |
| Интерфейс «зависает» | Долгая работа в `setOnAction` | `Task` / фоновый поток + `runLater` |
| `JavaFX runtime components are missing` | Запуск только через classpath без `--module-path` | VM options или `mvn javafx:run` |
| `javafx:run` не стартует | Неверный `mainClass` в плагине | Указать класс с `public static void main` |
| Код компилируется, Run в IDEA падает | Временная конфигурация без VM options | Сохранить конфигурацию с `--module-path` после `compile` |

Подробнее про экосистему и контейнеры — [JavaFX и GUI](./311.md).
