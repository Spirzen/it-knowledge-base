# jQuery

jQuery — это старейшая и самая известная JavaScript-библиотека, созданная в 2006 году Джоном Резигом для упрощения работы с HTML-документами, анимациями и AJAX-запросами. Её главный девиз — «Write less, do more» (Пиши меньше, делай больше). В эпоху, когда разные браузеры имели совершенно разные правила работы с кодом, jQuery стала спасением: она позволяла написать одну строчку кода, которая одинаково стабильно работала везде.

Главные особенности:
- Простой выбор элементов (селекторы). Вместо длинного стандартного кода `document.getElementById('myId')` в jQuery пишется короткое `$('#myId')`.
- Кроссбраузерность. Библиотека брала на себя решение всех проблем и багов совместимости между Internet Explorer, Chrome, Firefox и Safari.
- Цепочки вызовов (Chaining). Можно применять несколько действий к одному элементу подряд в одну строку: `$('#box').show().css('color', 'red').fadeOut();`.
- Легкий AJAX. Отправка данных на сервер без перезагрузки страницы в чистом JavaScript раньше требовала десятков строк сложного кода. С jQuery это стало делаться функцией `$.ajax()`.

В 2010–2015 годах jQuery использовалась практически на каждом втором сайте в мире. Без неё было невозможно представить верстку и веб-разработку. Однако сегодня jQuery считается устаревшей технологией (Legacy) по двум причинам:
1. Развитие чистого JavaScript (ES6+). Браузеры стали стандартизированными. Появились удобные встроенные методы вроде `document.querySelector()` и функция `fetch()`, которые делают то же самое, что и jQuery, но без необходимости скачивать стороннюю библиотеку.
2. Появление компонентных фреймворков (React, Vue, Angular). jQuery напрямую манипулирует элементами на странице, что очень медленно. Современные инструменты работают через виртуальное дерево (Virtual DOM) и гораздо лучше подходят для создания динамических приложений.

Несмотря на возраст, jQuery до сих пор работает на огромном количестве сайтов (по разным оценкам, до 70% сайтов в интернете). Она остается востребованной, так как на ней написана популярная CMS WordPress, а также тысячи старых сайтов, которые бизнес продолжает поддерживать.

**jQuery** — JavaScript-библиотека для работы с DOM, событиями, анимацией и AJAX. На пике популярности (2011–2014) она была на большинстве сайтов; сегодня остаётся в legacy-проектах, CMS и простых лендингах.
