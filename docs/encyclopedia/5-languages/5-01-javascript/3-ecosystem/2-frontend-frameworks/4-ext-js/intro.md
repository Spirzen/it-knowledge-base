# Ext JS

Ext JS — это коммерческий JavaScript-фреймворк для создания сложных корпоративных веб-приложений (Enterprise UI) с акцентом на работу с большими объемами данных. Его разрабатывает компания Sencha. В отличие от React или Vue, которые ориентированы на современный веб, Ext JS был создан в эпоху доминирования десктопных программ (первый релиз вышел в 2007 году). Его главная цель — перенести привычный интерфейс настольных систем (с окнами, таблицами, вкладками и сложными формами) внутрь браузера.

Главные особенности:
- Огромная библиотека готовых UI-компонентов. Из коробки доступны продвинутые таблицы (Grids) с фильтрацией и группировкой, графики, деревья данных, календари, формы и карусели. Разработчику вообще не нужно писать CSS — интерфейс собирается как конструктор.
- Строгая MVC/MVVM архитектура. Фреймворк жестко задает правила написания кода, что помогает крупным командам поддерживать порядок в огромных проектах.
- Продвинутая работа с данными (Data Package). Встроенные инструменты позволяют легко связывать UI-компоненты со сложными серверными базами данных, автоматически обрабатывать кэширование и валидацию.
- Коммерческая лицензия. В отличие от бесплатных React, Vue и Angular, Ext JS является платным продуктом с дорогой лицензией для бизнеса, которая включает официальную техническую поддержку.

В потребительском вебе (интернет-магазины, соцсети) Ext JS практически не используется, так как его интерфейсы выглядят тяжеловесно, а сайты весят много. Однако он до сих пор востребован в B2B-сегменте и Enterprise-разработке - внутренние CRM и ERP-системы крупных компаний, банковские терминалы и аналитические панели, СУБД и админ-панели, где нужно отображать миллионы строк в таблицах.

**Ext JS** — стек для крупных админок и legacy-систем — готовые гриды и формы, слой данных Store/Model, сборка через Sencha Cmd.
