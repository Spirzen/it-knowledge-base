### РђСЂС…РёС‚РµРєС‚СѓСЂРЅС‹Рµ РїР°С‚С‚РµСЂРЅС‹

РќР°С‡РёРЅР°СЏ СЃ РІРµСЂСЃРёРё 4, Ext JS РѕС„РёС†РёР°Р"СЊРЅРѕ РїРѕРґРґРµСЂР¶РёРІР°РµС‚ РґРІР° РѕСЃРЅРѕРІРЅС‹С… РїРѕРґС…РѕРґР° Рє РѕСЂРіР°РЅРёР·Р°С†РёРё РєРѕРґР°: **MVC (ModelвЂ“ViewвЂ“Controller)** Рё **MVVM (ModelвЂ“ViewвЂ“ViewModel)**. РћР±Р° РїР°С‚С‚РµСЂРЅР° РІРЅРµРґСЂРµРЅС‹ РєР°Рє РІСЃС‚СЂРѕРµРЅРЅС‹Рµ, СЃС‚СЂРѕРіРѕ С‚РёРїРёР·РёСЂРѕРІР°РЅРЅС‹Рµ РјРµС…Р°РЅРёР·РјС‹ С„СЂРµР№РјРІРѕСЂРєР°, СЃ РѕР±СЏР·Р°С‚РµР"СЊРЅС‹РјРё СЃРѕРіР"Р°С€РµРЅРёСЏРјРё Рѕ РёРјРµРЅРѕРІР°РЅРёРё, Р°РІС‚РѕРјР°С‚РёС‡РµСЃРєРѕР№ Р·Р°РіСЂСѓР·РєРѕР№ РєР"Р°СЃСЃРѕРІ Рё СѓРїСЂР°РІР"РµРЅРёРµРј СЃРІСЏР·СЏРјРё.

Р’ **MVC** РїСЂРёР"РѕР¶РµРЅРёРµ СЂР°Р·РґРµР"СЏРµС‚СЃСЏ РЅР° С‚СЂРё СЃР"РѕСЏ.  
вЂ” *РњРѕРґРµР"СЊ* (`Ext.Data.Model`) РѕРїРёСЃС‹РІР°РµС‚ СЃС‚СЂСѓРєС‚СѓСЂСѓ РґР°РЅРЅС‹С… — РїРѕР"СЏ, РёС… С‚РёРїС‹, РІР°Р"РёРґР°С†РёРё, Р·Р°РІРёСЃРёРјРѕСЃС‚Рё.  
вЂ” *РџСЂРµРґСЃС‚Р°РІР"РµРЅРёРµ* (view) вЂ” СЌС‚Рѕ РёРµСЂР°СЂС…РёСЏ РєРѕРјРїРѕРЅРµРЅС‚РѕРІ, РѕР±С‹С‡РЅРѕ РѕР±СЉСЏРІР"РµРЅРЅР°СЏ РєР°Рє РєР"Р°СЃСЃ, РЅР°СЃР"РµРґСѓСЋС‰РёР№ РѕС‚ `Ext.Component` РёР"Рё `Ext.Container`. РџСЂРµРґСЃС‚Р°РІР"РµРЅРёРµ РЅРµ СЃРѕРґРµСЂР¶РёС‚ Р±РёР·РЅРµСЃ-Р"РѕРіРёРєРё Рё РЅРµ РѕР±СЂР°С‰Р°РµС‚СЃСЏ РЅР°РїСЂСЏРјСѓСЋ Рє РґР°РЅРЅС‹Рј.  
вЂ” *РљРѕРЅС‚СЂРѕР"Р"РµСЂ* (`Ext.app.Controller`) СЃРІСЏР·С‹РІР°РµС‚ СЃРѕР±С‹С‚РёСЏ РїСЂРµРґСЃС‚Р°РІР"РµРЅРёСЏ (РЅР°РїСЂРёРјРµСЂ, РєР"РёРє РїРѕ РєРЅРѕРїРєРµ) СЃ РґРµР№СЃС‚РІРёСЏРјРё РЅР°Рґ РјРѕРґРµР"СЊСЋ Рё С…СЂР°РЅРёР"РёС‰РµРј, Р° С‚Р°РєР¶Рµ СЂРµР°РіРёСЂСѓРµС‚ РЅР° РёР·РјРµРЅРµРЅРёСЏ РґР°РЅРЅС‹С…, РёРЅРёС†РёРёСЂСѓСЏ РѕР±РЅРѕРІР"РµРЅРёРµ РёРЅС‚РµСЂС„РµР№СЃР°. РљРѕРЅС‚СЂРѕР"Р"РµСЂ РЅРµ СѓРїСЂР°РІР"СЏРµС‚ DOM вЂ” РѕРЅ СѓРїСЂР°РІР"СЏРµС‚ *СЃРѕСЃС‚РѕСЏРЅРёРµРј* Рё *РїРѕС‚РѕРєРѕРј СЃРѕР±С‹С‚РёР№*.

РЎРІСЏР·РєР° РјРµР¶РґСѓ РїСЂРµРґСЃС‚Р°РІР"РµРЅРёРµРј Рё РєРѕРЅС‚СЂРѕР"Р"РµСЂРѕРј РѕР±РµСЃРїРµС‡РёРІР°РµС‚СЃСЏ С‡РµСЂРµР· *СЃРµР"РµРєС‚РѕСЂС‹* вЂ” СЃРёРЅС‚Р°РєСЃРёСЃ, РїРѕС…РѕР¶РёР№ РЅР° CSS-СЃРµР"РµРєС‚РѕСЂС‹, РЅРѕ СЂР°Р±РѕС‚Р°СЋС‰РёР№ СЃ `itemId`, `xtype`, РёРµСЂР°СЂС…РёРµР№ РєРѕРјРїРѕРЅРµРЅС‚РѕРІ. РќР°РїСЂРёРјРµСЂ, Р·Р°РїРёСЃСЊ `'button[action=save]'` РѕР·РЅР°С‡Р°РµС‚: "РЅР°Р№С‚Рё РІСЃРµ РєРЅРѕРїРєРё СЃ `action: 'save'` РІРЅСѓС‚СЂРё РґР°РЅРЅРѕРіРѕ РїСЂРµРґСЃС‚Р°РІР"РµРЅРёСЏ Рё РїРѕРґРїРёСЃР°С‚СЊСЃСЏ РЅР° РёС… СЃРѕР±С‹С‚РёРµ `click`". Р­С‚Рѕ РїРѕР·РІРѕР"СЏРµС‚ РёР·Р±РµР¶Р°С‚СЊ Р¶С‘СЃС‚РєРёС… СЃСЃС‹Р"РѕРє Рё РѕР±РµСЃРїРµС‡РёРІР°РµС‚ РіРёР±РєРѕСЃС‚СЊ РїСЂРё СЂРµС„Р°РєС‚РѕСЂРёРЅРіРµ.

Р’ **MVVM** СЂРѕР"СЊ РїРѕСЃСЂРµРґРЅРёРєР° РјРµР¶РґСѓ РїСЂРµРґСЃС‚Р°РІР"РµРЅРёРµРј Рё РјРѕРґРµР"СЊСЋ РёРіСЂР°РµС‚ *ViewModel* (`Ext.app.ViewModel`). Р­С‚Рѕ Р°РІС‚РѕРЅРѕРјРЅС‹Р№ РѕР±СЉРµРєС‚, СЃРѕРґРµСЂР¶Р°С‰РёР№ *Р"РѕРєР°Р"СЊРЅРѕРµ СЃРѕСЃС‚РѕСЏРЅРёРµ РїСЂРµРґСЃС‚Р°РІР"РµРЅРёСЏ*, *РІС‹С‡РёСЃР"СЏРµРјС‹Рµ РїРѕР"СЏ* Рё *РїСЂРёРІСЏР·РєРё* (bindings). ViewModel РЅРµ Р·РЅР°РµС‚ Рѕ РєРѕРЅС‚СЂРѕР"Р"РµСЂРµ Рё РЅРµ СЃРІСЏР·Р°РЅ СЃ Р¶РёР·РЅРµРЅРЅС‹Рј С†РёРєР"РѕРј РїСЂРµРґСЃС‚Р°РІР"РµРЅРёСЏ РЅР°РїСЂСЏРјСѓСЋ вЂ” РѕРЅ СЃСѓС‰РµСЃС‚РІСѓРµС‚ РїР°СЂР°Р"Р"РµР"СЊРЅРѕ Рё СѓРЅРёС‡С‚РѕР¶Р°РµС‚СЃСЏ РІРјРµСЃС‚Рµ СЃ РїСЂРµРґСЃС‚Р°РІР"РµРЅРёРµРј. Р•РіРѕ РіР"Р°РІРЅР°СЏ С„СѓРЅРєС†РёСЏ вЂ” РѕР±РµСЃРїРµС‡РёС‚СЊ *СЂРµР°РєС‚РёРІРЅРѕСЃС‚СЊ* Р±РµР· РёРјРїРµСЂР°С‚РёРІРЅРѕРіРѕ РєРѕРґР°.

РљР"СЋС‡РµРІРѕР№ РјРµС…Р°РЅРёР·Рј MVVM вЂ” **РґРІСѓСЃС‚РѕСЂРѕРЅРЅСЏСЏ РїСЂРёРІСЏР·РєР° РґР°РЅРЅС‹С…** (two-way binding). РљРѕРіРґР° СЂР°Р·СЂР°Р±РѕС‚С‡РёРє РѕР±СЉСЏРІР"СЏРµС‚ РїСЂРёРІСЏР·РєСѓ РјРµР¶РґСѓ РїРѕР"РµРј `firstName` РІ ViewModel Рё Р·РЅР°С‡РµРЅРёРµРј `textfield`, С‚Рѕ Р"СЋР±РѕРµ РёР·РјРµРЅРµРЅРёРµ РІ С‚РµРєСЃС‚РѕРІРѕРј РїРѕР"Рµ Р°РІС‚РѕРјР°С‚РёС‡РµСЃРєРё РѕР±РЅРѕРІР"СЏРµС‚ `firstName`, Р° Р"СЋР±РѕРµ РїСЂРѕРіСЂР°РјРјРЅРѕРµ РёР·РјРµРЅРµРЅРёРµ `firstName` вЂ” РѕР±РЅРѕРІР"СЏРµС‚ С‚РµРєСЃС‚РѕРІРѕРµ РїРѕР"Рµ. Р”Р"СЏ СЃР"РѕР¶РЅС‹С… СЃР"СѓС‡Р°РµРІ РїРѕРґРґРµСЂР¶РёРІР°СЋС‚СЃСЏ *С„РѕСЂРјСѓР"С‹* вЂ” С„СѓРЅРєС†РёРё, Р·Р°РІРёСЃСЏС‰РёРµ РѕС‚ РґСЂСѓРіРёС… РїРѕР"РµР№ Рё Р°РІС‚РѕРјР°С‚РёС‡РµСЃРєРё РїРµСЂРµСЃС‡РёС‚С‹РІР°РµРјС‹Рµ РїСЂРё РёС… РёР·РјРµРЅРµРЅРёРё (РЅР°РїСЂРёРјРµСЂ, `fullName = firstName + ' ' + lastName`). Р’Р°Р¶РЅРѕ: С„РѕСЂРјСѓР"С‹ РЅРµ СЏРІР"СЏСЋС‚СЃСЏ РІС‹СЂР°Р¶РµРЅРёСЏРјРё РІ РєРѕРґРµ вЂ” РѕРЅРё РґРµРєР"Р°СЂР°С‚РёРІРЅРѕ РѕРїРёСЃС‹РІР°СЋС‚СЃСЏ РІ РєРѕРЅС„РёРіСѓСЂР°С†РёРё ViewModel Рё СѓРїСЂР°РІР"СЏСЋС‚СЃСЏ С„СЂРµР№РјРІРѕСЂРєРѕРј, С‡С‚Рѕ РёСЃРєР"СЋС‡Р°РµС‚ РїРѕР±РѕС‡РЅС‹Рµ СЌС„С„РµРєС‚С‹ Рё С†РёРєР"РёС‡РµСЃРєРёРµ Р·Р°РІРёСЃРёРјРѕСЃС‚Рё.

Р MVC, Рё MVVM РјРѕРіСѓС‚ СЃРѕСЃСѓС‰РµСЃС‚РІРѕРІР°С‚СЊ РІ РѕРґРЅРѕРј РїСЂРёР"РѕР¶РµРЅРёРё — РєСЂСѓРїРЅС‹Рµ СЂР°Р·РґРµР"С‹ СЃС‚СЂРѕСЏС‚СЃСЏ РїРѕ MVVM (РЅР°РїСЂРёРјРµСЂ, С„РѕСЂРјР° СЂРµРґР°РєС‚РёСЂРѕРІР°РЅРёСЏ), Р° РіР"РѕР±Р°Р"СЊРЅР°СЏ РЅР°РІРёРіР°С†РёСЏ, Р°СѓС‚РµРЅС‚РёС„РёРєР°С†РёСЏ, РёРЅС‚РµРіСЂР°С†РёСЏ СЃ РІРЅРµС€РЅРёРјРё API вЂ” СѓРїСЂР°РІР"СЏСЋС‚СЃСЏ РєРѕРЅС‚СЂРѕР"Р"РµСЂР°РјРё. Р­С‚Рѕ РїРѕР·РІРѕР"СЏРµС‚ РІС‹Р±РёСЂР°С‚СЊ РѕРїС‚РёРјР°Р"СЊРЅСѓСЋ РјРѕРґРµР"СЊ РІ Р·Р°РІРёСЃРёРјРѕСЃС‚Рё РѕС‚ Р·Р°РґР°С‡Рё.

### Р Р°Р±РѕС‚Р° СЃ РґР°РЅРЅС‹РјРё

Р’ Ext JS РґР°РЅРЅС‹Рµ РѕС‚РґРµР"РµРЅС‹ РѕС‚ РёРЅС‚РµСЂС„РµР№СЃР° РЅР° Р°СЂС…РёС‚РµРєС‚СѓСЂРЅРѕРј СѓСЂРѕРІРЅРµ. Р”Р°Р¶Рµ РїСЂРѕСЃС‚Р°СЏ С‚Р°Р±Р"РёС†Р° РЅРµ СЃРѕРґРµСЂР¶РёС‚ РґР°РЅРЅС‹С… "РІ СЃРµР±Рµ" вЂ” РѕРЅР° Р"РёС€СЊ *РѕС‚РѕР±СЂР°Р¶Р°РµС‚* СЃРѕРґРµСЂР¶РёРјРѕРµ *С…СЂР°РЅРёР"РёС‰Р°* (`Ext.Data.Store`), РєРѕС‚РѕСЂРѕРµ, РІ СЃРІРѕСЋ РѕС‡РµСЂРµРґСЊ, СѓРїСЂР°РІР"СЏРµС‚ РєРѕР"Р"РµРєС†РёРµР№ СЌРєР·РµРјРїР"СЏСЂРѕРІ *РјРѕРґРµР"Рё* (`Ext.Data.Model`).

РњРѕРґРµР"СЊ вЂ” СЌС‚Рѕ РЅРµ РїСЂРѕСЃС‚Рѕ POJO-РѕР±СЉРµРєС‚. Р­С‚Рѕ РїРѕР"РЅРѕС†РµРЅРЅС‹Р№ РєР"Р°СЃСЃ СЃ СЃС‚СЂРѕРіРёРј РѕРїРёСЃР°РЅРёРµРј СЃС‚СЂСѓРєС‚СѓСЂС‹ — РєР°Р¶РґРѕРµ РїРѕР"Рµ РґРµРєР"Р°СЂРёСЂСѓРµС‚СЃСЏ СЃ С‚РёРїРѕРј (`string`, `int`, `date`, `boolean`, `auto`), РїСЂРё РЅРµРѕР±С…РѕРґРёРјРѕСЃС‚Рё вЂ” СЃ РІР°Р"РёРґР°С‚РѕСЂРѕРј (`presence`, `length`, `format`, РєР°СЃС‚РѕРјРЅР°СЏ С„СѓРЅРєС†РёСЏ), РєРѕРЅРІРµСЂС‚РµСЂРѕРј (`convert`) Рё СѓРјРѕР"С‡Р°С‚РµР"СЊРЅС‹Рј Р·РЅР°С‡РµРЅРёРµРј (`defaultValue`). РњРѕРґРµР"СЊ РїРѕРґРґРµСЂР¶РёРІР°РµС‚ Р°СЃСЃРѕС†РёР°С†РёРё — `hasMany`, `belongsTo`, `hasOne`, С‡С‚Рѕ РїРѕР·РІРѕР"СЏРµС‚ СЃС‚СЂРѕРёС‚СЊ РіСЂР°С„С‹ РґР°РЅРЅС‹С… Р±РµР· СЂСѓС‡РЅРѕРіРѕ СЃС€РёРІР°РЅРёСЏ РѕР±СЉРµРєС‚РѕРІ.

РҐСЂР°РЅРёР"РёС‰Рµ РІС‹СЃС‚СѓРїР°РµС‚ РІ СЂРѕР"Рё *Р±СѓС„РµСЂР° РґР°РЅРЅС‹С…* Рё *РєРѕРѕСЂРґРёРЅР°С‚РѕСЂР° РѕРїРµСЂР°С†РёР№*. РћРЅРѕ РѕС‚РІРµС‡Р°РµС‚ Р·Р°:  
вЂ” Р·Р°РіСЂСѓР·РєСѓ Р·Р°РїРёСЃРµР№ РёР· РёСЃС‚РѕС‡РЅРёРєР° (С‡РµСЂРµР· РїСЂРѕРєСЃРё),  
вЂ” Р"РѕРєР°Р"СЊРЅРѕРµ РєСЌС€РёСЂРѕРІР°РЅРёРµ Рё СЃРѕСЂС‚РёСЂРѕРІРєСѓ,  
вЂ” РѕС‚СЃР"РµР¶РёРІР°РЅРёРµ РёР·РјРµРЅРµРЅРёР№ ("РіСЂСЏР·РЅС‹С…" Р·Р°РїРёСЃРµР№),  
вЂ” РїР°РєРµС‚РЅСѓСЋ СЃРёРЅС…СЂРѕРЅРёР·Р°С†РёСЋ СЃ СЃРµСЂРІРµСЂРѕРј (`sync()`),

- `Ext.mixin.Bindable` вЂ” РїРѕРґРґРµСЂР¶РєР° РїСЂРёРІСЏР·РѕРє (bindings),
- `Ext.mixin.Selectable` вЂ” РїРѕРІРµРґРµРЅРёРµ РІС‹Р±РѕСЂР° (РґР"СЏ РіСЂРёРґРѕРІ, РґРµСЂРµРІСЊРµРІ),
- `Ext.mixin.Factoryable` вЂ” С„Р°Р±СЂРёС‡РЅС‹Р№ РїР°С‚С‚РµСЂРЅ РґР"СЏ РґРёРЅР°РјРёС‡РµСЃРєРѕРіРѕ СЃРѕР·РґР°РЅРёСЏ РєРѕРјРїРѕРЅРµРЅС‚РѕРІ.

РњРёРєСЃРёРЅС‹ СѓРІР°Р¶Р°СЋС‚ Р¶РёР·РЅРµРЅРЅС‹Р№ С†РёРєР" РєРѕРјРїРѕРЅРµРЅС‚Р°: РµСЃР"Рё РјРёРєСЃРёРЅ СЃРѕРґРµСЂР¶РёС‚ РјРµС‚РѕРґ `initComponent`, РѕРЅ Р±СѓРґРµС‚ РІС‹Р·РІР°РЅ РїРѕСЃР"Рµ `initComponent` РѕСЃРЅРѕРІРЅРѕРіРѕ РєР"Р°СЃСЃР°, РЅРѕ РґРѕ `afterRender`. Р­С‚Рѕ РїРѕР·РІРѕР"СЏРµС‚ Р±РµР·РѕРїР°СЃРЅРѕ РёРЅРёС†РёР°Р"РёР·РёСЂРѕРІР°С‚СЊ СЃРѕСЃС‚РѕСЏРЅРёРµ, РЅРµ РЅР°СЂСѓС€Р°СЏ РїРѕСЂСЏРґРєР° СЃРѕР±С‹С‚РёР№.

РњРёРєС€РёРЅС‹ вЂ” РЅРµ "РїР°С‚С‡РёРЅРі" РїСЂРѕС‚РѕС‚РёРїР°. РћРЅРё РІРЅРµРґСЂСЏСЋС‚СЃСЏ РЅР° СЌС‚Р°РїРµ РѕРїСЂРµРґРµР"РµРЅРёСЏ РєР"Р°СЃСЃР°, Рё РєР°Р¶РґС‹Р№ СЌРєР·РµРјРїР"СЏСЂ РїРѕР"СѓС‡Р°РµС‚ *СЃРІРѕСЋ РєРѕРїРёСЋ* РјРµС‚РѕРґРѕРІ (РІ РїСЂРµРґРµР"Р°С… РѕРіСЂР°РЅРёС‡РµРЅРёР№ JavaScript), С‡С‚Рѕ РёСЃРєР"СЋС‡Р°РµС‚ РїРѕР±РѕС‡РЅС‹Рµ СЌС„С„РµРєС‚С‹ РїСЂРё СЃРѕРІРјРµСЃС‚РЅРѕРј РёСЃРїРѕР"СЊР·РѕРІР°РЅРёРё.

### Ext JS РІ РєРѕРЅС‚РµРєСЃС‚Рµ low-code РїР"Р°С‚С„РѕСЂРј

РџР"Р°С‚С„РѕСЂРјС‹ РєР"Р°СЃСЃР° Creatio (СЂР°РЅРµРµ bpmвЂ™online), ELMA365 Рё Р°РЅР°Р"РѕРіРёС‡РЅС‹Рµ enterprise-СЂРµС€РµРЅРёСЏ РґР"СЏ Р°РІС‚РѕРјР°С‚РёР·Р°С†РёРё Р±РёР·РЅРµСЃ-РїСЂРѕС†РµСЃСЃРѕРІ С‡Р°СЃС‚Рѕ РёСЃРїРѕР"СЊР·СѓСЋС‚ Ext JS РєР°Рє *Р±Р°Р·РѕРІСѓСЋ front-end-РїР"Р°С‚С„РѕСЂРјСѓ* РґР"СЏ РїРѕСЃС‚СЂРѕРµРЅРёСЏ РїРѕР"СЊР·РѕРІР°С‚РµР"СЊСЃРєРёС… РёРЅС‚РµСЂС„РµР№СЃРѕРІ вЂ” РѕСЃРѕР±РµРЅРЅРѕ РІ РјРѕРґСѓР"СЏС…, С‚СЂРµР±СѓСЋС‰РёС… РІС‹СЃРѕРєРѕР№ РёРЅС‚РµСЂР°РєС‚РёРІРЅРѕСЃС‚Рё — CRM-РїР°РЅРµР"Рё, РєРѕРЅСЃС‚СЂСѓРєС‚РѕСЂС‹ С„РѕСЂРј, Р°РЅР°Р"РёС‚РёС‡РµСЃРєРёРµ РґР°С€Р±РѕСЂРґС‹, СЂРµРґР°РєС‚РѕСЂС‹ РїСЂРѕС†РµСЃСЃРѕРІ.

Р’Р°Р¶РЅРѕ РїРѕРґС‡РµСЂРєРЅСѓС‚СЊ: РІ С‚Р°РєРёС… СЃРёСЃС‚РµРјР°С… Ext JS **РЅРµ РёСЃРїРѕР"СЊР·СѓРµС‚СЃСЏ "РІ С‡РёСЃС‚РѕРј РІРёРґРµ"**. РћРЅ РёРЅС‚РµРіСЂРёСЂСѓРµС‚СЃСЏ РІ СЃРѕР±СЃС‚РІРµРЅРЅСѓСЋ РјРµС‚Р°СЃРёСЃС‚РµРјСѓ:
- Р’РјРµСЃС‚Рѕ СЂСѓС‡РЅРѕРіРѕ РѕР±СЉСЏРІР"РµРЅРёСЏ `Ext.define('MyApp.view...')` РёРЅС‚РµСЂС„РµР№СЃС‹ РѕРїРёСЃС‹РІР°СЋС‚СЃСЏ РІ *РјРµС‚Р°РґР°РЅРЅС‹С…* (XML РёР"Рё JSON-РєРѕРЅС„РёРіСѓСЂР°С†РёРё), РєРѕС‚РѕСЂС‹Рµ РІ runtime РєРѕРјРїРёР"РёСЂСѓСЋС‚СЃСЏ РІРѕ РІРЅСѓС‚СЂРµРЅРЅРёРµ РѕР±СЉРµРєС‚С‹ Ext JS.
- РљР"Р°СЃСЃС‹ РєРѕРјРїРѕРЅРµРЅС‚РѕРІ Р·Р°РјРµРЅСЏСЋС‚СЃСЏ *РјРѕРґСѓР"СЏРјРё СЃС‚СЂР°РЅРёС†* (РЅР°РїСЂРёРјРµСЂ, `BasePageV2`, `SectionPageV2` РІ Creatio), РєРѕС‚РѕСЂС‹Рµ РЅР°СЃР"РµРґСѓСЋС‚ РѕС‚ Р°Р±СЃС‚СЂР°РєС†РёР№ РїР"Р°С‚С„РѕСЂРјС‹, Р° РЅРµ РЅР°РїСЂСЏРјСѓСЋ РѕС‚ `Ext.panel.Panel`.
- РџСЂРёРІСЏР·РєР° РґР°РЅРЅС‹С… РёРґС‘С‚ РЅРµ Рє `Ext.Data.Model`, Р° Рє *СЃСѓС‰РЅРѕСЃС‚СЏРј РґРѕРјРµРЅРЅРѕР№ РјРѕРґРµР"Рё* (РЅР°РїСЂРёРјРµСЂ, `Contact`, `Account`), СѓРїСЂР°РІР"СЏРµРјС‹Рј СЃРµСЂРІРµСЂРЅС‹Рј API Рё РєР"РёРµРЅС‚СЃРєРёРј РєСЌС€РµРј.
- РњРµС…Р°РЅРёР·Рј СЃРѕР±С‹С‚РёР№ СЂР°СЃС€РёСЂСЏРµС‚СЃСЏ РїР"Р°С‚С„РѕСЂРјРѕ-Р·Р°РІРёСЃРёРјС‹РјРё С‚СЂРёРіРіРµСЂР°РјРё ("РґРѕ СЃРѕС…СЂР°РЅРµРЅРёСЏ", "РїРѕСЃР"Рµ Р·Р°РіСЂСѓР·РєРё", "РїСЂРё СЃРјРµРЅРµ СЃС‚Р°С‚СѓСЃР°"), РєРѕС‚РѕСЂС‹Рµ С‚СЂР°РЅСЃР"РёСЂСѓСЋС‚СЃСЏ РІ РІС‹Р·РѕРІС‹ Ext-СЃРѕР±С‹С‚РёР№.

РўРµРј РЅРµ РјРµРЅРµРµ, Р·РЅР°РЅРёРµ Ext JS РґР°С‘С‚ СЂР°Р·СЂР°Р±РѕС‚С‡РёРєСѓ РєСЂРёС‚РёС‡РµСЃРєРѕРµ РїСЂРµРёРјСѓС‰РµСЃС‚РІРѕ РїСЂРё РєР°СЃС‚РѕРјРёР·Р°С†РёРё С‚Р°РєРёС… РїР"Р°С‚С„РѕСЂРј:
