# Angular

Angular — это мощный фронтенд-фреймворк с открытым исходным кодом от компании Google, предназначенный для разработки сложных, крупных и высоконагруженных веб-приложений. В отличие от React, это не просто библиотека, а полноценная платформа («все включено») с жестко заданной архитектурой и готовыми встроенными инструментами. Фреймворк разрабатывается на языке TypeScript (надстройке над JavaScript от Microsoft), что обеспечивает строгую типизацию и делает код более предсказуемым.

Главные особенности:
- Всё из коробки. Разработчику не нужно искать сторонние библиотеки. Маршрутизация (routing), валидация форм, HTTP-клиент для запросов к серверу и управление состоянием уже встроены и поддерживаются Google.
- Компонентная структура. Интерфейс строится из изолированных компонентов, каждый из которых содержит свою логику (TS), разметку (HTML) и стили (CSS).
- Двустороннее связывание данных. Как и во Vue, изменения в коде мгновенно обновляют интерфейс, а ввод пользователя в форму сразу меняет переменные в коде.
- Внедрение зависимостей (Dependency Injection). Архитектурный паттерн, который помогает легко передавать данные и сервисы между разными частями приложения, делая код чистым и удобным для тестирования.
- Мощный CLI. Консольный инструмент Angular CLI позволяет одной командой генерировать компоненты, собирать и тестировать проект.

Не путайте AngularJS (старую версию 1.x, созданную в 2010 году на чистом JS) и современный Angular (версии 2 и выше). В 2016 году Google полностью переписал фреймворк с нуля, изменив архитектуру. Сегодня актуальной является экосистема современного Angular (на июнь 2026 года вышла версия Angular 22 с продвинутой системой реактивности Angular Signals и интеграцией AI-инструментов).

**Angular** — цельная платформа с CLI — TypeScript по умолчанию, встроенные маршруты, формы, HTTP и RxJS. Удобна там, где команда хочет единые правила из коробки.
