# Node.js

Node.js — это JavaScript на сервере и в CLI — файлы, сеть, процессы, API для браузера. Раздел разбит на короткие статьи — от первого `node app.js` до Express, fullstack и выкладки в production.

Node.js — это бесплатная кроссплатформенная среда выполнения языка JavaScript, которая позволяет запускать JS-код вне браузера. Она построена на базе высокопроизводительного движка V8 от Google (используемого в Chrome) и написана преимущественно на C++. Раньше JavaScript работал исключительно внутри браузеров для оживления веб-страниц. Node.js извлек этот движок наружу, превратив JavaScript в полноценный язык программирования общего назначения. Теперь с помощью JS можно писать полноценные программы прямо на компьютере или сервере.

Один язык на весь стек позволяет разработчикам писать и фронтенд (внешний вид сайта), и бэкенд (логику сервера) на одном языке — JavaScript. Здесь имеет место и асинхронность - Node.js не ждет, пока завершится чтение тяжелого файла или ответ от базы данных. Он продолжает обрабатывать другие запросы, что делает его невероятно быстрым при работе с большим количеством одновременных сетевых подключений.

И самое главное, что у Node огромная экосистема. Node Package Manager — это крупнейший в мире репозиторий готовых библиотек и модулей, которые можно бесплатно скачивать и использовать в своих проектах.

> Это не язык программирования (языком остается JavaScript).

> Это не фреймворк и не библиотека (хотя внутри нее работают популярные серверные фреймворки, такие как Express или NestJS).
