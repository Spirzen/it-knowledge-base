# CLI экосистемы JavaScript

Консольные утилиты (CLI) — первый контакт с экосистемой — ими ставят зависимости, запускают dev-сервер, собирают production и проверяют код. Без карты команд легко копировать строки из README, не понимая, что именно выполняется.

## Материалы

- **[Справочник CLI — команды по категориям](./1.md)** — менеджеры пакетов и runtime (`node`, `npm`, `yarn`, `pnpm`, `bun`, `deno`), компиляторы и сборщики (`tsc`, `vite`, `webpack`, `turbo`), CLI фреймворков (`next`, `ng`, `vue`, …) и инструменты качества (`eslint`, `prettier`, `jest`). По **10 типовых команд** на каждую утилиту.

## Быстрый старт

1. Установите [Node.js LTS](https://nodejs.org/) — в комплекте идут `node` и `npm`.
2. Откройте [справочник](./1.md) и найдите свою задачу в оглавлении (установка пакетов, dev-сервер, сборка, тесты).
3. Углубляйтесь в профильные статьи раздела [Node.js](../1-runtime-node/intro.md) или нужного [фреймворка](../2-frontend-frameworks/intro.md).
