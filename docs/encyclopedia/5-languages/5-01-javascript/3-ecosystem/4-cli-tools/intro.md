# CLI экосистемы JavaScript

Консольные утилиты (CLI) — первый контакт с экосистемой — ими ставят зависимости, запускают dev-сервер, собирают production и проверяют код. Без карты команд легко копировать строки из README, не понимая, что именно выполняется.

В экосистеме JavaScript под CLI (Command Line Interface) понимают консольные инструменты, которые автоматизируют рутину: создание, настройку, сборку, тестирование и деплой проектов.Их можно разделить на четыре основные группы в зависимости от выполняемых задач.
- CLI пакетных менеджеров (Управление зависимостями). Эти инструменты установлены на компьютере у каждого JS-разработчика. Они управляют библиотеками в проекте.
- CLI фронтенд-фреймворков (Скаффолдинг и генерация). Они нужны, чтобы не настраивать конфигурационные файлы (Webpack, Babel) вручную. Одной командой они разворачивают готовый шаблон приложения и генерируют новые сущности.
- CLI инструментов сборки и проверки кода. Инструменты, которые запускаются через терминал локально или в процессах CI/CD (автоматического деплоя) для контроля качества кода.
- Инструменты для создания собственных CLI. Поскольку JavaScript (через Node.js) работает на сервере и ПК, разработчики часто пишут собственные консольные утилиты для автоматизации внутренних процессов компании. Для этого используют специальные библиотеки.
