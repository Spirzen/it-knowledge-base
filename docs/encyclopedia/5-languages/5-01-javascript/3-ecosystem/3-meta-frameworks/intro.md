# Meta Frameworks

Мета-фреймворк (или фреймворк над фреймворком) — это полноценная платформа разработки, которая берет за основу базовый фронтенд-инструмент (например, React или Vue) и добавляет к нему готовые серверные функции и строгие правила архитектуры. Если обычный фронтенд-фреймворк отвечает только за то, что происходит в браузере пользователя (клиентская часть), то мета-фреймворк объединяет клиентский и серверный код в одну общую систему (Fullstack).

Классические приложения на React или Vue работают как SPA (Single Page Application). Блокнот браузера изначально получает пустой HTML-файл и огромный JavaScript-скрипт. Браузер запускает этот скрипт и сам «рисует» сайт. У такого подхода есть два огромных минуса:
- Плохое SEO (поисковая оптимизация). Роботы Яндекса или Google, заходя на сайт, видят пустую страницу, так как не всегда успевают подождать, пока выполнится JavaScript. Сайт тяжело продвинуть в топ поисковиков.
- Долгая первая загрузка. Пользователь видит белый экран, пока скачивается и запускается тяжелый код.

Мета-фреймворки внедряют технологии SSR (Server-Side Rendering) или SSG (Static Site Generation). Когда пользователь запрашивает страницу, мета-фреймворк на сервере мгновенно собирает готовый HTML-код с текстом и картинками и отправляет его в браузер. Пользователь и поисковые роботы сразу видят готовый контент. После этого в фоновом режиме подгружается JavaScript, и сайт становится интерактивным (этот процесс называется гидратацией).

Помимо серверного рендеринга, они избавляют разработчика от рутинной настройки проекта:
- Файловый роутинг. Чтобы создать новую страницу на сайте, достаточно просто создать файл в специальной папке (например, файл `about.js` автоматически станет страницей `/about`).
- Оптимизация картинок и шрифтов. Фреймворк сам сжимает изображения под размер экрана пользователя.
- Встроенное API. Можно писать серверный код (например, запросы к базе данных) прямо внутри того же проекта.

Для каждого базового фронтенд-инструмента сегодня есть свой мета-лидер:
- Next.js — самый популярный мета-фреймворк, построенный поверх React. Используется для интернет-магазинов, блогов и крупных порталов.
- Nuxt.js — мощная платформа надстройка для Vue.
- SvelteKit — мета-фреймворк для быстро набирающего популярность инструмента Svelte.
- Remix — еще один современный конкурент Next.js на базе React, сфокусированный на быстрой работе с данными.

Meta-framework ставится **поверх** React — файловая маршрутизация, серверный рендер, сборка и договорённости проекта уже заложены в стартовый шаблон.

## Критерии выбора Next.js

Подключайте Next.js, если нужны SEO и быстрый первый экран (SSR/SSG), один репозиторий для UI и server routes, или вы хотите меньше времени тратить на выбор инструментов вручную. Для учебного SPA на Vite + Express meta-framework не обязателен — см. [fullstack Node](../1-runtime-node/264.md).
