# Meta Frameworks

Meta-framework ставится **поверх** React — файловая маршрутизация, серверный рендер, сборка и договорённости проекта уже заложены в стартовый шаблон.

## Материалы

- [Первая программа на Next.js](./2731.md) — App Router с нуля

## Критерии выбора Next.js

Подключайте Next.js, если нужны SEO и быстрый первый экран (SSR/SSG), один репозиторий для UI и server routes, или вы хотите меньше времени тратить на выбор инструментов вручную. Для учебного SPA на Vite + Express meta-framework не обязателен — см. [fullstack Node](../1-runtime-node/264.md).
