# JavaScript экосистема — Runtime и Frameworks

Здесь собрано то, что идёт **после** основ языка: где крутится JavaScript вне браузера, как собирают интерфейсы и какие платформы накладывают SSR, маршруты и сборку поверх React.

Четыре ветки раздела:

- **Runtime** — Node.js, npm, Express, связка с фронтом.
- **Frontend frameworks** — React, Vue, Angular, Ext JS.
- **Meta-frameworks** — Next.js и похожие каркасы.
- **CLI экосистемы** — справочник консольных утилит и типовых команд.

Ниже — ссылки по порядку изучения и справочники, когда нужна шпаргалка по API.
