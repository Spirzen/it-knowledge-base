## Первая программа на Node.js

### Node.js — серверный JavaScript

В браузере JavaScript ограничен правилами безопасности: нельзя слушать произвольный порт, читать файлы пользователя без разрешения. **Node.js** запускает тот же язык как обычную программу на компьютере или сервере — с доступом к сети, файловой системе и процессам.

Логичный шаг после синтаксиса JS и `async/await` — поднять **HTTP-сервер**: программу, которая ждёт запросы по сети и отвечает JSON или HTML.

**Express** — популярная библиотека поверх встроенного `http` в Node. Она даёт:

- **маршруты** — "если `GET /notes` — выполни эту функцию";
- **middleware** — общие шаги до маршрута (разбор JSON, логи, CORS);
- удобные `req` / `res` вместо низкоуровневых потоков.

Мы соберём **REST API "Заметки"** — тот же учебный сценарий, что в [Gin](/encyclopedia/5-languages/5-10-go/2412.md) и [Ktor](/encyclopedia/5-languages/5-09-kotlin/221.md). Данные пока в **памяти** (массив в переменной): после перезапуска сервера список пустой. Так проще увидеть путь запроса → ответ без настройки базы.

### Что такое REST в двух словах

**REST** — стиль API, где ресурсы (заметки, пользователи) имеют **URL**, а действие задаёт **HTTP-метод**:

| Метод | Обычный смысл | В нашем API |
|-------|----------------|-------------|
| GET | Прочитать | Список или одна заметка |
| POST | Создать | Новая заметка в теле JSON |
| DELETE | Удалить | Заметка по id в пути |

Ответы чаще всего **JSON** — текст в фигурных скобках, который понимают и браузер, и мобильное приложение.

---

### Что получится

| Метод | Путь | Действие |
|-------|------|----------|
| GET | `/health` | Сервер жив |
| GET | `/notes` | Список заметок |
| POST | `/notes` | Тело `{ "text": "..." }` — создать |
| DELETE | `/notes/:id` | Удалить по id |

Фронтенд (React, мобильное приложение) ходит сюда по HTTP — так устроена большая часть современных приложений.

```bash
mkdir notes-api && cd notes-api
npm init -y
npm install express
npm install -D nodemon
```

`package.json` — добавьте ESM и скрипты:

```json
{
  "name": "notes-api",
  "type": "module",
  "scripts": {
    "dev": "nodemon server.js",
    "start": "node server.js"
  }
}
```

| Поле / пакет | Смысл |
|--------------|--------|
| `"type": "module"` | Можно писать `import` / `export` |

| `npm run dev` | Разработка с автоперезапуском |

## Минимальный сервер — по шагам

Файл `server.js` — точка входа.

1. **`express()`** — объект приложения с методами `get`, `post`, `use`, `listen`.
2. **`app.use(express.json())`** — middleware: если клиент прислал JSON, положить объект в `req.body`.
3. **Маршруты** — функции "URL + метод совпали → ответь".
4. **`app.listen(PORT)`** — начать слушать порт (по умолчанию 3000).

```javascript
import express from 'express';

const app = express();
const PORT = process.env.PORT || 3000;

app.use(express.json());

const notes = [];
let nextId = 1;

app.get('/health', (_req, res) => {
  res.json({ status: 'ok' });
});

app.get('/notes', (_req, res) => {
  res.json(notes);
});

app.post('/notes', (req, res) => {
  const text = String(req.body?.text ?? '').trim();
  if (!text) {
    return res.status(400).json({ error: 'text is required' });
  }
  const note = { id: nextId++, text, createdAt: new Date().toISOString() };
  notes.push(note);
  res.status(201).json(note);
});

app.delete('/notes/:id', (req, res) => {
  const id = Number(req.params.id);
  const idx = notes.findIndex((n) => n.id === id);
  if (idx === -1) {
    return res.status(404).json({ error: 'not found' });
  }
  notes.splice(idx, 1);
  res.status(204).send();
});

app.listen(PORT, () => {
  console.log(`API: http://127.0.0.1:${PORT}`);
});
```

### Разбор фрагментов

| Код | Смысл |
|-----|--------|
| `_req` | Подчёркивание: параметр не используем, но сигнатура нужна |
| `req.body?.text` | Optional chaining: если `body` нет — `undefined`, без падения |
| `?? ''` | Если слева `null`/`undefined` — пустая строка |
| `.trim()` | Убрать пробелы по краям |
| `return res.status(400)...` | Остановить обработчик |
| `201` | HTTP "создано" |
| `req.params.id` | Часть URL `/notes/:id` → `id` из пути |
| `204` | Успех без тела ответа (типично для DELETE) |
| `process.env.PORT` | Порт из переменной окружения (хостинг задаёт сам) |

Запуск:

```bash
npm run dev
```

В консоли: `API: http://127.0.0.1:3000`. Терминал оставьте открытым; остановка — `Ctrl+C`.

## Проверка через curl

Второй терминал:

```bash
curl http://127.0.0.1:3000/health
curl http://127.0.0.1:3000/notes
curl -X POST http://127.0.0.1:3000/notes \
  -H "Content-Type: application/json" \
  -d "{\"text\": \"Изучить Node\"}"
curl http://127.0.0.1:3000/notes
curl -X DELETE http://127.0.0.1:3000/notes/1
```

| Флаг curl | Смысл |
|-----------|--------|
| `-X POST` | Метод POST |
| `-H "Content-Type: application/json"` | Тело — JSON; нужен `express.json()` |
| `-d "{...}"` | Тело запроса |

`Connection refused` — сервер не запущен или другой порт. Пустой `req.body` при POST — нет `express.json()` или заголовка `Content-Type`.

## Middleware — цепочка "до" маршрута

**Middleware** — функция `(req, res, next)`. Express вызывает их **по порядку** регистрации. Пока не вызван `next()`, запрос не дойдёт до следующего звена (если вы уже не отправили ответ).

| Middleware | Задача |
|------------|--------|
| `express.json()` | Разобрать JSON-тело |
| Логирование | Записать method, url, время |
| `cors` | Разрешить браузерный фронт с другого порта — [263](./263.md) |

Пример логирования — после `express.json()`:

```javascript
app.use((req, res, next) => {
  const started = Date.now();
  res.on('finish', () => {
    console.log(req.method, req.url, res.statusCode, `${Date.now() - started}ms`);
  });
  next();
});
```

`res.on('finish')` — ответ уже ушёл клиенту; можно замерить длительность.

Подробнее: [Express 263](./263.md).

## Вынести маршруты в Router

Когда эндпоинтов больше пяти, `server.js` раздувается. **Router** — подмножество маршрутов с общим префиксом:

`routes/notes.js`:

```javascript
import { Router } from 'express';

export function createNotesRouter(store) {
  const router = Router();

  router.get('/', (_req, res) => {
    res.json(store.list());
  });

  router.post('/', (req, res) => {
    const text = String(req.body?.text ?? '').trim();
    if (!text) return res.status(400).json({ error: 'text is required' });
    res.status(201).json(store.add(text));
  });

  router.delete('/:id', (req, res) => {
    const ok = store.remove(Number(req.params.id));
    if (!ok) return res.status(404).json({ error: 'not found' });
    res.status(204).send();
  });

  return router;
}
```

В `server.js`:

```javascript
import { createNotesRouter } from './routes/notes.js';
app.use('/notes', createNotesRouter(store));
```

`router.get('/')` + префикс `/notes` = **`GET /notes`**.

### Частые ошибки

| Симптом | Причина | Что сделать |
|---------|---------|-------------|
| `Cannot find module 'express'` | Нет `npm install` | `cd notes-api && npm install` |
| `req.body` всегда `undefined` | Нет `express.json()` или неверный `Content-Type` | Middleware выше маршрутов; curl с `-H` |
| DELETE не находит id | Путь `/notes/:id`, читать `req.params.id` | Двоеточие в шаблоне пути |
| Изменения не видны | Запущен `node`, не nodemon | `npm run dev` |
| CORS в браузере | Фронт :5173, API :3000 | [263](./263.md) или прокси [264](./264.md) |
