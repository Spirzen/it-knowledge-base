## Kotlin и Java — совместимость на практике

**Kotlin и Java** компилируются в один **байт-код JVM** — классы видят друг друга в одном проекте без мостов. Сложности начинаются на **границе API**: `null`, перегрузки, статические методы, коллекции.

Обзор: [экосистема Kotlin](./10.md). Java-сторона: [ООП Java](/encyclopedia/5-languages/5-03-java/18). Spring на Kotlin: [232.md](./232.md).

---

### Правило большого пальца

| Пишете | Думайте о потребителе |
|--------|------------------------|
| Kotlin, вызывают из Java | `@JvmStatic`, `@JvmOverloads`, `@Nullable` |
| Java, вызывают из Kotlin | Platform types `T!`, проверяйте null |
| Постепенная миграция | Новые файлы `.kt`, старые `.java` рядом |

## Вызов Java из Kotlin

Java-класс:

```java
// src/main/java/com/example/JavaGreeter.java
package com.example;

import org.jetbrains.annotations.Nullable;

public class JavaGreeter {
    public String greet(@Nullable String name) {
        return "Hello, " + (name != null ? name : "World");
    }
}
```

Kotlin:

```kotlin
fun main() {
    val g = JavaGreeter()
    val s: String? = g.greet(null)  // Java @Nullable → Kotlin String?
    println(s)
}
```

**Разбор:** без аннотаций Java `String` в Kotlin становится **platform type** `String!` — компилятор не заставит проверить null. Используйте JetBrains `@Nullable` / `@NotNull` или javax.

## Вызов Kotlin из Java

```kotlin
// KotlinUtils.kt
package com.example

object KotlinUtils {
    @JvmStatic
    fun twice(x: Int) = x * 2

    @JvmOverloads
    fun join(parts: List<String>, separator: String = ", ") =
        parts.joinToString(separator)
}

data class User(val id: Long, val name: String)
```

Java:

```java
int n = KotlinUtils.twice(21);
String line = KotlinUtils.join(List.of("a", "b")); // overload по умолчанию
User u = new User(1L, "Ann"); // генерируются getter'ы component1()...
```

| Аннотация | Зачем |
|-----------|--------|
| `@JvmStatic` | `KotlinUtils.twice()` без `.INSTANCE` |
| `@JvmOverloads` | Default-аргументы Kotlin → перегрузки Java |
| `data class` | `getName()`, `copy()`, `equals` для JavaBeans |

## SAM и лямбды

Java:

```java
public interface ClickListener {
    void onClick();
}
```

Kotlin:

```kotlin
val listener = ClickListener { println("click") }
```

Kotlin лямбда → SAM-адаптер Java. Обратно: Java 8+ лямбда передаётся в Kotlin `( ) -> Unit`, если тип функциональный.

## Коллекции и мутабельность

Java `List<String>` из API может быть **mutable**. Kotlin `List` по умолчанию read-only view:

```kotlin
fun process(items: MutableList<String>) {
    items.add("tail") // OK если Java передал ArrayList
}
```

На границе — явные типы `MutableList` / `java.util.List`.

## Постепенная миграция файла

1. Включить Kotlin в Maven/Gradle ([2.md](./2.md)).
2. Новые классы — `.kt` рядом с `.java` в том же пакете.
3. Заменить POJO на `data class`, сервисы — с конструкторной DI.
4. Удалить Java, когда тесты зелёные.

Не конвертируйте весь модуль одним коммитом без тестов.

### Частые ошибки

| Симптом | Причина |
|---------|---------|
| NPE из «безопасного» Kotlin | Java вернул null без `@Nullable` |
| `KotlinUtils.INSTANCE.twice` | Нет `@JvmStatic` на методе `object` |
| Дубли перегрузок | Конфликт `@JvmOverloads` с ручными Java-методами |
| `UnsupportedOperationException` | Изменили Kotlin `List` view с Java |
