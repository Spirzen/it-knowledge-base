## Консольный ввод и вывод

Программы на JVM по умолчанию общаются с пользователем через **стандартные потоки**: `stdin` (ввод), `stdout` (вывод), `stderr` (ошибки). Для учебных задач, утилит и скриптов этого достаточно без GUI.

Старт: [первая программа](./2.md). Дальше — [корутины](./222.md) и [Ktor](./221.md) для сетевых CLI-сервисов.

---

## Вывод в консоль

```kotlin
fun main() {
    print("Введите имя: ")   // без перевода строки
    println("Готово.")       // с переводом строки
    System.err.println("Ошибка конфигурации")  // в stderr
}
```

Строковая интерполяция:

```kotlin
val n = 42
println("Ответ: $n, квадрат: ${n * n}")
```

Многострочный текст — **тройные кавычки**:

```kotlin
val help = """
    Использование: app <имя>
    Пример: app Анна
""".trimIndent()
println(help)
```

## Ввод с клавиатуры

С Kotlin 1.6+ для простых случаев:

```kotlin
fun main() {
    print("Имя: ")
    val name = readln()
    print("Возраст: ")
    val age = readln().toIntOrNull() ?: run {
        println("Нужно целое число")
        return
    }
    println("Привет, $name! Через $age лет вам будет ${age + 1}.")
}
```

`readln()` читает строку до Enter (без символа `\n` в результате). Для пустого ввода вернётся `""`.

Альтернатива — `readLine()` из Java-совместимого API: возвращает `String?` (`null` при EOF).

```kotlin
val line = readLine()
if (line.isNullOrBlank()) {
    println("Пустой ввод")
}
```

## Аргументы командной строки

```kotlin
fun main(args: Array<String>) {
    if (args.isEmpty()) {
        println("Укажите имя: app <имя>")
        return
    }
    val name = args[0]
    val greet = args.getOrElse(1) { "Привет" }
    println("$greet, $name!")
}
```

Запуск:

```bash
./gradlew run --args="Анна"
# или после сборки:
java -jar app.jar Анна
```

В IntelliJ IDEA: Run → Edit Configurations → Program arguments.

## Цикл «меню» в консоли

```kotlin
fun main() {
    while (true) {
        println("1 — сложить  2 — выход")
        when (readln().trim()) {
            "1" -> {
                val a = readln().toIntOrNull() ?: continue
                val b = readln().toIntOrNull() ?: continue
                println(a + b)
            }
            "2" -> break
            else -> println("Неизвестная команда")
        }
    }
}
```

Для интерактивных утилит важно обрабатывать `toIntOrNull()` и пустые строки, иначе программа падает с `NumberFormatException`.

## Чтение файла из консольной программы

```kotlin
import java.io.File

fun main() {
    val path = readln().trim()
    val lines = File(path).readLines()
    println("Строк: ${lines.size}")
    lines.take(5).forEach { println(it) }
}
```

Большие файлы лучше обрабатывать через [Sequence](./225.md), а не `readLines()` целиком.

## Кодировка и Windows

Консоль Windows по умолчанию может использовать не UTF-8. Если кириллица отображается криво:

- в PowerShell: `chcp 65001` перед запуском;
- в Gradle для `run`: `-Dfile.encoding=UTF-8`.

В Linux и macOS UTF-8 обычно уже настроен.
