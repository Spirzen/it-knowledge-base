## Spring Boot на Kotlin — первая программа

На JVM **Spring Boot** чаще встречается в Java-кодовых базах, но **Kotlin** там first-class: те же стартеры, `data class`, null-safety, лаконичные контроллеры.

| Стек | Когда выбирать |
|------|----------------|
| [Ktor](./221.md) | Kotlin-native, явные маршруты, корутины «из коробки» |
| **Spring Boot + Kotlin** | Команда на Spring, экосистема (Security, Data, Cloud) |

Java-версия того же сценария: [271.md](/encyclopedia/5-languages/5-03-java/271). Обзор Spring: [27.md](/encyclopedia/5-languages/5-03-java/27).

**Перед стартом:** [первая программа на Kotlin](./2.md).

### Что получится

`GET http://localhost:8080/api/hello?name=Анна` → JSON `{"message":"Привет, Анна!"}`.

---

## Проект (Gradle Kotlin DSL)

[start.spring.io](https://start.spring.io): **Kotlin**, **Gradle**, **Spring Web**, Java **17**.

Корневой `build.gradle.kts` (фрагмент):

```kotlin
plugins {
    kotlin("jvm") version "1.9.24"
    kotlin("plugin.spring") version "1.9.24"
    id("org.springframework.boot") version "3.3.0"
    id("io.spring.dependency-management") version "1.1.5"
}

java {
    toolchain { languageVersion.set(JavaLanguageVersion.of(17)) }
}

dependencies {
    implementation("org.springframework.boot:spring-boot-starter-web")
    testImplementation("org.springframework.boot:spring-boot-starter-test")
}
```

Плагин `kotlin("plugin.spring")` открывает классы для Spring (аналог `open` в Java не нужен вручную).

---

## Точка входа

```kotlin
package com.example.demo

import org.springframework.boot.autoconfigure.SpringBootApplication
import org.springframework.boot.runApplication

@SpringBootApplication
class DemoApplication

fun main(args: Array<String>) {
    runApplication<DemoApplication>(*args)
}
```

`runApplication` — идиоматичный Kotlin-обёртка над `SpringApplication.run`.

---

## Модель и сервис

```kotlin
data class HelloResponse(val message: String)

@Service
class HelloService {
    fun greet(name: String?): HelloResponse {
        val who = name?.trim().takeUnless { it.isNullOrEmpty() } ?: "мир"
        return HelloResponse("Привет, $who!")
    }
}
```

`data class` автоматически даёт `equals`/`copy` — удобно для JSON.

---

## Контроллер

```kotlin
@RestController
@RequestMapping("/api")
class HelloController(private val service: HelloService) {

    @GetMapping("/hello")
    fun hello(@RequestParam(required = false) name: String?): HelloResponse =
        service.greet(name)
}
```

**Разбор:** конструкторная инъекция `HelloService` — рекомендуемый стиль; параметр `name` опционален.

## Запуск и проверка

```bash
./gradlew bootRun
curl -s "http://localhost:8080/api/hello?name=Анна"
```

В IDEA: Run `DemoApplicationKt`.

## Kotlin ↔ Java в одном проекте

- Java-классы вызываются из Kotlin без обёрток.
- Для Spring/JPA из Kotlin: плагины `allOpen` / `noArg` или `kotlin("plugin.jpa")`.
- Nullable в Kotlin не спасает от Java `null` — на границе API проверяйте вход.

---

### Частые ошибки

| Симптом | Причина |
|---------|---------|
| `Invalid bean definition` | Класс `final` без `plugin.spring` |
| 404 | Неверный `@RequestMapping` |
| Кракозябры в JSON | Кодировка UTF-8 в `application.properties`: `server.servlet.encoding.charset=UTF-8` |
