## Ktor Client

**Ktor Client** — HTTP-клиент на [корутинах](./222.md). Один стиль API для JVM, Android и Kotlin Multiplatform. Серверная часть того же стека: [Ktor — первая программа](./221.md).

---

## Зависимости (JVM)

`build.gradle.kts`:

```kotlin
plugins {
    kotlin("jvm") version "1.9.24"
    kotlin("plugin.serialization") version "1.9.24"
    application
}

dependencies {
    implementation("io.ktor:ktor-client-core:2.3.12")
    implementation("io.ktor:ktor-client-cio:2.3.12")
    implementation("io.ktor:ktor-client-content-negotiation:2.3.12")
    implementation("io.ktor:ktor-serialization-kotlinx-json:2.3.12")
    implementation("io.ktor:ktor-client-logging:2.3.12")
}
```

На **Android** вместо `cio` часто подключают `ktor-client-okhttp`.

## Создание клиента

```kotlin
import io.ktor.client.*
import io.ktor.client.call.*
import io.ktor.client.engine.cio.*
import io.ktor.client.plugins.contentnegotiation.*
import io.ktor.client.plugins.logging.*
import io.ktor.client.request.*
import io.ktor.http.*
import io.ktor.serialization.kotlinx.json.*
import kotlinx.serialization.json.Json

val client = HttpClient(CIO) {
    install(ContentNegotiation) {
        json(Json { ignoreUnknownKeys = true })
    }
    install(Logging) {
        level = LogLevel.INFO
    }
}
```

Клиент дорогой в создании — держите **один экземпляр** на приложение (singleton, DI) и закрывайте при завершении: `client.close()`.

## GET и POST

Предположим, запущен сервер из [статьи про Ktor Server](./221.md) на порту 8080.

```kotlin
import kotlinx.coroutines.runBlocking

suspend fun demo(client: HttpClient) {
    val health: Map<String, String> = client.get("http://127.0.0.1:8080/health").body()
    println(health)

    val notes: List<Note> = client.get("http://127.0.0.1:8080/notes").body()
    println("Заметок: ${notes.size}")

    val created: Note = client.post("http://127.0.0.1:8080/notes") {
        contentType(ContentType.Application.Json)
        setBody(NoteCreate("Из клиента"))
    }.body()
    println("Создано: ${created.id} — ${created.text}")
}

fun main() = runBlocking {
    val client = HttpClient(CIO) {
        install(ContentNegotiation) { json() }
    }
    try {
        demo(client)
    } finally {
        client.close()
    }
}
```

Все вызовы — `suspend`; в Android используйте `viewModelScope.launch`, в KMP — общий `CoroutineScope` в `commonMain`.

## Обработка ошибок

```kotlin
import io.ktor.client.plugins.*

suspend fun safeGet(client: HttpClient, url: String): String? =
    try {
        client.get(url).body()
    } catch (e: ClientRequestException) {
        println("HTTP ${e.response.status}: ${e.response.status.description}")
        null
    } catch (e: ServerResponseException) {
        println("Ошибка сервера: ${e.response.status}")
        null
    }
```

Для таймаутов настройте в блоке `HttpClient { }`:

```kotlin
engine {
    requestTimeout = 10_000
}
```

## Заголовки и авторизация

```kotlin
client.get("https://api.example.com/profile") {
    header(HttpHeaders.Authorization, "Bearer $token")
    parameter("page", 1)
}
```

Плагин `Auth` добавляет автоматическую подстановку токена для серии запросов.

## Android и KMP

| Платформа | Движок |
|-----------|--------|
| JVM / Desktop | `CIO` |
| Android | `OkHttp` |
| iOS (KMP) | `Darwin` |

В мультиплатформенном проекте объявите `expect fun createHttpClient(): HttpClient` в `commonMain` и `actual` в `androidMain` / `iosMain` — так сеть остаётся в общем коде, а движок подставляется по платформе.

Связь с UI: ответ загружают в `viewModelScope`, результат кладут в `StateFlow` — см. [Flow](./226.md) и [Jetpack Compose](./229.md).
