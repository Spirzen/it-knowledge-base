## Room, ViewModel и Compose — список заметок

[Compose — первый экран](./229.md) показал счётчик, который **сбрасывается** при повороте телефона или убийстве процесса. В реальном приложении список заметок, настройки и корзина живут дольше — их кладут в **базу на устройстве**.

Здесь соберём минимальный, но **настоящий** стек Google рекомендует для новых экранов:

- **Room** — SQLite без ручного SQL везде;
- **ViewModel** — состояние переживает поворот экрана;
- **Compose** — рисует список, когда данные в Flow обновились.

**Перед стартом:** [первая программа](./2.md), [Compose](./229.md), [корутины](./222.md) (хотя бы `runTest` и `launch`). Маршрут раздела: [intro](./intro.md).

### Слои (как думать о коде)

```
Compose (NotesScreen)
    ↓ collectAsState
ViewModel (NotesViewModel)
    ↓ Flow<List<Note>>
DAO (NoteDao) → Room → SQLite
```

Пользователь нажимает «Добавить» → ViewModel пишет в БД → Flow эмитит новый список → Compose перерисовывает список.

---

### Что получится

Экран: поле ввода, кнопка «Добавить», список заметок. Данные остаются после закрытия приложения.

## Зависимости (`app/build.gradle.kts`)

```kotlin
plugins {
    id("com.google.devtools.ksp") version "2.0.0-1.0.24" // подставьте под версию Kotlin
}

dependencies {
    val room = "2.6.1"
    implementation("androidx.room:room-runtime:$room")
    implementation("androidx.room:room-ktx:$room")
    ksp("androidx.room:room-compiler:$room")

    implementation("androidx.lifecycle:lifecycle-viewmodel-compose:2.8.0")
    implementation("androidx.compose.material3:material3")
}
```

`room-ktx` даёт `suspend` и `Flow` в DAO.

## Сущность и DAO

```kotlin
@Entity(tableName = "notes")
data class NoteEntity(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    @ColumnInfo(name = "text") val text: String
)

@Dao
interface NoteDao {
    @Query("SELECT * FROM notes ORDER BY id DESC")
    fun observeAll(): Flow<List<NoteEntity>>

    @Insert
    suspend fun insert(note: NoteEntity)
}
```

**Разбор:** `observeAll()` — реактивный источник; при `insert` Room сам обновит подписчиков Flow.

## База данных

```kotlin
@Database(entities = [NoteEntity::class], version = 1)
abstract class AppDatabase : RoomDatabase() {
    abstract fun noteDao(): NoteDao
}
```

В `Application` или через `Room.databaseBuilder(context, AppDatabase::class.java, "notes.db").build()` — для учебного проекта допустим ленивый синглтон в ViewModel (в проде — Hilt/Dagger).

## ViewModel

```kotlin
class NotesViewModel(private val dao: NoteDao) : ViewModel() {

    val notes: StateFlow<List<NoteEntity>> =
        dao.observeAll()
            .stateIn(
                scope = viewModelScope,
                started = SharingStarted.WhileSubscribed(5_000),
                initialValue = emptyList()
            )

    fun addNote(text: String) {
        if (text.isBlank()) return
        viewModelScope.launch {
            dao.insert(NoteEntity(text = text.trim()))
        }
    }
}
```

**Разбор:**

- `viewModelScope.launch` — запись в БД не блокирует UI-поток;
- `stateIn` — превращает cold `Flow` в `StateFlow` для Compose;
- `WhileSubscribed(5000)` — отписка, когда экрана нет (экономия ресурсов).

## Compose-экран

```kotlin
@Composable
fun NotesScreen(vm: NotesViewModel = viewModel(
    factory = /* фабрика с dao — см. ниже */
)) {
    val notes by vm.notes.collectAsState()
    var input by remember { mutableStateOf("") }

    Column(Modifier.padding(16.dp)) {
        OutlinedTextField(
            value = input,
            onValueChange = { input = it },
            label = { Text("Заметка") },
            modifier = Modifier.fillMaxWidth()
        )
        Button(
            onClick = {
                vm.addNote(input)
                input = ""
            },
            modifier = Modifier.padding(vertical = 8.dp)
        ) { Text("Добавить") }

        LazyColumn {
            items(notes, key = { it.id }) { note ->
                Text(note.text, modifier = Modifier.padding(8.dp))
            }
        }
    }
}
```

Фабрика ViewModel в учебном проекте (упрощённо):

```kotlin
// В Activity:
val db = Room.databaseBuilder(this, AppDatabase::class.java, "notes.db").build()
setContent {
    val vm: NotesViewModel = viewModel(factory = object : ViewModelProvider.Factory {
        override fun <T : ViewModel> create(modelClass: Class<T>): T {
            @Suppress("UNCHECKED_CAST")
            return NotesViewModel(db.noteDao()) as T
        }
    })
    MaterialTheme { NotesScreen(vm) }
}
```

В реальных проектах подключают **Hilt** — см. [экосистему](./10.md).

### Частые ошибки

| Симптом | Причина |
|---------|---------|
| Список пустой после добавления | DAO без `Flow` / не тот `Dispatcher` |
| `Cannot access database on main thread` | `insert` не `suspend` и не в корутине |
| KSP не генерирует DAO | Не применён plugin `ksp` |
| Сброс при повороте без ViewModel | Состояние только в `remember`, не в VM |
