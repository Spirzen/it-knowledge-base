## Назначение

Курируемый **навигатор** по официальному [справочнику языка C#](https://learn.microsoft.com/ru-ru/dotnet/csharp/language-reference/) на Microsoft Learn. Здесь собрана **полная текущая структура** документации (типы, ключевые слова, операторы, операторы языка, атрибуты, директивы препроцессора, параметры компилятора, XML-комментарии, сообщения CS). Тексты статей **не копируются** — только названия разделов и ссылки, как в [навигаторе Microsoft Learn](/tools/documentation/6).

Шпаргалка по синтаксису в энциклопедии: [Справочник по C#](./471.md). Учебный курс: [раздел C#](./intro).
