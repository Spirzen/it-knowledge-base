## Назначение

Курируемый **навигатор** по официальному [.NET API browser](https://learn.microsoft.com/ru-ru/dotnet/api/) — базовой библиотеке классов (BCL), которую использует C# и другие языки .NET. В каталоге перечислены **все пространства имён** и число типов для выбранной целевой платформы. Документация по членам типов открывается на Learn; тексты **не дублируются** в энциклопедии.

Учебные статьи по API: [служебные классы](./32.md), [коллекции](./28.md), [async](./39.md), [Task и async/await](./392.md), [класс `Thread`](./391.md). Платформа: [раздел .NET](../5-04-platforma-dotnet/intro).

## Часто используемые пространства имён

| Пространство имён | Назначение |
|-------------------|------------|
| `System` | Базовые типы, `Object`, `String`, `Exception`, `GC` |
| `System.Collections.Generic` | `List<T>`, `Dictionary<TKey,TValue>`, `IEnumerable<T>` |
| `System.Linq` | LINQ to Objects |
| `System.Threading` / `System.Threading.Tasks` | Потоки (`Thread` — учебная статья [391](./391.md)), `Task`, `async` |
| `System.Net.Http` | `HttpClient`, HTTP |
| `System.IO` | Файлы, потоки, `Path` |
| `System.Text.Json` | JSON-сериализация (.NET Core+) |
| `System.Diagnostics` | Логирование, `Activity`, метрики |
