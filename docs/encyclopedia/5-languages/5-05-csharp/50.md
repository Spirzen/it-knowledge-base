# Сравнение C# и Java

<div class="article-tags">
  <span class="tag tag-reference">СПРАВОЧНИК</span>
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>
</div>

**C#** и **Java** — два популярных языка для корпоративных приложений, веб-сервисов и игр. Оба поддерживают [объектно-ориентированное программирование](/encyclopedia/4-code-dev/4-08-oop/intro), [строгую статическую типизацию](/encyclopedia/1-basics/1-09-dannye-i-informatsiya/4) и похожий C-style синтаксис (фигурные скобки, точка с запятой, классы). Программа на любом из них сначала [компилируется](/encyclopedia/4-code-dev/4-02-chto-takoe-kod-i-kak-on-rabotaet/1) в промежуточный [байт-код](/encyclopedia/4-code-dev/4-03-vypolnenie-koda/314), а затем выполняется виртуальной машиной с [сборкой мусора](/encyclopedia/4-code-dev/4-15-sborka-musora/1).

Сходство синтаксиса обманчиво. За одинаковыми словами `class`, `interface`, `new` стоят разные платформы, библиотеки и привычные инструменты команд. Ниже — разбор по темам с таблицами и ссылками на статьи энциклопедии. Актуальные версии на **2026 год**

- .NET 10 и C# 14;
- Java 25 LTS, в продакшене часто ещё Java 21 LTS.

Для общего выбора первого языка см. [Как выбрать язык программирования](/encyclopedia/5-languages/kak-vybrat-yazyk-programmirovaniya#попарное-сравнение-для-выбора).

## Общее наследие

Оба языка создавались в эпоху **управляемого кода** — когда разработчик пишет на высоком уровне, а память и безопасность типов контролирует runtime.

| | C# | Java |
|---|-----|------|
| Первый релиз | 2000, вместе с [.NET](/encyclopedia/5-languages/5-04-platforma-dotnet/11) | 1995, JDK 1.0 |
| Создатель | Microsoft, Андерс Хейлсберг (Turbo Pascal, Delphi) | Sun Microsystems, Джеймс Гослинг; с 2010 — Oracle |
| Исходная идея | Язык уровня Java с расширениями для Windows | Один исходник — запуск на любой ОС через JVM |
| Стандарт | [ECMA-334](https://www.ecma-international.org/publications-and-standards/standards/ecma-334/) (язык), [ECMA-335](https://www.ecma-international.org/publications-and-standards/standards/ecma-335/) (CLI) | [JLS](https://docs.oracle.com/javase/specs/jls/), [JVMS](https://docs.oracle.com/javase/specs/jvms/) |
| Открытость | .NET 5+ — open source (MIT), [Roslyn](https://github.com/dotnet/roslyn), CoreCLR на GitHub | [OpenJDK](https://openjdk.org/) (GPL+Classpath) |

Microsoft разрабатывала C# как язык той же "семьи", что и Java

- классы и интерфейсы;
- сборщик мусора;
- байт-код вместо прямой компиляции в exe под одну ОС;
- плюс [свойства](./25.md), [делегаты](./33.md), [структуры](./18.md) и интеграция с Windows.

Сегодня и [.NET](https://dotnet.microsoft.com/), и OpenJDK работают на Windows, Linux и macOS. Выбор языка редко сводится к операционной системе сервера.

## Среда выполнения — CLR и JVM

**CLR** (Common Language Runtime) и **JVM** (Java Virtual Machine) решают одну задачу

- загружают байт-код;
- компилируют "горячие" участки в машинный код через **JIT**;
- выделяют объекты в [куче](/encyclopedia/5-languages/5-05-csharp/19);
- периодически запускают **GC**, чтобы освободить память.

| Аспект | CLR (.NET) | JVM |
|--------|------------|-----|
| Что деплоим | Сборка (assembly) — файл `.dll` с типами и метаданными | JAR или модуль (JPMS с Java 9) |
| Другие языки на той же VM | C#, F#, VB.NET в одном процессе | Kotlin, Scala, Groovy — свои компиляторы, общая JVM |
| Компиляция заранее (AOT) | [Native AOT](https://learn.microsoft.com/dotnet/core/deploying/native-aot/) (.NET 7+), ReadyToRun | GraalVM Native Image |
| Настройка GC | Workstation / Server, [параметры GC](https://learn.microsoft.com/dotnet/core/runtime-config/garbage-collector) | G1, ZGC, Shenandoah — [шпаргалка GC](/encyclopedia/4-code-dev/4-15-sborka-musora/4#java--поколения-и-выбор-алгоритма) |
| Потоки | Потоки ОС, пул потоков, [async/await](./392.md) | Потоки ОС, [virtual threads](/encyclopedia/5-languages/5-03-java/308) (Java 21) |
| Метаданные и рефлексия | Source generators, атрибуты | Reflection API, [аннотации](/encyclopedia/5-languages/5-03-java/299) |

Для обычного REST-сервиса с базой данных разница между CLR и JVM обычно меньше, чем разница между командами, выбранным фреймворком и уже существующим кодом в компании.

## Синтаксис

Внешне языки похожи. Ниже — места, где новичок чаще всего путает правила.

### Первая программа и точка входа

C# (.NET 6+, [top-level statements](./49.md))

```csharp
Console.WriteLine("Hello, World!");
```

Java ([точка входа `main`](/encyclopedia/5-languages/5-03-java/40))

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

В Java метод `public static void main(String[] args)` обязателен — JVM ищет именно его. В C# с .NET 6+ достаточно команд в `Program.cs` без обёртки-класса.

### Свойства и доступ к полям

C# — ключевое слово `property`, геттер и сеттер в одном объявлении

```csharp
public class User {
    public string Name { get; set; }
    public int Age { get; private set; }
}
```

Java — отдельные методы `getName()` / `setName()` по соглашению JavaBeans; для простых DTO с Java 16 — `record`

```java
public record User(String name, int age) {}
```

В C# аналог — [тип `record`](./25.md) и выражение `with` для копии с изменением полей.

### Строки

| Задача | C# | Java |
|--------|-----|------|
| Сравнить текст по символам | `a == b` для типа `string` | `a.equals(b)` |
| Сравнить, указывают ли переменные на один объект | `ReferenceEquals(a, b)` | `a == b` |
| Безопасно обработать отсутствие значения | `?.`, [nullable reference types](./22.md) | `Optional<T>`, в Kotlin — встроенная проверка null |

Подробнее — [работа с типами в C#](./21.md), [строки в Java](/encyclopedia/5-languages/5-03-java/296), [типы в Java](/encyclopedia/5-languages/5-03-java/15).

### Числа, struct и boxing

| | C# | Java |
|---|-----|------|
| `int` | Синоним структуры `System.Int32` | [Примитив](/encyclopedia/5-languages/5-03-java/15#priminitiv-i-klass-obertka), не объект |
| Число может быть "пустым" | `int?` (`Nullable<int>`) | `Integer`, autoboxing |
| Маленькие типы без аллокации в куче | `struct`, `record struct` | Только примитивы; остальное — объекты в куче |
| Указатели | Блок `unsafe` | В стандартной Java недоступны |

Таблицы boxing и unboxing — [типы данных в C#](./18.md#znachimye-tipy-i-boxing), [упаковка в Java](/encyclopedia/5-languages/5-03-java/15#upakovka-i-raspakovka-boxing--unboxing).

### Лямбды, LINQ и Stream API

| Возможность | C# | Java |
|-------------|-----|------|
| Лямбда-выражения | С версии 3.0 | С Java 8 |
| Запросы к коллекциям | [LINQ](./29.md) — `list.Where(x => x > 0)` | Stream API — `list.stream().filter(x -> x > 0)` |
| Сопоставление с образцом | `switch` expressions, `is` (C# 7+) | `instanceof` + `switch` (Java 21+) |
| Неизменяемый DTO | `record` (C# 9) | `record` (Java 16) |
| Ожидание сети или диска | `async` / `await` | `CompletableFuture`, [virtual threads](/encyclopedia/5-languages/5-03-java/308) |

[LINQ](./29.md) в C# один для списков в памяти, XML и запросов к БД через [EF Core](./441.md). В Java [Stream API](/encyclopedia/5-languages/5-03-java/11) покрывает коллекции; для SQL — JPA, jOOQ, [работа с БД](/encyclopedia/5-languages/5-03-java/22).

## Асинхронность и параллелизм

**Асинхронность** — способ не блокировать поток, пока программа ждёт ответ сети, диска или базы. Теория — [процессы и потоки](/encyclopedia/4-code-dev/4-05-asinhronnost/1), [асинхронность в коде](/encyclopedia/4-code-dev/4-05-asinhronnost/intro).

### C# — async и await

Ключевые слова встроены в язык и стандартную библиотеку

```csharp
var json = await httpClient.GetStringAsync(url);
```

Компилятор строит **state machine** (автомат состояний): пока идёт I/O, поток может обслуживать другие задачи. Разбор — [Task и async/await](./392.md), [асинхронность в C#](./39.md).

### Java — пулы потоков и virtual threads

До Java 21 типичны

- пул потоков и `CompletableFuture`;
- реактивные библиотеки (Project Reactor, RxJava);
- NIO для неблокирующего ввода-вывода.

С **Java 21** появились **virtual threads** (лёгкие потоки JVM)

```java
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    executor.submit(() -> fetchData(url));
}
```

Подробнее — [virtual threads](/encyclopedia/5-languages/5-03-java/308), [асинхронность в Java](/encyclopedia/5-languages/5-03-java/298).

### Сводка по задачам

| Задача | C# | Java |
|--------|-----|------|
| HTTP, файлы, БД без блокировки UI | `async`/`await`, `Task` | Virtual threads, NIO, reactive |
| Параллельные вычисления на CPU | `Parallel.For`, PLINQ, `Task.Run` | `parallelStream()`, `ForkJoinPool` |
| Блокировки и очереди | `lock`, `Monitor`, [channels](https://learn.microsoft.com/dotnet/api/system.threading.channels) | `synchronized`, `java.util.concurrent` |

## Производительность

Оба языка используют JIT и дают высокую скорость на задачах с интенсивными вычислениями. В синтетических тестах (TechEmpower, BenchmarkDotNet, JMH) лидер зависит от сценария. В реальном веб-API на результат сильнее влияют

- архитектура и запросы к БД;
- кеширование;
- сеть;
- настройка пула соединений.

| Фактор | C# / .NET | Java |
|--------|-----------|------|
| Меньше объектов в куче | `struct`, `Span<T>` | Объектная модель, `StringBuilder` для конкатенации |
| Быстрый холодный старт | Native AOT | GraalVM Native Image |
| Очень большая куча | Настройки GC CLR | ZGC, Shenandoah |

Профилирование — [производительность в C#](./41.md), [JVM и память в Java](/encyclopedia/5-languages/5-03-java/23), [настройка JVM](/encyclopedia/5-languages/5-03-java/3.md#24-jvm--параметры-запуска-и-настройка).

## Как выбрать язык под задачу

### C# подойдёт, если вы хотите

- делать игры в [Unity](/encyclopedia/9-spinoff/9-04-razrabotka-igr/3);
- работать в стеке Microsoft (Azure, Active Directory);
- писать [десктоп под Windows](/encyclopedia/4-code-dev/4-11-desktopnye-prilozheniya/intro) (WPF, WinForms) или кроссплатформу через MAUI;
- использовать единый CLI `dotnet` и частые обновления языка ([версии C#](./48.md));
- перейти с Java на синтаксически близкий язык с LINQ и async из коробки.

### Java подойдёт, если вы хотите

- читать и дописывать большой legacy на Spring;
- строить стек вокруг Spark, Hadoop, Kafka;
- максимизировать число вакансий и переносимость между компаниями;
- опираться на платформу без привязки к одному вендору;
- идти в Android — тогда первым языком лучше взять [Kotlin](/encyclopedia/5-languages/5-09-kotlin/intro).

### Оба языка в одной карьере

Синтаксис и [ООП](/encyclopedia/4-code-dev/4-08-oop/intro) переносятся за один–три месяца практики. Дольше учится экосистема

- Spring или ASP.NET;
- Maven/Gradle или NuGet;
- привычки async/await или virtual threads.

На собеседованиях по .NET часто спрашивают темы из [474](./474.md); по Java — [Core Java interview](/encyclopedia/5-languages/5-03-java/301).

## Словарь соответствий

| Понятие | C# | Java |
|---------|-----|------|
| Базовый тип для всех объектов | `object`, `System.Object` | `java.lang.Object` |
| Группировка кода | `namespace`, `using` | `package`, `import` |
| Метод в интерфейсе с телом | `interface` + реализация по умолчанию (C# 8) | `default` в интерфейсе (Java 8) |
| Исключения, которые компилятор заставляет обработать | Нет (всё unchecked) | Checked и unchecked |
| Наследование классов | Один родитель | Один родитель |
| Метаданные в коде | Атрибуты `[Obsolete]` | Аннотации `@Deprecated` |
| Сборка артефакта | `dotnet build` → `.dll` | `mvn package` → `.jar` |
| Интерактивная консоль | `dotnet-script`, C# Interactive | `jshell` |
| Точка входа | `Main` или top-level statements | `public static void main` |

Развёрнутое сравнение ООП — [ООП в C#](./25.md#мини-сравнение-с-другими-языками), [ООП в Java](/encyclopedia/5-languages/5-03-java/18#мини-сравнение-с-другими-языками). [Парадигмы](/encyclopedia/4-code-dev/4-07-paradigmy-i-urovni-abstraktsii/intro), [обобщения в C#](./26.md), [generics в Java](/encyclopedia/5-languages/5-03-java/19).
