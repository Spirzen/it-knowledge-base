## FAQ — Часто задаваемые вопросы

Типичные сбои и ситуации, с которыми сталкиваются новички после раздела. Здесь — **что делать и где копать в главах**; определения для зачёта — в [чек-листе](./999.md).

<div class="faq-list">

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `dart` не находится после установки Flutter SDK — только `flutter` работает.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Dart входит в состав Flutter: добавьте в PATH каталог <strong>`flutter/bin/cache/dart-sdk/bin`</strong> или установите отдельный Dart SDK с dart.dev. Проверьте `dart --version`. Подробнее здесь — [первая программа](./7.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `dart run script.dart` — "Couldn't resolve package" для файла в одной папке.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Для зависимостей нужен <strong>`pubspec.yaml`</strong> и `dart pub get`. Одиночный файл без пакетов запускайте как `dart run script.dart` из его каталога или создайте проект `dart create`. Подробнее здесь — [первая программа](./7.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Код из статьи про `dart:io` не компилируется для web.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>`dart:io` недоступен в браузере</strong> — только VM и нативные платформы. Для web используйте `dart:html` / `package:http`. Подробнее здесь — [консоль и HTTP](./9.md), [runtime](./3.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `Null check operator used on a null value` — программа падает в runtime.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Оператор <strong>`!`</strong> принудительно снимает nullable; при `null` будет исключение. Используйте `?.`, `??` или проверку `if (x != null)`. Подробнее здесь — [типы](./4.md), [основы](./2.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Присвоил `null` переменной — компилятор: "A value of type 'Null' can't be assigned to 'String'".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Тип должен быть nullable: <strong>`String?`</strong>, а не `String`. Null safety включён по умолчанию в Dart 3. Подробнее здесь — [типы](./4.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `late String name` — "LateInitializationError: Field has not been initialized".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>`late`</strong> обещает присвоение до первого чтения. Инициализируйте в конструкторе, `initState` (Flutter) или через `late final x = ...`. Подробнее здесь — [классы и ООП](./10.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `final list = [1, 2]; list.add(3)` работает — final же "константа"?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>`final`</strong> фиксирует ссылку на объект, но содержимое изменяемой коллекции можно менять. Неизменяемый список — `const` или `List.unmodifiable`. Подробнее здесь — [основы](./2.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `async` функция вернула `Future`, а я ждал число сразу.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Результат появится позже — нужен <strong>`await`</strong> внутри другой `async` функции или `.then()`. В `main` используйте `void main() async { ... }`. Подробнее здесь — [async](./6.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Забыл `await` при записи файла — программа завершилась, файл пустой.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `writeAsString` возвращает <strong>`Future`</strong>; без `await` процесс может выйти до завершения I/O. Подробнее здесь — [простые приложения](./103.md), [консоль и HTTP](./9.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `Unhandled Exception` в `Future` — стек указывает на event loop, а не на мой код.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Оборачивайте асинхронный код в <strong>`try/catch`</strong> внутри `async` или используйте `.catchError` на Future. Подробнее здесь — [async](./6.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> HTTP-запрос в Flutter "завис" — UI не реагирует.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Сетевой вызов на <strong>главном isolate</strong> блокирует UI. Используйте `async`/`await` (не блокирующий `HttpClient` в синхронном коде) или `compute`/`Isolate.run` для тяжёлой работы. Подробнее здесь — [async](./6.md), [Flutter](./311.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `HttpClient` — "Bad state: HttpClient is closed".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Клиент закрыли через <strong>`close()`</strong>, а потом снова вызвали `getUrl`. Создайте новый экземпляр или закрывайте в `finally` после последнего запроса. Подробнее здесь — [консоль и HTTP](./9.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Локальный `HttpServer` на 8080 — "Address already in use".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Порт занят предыдущим запуском или другим сервисом. Завершите процесс или смените порт в <strong>`HttpServer.bind`</strong>. Подробнее здесь — [простые приложения](./103.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `jsonDecode` — "type 'String' is not a subtype of type 'int'".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> JSON числа могут прийти как <strong>`double`</strong>; поля вручную приводите через `(j['id'] as num).toInt()` или используйте `fromJson` с проверками. Подробнее здесь — [простые приложения](./103.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Switch по enum — компилятор требует `default` после добавления нового значения.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Для <strong>exhaustive switch</strong> (Dart 3) все варианты enum должны быть покрыты — это защита от забытых веток. Добавьте case для нового значения. Подробнее здесь — [паттерны Dart 3](./8.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Pattern matching по record — "The matched value isn't compatible with this pattern".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Имена полей и типы в pattern должны <strong>точно совпадать</strong> с record. Используйте `(a: var x, b: var y)` для именованных полей. Подробнее здесь — [паттерны Dart 3](./8.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `~/` и `/` дали разные результаты на двух `int`.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>`/`</strong> для int в Dart 3 даёт `double` (3/2 = 1.5); <strong>`~/`</strong> — целочисленное деление (1). Подробнее здесь — [синтаксис](./12.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Приватное поле `_name` видно из другого файла в том же проекте.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> В Dart приватность — <strong>на уровне библиотеки</strong> (файла), не класса. Для настоящей инкапсуляции используйте отдельные файлы/part. Подробнее здесь — [классы и ООП](./10.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `extends` vs `implements` — дублировал весь интерфейс вручную.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>`implements`</strong> требует реализовать все члены; <strong>`extends`</strong> наследует реализацию. Для mixin-поведения — `with`. Подробнее здесь — [классы и ООП](./10.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Flutter: изменил переменную в `State`, UI не обновился.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> После изменения состояния вызовите <strong>`setState(() { ... })`</strong>. Без этого framework не перестроит виджеты. Подробнее здесь — [Flutter](./311.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Hot reload не подхватил изменение в `main()` или static field.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Hot reload <strong>не переинициализирует</strong> глобальное состояние и некоторые static. Сделайте hot restart (Shift+R) или полный перезапуск. Подробнее здесь — [Flutter](./311.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `pub get` failed — version solving failed на конфликт SDK.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Проверьте <strong>`environment: sdk:`</strong> в `pubspec.yaml` и версию Flutter/Dart. Обновите зависимости или ослабьте constraint. Подробнее здесь — [первая программа](./7.md), [Flutter](./311.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `print` в production Flutter засоряет логи — чем заменить?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Используйте <strong>`debugPrint`</strong>, `log` из `dart:developer` или пакет logger; в release `print` часто отключают. Подробнее здесь — [основы](./2.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Сравнил два списка через `==` — false, хотя элементы одинаковые.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Для списков `==` сравнивает <strong>элементы по deep equality</strong> если элементы поддерживают `==`; разные экземпляры List с теми же элементами — equal. Для объектов без переопределения `==` сравниваются ссылки. Подробнее здесь — [типы](./4.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `Stream` подписался, события не приходят — забыл `listen`.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Stream <strong>ленивый</strong> до подписки. Вызовите `stream.listen(...)` или используйте `await for`. Не забудьте `cancel` на subscription. Подробнее здесь — [async](./6.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Пришёл из JavaScript — `dynamic` везде, компилятор молчит, потом падает в runtime.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>`dynamic`</strong> отключает статические проверки. Для учебного кода задавайте конкретные типы и nullable явно. Подробнее здесь — [типы](./4.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `readAsLines` проглотил последнюю строку без `\n` в конце файла.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Это нормальное поведение — последняя строка без завершающего перевода всё равно попадает в список. При записи добавляйте `\n` явно, как в [простых приложениях](./103.md). Подробнее здесь — [консоль и HTTP](./9.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Хочу только Flutter — можно пропустить консоль и `dart:io`?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Для UI можно, но <strong>async, типы и null safety</strong> одинаковы; консольные примеры быстрее отладить без эмулятора. Минимум — [основы](./2.md), [async](./6.md), [первая программа](./7.md). Подробнее здесь — [оглавление](./intro).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Dart и Flutter — в чём разница, нужно ли учить Dart для Flutter?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>Flutter</strong> — UI-фреймворк; <strong>Dart</strong> — язык, на котором пишут и виджеты, и логику. Без Dart Flutter не освоить. Подробнее здесь — [Flutter](./311.md), [основы](./2.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Как установить Dart SDK отдельно от Flutter на Windows?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Скачайте SDK с dart.dev или используйте `flutter/bin/cache/dart-sdk/bin` из Flutter. Проверка — `dart --version`. Подробнее здесь — [первая программа](./7.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Dart null safety — что такое `String` и `String?`?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `String` не принимает null; `String?` — nullable. Операторы `?.`, `??`, `!` для безопасной работы. Подробнее здесь — [типы](./4.md), [основы](./2.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Dart async await tutorial — как начать с нуля?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Объявите `Future`-функцию, вызовите с `await` внутри `async main` или handler. Пример HTTP — [async](./6.md), [консоль и HTTP](./9.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Dart vs JavaScript — что лучше для веба?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> JS — нативный язык браузера; Dart в web компилируется в JS или Wasm, силён во Flutter и typed backend. Сравнение runtime — [3.md](./3.md), [JavaScript](../5-01-javascript/intro).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Dart vs Kotlin для Android — что выбирают в 2025?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Нативный Android — Kotlin; кроссплатформа iOS+Android — Flutter на Dart. Подробнее здесь — [Flutter](./311.md), [Kotlin](../5-09-kotlin/intro).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Как запустить Dart консольное приложение hello world?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `dart create -t console myapp`, затем `dart run bin/myapp.dart` или один файл `dart run hello.dart`. Подробнее здесь — [первая программа](./7.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Future vs Stream в Dart — когда что использовать?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> <strong>Future</strong> — одно значение позже (HTTP, файл); <strong>Stream</strong> — поток событий (WebSocket, клавиатура). Подробнее здесь — [async](./6.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Dart isolate — как сделать многопоточность?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Изолаты не делят память; тяжёлые задачи — `Isolate.run` или `compute` во Flutter. Подробнее здесь — [runtime](./3.md), [async](./6.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Flutter hot reload не работает — что проверить?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Изменения в `main`, static и native code требуют hot restart. Убедитесь, что проект в debug mode. Подробнее здесь — [Flutter](./311.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> pubspec.yaml — как добавить зависимость в Dart проект?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Секция `dependencies:` + `dart pub get`. Версии и SDK constraint в `environment:`. Подробнее здесь — [первая программа](./7.md), [Flutter](./311.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Dart read file example — как прочитать txt?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `await File('path').readAsString()` или `readAsLines()` из `dart:io`. Подробнее здесь — [консоль и HTTP](./9.md), [простые приложения](./103.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> jsonEncode jsonDecode Dart — без пакетов?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Модуль <strong>`dart:convert`</strong> встроен; для моделей — `toJson`/`fromJson`. Пример — [простые приложения](./103.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Dart switch expression — синтаксис Dart 3?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `switch (x) { case 1 => 'a', _ => 'b' }` и pattern matching по records/sealed types. Подробнее здесь — [паттерны Dart 3](./8.md), [синтаксис](./12.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> StatelessWidget vs StatefulWidget Flutter разница?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Stateless — UI без изменяемого состояния; Stateful — есть `State` и `setState` при обновлении. Подробнее здесь — [Flutter](./311.md), [ООП](./10.md).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Сколько учить Dart перед Flutter?</p>

## Что запомнить

Dart — язык от Google со статической типизацией, null safety и встроенной асинхронностью. Dart VM поддерживает JIT (разработка) и AOT (релиз); изоляты (isolates) не делят память — обмен через сообщения.

Основные особенности Dart:

- **Null safety** — типы `T` и `T?`, операторы `?.`, `??`, `!`.
- **Async/await и Future/Stream** — основа I/O и Flutter.
- **Sound typing** — ошибки типов ловятся анализатором до запуска.
- **Dart 3** — records, patterns, exhaustive switch, sealed classes.
- **Две платформы** — VM/`dart:io` для консоли и серверов; web-кompиляция без `dart:io`.

Маршрут: [история](./1.md) → [runtime](./3.md) → [основы](./2.md) → [типы](./4.md) → [async](./6.md) → [первая программа](./7.md) → [ООП](./10.md) → [консоль и HTTP](./9.md) → [Flutter](./311.md).

Три практических правила:

1. Каждый I/O — с `await`; каждый `HttpClient` — с `close()` в `finally`.
2. Nullable обрабатывайте явно, без злоупотребления `!`.
3. Flutter UI меняется только через `setState` / state management.
