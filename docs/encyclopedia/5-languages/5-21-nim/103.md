### Как запускать примеры из главы

1. **Команда:** `nim c -r имя.nim` — компиляция и сразу запуск (аналог `python script.py`).
2. **Только проверка:** `nim check имя.nim` — быстрая диагностика без полной линковки.
3. **Версия:** `nim --version` — убедитесь, что установлен Nim 2.x (ORC по умолчанию).

## Генератор паролей

Утилита показывает три приёма Nim: модуль `random`, изменяемая строка `result` в `proc` и литерал `const` для алфавита.

---

### Как запустить

- **Файл:** `password.nim`
- **Команда:** `nim c -r password.nim`

```nim

import std/random, strutils

proc generatePassword(length = 16): string =
  const chars = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789"
  result = newString(length)
  for i in 0 ..< length:
    result[i] = chars[rand(chars.len)]

randomize()
echo generatePassword()
echo generatePassword(24)
```

**Разбор:**

- `length = 16` — параметр по умолчанию (см. [функции](./6.md)).
- `result` — встроенная переменная возврата; можно писать `return`, но для накопления строки `result` читается короче.
- `0 ..< length` — полуоткрытый диапазон (верхняя граница не входит), как в [управляющих конструкциях](./5.md).
- `randomize()` — инициализация генератора; без неё последовательность при каждом запуске будет одинаковой.

Для CLI с аргументами добавьте `import std/os` и `parseInt(paramStr(1))` — паттерн тот же, что в [первой программе](./7.md) с `readLine`.

## Сортировщик файла

Чтение текстового файла, нормализация строк и запись отсортированного списка — типичная задача для Nim без сторонних библиотек.

```nim

import std/[strutils, algorithm, os, sequtils]

proc sortFile(input, output: string) =
  let lines = readFile(input).splitLines().map(strip).filterIt(it.len > 0)
  writeFile(output, lines.sorted().join("\n") & "\n")

when isMainModule:
  if paramCount() < 2:
    echo "Использование: ", getAppFilename(), " input.txt output.txt"
    quit(1)
  sortFile(paramStr(1), paramStr(2))
  echo "Готово: ", paramStr(2)
```

**Разбор:**

- `readFile` / `writeFile` — весь файл в память; для гигабайтных логов нужна построчная обработка (`File`, `readLine`).
- `filterIt(it.len > 0)` — убирает пустые строки после `strip`.
- `sorted()` из `algorithm` — сортировка по умолчанию лексикографически; для чисел сначала `map(parseInt)`.
- `when isMainModule` — код запуска только при прямом вызове файла, а не при `import` модуля.

Общая идея работы с файлами на уровне ОС пересекается с материалами про [исполняемые файлы и архивы](/encyclopedia/1-basics/1-20-ispolnyaemye-fayly-i-arhivy/1) — там про форматы, здесь про поток строк.

## HTTP (httpclient)

Минимальный HTTP GET через `std/httpclient`. Перед продакшеном стоит прочитать [HTTP как основа веб-интеграций](/encyclopedia/2-system-network/2-09-osnovy-integratsionnogo-vzaimodeystviya/118) — статусы, заголовки, таймауты.



<ExternalCodeEmbed example="nim/nim-521-103-002" title="HTTP (httpclient)" minHeight={336} />



**Разбор:**

- `defer: client.close()` — освобождение сокета при выходе из `proc` (в том числе при исключении).
- `timeout` в миллисекундах — защита от "зависшего" сервера.
- Срез `body[0 ..< maxLen]` — подстрока без копирования всего ответа в лог.

Для POST и заголовков используйте `HttpClient.request` с `headers` и `body`; для HTTPS достаточно URL с `https://` при сборке с OpenSSL в toolchain.
