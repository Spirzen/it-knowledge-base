## Простые приложения на Scala

Scala на JVM сочетает функциональный стиль (`map`, `Option`, `for`-comprehension) с ООП. Для старта достаточно `scala-cli` или sbt: примеры ниже — консольные утилиты без Akka/Play.

Эта глава полезна после [первой программы](/encyclopedia/5-languages/5-18-scala/7) и [основ языка](/encyclopedia/5-languages/5-18-scala/2). Если хотите сначала закрепить типы и `match`, откройте [типы и паттерн-матчинг](/encyclopedia/5-languages/5-18-scala/4), а затем возвращайтесь к практическим мини-проектам ниже.

---

### Что именно вы соберете

- Генератор паролей для CLI-утилит и внутренних инструментов.
- Мини-сервис работы с файлами (чтение, сортировка, запись).
- Безопасный калькулятор с `Option` вместо аварийного падения.
- JSON-хранилище задач с сериализацией.
- Минимальный HTTP-эндпоинт на стандартной библиотеке JVM.

Каждый блок можно запускать отдельно. В результате вы получаете рабочие шаблоны для pet-проектов, техзаданий и внутренних автоматизаций команды.

---

### Как запускать примеры из главы

1. **scala-cli:** `scala-cli run файл.scala` (Scala 3).
2. **sbt:** проект с `scalaVersion` → `sbt run`.
3. **Нужно:** JDK 17+.

## Генератор паролей

### Как запустить

- **Файл:** `password.scala`
- **Команда:** `scala-cli run password.scala`
- **Результат:** пароль в stdout.

```scala

import scala.util.Random

def generatePassword(length: Int = 16): String = {
  val chars = ('a' to 'z') ++ ('A' to 'Z') ++ ('0' to '9') ++ "!@#$%^&*"
  Random.shuffle(chars).take(length).mkString
}

@main def run(): Unit = println(generatePassword())
```

---

### Как улучшить генератор до "практического"

В продакшен-утилите стоит добавить:

- минимальную длину (например, от 12 символов);
- флаги `--length`, `--no-symbols`;
- проверку, что в результате есть хотя бы один символ каждого требуемого класса;
- опциональный вывод в буфер обмена.

Для криптографической стойкости используйте `java.security.SecureRandom`, а не `scala.util.Random`.

## Сортировщик файла

### Как запустить

- **Файл:** `sort.scala`, `input.txt` рядом
- **Команда:** `scala-cli run sort.scala`

```scala

import scala.io.Source
import java.nio.file.{Files, Paths}
import scala.jdk.CollectionConverters.*

def sortFile(in: String, out: String): Unit = {
  val lines = Source.fromFile(in, "UTF-8").getLines().map(_.trim).filter(_.nonEmpty).toSeq.sorted
  Files.write(Paths.get(out), lines.asJava)
}
```

---

### Практические замечания по файлам

- Для больших файлов лучше обрабатывать потоками, а не загружать все строки в память.
- В `Source.fromFile` используйте `try/finally` или `Using` для гарантированного закрытия ресурса.
- При записи в файл удобно сначала писать во временный файл и затем атомарно переименовывать.

Эти приемы полезны для ETL-утилит, миграций и pre-processing перед [Spark](/encyclopedia/5-languages/5-18-scala/3).

## Калькулятор с `Option`

### Как запустить

- **Команда:** `scala-cli run` — вызовите `calc` из `main` в том же файле.

```scala
def calc(a: Double, b: Double, op: Char): Option[Double] = op match {
  case '+' => Some(a + b)
  case '-' => Some(a - b)
  case '*' => Some(a * b)
  case '/' if b != 0 => Some(a / b)
  case _ => None
}
```

---

### Когда брать `Option`, а когда `Either`

- `Option` подходит, когда важно только "есть результат / нет результата".
- `Either[String, A]` подходит, когда нужна причина ошибки.

Пример улучшения:

```scala
def calc2(a: Double, b: Double, op: Char): Either[String, Double] = op match {
  case '+' => Right(a + b)
  case '-' => Right(a - b)
  case '*' => Right(a * b)
  case '/' if b != 0 => Right(a / b)
  case '/' => Left("division by zero")
  case x => Left(s"unknown operation: $x")
}
```

## JSON-трекер (circe / uPickle — или java.nio + ручной JSON)

На JVM для учёба часто используют **uPickle**:

```scala
// build.sbt: libraryDependencies += "com.lihaoyi" %% "upickle" % "4.0.2"

import upickle.default.*

case class Task(id: Long, title: String, done: Boolean = false)

def load(path: os.Path): Seq[Task] =
  if (!os.exists(path)) Nil else read[Seq[Task]](os.read(path))

def save(path: os.Path, tasks: Seq[Task]): Unit =
  os.write(path, write(tasks, indent = 2))
```

## Минимальный HTTP (com.sun.net.httpserver)

```scala

import com.sun.net.httpserver.{HttpServer, HttpHandler, HttpExchange}
import java.net.InetSocketAddress

val server = HttpServer.create(new InetSocketAddress(8080), 0)
server.createContext("/", (ex: HttpExchange) => {
  val body = """{"ok":true}"""
  ex.getResponseHeaders.add("Content-Type", "application/json")
  ex.sendResponseHeaders(200, body.length)
  ex.getResponseBody.write(body.getBytes("UTF-8"))
  ex.close()
})
server.start()
```

---

### Что добавить после первого запуска HTTP

1. Разделить роутинг и бизнес-логику по функциям.
2. Добавить JSON-сериализацию ответа и стандартный формат ошибок.
3. Включить базовые метрики и логирование запроса/времени ответа.
4. Вынести конфигурацию порта в переменные окружения.

Параллельно полезно повторить базу по [HTTP и HTTPS](/encyclopedia/2-system-network/2-09-osnovy-integratsionnogo-vzaimodeystviya/118) и [архитектуре JVM-приложений на Scala](/encyclopedia/5-languages/5-18-scala/3).

## Характерный пример — `for`-comprehension

```scala
def safeDivide(a: Double, b: Double): Option[Double] =
  for {
    _ <- Option.when(b != 0)(())
    r <- Some(a / b)
  } yield r

println(safeDivide(10, 2))
println(safeDivide(10, 0))
```

Цепочка `Option` читается как последовательность шагов без вложенных `if`.
