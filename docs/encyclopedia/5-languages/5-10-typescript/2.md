## Мини-шпаргалка



<ExternalCodeEmbed example="typescript/typescript-510-2-001" title="Мини-шпаргалка" minHeight={552} />



Разбор:

- `interface User` — контракт объекта; `role` — literal union.
- `isString` — type predicate для narrowing.
- `Partial<Pick<…>>`, `Omit` — utility types ([Справочник — утилитарные типы](/encyclopedia/5-languages/5-01-javascript/301#7-утилитарные-типы)).
- `first<User>(…)` — generic с сохранением типа элемента.
