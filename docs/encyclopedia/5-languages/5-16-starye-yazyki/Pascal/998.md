## Итоги по Pascal

Pascal учит **дисциплине**: типы объявляют заранее, программа имеет предсказуемый скелет, подпрограммы разделяют ответственность. ISO Pascal — фундамент; **Free Pascal / Lazarus** и **Delphi** — промышленные ветви с модулями, классами и GUI.

**Итоги раздела:**

- Строгая типизация ловит ошибки на этапе компиляции.
- `program` / `uses` / `begin` / `end.` — каркас; диалект влияет на `uses` и строки.
- Процедуры и функции — основной инструмент декомпозиции; `var` — передача по ссылке.
- Object Pascal добавляет ООП; в учебном маршруте это продолжение после базы — см. [711](./711.md).

Pascal полезен не только «для школы»: FPC/Lazarus — живой кроссплатформенный стек; Delphi — legacy и RAD на Windows.
