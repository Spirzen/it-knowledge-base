## Итоги по Visual Basic

Visual Basic — семейство языков Microsoft: **VB.NET** на CLR, **VBA** в Office, **VB6** в legacy. Синтаксис похож (`Sub`, `Dim`, `If`), среда и типы — разные.

**Что запомнить:**

- Новые проекты на .NET — **VB.NET** + `Option Strict On`, `Try/Catch`, NuGet.
- Автоматизация Excel/Word — **VBA**, объектная модель приложения.
- VB6 — сопровождение EXE/COM, не цель для нового обучения.
- WinForms/WPF, LINQ, async — в [10](./10.md), [11](./11.md), [711](./711.md).

VB.NET в режиме сопровождения, но экосистема [.NET](/encyclopedia/5-languages/5-04-platforma-dotnet/intro) общая с C#.
