## Итоги по Visual Basic

Visual Basic — семейство языков Microsoft: **VB.NET** на CLR, **VBA** в Office, **VB6** в legacy. Синтаксис похож (`Sub`, `Dim`, `If`), среда и типы — разные.

**Что запомнить:**

- Новые проекты на .NET — **VB.NET** + `Option Strict On`, `Try/Catch`, NuGet.
- Автоматизация Excel/Word — **VBA**, объектная модель приложения.
- VB6 — сопровождение EXE/COM, не цель для нового обучения.
- WinForms/WPF, LINQ, async — в [Консоль, CLI, коллекции и файлы](./10.md), [Лямбды, LINQ, операторы и свои коллекции](./11.md), [Справочник по visual-basic](./711.md).

VB.NET в режиме сопровождения, но экосистема [.NET](/encyclopedia/5-languages/5-04-platforma-dotnet/intro) общая с C#.

## Что это даёт на практике

Если упростить до прикладного уровня, раздел помогает ответить на три рабочих вопроса:

1. **На чём писать новый код в Windows-среде?**  
   Обычно это VB.NET (или C# в той же платформе), с понятной структурой проекта и контролем типов.
2. **Как автоматизировать Excel/Office без отдельного сервера?**  
   Это зона VBA: код рядом с документом, быстрый запуск макросов и обработка таблиц.
3. **Что делать со старой системой на VB6?**  
   Не "ломать и переписывать всё", а постепенно модернизировать, оборачивая критические части через .NET/Interop.

## Мини-карта применения

| Сценарий | Что выбрать | Почему |
|----------|-------------|--------|
| Внутреннее desktop-приложение под Windows | VB.NET + WinForms | Быстрый старт, зрелая экосистема .NET |
| Автоматизация отчётов в Excel | VBA | Код в `.xlsm`, простой запуск пользователем |
| Поддержка старого EXE с COM | VB6 + аккуратная миграция | Дешевле и безопаснее, чем резкий rewrite |
| Учебный вход в .NET | VB.NET, затем сравнение с C# | Легче читать синтаксис, единая BCL |

## Типичные выводы после раздела

- Если нужен контроль качества кода, включайте `Option Strict On` и проверяйте преобразования типов.  
- Если код живёт в Office-документе, — — $3.  
- Если в проекте много перечислений и "магических значений", пора выносить модель в `Enum`, `Class`, `Structure` и покрывать сценарии тестами.  
- Если логика превращается в длинные `If`, переходите к `Select Case`, маленьким `Function` и слоям ответственности.
