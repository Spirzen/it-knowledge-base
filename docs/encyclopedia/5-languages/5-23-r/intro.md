# О разделе

Раздел про язык **R** для статистики, анализа данных и воспроизводимых отчётов. Материалы выстроены от истории и модели данных к практике: типы, управление потоком, функции, пакеты и первая программа.

## Как читать

| Глава | Тема |
|-------|------|
| [История](1.md) | S → R, CRAN, ggplot2, Shiny, tidyverse |
| [Основы](2.md) | Векторы, `data.frame`, пакеты, tidyverse, рабочий процесс |
| [Архитектура](3.md) | Интерпретатор, память, S3, CRAN, графика, параллелизм |
| [Типы и векторизация](4.md) | Атомарные типы, факторы, списки, `NA`, индексация |
| [Управление и операторы](5.md) | `if`, циклы, `&&`/`&`, `tryCatch()` |
| [Функции и пакеты](6.md) | `function`, `...`, замыкания, `library()` |
| [Первая программа](7.md) | Установка, Posit/RStudio, `Rscript` |

Рекомендуемый порядок для новичка: **7 → 4 → 5 → 6 → 2 → 3 → 1** (сначала запустить код, затем углубиться в теорию).
