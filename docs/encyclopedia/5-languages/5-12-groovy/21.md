## Spock — первая спецификация

**Spock** — фреймворк тестов на **Groovy**, который отлично подходит для **Java-проектов**: читаемые блоки `given` / `when` / `then`, встроенные моки, таблицы `where`.

Язык Groovy в продакшеSpock — в `src/test/groovy` рядом с Java-кодом.

База Groovy: [первая программа](./2.md) · теория: [справочник § Spock](./3.md) · Java-тесты: [JUnit 5](/encyclopedia/5-languages/5-03-java/291).

---

### Зачем Spock, если есть JUnit

| JUnit 5 | Spock |
|---------|-------|
| `@Test void should...()` | Имя спецификации = предложение |
| `@ParameterizedTest` | Блок `where:` внизу |
| Mockito отдельно | `Mock()` встроен |

---

### Что тестируем

Простой **Java**-калькулятор — Spock вызывает его как обычный класс:

```java
// src/main/java/com/example/Calc.java
package com.example;

public class Calc {
    public int add(int a, int b) { return a + b; }
    public int divide(int a, int b) {
        if (b == 0) throw new ArithmeticException("zero");
        return a / b;
    }
}
```

## Gradle (Groovy DSL)

В `build.gradle`:

```groovy
plugins {
    id 'java'
}

repositories {
    mavenCentral()
}

dependencies {
    testImplementation 'org.spockframework:spock-core:2.3-groovy-4.0'
    testImplementation 'org.apache.groovy:groovy:4.0.21'
}

test {
    useJUnitPlatform()
}
```

Папка тестов: `src/test/groovy` (зеркало пакета `com.example`).

## Первая спецификация

```groovy
package com.example

import spock.lang.Specification
import spock.lang.Unroll

class CalcSpec extends Specification {

    def calc = new Calc()

    def "сложение двух чисел"() {
        given:
        def a = 2
        def b = 3

        when:
        def result = calc.add(a, b)

        then:
        result == 5
    }

    @Unroll
    def "деление #a / #b = #expected"() {
        expect:
        calc.divide(a, b) == expected

        where:
        a | b | expected
        10| 2 | 5
        9 | 3 | 3
    }

    def "деление на ноль бросает исключение"() {
        when:
        calc.divide(1, 0)

        then:
        thrown(ArithmeticException)
    }
}
```

**Разбор блоков:**

- `given` — подготовка данных;
- `when` — действие;
- `then` — проверки (`==`, `thrown`);
- `expect` — когда when+then в одном шаге;
- `where` — таблица кейсов, `@Unroll` даёт отдельный тест на строку.

---

## Запуск

```bash
./gradlew test
```

В IDEA: правый клик на `CalcSpec` → Run.

Отчёт JUnit-совместимый — CI подхватит без отдельной настройки.

---

### Частые ошибки

| Симптом | Причина |
|---------|---------|
| Spec не находится | Тесты не в `src/test/groovy` |
| `No tests found` | Не `useJUnitPlatform()` |
| `==` для объектов | Для POJO нужен `equals` или `is()` matcher |
