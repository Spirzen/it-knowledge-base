## Первая программа на Fiber

### Где применяют Fiber

**Fiber** оптимизирован под **высокую пропускную способность**: внутри — **fasthttp**, а не стандартный `net/http`. API намеренно похож на **Express** ([Node.js](/encyclopedia/5-languages/5-01-javascript/262.md)): `app.Get`, `app.Group`, `c.JSON`.

Платите за скорость ограничениями: нельзя напрямую подключить middleware из экосистемы `net/http`, HTTP/2 часто решают reverse proxy. Для нового микросервиса без legacy — отличный выбор; для встраивания в старый `ServeMux` — [Echo](./2413.md) или [Gin](./2412.md).

Обзор: [19.md](./19.md).

## REST API «Заметки»

`main.go`:

```go
package main

import (
    "strconv"
    "sync"

    "github.com/gofiber/fiber/v2"
)

type Note struct {
    ID   int    `json:"id"`
    Text string `json:"text"`
}

type NoteCreate struct {
    Text string `json:"text"`
}

var (
    notes  []Note
    nextID = 1
    mu     sync.Mutex
)

func main() {
    app := fiber.New()

    app.Get("/health", func(c *fiber.Ctx) error {
        return c.JSON(fiber.Map{"status": "ok"})
    })

    api := app.Group("/api")
    api.Get("/notes", listNotes)
    api.Post("/notes", createNote)
    api.Delete("/notes/:id", deleteNote)

    app.Listen(":3000")
}

func listNotes(c *fiber.Ctx) error {
    mu.Lock()
    defer mu.Unlock()
    return c.JSON(notes)
}

func createNote(c *fiber.Ctx) error {
    var body NoteCreate
    if err := c.BodyParser(&body); err != nil {
        return c.Status(fiber.StatusBadRequest).JSON(fiber.Map{"error": err.Error()})
    }
    if body.Text == "" {
        return c.Status(fiber.StatusBadRequest).JSON(fiber.Map{"error": "text required"})
    }
    mu.Lock()
    note := Note{ID: nextID, Text: body.Text}
    nextID++
    notes = append(notes, note)
    mu.Unlock()
    return c.Status(fiber.StatusCreated).JSON(note)
}

func deleteNote(c *fiber.Ctx) error {
    id, err := strconv.Atoi(c.Params("id"))
    if err != nil {
        return c.Status(fiber.StatusBadRequest).JSON(fiber.Map{"error": "invalid id"})
    }
    mu.Lock()
    defer mu.Unlock()
    for i, n := range notes {
        if n.ID == id {
            notes = append(notes[:i], notes[i+1:]...)
            return c.SendStatus(fiber.StatusNoContent)
        }
    }
    return c.Status(fiber.StatusNotFound).JSON(fiber.Map{"error": "not found"})
}
```

```bash
go run .
```

Порт по умолчанию в примере: **3000** (типично для Fiber).

## Проверка

```bash
curl http://127.0.0.1:3000/health
curl -X POST http://127.0.0.1:3000/api/notes \
  -H "Content-Type: application/json" \
  -d '{"text":"Изучить Fiber"}'
```

---

### Разбор Fiber

- **`c *fiber.Ctx`** — контекст fasthttp; методы `JSON`, `Params`, `BodyParser` похожи на Express.
- **`fiber.Map`** — короткая запись `map[string]interface{}` для JSON-ответов.
- **Порт 3000** — `app.Listen(":3000")`; не путайте с Gin/Echo на 8080 в curl-примерах.

---

### Частые ошибки

| Симптом | Причина |
|---------|---------|
| Middleware из `net/http` не работает | Fiber не совместим с экосистемой stdlib без адаптера |
| `Cannot GET /api/notes` | Группа `app.Group("/api")` не применена к маршрутам |
| Тело POST пустое | Нужен `c.BodyParser(&body)` и заголовок `Content-Type: application/json` |
| Странные ошибки за nginx | HTTP/2 к Fiber часто терминируют на прокси — см. ниже |

---

## Важно помнить

- Нельзя вставить Fiber в существующий `http.ServeMux` без адаптера;
- HTTP/2 напрямую не поддерживается — часто ставят nginx/envoy перед сервисом;
- для библиотек, завязанных на `net/http`, предпочтите [Echo](./2413.md) или [Gin](./2412.md).
