# pyTelegramBot — боты в Telegram

<div class="article-tags">
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

<span class="complexity-badge">Разработчику</span>

**pyTelegramBotAPI** устанавливается как `pip install pytelegrambotapi`, в коде чаще пишут `import telebot`. Библиотека обращается к [Telegram Bot API](https://core.telegram.org/bots/api): бот — это программа на вашем сервере или компьютере, которая получает обновления (сообщения, нажатия кнопок) и отправляет ответы.

Если смотреть практично, Telegram-бот — это самый быстрый способ добавить интерфейс к скрипту или сервису без фронтенда. Частые сценарии: уведомления об ошибках, внутренние сервисные команды, мини-боты для поддержки и FAQ.

```bash
pip install pytelegrambotapi
```

Путеводитель: [Инструменты и среды](/encyclopedia/1-basics/1-035-bazovaya-informatika/9). HTTP в Python: [requests](./34.md).

---

## Подготовка

1. В Telegram откройте [@BotFather](https://t.me/BotFather).
2. Команда `/newbot` → имя и username (должен оканчиваться на `bot`).
3. Сохраните **токен** — это пароль бота. Не публикуйте его в репозитории.

```bash
pip install pytelegrambotapi
```

Токен лучше хранить в переменной окружения:

```bash
# Windows PowerShell
$env:BOT_TOKEN="123456:ABC..."

# Linux / macOS
export BOT_TOKEN="123456:ABC..."
```

## Минимальный бот

```python

import os
import telebot

bot = telebot.TeleBot(os.environ["BOT_TOKEN"])

@bot.message_handler(commands=["start", "help"])
def send_welcome(message):
    bot.reply_to(
        message,
        "Привет! Я учебный бот.\n"
        "Команды: /start, /help, /echo <текст>",
    )

@bot.message_handler(commands=["echo"])
def echo(message):
  # /echo привет → "привет"
    parts = message.text.split(maxsplit=1)
    if len(parts) < 2:
        bot.reply_to(message, "Напишите: /echo ваш текст")
        return
    bot.reply_to(message, parts[1])

@bot.message_handler(func=lambda m: True)
def fallback(message):
    bot.reply_to(message, "Не понял. Попробуйте /help")

if __name__ == "__main__":
    bot.infinity_polling()
```

Запуск: `python bot.py`. Напишите боту в Telegram после `/start`.

```bash
python bot.py
```

## Команды и обработчики

| Декоратор | Срабатывает когда |
|-----------|-------------------|
| `@bot.message_handler(commands=["ping"])` | Сообщение `/ping` |
| `@bot.message_handler(content_types=["photo"])` | Фото |
| `@bot.message_handler(func=lambda m: m.text and m.text.startswith("#"))` | Свой фильтр |

Объект `message` содержит `chat.id`, `from_user`, `text`, `document` и др. — см. [типы Bot API](https://core.telegram.org/bots/api#message).

## Клавиатура с кнопками

```python
from telebot import types

@bot.message_handler(commands=["menu"])
def menu(message):
    kb = types.ReplyKeyboardMarkup(resize_keyboard=True)
    kb.add("Расписание", "Справка")
    bot.send_message(message.chat.id, "Выберите пункт:", reply_markup=kb)

@bot.message_handler(func=lambda m: m.text == "Справка")
def help_btn(message):
    bot.send_message(message.chat.id, "Список команд: /start, /menu")
```

**Inline-кнопки** (под сообщением, не в поле ввода):

```python
markup = types.InlineKeyboardMarkup()
markup.add(types.InlineKeyboardButton("Сайт", url="https://example.com"))
bot.send_message(message.chat.id, "Ссылки:", reply_markup=markup)
```

## Long polling и webhook

Учебные боты обычно используют **`infinity_polling()`** — библиотека сама опрашивает серверы Telegram.

На продакшене часто ставят **webhook** (HTTPS-URL, куда Telegram шлёт POST). Для школы и домашних проектов polling достаточно.

Правило выбора:

- `polling` — проще старт, локальная разработка, демо и учебные проекты;
- `webhook` — стабильный продакшен, меньше лишних запросов, лучше контроль доставки.

## Безопасность и ограничения

- Токен = полный доступ к боту; при утечке — `/revoke` в BotFather и новый токен.
- Бот **не видит** все сообщения в группе, пока не включён режим Privacy или бот не добавлен как админ (зависит от настроек).
- Соблюдайте [правила Telegram](https://core.telegram.org/bots/faq) и не рассылайте спам.

Альтернативы: `python-telegram-bot`, `aiogram` (асинхронный стиль). **telebot** выбирают за простой синхронный API для первых проектов.

---

## Частые ошибки новичков

1. Токен хранится прямо в коде и случайно попадает в Git.
2. Нет обработки исключений сети, из-за чего бот "падает молча".
3. Слишком общий `fallback`-обработчик перекрывает полезные команды.
4. Логика бота и доступ к базе смешаны в одном файле без структуры.

Минимум, который стоит добавить сразу:

```python

import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)
```

И логировать ключевые шаги: запуск, входящие команды, ошибки отправки сообщений.

## Как масштабировать учебного бота

- Вынести команды по модулям (`handlers/start.py`, `handlers/admin.py`).
- Хранить состояние пользователя в Redis/БД, а не в памяти процесса.
- Добавить ограничение частоты команд (rate limit) для защиты от спама.
- Подключить мониторинг ошибок и оповещения (см. [веб и API в Python](./34.md)).
