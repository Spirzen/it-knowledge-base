## Первая программа на Tkinter

### Где применяют Tkinter

**Tkinter** входит в стандартную поставку CPython — отдельная установка не нужна. Это самый быстрый способ показать **окно с кнопками** на уроке или в утилите: установили Python — уже можно рисовать UI.

Мы сделаем "Конвертер °C → °F" и разберём **`mainloop()`** — без него окно исчезнет, как `app.exec()` в Qt.

Теория: [311.md](./311.md). **Элементы UI по рецептам:** [3112.md](./3112.md). **Галерея примеров:** [Tkinter — окна и виджеты](/lab/Примеры/1124). Богаче UI: [PyQt6](./3131.md). Общая теория десктопа: [Архитектура десктопных приложений](/encyclopedia/4-code-dev/4-11-desktopnye-prilozheniya/1) · [112.md](/encyclopedia/4-code-dev/4-11-desktopnye-prilozheniya/112.md).

### Что получится

Поле ввода, кнопки "Перевести" и "Выход", метка результата, Enter в поле вызывает расчёт.

## Минимальное окно

```python

import tkinter as tk

root = tk.Tk()
root.title("Привет, Tkinter")
root.geometry("320x120")

label = tk.Label(root, text="Окно работает")
label.pack(pady=20)

root.mainloop()
```

Разбор фрагмента:

- `tk.Tk()` создаёт главное окно приложения.
- `Label` добавляет статический текст, а `pack(pady=20)` размещает его с вертикальным отступом.
- `mainloop()` запускает цикл событий; без него окно не будет интерактивным и быстро закроется.

`mainloop()` запускает цикл обработки событий — без него окно сразу закроется.

## Конвертер температуры

```python

import tkinter as tk

from tkinter import messagebox


def convert():
    raw = entry.get().strip().replace(",", ".")
    try:
        celsius = float(raw)
    except ValueError:
        messagebox.showerror("Ошибка", "Введите число, например 25")
        return
    fahrenheit = celsius * 9 / 5 + 32
    result_var.set(f"{celsius:.1f} °C = {fahrenheit:.1f} °F")


root = tk.Tk()
root.title("Конвертер температуры")
root.resizable(False, False)

frame = tk.Frame(root, padx=16, pady=16)
frame.pack()

tk.Label(frame, text="Температура (°C):").grid(row=0, column=0, sticky="w")
entry = tk.Entry(frame, width=12)
entry.grid(row=0, column=1, padx=(8, 0))
entry.focus_set()

result_var = tk.StringVar(value="— ")
tk.Label(frame, textvariable=result_var).grid(row=1, column=0, columnspan=2, pady=(12, 0))

btn_row = tk.Frame(frame)
btn_row.grid(row=2, column=0, columnspan=2, pady=(12, 0))
tk.Button(btn_row, text="Перевести", command=convert).pack(side=tk.LEFT, padx=4)
tk.Button(btn_row, text="Выход", command=root.destroy).pack(side=tk.LEFT, padx=4)

entry.bind("<Return>", lambda _e: convert())

root.mainloop()
```

Разбор фрагмента:

- Функция `convert()` получает строку из `Entry`, приводит её к числу и считает перевод в Фаренгейты.
- `try/except ValueError` отлавливает нечисловой ввод и показывает `messagebox.showerror(...)`.
- `StringVar` (`result_var`) связан с меткой, поэтому результат появляется в интерфейсе сразу после `set(...)`.
- `command=convert` и `entry.bind("<Return>", ...)` дают два способа запуска одной логики: кнопкой и Enter.

---

### `pack` и `grid`

- **`pack`** — укладка "стопкой" или "в ряд" (простые формы).
- **`grid`** — таблица строк и столбцов (формы с выравниванием).

Не смешивайте `pack` и `grid` в одном родительском контейнере.

## Диалоги и меню

```python
from tkinter import filedialog

path = filedialog.askopenfilename(
    title="Выберите файл",
    filetypes=[("Текст", "*.txt"), ("Все", "*.*")],
)
```

Разбор фрагмента:

- `filedialog.askopenfilename(...)` открывает системный диалог выбора файла.
- `filetypes` задаёт фильтр расширений и помогает пользователю выбрать корректный тип документа.
- Результат записывается в `path`; если диалог закрыт через Cancel, вернётся пустая строка.

Меню:

```python
menubar = tk.Menu(root)
file_menu = tk.Menu(menubar, tearoff=0)
file_menu.add_command(label="Выход", command=root.destroy)
menubar.add_cascade(label="Файл", menu=file_menu)
root.config(menu=menubar)
```

Разбор фрагмента:

- `Menu(root)` создаёт верхнее меню окна.
- `file_menu.add_command(...)` добавляет команду в подменю.
- `add_cascade(...)` привязывает подменю к пункту `Файл`.
- `root.config(menu=menubar)` активирует меню в приложении.

### Частые ошибки

| Симптом | Причина |
|---------|---------|
| Окно "мигает" и закрывается | Нет `mainloop()` |
| `TclError: cannot use geometry manager grid inside ... pack` | Смешаны `pack` и `grid` |
| Интерфейс "зависает" при долгой операции | Тяжёлую работу выносите в `threading` или `after()` |
| `TclError: no display name` | Нет GUI (SSH без X11) — нужен X forwarding или другой хост |
