Пошаговые рецепты: **импорт → создать → разместить → обработчик**. Каркас приложения — в [Первая программа на Tkinter](./3111.md), теория — [311.md](./311.md). Общие названия элементов — [Архитектура десктопных приложений](/encyclopedia/4-code-dev/4-11-desktopnye-prilozheniya/1#элементы-управления-и-ввод-данных); UI-поток и потоки — [112.md](/encyclopedia/4-code-dev/4-11-desktopnye-prilozheniya/112.md).

## Как пользоваться

1. Создайте `root = tk.Tk()` и контейнер (`frame = tk.Frame(root)`), как в [3111.md](./3111.md).
2. Найдите нужный элемент ниже, скопируйте блок в свой `frame` (или `root`).
3. В конце файла оставьте `root.mainloop()`.

**Правило:** в одном родителе используйте один менеджер — только `pack`, только `grid` или только `place`.

---

## Главное окно

```python
import tkinter as tk

root = tk.Tk()
root.title("Моё приложение")
root.geometry("640x480")
root.minsize(400, 300)
root.mainloop()
```

| Действие | Код |
|----------|-----|
| Закрыть программу | `root.destroy()` |
| Обработчик крестика | `root.protocol("WM_DELETE_WINDOW", on_close)` |
| Отложенный вызов | `root.after(1000, func)` |

## Контейнер (Frame)

**Куда:** в `root` или во вложенный `Frame`.

```python
frame = tk.Frame(root, padx=12, pady=12)
frame.pack(fill=tk.BOTH, expand=True)

# Группа с рамкой и заголовком
group = tk.LabelFrame(frame, text="Параметры", padx=8, pady=8)
group.grid(row=0, column=0, sticky="ew")
```

---

## Label (метка)

**Куда:** в `frame`. **Импорт:** `tk.Label`.

```python
label = tk.Label(frame, text="Имя пользователя:")
label.grid(row=0, column=0, sticky="w", padx=4, pady=4)

# Динамический текст
status_var = tk.StringVar(value="Готово")
status = tk.Label(frame, textvariable=status_var)
status.pack()
status_var.set("Сохранено")
```

## TextBox — однострочный (Entry)

**Куда:** рядом с подписью в `frame`.

```python
entry = tk.Entry(frame, width=30)
entry.grid(row=0, column=1, padx=4, pady=4)
entry.focus_set()

text = entry.get().strip()
entry.delete(0, tk.END)
entry.insert(0, "значение по умолчанию")
```

**Enter в поле:**

```python
entry.bind("<Return>", lambda e: on_submit())
```

## Button (кнопка)

```python
def on_save():
    print("Сохранить")

btn = tk.Button(frame, text="Сохранить", command=on_save)
btn.grid(row=3, column=1, sticky="e", pady=8)
# command=on_save — без скобок!
```

Современный вид — `ttk`:

```python
from tkinter import ttk

btn = ttk.Button(frame, text="OK", command=on_save)
btn.pack(pady=4)
```

## ListBox (список)

```python
listbox = tk.Listbox(frame, height=6)
for item in ("Яблоко", "Груша", "Слива"):
    listbox.insert(tk.END, item)
listbox.pack(fill=tk.BOTH, expand=True)

listbox.bind("<<ListboxSelect>>", lambda e: print(listbox.get(listbox.curselection())))
```

## DataGrid (таблица) — Treeview

```python
from tkinter import ttk

cols = ("name", "age")
tree = ttk.Treeview(frame, columns=cols, show="headings", height=8)
tree.heading("name", text="Имя")
```

## ScrollPane (прокрутка)

```python
canvas = tk.Canvas(frame)
scrollbar = tk.Scrollbar(frame, orient=tk.VERTICAL, command=canvas.yview)
scroll_frame = tk.Frame(canvas)
scroll_frame.bind("<Configure>", lambda e: canvas.configure(scrollregion=canvas.bbox("all")))
canvas.create_window((0, 0), window=scroll_frame, anchor="nw")
canvas.configure(yscrollcommand=scrollbar.set)
canvas.pack(side=tk.LEFT, fill=tk.BOTH, expand=True)
scrollbar.pack(side=tk.RIGHT, fill=tk.Y)
# Виджеты добавляйте в scroll_frame
```

Для `Text`/`Listbox` часто достаточно `scrollbar.config(command=widget.yview)` и `widget.config(yscrollcommand=scrollbar.set)`.

## Tooltip (подсказка)

```python
def create_tooltip(widget, text):
    tip = {"win": None}

    def enter(_):
        x, y, _, h = widget.bbox("insert") or (0, 0, 0, 0)
        x += widget.winfo_rootx() + 20
        y += widget.winfo_rooty() + h + 4
        tip["win"] = tw = tk.Toplevel(widget)
        tw.wm_overrideredirect(True)
        tw.geometry(f"+{x}+{y}")
        tk.Label(tw, text=text, bg="#ffffe0", relief=tk.SOLID, borderwidth=1).pack()

    def leave(_):
        if tip["win"]:
            tip["win"].destroy()
            tip["win"] = None

    widget.bind("<Enter>", enter)
    widget.bind("<Leave>", leave)

create_tooltip(btn, "Сохранить документ на диск")
```

## Context menu (контекстное меню)

```python
menu = tk.Menu(root, tearoff=0)
menu.add_command(label="Копировать", command=copy)

    menu.tk_popup(event.x_root, event.y_root)
```

```python
widget.pack(side=tk.TOP, fill=tk.X, expand=True, padx=5, pady=5)
widget.grid(row=0, column=1, sticky="ew", padx=4, pady=4)
frame.grid_columnconfigure(1, weight=1)
widget.place(x=10, y=20, width=200)
```

## Частые ошибки

| Симптом | Причина |
|---------|---------|
| Виджет не виден | Нет `pack`/`grid`/`place` |
| `TclError` geometry manager | Смешали `pack` и `grid` в одном родителе |
| Кнопка срабатывает при старте | `command=func()` вместо `command=func` |
| Картинка пропала | Нет ссылки на `PhotoImage` на `self` |
