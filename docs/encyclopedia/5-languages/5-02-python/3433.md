## Модели SQLAlchemy и Pydantic

Разделяют **модель таблицы** (БД) и **схему API** (JSON):

```python
from datetime import datetime
from sqlalchemy import String, DateTime, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

class Base(DeclarativeBase):
    pass

class UserRow(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    username: Mapped[str] = mapped_column(String(64), unique=True)
    email: Mapped[str] = mapped_column(String(255))
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now()
    )
```

```python
from pydantic import BaseModel, Field

class UserCreate(BaseModel):
    username: str
    email: str = Field(..., pattern=r"^[^@]+@[^@]+\.[^@]+$")

class UserRead(BaseModel):
    id: int
    username: str
    email: str

    model_config = {"from_attributes": True}
```

`from_attributes=True` позволяет собрать ответ из ORM-объекта (`UserRead.model_validate(row)`).

## Подключение и сессия

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, Session

DATABASE_URL = "sqlite:///./app.db"
engine = create_engine(DATABASE_URL, connect_args={"check_same_thread": False})
SessionLocal = sessionmaker(bind=engine, autoflush=False, autocommit=False)

def init_db():
    Base.metadata.create_all(bind=engine)
```

В FastAPI сессию отдают через **зависимость** — одна сессия на запрос, закрытие в `finally`:

```python
from fastapi import Depends

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

## CRUD-эндпоинты

```python
from fastapi import FastAPI, HTTPException, Depends

app = FastAPI()

@app.on_event("startup")
def on_startup():
    init_db()

@app.post("/users", response_model=UserRead, status_code=201)
def create_user(body: UserCreate, db: Session = Depends(get_db)):
    if db.query(UserRow).filter_by(username=body.username).first():
        raise HTTPException(status_code=409, detail="username занят")
    row = UserRow(username=body.username, email=body.email)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row

@app.get("/users/{user_id}", response_model=UserRead)
def get_user(user_id: int, db: Session = Depends(get_db)):
    row = db.get(UserRow, user_id)
    if row is None:
        raise HTTPException(status_code=404, detail="не найден")
    return row
```

Паттерн: **один commit на успешную бизнес-операцию**; при ошибке — `rollback` (можно обернуть в middleware или контекст).

## Асинхронный вариант

FastAPI нативно async; для PostgreSQL используют **`asyncpg`** + `create_async_engine` и `AsyncSession`. Синхронный SQLAlchemy в `async def` без `run_in_executor` **блокирует** event loop — для высокой нагрузки переходят на async stack или отдельный worker pool.

См. [асинхронность](./29.md) и [базы данных](./314.md) (раздел про `asyncpg`).

## Миграции Alembic

`create_all` удобен для прототипа, но не версионирует изменения схемы. **Alembic** хранит ревизии:

```bash
alembic init alembic
# настроить sqlalchemy.url в alembic.ini
alembic revision --autogenerate -m "create users"
alembic upgrade head
```

В CI/CD `upgrade head` выполняют перед выкладкой новой версии API.

## Типичные ошибки

| Ошибка | Последствие |
|--------|-------------|
| Сессия на всё приложение | Гонки, утечки соединений |
| N+1 запросов | Сотни SQL на один HTTP-вызов — нужен `joinedload` |
| Секреты в репозитории | Утечка `DATABASE_URL` — переменные окружения |
| Нет индексов на ключи поиска | Медленные `filter_by` на больших таблицах |
