## Обмен, строки, числа

<span id="obmen-peremennyh"></span>

### Обмен двух переменных

```python
a, b = b, a
```

Справа создаётся **кортеж** `(b, a)`, слева значения **распаковываются** в имена. Временная переменная `tmp` не нужна. Подробнее про кортежи и `return a, b` — в [Функции в Python](./24.md#кортеж).

---

<span id="razvorot-stroki-i-palindrom"></span>

### Разворот строки

```python
s[::-1]
```

Срез `[start:stop:step]` с `step = -1` идёт от конца к началу. Строки в Python **неизменяемы** — получается новая строка, исходная `s` не меняется. Другие способы (`reversed`, цикл) длиннее; срез — идиома. См. [строки в типах данных](./19.md#строка).

---

<span id="razvorot-spiska-oneliner"></span>

### Разворот списка

```python
my_list[::-1]       # новый list, исходный не меняется
my_list.reverse()   # на месте, возвращает None
```

Срез с шагом `-1` — та же идиома, что и для строк. На месте — только метод `reverse()`. Ещё три варианта (`reversed()`, циклы) и таблица выбора — в [коллекции — списки](./22.md#razvorot-spiska).

---

### Проверка палиндрома

```python
s == s[::-1]
```

Сравнение строки с её разворотом. Для учебных задач достаточно; в проде часто нормализуют регистр и убирают пробелы:

```python
t = "".join(ch.lower() for ch in s if ch.isalnum())
is_palindrome = t == t[::-1]
```

---

### Факториал через `math.prod`

```python
import math

math.prod(range(1, n + 1))   # n >= 0; для n == 0 произведение пустого range — 1
```

`range(1, n + 1)` даёт множители `1, 2, …, n`. Модуль [`math`](https://docs.python.org/3/library/math.html) появился в стандартной библиотеке давно; `prod` — с **Python 3.8**. Для `n < 0` факториал не определён — проверяйте вход отдельно. Альтернатива — [`functools.reduce`](./24.md#lambda-map-filter-reduce) или цикл, если зависимость от `math` нежелательна.

## Списки и словари

### Выравнивание вложенного списка (flatten)

```python
[i for sub in lst for i in sub]
```

**Вложенное** [списковое включение](./19.md): внешний цикл по `sub`, внутренний — по элементам. Работает для списка списков **одного уровня**. Для произвольной глубины — `itertools.chain.from_iterable` или рекурсия. В Python 3.12+ у `list` есть метод `sum(lst, [])`, но он медленный на больших данных — включение предпочтительнее.

---

### Чётные числа из диапазона

```python
[x for x in range(10) if x % 2 == 0]
```

Шаблон **включения с условием**: `0, 2, 4, 6, 8`. Тот же смысл — `filter(lambda x: x % 2 == 0, range(10))`, но включение читается привычнее в Python. Подробнее про `lambda`, `map` и `filter` — [анонимные функции](./24.md#lambda-map-filter-reduce); см. также [циклы и итерации](./22.md).

---

### Слияние двух словарей

```python
{**d1, **d2}
```

Распаковка обоих словарей в литерал: ключи из `d2` **перекрывают** совпадающие ключи из `d1` (порядок вставки в Python 3.7+ предсказуем). Для **изменения на месте** — `d1.update(d2)` или с Python 3.9 — `d1 | d2`. Подробнее про `dict` — [типы данных](./19.md).

---

### Подсчёт частот элементов

```python
from collections import Counter

Counter(lst)
```

`Counter` ведёт себя как словарь «элемент → количество». Для строки `Counter("hello")` считает буквы. См. [модуль `collections`](https://docs.python.org/3/library/collections.html#collections.Counter).

---

### Уникальные элементы

```python
set(lst)
```

`set` убирает дубликаты; **порядок** в старых версиях не гарантировался, в CPython 3.7+ порядок вставки сохраняется для `set`, но для стабильного порядка уникальных значений используйте `dict.fromkeys(lst)` или `sorted(set(lst))`.

---

### Список строк в одну строку

```python
" ".join(lst)
```

`join` вызывают у **разделителя** (строки), аргумент — итерируемый из строк. Элементы должны быть типа `str`; иначе — `str(x)` в генераторе: `" ".join(str(x) for x in lst)`. Обратная операция — `s.split()`.

---

<span id="walrus-oneliner"></span>

### Walrus в условии

```python
if (n := len(data)) > 10:
    print(f"{n} items")
```

Оператор **`:=`** (Python 3.8+) присваивает значение переменной внутри выражения и возвращает его — удобно, когда результат нужен и в условии, и в теле блока. Тот же приём работает в `while (line := input()) != "quit"`. Подробнее — [оператор walrus](./21.md#op-walrus) и [управляющие конструкции](./23.md#walrus-v-usloviyah).

## Когда не увлекаться

<div class="callout callout--caution">
  <div class="callout-title">Production и командный код</div>

  <div class="callout-body">
  Однострочник уместен в REPL, тесте или коротком скрипте.

  В модуле, который сопровождает команда, длинное включение или цепочка вызовов лучше разбить на именованные шаги — так проще отлаживать и покрывать тестами.

  См. [рефакторинг](/encyclopedia/4-code-dev/4-02-chto-takoe-kod-i-kak-on-rabotaet/612) и [pytest](./37).
</div>
</div>

ИИ-ассистенты часто предлагают «умные» однострочники; перед вставкой в проект проверьте граничные случаи (`n = 0`, пустой `lst`, `None` в списке для `join`) и [PEP 8](https://peps.python.org/pep-0008/) — длина строки и читаемость.
