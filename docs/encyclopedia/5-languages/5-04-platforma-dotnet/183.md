# Справочник .NET API

<div class="article-tags"><span class="tag tag-reference">СПРАВОЧНИК</span></div>

## Назначение

Единая точка входа в **официальную документацию API** платформы .NET на русскоязычном Microsoft Learn. Навигатор покрывает базовую библиотеку классов (BCL) для современного **.NET 10** и для сопровождения приложений на **.NET Framework 4.8 / 4.8.1**. См. также раздел C#: [Справочник .NET API (BCL)](../5-05-csharp/473.md).

Учебный курс: [раздел Платформа .NET](./intro). Концепции: [архитектура](./12.md), [типы приложений](./13.md), [NuGet](./17.md).

## Краткое пояснение

Поиск пространства имён и переход на страницу API с корректным параметром `view=` для выбранной целевой платформы.

## Когда какую платформу выбирать

| Сценарий | Рекомендуемый `view` |
|----------|----------------------|
| Новые сервисы, консоль, worker, ASP.NET Core | `net-10.0` |
| Legacy на IIS / .NET Framework 4.8 | `netframework-4.8` |
| Обновление 4.8 → 4.8.1 без смены стека | `netframework-4.8.1` |
