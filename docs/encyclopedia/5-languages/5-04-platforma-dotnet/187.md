## Зачем этот материал

F# позиционируется как функциональный язык, но **не запрещает** циклы, изменяемые переменные и побочные эффекты. Разработчик с опытом C# или Java часто ищет привычные `while` и `for`. Задача статьи — показать синтаксис, **точку входа** приложения и критерии: когда императивный код оправдан, а когда лучше `Seq`, рекурсия или агенты.

В [Первой программе на F#](./182.md) меню построено через рекурсию — это осознанный приём. Здесь — альтернативы и мост к стилю .NET.

---

## Изменяемые значения

По умолчанию `let` создаёт неизменяемую привязку. Для обновления:

```fsharp
let mutable counter = 0
counter <- counter + 1
```

Оператор `<-` только для `mutable`. Частое изменение одного поля в доменной логике часто переписывают на:

- новую копию записи `{ r with Count = r.Count + 1 }`;
- `MailboxProcessor` для сериализованного состояния (см. [Асинхронность: task, async и агенты](./189.md));
- свёртку `List.fold` / итератор `Seq`.

`mutable` уместен в тонком слое UI, прототипе, обёртке над изменяемым API .NET (`StringBuilder`, потоки).

## Циклы

### `while`

```fsharp
let rec readUntilEmpty () =
    let mutable lines = []
    let mutable line = System.Console.ReadLine()
    while not (System.String.IsNullOrEmpty line) do
        lines <- line :: lines
        line <- System.Console.ReadLine()
    List.rev lines
```

`while` возвращает `unit`, не значение коллекции — результат собирают вручную.

### `for .. to` и `for .. downto`

```fsharp
for i = 1 to 5 do
    printfn "%d" i
```

Индексный цикл по диапазону целых — читаемо для портирования алгоритмов с фиксированными границами.

### `for .. in`

```fsharp
let xs = [1; 2; 3]
for x in xs do
    printfn "%d" x
```

Эквивалент по смыслу — `List.iter` или `Seq.iter` без побочных эффектов в цепочке преобразований:

```fsharp
xs |> List.iter (fun x -> printfn "%d" x)
```

| Задача | Предпочтительно |
|--------|------------------|
| Преобразовать все элементы | `List.map` / `Array.map` |
| Отфильтровать | `List.filter` / `Seq.filter` |
| Накопить результат | `List.fold` / `Seq.fold` |
| Побочный эффект на каждый элемент | `iter` или `for .. in` |
| Неизвестное число итераций до условия | `while` или рекурсия с аккумулятором |

## Вложенные функции и область видимости

`let` внутри `let` ограничивает имя вложенной областью:

```fsharp
let outer x =
    let double y = y * 2
    let inner z = double z + x
    inner 10
```

Вложенная функция видит параметры внешней (`x`), но не наоборот. Это замена локальным «приватным» helper-методам без отдельного модуля.

`and` связывает взаимно рекурсивные функции:

```fsharp
let rec even n = if n = 0 then true else odd (n - 1)
and odd n = if n = 0 then false else even (n - 1)
```

Повторное `let` с тем же именем во внешней области **не перезаписывает** глобальное значение в модуле — создаётся новая привязка в текущей области (важно в FSI и во вложенных блоках).

## Точка входа

Консольное приложение .NET ожидает метод входа. В F#:

```fsharp
[<EntryPoint>]
let main argv =
    printfn "Args: %A" argv
    0
```

- `argv` — аргументы командной строки как `string array`;
- возвращаемый `int` — код завершения процесса (0 — успех).

В шаблоне SDK иногда используют **top-level** код в `Program.fs` без явного `main` — компилятор генерирует точку входа сам. Для библиотек атрибут `EntryPoint` не ставят.

Несколько функций с `[<EntryPoint>]` в одной сборке — ошибка компиляции.

## Композиция функций `>>` и `<<`

Операторы соединяют функции без промежуточных имён:

```fsharp
let trim s = s.Trim()
let upper s = s.ToUpper()

let normalize = trim >> upper
// normalize "  hi  "  ===  "HI"

let pipeline x = x |> trim |> upper   // тот же смысл с |>
```

- `f >> g` — сначала `f`, затем `g` (как «слева направо»);
- `g << f` — порядок аргументов обратный.

Удобно для цепочек валидации без вычислительного выражения.

## Практическая рекомендация

1. **Домен и бизнес-правила** — чистые функции, `match`, `Result`.
2. **Обход коллекций** — `map` / `filter` / `fold`, не ручной индекс без нужды.
3. **Ввод-вывод и .NET** — `async` / `task`, `use` для ресурсов.
4. **Циклы и mutable** — граница с «внешним миром» или порт legacy-кода.
