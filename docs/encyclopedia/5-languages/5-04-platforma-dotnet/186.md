## Роль `match` в F#

Конструкция `match ... with` — основной способ ветвления и разбора данных в F#. В отличие от цепочки `if`, `match` **декомпозирует** значение: извлекает поля записи, вариант объединения, голову списка. Компилятор проверяет **исчерпывающность** — все допустимые случаи должны быть обработаны (для размеченных объединений и многих других типов).

Теория типов и доменная модель — в [F# в экосистеме .NET](./18.md). Здесь — типовые приёмы на практике.

**Предварительно:** [Интерактивная работа с F#](./185.md) (удобно отрабатывать примеры в FSI).

## Литералы и простые условия

```fsharp
let sign n =
    match n with
    | 0 -> "zero"
    | n when n > 0 -> "positive"
    | _ -> "negative"
```

- Отдельная ветка для конкретного значения (`0`).
- `when` добавляет предикат к шаблону.
- `_` — всё остальное (часто последняя ветка).

`if` подходит для одного булева условия; `match` — когда вариантов несколько и они связаны со **структурой** данных.

## Списки

Список F# — односвязная цепочка. Главный шаблон:

```fsharp
let rec sumList xs =
    match xs with
    | [] -> 0
    | head :: tail -> head + sumList tail
```

| Шаблон | Значение |
|--------|----------|
| `[]` | пустой список |
| `h :: t` | первый элемент и «хвост» |
| `[a; b]` | ровно два элемента (фиксированная длина) |
| `_ :: _ :: _` | минимум два элемента, остальное не важно |

Обход без рекурсии в учебных примерах часто заменяют `List.fold`, но `match` остаётся читаемым при нестандартной логике (например, пропуск каждого второго элемента).

## Записи и кортежи

```fsharp
type Order = { Id: int; Amount: decimal; Paid: bool }

let describe { Id = id; Paid = paid } =
    if paid then $"Order {id} closed" else $"Order {id} pending"
```

Кортеж:

```fsharp
let swap (a, b) = (b, a)

let formatPoint (x, y) =
    match (x, y) with
    | (0, 0) -> "origin"
    | (0, _) -> "on Y axis"
    | (_, 0) -> "on X axis"
    | _ -> "elsewhere"
```

Имена полей в шаблоне записи можно указывать выборочно — остальные игнорируются.

## Размеченные объединения

```fsharp
type Shape =
    | Circle of radius: float
    | Rectangle of width: float * height: float

let area shape =
    match shape with
    | Circle r -> System.Math.PI * r * r
    | Rectangle (w, h) -> w * h
```

Добавление нового варианта (`Triangle`) без новой ветви в `area` даст **предупреждение** компилятора — это защита от забытых случаев. В императивных языках аналог — `switch` по enum, но без такой проверки на этапе компиляции.

## `Option` и `Result`

`Option` моделирует «значение есть / нет»:

```fsharp
let parsePositive (s: string) =
    match System.Int32.TryParse s with
    | true, n when n > 0 -> Some n
    | _ -> None

let printIfSome opt =
    match opt with
    | Some v -> printfn "%d" v
    | None -> printfn "no value"
```

`Result` — успех или ошибка с типизированной причиной:

```fsharp
type AppError = | NotFound | InvalidInput

let load id =
    if id <= 0 then Error InvalidInput
    else Ok $"item-{id}"

let handle result =
    match result with
    | Ok data -> printfn "ok: %s" data
    | Error NotFound -> printfn "missing"
    | Error InvalidInput -> printfn "bad id"
```

Цепочки из нескольких шагов часто пишут через `Result.bind` или вычислительные выражения (см. [Справочник по F#](./181.md)), но `match` остаётся базой для чтения и отладки.

## Массивы

```fsharp
let firstOrZero (arr: int[]) =
    match arr.Length with
    | 0 -> 0
    | _ -> arr.[0]
```

Для срезов и диапазонов индексов удобны `Array`/`Seq`, но `match` по длине или по паре `(индекс, элемент)` встречается в низкоуровневой логике.

## Частые ошибки

| Ошибка | Как избежать |
|--------|----------------|
| Неполный `match` по DU | Добавить все варианты или осознанный wildcard с комментарием |
| Лишний wildcard раньше специфичных веток | Специфичные шаблоны — **выше** общих |
| `null` вместо `None` | В чистом F# использовать `Option`; `null` — в основном interop с .NET |
| Дублирование логики в каждой ветке | Вынести общее в `let` до `match` или вспомогательную функцию |

---

## Когда переходить к активным шаблонам

Если шаблон сложный (парсинг строки, проверка диапазона), его выносят в **активный шаблон** `(|...|)` — см. раздел в [Справочник по F#](./181.md). На старте достаточно обычного `match`; активные шаблоны — для повторяющейся декомпозиции.
