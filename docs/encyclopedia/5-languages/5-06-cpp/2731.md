## Qt Widgets — первое окно на C++

Если вы знакомы с C++, но ещё **не собирали GUI**, здесь — короткий путь к рабочему результату.

| Термин | Простыми словами |
|--------|------------------|
| **Qt** | библиотека для интерфейса, сети, файлов, многопоточности |
| **Qt Widgets** | классические кнопки и окна (как в офисных программах) |
| **Виджет** | прямоугольный элемент UI: кнопка, надпись, поле ввода |
| **Сигнал / слот** | "событие произошло" → "выполнить реакцию" |
| **moc** | Meta-Object Compiler — генерирует код для сигналов (включается `CMAKE_AUTOMOC`) |

**Qt Widgets** удобен для учебного старта: мало "магии", видна иерархия объектов. **Qt Quick (QML)** — отдельная статья [2732](./2732.md).

## Что получится в конце

Окно с надписью и кнопкой. По нажатию текст меняется — **без** цикла `while (кнопка нажата?)`. Связь делает **`connect`**.

```
┌─────────────────────────────┐
│  Qt Hello                   │
│                             │
│   Нажмите кнопку            │
│   ┌─────────┐               │
│   │  Click  │               │
│   └─────────┘               │
└─────────────────────────────┘
```

## Установка Qt 6

Нужны: компилятор **C++17**, **CMake 3.20+**, **Qt 6** с модулем **Qt Widgets**.

| Способ | Когда удобно |
|--------|----------------|
| [qt.io/download](https://www.qt.io/download) | Windows/macOS, выбор MSVC/MinGW |
| Пакеты ОС (`qt6-base-dev` и аналоги) | Linux, CI |
| Qt Creator | путь к Qt подставляется в `CMAKE_PREFIX_PATH` |

Запомните каталог kit, например `C:/Qt/6.7.0/msvc2019_64` — его передают в CMake как **`CMAKE_PREFIX_PATH`**.

<div class="callout callout--tip">
  <div class="callout-title">Проверка</div>
  В kit есть `bin/qmake` (или `bin/qt-cmake`) и `lib/cmake/Qt6`. Ошибка `Could not find Qt6` почти всегда означает неверный `CMAKE_PREFIX_PATH`.
</div>

## Структура проекта

```
qt-hello/
├── CMakeLists.txt
└── main.cpp
```

| Файл | Роль |
|------|------|
| `CMakeLists.txt` | цель `qt_hello`, Qt6::Widgets, AUTOMOC |
| `main.cpp` | окно, виджеты, `connect` |

В больших проектах логику выносят в `MainWindow`, формы — в `.ui`. Для первого шага достаточно одного `main.cpp`.

---

## CMakeLists.txt — построчно

```cmake
cmake_minimum_required(VERSION 3.20)
project(qt_hello LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_AUTOMOC ON)
set(CMAKE_AUTORCC ON)
set(CMAKE_AUTOUIC ON)

find_package(Qt6 REQUIRED COMPONENTS Widgets)

add_executable(qt_hello main.cpp)
target_link_libraries(qt_hello PRIVATE Qt6::Widgets)
```

| Строка | Зачем |
|--------|--------|
| `CMAKE_AUTOMOC ON` | запуск **moc** для классов с `Q_OBJECT` |
| `AUTORCC` / `AUTOUIC` | ресурсы и формы Designer (пока не используем, привычка полезна) |
| `find_package(Qt6 ... Widgets)` | только модуль виджетов, не весь Qt |
| `Qt6::Widgets` | линковка с библиотекой виджетов |

Конфигурация (подставьте свой путь):

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.7.0/msvc2019_64"
cmake --build build
./build/qt_hello    # или build\qt_hello.exe на Windows
```

## Событийный цикл — зачем `QApplication`

Консольная программа завершается на `return` из `main`. GUI должно **ждать** клики и клавиши.

| Шаг | Код | Смысл |
|-----|-----|--------|
| 1 | `QApplication app(argc, argv);` | одно приложение на процесс |
| 2 | создать окно и виджеты | дерево объектов |
| 3 | `window.show();` | сделать окно видимым |
| 4 | `return app.exec();` | цикл событий до выхода |

Без `exec()` окно может **мелькнуть и исчезнуть** — частая ошибка новичка.

## main.cpp — полный код и разбор

```cpp
#include <QApplication>
#include <QPushButton>
#include <QVBoxLayout>
#include <QWidget>
#include <QLabel>

int main(int argc, char* argv[]) {
    QApplication app(argc, argv);

    QWidget window;
    window.setWindowTitle("Qt Hello");

    auto* label = new QLabel("Нажмите кнопку", &window);
    auto* button = new QPushButton("Click", &window);

    QObject::connect(button, &QPushButton::clicked, [label]() {
        label->setText("Привет из Qt!");
    });

    auto* layout = new QVBoxLayout(&window);
    layout->addWidget(label);
    layout->addWidget(button);

    window.resize(320, 120);
    window.show();

    return app.exec();
}
```

---

### Шаг 1. `QApplication`

`argc` / `argv` — Qt может обрабатывать флаги вроде `-style` на некоторых платформах.

---

### Шаг 2. Окно-контейнер

`QWidget window` — верхнеуровневое окно. `setWindowTitle` — заголовок в рамке ОС.

---

### Шаг 3. Родитель и владение

```cpp
auto* label = new QLabel("...", &window);
```

Второй аргумент — **родитель** `&window`. При уничтожении родителя Qt **удаляет детей**. В простых примерах часто пишут `new` без `delete` — это **дерево владения Qt**. В больших проектах владение всё равно проектируют явно ([27](./27.md)).

---

### Шаг 4. `connect` — разбор по частям

```cpp
QObject::connect(button, &QPushButton::clicked, [label]() {
    label->setText("Привет из Qt!");
});
```

| Часть | Смысл |
|-------|--------|
| `button` | отправитель |
| `&QPushButton::clicked` | сигнал "нажали и отпустили" |
| `[label]() { ... }` | слот-лямбда: захватывает указатель на label |
| `setText` | обновление UI |

Кнопка **излучает сигнал**; она **не знает** про `QLabel` напрямую — связь задана снаружи.

---

### Шаг 5. Layout

`QVBoxLayout` выстраивает виджеты **столбиком** и пересчитывает геометрию при `resize`.

## Сигналы и слоты — чуть глубже

- **Один сигнал** → **несколько слотов** возможно.
- **Один слот** ← **несколько сигналов** возможно (осторожно с побочными эффектами).

Для прототипа удобны **лямбды**. В рабочем коде чаще метод класса:

```cpp
class MainWindow : public QWidget {
    Q_OBJECT
public:
    explicit MainWindow(QWidget* parent = nullptr);
private slots:
    void onClicked();
private:
    QLabel* label_;
};
```

`connect(button, &QPushButton::clicked, this, &MainWindow::onClicked);`

Класс с `Q_OBJECT` **обязан** проходить через moc → `CMAKE_AUTOMOC ON`.

## Частые ошибки

| Симптом | Вероятная причина |
|---------|-------------------|
| Окно не появляется | нет `show()` или выход из `main` без `exec()` |
| `Could not find Qt6` | неверный `CMAKE_PREFIX_PATH` |
| moc / vtable | нет `AUTOMOC` или забыт `Q_OBJECT` |
| Клик молчит | опечатка в `connect`, другой объект в лямбде |
| Текст обрезан | нет layout или маленький `resize` |
