:::

## Уровень 1 — язык и память

### 1.1. Каталог файлов

**Цель:** обход каталога, фильтр по расширению `.cpp`.

- `std::filesystem` (C++17)
- вывод относительных путей и размера файла
- обработка ошибок доступа без падения

**Проверка:** запуск на каталоге с вложенными папками; пустой каталог — корректное сообщение.

### 1.2. RAII-лог

**Цель:** класс `LogScope`, пишущий в файл при создании строку «enter» и при уничтожении «leave».

- запрет копирования
- в `main` — вложенные блоки и `throw` между ними: «leave» всё равно появляется для уже созданных scope

**Материал:** [30](./30.md), [19](./19.md).

### 1.3. Rule of Five в мини-строке

**Цель:** класс `SmallString` с буфером в куче: конструктор, копирование, перемещение, деструктор, `operator=`.

**Проверка:** под санитайзером Address/UB — нет утечек при цепочке присваиваний и `push_back` в `vector<SmallString>`.

## Уровень 2 — STL и C++20

### 2.1. Частотный словарь

**Цель:** прочитать текстовый файл, посчитать слова (`std::map` или `unordered_map`), вывести топ-10.

- нормализация: нижний регистр, отброс пунктуации
- `std::algorithm` + при желании **ranges** ([31](./31.md))

### 2.2. Конвейер ranges

**Цель:** из `vector<int>` получить сумму квадратов чётных чисел одной ленивой цепочкой `filter` → `transform` → алгоритм свёртки.

**Проверка:** результат совпадает с эквивалентным обычным циклом на тестовых данных.

### 2.3. optional и ошибки

**Цель:** функция `parse_int(string_view) -> optional<int>` без исключений; CLI читает числа из argv и печатает «invalid» для неудачных.

### 4.1. Widgets

**Цель:** окно со списком задач: поле ввода, кнопка «добавить», `QListWidget`.

**Проверка:** повторный запуск не обязан хранить данные (достаточно сессии в памяти).

**Материал:** [2731](./2731.md).
