## Установка

При установке Qt 6 выберите компонент **Qt Quick / Qt Declarative**. Путь к Qt передаётся в CMake через `CMAKE_PREFIX_PATH`, как в [2731](./2731.md).

## CMakeLists.txt

```cmake
cmake_minimum_required(VERSION 3.20)
project(qt_quick_hello LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_AUTOMOC ON)

find_package(Qt6 REQUIRED COMPONENTS Quick Qml)

qt_add_executable(quick_hello
    main.cpp
    counter.cpp
    counter.hpp
)

qt_add_qml_module(quick_hello
    URI HelloApp
    VERSION 1.0
    QML_FILES qml/Main.qml
)

target_link_libraries(quick_hello PRIVATE Qt6::Quick)
```

Сборка:

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="/path/to/Qt/6.x/gcc_64"
cmake --build build
```

## Модель на C++ (счётчик)

`counter.hpp`:

```cpp
#pragma once
#include <QObject>

class Counter : public QObject {
    Q_OBJECT
    Q_PROPERTY(int value READ value WRITE setValue NOTIFY valueChanged)
public:
    explicit Counter(QObject* parent = nullptr) : QObject(parent) {}

    int value() const { return value_; }
    void setValue(int v) {
        if (value_ == v) return;
        value_ = v;
        emit valueChanged();
    }

    Q_INVOKABLE void increment() { setValue(value_ + 1); }

signals:
    void valueChanged();

private:
    int value_{0};
};
```

`Q_PROPERTY` делает поле видимым в QML как `counter.value`. `Q_INVOKABLE` экспортирует метод `increment()`.

`counter.cpp` — пустой или только `#include "counter.hpp"` при реализации в заголовке (для учебного примера допустимо).

## main.cpp

```cpp
#include <QGuiApplication>
#include <QQmlApplicationEngine>
#include "counter.hpp"

int main(int argc, char* argv[]) {
    QGuiApplication app(argc, argv);

    Counter counter;

    QQmlApplicationEngine engine;
    engine.rootContext()->setContextProperty("counter", &counter);
    engine.loadFromModule("HelloApp", "Main");

    if (engine.rootObjects().isEmpty())
        return -1;

    return app.exec();
}
```

`setContextProperty` — быстрый способ отдать в QML готовый объект без регистрации типа. В крупных проектах тип регистрируют через `qmlRegisterType`.

## Main.qml

```qml
import QtQuick
import QtQuick.Controls

ApplicationWindow {
    width: 360
    height: 200
    visible: true
    title: "Qt Quick Hello"

    Column {
        anchors.centerIn: parent
        spacing: 12

        Label {
            text: "Значение: " + counter.value
        }

        Button {
            text: "+1"
            onClicked: counter.increment()
        }
    }
}
```

Привязка `counter.value` обновляет подпись при сигнале `valueChanged`.

## Сигналы, свойства, C++

| Механизм | Назначение |
|----------|------------|
| `Q_PROPERTY` | Двусторонняя привязка QML ↔ C++ |
| `NOTIFY` | Обновление UI при изменении |
| `Q_INVOKABLE` | Вызов метода из QML |
| `setContextProperty` | Глобальный объект в QML (осторожно в больших apps) |
| `qmlRegisterType` | Создание `Counter {}` прямо в QML |

## QWidget или Quick?

- **Widgets** — офисные формы, нативные диалоги, стабильный desktop: [2731](./2731.md).
- **Quick** — анимации, touch, встраиваемые HMI, мобильные экраны.

Гибрид: `QQuickWidget` внутри окна на виджетах.
