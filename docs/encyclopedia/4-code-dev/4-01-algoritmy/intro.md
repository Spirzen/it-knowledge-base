# О разделе

В статьях раздела алгоритмы и циклы обработки данных по возможности сначала записываются **псевдокодом на русском** (`для i от …`, `если … то`), а примеры на Python или другом языке иллюстрируют ту же логику. Так проще учиться до углублённого изучения синтаксиса в [разделе "Языки"](/encyclopedia/5-languages/intro).
