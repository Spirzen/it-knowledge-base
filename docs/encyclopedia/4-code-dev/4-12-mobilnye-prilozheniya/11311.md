## Первая программа на React Native

Практический маршрут от пустого проекта до экрана со списком, переходом на второй экран и сохранением данных. Теория и сравнение стеков — в [React Native](./1131.md); ускоренный старт через Expo Go — в [Первая программа на Expo](./11321.md).

**React Native** переносит идеи [React](/encyclopedia/5-languages/5-01-javascript/27) на iOS и Android: компоненты, props и `useState`, но вместо `<div>` — `<View>`, вместо `<span>` — `<Text>`.

## Установка и создание проекта

### Что установить

| Компонент | Зачем |
|-----------|--------|
| **Node.js LTS** | `npm`, Metro, Expo CLI |
| **Expo Go** (телефон) | Запуск без сборки APK на старте |
| **Android Studio** (по желанию) | Эмулятор Android, позже release-сборка |
| **Xcode** (только macOS) | Симулятор и сборка под iPhone |

Проверка:

```bash
node -v    # v20 или v22 LTS
npm -v
```

### Два пути старта

| Путь | Команда | Когда выбирать |
|------|---------|----------------|
| **Expo** | `npx create-expo-app@latest` | Обучение, прототип, QR на телефон |
| **React Native CLI** | `npx @react-native-community/cli init` | Свои нативные модули с первого дня |

Ниже везде **Expo** — короче путь; JSX и API те же в bare workflow.

### Создание и запуск

```bash
npx create-expo-app@latest MyFirstApp
cd MyFirstApp
npx expo start
```

В терминале появится QR-код. Откройте **Expo Go**, отсканируйте код. ПК и телефон должны быть в одной сети; иначе `npx expo start --tunnel`.

Структура шаблона:

```
MyFirstApp/
  App.js              # точка входа (или app/ при Expo Router)
  app.json            # имя, иконка, bundle id
  package.json
  assets/
```

Зависимости для Expo ставьте через `npx expo install <пакет>` — так подбирается версия под SDK.

## Компоненты и Flexbox

### Базовые компоненты

| Компонент | Роль | Аналог в веб-React |
|-----------|------|---------------------|
| `View` | Контейнер, layout | `div` |
| `Text` | Любой текст на экране | `span` / `p` |
| `Image` | Картинка (`source={{ uri }}` или `require`) | `img` |
| `Pressable` | Кнопка, область нажатия | `button` |
| `TextInput` | Однострочный ввод | `input` |
| `ScrollView` | Прокрутка, если контент не помещается | `overflow: auto` |
| `FlatList` | Длинные списки (виртуализация) | список с windowing |

<div class="callout callout--warning">
  <div class="callout-title">Текст только внутри Text</div>
  Строку нельзя положить прямым ребёнком <code>View</code> — оберните в <code>&lt;Text&gt;</code>. Иначе ошибка «Text strings must be rendered within a Text component».
</div>

### Flexbox в React Native

В RN **все** `View` по умолчанию — `flex` с направлением **`column`** (сверху вниз). Это отличается от CSS в браузере, где блочный поток иной.

| Свойство | Назначение |
|----------|------------|
| `flex: 1` | Занять оставшееся место в родителе |
| `flexDirection` | `'row'` \| `'column'` |
| `justifyContent` | Распределение по главной оси (`center`, `space-between`, …) |
| `alignItems` | Выравнивание по поперечной оси |
| `gap` | Отступ между дочерними элементами |

Пример карточки с шапкой и кнопкой внизу:

```jsx
import { StyleSheet, Text, View, Pressable } from 'react-native';

export default function CardScreen() {
  return (
    <View style={styles.screen}>
      <View style={styles.card}>
        <Text style={styles.title}>Задача</Text>
        <Text style={styles.body}>Описание карточки</Text>
        <Pressable style={styles.button}>
          <Text style={styles.buttonLabel}>Готово</Text>
        </Pressable>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, padding: 16, backgroundColor: '#f3f4f6' },
  card: {
    flex: 1,
    backgroundColor: '#fff',
    borderRadius: 12,
    padding: 20,
    justifyContent: 'space-between',
  },
  title: { fontSize: 20, fontWeight: '600' },
  body: { fontSize: 16, color: '#4b5563' },
  button: {
    backgroundColor: '#2563eb',
    padding: 14,
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonLabel: { color: '#fff', fontWeight: '600' },
});
```

`StyleSheet.create` — объекты JavaScript; не все CSS-свойства доступны (нет `grid`, ограничен `position`).

## Состояние, пропсы и списки

### `useState` на одном экране

```jsx
import { useState } from 'react';
import { StyleSheet, Text, View, Pressable, TextInput } from 'react-native';

export default function App() {
  const [name, setName] = useState('');
  const [count, setCount] = useState(0);

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Привет, React Native</Text>
      <TextInput
        style={styles.input}
        placeholder="Ваше имя"
        value={name}
        onChangeText={setName}
      />
      {name ? <Text style={styles.greet}>Привет, {name}!</Text> : null}
      <Text style={styles.counter}>Счётчик: {count}</Text>
      <Pressable style={styles.button} onPress={() => setCount((c) => c + 1)}>
        <Text style={styles.buttonText}>+1</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', padding: 24 },
  title: { fontSize: 22, fontWeight: '600', marginBottom: 16 },
  input: { borderWidth: 1, borderColor: '#ccc', padding: 12, borderRadius: 8 },
  greet: { marginTop: 12, fontSize: 18 },
  counter: { marginTop: 24, fontSize: 18 },
  button: {
    marginTop: 12,
    backgroundColor: '#2563eb',
    padding: 14,
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonText: { color: '#fff', fontWeight: '600' },
});
```

### Пропсы — переиспользуемый дочерний компонент

```jsx
function Greeting({ name, onPress }) {
  return (
    <Pressable onPress={onPress} style={styles.greetBox}>
      <Text>Привет, {name || 'гость'}</Text>
    </Pressable>
  );
}

// В родителе:
<Greeting name={name} onPress={() => setCount((c) => c + 1)} />
```

Пропсы **только для чтения** в дочернем компоненте; изменяемое состояние экрана — в `useState` родителя или в глобальном store (Context, Zustand, Redux) в крупных приложениях.

### `FlatList` для списков

Для десятков и сотен строк `ScrollView` с `map` тормозит. `FlatList` рисует только видимые ячейки:

```jsx
import { FlatList, StyleSheet, Text, View } from 'react-native';

const TASKS = [
  { id: '1', title: 'Купить молоко' },
  { id: '2', title: 'Позвонить в поддержку' },
  { id: '3', title: 'Прочитать главу про RN' },
];

export default function TaskList() {
  return (
    <View style={styles.screen}>
      <FlatList
        data={TASKS}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <View style={styles.row}>
            <Text style={styles.rowTitle}>{item.title}</Text>
          </View>
        )}
        ItemSeparatorComponent={() => <View style={styles.separator} />}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, paddingTop: 48 },
  row: { padding: 16, backgroundColor: '#fff' },
  rowTitle: { fontSize: 16 },
  separator: { height: 1, backgroundColor: '#e5e7eb' },
});
```

`keyExtractor` обязателен для стабильных ключей при обновлении данных.

## Навигация между экранами

Стандарт — **React Navigation**. Установка в Expo-проекте:

```bash
npx expo install @react-navigation/native @react-navigation/native-stack
npx expo install react-native-screens react-native-safe-area-context
```

Минимальный стек из двух экранов (`App.js`):

```jsx
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { Pressable, StyleSheet, Text, View } from 'react-native';

const Stack = createNativeStackNavigator();

function HomeScreen({ navigation }) {
  return (
    <View style={styles.center}>
      <Text style={styles.h1}>Главная</Text>
      <Pressable
        style={styles.btn}
        onPress={() => navigation.navigate('Details', { taskId: '42' })}
      >
        <Text style={styles.btnText}>Открыть детали</Text>
      </Pressable>
    </View>
  );
}

function DetailsScreen({ route, navigation }) {
  const { taskId } = route.params;
  return (
    <View style={styles.center}>
      <Text>Задача #{taskId}</Text>
      <Pressable style={styles.btn} onPress={() => navigation.goBack()}>
        <Text style={styles.btnText}>Назад</Text>
      </Pressable>
    </View>
  );
}

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator>
        <Stack.Screen name="Home" component={HomeScreen} options={{ title: 'Список' }} />
        <Stack.Screen name="Details" component={DetailsScreen} options={{ title: 'Детали' }} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

const styles = StyleSheet.create({
  center: { flex: 1, alignItems: 'center', justifyContent: 'center', gap: 16 },
  h1: { fontSize: 22, fontWeight: '600' },
  btn: { backgroundColor: '#2563eb', paddingHorizontal: 20, paddingVertical: 12, borderRadius: 8 },
  btnText: { color: '#fff' },
});
```

| Понятие | Назначение |
|---------|------------|
| `navigation.navigate('Details', params)` | Переход вперёд с параметрами |
| `route.params` | Данные, переданные на экран |
| `navigation.goBack()` | Возврат |
| `Stack.Screen` `options` | Заголовок, кнопка «Назад» на iOS/Android |

В новых проектах Expo часто выбирают **Expo Router** (файлы в `app/` = маршруты). Обзор — в [Expo](./1132.md).

## API и локальное хранилище

### Запрос к REST API

Тот же `fetch`, что и в [веб-React](/encyclopedia/5-languages/5-01-javascript/272). Пример загрузки списка постов:

```jsx
import { useEffect, useState } from 'react';
import { ActivityIndicator, FlatList, StyleSheet, Text, View } from 'react-native';

export default function PostsScreen() {
  const [posts, setPosts] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    let cancelled = false;
    (async () => {
      try {
        const res = await fetch('https://jsonplaceholder.typicode.com/posts?_limit=10');
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const data = await res.json();
        if (!cancelled) setPosts(data);
      } catch (e) {
        if (!cancelled) setError(e.message);
      } finally {
        if (!cancelled) setLoading(false);
      }
    })();
    return () => { cancelled = true; };
  }, []);

  if (loading) {
    return (
      <View style={styles.center}>
        <ActivityIndicator size="large" />
      </View>
    );
  }
  if (error) {
    return (
      <View style={styles.center}>
        <Text>Ошибка: {error}</Text>
      </View>
    );
  }

  return (
    <FlatList
      style={styles.list}
      data={posts}
      keyExtractor={(item) => String(item.id)}
      renderItem={({ item }) => (
        <View style={styles.row}>
          <Text style={styles.title}>{item.title}</Text>
        </View>
      )}
    />
  );
}

const styles = StyleSheet.create({
  center: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  list: { flex: 1, paddingTop: 48 },
  row: { padding: 16, borderBottomWidth: 1, borderBottomColor: '#e5e7eb' },
  title: { fontSize: 14 },
});
```

На реальном устройстве для `http://127.0.0.1` используйте IP компьютера в LAN или HTTPS; localhost на телефоне указывает на сам телефон.

### Локальное хранилище

| Инструмент | Когда |
|------------|--------|
| **AsyncStorage** | Настройки, черновик, кэш JSON (не для паролей) |
| **expo-secure-store** | Токены, секреты (ограниченный объём) |
| **SQLite** (`expo-sqlite`) | Структурированные данные офлайн |

AsyncStorage:

```bash
npx expo install @react-native-async-storage/async-storage
```

```jsx
import AsyncStorage from '@react-native-async-storage/async-storage';

const KEY = '@myapp/onboarding_done';

export async function saveOnboardingDone() {
  await AsyncStorage.setItem(KEY, '1');
}

export async function isOnboardingDone() {
  const v = await AsyncStorage.getItem(KEY);
  return v === '1';
}
```

Вызовите `saveOnboardingDone` после первого входа и при старте приложения проверяйте флаг, чтобы показать нужный экран.

## Сборка и публикация

| Этап | Expo | Bare RN |
|------|------|---------|
| Dev на телефоне | Expo Go + `npx expo start` | Metro + эмулятор / USB |
| Store-сборка | **EAS Build** | Gradle (Android), Xcode (iOS) |
| Подпись | `eas credentials` / профили в `eas.json` | Keystore, provisioning profile |

```bash
npm install -g eas-cli
eas login
eas build:configure
eas build --platform android
```

Готовый **AAB** загружается в Google Play; **APK** — для тестов и RuStore. Пошагово: [Публикация Android](./1141.md), цепочка Gradle на Windows — [Сборка и развёртывание](./112.md#slozhnost-sborki-sravnenie-stekov).

### Частые ошибки

| Симптом | Причина |
|---------|---------|
| Metro error | `npx expo start -c`, переустановка `node_modules` |
| `<View>` must have single child | Оберните соседние элементы в один `View` или Fragment |
| Text strings must be in `<Text>` | Строка вне `Text` |
| `Network request failed` | Неверный URL, HTTP без разрешения, нет сети |
| Navigation undefined | Нет `NavigationContainer` в корне |
| iOS build only on Mac | IPA требует macOS и Xcode |
