## Первая программа на Expo

Эта статья рассчитана на быстрый практический результат за 20-40 минут — создать проект, запустить на телефоне, изменить экран и собрать первый рабочий прототип. Для расширения маршрута используйте [Expo](./1132.md), [React Native](./1131.md) и [публикацию Android](./1141.md).

---

### Expo - старт React Native без нативной сборки

**Expo** — инструменты поверх React Native — CLI, SDK модулей (камера, уведомления), облачная сборка **EAS**. Обзор экосистемы: [Expo](./1132.md). Полный курс RN (Flexbox, списки, навигация, API): [Первая программа на React Native](./11311.md).

## Установка и проект

```bash
# Node.js LTS обязателен
npx create-expo-app@latest ExpoHello
cd ExpoHello
npx expo start
```

На телефоне установите **Expo Go** (App Store / Google Play) и отсканируйте QR.

---

## Структура (шаблон по умолчанию)

```
ExpoHello/
  App.js           # или app/_layout.tsx при Expo Router
  app.json         # имя, иконка, slug, bundle id
  package.json
  assets/
```

`app.json` (фрагмент):

```json
{
  "expo": {
    "name": "ExpoHello",
    "slug": "expo-hello",
    "version": "1.0.0",
    "orientation": "portrait",
    "platforms": ["ios", "android"]
  }
}
```

## Expo Go и Development Build

| Режим | Описание |
|-------|----------|
| **Expo Go** | Готовое приложение-контейнер; ваш JS грузится с dev-сервера. Не все нативные модули доступны. |
| **Development build** | Собственный бинарник с нужными native-модулями (`eas build --profile development`). |
| **Production build** | Сборка для App Store / Google Play |

Когда нужен камера/Bluetooth-модуль вне SDK Expo Go — переходите на **prebuild** (`npx expo prebuild`) или EAS dev build.

## Полезные команды

```bash
npx expo start          # dev-сервер
npx expo start --tunnel # если телефон не видит LAN
npx expo install expo-camera   # версии, совместимые с SDK
npx expo doctor         # проверка окружения
```

---

## Публикация

1. Аккаунт на [expo.dev](https://expo.dev).
2. `npm install -g eas-cli` → `eas login` → `eas build:configure`.
3. `eas build --platform android` / `ios`.
4. `eas submit` — загрузка в сторы (требуются учётные записи разработчика Apple/Google).

---

### Частые ошибки

| Проблема | Решение |
|----------|---------|
| QR не открывается | Одна Wi‑Fi сеть; попробуйте `--tunnel` |
| Красный экран "Unable to resolve module" | `npm install`, перезапуск `expo start -c` |
| Нужен нативный код | Dev build, не Expo Go |
| EAS build failed | Проверьте `eas.json` и аккаунт expo.dev |

---

### Что попробовать

1. `npx expo install expo-camera` — фото с экрана (потребует dev build при ограничениях SDK).
2. `eas build --profile preview --platform android` — первая APK в облаке.
3. Сравните с bare [React Native](./11311.md), когда упрётесь в Expo Go.
