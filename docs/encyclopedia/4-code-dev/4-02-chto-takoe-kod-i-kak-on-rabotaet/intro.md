# О разделе

Фундамент **как код превращается в программу**. Стадия SDLC, на которой код становится продуктом — **[Конструирование ПО](/encyclopedia/7-project/7-12-konstruirovanie-po/intro)**.

### Зачем этот раздел

База до [языков](/encyclopedia/5-languages): синтаксис, компиляция, циклы, стиль. Без этого сложнее понимать ошибки компилятора и runtime.

| Ошибка | Что делать |
|--------|------------|

| Сразу фреймворк | Сначала переменные и циклы в разделе |

### Что попробовать

1. Один пример на странице [1.md](./1.md) (симулятор компиляции).
2. Перепишите псевдокод `ЕСЛИ…ТО…` на знакомом языке.
3. [Чек-лист](./999.md) — отметьте слабые пункты.
