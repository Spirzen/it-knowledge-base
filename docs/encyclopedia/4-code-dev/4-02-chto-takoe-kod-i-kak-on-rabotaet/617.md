# Каталог примеров кода (IT Code Examples)

<div class="article-tags">
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

<span class="complexity-badge">Разработчику</span>

Энциклопедия **Вселенная IT** не может бесконечно раздувать HTML и JS-бандл тысячами длинных листингов и тяжёлых React-демо. Для этого есть два открытых сервиса:

| Сервис | URL | Что выносим |
|--------|-----|-------------|
| **IT Code Examples** | [code.spirzen.ru](https://code.spirzen.ru/) | Длинные листинги, мультифайловые практикумы (Astro + Shiki) |
| **IT Play** | [play.spirzen.ru](https://play.spirzen.ru/) | Интерактивные симуляторы и визуализации (Astro + React) |

В статье остаётся **объяснение**; код и интерактив подгружаются через iframe. Это пилот трёхуровневой архитектуры: **spirzen.ru** — текст и SEO, **code** — статический код, **play** — интерактив.

---

## Зачем выносить код и демо отдельно

| Проблема в энциклопедии | Решение |
|-------------------------|---------|
| Длинные листинги раздувают HTML статей | Код в `it-code-examples` |
| Тяжёлые React-демо раздувают JS-бандл (~4000 файлов) | Демо в `it-play` |
| Мультифайловые практикумы тяжело читать в markdown | Вкладки файлов, подсветка на сборке |
| Лимит GitHub Pages (~1 GB) | Отдельные репозитории — отдельные лимиты |

Короткие фрагменты (3–15 строк) и лёгкие inline-виджеты по-прежнему уместны прямо в markdown. Всё **длиннее ~30 строк**, **мультифайловое** или **интерактивное с состоянием** — в отдельные сервисы.

## Для авторов статей

### Код (code.spirzen.ru)

```jsx
import ExternalCodeEmbed from '@site/src/components/ExternalCodeEmbed';

<ExternalCodeEmbed example="python/hello-world" title="Python — Hello World" />
```

| Проп | Назначение |
|------|------------|
| `example` | Slug вида `python/hello-world` → `/e/embed/python/hello-world/` |
| `title` | Заголовок iframe (доступность) |
| `src` | Полный URL embed (override) |
| `minHeight` | Минимальная высота, по умолчанию 200 |

### Интерактив (play.spirzen.ru)

```jsx
import ExternalPlayEmbed from '@site/src/components/ExternalPlayEmbed';

<ExternalPlayEmbed example="code-basics/block-builder" title="Конструктор блоков" />
```

| Проп | Назначение |
|------|------------|
| `example` | Slug вида `code-basics/block-builder` → `/p/embed/code-basics/block-builder/` |
| `title` | Заголовок iframe |
| `src` | Полный URL embed (override) |
| `minHeight` | Минимальная высота, по умолчанию 320 |

**Правило для новых материалов:** текст → `it-knowledge-base`, код → `it-code-examples`, интерактив → `it-play`.

Локально: энциклопедия `npm start` (:3000), code `npm run dev` (:4321), play `npm run dev` (:4322). URL подставляются автоматически.
