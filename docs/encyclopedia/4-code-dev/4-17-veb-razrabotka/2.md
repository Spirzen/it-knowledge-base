# Веб-разработка — итоги

---

## Главное

### Три слоя страницы

**HTML** — структура и смысл; **CSS** — внешний вид; **JavaScript** — поведение в браузере. Оформление держите в CSS, структуру — в семантических тегах HTML. — [глава 5](./5.md).

### Дизайн и проект

**Wireframe** до кода; типографика, сетка, адаптив, доступность (a11y).

Этапы проекта:

- идея → ТЗ → макет → вёрстка → программирование → контент → тест → публикация

Варианты по сложности — статика, CMS (WordPress), своё приложение. — [главы 6–7](./6.md).

### Клиент и сервер

**Клиент** (чаще браузер) инициирует **HTTP-запрос**. **Сервер** обрабатывает его и возвращает **ответ** — HTML, JSON, файл или ошибку. При разработке сервер часто на `http://localhost:PORT`. Подробнее — [1.23 фронт/бэк](/encyclopedia/1-basics/1-23-frontend-i-bekend/intro), [глава 1](./1.md).

### HTTP

Запрос включает **метод** (`GET`, `POST`, …), **URL**, **заголовки** и опционально **тело**. Ответ — **статус-код** (200, 404, …), заголовки, тело. [HTTP-методы](/encyclopedia/2-system-network/2-09-osnovy-integratsionnogo-vzaimodeystviya/118), [статус-коды](/encyclopedia/2-system-network/2-03-set-i-internet/611#status-codes-cheatsheet).

### JSON и CRUD

**JSON** — текстовый формат обмена; объекты — map, массивы — list. **CRUD** — create, read, update, delete; в REST сопоставляется с POST, GET, PUT/PATCH, DELETE.

### REST и API

**REST** — ресурсы с URI (`/tasks/5`) и корректные статус-коды. **API** — набор endpoints для программ. [REST, GraphQL](/encyclopedia/2-system-network/2-09-osnovy-integratsionnogo-vzaimodeystviya/130).

### CORS

Ограничение **браузера** при запросе с одного origin на другой. Лечится заголовками на **сервере API** или dev-proxy. [CORS](/encyclopedia/2-system-network/2-03-set-i-internet/411).

### Конфигурация

**`.env`** и переменные окружения хранят секреты локально; файл в [`.gitignore`](/encyclopedia/4-code-dev/4-13-osnovy-raboty-s-git/116). [1112 безопасность .env](/encyclopedia/4-code-dev/4-14-razrabotka-i-otladka/1112).

## Статус-коды — шпаргалка

| Код | Значение |
|-----|----------|
| 200 | OK, данные отданы |
| 201 | ресурс создан |
| 204 | успех без тела |
| 400 | ошибка в запросе клиента |
| 401 | не авторизован |
| 403 | нет прав |
| 404 | не найдено |
| 500 | ошибка сервера |

### Архитектура и стек

- **SPA** — интерфейс в браузере, данные с API.
- **MPA** — готовые HTML-страницы с сервера.
- **MERN** — MongoDB, Express, React, Node.js (один язык JS).
- **LAMP** — Linux, Apache, MySQL, PHP (классика хостинга).
- **CMS** — WordPress и аналоги, когда контент правит заказчик.
- Бэкенд — Django, Spring, ASP.NET Core, Node.js; фронт — React, Vue, Angular; сборка — Vite.
- Настройки UI — `localStorage`; заказы и пользователи — **SQL**; ускорение — Redis; фон — RabbitMQ или Kafka.
- Перенос — Git, `.env`, миграция БД; рост нагрузки — реплики, балансировщик, контейнеры.
