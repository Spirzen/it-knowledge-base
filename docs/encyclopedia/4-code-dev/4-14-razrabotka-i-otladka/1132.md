**Visual Studio** — интегрированная среда разработки (IDE) от Microsoft для **Windows**: в одном приложении можно писать код, собирать проекты, отлаживать, тестировать и публиковать решения. Официальные материалы на русском: [что такое Visual Studio](https://learn.microsoft.com/ru-ru/visualstudio/get-started/visual-studio-ide?view=visualstudio), [установка](https://learn.microsoft.com/ru-ru/visualstudio/install/install-visual-studio?view=visualstudio), [заметки о выпуске 2026](https://learn.microsoft.com/ru-ru/visualstudio/releases/2026/release-notes), [архив версий](https://learn.microsoft.com/ru-ru/previous-versions/visualstudio/).

> **Visual Studio ≠ Visual Studio Code.** VS Code — лёгкий кроссплатформенный редактор; полноценная IDE для .NET, C++, MAUI, Azure и корпоративных сценариев — это **Visual Studio** (только Windows). Расширения для VS Code описаны в [главе про VS Code](/encyclopedia/4-code-dev/4-14-razrabotka-i-otladka/1131).

---

### Когда ставить Visual Studio

| Сценарий | Visual Studio | VS Code |
|----------|---------------|---------|
| WinForms / WPF / .NET MAUI / большой .NET solution | Предпочтительно | Возможно, но больше ручной настройки |
| C++ с MSVC, игры на DirectX | Предпочтительно | Расширения, без полного набора workload |
| Быстрый скрипт, фронт, Node, Python "в файле" | Избыточно | Удобнее |
| macOS / Linux как основная ОС | Не ставится | Основной выбор + `dotnet` CLI |

На учебном проекте ASP.NET Core достаточно **Community** и workload "ASP.NET и веб-разработка"; Enterprise нужен реже (расширенное тестирование, корпоративные политики).

## Выпуски и лицензирование

| Выпуск | Для кого | Ссылка |
|--------|----------|--------|
| **Community** | Учащиеся, open source, индивидуальные разработчики | [Скачать](https://visualstudio.microsoft.com/vs/community/) |
| **Professional** | Небольшие команды, платная подписка / пробный период | [Сравнение](https://visualstudio.microsoft.com/vs/professional/) |
| **Enterprise** | Корпорации, расширенная диагностика и тестирование | [Сравнение](https://visualstudio.microsoft.com/vs/enterprise/) |

Полная таблица возможностей: [сравнение выпусков](https://visualstudio.microsoft.com/vs/compare/). **Community** не требует входа в учётную запись для работы, но периодические запросы входа лучше выполнять, чтобы не прерывать работу ([вход в Visual Studio](https://learn.microsoft.com/ru-ru/visualstudio/ide/signing-in-to-visual-studio?view=visualstudio)).

Актуальная линейка продуктов — **Visual Studio 2026** (внутренние обновления нумеруются, например **18.x**). Параллельно поддерживается **Visual Studio 2022**; обе версии можно ставить **рядом** на одном ПК ([параллельная установка](https://learn.microsoft.com/ru-ru/visualstudio/install/install-visual-studio-versions-side-by-side?view=visualstudio)).

## Visual Studio - IDE для .NET и C++

По [обзору Microsoft Learn](https://learn.microsoft.com/ru-ru/visualstudio/get-started/visual-studio-ide?view=visualstudio) среда закрывает весь цикл разработки:

| Этап | Возможности |
|------|-------------|
| **Код** | Редактор с IntelliSense, лампочки быстрых исправлений, структурирование, [Обозреватель решений](https://learn.microsoft.com/ru-ru/visualstudio/ide/quickstart-ide-orientation?view=visualstudio) и представление классов |
| **ИИ** | [GitHub Copilot](https://learn.microsoft.com/ru-ru/visualstudio/ide/visual-studio-github-copilot-get-started?view=visualstudio), [IntelliCode](https://learn.microsoft.com/ru-ru/visualstudio/ide/intellicode-visual-studio?view=visualstudio), отладка с Copilot |
| **Сборка** | MSBuild, многопроцессорные сборки C++/C#, конфигурации Debug/Release |
| **Отладка** | Точки останова, просмотр переменных, профилирование ([тур по отладчику](https://learn.microsoft.com/ru-ru/visualstudio/debugger/debugger-feature-tour?view=visualstudio)) |
| **Тесты** | Модульные тесты, покрытие кода (с VS 2026 — также в Community/Professional) |
| **Git** | Клонирование, ветки, коммиты, pull request'ы ([Git в Visual Studio](https://learn.microsoft.com/ru-ru/visualstudio/version-control/git-with-visual-studio?view=visualstudio)) |
| **Публикация** | Профили развёртывания, Azure, сетевые и локальные папки ([развёртывание](https://learn.microsoft.com/ru-ru/visualstudio/deployment/deploying-applications-services-and-components?view=visualstudio)) |

**Языки и стеки:** C#, C++, Python, JavaScript/TypeScript, visual-basic, F#; веб (ASP.NET, Blazor, Node.js), десктоп ([WinForms](/encyclopedia/4-code-dev/4-11-desktopnye-prilozheniya/115), WPF), мобильные ([.NET MAUI](/encyclopedia/4-code-dev/4-12-mobilnye-prilozheniya/1133)), облако и игры (C++). Расширения — [Visual Studio Marketplace](https://marketplace.visualstudio.com/) или [собственные расширения](https://learn.microsoft.com/ru-ru/visualstudio/extensibility/visualstudio.extensibility/get-started/create-your-first-extension?view=visualstudio).

**Первые проекты (учебники Learn):** [C#](https://learn.microsoft.com/ru-ru/visualstudio/get-started/csharp/tutorial-console?view=visualstudio) · [C++](https://learn.microsoft.com/ru-ru/cpp/get-started/tutorial-console-cpp) · [Python](https://learn.microsoft.com/ru-ru/visualstudio/python/installing-python-support-in-visual-studio) · [Node.js](https://learn.microsoft.com/ru-ru/visualstudio/javascript/tutorial-nodejs?view=visualstudio) · [visual-basic](https://learn.microsoft.com/ru-ru/visualstudio/get-started/visual-basic/tutorial-console?view=visualstudio) · [F#](https://learn.microsoft.com/ru-ru/visualstudio/get-started/tutorial-fsharp-web-app?view=visualstudio).

Ориентация в окнах IDE: [краткий тур по Visual Studio](https://learn.microsoft.com/ru-ru/visualstudio/ide/quickstart-ide-orientation?view=visualstudio).

## Установка

Сводка по [руководству по установке](https://learn.microsoft.com/ru-ru/visualstudio/install/install-visual-studio?view=visualstudio).

---

### Шаг 1. Подготовка компьютера

1. Проверить [системные требования VS 2026](https://learn.microsoft.com/ru-ru/visualstudio/releases/2026/vs-system-requirements) или [VS 2022](https://learn.microsoft.com/ru-ru/visualstudio/releases/2022/system-requirements).
2. Установка от имени **администратора** ([разрешения](https://learn.microsoft.com/ru-ru/visualstudio/ide/user-permissions-and-visual-studio?view=visualstudio)).
3. Установить обновления **Windows**, перезагрузить ПК, освободить место на системном диске.
4. При необходимости — [совместимость и параллельные версии](https://learn.microsoft.com/ru-ru/visualstudio/releases/2026/compatibility).

---

### Шаг 2. Скачивание

- С [страницы загрузок](https://visualstudio.microsoft.com/downloads/) — последний билд (загрузчик `VisualStudioSetup.exe` / `vs_community.exe` в папке "Загрузки").
- Конкретный билд — из [журнала выпусков 2026](https://learn.microsoft.com/ru-ru/visualstudio/releases/2026/release-history) или [2022](https://learn.microsoft.com/ru-ru/visualstudio/releases/2022/release-history).
- В корпоративной среде администратор может указать свой источник или [офлайн-установку](https://learn.microsoft.com/ru-ru/visualstudio/install/create-an-offline-installation-of-visual-studio?view=visualstudio).

---

### Шаг 3–4. Установщик и рабочие нагрузки

<ExternalPlayEmbed example="basics/installer-wizard-play" title="Мастер установки" minHeight={480} playProps={{ appName: 'Установка Visual Studio', productName: 'Visual Studio Community', welcomeText: 'Мастер загрузит и настроит среду разработки. Запустить загрузчик → принять лицензию → в **Visual Studio Installer** выбрать способ настройки:

| Способ | Когда использовать |
|--------|-------------------|
| **Рабочие нагрузки вручную** | Чистая установка, минимальный набор |
| **Перенос из VS 2022+** | Обновление до 2026 с копированием workload, SDK, расширений Marketplace |
| **Импорт `.vsconfig`** | Единый стандарт среды в команде ([импорт/экспорт](https://learn.microsoft.com/ru-ru/visualstudio/install/import-export-installation-configurations?view=visualstudio)) |

Типичные **рабочие нагрузки** (имена в русском установщике могут слегка отличаться):

| Задача | Рабочая нагрузка |
|--------|------------------|
| C# / .NET, WinForms, WPF | **Разработка классических приложений .NET** |
| ASP.NET, Blazor, веб API | **ASP.NET и веб-разработка** |
| .NET MAUI | **Разработка приложений .NET MAUI** |
| C++ (в т.ч. игры) | **Разработка классических приложений на C++** / игровые workload |
| Python | **Разработка на Python** |
| Azure | **Разработка Azure** |
| SQL Server / SSDT | **Хранение и обработка данных** |

После установки недостающие компоненты добавляются через **Сервис → Получить средства и компоненты** (открывает Installer) или Installer из меню "Пуск".

Дополнительно: отдельные компоненты на вкладке "Отдельные компоненты", [языковые пакеты](https://learn.microsoft.com/ru-ru/visualstudio/install/install-visual-studio?view=visualstudio) (`ru-ru` поддерживается), смена диска установки — только при **первой** установке ([расположения](https://learn.microsoft.com/ru-ru/visualstudio/install/change-installation-locations?view=visualstudio)).

**Командная строка** (тихая установка, CI, админы): [параметры установки](https://learn.microsoft.com/ru-ru/visualstudio/install/use-command-line-parameters-to-install-visual-studio?view=visualstudio), пример смены языка установщика: `vs_installer.exe --locale en-US`.

После установки: **Пуск** → шаблон (зависит от workload) → **Создать**. Примеры в энциклопедии — [WinForms](/encyclopedia/4-code-dev/4-11-desktopnye-prilozheniya/115), [MAUI](/encyclopedia/4-code-dev/4-12-mobilnye-prilozheniya/1133), [ASP.NET Razor/MVC](/encyclopedia/5-languages/5-05-csharp/455).

**Обслуживание:** [обновление](https://learn.microsoft.com/ru-ru/visualstudio/install/update-visual-studio?view=visualstudio) · [изменение компонентов](https://learn.microsoft.com/ru-ru/visualstudio/install/modify-visual-studio?view=visualstudio) · [удаление](https://learn.microsoft.com/ru-ru/visualstudio/install/uninstall-visual-studio?view=visualstudio).

## Visual Studio 2026 — что нового

Линейка **2026** позиционируется как новая эпоха IDE: глубокая интеграция **ИИ**, обновлённый интерфейс **Fluent**, ускорение сборок и ужесточение платформенных требований. Актуальный список изменений — в [заметках о выпуске](https://learn.microsoft.com/ru-ru/visualstudio/releases/2026/release-notes); [история билдов](https://learn.microsoft.com/ru-ru/visualstudio/releases/2026/release-history).

---

### Ключевые темы (релиз 18.0, ноябрь 2025)

- **Fluent UI** — обновлённый внешний вид, 11 новых тем, отдельная настройка "Внешний вид редактора".
- **Современные параметры** — новый UI настроек вместо классического "Сервис → Параметры" (часть опций ещё ведёт в legacy-диалог).
- **Покрытие кода** — анализ покрытия в **Community** и **Professional** (раньше — в основном Enterprise).
- **Copilot в поиске** — подсказка "Вы имели в виду?" в All-In-One Search (`Ctrl+Shift+P`).
- **Помощник по настройке** — подсказки по отсутствующим MSVC, Windows SDK, `.NET SDK` после обновления IDE.
- **M365 / Teams** — шаблоны агентов, Toolkit, .NET 10 в шаблонах M365.

---

### Обновление 18.6 (май 2026) — пример свежих улучшений

- **Системные темы** — автопереключение светлой/тёмной темы VS при смене темы Windows (Параметры → Среда → Визуальный интерфейс).
- **Copilot:** панель навыков агента, сводный diff по нескольким файлам, индикатор заполнения контекста, **режим планирования** (план в `.copilot/plans/*.md` перед правками кода).
- **Git + Copilot:** прикрепление коммита в чат из истории; инструкции для сообщений коммита — через файл инструкций Copilot в репозитории.
- **C++:** MSVC **14.51**, улучшения C++23, Segment Heap по умолчанию для новых проектов, агент `@BuildPerfCpp` для оптимизации времени сборки.

Для фиксации конкретного билда в команде используйте [журнал выпусков 2026](https://learn.microsoft.com/ru-ru/visualstudio/releases/2026/release-history) (даты и номера сборок).
