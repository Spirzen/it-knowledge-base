# 3.04. Чек-лист самопроверки

	- Понимаете синтаксис и особенности каждого формата?
	- Умеете правильно оформлять списки, объекты и вложенные структуры?
	- Разбираетесь в правилах написания markdown?
	- Знаете основные элементы форматирования текста?
	- Чем отличается узел от элемента XML?
	- Что такое XPath?
	- Что такое XSLT?
