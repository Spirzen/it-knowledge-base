## Геометрические данные

```
Геометрические данные
Пространство
Информация о форме, размере, расположении объектов в пространстве
Географические объекты
Координаты, контуры, высоты, формы рельефа, границы объектов
Геоданные
ГИС (геоинформационные системы)
геоинформатика
характеристики конструкций
биометрические данные человека (лицо, отпечатки пальцев, сетчатка глаза)
биометрическая идентификация
Уникальные физические характеристики человека, такие как геометрия лица, рисунок вен, отпечатки пальцев, радужка глаза – для идентификации.
Геометрические характеристики в инженерии: Параметры сечений балок (площадь, моменты инерции) для расчета их прочности и сопротивления деформации.
Данные о вершинах, ребрах, гранях (меши) для создания и управления трехмерными объектами
R-дерево
древовидная структура данных (дерево)
B-дерево и отличия от R-дерева
R-trees для индексации геометрических данных

```
