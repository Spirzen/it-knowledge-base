## NewSQL системы

```
NewSQL системы
CockroachDB
Google Spanner
VoltDB
NuoDB
ClustrixDB

NewSQL — это класс современных реляционных систем управления базами данных (СУБД), которые сочетают масштабируемость и производительность NoSQL-систем с гарантиями транзакций (ACID) и привычным языком SQL традиционных реляционных баз данных, решая проблемы масштабирования для OLTP-нагрузок (онлайн-транзакции). Они позволяют горизонтально масштабировать базы данных, сохраняя при этом целостность данных, что критично для финансовых и других систем, где важны и скорость, и надежность.
```
