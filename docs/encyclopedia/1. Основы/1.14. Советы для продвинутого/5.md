## Железо и производительность

Аппаратное обеспечение компьютерной системы представляет собой совокупность физических компонентов, которые обеспечивают вычислительные возможности устройства. Управление параметрами работы этих компонентов позволяет достичь определённого уровня производительности в конкретных задачах.

Производительность системы зависит от взаимодействия центрального процессора, видеокарты, оперативной памяти, систем охлаждения и других элементов. Каждый компонент выполняет свою функцию, и правильная настройка всех частей влияет на итоговые результаты работы.

---

### Главные мысли

1. Процессор считает всё подряд. Упирается в потолок в тяжёлых расчётах, компиляции, некоторых играх.
2. Видеокарта рисует картинку. Упирается в потолок в играх, 3D-моделировании, нейросетях.
3. Оперативка держит открытые программы. Упирается в потолок, когда открыто 100 вкладок браузера.
4. SSD загружает систему и файлы. Упирается в потолок при копировании терабайтов мелочи.
5. Можно разогнать:
- процессор (поднять частоту);
- видеокарту (частоту ядра и памяти);
- оперативку (частоту и тайминги).
6. При разгоне:
- компьютер становится горячее;
- жрёт больше электричества;
- может начать вылетать, если перестараться.
7. Нормальная температура для процессора - 30-60 градусов.
8. Для видеокарты - 40-70 градусов.
9. SSD/диск - 25-45 градусов.
10. Если процессор греется под 90°C — он начнёт сбрасывать частоту (тормозить). А если 100°C — выключится.
11. Если горячо:
- почистить от пыли;
- заменить термопасту;
- добавить вентиляторы в корпус;
- поставить более мощный кулер или "водянку".
12. Охлаждение бывает:
- воздушное (дешево, не течет);
- водяное (тише, эффективнее, но риск протечки);
- коробочное (обычно в комплекте с процессором, греется и шумит).
13. Для обычного пользователя хороший воздушный кулер за 3000–5000 руб — норм.
14. Если у вас старый компьютер с обычным жёстким диском (HDD), купите SSD.
15. Windows сама дефрагментирует SSD, но для SSD вместо дефрагментации используется TRIM.
16. Если бюджет ограничен - покупайте сначала SSD, затем ОЗУ, и потом видеокарту.
17. Перед апгрейдом проверьте совместимость:
- сокет процессора;
- форм-фактор материнской платы;
- объём и тип оперативки;
- блок питания.
18. Не поднимайте напряжение без охлаждения.
19. Не ставьте частоты, найденные в интернете для чужого процессора.
20. Не запускайте стресс-тест без контроля температуры.

---

### Ключевые понятия

| Термин | Определение | Область применения |
|--------|-------------|-------------------|
| Тактовая частота | Количество операций за единицу времени | Процессоры, видеокарты, память |
| Напряжение питания | Электрический потенциал для работы компонентов | Стабилизация работы ЦП и ГП |
| Температура работы | Уровень теплового режима активного элемента | Контроль безопасности компонентов |
| FPS | Частота отображения кадров в секунду | Видеоигры, графические задачи |
| Разгон | Увеличение заводских параметров компонента | Повышение производительности |
| Стресс-тест | Проверка стабильности под максимальной нагрузкой | Валидация настроек разгона |

## Центральные процессоры (CPU)

Центральный процессор представляет собой основной вычислительный элемент компьютерной системы. Он обрабатывает данные, управляет работой остальных компонентов и обеспечивает выполнение программных инструкций.

### Параметры процессора

| Параметр | Типичное значение | Влияние на производительность |
|----------|------------------|------------------------------|
| Ядерность | 4–16 ядер | Многозадачность, параллельные вычисления |
| Потокность | 4–32 потока | Одновременное выполнение задач |
| Тактовая частота | 2,5–5,0 ГГц | Скорость выполнения одной операции |
| Кэш-память | L1/L2/L3, до 64 МБ | Доступ к быстродействующей памяти |
| ТЭП (TDP) | 65–150 Вт | Тепловыделение и энергопотребление |

### Базовые настройки BIOS/UEFI

BIOS и UEFI представляют собой интерфейсы начальной загрузки и настройки аппаратного обеспечения. Через эти системы выполняется конфигурация параметров разгона перед запуском операционной системы.

```bash
# Пример последовательности действий при работе с BIOS

Шаг 1: Перезагрузка компьютера
Шаг 2: Вход в BIOS/UEFI (клавиша Del/F2 при старте)
Шаг 3: Переход в раздел Advanced или overclocking
Шаг 4: Изменение параметров CPU multiplier
Шаг 5: Сохранение настроек и выход
```

### Параметры для изменения

```yaml
Процессор Intel:
  - Базовая частота: 3,6 ГГц
  - Максимальная частота (Turbo): 4,8 ГГц
  - Коэффициент умножения: изменяется вручную
  - Напряжение Vcore: 1,1–1,3 В
  
Процессор AMD:
  - Базовая частота: 3,5 ГГц
  - Максимальная частота (PBO): динамически регулируется
  - Curve Optimizer: индивидуальная калибровка напряжения
  - Precision Boost Override: увеличение лимитов мощности
```

## Видеокарты (GPU)

Графический процессор отвечает за обработку визуальных данных, рендеринг изображений и выполнение вычислений графических шейдеров. Современные GPU также применяются для задач искусственного интеллекта и майнинга криптовалют.

### Основные характеристики видеокарт

| Характеристика | Описание | Практическое применение |
|---------------|----------|----------------------|
| Видеопаметь | Объём встроенной памяти GPU | Текстуры высокого разрешения |
| Чипсет GPU | Графический процессор | Вычислительная мощность |
| Подсветка | RGB элементы корпуса | Эстетическое оформление |
| Интерфейс PCIe | Версия шины подключения | Пропускная способность |
| Система охлаждения | Радиаторы, вентиляторы | Отвод тепла при нагрузке |

### Программные утилиты для настройки

| Утилита | Производитель | Функционал |
|---------|--------------|------------|
| MSI Afterburner | MSI | Разгон, мониторинг температуры, запись игры |
| GPU-Z | TechPowerUp | Детальная информация о видеокарте |
| HWInfo | German software GmbH | Полный мониторинг системы |
| FurMark | Geeks3D | Экстремальное тестирование нагрузки |

### Настройка в MSI Afterburner

```ini
; Конфигурационный файл MSI Afterburner

[Overclocking]
CoreClock = +100       ; Доп. частота ядра в МГц
MemoryClock = +200     ; Доп. частота памяти в МГц
Voltage = 0            ; Доп. напряжение в мВ
FanSpeed = 70          ; Скорость вентиляторов в %

[Monitoring]
TemperatureEnable = true
FrametimeEnable = true
UsageEnable = true
```

## Оперативная память (RAM)

Оперативная память представляет собой быстродоступное хранилище данных для активных процессов. Скорость обмена данными между процессором и памятью напрямую влияет на общую производительность системы.

### Параметры модулей памяти

| Параметр | Стандарт | Значение |
|----------|----------|----------|
| Тип памяти | DDR4 / DDR5 | Совместимость с материнской платой |
| Частота | 2133–5200+ МГц | Скорость передачи данных |
| Задержки (CL) | CL15–CL36 | Время доступа к данным |
| Объём | 8–128 ГБ | Количество доступной памяти |
| Каналы | Single/Dual/Quad | Ширина полосы пропускания |

### Настройка таймингов памяти

```markdown
Типичные значения таймингов:

    CL-T-RC: первичный тайминг и общая длительность цикла
    tRCD: время между активацией строки и чтением из неё
    tRP: время предзарядки банка памяти после завершения чтения
    tRAS: время активной строки перед закрытием

Пример конфигурации DDR4-3200:
    CL16-18-18-36 @ 1,35V
```

## Системы охлаждения

Эффективное охлаждение компонентов предотвращает перегрев и сохраняет стабильную работу оборудования под нагрузкой. Выбор системы охлаждения зависит от тепловой нагрузки процессора и бюджета.

### Типы систем охлаждения

| Тип | Принцип работы | Преимущества | Недостатки |
|-----|----------------|--------------|------------|
| Воздушное | Тепло передаётся через радиатор и рассеивается вентиляторами | Низкая цена, надёжность | Ограниченная эффективность под пиковой нагрузкой |
| Водяное | Тепло переносится жидкостью по контуру к радиатору | Высокая эффективность | Требует обслуживания |
| Встроенное | Кулер установлен на процессоре с завода | Минимальная стоимость | Низкая производительность |

### Контроль температур

| Утилита | Мониторинг | Особенности |
|---------|-----------|-------------|
| HWMonitor | Температуры, напряжения, обороты | Подробный детализированный отчёт |
| Speccy | Общая сводка системы | Удобный интерфейс, портативность |
| Open Hardware Monitor | Все датчики системы | Открытый исходный код |
| Core Temp | Температура ядер ЦП | Минималистичность, точность |

### Рекомендации по чистке системы

```markdown
1. Отключение питания перед обслуживанием
2. Использование баллона со сжатым воздухом для очистки пыли
3. Замена термопасты раз в 12–24 месяца
4. Проверка работы вентиляторов и помпы
5. Осмотр кабелей на отсутствие повреждений изоляции
```

## Обновление драйверов

Драйверы представляют собой программное обеспечение для управления аппаратными компонентами. Производители выпускают обновления для исправления ошибок и добавления поддержки новых функций.

### Процедуры обновления драйверов видеокарт

```yaml
Производитель NVIDIA:
  Шаг 1: Посещение сайта производителя
  Шаг 2: Выбор модели видеокарты
  Шаг 3: Скачивание актуальной версии
  Шаг 4: Установка с перезагрузкой

Производитель AMD:
  Шаг 1: Посещение сайта производителя
  Шаг 2: Выбор серии видеокарты
  Шаг 3: Скачивание пакета драйверов
  Шаг 4: Установка без перезагрузки (если требуется)
```

### Проверка установленных версий

```powershell
# Команда PowerShell для проверки версий драйверов

Get-WmiObject Win32_VideoController | 
    Select-Object Name, DriverVersion, Adapter RAM | 
    Format-Table
```

### Базовые рекомендации по обновлению

- Сохранение резервных копий существующих версий
- Создание точки восстановления системы
- Проверка отзывов об обновлениях
- Установка только официальных версий с сайтов производителей

## SSD и оптимизация дисков

Системы хранения данных влияют на скорость загрузки операционной системы, запуска приложений и обработки файлов. Современные твердотельные накопители значительно превосходят традиционные HDD по скорости доступа.

### Типы накопителей

| Тип | Интерфейс | Скорость чтения | Скорость записи |
|-----|-----------|----------------|----------------|
| SATA SSD | SATA III | до 550 МБ/с | до 520 МБ/с |
| NVMe M.2 | PCIe Gen3/4 | до 3500 МБ/с | до 3000 МБ/с |
| NVMe M.2 | PCIe Gen5 | до 7000 МБ/с | до 6000 МБ/с |

### Команды дефрагментации

```cmd
# Windows System Information

defrag C: /H /U /V      # Расширенная информация о дисках
dfrgui.exe              # Запуск дефрагментатора через GUI
chkdsk C: /f            # Проверка и восстановление ошибок
sfc /scannow           # Проверка целостности системных файлов
```

### Настройка службы автоматической оптимизации

```powershell
# Управление службой Defrag

Disable-ScheduledTask -TaskName "Defrag" -TaskPath "\Microsoft\Windows\Defrag"
Optimize-Volume -DriveLetter C -ReTrim -Verbose
Set-DiskType -DriveLetter C -Type SolidState
```

## Мониторинг состояния системы

Мониторинг ключевых показателей позволяет отслеживать стабильность работы компонентов и выявлять потенциальные проблемы до наступления критических ситуаций.

### Критические показатели для контроля

| Показатель | Нормальное значение | Предупреждающее значение | Критическое значение |
|------------|-------------------|------------------------|--------------------|
| CPU температура | 30–60°C | 65–75°C | `>`80°C |
| GPU температура | 40–70°C | 75–85°C | `>`90°C |
| VRM температура | 30–50°C | 55–65°C | `>`70°C |
| Объем памяти (RAM) | `<`50% использование | 50–80% использование | `>`90% использование |
| Дисковое пространство | `>`20% свободно | 10–20% свободно | `<`10% свободно |

### Автоматические алерты

```python
# Пример скрипта Python для мониторинга температур

import psutil
import platform
import time

def get_cpu_temperature():
    try:
        return float(psutil.sensors_temperatures()['cpu_thermal'][0].current)
    except KeyError:
        return 0

while True:
    temp = get_cpu_temperature()
    if temp > 75:
        print(f"Warning: CPU temperature critical ({temp}°C)")
    elif temp > 80:
        print(f"Alert: CPU temperature dangerous ({temp}°C)")
    
    time.sleep(5)
```

### Приоритетность апгрейда

| Приоритет | Компонент | Эффективность | Стоимость |

| 2 | Оперативная память | Средняя | Средняя |
| 3 | Видеокарта | Высокая | Высокая |
| 4 | Процессор | Средняя | Очень высокая |
| 5 | Блок питания | Средняя | Средняя |

```markdown
Ключевые параметры совместимости:
```

## Безопасность при разгоне

Разгон компонентов требует соблюдения правил техники безопасности и ответственного подхода к настройке параметров. Нарушение регламента может привести к повреждениям оборудования или потере гарантии.

### Правила безопасного разгона

- Начало с минимальных увеличений параметров
- Мониторинг температур на каждом этапе
- Проведение стресс-тестов после каждой настройки
- Сохранение резервных конфигураций перед изменениями
- Информирование себя о пределах безопасности компонентов

### Риски неправильного разгона

| Риск | Последствия | Предотвращение |
|------|-------------|---------------|
| Перегрев | Деградация материала, поломка | Регулярный контроль температур |
| Перенапряжение | Повеждение электронных цепей | Соблюдение лимитов напряжения |
| Нестабильность | Синие экраны, зависания | Испытания нагрузками длительное время |
| Потеря гарантии | Отказ в сервисном обслуживании | Информирование о рисках заранее |
