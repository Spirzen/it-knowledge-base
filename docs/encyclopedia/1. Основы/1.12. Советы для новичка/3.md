## Эффективная работа с системой

Компьютер, как и любое другое устройство, требует ухода. Создавайте точки восстановления системы перед установкой новых программ или обновлений — это поможет вернуть систему к работоспособному состоянию в случае сбоя. Периодически проверяйте жёсткий диск на ошибки с помощью встроенных инструментов (например, команда chkdsk в Windows). 

Если вы заметили, что система стала работать медленнее, возможно, дело в перегреве компонентов - об этом мы уже говорили. Используйте программы для мониторинга температуры, чтобы убедиться, что всё в порядке, и наконец, старайтесь избегать экспериментов с системными файлами и папками, если вы не уверены в своих действиях. Удаление файлов из папок System32 или Program Files может привести к серьёзным проблемам. Некоторые вирусы как раз «сносят» системные папки, чем ломают систему.

Здесь важные советы:
- *Использовать для заметок блокнот*, а не Word;
- *Не удалять файлы из папок System32 или Program Files без понимания*;
- *Не чистить реестр без понимания* – можно сломать систему;
- *Регулярно обновлять систему*.

Использование горячих клавиш значительно ускоряет работу за компьютером. Например, комбинаций Win+E открывает проводник, Ctrl+C/V/X позволяют быстро копировать, вставлять и вырезать данные (не обязательно каждый раз вызывать контекстное меню правой кнопкой мыши), а Alt+Tab помогает переключаться между открытыми окнами. Эти простые сочетания экономят время и делают процесс работы более комфортным.

*Горячие клавиши*:


| Комбинация | Значение |
| :--- | :---: |
|Win + E	|Открыть Проводник
|Win + R	|Выполнить
|Win + V	|История буфера обмена
|Win + Tab	|Меню выбора открытых окон
|Win + Shift + S	|Скриншот области экрана
|Win	|Меню Пуск
|Ctrl + C	|Копировать
|Ctrl + X	|Вырезать
|Ctrl + V	|Вставить
|Ctrl + B	|Жирный шрифт
|Ctrl + I	|Курсив
|Ctrl + U	|Подчеркнутый
|Ctrl + Z	|Отменить последнее действие
|Ctrl + Y	|Вернуть отменённое действие
|Ctrl + A	|Выделить все элементы списка
|Ctrl + Shift + N	|Создать папку
|Ctrl + F	|Поиск
|F2	|Переименовать
|Alt + F4	|Закрыть программу
|Win + D	|Свернуть все окна
|Alt + Tab	|Переключиться между окнами
|Del	|Удалить
|Shift + Del	|Безвозвратно удалить
|Shift + Alt	|Переключить раскладку клавиатуры (язык)
|Ctrl + Alt + Delete	|Открыть параметры безопасности компьютера (в новых Windows), в старых Windows – диспетчер задач
|Ctrl + Shift + Esc	|Открыть диспетчер задач (в новых Windows)
