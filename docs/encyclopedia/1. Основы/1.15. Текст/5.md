## Веб-технологии

**HTM, HTML (HyperText Markup Language)** – язык разметки веб-страниц, состоящий из тегов и атрибутов. Очень похож на XML, но они отличаются тем, что в HTML имеется стандартизированный набор тегов и атрибутов с установленной целью, допустим `<head>` для заголовка, и `<a href=”” />` для ссылки, тогда как в XML можно создать свой, произвольный элемент `<Element123>`.

**CSS (Cascading Style Sheets)** – язык стилей для веб-страниц, который позволяет добавить оформление (кнопок, цветов, шрифтов, таблиц) элементов в HTML, и состоит из селекторов, свойств и значений. 

Пример:
```css
selector {
  property: value;
}
```



**JS (JavaScript)** – клиентский язык программирования для веб-страниц и приложений, который обрабатывается в браузере при помощи специального движка, и обеспечивает анимации, выполнение логики, связи и вычисления, словно «вдыхая душу» в пустые кнопки HTML/CSS.

**CHM (Compiled HTML Help)** – формат справки Microsoft, компилируется из HTML-файлов и представляет собой собранный пакет веб-страниц, с оглавление, предметным указателем и полнотекстовым поиском.
