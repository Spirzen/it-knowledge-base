# 1.11. Браузеры

## Браузеры

Браузеры – специальные программы для работы с сетью Интернет, позволяющие просматривать веб-страницы (сайты, приложения) и даже открывать некоторые файлы локально. Браузеры — это наши окна в сеть, без которых сложно представить современную жизнь. Они позволяют открывать сайты, читать новости, работать с документами. Google Chrome завоевал популярность благодаря своей скорости и богатой библиотеке расширений и породил много мемов, связанных с потреблением оперативной памяти (он её сильно нагружает).
