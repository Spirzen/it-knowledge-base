# 1.09. Чек-лист самопроверки

	- [ ] Что такое информация?
	- [ ] Что такое данные?
	- [ ] Что такое бит и байт?
	- [ ] Сможете привести пример иерархической структуры?
	- [ ] Чем двоичная структура отличается от ключ-значения?
	- [ ] Сможете привести пример линейной структуры?
	- [ ] Что такое булево значение?
	- [ ] Какие бывают виды информации?
	- [ ] Из чего состоит таблица?
	- [ ] Сколько бит в одном байте?
	- [ ] Какие типы данных вы запомнили?
	- [ ] Чем символ отличается от строки?
