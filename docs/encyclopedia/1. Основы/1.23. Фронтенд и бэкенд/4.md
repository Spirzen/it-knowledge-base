# 1.23. Чек-лист самопроверки

	- Что вам интереснее – фронтенд или бэкенд?
	- Знаете ли основы HTML, CSS и JavaScript?
	- Понимаете ли работу DOM и особенности браузерного рендеринга?
	- Умеете работать с современными фреймворками (React, Vue.js, Angular)?
	- Знаете принципы адаптивной и кроссбраузерной верстки?
	- Понимаете основы UX/UI дизайна?
	- Владеете хотя бы одним серверным языком (C#, Java, Python и др.)?
	- Знаете основные фреймворки для бэкенда (.NET, Spring Boot, Django и др.)?
	- Понимаете работу с базами данных (SQL, NoSQL)?
	- Разбираетесь в создании и работе API (REST, GraphQL)?
	- Знаете основы безопасности (аутентификация, авторизация)?
	- Понимаете принципы масштабирования и оптимизации?
