## Аббревиатуры и сокращения в IT

| Аббревиатура | Расшифровка | Определение |
|--------------|-------------|-------------|
| A/B Testing | A/B Testing | Метод сравнения двух версий (A и B) для определения лучшей по целевым метрикам. |
| ACID | Atomicity, Consistency, Isolation, Durability | Атомарность, Согласованность, Изоляция, Долговечность — свойства транзакций БД. |
| ACL | Access Control List | Список контроля доступа (кто и что может делать с файлом/ресурсом). |
| AD | Active Directory | Служба каталогов Microsoft для управления пользователями и правами в сети. |
| ADR | Architectural Decision Record | Документ, фиксирующий важное архитектурное решение и его причины. |
| Agile | (англ. "гибкий") | Методология разработки. |
| AI | Artificial Intelligence | Искусственный интеллект. |
| AJAX | Asynchronous JavaScript and XML | Технология асинхронных запросов к серверу без перезагрузки страницы (теперь чаще JSON, чем XML). |
| AKF | AKF Scale | Модель масштабирования (X, Y, Z — копирование, сервисы, шардирование данных). |
| ALB | Application Load Balancer | Балансировщик на уровне приложений (L7) в AWS. |
| AMQP | Advanced Message Queuing Protocol | Протокол очередей сообщений (используется в RabbitMQ). |
| API | Application Programming Interface | Интерфейс для взаимодействия программ. |
| APM | Application Performance Monitoring | Мониторинг производительности приложений (трассировка, метрики, алерты). |
| APT | Advanced Package Tool | Менеджер пакетов в Debian/Ubuntu (apt-get, apt). |
| AR | Augmented Reality | Дополненная реальность. |
| ARP | Address Resolution Protocol | Протокол для получения MAC-адреса по IP-адресу в локальной сети. |
| ASCII | American Standard Code for Information Interchange | Кодировка символов (7 бит). |
| AWS | Amazon Web Services | Крупнейшая облачная платформа от Amazon. |
| BASE | Basically Available, Soft state, Eventual consistency | Модель согласованности в NoSQL БД (вместо ACID — доступность и согласованность в итоге). |
| BDD | Behavior-Driven Development | Разработка через поведение (описание поведения системы на естественном языке). |
| BIOS | Basic Input/Output System | Фирменное ПО для управления «железом» (устаревает, заменяется UEFI). |
| BLOB | Binary Large Object | Бинарные данные большого объёма (изображения, видео, файлы в БД). |
| BPMN | Business Process Model and Notation | Система условных обозначений и их описания в XML для моделирования бизнес-процессов. |
| CAP | Consistency, Availability, Partition tolerance | Теорема CAP: в распределённой системе можно гарантировать только два из трёх свойств. |
| CAS | Compare-And-Swap | Атомарная операция сравнения и замены значения в памяти (lock-free алгоритмы). |
| CASCADE | CASCADE | Каскадное удаление/обновление связанных записей в БД (ON DELETE CASCADE). |
| CCPA | California Consumer Privacy Act | Калифорнийский закон о защите данных потребителей (аналог GDPR в США). |
| CD | Continuous Delivery/Deployment | Непрерывная поставка/развёртывание. Delivery — с ручным подтверждением, Deployment — без. |
| CDN | Content Delivery Network | Сеть доставки контента (ускоряет загрузку статики). |
| CI | Continuous Integration | Непрерывная интеграция. Автоматическая сборка и тестирование кода после каждого коммита. |
| CLI | Command-Line Interface | Интерфейс командной строки (терминал, консоль). |
| CMS | Content Management System | Система управления контентом (WordPress, Bitrix). |
| CMYK | Cyan, Magenta, Yellow, Key (Black) | Цветовая модель для печати (смешение красок). |
| CQRS | Command Query Responsibility Segregation | Разделение операций на команды (изменение) и запросы (чтение) в разные модели. |
| CRTP | Curiously Recurring Template Pattern | Паттерн в C++, где базовый класс принимает наследника как параметр шаблона. |
| CRM | Customer Relationship Management | Управление взаимоотношениями с клиентами (система для продаж). |
| CRUD | Create, Read, Update, Delete | Базовые операции с данными — создание, чтение, обновление и удаление. |
| CSRF | Cross-Site Request Forgery | Межсайтовая подделка запроса — атака, заставляющая пользователя выполнять действия без его ведома. |
| CSS | Cascading Style Sheets | Язык стилей для оформления HTML-документов. |
| CSV | Comma-Separated Values | Текстовый формат табличных данных (значения разделены запятыми). |
| CTA | Call To Action | Элемент интерфейса, побуждающий к действию (кнопка «Купить», «Подписаться»). |
| CTE | Common Table Expression | Временное именованное подзапросное выражение в SQL (WITH ... AS). |
| DAG | Directed Acyclic Graph | Направленный ациклический граф (граф зависимостей задач в CI/CD, Spark). |
| DAO | Data Access Object | Объект для доступа к данным — паттерн, разделяющий бизнес-логику и работу с БД. |
| DBA | Database Administrator | Администратор баз данных. |
| DBMS | Database Management System | Система управления базами данных (MySQL, PostgreSQL, Oracle). |
| DCL | Data Control Language | Подмножество SQL для управления правами (GRANT, REVOKE). |
| DDD | Domain-Driven Design | Домен-ориентированное проектирование. Код отражает бизнес-логику через единый язык. |
| DDL | Data Definition Language | Подмножество SQL для определения структуры БД (CREATE, ALTER, DROP). |
| DDoS | Distributed Denial of Service | Распределённая атака типа «отказ в обслуживании» (тысячи запросов с разных IP). |
| DevOps | Development + Operations | Культура взаимодействия разработчиков и админов (автоматизация, CI/CD, мониторинг). |
| DML | Data Manipulation Language | Подмножество SQL для манипуляции данными (INSERT, UPDATE, DELETE). |
| DNS | Domain Name System | Система преобразования доменных имён в IP-адреса. |
| Docker | от "dock worker" (докер) | Платформа контейнеризации (упаковка приложений в изолированные контейнеры). |
| DOM | Document Object Model | Объектная модель документа. Интерфейс для доступа к HTML/XML из скриптов. |
| DRY | Don’t Repeat Yourself | Принцип избегания дублирования (выносить общее в отдельные функции и классы). |
| DTO | Data Transfer Object | Объект для передачи данных между слоями/сервисами (без логики, только поля + геттеры). |
| E2E | End-to-End | Сквозное тестирование (полный сценарий от UI до БД). |
| ECS | Entity Component System | Архитектурный паттерн для игр: Entity — ID, Component — данные, System — логика. |
| EDA | Event-Driven Architecture | Событийно-ориентированная архитектура (сервисы общаются через события). |
| ELB | Elastic Load Balancer | Эластичный балансировщик нагрузки от AWS. |
| Elasticsearch | Elastic + Search | Поисковая система на основе Lucene (полнотекстовый поиск, аналитика логов). |
| ELK | Elasticsearch, Logstash, Kibana | Стек для сбора, обработки и визуализации логов. |
| EOL | End of Life | Конец жизненного цикла (продукт больше не поддерживается). |
| ERD | Entity-Relationship Diagram | Диаграмма «сущность-связь» — модель данных для описания концептуальных схем. |
| ERP | Enterprise Resource Planning | Планирование ресурсов предприятия (1С, SAP). |
| ETL | Extract, Transform, Load | Процесс «извлечь — преобразовать — загрузить» для data warehousing. |
| FIFO | First In, First Out | Принцип очереди: первый пришёл — первый ушёл. |
| FP | Functional Programming | Функциональное программирование (чистые функции, иммутабельность, лямбды). |
| FQDN | Fully Qualified Domain Name | Полное имя домена (например, `mail.example.com.` с точкой в конце). |
| FSM | Finite-State Machine | Конечный автомат — модель с состояниями и переходами между ними. |
| FTP | File Transfer Protocol | Протокол передачи файлов (устаревает, заменяется SFTP/FTPS). |
| FUD | Fear, Uncertainty, Doubt | Страх, неопределённость, сомнение — тактика для отпугивания от конкурентов. |
| GC | Garbage Collector | Сборщик мусора (автоматическое управление памятью в Java, C#, Go, JS). |
| GCP | Google Cloud Platform | Облачная платформа Google. |
| GDPR | General Data Protection Regulation | Общий регламент защиты данных ЕС — закон о приватности и правах пользователей. |
| GIF | Graphics Interchange Format | Формат анимированных изображений (8 бит на пиксель). |
| GIL | Global Interpreter Lock | Глобальная блокировка интерпретатора (в Python — ограничение на многопоточность CPU). |
| Git | (от англ. "git" – мерзавец) | Система контроля версий (распределённая, создана Линусом Торвальдсом). |
| GKE | Google Kubernetes Engine | Управляемый Kubernetes от Google Cloud. |
| GPG | GNU Privacy Guard | Криптографическая система для шифрования и подписей (альтернатива PGP). |
| gRPC | gRPC Remote Procedure Calls | Высокопроизводительный RPC-фреймворк от Google (Protocol Buffers, HTTP/2). |
| GUI | Graphical User Interface | Графический интерфейс пользователя (окна, кнопки, мышь). |
| HATEOAS | Hypermedia As The Engine Of Application State | Принцип REST: сервер передаёт клиенту ссылки на возможные действия. |
| HCI | Human-Computer Interaction | Взаимодействие человека и компьютера (эргономика интерфейсов). |
| HDD | Hard Disk Drive | Жёсткий магнитный диск (традиционный накопитель на вращающихся пластинах). |
| HLL | HyperLogLog | Алгоритм приблизительного подсчёта уникальных элементов (экономия памяти). |
| HMI | Human-Machine Interface | Интерфейс человек-машина (панели управления, приборы, киоски). |
| HSM | Hardware Security Module | Аппаратный модуль безопасности для хранения ключей шифрования. |
| HTML | HyperText Markup Language | Язык разметки веб-страниц (структура, заголовки, параграфы). |
| HTTP | HyperText Transfer Protocol | Протокол передачи данных в вебе (запрос-ответ). |
| HTTPS | HTTP Secure | HTTP с шифрованием (SSL/TLS) — безопасная версия. |
| HTTP/2 | HTTP version 2 | Вторая версия HTTP (мультиплексирование, сжатие заголовков, server push). |
| HTTP/3 | HTTP version 3 | Третья версия HTTP (на основе QUIC вместо TCP, быстрее и надёжнее). |
| i18n | Internationalization | Интернационализация (18 букв между I и n) — адаптация под разные языки и регионы. |
| IaaS | Infrastructure as a Service | Инфраструктура как услуга (аренда серверов, дисков, сети в облаке). |
| IAM | Identity and Access Management | Управление идентификацией и доступом (пользователи, роли, политики). |
| IANA | Internet Assigned Numbers Authority | Организация, управляющая корневыми DNS-серверами и портами. |
| ICMP | Internet Control Message Protocol | Протокол управления ошибками и диагностики сети (ping работает на нём). |
| IDE | Integrated Development Environment | Интегрированная среда разработки (VS Code, IntelliJ, PyCharm). |
| IDL | Interface Definition Language | Язык описания интерфейсов для удалённого вызова (gRPC, CORBA, Thrift). |
| IETF | Internet Engineering Task Force | Организация, разрабатывающая интернет-стандарты (RFC). |
| IIoT | Industrial Internet of Things | Промышленный интернет вещей (заводы, датчики, автоматизация). |
| IK | Inverse Kinematics | Обратная кинематика — расчёт позы по положению конечности (роботы, игры). |
| IoC | Inversion of Control | Инверсия управления — фреймворк сам вызывает ваш код (DI — частный случай). |
| IoT | Internet of Things | Интернет вещей (умные лампочки, датчики, холодильники с Wi-Fi). |
| IP | Internet Protocol | Протокол маршрутизации (основа интернета, отвечает за адресацию). |
| IPA | International Phonetic Alphabet | Международный фонетический алфавит (для транскрипции произношения). |
| IPC | Inter-Process Communication | Межпроцессное взаимодействие (сокеты, pipes, shared memory, сигналы). |
| IR | Intermediate Representation | Промежуточное представление (LLVM IR, байткод JVM, C# IL). |
| IRR | Internal Rate of Return | Внутренняя норма доходности (финансовый показатель для оценки инвестиций). |
| ISO | International Organization for Standardization | Международная организация по стандартизации (ISO 9001, ISO 27001). |
| ISP | Internet Service Provider | Интернет-провайдер (Ростелеком, МТС, Beeline). |
| JDK | Java Development Kit | Пакет для разработки на Java (компилятор javac, JVM, библиотеки). |
| JIRA | (от "Gojira" – Годзилла) | Система управления проектами (задачи, баги, спринты) от Atlassian. |
| JIT | Just-In-Time | Компиляция «на лету» (байткод → машинный код во время выполнения). |
| JPA | Java Persistence API | Спецификация для объектно-реляционного отображения (ORM) в Java/Hibernate. |
| JPEG | Joint Photographic Experts Group | Формат сжатия изображений (потеря качества, но сильное сжатие). |
| JRE | Java Runtime Environment | Среда выполнения Java (JVM + стандартные библиотеки, без компилятора). |
| JS | JavaScript | Язык программирования для веба (работает в браузере и на сервере через Node.js). |
| JSON | JavaScript Object Notation | Формат обмена данными (ключ-значение, читаемый человеком). |
| JVM | Java Virtual Machine | Виртуальная машина Java (исполняет байткод, управляет памятью). |
| JWT | JSON Web Token | Компактный токен для аутентификации (содержит данные и подпись). |
| Kanban | (яп. "канбан" – сигнальная карта) | Метод управления задачами с визуальной доской и лимитом WIP. |
| KISS | Keep It Simple, Stupid | Принцип простоты (пиши максимально просто и понятно, не усложняй). |
| KPI | Key Performance Indicator | Ключевые показатели эффективности (скорость загрузки, конверсия, uptime). |
| Kubernetes | K8s (от "helmsman" – рулевой) | Оркестратор контейнеров (управляет контейнерами Docker в кластере). |
| LAN | Local Area Network | Локальная вычислительная сеть (офис, дом, школа — внутри одного здания). |
| LIFO | Last In, First Out | Принцип стека: последний пришёл — первый ушёл. |
| LLM | Large Language Model | Большая языковая модель (GPT, Llama, Gemini, Claude). |
| LOL | Laughing Out Loud | Громко смеюсь (часто в чатах разработчиков в комментариях к коммитам). |
| LTS | Long-Term Support | Долгосрочная поддержка (версии Node.js, Java, Ubuntu с длительным сопровождением). |
| MBR | Master Boot Record | Главная загрузочная запись (устаревший способ загрузки ОС, заменён UEFI). |
| MIME | Multipurpose Internet Mail Extensions | Расширения для передачи не-текстовых данных по email (Content-Type). |
| MITM | Man-in-the-Middle | Атака «человек посередине» (перехват трафика между клиентом и сервером). |
| ML | Machine Learning | Машинное обучение (компьютер учится на данных без явных правил). |
| MLOps | Machine Learning + Operations | DevOps для ML-моделей (обучение, деплой, мониторинг, версионирование). |
| MongoDB | от "humongous" (огромный) + DB | Документо-ориентированная NoSQL БД (хранит JSON-подобные документы). |
| MPP | Massively Parallel Processing | Массово-параллельная обработка (Greenplum, Redshift, ClickHouse). |
| MR | Merge Request | Запрос на слияние (аналог Pull Request в GitLab). |
| MSA | Microservice Architecture | Микросервисная архитектура (приложение разбито на маленькие независимые сервисы). |
| MTBF | Mean Time Between Failures | Среднее время между отказами (показатель надёжности оборудования). |
| MTTR | Mean Time To Recovery | Среднее время восстановления после сбоя (чем меньше, тем лучше). |
| MVC | Model-View-Controller | Паттерн проектирования: Model (данные), View (отображение), Controller (логика). |
| MVP | Minimum Viable Product | Минимально жизнеспособный продукт (с минимальными фичами для запуска). |
| MVVM | Model-View-ViewModel | Паттерн для UI: Model (данные), View (интерфейс), ViewModel (связующий слой с биндингом). |
| MVT | Minimum Viable Testable | Минимальный тестируемый продукт (используется в TDD и экспериментах). |
| MySQL | My (имя дочери автора) + SQL | Популярная реляционная СУБД (используется в вебе). |
| NACK | Negative Acknowledgement | Отрицательное подтверждение — пакет получен с ошибкой, повторите. |
| NAT | Network Address Translation | Трансляция сетевых адресов (роутер выдаёт локальные IP за одним внешним). |
| NFV | Network Function Virtualization | Виртуализация сетевых функций (файрволлы, балансировщики как софт). |
| Nginx | Engine X | Высокопроизводительный веб-сервер и reverse-proxy. |
| NIO | Non-blocking I/O | Неблокирующий ввод-вывод (Java NIO, Netty) — один поток на много соединений. |
| NIST | National Institute of Standards and Technology | Американский институт стандартов (разрабатывает криптостандарты). |
| NLP | Natural Language Processing | Обработка естественного языка (токенизация, распознавание сущностей). |
| NLU | Natural Language Understanding | Понимание естественного языка (подзадача NLP, например, извлечение сущностей). |
| NPM | Node Package Manager | Менеджер пакетов для Node.js (команда `npm install`, огромный реестр библиотек). |
| NPS | Net Promoter Score | Метрика лояльности клиентов («порекомендуете ли вы нас?» от 0 до 10). |
| NS | Namespace | Пространство имён (в Kubernetes, Linux, C++ — для изоляции или группировки). |
| NTFS | New Technology File System | Файловая система Windows (по умолчанию для системных дисков). |
| NTP | Network Time Protocol | Протокол синхронизации времени по сети (точные часы на серверах). |
| OAuth | Open Authorization | Протокол авторизации (дай приложению доступ без пароля). |
| OAuth2 | Open Authorization 2.0 | Версия 2.0 протокола OAuth (с токенами, refresh-токенами). |
| OIDC | OpenID Connect | Надстройка над OAuth2 для аутентификации пользователей (узнать, кто вошёл). |
| OKR | Objectives and Key Results | Система постановки целей (главная цель + измеримые ключевые результаты). |
| OOM | Out-Of-Memory | Ошибка «не хватает памяти» (часто встречается в алертах Kubernetes). |
| OOP | Object-Oriented Programming | Объектно-ориентированное программирование (инкапсуляция, наследование, полиморфизм). |
| OPA | Open Policy Agent | Механизм авторизации как код (политики в Rego для K8s, Docker, Envoy). |
| ORM | Object-Relational Mapping | Технология связи ООП и БД (таблицы → классы, строки → объекты). |
| OTLP | OpenTelemetry Protocol | Протокол для отправки трейсов, метрик и логов в OpenTelemetry. |
| P2P | Peer-to-Peer | Равный-равному — пиринговые сети (торренты, блокчейн, мессенджеры). |
| PaaS | Platform as a Service | Платформа как услуга (облачная среда с БД, очередями, рантаймом). |
