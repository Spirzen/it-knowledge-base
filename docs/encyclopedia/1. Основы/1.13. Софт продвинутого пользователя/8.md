# 1.13. Виртуализация и работа с ОС

## Виртуализация и работа с ОС

Виртуализация позволяет запускать несколько операционных систем на одном компьютере, что полезно для тестирования программ и разработки. Существуют программные решения для создания виртуальных машин (ВМ). 

Контейнеризация приложений - сложная тема, мы её обсудим отдельно. 

В части операционной системы, особенно касаясь установки, нельзя пройти мимо инструментов для создания загрузочных USB-накопителей, что необходимо знать. Всё это - программы для оптимизации рабочего процесса и экспериментов с различными средами без риска повредить основную систему. 

Можно установить виртуальную машину на свою основую систему без риска её повреждения.

- VirtualBox / VMware Workstation / Hyper-V – запуск виртуальных машин;
- Docker – контейнеризация приложений для разработки и деплоя;
- Rufus – создание загрузочных USB для установки ОС.
