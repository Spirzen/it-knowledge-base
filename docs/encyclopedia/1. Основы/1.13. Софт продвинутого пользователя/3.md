## Разработка и программирование

Для разработчиков часто есть выбор правильного инструмента, с учётом привычек и используемых технологий. VS Code сталодним из самых популярных редакторов благодаря своей лёгкости, поддержке множества языков программирования и расширений. Однако расширения требуют ресурсов, а в части ресурсов полегче может быть Notepad++ - отлично подходит для работы с большими текстовыми файлами, такими как логи и дампы. Но это лишь редакторы текста, которые лишь оснащены автодополнением и подсветкой синтаксиса. 

Для полноценной разработки используют IDE - интегрированные среды разработки, которые предоставляют все необходимые инструменты для создания сложных проектов. Можно выделить и СУБД, которые позволяют работать с базами данных через графический интерфейс, но мы отдельно изучим это всё - и СУБД, и IDE. Сейчас просто приведём примеры такого софта:

- VS Code (Visual Studio Code) – лёгкий, мощный редактор кода от Microsoft, поддерживает кучу языков и расширений (Python, JavaScript, C++);
- Notepad++ - улучшенный блокнот с подсветкой синтаксиса, позволяет работать даже с большими файлами, логами, дампами;
- Visual Studio – IDE (интегрированная среда разработки) для C#;
- NetBeans – IDE для Java;
- DB Browser for SQLite – графический интерфейс для работы с базами SQLite.
