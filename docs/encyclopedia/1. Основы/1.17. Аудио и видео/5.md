# 1.17. Редактирование

# Раздел в разработке

## Редактирование аудио

Редактирование аудио — это процесс обработки исходных данных для создания готового продукта. Нормализация, например, увеличивает громкость до максимального уровня без искажений, а эквалайзер позволяет настроить частотный баланс.

Основные операции:
	- Обрезка, склейка (Audacity, Adobe Audition);
	- Нормализация громкости;
	- Удаление шумов;
	- Наложение эффектов (реверберация, эквалайзер).

Программы
	- Профессиональные: Pro Tools, Ableton Live (для музыки);
	- Для начинающих: Audacity, GarageBand.

## Редактирование видео

При монтаже видео основные операции связаны с составляющими элементами видео, их последовательностью и визуалом. 

Цветокоррекция позволяет улучшить визуальное восприятие, корректируя яркость, контраст и цветовой баланс. Эффекты позволяют улучшить динамику и эстетику видео.

Основные операции:
	- Монтаж клипов (резка, переходы);
	- Цветокоррекция (LUTs, кривые);
	- Добавление эффектов (стабилизация, slow motion);
	- Работа со слоями (титры, маски).

Программы
	- Профессиональные: Adobe Premiere Pro, DaVinci Resolve;
	- Для начинающих: Shotcut, iMovie.
