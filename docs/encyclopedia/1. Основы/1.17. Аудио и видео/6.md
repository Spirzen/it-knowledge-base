# 1.17. Разбор форматов

# Раздел в разработке

## Разбор форматов

**Видеоформаты**
	- AVI (Audio Video Interleave) – универсальный формат, без стандартизации сжатия, с поддержкой множества кодеков (DivX, XviD, H.264). Используется для фильмов, обычно размер до 2 ГБ.
		- MPEG (Moving Picture Experts Group) – семейство стандартов:
		- MPEG-1 (VCD-качество, 352x240);
		- MPEG-2 (DVD, цифровое ТВ);
		- MPEG-4 (современные форматы, включая MP4) – универсальный контейнер, включающий видео, аудио, субтитры, поддерживается даже в потоковом вещании (YouTube).
	- MKV (Matroska Video) – универсальный медиаконтейнер, с отсылкой к матрёшкам – по аналогии с вложенными друг в друга элементами.

**Аудиоформаты**
	- MP3 (MPEG-1 Audio Layer III) – используется для музыки, обладает битрейтом от 32 до 320 кбит/с, отбрасывает «неслышимые» частоты, за счёт чего происходит сжатие с потерями, оптимальное для сети и обмена музыкой. Структура включает ID3v2 заголовок (метаданные), сжатые аудиоданные и ID3v1 тег (дополнительные метаданные).
	- WAV (Waveform Audio File Format) – несжатый, или слабо сжатый формат аудио с отличным качеством, но огромным размером (1 минута может быть более 10 МБ), с качеством CD: 1411 кбит/с. Используется в профессиональной аудиозаписи.
	- WMA (Windows Media Audio) – формат сжатия с небольшими потерями, более лучшее качество, чем MP3 при том же битрейте.
	- AMR (Adaptive Multi-Rate) – формат с сильным сжатием, оптимизированный для речи. Низкий битрейт (4.75 – 12.2 кбит/с), ужасное качество, но подходит для голосовых записей и звонков.
	- M4A (MPEG-4 Audio) – аудиоверсия MP4, альтернатива MP3 с лучшим качеством, поддержкой обложек и метаданных.

**Прочие форматы медиа**
	- SWF (Small Web Format) – устаревший формат для Flash-анимации, векторная анимация+интерактивность, поддержка прекращена в 2020 году.
	- PPT, PPTX, PPS, PPSX, POT, POTX (PowerPoint) – формат презентаций, представляет собой ZIP-архив с XML (PPTX), содержащий слайды, аудио, видео и текст.
