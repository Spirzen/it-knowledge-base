# 1.16. Работа с файлами. Графика

# Раздел в разработке

★ **Графика** – визуальное представление данных, от простых иконок до сложных 3D-сцен. В компьютерах она делится на двумерную (2D) и трёхмерную (3D), а также на растровую и векторную. Разберёмся, чем они отличаются и где применяются.

## 2D и 3D

★ **2D-графика** – плоские изображения, имеющие только ширину и высоту (X и Y). Примеры – фотографии, иконки, интерфейсы, рисунки в графических редакторах (Photoshop, Paint), 2D-анимация (мультфильмы, аниме, мультяшная графика в играх – Cuphead, платформерах старой школы, допустим, эпохи NES/Dendy). В двумерной графике используются пиксели (растр) или математические кривые (вектор).

★ **3D-графика** – объекты, имеющие дополнительную, третью, Z-ось – глубину, а также обладает объёмом и перспективой. Примеры – видеоигры, кино, архитектурные визуализации. Трёхмерная графика создаётся посредством трёх составляющих:

	- *моделирование* – создание 3D-объектов (кубы, сферы, сложные формы);
	- *текстурирование* – наложение изображение на модель;
	- *освещение и рендеринг* – расчёт лучей света, теней, отражений, отрисовка итогового изображения.

Разница 2D и 3D

| Характеристика | 2D | 3D |
| :--- | :---: | ---: |
|Измерения	|X, Y	|X, Y, Z
|Объём	|Нет	|Есть
|Примеры	|Фото, иконки, интерфейсы	|Игры, CGI-анимация, VR/AR, кино, видеоигры

***В разработке***
Моделирование — создание 3D-объектов (Blender, Maya, 3ds Max).

Трансформации — перемещение, вращение, масштабирование (матрицы 4x4).

Проекция — переход от 3D к 2D (перспективная, ортогональная).

Рендеринг — расчёт цвета пикселей (растеризация, ray tracing).

Шейдеры — программы, управляющие отображением (vertex, fragment, compute).

API: OpenGL, Vulkan, DirectX, Metal, WebGL.

## Вектор и растр

★ **Растровая графика** состоит из пикселей (точек), и чем больше пикселей – тем выше качество (разрешение). Подходит для фотореалистичных изображений, однако при увеличении изображения теряет качество (видна «пикселизация), а размер файлов очень большой. К примеру, фотография в формате JPEG – это сетка из миллионов пикселей.

***В разработке***

Изображение = сетка пикселей (bitmap).

альфа-канал, сжатие.

***В разработке***

★ **Векторная графика** состоит из математических формул, точек, линий и фигур, имеющих координаты. И поскольку фактически такое изображение – просто набор координат точек, полигонов и линий – программы сами «дорисовывают» изображение, из-за чего масштабировать можно без потери качества, и размер файла маленький (если нет сложных эффектов). К примеру, это будет набор формул, описывающих контуры.

***В разработке***

Изображение = математические примитивы (линии, кривые, фигуры).

## Растровые форматы

*BMP (Bitmap)* – один из самых старых форматов, хранит изображения без сжатия (или с минимальным RLE-сжатием). Не теряет качество, но обладает огромным размером файла. Крайне неоптимальный формат, которым редко пользуются.

*JPG / JPEG (Joint Photographic Experts Group)* – формат с потерями для фотографий, отличается хорошим регулируемым сжатием. Самый распространенный формат для изображений в интернете.

*PNG (Portable Network Graphics)* – формат без потерь с поддержкой прозрачности (альфа-канал), имеющий чёткие контуры, используется в скриншотах, веб-графике и логотипах.

*GIF (Graphics Interchange Format)* – поддерживает анимацию и прозрачность, но только 256 цветов, и подойдёт лишь для простой графики с анимацией и мемами.

*TGA (TARGA)* – формат для хранения растровых изображений с альфа-каналом (поддержкой прозрачности), используется для текстур в играх и рендеров.

*TIF / TIFF (Tagged Image File Format)* – гибкий формат без потерь, поддерживает слои, сжатие (LZW, ZIP), используется для сканирования документов, полиграфии, отличается высоким качеством и большим размером.

*PSD (Photoshop Document)* – внутренний формат Adobe Photoshop, сохраняет слои, маски, эффекты, поддерживает сложные проекты.

## Векторные форматы

*SVG (Scalable Vector Graphics)* – векторный формат на основе XML, масштабируется без потерь, обладает маленький размер, открывается даже текстовым редактором, используется для логотипов, иконок, веб-графики.

*ICO (Icon)* – формат для иконок в Windows, может содержать несколько размеров в одном файле. Используется для иконок программ и «фавиконок» сайтов (значков страниц).

*VSD, VSDX, VSS, VSTX (Visio)* – форматы Microsoft Visio для диаграмм, схем, блок-схем, с поддержкой сложных векторных объектов, однако требуется Visio.

*DWG (Drawing)* – собственный бинарный формат AutoCAD, основной для хранения чертежей, применимых в архитектуре, машиностроении, строительстве.

*DXF (Drawing Exchange Format)* – текстовый/бинарный формат для обмена данными между CAD-системами, для экспорта/импорта между разными САПР (системы автоматизированного проектирования).

## Географические форматы

*GeoJSON* – JSON-формат для хранения географических данных (точки, линии, полигоны). Используется в веб-картах (OpenStreetMap, Leaflet).

*GML (Geography Markup Language)* – XML-формат для географических данных, используется в ГИС (геоинформационных системах) вроде QGIS, ArcGIS.

*IDF (Intermediate Data Format)* – формат обмена векторными данными, используется в географических системах (ГИС «ИнГео»), проектировании, CAD/CAM системах.

*MIF/MID (MapInfo Interchange Format)* – используется в программе MapInfo для хранения векторных геоданных, MIF хранит геометрию (координаты объектов), MID хранит атрибутивную информацию (табличные данные).

*SHP (Shapefile)* – стандартный формат ESRI (разработчик ArcGIS) для хранения векторных данных, состоит из набора файлов:

	- SHP – геометрия;
	- SHX – индекс геометрии;
	- DBF – атрибуты;
	- PRJ – система координат;
	- CPG – кодировка атрибутов.

*GeoPackage (CPKG)* – современная альтернатива Shapefile на основе SQLite.

*KML/KMZ (Keyhole Markup Language)* – формат для Google Earth с XML-структурой и поддержкой 3D-объектов.
