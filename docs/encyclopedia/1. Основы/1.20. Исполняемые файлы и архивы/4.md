# 1.20. Специализированные форматы

## Специализированные форматы

|Формат	|Описание|
| :--- | :---: |
|.BIN	|Бинарные данные (образы, прошивки), содержат сырые данные, которые могут быть прочитаны только специальными программами.
|.DB	|Файл базы данных, хранят структурированные данные.
|.SQL	|Скрипт базы данных, содержит команды для создания таблиц, вставки данных и выполнения иных запросов.
|.SIG	|Цифровая подпись файла для проверки целостности и подлинности.
|.TMP	|Временный файл
|.BAK	|Резервная копия
|.OVERRIDE	|Файл переопределения настроек
