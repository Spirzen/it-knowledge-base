## Конфигурационные файлы

Конфигурационные файлы — это текстовые файлы, которые содержат настройки программы. Они позволяют адаптировать программу под конкретные задачи без изменения её кода.

| Формат | Описание | Пример |
| :--- | :---: | ---: |
|.CONF	|Конфигурация Linux-сервисов	|nginx.conf
|.CFG	|Конфигурации программ	|config.cfg
|.YML / .YAML	|Конфигурация для Docker / Kubernetes. Они требуют строгого соблюдения формата, так как даже лишний пробел может привести к ошибке.	|docker-compose.yml
|.REG	|Файл реестра Windows. Будьте осторожны с ними, так как они могут повредить систему, если содержат ошибки.	|settings.reg
|.ASPX	|Конфигурация ASP.NET	|Web.aspx
