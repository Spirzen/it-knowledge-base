## Зачем эта статья

**Клиентская Windows** (10, 11) — массовая ОС на ноутбуках и ПК в офисах и дома. **Windows Server** — другая линейка: роли AD, DNS, лицензии по ядрам — см. [63](./63) и [настройку серверов](./4.md).

Пошаговая установка, UEFI и Rufus — в [главе 2](./2). Культурные шутки про "переустанови Windows" — в [131](/encyclopedia/9-spinoff/9-10-internet-kultura/131), не вместо runbook.

## Данные и разделы — контраст с Linux

На Windows пользовательские файлы по умолчанию живут в **`C:\Users\<имя>`** вместе с профилем, `AppData` и реестром. Отдельного "домашнего раздела", как **`/home`** в Linux, обычно нет — поэтому [переустановка с форматированием диска C:](/glossary/П#переустановка-windows) без бэкапа часто означает потерю документов.

| Подход | Windows (типично) | Linux (типично) |
|--------|-------------------|-----------------|
| Система | Один том `C:` или раздел EFI + C: | `/` на отдельном разделе |
| Пользователь | `C:\Users\...` | `/home/<user>` |
| Сохранить данные при переустановке | Бэкап на внешний носитель / облако | Часто достаточно не трогать раздел `/home` — [93](./93) |
| Метаданные ОС | Реестр, SID | Файлы в `/etc`, домашние dotfiles |

<div class="callout callout--warning">
  <div class="callout-title">"Сохранить личные файлы" в установщике</div>

  <div class="callout-body">
  Режим *Keep personal files* в установщике Windows не заменяет полноценный бэкап: часть настроек и `AppData` сбрасывается, повреждённые файлы могут не перенестись. Перед [чистой установкой](/glossary/Ч#чистая-установка) копируйте важное вне диска C: — см. [2 — резервное копирование](./2#как-установить-операционную-систему).

## Активация и лицензия

После установки Windows нужна **легальная лицензия**:

- **OEM** — ключ вшит в UEFI ноутбука или готового ПК; при смене материнской платы активация может слететь.
- **Цифровая лицензия** — привязка к учётной записи Microsoft; повторная активация на том же железе часто проходит автоматически.
- **Корпоративная** (VL, KMS) — через IT-отдел, не "ключ с форума".

Установка с официального образа Microsoft возможна **без ключа** на этапе setup; ограничения неактивированной системы — водяной знак, ограничение персонализации. "Сборки" с торрентов несут риск вредоносного ПО и непредсказуемых обновлений — в мемах это высмеивают, в эксплуатации это инцидент безопасности.

## Диагностика перед переустановкой

Когда система ещё загружается, имеет смысл пройти официальный путь восстановления:

```cmd
sfc /scannow
DISM /Online /Cleanup-Image /RestoreHealth
```

Команды проверяют и подменяют повреждённые системные файлы из хранилища компонентов. Они **не заменяют** антивирусную зачистку rootkit и не убирают годы "мусора" в реестре — поэтому в рунете шутку "сначала перезагрузи, потом переустанови" ставят рядом с реальным опытом, когда repair install не помогает.

Полный разбор команд — в конце [главы 2](./2#проверка-целостности-системы). Культура формулы — [131](/encyclopedia/9-spinoff/9-10-internet-kultura/131), [Неолурк](https://neolurk.org/wiki/%D0%9F%D0%B5%D1%80%D0%B5%D1%83%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BA%D0%B0_Windows).
