## Зачем эта статья

Теория — в [основах сети](./1.md), [DNS](./6.md) и [протоколах](./4.md). Здесь — **практика на своём устройстве**: где в системе лежат настройки подключения, что в них можно изменить без командной строки и когда одних «центров управления сетью» уже недостаточно.

Рекомендуемый маршрут после этой страницы:

1. [Ускорение интернета](./220.md) — если канал медленный или нестабильный.
2. [Сетевые и системные диагностические утилиты](./505.md) — `ping`, Wireshark, PuTTY и аналоги.
3. [Приватность, self-hosting и домашняя сеть](./404.md) — VPN, свои сервисы, DNS и бэкапы.

## Два уровня работы с сетью

| Уровень | Что это | Примеры |
| :--- | :--- | :--- |
| **Настройки ОС** | Графические центры: Wi‑Fi, Ethernet, VPN, точка доступа | «Параметры → Сеть», «Системные настройки → Сеть» |
| **Инструменты** | Утилиты, скрипты, анализаторы, фаерволы | `ping`, Wireshark, `ufw`, PowerShell |

Сначала почти всегда достаточно **настроек системы**. К утилитам переходят, когда нужно понять *почему* не открывается сайт, *куда* уходит трафик или *как* безопасно подключиться к домашнему серверу.

## Windows

### Где открыть

| Задача | Путь |
| :--- | :--- |
| Основной центр | **Параметры** (`Win + I`) → **Сеть и интернет** |
| Классические адаптеры | `Win + R` → `ncpa.cpl` — список интерфейсов, «Свойства», IPv4/DNS |
| Быстрый статус | Панель задач → значок сети → имя Wi‑Fi / Ethernet |
| Диагностика | **Параметры → Сеть и интернет → Дополнительные параметры сети → Сброс сети** |
| Драйверы | **Диспетчер устройств → Сетевые адаптеры** |

Подробнее про свойства адаптера, виртуальные NIC и VPN-интерфейсы — в [настройках сетевых адаптеров Windows](./620.md).

### Что настраивают

| Раздел в «Сеть и интернет» | Назначение |
| :--- | :--- |
| **Wi‑Fi** | Подключение к точке доступа, «Забыть сеть», известные сети, случайный MAC (приватность) |
| **Ethernet** | Кабельное подключение, профиль сети (частный / общедоступный) |
| **VPN** | Встроенные профили (IKEv2, L2TP и др.); WireGuard/OpenVPN — отдельные клиенты |
| **Мобильный хот-спот** | Раздача интернета с ПК по Wi‑Fi или Bluetooth (см. ниже) |
| **Прокси** | Ручной или автоматический прокси для приложений |
| **DNS** | В профиле адаптера (IPv4) или через «Назначение DNS-сервера» в параметрах |

**Режим «В самолёте»** — **Центр уведомлений** (`Win + A`) или **Параметры → Сеть и интернет → Режим «В самолёте»**. Отключает Wi‑Fi, Bluetooth (опционально) и сотовую связь на ноутбуках с LTE-модулем. Полезен в самолёте и когда нужно быстро оборвать все беспроводные каналы.

## macOS

### Где открыть

| Задача | Путь |
| :--- | :--- |
| Основной центр | **Системные настройки** (или **Системные параметры** в новых версиях) → **Сеть** |
| Меню статуса | Значок Wi‑Fi / Ethernet в строке меню |
| Расширенно | В «Сеть» → **Подробнее…** / **Дополнительно** — TCP/IP, DNS, прокси, аппаратный адрес |
| Bluetooth | **Системные настройки → Bluetooth** (отдельно от Wi‑Fi, но часто рядом в быстрых переключателях) |

### Что настраивают

- **Wi‑Fi** — сеть, пароль, «Автоматически подключаться», диагностика беспроводной сети.
- **Ethernet / USB‑адаптер** — DHCP или статический IP, DNS.
- **VPN** — встроенные типы (L2TP, IKEv2); сторонние клиенты добавляют свой интерфейс в список.
- **Общий доступ** — **Системные настройки → Общий доступ** → «Общий интернет»: раздача с Ethernet на Wi‑Fi или наоборот (аналог хот-спота).
- **Режим «В самолёте»** — **Центр управления** (иконка в меню) или **Системные настройки → Режим «В самолёте»**; отключает радиомодули по выбору.

На iPhone/iPad с macOS Ventura+ часть сетевых опций синхронизируется через iCloud; на Mac остаётся отдельный центр «Сеть».

## Linux (рабочий стол)

Дистрибутивы различаются, но логика одна: **NetworkManager** (большинство Ubuntu, Fedora, Debian с GNOME/KDE) или **systemd-networkd** / **netplan** на серверах.

### Где открыть (типичный GNOME)

| Задача | Путь |
| :--- | :--- |
| Графика | **Параметры → Сеть** или значок в верхней панели |
| Детали Wi‑Fi / Ethernet | Клик по подключению → шестерёнка → IPv4, DNS, маршруты |
| Терминал (NetworkManager) | `nmcli connection show`, `nmtui` (TUI) |
| Файлы (продвинуто) | `/etc/NetworkManager/system-connections/`, **netplan** в `/etc/netplan/` (Ubuntu Server) |

### Что настраивают

- **Wi‑Fi / Ethernet** — DHCP, статический IP, DNS, MTU.
- **VPN** — импорт OpenVPN/WireGuard в NetworkManager или `wg-quick` / `openvpn`.
- **Точка доступа (hotspot)** — в GNOME: **Параметры → Сеть → Wi‑Fi → ⋮ → Включить точку доступа** (если адаптер поддерживает AP-режим).
- **Режим «В самолёте»** — в GNOME/KDE переключатель **Режим полёта** в быстрых настройках; эквивалент `rfkill block wifi`.

На сервере без GUI сеть чаще правят через `nmcli`, netplan или `/etc/network/interfaces` — см. [системное администрирование](/encyclopedia/2-system-network/2-06-sistemnoe-administrirovanie/6).

## iOS (iPhone, iPad)

### Где открыть

**Настройки** — главный центр; быстрые переключатели — **Пункт управления** (свайп сверху справа).

| Раздел | Назначение |
| :--- | :--- |
| **Wi‑Fi** | Сеть, пароль, «Забыть эту сеть», Настройка DNS (вручную), Низкорежимный режим данных |
| **Сотовая связь** | Мобильный интернет, роуминг, eSIM |
| **Bluetooth** | Подключение наушников, авто, аксессуаров (не заменяет Wi‑Fi для интернета) |
| **VPN** | Профили из приложений (WireGuard, корпоративный клиент) |
| **Режим «В самолёте»** | В «Настройках» или Пункте управления — отключает сотовую, Wi‑Fi и Bluetooth (Wi‑Fi/Bluetooth можно включить обратно отдельно) |
| **Режим модема** | **Настройки → Режим модема** — раздача LTE/5G по Wi‑Fi, USB или Bluetooth |

**Персональная точка доступа** (Personal Hotspot) — раздача мобильного интернета другим устройствам. Требует тариф с разрешённым tethering; пароль Wi‑Fi задаётся в настройках точки доступа.

## Android

### Где открыть

**Настройки**; быстрые плитки — шторка уведомлений.

| Раздел (названия могут отличаться) | Назначение |
| :--- | :--- |
| **Сеть и интернет** / **Подключения** | Wi‑Fi, мобильная сеть, SIM, VPN |
| **Wi‑Fi** | Сеть, частный DNS, MAC-адрес устройства |
| **Точка доступа и модем** | Раздача интернета по Wi‑Fi, USB, Bluetooth |
| **Bluetooth** | Отдельный раздел настроек |
| **VPN** | Встроенный клиент + приложения |
| **Режим «В самолёте»** | Плитка или **Настройки → Сеть** — отключает радиомодули |

На Samsung, Xiaomi и др. пункты могут называться иначе («Подключения», «Мобильная сеть»), но набор возможностей тот же.

## Общие понятия

### Точка доступа и «общий интернет»

| Термин | Суть |
| :--- | :--- |
| **Точка доступа (hotspot)** | Устройство раздаёт **свой** канал (обычно мобильный или Ethernet) по Wi‑Fi другим клиентам. Телефон становится мини-роутером. |
| **Общий доступ к интернету (ICS)** | На Windows/macOS — один интерфейс (например Ethernet) «делится» на другой (Wi‑Fi). Аналог хот-спота на ПК. |
| **Режим модема** | На iOS/Android — синоним раздачи сотового интернета; на ПК часто через USB-модем или привязку телефона. |

Ограничения: оператор может запрещать tethering; батарея на телефоне разряжается быстрее; NAT на телефоне усложняет входящие подключения к раздаваемым клиентам.

### Режим «В самолёте»

Отключает **радиопередатчики** (сотовая связь, Wi‑Fi, Bluetooth — в зависимости от ОС и настроек). Не влияет на Ethernet по кабелю на ноутбуке. После посадки Wi‑Fi и Bluetooth обычно включают вручную.

### Параметры адаптера и «свойства сети»

На **Windows** в `ncpa.cpl` → **Свойства** адаптера:

- **IPv4** — IP вручную или DHCP, маска, шлюз, DNS;
- **IPv6** — аналогично;
- компоненты (клиент Microsoft Networks, QoS, драйверы VPN).

На **macOS** — вкладки TCP/IP, DNS, прокси в «Сеть → Подробнее».

На **Linux** — те же поля в GUI NetworkManager или в конфигах.

Теория IP, маски и шлюза — [основы IP-адресации](./41.md); DHCP и DNS — [DNS](./6.md).

### VPN в настройках ОС

Встроенный раздел VPN хранит **профили**: сервер, тип туннеля, учётные данные. Клиенты WireGuard/OpenVPN часто добавляют виртуальный адаптер и свой пункт в списке сетей. Протоколы и безопасность — [статья про VPN](./613.md).

### Bluetooth и «сеть»

Bluetooth — **не замена Wi‑Fi** для интернета в быту, кроме режима модема (телефон → ПК по BT). Используется для периферии и иногда низкоскоростного PAN. Подробнее — [беспроводные сети](./71.md).

## Когда настроек ОС недостаточно

Типичные ситуации:

| Симптом | Следующий шаг |
| :--- | :--- |
| «Интернет тормозит» | [Ускорение интернета](./220.md) |
| «Сайт не открывается, ping странный» | [Диагностические утилиты](./505.md) |
| «Хочу свой Nextcloud / VPN домой» | [Приватность и self-hosting](./404.md) |
| Нужна теория (TCP, HTTP, DNS) | [Маршрут раздела](./intro.md) |

На практике приходится использовать **специальные инструменты**:

- **Утилиты и скрипты** — `ping`, `tracert`/`traceroute`, `ipconfig`/`ip`, `curl`, PowerShell `Test-NetConnection`;
- **Анализаторы** — Wireshark, `tcpdump` — кто с кем говорит и на каком порту;
- **Фаерволы** — Windows Defender Firewall, `ufw`, `iptables`/nftables — какие порты открыты наружу;
- **Мониторинг** — `mtr`, Netdata, логи роутера;
- **Удалённый доступ** — SSH (PuTTY, `ssh`), RDP — администрирование серверов и [Home Lab](/encyclopedia/2-system-network/2-06-sistemnoe-administrirovanie/10).

Один «центр сети» в ОС не покажет маршрут пакета до сервера в другой стране и не заменит захват трафика при отладке API.
