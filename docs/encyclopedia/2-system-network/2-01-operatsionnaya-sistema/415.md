## Что такое Windows 11

Windows 11 — отдельный продукт на том же **ядре NT**, что и Windows 10 (версия `10.0`, build **≥ 22000**). Главные отличия для пользователя:

- перерисованный интерфейс — полупрозрачные окна, закруглённые углы, **центр панели задач** (можно вернуть выравнивание влево);
- **меню Пуск** без живых плиток — закреплённые приложения, рекомендации, список "Все приложения";
- **Snap Layouts** и **Snap Groups** — быстрая расстановка окон на больших мониторах;
- **виджеты** и лента новостей (нужна учётная запись Microsoft);
- **Internet Explorer удалён** — браузер по умолчанию **Microsoft Edge** на Chromium;
- жёстче **аппаратные требования** — UEFI, Secure Boot, **TPM 2.0** (подробнее — [платформы / 312](../2-02-platformy/312.md));
- бесплатное обновление с лицензионной Windows 10 при совместимом железе.

Поддержка Android-приложений (Amazon Appstore), **Copilot**, вкладки в Проводнике и DirectStorage — функции более поздних обновлений; базовая логика работы системы от этого не меняется.

## Системные требования и редакции

| Компонент | Официальный минимум | Практическая рекомендация |
|-----------|---------------------|---------------------------|
| Процессор | 64-bit, ≥ 2 ядра, ≥ 1 ГГц, PAE/NX/SSE2 | Intel 8-го поколения+ / Ryzen 2000+ (см. список Microsoft) |
| ОЗУ | 4 ГБ | 8 ГБ и выше для комфортной работы |
| Диск | 64 ГБ (Win10 требовала 20 ГБ) | SSD, запас под обновления |
| Графика | DirectX 12, WDDM 2.x | — |
| Прошивка | UEFI, Secure Boot | TPM 2.0 |

**Редакции** при чистой установке — Home, Home Single Language, Pro, Pro Education, Education, Pro for Workstations. Корпоративные Enterprise/IoT поставляются через каналы VL.

Проверка совместимости:

```powershell
Get-ComputerInfo | Select-Object OsName, OsBuildNumber, WindowsVersion
tpm.msc
Confirm-SecureBootUEFI
```

## Установка и первый запуск

Общая схема установки ОС — [2.06 / установка](../2-06-sistemnoe-administrirovanie/2.md). Ниже — особенности именно Windows 11.

### Подготовка

- Скачайте ISO через [Media Creation Tool](https://www.microsoft.com/software-download/windows11) или официальный ISO.
- Запишите флешку **Rufus** (режим GPT + UEFI) или используйте Media Creation Tool напрямую.
- На **виртуальной машине** (VMware, Hyper-V) укажите тип гостя "Windows 10/11 64-bit", выделите ≥ 4 ГБ RAM и включите TPM в настройках ВМ (Hyper-V Generation 2, VMware virtual TPM).
- Не ставьте экспериментальную систему поверх единственной копии данных без бэкапа.

### Мастер установки

1. Язык установки → **Установить** → при отсутствии ключа — "У меня нет ключа продукта".
2. Выбор редакции → лицензия → **Выборочная: только установка Windows (для опытных пользователей)**.
3. Разметка диска — для чистой установки удалите старые разделы, оставьте "Нераспределённое пространство" (нужен **GPT**).
4. Копирование файлов и перезагрузки (~10–20 минут на SSD).
5. **OOBE** (Out-of-Box Experience) — страна, раскладки (можно две), сценарий "для личного использования" или "для работы/учёбы" (второй вариант — управление организацией).

### Учётная запись и конфиденциальность

- Microsoft предлагает вход в **учётную запись Microsoft**. Локальную учётную запись можно создать через "Автономная учётная запись" / "Sign in options" → "Offline account" (формулировки менялись между сборками).
- Альтернатива после установки: **Параметры → Учётные записи → Семья и другие пользователи**.
- На экране конфиденциальности отключите лишнюю телеметрию и рекламный ID, если они вам не нужны. Развёрнутый чек-лист — [настройка Windows](/encyclopedia/1-basics/1-035-bazovaya-informatika/207).

После входа — **Центр обновления Windows**, драйверы с сайта производителя ПК или GPU.

## Интерфейс

### Меню Пуск и панель задач

- Вверху — **закреплённые** (Pinned) приложения, внизу — **рекомендации** (недавние файлы и программы).
- **Все приложения** — полный алфавитный список; из контекстного меню можно открепить, удалить или закрепить на панели задач.
- **Win + X** — быстрое меню (Диспетчер устройств, Терминал, параметры).
- Выравнивание значков: **Параметры → Персонализация → Панель задач → Поведение панели задач** (слева / по центру).

### Поиск

Поиск на панели задач ищет файлы, приложения и (опционально) в интернете. Вкладка **More** фильтрует по почте, папкам, музыке, видео.

### Виртуальные рабочие столы

| Комбинация | Действие |
|------------|----------|
| `Win + Ctrl + D` | Новый рабочий стол |
| `Win + Ctrl + F4` | Закрыть текущий стол |
| `Win + Ctrl + ←/→` | Переключение между столами |
| `Win + Tab` | Обзор столов; перенос окна ПКМ по миниатюре |

Столы можно **переименовать** на панели обзора. При закрытии стола окна переносятся на соседний.

### Snap Layouts и группы окон

- Наведите курсор на кнопку **Развернуть** — сетка вариантов (2, 3 или 4 окна).
- Перетаскивание окна к краю или углу экрана — классический snap.
- **Snap Groups** — сохранённый набор окон; восстановление одним щелчком на панели задач (на больших мониторах).

### Виджеты

Кнопка виджетов на панели задач открывает боковую панель (погода, новости, курс валют). Для полноценной работы нужна **учётная запись Microsoft**. Управление лентой — через меню "…" → интересы.

### Диспетчер задач и Game Bar

- **Ctrl + Shift + Esc** — Диспетчер задач. На вкладке **Производительность** для дисков показывается тип **HDD/SSD**; для части GPU — температура.
- **Win + G** — игровая панель (Xbox Game Bar) — FPS, запись клипа (**Capture**), оверлей друзей.
- **Win + Alt + R** — начать/остановить запись последних 30 секунд (настраивается).

### Скриншоты и голосовой ввод

| Способ | Результат |
|--------|-----------|
| `PrtSc` | Весь экран в буфер обмена |
| `Alt + PrtSc` | Активное окно |
| `Win + Shift + S` | Область экрана (Snipping Tool) |
| `Win + H` | Голосовой ввод (языки зависят от сборки) |

### Панель уведомлений и быстрые действия

Кнопка в правом углу панели задач открывает **центр уведомлений** и плитки:

- геолокация;
- ночной свет;
- Focus assist;
- VPN;
- проекция на второй экран;
- **Screen snip**.

### Режим "Бога" (God Mode)

Создайте на рабочем столе папку с именем:

```text
GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}
```

Внутри — ярлыки ко многим оснасткам "Параметров" и "Панели управления" в одном окне.

## Стандартные приложения

Часть пакетов ставится при первом запуске из Microsoft Store. Основной набор "из коробки":

| Приложение | Назначение |
|------------|------------|
| Calculator | Калькулятор, режим Graphing |
| Calendar / Mail / To Do | Планирование и почта |
| Photos | Просмотр фото; встроенный **Video Editor** |
| Snipping Tool | Скриншоты (заменил отдельный "Ножницы") |
| Groove Music / Movies & TV | Локальная медиатека |
| Paint / Notepad / WordPad | Простое редактирование |
| Maps, Weather, News | Карты и лента (часто отключают) |
| Microsoft Store | UWP и win32 из магазина |
| Edge | Браузер по умолчанию |
| OneDrive | Синхронизация облака (5 ГБ бесплатно) |

**Удаление** лишних UWP — **Параметры → Приложения → Установленные приложения** или PowerShell (осторожно с зависимостями Store/Xbox):

```powershell
Get-AppxPackage *windowscommunicationsapps* | Remove-AppxPackage
```

Список provisioned-пакетов для образов — [Справочник по Windows 11](./41.md).

## Диск и файлы

### Очистка диска

- **cleanmgr** или **Параметры → Система → Память → Временные файлы** — удаление кэша обновлений, корзины, временных файлов.
- Вкладка **More options** — очистка точек восстановления (кроме последней).

### Storage Sense

**Параметры → Система → Память → Контроль памяти** — автоматическое удаление временных файлов и содержимого корзины по расписанию. Полезно на ноутбуках с малым SSD.

### Несколько разделов на USB-накопителе

В "Управлении дисками" (`diskmgmt.msc`) на флешке можно создать **несколько томов**, если носитель отформатирован как сменный диск. Для загрузочной флешки обычно один раздел FAT32/NTFS — см. [установку ОС](../2-06-sistemnoe-administrirovanie/2.md).

## Microsoft Edge

Edge в Windows 11 — Chromium-браузер; архитектура движков — [2.04 / 127](../2-04-kak-rabotayut-sayty-i-veb-sayty/127.md). Практические настройки:

| Задача | Где |
|--------|-----|
| Тема новой вкладки | **Параметры → Новая вкладка** |
| Блокировка трекеров | **Конфиденциальность → Предотвращение отслеживания** |
| SmartScreen | **Конфиденциальность → Безопасность Microsoft** |
| Поисковая система | **Конфиденциальность → Службы поиска** |
| Профили и синхронизация | Иконка профиля → **Manage profile settings** |
| PWA на панели задач | Меню "…" → **Apps → Install this site as an app** / Pin to taskbar |
| Импорт из Chrome/Firefox | **Параметры → Import browser data** |
| PDF | Встроенный просмотр; печать и аннотации в ридере Edge |
| Сброс | **Параметры → Reset settings** |

Внутренний диспетчер вкладок Edge: `Shift + Esc` в окне браузера (память по вкладкам).

## Параметры системы

### Обновления

**Параметры → Центр обновления Windows** — обязательные накопительные обновления и **необязательные** (optional updates): драйверы, исправления. Перед установкой драйверов из optional стоит проверить версию на сайте OEM.

### Защита

**Конфиденциальность и защита → Безопасность Windows**:

- **Защита на основе репутации** — блокировка неизвестных и нежелательных приложений;
- **Контролируемый доступ к папкам** (Controlled folder access) — защита Documents/Pictures от шифровальщиков; разрешённые приложения добавляются вручную;
- **Exploit protection** — mitigations для процессов (наследие EMET).

### Вход в систему

**Учётные записи → Параметры входа → Restart apps** — автоматически открывать приложения после перезагрузки. На слабом ПС (HDD, ≤ 8 ГБ RAM) параметр лучше **выключить**.

### Сеть

**Параметры → Сеть и Интернет → Состояние**:

- **Использование данных** — трафик по приложениям за 30 дней, лимит для тарификации;
- **Сброс сети** (Network reset) — сброс DNS-кэша, TCP/IP и переустановка адаптеров. Перед сбросом сохраните скриншоты статических IP/VPN.

**Лимит трафика** — **Wi‑Fi / Ethernet → свой адаптер → Лимит данных**.

Подробный разбор списка адаптеров (`ncpa.cpl`), IPv4/DHCP/DNS, профилей сети и пунктов «Дополнительно» — [Настройки сетевых адаптеров в Windows](/encyclopedia/2-system-network/2-03-set-i-internet/620).

### Персонализация

- **Текстовый курсор** — толщина и цвет в **Специальные возможности → Текстовый курсор**;
- **Папки в меню "Пуск"** — **Персонализация → Панель задач → Поведение** — отображение Downloads/Documents и т.д.

## Учётные записи

### Учётная запись Microsoft

Синхронизирует темы, пароли Edge, OneDrive, Microsoft Store. Управление — [account.microsoft.com](https://account.microsoft.com).

### Локальная учётная запись

**Параметры → Учётные записи → Семья и другие пользователи → Добавить пользователя** → "У меня нет данных для входа" → "Добавить пользователя без учётной записи Microsoft".

### Windows Hello

**Параметры → Учётные записи → Параметры входа** — PIN, отпечаток, распознавание лица, ключ FIDO/USB. PIN привязан к устройству и удобнее длинного пароля при краже только пароля учётной записи.

## Восстановление и производительность

### Среда восстановления (WinRE)

Вызов: **Параметры → Система → Восстановление** → "Перезагрузить сейчас", или загрузка с установочной флешки → **Восстановление системы**.

Меню **Поиск и устранение неисправностей → Дополнительные параметры**:

| Пункт | Назначение |
|-------|------------|
| Startup Repair | Автоматический ремонт загрузки |
| Startup Settings | Безопасный режим, отключение подписи драйверов |
| Command Prompt | `sfc`, `chkdsk`, `bootrec` |
| Uninstall Updates | Откат последнего KB |
| System Restore | Откат к точке восстановления |
| System Image Recovery | Восстановление из образа |

### Точки восстановления

**Параметры → Система → О системе → Защита системы** (или `sysdm.cpl` → **Защита системы**):

1. Включите защиту для системного диска.
2. **Max Usage** — по умолчанию ~3% диска; при частых экспериментах увеличьте до 5–10%.
3. **Создать** — ручная точка перед установкой драйвера или ПО.

### История файлов

<span id="istoriya-faylov"></span>

**Параметры → Конфиденциальность и защита → История файлов** (или "Панель управления → История файлов"). Нужен **внешний диск или отдельный раздел**. Новый диск — инициализация в `diskmgmt.msc` (GPT для ≥ 1 ТБ), **New Simple Volume**. Подробнее — [резервное копирование в домашней сети](../2-06-sistemnoe-administrirovanie/61.md).

### Ускорение работы

| Действие | Где |
|----------|-----|
| Автозагрузка | **Диспетчер задач → Автозагрузка** |
| Фоновые приложения | **Параметры → Приложения → Установленные приложения** → "Дополнительные параметры" |
| Схема питания | **Параметры → Система → Питание** → "Максимальная производительность" (если доступно) |
| Подсказки Windows | **Параметры → Система → Уведомления** |
| Место на диске | Storage Sense + cleanmgr |
| Дефрагментация | **Оптимизация дисков** — для **SSD** только TRIM, не классическая дефрагментация |
| Индексирование | Служба **Windows Search** — "Вручную", если поиском не пользуетесь |
| Визуальные эффекты | `sysdm.cpl` → **Дополнительно → Быстродействие → Параметры** |

Радикальная "очистка" системы и сравнение с Linux — [Сравнение Windows и Linux](./413.md). Безопасная первичная настройка — [Настройка Windows](/encyclopedia/1-basics/1-035-bazovaya-informatika/207).
