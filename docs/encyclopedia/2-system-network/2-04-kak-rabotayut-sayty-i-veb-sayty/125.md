## Интернет

**Интернет** (с большой буквы в русской традиции) — глобальная сеть сетей на базе IP и маршрутизации. Техника — [2.03 / 1](/encyclopedia/2-system-network/2-03-set-i-internet/1), история — [1.07](/encyclopedia/1-basics/1-07-nemnogo-o-proshlom/4).

В бытовой речи "интернет" часто означает **всё онлайн** — браузер, мессенджеры, игры. В споре на форуме фраза "интернет сломался" может означать DNS, провайдера, один сайт или Wi‑Fi — уточняйте уровень ([стек](/encyclopedia/2-system-network/2-03-set-i-internet/4)).

Культурный контекст рунета — [Форумная культура Рунета](/encyclopedia/9-spinoff/9-10-internet-kultura/120). Справочник — [Неолурк: Интернет](https://neolurk.org/wiki/%D0%98%D0%BD%D1%82%D0%B5%D1%80%D0%BD%D0%B5%D1%82).

## Сайт и веб-сайт

**Сайт** — ресурс с адресом (домен + пути), страницами и общей темой. Технически — файлы и ответы сервера, часто HTML — [Сайты и веб-сайты](./1).

| В культуре | В технике |
|------------|-----------|
| "зайти на сайт" | HTTP GET, DNS, TLS |
| "сайт лёг" | 5xx, таймаут, DDoS |
| "сайт на WordPress" | CMS, PHP, хостинг |

Форум, блог, соцсеть — **все сайты** (или веб-приложения), но **разные жанры** общения — [Мессенджер, соцсеть и блог — три формата общения](/encyclopedia/9-spinoff/9-10-internet-kultura/124).

Неолурк — [Интернет-сайт](https://neolurk.org/wiki/%D0%98%D0%BD%D1%82%D0%B5%D1%80%D0%BD%D0%B5%D1%82-%D1%81%D0%B0%D0%B9%D1%82), [Блог](https://neolurk.org/wiki/%D0%91%D0%BB%D0%BE%D0%B3).

## HTTP и HTTPS

**HTTP** — протокол запроса документа: метод (`GET`, `POST`), заголовки, код ответа (`200`, `404`, `500`). База — [2.09 / 118](/encyclopedia/2-system-network/2-09-osnovy-integratsionnogo-vzaimodeystviya/118), загрузка страницы — [2.03 / 5](/encyclopedia/2-system-network/2-03-set-i-internet/5).

**HTTPS** — HTTP поверх TLS (шифрование). Замок в адресной строке — [Адресная строка браузера](./11); разбор — [HTTPS и TLS — шифрование веба](./128).

На форумах "HTTP" в шутках иногда путают с "веб вообще"; в баг-репорте пишите конкретно: URL, метод, код, тело ответа.

Неолурк — [Http](https://neolurk.org/wiki/Http), [Https](https://neolurk.org/wiki/Https).

## URL, домен и "ссылка на тред"

**URL** — полный адрес ресурса. **Домен** — человекочитаемое имя (`example.com`), DNS переводит его в IP — [2.03 / 3](/encyclopedia/2-system-network/2-03-set-i-internet/3).

В мемах и чатах "кинь ссылку" = URL на [тред](/glossary/Т#тред), пост или картинку. Постоянный URL — основа **архива** форума и блога; в мессенджере сообщение уезжает в поток — [Мессенджер, соцсеть и блог — три формата общения](/encyclopedia/9-spinoff/9-10-internet-kultura/124).

## От протокола к мему (цепочка)

```text
Пользователь вводит URL
    → DNS, TCP, TLS, HTTP
        → HTML + картинки
            → браузер рисует страницу форума
                → пользователь пишет пост с [BB-кодом](./123)
                    → другие цитируют → мем / формула
```

Мемы и [лулз](/glossary/Л#лулз) не "живут в HTTP" — они живут в **контенте**, который HTTP доставляет. Эпоха [веб 2.0](/glossary/В#веб-20) и UGC ускорила копирование — [Веб 2.0 и эпоха пользовательского контента](/encyclopedia/9-spinoff/9-10-internet-kultura/130). Скорость и алгоритмы ленты влияют на **виральность** — [Мемы рунета — примеры и контекст](/encyclopedia/9-spinoff/9-10-internet-kultura/127), [Культурные артефакты и трансляция](/encyclopedia/9-spinoff/9-10-internet-kultura/116).
