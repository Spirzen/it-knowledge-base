## Мини-глоссарий

| Термин | Коротко |
| :--- | :--- |
| **БД** | Данные + правила их организации (схема). |
| **СУБД** | Программа, которая хранит БД, принимает запросы, обеспечивает целостность и доступ. |
| **Схема (концептуальная / логическая / физическая)** | От идеи предметной области до таблиц на диске. |
| **relation** | Отношение = таблица в модели Кодда ("реляционная" от этого слова). |
| **relationship** | Связь на ER-диаграмме; в SQL — FK и JOIN. |
| **schema в PostgreSQL** | Имя пространства имён (`CREATE SCHEMA`) — отдельно от "схемы данных" в общем смысле. |
