Локализацию добавляйте сразу в шаблон:
- `lang` — язык документа (`<html lang="ru">`);
- `dir` — направление текста для отдельных фрагментов (`dir="rtl"` для арабского/иврита);
- `translate="no"` — фрагменты, которые браузерный переводчик не должен менять (команды, имена брендов, артикулы).


Сейчас попробуйте сделать проект-калькулятор на HTML, базовый HTML-шаблон с полями для ввода чисел, кнопками операций (`+`, `-`, `*`, `/`, `=`) и полем для отображения результата:
	- для ввода чисел используйте `input type="number"`;
	- кнопки — `<button>`, создайте кнопки операций `+`, `-`, `*`, `/`, `=`;
	- поле результата — `<div>`;
	- контейнер для калькулятора сделайте как `<div class="calculator">`;
	- для обработки кликов используйте атрибут `onclick` на кнопках (логику напишете на JavaScript позже);
	- обратите внимание на идентификаторы и классы – мы предусмотрим их заранее;
	- можете добавить комментарии на свой вкус;
	- можете разбавить страницу своими тегами и элементами для тренировки.

Попробуйте изучить и разобрать код. Здесь вы можете найти:
- **Семантическую разметку** — `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<time>`, `<address>`, `<figure>`, `<figcaption>`.
- **Формы** — `<form>`, `<fieldset>`, `<legend>`, `<select>`, `<textarea>`; для почты и даты рядом в примере — `type="email"` и `type="date"` (встроенная проверка и нативный календарь без отдельного JS). Остальные типы `<input>` — в [основных тегах](./2.md#input-types); атрибуты валидации — `required`, `minlength`, `max`, `autocomplete`.
- **Таблицы** — `<table>`, `<caption>`, `<thead>`, `<tbody>`, `<th scope="col">`.
- **Мультимедиа** — `<img>`, `<audio>`, `<video>` с резервным контентом.
- **Интерактив** — `<details>`, `<summary>`, `<dialog>`, `<progress>`, `<meter>`.
- **Callout и `<details>` на живой странице** — см. ниже и в [основах HTML](./1.md#callout-i-details).
- **Доступность** — `aria-labelledby`, `alt`, `scope`, семантические заголовки.
- **Минимальный CSS**: только для читаемости и базового оформления.
- **Минимальный JS**: только вызов `showModal()` — всё остальное работает без скриптов.

### Callout и `<details>` — как это выглядит в статье

В шаблоне `demo.html` выше `<details>` уже есть в секции "Интерактивные элементы". В Markdown-статьях энциклопедии тот же приём плюс **callout** — цветные выноски на `<div>`.

<div class="callout callout--tip">
  <div class="callout-title">Практика</div>

  <div class="callout-body">
  В своём `demo.html` добавьте один callout (скопируйте разметку из [основ HTML](./1.md)) и второй блок `<details>` с ответом на вопрос по вашему калькулятору.
</div>
  </div>


<details>
  <summary>Зачем два разных приёма?</summary>
  <p><strong>Callout</strong> — сразу виден на странице (совет, предупреждение). <strong><code>&lt;details&gt;</code></strong> — по клику, когда текст длинный или второстепенный. Оба дополняют основной поток, а не заменяют заголовки и абзацы.</p>
</details>
