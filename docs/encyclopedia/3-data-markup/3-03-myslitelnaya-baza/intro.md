# О разделе

Раздел объединяет **как мы думаем** (когнитивистика), **какой математикой пользуется IT** (логика, дискретка, вероятность, информация) и **формальные границы вычислений** (ТАФЯ: автоматы, грамматики, Тьюринг). Материал можно читать выборочно; ниже — три типичных маршрута.

В ключевых статьях идеи сначала даются **человеческим псевдокодом** ("если … то", "для каждого", "множество A пересечь B"), затем — формулами и интерактивами. Так проще связать теорию с `if`, SQL и планированием задач.
