# О разделе

Рекомендуемая последовательность:

1. **Основа** — [Конфигурационные данные в текстовых форматах](./1.md), сравнение форматов, [секреты и `.env`](./1.md#konfigi-env-i-sekrety). По желанию до JSON/XML — [Текстовые форматы](./111.md) (кодировки, Unicode).
2. **Форматы обмена и настроек** — [XML](./2.md) → [JSON](./3.md) → [JSONB](./217.md) → [YAML](./4.md) → [TOML](./218.md) → [CSV](./219.md). Для UI на .NET — [XAML](./6.md). Чтение JSON на Python — [Lab / файлы и текст](/lab/Примеры/1126#6-json-в-файле).
3. **Контракты и API** — [JSON Schema, OpenAPI и Schema.org](./220.md) → [GraphQL](./221.md).
4. **Стек XML** — [XPath](./213.md) → [XSLT](./214.md) → [XML DOM](./215.md). Справочники — [XML](./211.md), [XSLT](./212.md).
5. **Документация (не конфиг)** — [Markdown](./5.md).
6. **Бинарная и колоночная сериализация** — [MessagePack, Protobuf…](./216.md) → [Parquet и ORC](./222.md).
7. **Смежно** — [Шрифты](./113.md), [эмодзи](./112.md).
8. **Закрепление** — [Итоги](./98.md), [чек-лист](./99.md).
