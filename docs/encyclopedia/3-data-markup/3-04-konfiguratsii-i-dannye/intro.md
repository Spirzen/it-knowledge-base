# О разделе

Рекомендуемая последовательность:

1. **Основа:** [Конфигурационные данные в текстовых форматах](./1.md) — зачем конфиги, сравнение форматов, секреты. По желанию до JSON/XML: [Текстовые форматы представления данных](./111.md) (кодировки, Unicode).
2. **Форматы обмена и настроек:** [XML](./2.md) → [JSON](./3.md) → [YAML](./4.md) (в т.ч. для Docker Compose — [готовые стеки](/lab/Примеры/11111)). Для UI на .NET — [XAML](./6.md) (разметка, не файл настроек); закрепить синтаксис на готовых окнах — [C# WinForms и WPF (Lab)](/lab/Примеры/1138). Чтение и запись JSON-файла на Python — [1126 — файлы и текст](/lab/Примеры/1126#6-json-в-файле). Обзор экосистемы XML (история SGML/HTML, приложения DocBook, жизненный цикл документа) — в главе [XML](./2.md).
3. **Стек XML:** [XPath](./213.md) → [XSLT](./214.md) → [XML DOM](./215.md). Справочники: [XML](./211.md), [XSLT](./212.md).
4. **Документация (не конфиг):** [Markdown](./5.md) — README, статьи энциклопедии; для настроек приложения используйте JSON/YAML из п. 2.
5. **Бинарная сериализация:** [MessagePack, BSON, Protobuf, CBOR](./216.md).
6. **Смежно:** [Шрифты](./113.md), [эмодзи в тексте](./112.md) — как символы отображаются в UI и логах.
7. **Закрепление:** [Итоги](./98.md), [чек-лист самопроверки](./99.md).
