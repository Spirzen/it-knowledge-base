## Definition of Ready

- Минимальный порог **входа** в работу: ценность, **AC**, зависимости, макеты, API.
- Без DoR — уточнения, срыв спринта, боль в [удалёнке](/encyclopedia/7-project/7-23-udalennaya-komanda/1).
- В [Scrum](/encyclopedia/7-project/7-14-scrum/intro) — в спринт только ready items; в [Kanban](/encyclopedia/7-project/7-18-kanban/intro) — политика колонки Ready.
- Живёт в **шаблоне тикета** [трекера](/encyclopedia/7-project/7-09-bazy-znaniy-i-zadachniki/21), не только Confluence.

---

## Definition of Done

- Общий барьер **качества** до Done: review, CI, stage, docs, observability.
- **Уровни:** задача → спринт/stage → релиз/prod.
- **Web:** PR, tests, stage, API wiki, metrics.
- **Mobile:** + TestFlight/internal, min OS, store texts, **flags** для rollback.
- **Enforcement:** CI, branch protection, release checklist — не плакат ([методология FAQ](/encyclopedia/7-project/7-03-metodologiya-i-zhiznennyy-tsikl-po/998)).

[Тестирование](/encyclopedia/7-project/7-05-testirovanie/intro) · [культура кода](/encyclopedia/7-project/7-10-kultura-koda/intro).

## Release notes

- Язык **пользователя**, не git log.
- Блоки: новое, исправлено, breaking, ограничения, админы.
- Аудитории: user, support L1, DevOps, API consumers.
- Черновик **до** prod; [ИИ](/encyclopedia/7-project/7-24-ii-v-proektnom-protsesse/1) — только с факт-чеком.
- При **gradual rollout** — честно о флаге и сегментах.

[Техписьмо](/encyclopedia/7-project/7-08-tehnicheskoe-pismo/intro).

---

## Feature flags

- **Gradual rollout:** internal → 5% → … → 100% → удалить legacy.
- **Kill switch:** первый шаг runbook при [инциденте](/encyclopedia/7-project/7-21-incidenty-i-ekspluatatsiya/1).
- Типы: release, ops, permission, experiment — **разные** флаги.
- **LaunchDarkly** / Unleash — targeting, audit; MVP — осторожно с env-only.
- **Flag debt** — удалять по дате; реестр в wiki.

## Типичные ошибки

- DoR/DoD только на wiki — **не проверяют** в workflow.
- DoD = "код написан" — нет stage/tests.
- Release notes после prod или "misc fixes".
- Флаги без kill switch drill и без плана удаления.
- Mobile big bang без remote flags.
