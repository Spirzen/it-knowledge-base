## Быстрые ориентиры (если застряли на вопросе)

<details>
<summary>1–8: определения</summary>

Два смысла: старый/чужой контекст vs нет автотестов. Управляемое = предсказуемое. Критическое = нет исходников, связанность, нет истории. Техдолг растёт, если правки без тестов и без фиксации знаний.

</details>

<details>
<summary>15–21: тесты и рефакторинг</summary>

Characterization фиксирует «как сейчас». Seam — точка подмены. Mikado — граф мелких разрывов зависимостей. Flaky ломает доверие к CI.

</details>

<details>
<summary>23–27: стратегии</summary>

Strangler переключает трафик по частям. ACL переводит чужие модели. Clean room пишет новое без чтения старых исходников. Rewrite — при тупике стека, лицензии, потере знаний, недостижимости целей иначе.

</details>
