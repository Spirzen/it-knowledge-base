## Модели договора

| Модель | Суть |
|--------|------|
| **Fix price** | Фиксированная цена; нужны детальные оценки и резерв на риски |
| **T&M** | Оплата по факту; оценка на весь проект ориентировочная, детализация по ближайшим спринтам/этапам |
| **Смешанная** | Разные блоки по-разному |

## Точность оценок по фазам

| Тип | Когда | Типичный разброс |
|-----|-------|------------------|
| Грубый порядок (ROM) | Идея проекта | −25 % … +75 % |
| Порядок величины | Инициация, первое КП | уточняется |
| Бюджетная | После обследования | −10 % … +25 % |
| Точная (definitive) | Перед разработкой | −5 % … +10 % |

Оценка строится по **ИСР (WBS)** — каждая работа получает трудозатраты и срок, затем календарный план с учётом параллелизма. Три разработчика по 40 часов — **120 человеко-часов**, но не обязательно 120 календарных часов.

<div class="callout callout--info">
  <div class="callout-title">Мифический человеко-час</div>

  <div class="callout-body">
  Линейное деление «человеко-часы / 8» игнорирует совещания, ожидания, согласования и риски. На ERP-проектах календарь почти всегда длиннее суммы «чистых» часов.

</div>
