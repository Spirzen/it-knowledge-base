# О разделе

**База знаний** — единое место, где команда хранит инструкции, решения инцидентов и онбординг, чтобы не отвечать на одни и те же вопросы в чате. Раздел про инструменты (Confluence, Wiki), структуру статей, связь с [техподдержкой](/encyclopedia/2-system-network/2-07-tehnicheskaya-podderzhka/intro) и качество контента. Отдельно — задачники и тренажёры, если они есть в подборке.
