## CAPSLOCK — крик или акцент

В текстовых каналах **нет интонации**. Заглавные буквы исторически заменяли **крик и срочность**: в IRC, ранних форумах и почте без форматирования CAPS был единственным способом выделить слово.

| Сигнал | Как часто читают в работе | Более безопасная альтернатива |
|--------|---------------------------|-------------------------------|
| ВСЁ СООБЩЕНИЕ КАПСОМ | давление, злость | обычный регистр + "нужен ответ до 18:00" |
| Одно слово КАПСОМ | сильный акцент | **жирный** в markdown или "важно:" в начале строки |
| "СРОЧНО!!!" в теме | спам, паника | приоритет в тикете, пинг дежурного по регламенту |

<div class="callout callout--tip">
  <div class="callout-title">Исключения</div>

  <div class="callout-body">
  Аббревиатуры (API, SQL, RFC) и оформление по стандарту (HTTP, GET) — норма. Капс как **системный** сигнал (лог `ERROR`) в цитате лога тоже уместен.
  </div>
</div>

## T9 и "случайные" слова

**T9** (predictive text на цифровых клавиатах телефонов 2000-х) давал **ошибки-соседи**: "привет" превращался в "привег", "щас" писали намеренно как разговорный маркер.

Сегодня автозамена на смартфоне — преемник T9. Эффекты те же:

- случайная отправка до проверки;
- "коррекция" термина в обычное слово (`kubectl` → что-то бытовое);
- смешение языков в одном сообщении.

В **рабочем** чате одна опечатка — норма; поток обрывистых "слов-призраков" без пояснения читается как невнимательность. Правило: перед отправкой в канал с руководством или клиентом — **дочитать**; для срочного инцидента — короткая структура из [главы 1](./1) (контекст, факт, просьба).

Карточка — [глоссарий: T9](/glossary/T#t9).

## Форумные сигналы в мессенджере

Привычки с форумов и рунетских тредов переносят в Slack или Telegram:

| Приём | Откуда | Риск в работе |
|-------|--------|----------------|
| "сабж: …" | заголовок треда | ок в техническом чате своих; странно для заказчика |
| [лулз](/glossary/Л#лулз), "кек" | ирония своих | непонятно или неуместно вне команды |
| [ИМХО](/glossary/И#имхо) | смягчение мнения | допустимо между равными |
| [RTFM](/glossary/R#rtfm) | "читай доку" | звучит грубо; лучше ссылка на раздел доки |
| Мем-цитата без контекста | шибболет | исключает новичка и смежные роли |

Ориентир из [Цифровая коммуникация](./1): **контексто-зависимость**. Внутри команды можно договориться о тёплом сленге; в тикете для смежного отдела — нейтральный язык и явные ссылки.

## Сленг разработчика в чате

В IT-чатах смешиваются **профессиональный** жаргон ([1.06 / 1](/encyclopedia/1-basics/1-06-sleng/1)) и **форумный** слой ([1.06 / 2](/encyclopedia/1-basics/1-06-sleng/2), [Форумная культура Рунета](/encyclopedia/9-spinoff/9-10-internet-kultura/120)). Ниже — частые слова, которые слышит новичок в Telegram или Discord команды.

| Слово | Обычный смысл в чате | В работе лучше |
|-------|----------------------|----------------|
| [Запилить](/glossary/З#запилить) / [выпилить](/glossary/В#выпилить) | добавить / убрать (фичу, файл, строку) | "добавлю PR", "удалю ветку" |
| [Костыль](/glossary/К#костыль) | временный обход без "правильного" решения | "workaround до релиза 2.1" |
| Прод / стейдж / дев | окружения | те же термины, но с именем сервиса |
| "Залить на прод" | выкатить в production | "деплой в prod", ссылка на пайплайн |
| [RTFM](/glossary/R#rtfm) | "сначала документация" | ссылка на раздел docs или RFC |
| [Быдлокодер](/glossary/Б#быдлокодер) | ярлык за "плохой" код | конкретика в ревью по стандарту |
| [Хеллоуворлдщик](/glossary/Х#хеллоуворлдщик) | новичок с учебными примерами | стажёр, junior |
| [Олдфаг](/glossary/О#олдфаг) | давно в теме / на площадке | "работаю с X с 2018" |
| [Матан](/glossary/М#матан) | шутка про сложную теорию | "нужна статистика / линейная алгебра" |
| "Стек оверфло" | часто — сайт [Stack Overflow](https://stackoverflow.com/), не ошибка переполнения стека | уточнить: "нашёл ответ на SO" |

## Срочность без капса

Вместо "СРОЧНО ПОСМОТРИТЕ" в продакшен-канале:

1. **Канал** — тот, где дежурный по регламенту (не общий "болталка").
2. **Факт** — сервис, ошибка, время начала, `trace-id`.
3. **Ожидание** — "нужен откат" / "нужна оценка за 30 мин".
4. **Пинг** — `@oncall` или роль, если так принято, один раз.

Так сообщение остаётся срочным по содержанию, а не по объёму заглавных букв.

## Чек-лист перед отправкой

- Сообщение читается без капса и без "!!!"?
- Термины и имена сервисов написаны верно (автозамена не подменила)?
- Адресат поймёт [сабж](/glossary/С#сабж) без форумной шапки?
- Для иронии и мема аудитория "своя"?
