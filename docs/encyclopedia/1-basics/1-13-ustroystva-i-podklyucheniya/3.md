# Звуковое оборудование и видеокамеры

<div class="article-tags">

  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>

<span class="complexity-badge">Всем</span>

Звук и видео нужны для созвонов, записи и развлечений. Большинство проблем «не слышу» / «меня не слышат» / «чёрный экран в Zoom» — не поломка железа, а **не то устройство по умолчанию** или доступ программы.

---

## Звук: ввод и вывод

Звуковая подсистема ОС разделяет:

| Направление | Устройство | Пример использования |
|-------------|------------|----------------------|
| **Вывод (playback)** | Колонки, наушники, HDMI на TV | Музыка, системные звуки |
| **Ввод (recording)** | Микрофон, линия входа | Звонок, диктовка |

★ **Устройство по умолчанию** — куда ОС отправляет звук и откуда записывает, если программа не выбрала другое явно.

Программа (Zoom, браузер) может переопределить микрофон в **своих** настройках — тогда системная «галочка» не поможет, пока не проверите оба места.

Инженерный обзор — [Аудиооборудование (1.08/715)](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/715).

## Микрофон и наушники

| Тип | Подключение | Заметки |
|-----|-------------|---------|
| **Проводные наушники 3.5 mm** | Разъём combo или раздельные | На ноутбуке один разъём — TRRS |
| **USB-гарнитура** | USB | Отдельный звуковой «чип» внутри |
| **Bluetooth-наушники** | BT | Может быть профиль только для музыки без микрофона в звонке |
| **Встроенный микрофон ноутбука** | Внутри | Удобен, но ловит шум клавиатуры |

**Шумоподавление** бывает аппаратным (гарнитура) и программным (Zoom, Teams, Krisp). Для созвонов лучше **близкий** микрофон и наушники, чтобы не было эха из колонок.

## Видеокамера

★ **Веб-камера** — камера для видеосвязи и записи; встроена в ноутбук или подключается по USB.

| Аспект | Пояснение |
|--------|-----------|
| **Разрешение** | 720p достаточно для звонков; 1080p — для записи |
| **Индикатор** | Светодиод при активной камере — сигнал конфиденциальности |
| **Права доступа** | ОС и браузер спрашивают разрешение; без него — чёрный экран |
| **Несколько камер** | Встроенная + внешняя — выбор в настройках приложения |

Практика видеосвязи — [1.035/304](/encyclopedia/1-basics/1-035-bazovaya-informatika/304). Заклеивать камеру — личная привычка; программно доступ всё равно контролируется разрешениями ОС.

## Типовые проблемы

### «Нет звука»

1. Проверить **громкость** и не mute ли канал в микшере (Windows: значок динамика → громкость приложений).
2. Выбрать правильное **устройство вывода** (случайно переключилось на HDMI без мониторов).
3. Переподключить **USB/BT**-гарнитуру; перезапустить приложение.
4. Обновить **драйвер** звука (Диспетчер устройств) — [глава 7](./7).

### «Меня не слышат»

1. Устройство **записи** по умолчанию и в приложении.
2. Разрешение **микрофона** в настройках конфиденциальности ОС.
3. Не играет ли звук в **колонки**, а вы говорите в микрофон ноутбука с закрытой крышкой.

### «Камера не работает»

1. Разрешение **камеры** для приложения.
2. Не занята ли камера **другой** программой.
3. В ноутбуке — сочетание Fn, отключающее камеру (редко).
