## Работа с Excel

### Что такое Microsoft Excel?

**Microsoft Excel** — табличный процессор из пакета Microsoft Office. Он хранит данные в **ячейках** на **листах**, пересчитывает **формулы** при изменении исходных значений и помогает быстро отфильтровать, отсортировать или показать данные на **диаграмме**.

В IT Excel часто встречается раньше «настоящих» инструментов данных: чек-листы тестирования, реестры требований, черновые отчёты, импорт через CSV. Подробнее про формат файла — в [Формат XLSX](./4.md); полный справочник функций — в [41.md](./41); разведочный анализ — в [429](/encyclopedia/3-data-markup/3-11-analiz-dannyh/429).

**Книга** — файл `.xlsx`. **Лист** — вкладка внизу окна. **Ячейка** — пересечение строки (номер) и столбца (буква), адрес вроде `C5`. **Диапазон** — прямоугольный блок, например `A1:D10`.

### Запуск и сохранение

Excel запускают из меню «Пуск», ярлыка на рабочем столе или двойным щелчком по файлу `.xlsx`. Стартовый экран предлагает пустую книгу или шаблон (бюджет, календарь, отчёт).

Сохранение — **Ctrl+S** или «Файл → Сохранить». При первом сохранении укажите папку, имя и тип **Книга Excel (*.xlsx)**. Для обмена только значениями без формул иногда выбирают CSV — см. [98](./98).

Несколько **листов** добавляют кнопкой «+» у вкладок. Переименование — двойной щелчок по названию вкладки. Лист можно скопировать или переместить через контекстное меню вкладки.

---

### Интерфейс

Окно Excel строится вокруг таких зон:

- **Лента** — вкладки «Главная», «Вставка», «Разметка страницы», «Формулы», «Данные» и др.
- **Строка имён** — показывает адрес активной ячейки; сюда же можно ввести имя диапазона.
- **Строка формул** — содержимое или формула выделенной ячейки; правка удобнее здесь, чем прямо в ячейке.
- **Область листа** — сетка ячеек; полосы прокрутки ведут по строкам и столбцам.
- **Вкладки листов** — переключение между листами книги.
- **Строка состояния** — сумма/среднее по выделению, режим готовности, масштаб.

<div class="callout callout--tip">
  <div class="callout-title">Быстрый старт данных</div>
  Выделите диапазон с заголовками и нажмите **Ctrl+T** — Excel оформит **таблицу** с фильтрами в шапке. Так проще ссылаться на столбцы в формулах и не «ломать» диапазон при добавлении строк.

### Ввод и редактирование

Щелчок по ячейке активирует её. Текст или число вводят с клавиатуры; **Enter** фиксирует значение и переходит вниз, **Tab** — вправо.

- **Копирование / вставка / вырезание** — Ctrl+C, Ctrl+V, Ctrl+X (как в Word).
- **Отмена / повтор** — Ctrl+Z, Ctrl+Y.
- **Заполнение** — потяните за **маркер автозаполнения** (маленький квадрат в углу выделения): Excel скопирует значение или продолжит ряд (1, 2, 3… или даты, если задан шаблон).
- **Автозаполнение по образцу** — выделите две ячейки с началом ряда (например `5` и `10`), потяните маркер вниз: программа продолжит шаг (+5).

Чтобы изменить ширину столбца, перетащите границу заголовка A, B, C… Двойной щелчок по границе подгонит ширину под содержимое.

### Форматы ячеек

Excel различает **тип данных** и **отображение**. Число `0,15` с форматом «Процентный» покажется как `15%`.

Частые категории (правый щелчок → «Формат ячеек» или «Главная → Числовой формат»):

| Категория | Когда использовать |
|-----------|---------------------|
| **Общий** | Универсальный ввод; Excel сам угадывает число или текст |
| **Числовой** | Счёт, количество знаков после запятой |
| **Денежный / финансовый** | Цены, бюджеты (символ валюты) |
| **Дата / время** | Сроки, дедлайны, логи |
| **Процентный** | Доли и KPI |
| **Текстовый** | Артикулы, телефоны с ведущими нулями |

**Условное форматирование** («Главная → Условное форматирование») подсвечивает ячейки по правилам: больше порога, топ-N значений, цветовые шкалы, гистограммы в ячейке. Удобно для статусов задач и быстрого обзора таблицы без формул.

### Формулы

Любая **формула** начинается со знака **`=`**. Excel вычисляет выражение и показывает результат в ячейке; при изменении исходных ячеек результат пересчитывается.

| Действие | Пример |
|----------|--------|
| Сложение | `=A1+B1` |
| Сумма диапазона | `=СУММ(A1:A10)` |
| Среднее | `=СРЗНАЧ(B2:B100)` |
| Условие | `=ЕСЛИ(C2>100; "Превышен"; "OK")` |
| Сумма с условием | `=СУММЕСЛИ(D:D; "Готово"; E:E)` |
| Подсчёт непустых | `=СЧЁТЗ(A2:A50)` |

**Ссылки на ячейки** бывают относительными (`A1` сдвигается при копировании) и абсолютными (`$A$1` — столбец и строка зафиксированы). Смешанный вид `$A1` фиксирует только столбец.

<div class="callout callout--info">
  <div class="callout-title">Функции и справочник</div>
  В русской локали Excel разделитель аргументов — **точка с запятой** (`;`), в английской — запятая. Сотни функций с примерами — в [Справочнике по Excel](./41). Для автоматизации повторяющихся действий — [VBA в Excel](/encyclopedia/5-languages/5-16-starye-yazyki/visual-basic/8).

### Фильтрация и сортировка

**Фильтр** временно скрывает строки, которые не подходят под условие; данные на листе остаются.

1. Выделите таблицу с **строкой заголовков**.
2. «Главная → Сортировка и фильтр → Фильтр».
3. В каждом столбце появится кнопка со стрелкой — выберите значения или условие («больше», «содержит»…).

**Сортировка** меняет порядок строк: «от А до Я», «от Я до А» или **настраиваемая сортировка** по нескольким столбцам (например сначала «Отдел», затем «Дата»).

Для реестра требований или баг-трекера в Excel фильтр помогает показать только открытые пункты; сортировка — выстроить по приоритету. В проектной документации те же приёмы — в [1007](/encyclopedia/7-project/7-08-tehnicheskoe-pismo/1007).

### Диаграммы

**Диаграмма** — наглядное представление чисел на листе. Перед вставкой решите, что сравниваете: доли, динамику во времени или рейтинг.

| Тип | Подходит для |
|-----|----------------|
| **Гистограмма** | Сравнение категорий (продажи по месяцам) |
| **График** | Изменение во времени |
| **Круговая** | Доли целого (не более 5–7 сегментов) |
| **Линейчатая** | Ранжирование длинных подписей |

Шаги:

1. Выделите диапазон с подписями и числами (заголовки столбцов включайте, если они есть).
2. «Вставка → Диаграммы» или «Рекомендуемые диаграммы» — Excel предложит варианты.
3. На вкладке «Конструктор» смените тип, подписи, легенду.
4. Диаграмму можно оставить на листе с данными или перенести на **отдельный лист** («Переместить диаграмму»).

Удаление — выделить диаграмму и нажать Delete.

### Печать и обмен

«Разметка страницы» задаёт **поля**, **ориентацию** (книжная / альбомная), **масштаб** и **область печати**. Для широкой таблицы часто включают «повторять строки» — шапка повторяется на каждой странице.

Экспорт в PDF — «Файл → Сохранить как → PDF». Для вставки фрагмента в Word скопируйте диапазон и вставьте с сохранением форматирования или используйте «Вставка → Таблица → Таблица Excel» в [Word](./211).

### Горячие клавиши

| Сочетание | Действие |
|-----------|----------|
| Ctrl+N | Новая книга |
| Ctrl+O | Открыть |
| Ctrl+S | Сохранить |
| Ctrl+C / V / X | Копировать, вставить, вырезать |
| Ctrl+Z / Y | Отмена, повтор |
| Ctrl+; | Текущая дата в ячейку |
| Ctrl+Shift+: | Текущее время |
| Ctrl+` | Показать формулы вместо результатов |
| Ctrl+T | Создать таблицу из диапазона |
| F2 | Редактировать активную ячейку |
| F4 | Повтор последнего действия / переключение $ в ссылке |
