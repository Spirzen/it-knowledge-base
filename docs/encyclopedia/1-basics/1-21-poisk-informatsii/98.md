Основные категории поисковых инструментов:
	- Общие поисковики (Google, Bing);
	- Специализированные поисковики (Stack Overflow, Wolfram Alpha);
	- Поисковики изображений (TinEye);
	- Форумные поисковики (BoardReader).

Поисковые запросы:
	- Использование кавычек для точных фраз;
	- Исключение слов с помощью "-";
	- Поиск на конкретном сайте через "site:";
	- Использование специальных операторов (filetype:, intitle:);

Три основных правила эффективного поиска:
1. Используйте правильные операторы и синтаксис.
2. Проверяйте достоверность информации.
3. Комбинируйте различные источники.

Три фундаментальных момента:
	- Качество поиска зависит от точности запроса;
	- Необходимо критически оценивать источники;
	- Разные поисковики лучше подходят для разных задач.
