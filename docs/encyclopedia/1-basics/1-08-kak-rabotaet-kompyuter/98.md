## Что запомнить

**Общая схема**

- Компьютер принимает данные, обрабатывает их по программе и выводит результат — цепочка **ввод → обработка → вывод**.
- "Железо" и ПО работают вместе: без [ОС](/encyclopedia/2-system-network/2-01-operatsionnaya-sistema/intro) и драйверов устройства не оживают.

**Ключевые роли**

| Роль | Компонент | Глава |
|------|-----------|-------|
| Вычисления | CPU | [2](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/2), [1](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/1) |
| Быстрая память | RAM | [2](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/2) |
| Долговременное хранение | HDD / SSD, разделы, ФС | [3](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/3) |
| Графика и параллельные задачи | GPU | [4](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/4) |
| Ввод-вывод | Периферия, драйверы, БП | [5](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/5) |
| Старт системы | BIOS/UEFI, загрузчик | [6](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/6) |

**Принципы**

- Все узлы связаны через **материнскую плату**; скорость системы ограничена **самым медленным звеном** (диск, ОЗУ, охлаждение).
- **Совместимость** сокета, чипсета, форм-фактора и БП важна не меньше "мощности" отдельной детали.
- **NVMe** — протокол быстрого SSD, отдельный "тип диска" рядом с HDD — упрощение для магазина, не точная классификация.

**Наглядная схема**

- Метафора "кабинета" в [7](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/7) связывает роли; справочник характеристик — в [81](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/81).
