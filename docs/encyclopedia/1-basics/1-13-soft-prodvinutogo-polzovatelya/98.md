## Что запомнить

## Стек в одном абзаце

Продвинутому пользователю нужны не «ещё десять программ», а **связный набор**: [PowerToys](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/9) и [AutoHotkey](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/6) для скорости, [VS Code](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/3) для текста и конфигов, [Everything](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/9) и [файловые менеджеры](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/2) для данных, [VirtualBox / Docker](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/8) для экспериментов, [Wireshark / PuTTY](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/5) для сети.

## Три правила выбора

1. **Задача первична** — софт под сценарий, не наоборот.
2. **Один инструмент на роль** — меньше конфликтов и фона.
3. **Скрипты + софт** — см. [советы 1.14](/encyclopedia/1-basics/1-14-sovety-dlya-prodvinutogo/intro).
