## FAQ — Часто задаваемые вопросы

Типичные затыки и **поисковые запросы** по продвинутому софту. Краткий ответ здесь; детали — в главах. Навыки для самопроверки — в [чек-листе](./99).

<div class="faq-list">

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Установил десять утилит из раздела — Windows стала медленнее. Это нормальная цена?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Часто виноваты <strong>фоновые службы и автозапуск</strong>. Принцип "один инструмент на роль"; лишнее удалите или отключите в автозагрузке. Подробнее здесь — [обзор стека](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/1).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Everything не находит файл, который вижу в проводнике.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Проверьте <strong>индексацию NTFS</strong>, фильтры по типу, не на другом ли диске (сетевой путь индексируется иначе). Обновите индекс (`F5` в Everything). Подробнее здесь — [файловые менеджеры](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/2).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Total Commander — зачем, если есть проводник Windows?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Две панели, массовое переименование, синхронизация папок, FTP — <strong>экономия на рутине</strong>, когда файлов много. Для редкого копирования хватит проводника. Подробнее здесь — [файловые менеджеры](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/2).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> VS Code "съел" все расширения — редактор тормозит при открытии папки.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Отключите лишние extensions, исключите `node_modules` в settings, проверьте <strong>антивирусное сканирование</strong> рабочей папки. Подробнее здесь — [редакторы кода](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/3), [VS Code по документации](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/11).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Открыл конфиг `.yaml` в VS Code — подсветки нет, всё серое.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Выберите язык вручную (нижний правый угол) или установите extension для YAML. Для одноразового просмотра хватит Notepad++. Подробнее здесь — [редакторы кода](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/3).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Inkscape или GIMP — что ставить "для диаграмм и схем"?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Для блок-схем и архитектуры лучше <strong>draw.io</strong>; GIMP — растр, Inkscape — вектор иллюстраций. Подробнее здесь — [графика и 3D](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/4), [diagrams.net](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/10).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Wireshark показывает тысячи пакетов — с чего начать новичку?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Фильтр по IP или `http`, захват на <strong>одном интерфейсе</strong>, учебный сценарий (ping, открытие сайта). Не снимайте трафик чужих сетей без разрешения. Подробнее здесь — [сетевые утилиты](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/5).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> PuTTY подключается, но сразу "Connection closed".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Проверьте порт (22), логин, ключ vs пароль, firewall на сервере. Для Windows-сервера нужен RDP, SSH там может быть выключен. Подробнее здесь — [сетевые утилиты](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/5).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> AutoHotkey-скрипт срабатывает в одной программе, в другой — нет.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Уточните `#IfWinActive`, права администратора (игры с античитом блокируют синтез ввода), раскладку. Подробнее здесь — [автоматизация](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/6).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> PowerShell ругается "выполнение сценариев отключено".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Политика `ExecutionPolicy` — для своих скриптов часто `RemoteSigned` для текущего пользователя. Не снижайте политику глобально без понимания рисков. Подробнее здесь — [автоматизация](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/6).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Задача в Планировщике "успешна", но скрипт ничего не сделал.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Часто <strong>другая рабочая папка</strong>, относительные пути и учётная запись без прав. Логируйте вывод в файл, проверьте "Выполнить с наивысшими правами" только если нужно. Подробнее здесь — [автоматизация](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/6).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> BitLocker включил — где хранить ключ восстановления?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Microsoft account, распечатка, отдельный носитель — <strong>не на том же зашифрованном диске</strong>. Без ключа данные при сбое загрузчика не вернуть. Подробнее здесь — [безопасность](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/7).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> VeraCrypt-контейнер открывается только на одном ПК — на другом "неверный пароль".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Проверьте раскладку, PIM, версию VeraCrypt и целостность файла контейнера. Копируйте контейнер с проверкой хеша. Подробнее здесь — [безопасность](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/7).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> VirtualBox: гостевая Linux не видит интернет.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Режим сети NAT vs Bridged, установлены ли <strong>Guest Additions</strong>, не конфликтует ли VPN на хосте. Подробнее здесь — [виртуализация](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/8).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Docker Desktop требует WSL2 — нужен ли ещё VirtualBox?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Docker на Windows опирается на WSL2/Hyper-V; VirtualBox <strong>может конфликтовать</strong> с Hyper-V на старых конфигурациях. Для полноценных desktop-ВМ — VirtualBox; для контейнеров — Docker. Подробнее здесь — [виртуализация](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/8).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> PowerToys Run (`Alt+Space`) не открывается после обновления Windows.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Переустановите PowerToys, проверьте конфликт с другими лаунчерами (Listary, Raycast-подобные). Запуск от имени пользователя, не админа. Подробнее здесь — [PowerToys](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/9).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> FancyZones ломает полноэкранные игры.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Исключите exe игры в настройках или отключайте зоны на время игры. Подробнее здесь — [PowerToys](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/9).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Диаграмма draw.io в Git показывает конфликт — как мёржить?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> `.drawio` — XML; открывайте обе версии, сравнивайте diff или мёржите вручную в редакторе. Не бинарный merge. Подробнее здесь — [diagrams.net](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/10).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> VS Code Remote SSH — "Could not establish connection".</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Проверьте SSH-ключ, `AllowTcpForwarding`, место на сервере для server-side VS Code, версию glibc на старом Linux. Подробнее здесь — [VS Code](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/11).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Notepad++ или VS Code — что держать "по умолчанию" для логов?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Notepad++ быстрее на <strong>огромных однофайловых логах</strong>; VS Code — для проектов, Git и плагинов. Можно оба. Подробнее здесь — [редакторы кода](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/3).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Blender "тяжёлый" — ноутбук греется сразу.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Снизьте samples в preview, используйте Eevee вместо Cycles для учебных сцен, следите за <strong>вентиляцией</strong>. Подробнее здесь — [графика и 3D](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/4).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Менеджер паролей sync — стоит ли доверять облаку?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Reputable менеджеры шифруют vault <strong>мастер-паролем на клиенте</strong>; риск ниже, чем у одного пароля в блокноте. Включите 2FA на аккаунте менеджера. Подробнее здесь — [безопасность](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/7).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> `winget install` поставил не ту версию программы.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Уточните Id пакета (`winget search`), зафиксируйте версию в скрипте развёртывания. Экспорт списка — для воспроизводимой установки. Подробнее здесь — [обзор](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/1), [советы 1.14](/encyclopedia/1-basics/1-14-sovety-dlya-prodvinutogo/2).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> ProcMon генерирует гигabytes логов за минуту — как не утонуть?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Фильтры по PID процесса, path contains, operation type. Снимайте короткий trace воспроизведения бага. Подробнее здесь — [сетевые утилиты](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/5), [советы 1.14 — Windows](/encyclopedia/1-basics/1-14-sovety-dlya-prodvinutogo/6).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Хочу "всё из 1.13" за выходные — реалистично?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Лучше <strong>одна роль в неделю</strong>: файлы → редактор → одна утилита автоматизации. Стек наращивается под ваши реальные задачи. Подробнее здесь — [обзор](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/1), [путь 1.14](/encyclopedia/1-basics/1-14-sovety-dlya-prodvinutogo/1).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Vim в VS Code включил — теперь не могу нормально печатать.</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Режим Normal/Insert путает новичков; отключите extension или пройдите `vimtutor`. Для конфигов хватит обычного VS Code. Подробнее здесь — [редакторы кода](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/3).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Старый ПК — какие инструменты из раздела точно не потянет?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Blender, Docker Desktop, Wireshark на постоянном захвате, несколько ВМ одновременно. Everything, Notepad++, PowerToys Run — лёгкие. Подробнее здесь — [обзор](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/1).</p>
</div>

<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Everything search Windows — как пользоваться и искать файлы?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> С voidtools.com, индекс NTFS, ввод имени — мгновенный результат. Фильтры `ext:pdf`, `dm:` по дате. Подробнее здесь — [файловые менеджеры](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/2).</p>
</div>
<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> VS Code или Notepad++ — что выбрать для конфигов и логов?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Notepad++ быстрее на гигабайтных логах; VS Code — проекты, Git, расширения. Подробнее здесь — [редакторы](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/3).</p>
</div>
<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Как установить Visual Studio Code на Windows 10 и 11?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Installer с code.visualstudio.com, галочка "Add to PATH", расширения из Marketplace. Подробнее здесь — [VS Code](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/11).</p>
</div>
<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> VirtualBox или VMware — что лучше для домашней виртуалки?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> VirtualBox бесплатен для учёбы; VMware удобнее на части железа. Снапшоты — в обоих. Подробнее здесь — [виртуализация](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/8).</p>
</div>
<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Docker Desktop Windows — зачем нужен обычному пользователю?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Запуск контейнеров (изолированных сервисов) для dev и self-host без полной ВМ на каждый стек. Подробнее здесь — [виртуализация](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/8).</p>
</div>
<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> PuTTY — как подключиться по SSH к Linux-серверу?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Host Name = IP, Port 22, SSH; ключ в Connection → SSH → Auth. Подробнее здесь — [сетевые утилиты](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/5).</p>
</div>
<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> AutoHotkey — как назначить горячую клавишу в Windows?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Файл `.ahk`, строка вроде `^!n::Run "notepad"`. Компиляция в .exe для автозапуска. Подробнее здесь — [автоматизация](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/6).</p>
</div>
<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> Microsoft PowerToys — где скачать для Windows 11?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Microsoft Store или GitHub releases. Run (`Alt+Space`), FancyZones, PowerRename. Подробнее здесь — [PowerToys](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/9).</p>
</div>
<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> BitLocker — как включить шифрование диска в Windows?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> Параметры → Конфиденциальность → Шифрование устройства (Pro). Сохраните ключ восстановления. Подробнее здесь — [безопасность](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/7).</p>
</div>
<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> VeraCrypt или BitLocker — что выбрать?</p>
  <p class="faq-a"><span class="faq-label">Ответ.</span> BitLocker — встроенное шифрование системного тома; VeraCrypt — файловые контейнеры и кроссплатформа. Подробнее здесь — [безопасность](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/7).</p>
</div>
<div class="faq-item">
  <p class="faq-q"><span class="faq-label">Вопрос.</span> draw.io diagrams.net бесплатно — как рисовать блок-схемы?</p>
