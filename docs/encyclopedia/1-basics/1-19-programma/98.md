<span class="complexity-badge">Всем</span>

Основные категории программного обеспечения:
	- Системное ПО (ОС, драйверы);
	- Прикладное ПО (офисные программы);
	- Инструментальное ПО (среды разработки).
  
Три основных правила работы с программами:
1. Понимайте зависимости и требования программы.
2. Учитывайте особенности исполнения (компиляция/интерпретация).
3. Следите за корректностью конфигурации и настроек.

Три фундаментальных момента:
	- Программы состоят из инструкций, выполняемых последовательно;
	- Для работы программы нужны ресурсы и настройки;
	- Различные парадигмы программирования подходят для разных задач.
