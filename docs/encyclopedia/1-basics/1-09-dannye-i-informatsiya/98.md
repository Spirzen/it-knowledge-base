<span class="complexity-badge">Всем</span>

Три основных аспекта работы с данными:
	- Хранение (структуры данных)
	- Передача (единицы измерения)
	- Обработка (типы данных)

Основные форматы представления информации::
1. Текстовая информация.
2. Графическая информация
3. Аудиоинформация
4. Видеоинформация

Три фундаментальных момента:
	- Все данные в компьютере сводятся к последовательности 0 и 1;
	- Разные типы данных требуют разных подходов к обработке;
	- Эффективное хранение и структурирование данных критически важно.
