## Сравнение форматов

| Формат | Тип | Сжатие | Прозрачность | Анимация | Типичное применение | Частая ошибка |
| :--- | :---: | :---: | :---: | :---: | :--- | :--- |
| BMP | Растр | Нет | Нет | Нет | Legacy, простые буферы | Хранить большие фото |
| JPG | Растр | С потерями | Нет | Нет | Фотографии | Скриншоты с текстом |
| PNG | Растр | Без потерь | Да | APNG* | UI, скриншоты, диаграммы | Фото вместо WebP/JPEG |
| WebP | Растр | Оба режима | Да | Да | Веб, фото и UI | Нет fallback для старых клиентов |
| AVIF | Растр | Lossy / lossless | Да | Ограниченно | Веб, экономия трафика | Только AVIF без `<picture>` |
| GIF | Растр | Без потерь | 1-bit | Да | Простые мемы, legacy | Фото и плавные градиенты |
| TGA | Растр | RLE / нет | Да | Нет | Текстуры 3D, рендер | Публикация в браузере |
| TIFF | Растр | Без потерь (+JPEG) | Да | Нет | Печать, архив, GIS | Веб без конвертации |
| PSD | Растр | Нет | Да | Нет | Рабочий файл Photoshop | Отдавать PSD пользователю |
| SVG | Вектор | Текст + gzip | Да | Да (CSS/JS) | Иконки, логотипы, схемы | Трассировка фото → гигабайт |
| ICO | Растр-контейнер | Нет | Да | Нет | Favicon, иконки Windows | Один размер без `@2x` |
| VSDX | Вектор + семантика | ZIP/XML | Да | Нет | Диаграммы Visio | Ожидать открытия без Visio |
| DWG / DXF | CAD | Бинарный / текст | — | Нет | Чертежи, САПР | Путать с веб-SVG |
| GeoJSON | Вектор (гео) | Нет | — | Нет | Веб-карты | Перепутать порядок lon/lat |
| Shapefile | Вектор (гео) | Набор файлов | — | Нет | Обмен GIS | Один `.shp` без `.dbf`/`.prj` |
| GeoPackage | Вектор (гео) | SQLite | — | Нет | Современный GIS | — |
| KML / KMZ | Вектор + растр | XML / ZIP | — | Туры | Google Earth, маршруты | Огромные вложенные модели |

\* APNG — расширение PNG; поддержка браузеров неполная.

<div class="callout callout--tip">
  <div class="callout-title">Быстрый выбор</div>

  <div class="callout-body">
  **Иконка или логотип** → SVG. **Фото на сайте** → AVIF/WebP + JPEG в `<picture>`. **Скриншот** → PNG. **Чертёж** → DWG/DXF в CAD, не в Figma.
</div>
  </div>
