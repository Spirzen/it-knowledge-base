## Где применяют два разных редактора

| | **Paint.NET** | **CorelDRAW** |
|---|---------------|---------------|
| Тип | **Растр** (сетка пикселей) | **Вектор** (линии, кривые, объекты) |
| Сильные стороны | Фото, ретушь, слои, эффекты | Логотипы, макеты, печать, типографика |
| Типичный файл | `.png`, `.jpg`, `.pdn` | `.cdr`, экспорт в `.pdf`, `.svg` |
| Платформа | Windows (основная) | Windows (основная) |
| Лицензия | Бесплатно | Коммерческая (есть пробный период) |

Фото обрабатывают в растре; логотип, который нужно увеличить без "лесенки", рисуют в векторе.

## Paint.NET

**Paint.NET** — бесплатный редактор изначально как замена встроенному Paint в Windows. Сейчас это полноценный инструмент начального и среднего уровня.

**Возможности:**

- слои и прозрачность (альфа-канал);
- выделения, кисти, заливка, градиенты;
- коррекция яркости, контраста, оттенка;
- плагины сообщества (эффекты, форматы, инструменты).

**Установка:** [getpaint.net](https://www.getpaint.net/download.html) — установщик или портативная сборка.

**Первые шаги:**

1. Откройте изображение → `Файл → Открыть`.
2. Дублируйте слой (`Слои → Дублировать`), чтобы не портить оригинал.
3. Обрежьте лишнее инструментом "Выделение" → `Изображение → Обрезать по выделению`.
4. Сохраните копию в **PNG** (если нужна прозрачность) или **JPEG** (фото для веба).

**Когда выбирать Paint.NET:** школьный проект, аватар, коллаж, подпись на скриншоте, быстрая подготовка картинки для презентации.

## CorelDRAW

**CorelDRAW** (часто говорят **CorelDraw**) — пакет векторной графики от Corel. В одной линейке бывают CorelDRAW (рисование), Corel PHOTO-PAINT (растр) — в статьях под "CorelDRAW" обычно имеют в виду векторный редактор.

**Возможности:**

- кривые Безье, фигуры, булевы операции (объединить, вычесть);
- мощная работа с текстом: кривые, обтекание, OpenType;
- цветовые профили и подготовка к **CMYK**-печати;
- экспорт в PDF, SVG, EPS для типографий.

**Типовой workflow:**

1. Новый документ → задать размер (визитка, A4, баннер).
2. Построить логотип из примитивов и кривых.
3. Добавить текст, проверить кегль и контраст.
4. Экспорт: PDF для печати, PNG для экрана.

**Когда выбирать CorelDRAW:** фирменный стиль, визитки, буклеты, иллюстрации для печати, векторные иконки. В веб-разработке чаще встречают **Figma** или **Illustrator**, но в учебниках и на курсах дизайна Corel остаётся стандартом.

Формат **CDR** проприетарный; для обмена используйте PDF или SVG — см. [форматы](./4.md).

## Сравнение с соседями

| Задача | Инструмент |
|--------|------------|
| Бесплатно, только Windows, фото | Paint.NET, GIMP |
| Профессиональное фото | Adobe Photoshop, Affinity Photo |
| Вектор, индустрия | CorelDRAW, Adobe Illustrator, Inkscape (бесплатно) |
| 3D | [Blender](/encyclopedia/9-spinoff/9-08-kompyuternaya-grafika/131.md) |

**Inkscape** — бесплатная альтернатива Corel для вектора (SVG); удобно, если нет лицензии Corel.
