# Первые шаги в macOS

<div class="article-tags">
  <span class="tag tag-required">ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

<span class="complexity-badge">Всем</span>

**macOS** — операционная система Apple для MacBook, iMac и Mac mini. Если вы привыкли к Windows, многие привычные элементы называются иначе, но задачи те же: открыть файл, установить программу, настроить интернет, сделать резервную копию.

Mac часто покупают вместе с iPhone — тогда удобна связка через iCloud. Если у вас Android, Mac тоже подойдёт: ставьте Google Drive, Chrome и синхронизируйте фото через [облако](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/15). Альтернатива с открытым кодом — [Linux](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/17).

## Мини-глоссарий

| Термин | Простое объяснение |
|--------|-------------------|
| **Finder** | Программа для файлов и папок, аналог Проводника |
| **Dock** | Панель с иконками внизу экрана |
| **Spotlight** | Поиск файлов, программ и настроек по Cmd+Space |
| **Apple ID** | Аккаунт для App Store, iCloud, iMessage |
| **.dmg** | Образ диска с установщиком программы |
| **Gatekeeper** | Защита от неподписанных программ |
| **Time Machine** | Встроенный бэкап macOS на внешний диск |
| **FileVault** | Шифрование всего диска |
| **Trackpad** | Сенсорная панель вместо мыши на ноутбуке |

## Соответствие с Windows

| В Windows | В macOS |
|---------|---------|
| Проводник | **Finder** — файловый менеджер |
| Пуск | **Dock** (панель внизу) + меню Apple () |
| Ctrl+C / Ctrl+V | **Cmd+C / Cmd+V** |
| Alt+Tab | **Cmd+Tab** — переключение окон |
| Параметры | **System Settings** (Настройки системы) |
| Win+Печать | **Cmd+Shift+3/4** — скриншот |
| Диспетчер задач | **Мониторинг системы** или Cmd+Option+Esc |
| Win+E | **Cmd+Space** → Finder |
| Панель задач | **Dock** + строка меню сверху |

## Первый час — пошаговый гайд

### Шаг 1. Включение и мастер настройки

1. Включите Mac, выберите язык и раскладку клавиатуры.
2. Подключите Wi‑Fi.
3. Создайте **Apple ID** или войдите в существующий. Отдельный надёжный пароль и **двухфакторная аутентификация** обязательны.
4. Настройте Touch ID (отпечаток), если есть.
5. Решите, переносить ли данные со старого Mac или Windows — для Windows нужна утилита Migration Assistant.

### Шаг 2. Обновления

1. Откройте **System Settings** (иконка шестерёнки в Dock или меню ).
2. **General → Software Update** — установите все обновления безопасности.
3. Перезагрузите, если система просит.

### Шаг 3. Finder

1. Откройте Finder (иконка улыбающегося лица в Dock).
2. Боковая панель: Desktop, Documents, Downloads, Applications.
3. **Finder → Settings → Advanced** — включите "Показывать все расширения имени файлов", чтобы видеть `.pdf`, `.docx`.
4. Создайте папку `Работа` в Documents для личных файлов.

### Шаг 4. Dock и строка меню

1. Перетащите в Dock часто используемые программы (Safari, Mail, Notes).
2. Уберите лишние иконки: перетащите за пределы Dock с задержкой.
3. Строка меню сверху показывает меню **активной** программы — это отличается от Windows.

### Шаг 5. Trackpad и мышь

1. **System Settings → Trackpad** — включите "Нажатие для клика", прокрутку двумя пальцами.
2. Жесты: смахивание тремя пальцами — переключение рабочих столов.
3. Подключите мышь через Bluetooth или USB при необходимости.

### Шаг 6. Браузер

- **Safari** встроен и экономит батарею на MacBook.
- **Chrome** или **Firefox** — если привычны с Windows.
- Не устанавливайте "ускорители" и "чистильщики" из рекламы.

### Шаг 7. iCloud и бэкап

1. **System Settings → Apple ID → iCloud** — включите iCloud Drive.
2. Подключите внешний диск для **Time Machine** (см. раздел ниже).
3. См. [Облако и бэкап](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/15).

## Интерфейс macOS

### Finder — работа с файлами

| Действие | Как сделать |
|----------|-------------|
| Копировать | Cmd+C, затем Cmd+V |
| Переместить | Cmd+C, **Cmd+Option+V** (вырезать-вставить) |
| Удалить | Cmd+Delete (в Корзину) |
| Быстрый просмотр | Пробел (Quick Look) |
| Показать путь | Cmd+Click на заголовке окна |
| Скрытые файлы | Cmd+Shift+. (точка) |

Папки по умолчанию:

| Папка | Назначение |
|-------|------------|
| Desktop | Рабочий стол |
| Documents | Документы пользователя |
| Downloads | Загрузки из браузера |
| Applications | Установленные программы |
| Library | Настройки программ (скрыта, не трогать без инструкции) |

См. [работу с проводником на Windows](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/1111) — принципы те же, названия другие.

### Dock

- Иконка с точкой под ней — программа запущена.
- Правый клик (или Ctrl+клик) — контекстное меню.
- Разделитель: слева программы, справа папки и Корзина.

### Рабочие столы (Spaces)

- Ctrl+стрелка влево/вправо или жест тремя пальцами — другой рабочий стол.
- Удобно разделить "работу" и "личное".

## Установка программ — пошагово

### Способ 1. App Store

1. Откройте **App Store** из Dock.
2. Войдите Apple ID, если просит.
3. Найдите программу, нажмите "Получить" / "Установить".
4. Программа появится в Applications и Dock (если закрепите).

Аналог Microsoft Store. Программы проверены Apple.

### Способ 2. С сайта разработчика (.dmg)

1. Скачайте `.dmg` только с **официального сайта**.
2. Дважды кликните `.dmg` — откроется виртуальный диск.
3. Перетащите иконку программы в папку **Applications**.
4. Извлеките диск: правый клик → Извлечь, или кнопка извлечения рядом с именем диска.
5. Запустите из Applications. При первом запуске macOS может спросить подтверждение.

### Способ 3. Homebrew (для продвинутых позже)

Менеджер пакетов через терминал. Понадобится при разработке — [софт продвинутого пользователя](/encyclopedia/1-basics/1-13-soft-prodvinutogo-polzovatelya/intro), [терминал](/encyclopedia/2-system-network/2-05-terminal/intro).

### Gatekeeper

Встроенная защита macOS от неподписанных программ.

- Если система блокирует программу: **System Settings → Privacy & Security** → "Всё равно открыть" (после первой попытки запуска).
- Не отключайте Gatekeeper полностью без понимания риска.
- См. [опасные скрипты](/encyclopedia/8-infra-security/8-03-zabota-o-kode-i-dannyh/101).

## Spotlight — универсальный поиск

1. **Cmd+Space** — открыть Spotlight.
2. Введите имя файла, программы или настройки ("Wi-Fi", "Bluetooth", "Display").
3. Стрелки — выбор, Enter — открыть.
4. Можно считать простые выражения и конвертировать валюты.

Если Spotlight не находит файл — проверьте **System Settings → Siri & Spotlight → Spotlight Privacy** — папка не должна быть исключена ошибочно.

## iCloud и Time Machine

### iCloud Drive

- Синхронизация документов между Mac, iPhone и iPad.
- **System Settings → Apple ID → iCloud → iCloud Drive** — включить.
- Папка iCloud Drive появится в Finder.
- Фото — отдельный переключатель **Photos** в iCloud.

См. [Облако и бэкап](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/15). На Android вместо iCloud — [Google Drive](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/18).

### Time Machine — пошаговая настройка

1. Купите внешний USB-диск (объём больше, чем занято на Mac).
2. Подключите диск. macOS предложит использовать для Time Machine — согласитесь.
3. Или **System Settings → General → Time Machine → Add Backup Disk**.
4. Выберите диск, при желании включите шифрование.
5. Первый бэкап займёт часы. Дальше — инкрементально в фоне.

**Восстановление файла:** откройте Finder → Enter Time Machine (из меню или иконки в строке меню) → выберите дату → восстановить файл.

**Восстановление системы:** режим Recovery (удержание питания на Apple Silicon, Cmd+R на Intel Mac).

## Практические сценарии

### Сценарий 1. Переход с Windows на Mac

1. Экспортируйте закладки браузера, сохраните файлы в облако ([OneDrive → Mac](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/15)).
2. На Mac установите Chrome, войдите в Google или Microsoft аккаунт.
3. Привыкайте к Cmd вместо Ctrl — наклейка на клавиатуре первую неделю помогает.
4. LibreOffice или Microsoft 365 для документов `.docx`.

### Сценарий 2. MacBook для учёбы

1. Папка `Учёба` в iCloud Drive — доступ с iPhone для конспектов.
2. Time Machine на домашний диск — бэкап перед сессией.
3. Не храните единственную копию курсовой только на Desktop.

### Сценарий 3. Программа не открывается

1. Проверить, скачана ли версия для **Apple Silicon (M1/M2/M3)** или Intel.
2. **Privacy & Security → Open Anyway** после первой блокировки.
3. Удалить и скачать заново с официального сайта.

### Сценарий 4. Заканчивается место на диске

1. **System Settings → General → Storage** — рекомендации по очистке.
2. Очистить Downloads, старые резервные копии iPhone в Finder.
3. Крупные файлы перенести на внешний диск, не синхронизировать видео 4K в iCloud без платного тарифа.

## Частые ошибки

### Ошибка 1. Закрыть окно крестиком = выйти из программы

На Mac красный крестик часто **закрывает окно**, но программа остаётся в памяти (точка в Dock). Полный выход — **Cmd+Q**.

### Ошибка 2. Искать меню "Файл" в окне программы

Меню всегда **вверху экрана** в строке меню, не в окне.

### Ошибка 3. Не настроить Time Machine

"Настрою потом" часто заканчивается поломкой без бэкапа. Подключите диск в первый день.

### Ошибка 4. Заполнить iCloud бесплатными 5 ГБ

Включили Фото, iCloud Drive и резерв iPhone — лимит исчерпан. Расширьте тариф или отключите лишнее.

### Ошибка 5. Скачать программу с неофициального сайта

Поддельные установщики с рекламы — malware. Только сайт разработчика или App Store.

### Ошибка 6. Перепутать Cmd и Ctrl

Ctrl на Mac используется реже. Большинство привычных Ctrl+... на Windows — это Cmd+... на Mac.

### Ошибка 7. Не извлечь .dmg после установки

Висит "лишний диск" на рабочем столе — извлеките образ после переноса в Applications.

## Устранение неполадок

### Mac не включается

1. Подключите зарядку, подождите 15 минут.
2. На Apple Silicon — удерживайте кнопку питания 10 секунд, затем включите снова.
3. Если экран чёрный — яркость (клавиши F1/F2 или Touch Bar).

### Wi‑Fi не подключается

1. **System Settings → Wi-Fi** — выключить/включить.
2. Забыть сеть и подключиться заново.
3. Перезагрузка роутера. См. [сеть и интернет](/encyclopedia/2-system-network/2-03-set-i-internet/intro).

### Программа зависла

1. **Cmd+Option+Esc** → выбрать программу → Завершить принудительно.
2. **Мониторинг системы** (Programs → Utilities) — вкладка CPU, завершить процесс.

### Медленно работает

1. **Storage** — мало свободного места (нужно хотя бы 10–15 % диска).
2. Перезагрузка раз в неделю.
3. Проверить Login Items — лишние программы в автозапуске (**System Settings → General → Login Items**).

### Не печатает принтер

1. **System Settings → Printers & Scanners** — добавить принтер.
2. Для старых моделей — драйвер с сайта производителя.
3. USB или Wi‑Fi в одной сети с Mac.

### Не видит внешний диск

1. Другой кабель и порт.
2. **Disk Utility** (Дисковая утилита) — диск виден, но не смонтирован: возможно, формат NTFS (на Mac только чтение без доп. ПО) или нужен формат APFS/exFAT.

## FAQ

**Нужен ли антивирус на Mac?**

Для домашнего использования достаточно встроенной защиты (Gatekeeper, XProtect) и осторожности с загрузками. Не ставьте "чистильщики" из рекламы.

**Можно ли ставить Windows на Mac?**

Да, через Boot Camp (Intel) или виртуальную машину (Parallels, UTM). Для игр и специфичного софта — вариант. См. [операционные системы](/encyclopedia/2-system-network/2-01-operatsionnaya-sistema/intro).

**Чем Mac отличается от Linux?**

Mac — закрытая система от Apple с графическим интерфейсом "из коробки". Linux — бесплатен и гибок, но требует больше самостоятельной настройки. См. [Первые шаги в Linux](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/17).

**Как перенести фото с Android на Mac?**

USB-кабель (режим передачи файлов), Google Фото в браузере, или облако. См. [Android](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/18).

**Сколько RAM нужно?**

8 ГБ — веб и документы. 16 ГБ — комфортнее для нескольких программ и вкладок. 8 ГБ на Apple Silicon часто ощущается лучше, чем на старом Intel с 8 ГБ.

**Где удалённые программы?**

В Launchpad удерживайте иконку до дрожания → минус. Или Finder → Applications → перетащить в Корзину.

**Как подключить Android к Mac?**

Google Drive в браузере, USB с Android File Transfer, или синхронизация фото через [облако](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/15). См. [Android](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/18).

**Нужен ли Microsoft Office?**

Microsoft 365, LibreOffice или веб-версии Google — по задаче. См. [офисные пакеты](/encyclopedia/1-basics/1-11-soft-ryadovogo-polzovatelya/51).

**Что такое Rosetta?**

Переводчик для программ Intel на Mac с Apple Silicon. Система предложит установить при первом запуске старого .dmg.

## Вторая неделя — углубление

### Настройка уведомлений

1. **System Settings → Notifications**.
2. Отключите навязчивые программы (Game Center, News).
3. Оставьте почту, календарь, мессенджеры.
4. **Focus** (Режим фокусирования) — тихие часы без отвлечений.

### Принтер и сканер

1. **System Settings → Printers & Scanners → Add Printer**.
2. Выберите принтер по Wi‑Fi или USB.
3. Сканирование — через Preview (Просмотр) → Import from Scanner.

### Резервная копия iPhone с Mac

1. Подключите iPhone кабелем.
2. Finder → iPhone в боковой панели.
3. **Back up all data on your iPhone to this Mac** — локальная копия помимо iCloud.
4. Шифровать бэкап — сохранит пароли Wi‑Fi.

### Работа с несколькими мониторами

1. **System Settings → Displays** — расположение мониторов перетаскиванием.
2. Галочка "Mirror" — дублирование, без неё — расширенный стол.
3. Dock может быть на любом экране — перетащите курсор вниз нужного монитора.

## Форматы дисков для Mac

| Формат | Mac читает | Mac записывает | Для чего |
|--------|------------|----------------|----------|
| APFS | Да | Да | Внутренний диск Mac, Time Machine (новые версии) |
| exFAT | Да | Да | Флешки между Mac и Windows |
| FAT32 | Да | Да | Старые флешки, лимит 4 ГБ на файл |
| NTFS | Да | Нет (без доп. ПО) | Диски от Windows — только чтение |
| ext4 (Linux) | Нет (без ПО) | Нет | Диски от [Linux](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/17) |

Для обмена файлами Mac ↔ Windows форматируйте флешку в **exFAT** через Disk Utility.

## Пошаговая настройка Time Machine (расширенная)

1. Купите HDD 2–4 ТБ (в 2–3 раза больше занятого на Mac).
2. Подключите — диалог "Use as Backup Disk" → **Encrypt Backup Disk** (запомните пароль).
3. **System Settings → General → Time Machine → Options** — исключите папки с виртуальными машинами и кэшем torrent.
4. Первая копия — оставьте Mac на зарядке на ночь.
5. Раз в месяц: **Enter Time Machine** → откройте старый документ — убедитесь, что снимки есть.

Если диск заполнен — macOS удаляет старые снимки. Второй диск по ротации — для параноиков. См. [облако и бэкап](/encyclopedia/1-basics/1-12-sovety-dlya-novichka/15).

## Дополнительные частые ошибки

### Ошибка 8. Хранить всё на Desktop

Desktop синхронизируется и захламляется. Документы — в Documents, проекты — в отдельных папках.

### Ошибка 9. Игнорировать мало места на диске

macOS при `<10` % свободного места сильно тормозит. **Storage** → рекомендации по очистке.

### Ошибка 10. Один Apple ID на всю семью

У каждого — свой Apple ID. Семейный доступ — через "Family Sharing", не через общий пароль.

## Дополнительное устранение неполадок

### Bluetooth-наушники не подключаются

1. Забыть устройство в **System Settings → Bluetooth**.
2. Наушники в режим сопряжения (инструкция производителя).
3. Подключить заново.

### Камера / микрофон не работают в Zoom

**System Settings → Privacy & Security → Camera / Microphone** — разрешить Zoom.

### Не открывается сайт только на Safari

Попробовать Chrome. Очистить DNS: отключить VPN, перезагрузить Mac. См. [сеть](/encyclopedia/2-system-network/2-03-set-i-internet/intro).

### MacBook греется и шумит

1. **Activity Monitor** — какой процесс грузит CPU.
2. Закрыть вкладки с видео 4K в браузере.
3. Проверить вентиляционные отверстия — не закрыты подушкой.
