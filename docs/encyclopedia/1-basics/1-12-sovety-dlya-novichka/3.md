## Горячие клавиши в Windows

<div class="callout callout--tip">
  <div class="callout-title">Эффективность работы</div>
  Использование горячих клавиш сокращает время выполнения рутинных операций в два раза по сравнению с использованием мыши. Мышью можно выполнить только одну задачу за раз, тогда как комбинации клавиш позволяют выполнять сложные действия мгновенно.
</div>

<details>
<summary>
<b>Как запоминать сочетания?</b>
</summary>
Логика построения сочетаний базируется на модификаторах. Клавиша `Ctrl` отвечает за управление файлами и окнами, `Alt` — за доступ к меню и системным функциям, `Win` — за вызов интерфейса системы, `Shift` — за расширение выбора или инверсию действия. Понимание этой логики позволяет вспомнить забытое сочетание без поиска в интернете. На Mac ту же роль для копирования, вставки и многих системных команд выполняет клавиша **⌘ (Command)** — см. главу «macOS» и раздел про скриншоты в этой же подборке.
</details>

## Базовое управление системой

Горячие клавиши этой группы отвечают за навигацию по системе, переключение между приложениями и управление окнами.

| Сочетание | Действие | Описание |
| :--- | :--- | :--- |
| `Win` + `E` | Проводник | Открывает окно проводника файлов для навигации по диску. |
| `Win` + `D` | Рабочий стол | Сворачивает все открытые окна и показывает рабочий стол. Повторное нажатие возвращает окна. |
| `Win` + `L` | Блокировка | Немедленно блокирует сеанс пользователя. Требует ввода пароля для входа обратно. |
| `Win` + `I` | Параметры | Открывает приложение «Параметры» Windows для настройки системы. |
| `Win` + `X` | Быстрое меню | Вызывает расширенное меню пользователя (Администрирование, Диспетчер устройств, Терминал). |
| `Alt` + `Tab` | Переключение | Переключает фокус между последними активными окнами. Удержание `Alt` и нажатие `Tab` циклически меняет выбор. |
| `Alt` + `F4` | Закрытие | Закрывает текущее активное окно или программу. На рабочем столе вызывает диалог выключения. |
| `Win` + `M` | Свернуть всё | Сворачивает все открытые окна. |
| `Win` + `Shift` + `M` | Развернуть | Восстанавливает свернутые окна после нажатия `Win` + `M`. |
| `Win` + `Стрелка влево/вправо` | Прикрепление | Прикрепляет окно к левой или правой половине экрана. |
| `Win` + `Стрелка вверх` | Развернуть | Разворачивает окно на весь экран. |
| `Win` + `Стрелка вниз` | Сворачивать | Сворачивает окно или восстанавливает его из развернутого состояния. |
| `Win` + `Стрелка вверх/вниз` + `влево/вправо` | Зонирование | Перемещает окно в угол экрана, занимая четверть пространства. |

> **💡 Совет**  
> Комбинация `Win` + `V` открывает историю буфера обмена, позволяя копировать несколько элементов подряд и выбирать нужный для вставки позже.

## Работа с окнами и приложениями

Управление визуальным представлением окон и их расположением на экране.

### Управление окнами

| Сочетание | Действие | Описание |
| :--- | :--- | :--- |
| `Alt` + `Space` | Меню окна | Открывает системное меню текущего окна (свернуть, развернуть, закрыть, переместить). |
| `Alt` + `Enter` | Свойства | Открывает свойства выбранного файла или папки в проводнике. |
| `Ctrl` + `Shift` + `Esc` | Диспетчер задач | Сразу открывает Диспетчер задач без промежуточного экрана безопасности. |
| `Win` + `Tab` | Вид всех окон | Открывает режим «Обзор задач» с анимацией всех открытых окон и виртуальных рабочих столов. |
| `Win` + `Ctrl` + `D` | Новый рабочий стол | Создает новый виртуальный рабочий стол. |
| `Win` + `Ctrl` + `F4` | Закрыть рабочий стол | Закрывает текущий виртуальный рабочий стол. |
| `Win` + `Ctrl` + `Стрелка влево/вправо` | Переключение столов | Переключается между созданными виртуальными рабочими столами. |

### Специфические действия

| Сочетание | Действие | Описание |
| :--- | :--- | :--- |
| `Win` + `P` | Проектор | Открывает меню проекции для выбора режима отображения на второй монитор или проектор. |
| `Win` + `G` | Игровая панель | Открывает игровую панель Xbox для записи геймплея и использования виджетов. |
| `Win` + `.` (точка) | Эмодзи и символы | Открывает панель эмодзи, смайликов и специальных символов. |
| `Win` + `,` (запятая) | Предпросмотр | Временно скрывает все окна, чтобы увидеть рабочий стол (возврат по отпусканию клавиш). |
| `Win` + `H` | Транскрибация | Запускает функцию диктовки текста голосом. |
| `Win` + `A` | Центр действий | Открывает центр уведомлений и быстрых настроек (Wi-Fi, Bluetooth, яркость). |

## Работа с текстом и файлами

Команды для редактирования текста, управления буфером обмена и файловой системой.

### Редактирование текста

| Сочетание | Действие | Описание |
| :--- | :--- | :--- |
| `Ctrl` + `C` | Копировать | Копирует выделенный объект в буфер обмена. |
| `Ctrl` + `X` | Вырезать | Перемещает выделенный объект в буфер обмена, удаляя оригинал. |
| `Ctrl` + `V` | Вставить | Вставляет содержимое буфера обмена в текущую позицию курсора. |
| `Ctrl` + `Z` | Отмена | Отменяет последнее выполненное действие. |
| `Ctrl` + `Y` | Повтор | Повторяет отмененное действие. |
| `Ctrl` + `A` | Выделить всё | Выделяет весь текст или объекты в текущем окне. |
| `Ctrl` + `S` | Сохранить | Сохраняет текущий файл или документ. |
| `Ctrl` + `N` | Новый | Создает новый документ или окно программы. |
| `Ctrl` + `O` | Открыть | Открывает диалоговое окно для выбора файла. |
| `Ctrl` + `P` | Печать | Открывает окно печати документа. |
| `Ctrl` + `F` | Найти | Открывает поле поиска внутри документа или браузера. |
| `Ctrl` + `H` | Заменить | Открывает панель замены текста. |
| `Ctrl` + `K` | Вставить ссылку | В большинстве редакторов открывает окно для вставки гиперссылки. |
| `Ctrl` + `Arrow` (стрелки) | Перемещение слова | Перемещает курсор на слово вперед или назад вместо символа. |
| `Ctrl` + `Backspace` | Удаление слова | Удаляет слово слева от курсора целиком. |
| `Shift` + `Arrow` (стрелки) | Выделение | Выделяет текст по одному символу или слову в зависимости от модификаторов. |
| `Home` / `End` | Начало / Конец | Перемещает курсор в начало или конец строки. |
| `Ctrl` + `Home` / `End` | Начало / Конец файла | Перемещает курсор в самое начало или конец документа. |

### Файловая система

| Сочетание | Действие | Описание |
| :--- | :--- | :--- |
| `F2` | Переименовать | Переименовывает выбранный файл или папку. |
| `Delete` | Удалить | Перемещает файл в корзину. |
| `Shift` + `Delete` | Безвозвратно удалить | Удаляет файл без помещения в корзину. |
| `Alt` + `Enter` | Свойства | Открывает свойства выбранного файла. |
| `Ctrl` + `Shift` + `N` | Новая папка | Создает новую пустую папку в текущей директории. |
| `Alt` + `Up` | Наверх | Переходит на уровень выше в дереве папок. |
| `Alt` + `Left` / `Right` | Назад / Вперед | Возвращает к предыдущей или следующей просмотренной папке. |
| `F5` | Обновить | Обновляет содержимое окна проводника. |
| `Ctrl` + `Shift` + `Esc` | Диспетчер задач | Открывает диспетчер задач напрямую. |

## Системные утилиты и диагностика

Клавиши для вызова инструментов диагностики, консолей и специализированных утилит.

| Сочетание | Действие | Описание |
| :--- | :--- | :--- |
| `Win` + `R` | Выполнить | Открывает диалоговое окно «Выполнить» для запуска программ по имени. |
| `Win` + `Cmd` (или `Ctrl` + `R`) | Терминал PowerShell | Открывает PowerShell или командную строку (зависит от версии Windows). |
| `Win` + `X` | Меню администратора | Вызывает скрытое меню для быстрого доступа к административным инструментам. |
| `Win` + `Break` | Свойства системы | Открывает раздел «Сведения о системе» в параметрах. |
| `Print Screen` (`PrtScn`) | Снимок экрана | Делает снимок всего экрана и копирует его в буфер обмена. |
| `Alt` + `Print Screen` | Активное окно | Делает снимок только активного окна. |
| `Win` + `Print Screen` | Файл снимка | Делает снимок экрана и сохраняет его автоматически в папку «Изображения». |
| `Win` + `Shift` + `S` | Область захвата | Открывает инструмент «Ножницы» для выделения области экрана. |
| `Win` + `G` | Игровая панель | Вызывает оверлей для записи видео и скриншотов. |
| `Win` + `Q` / `S` | Поиск | Открывает поиск по системе или в приложении Bing. |
| `Win` + `E` | Проводник | Запускает проводник файлов. |
| `Win` + `I` | Параметры | Открывает настройки Windows. |
| `Win` + `A` | Центр уведомлений | Открывает быстрые настройки. |
| `Win` + `U` | Специальные возможности | Открывает параметры специальных возможностей. |

## Продвинутые сценарии использования

### Виртуальные рабочие столы

Windows поддерживает создание нескольких виртуальных рабочих столов для разделения задач. Например, один стол для работы, другой для игр, третий для общения.

1.  Создайте новый стол: `Win` + `Ctrl` + `D`.
2.  Переключитесь между столами: `Win` + `Ctrl` + `Стрелка влево` или `вправо`.
3.  Закройте текущий стол: `Win` + `Ctrl` + `F4`.
4.  Просмотр всех окон: `Win` + `Tab`.

### Контекстные меню

Клавиша `Shift` + `ПКМ` (правая кнопка мыши) открывает расширенное контекстное меню с дополнительными опциями, которые часто скрыты в стандартном меню. Это особенно полезно для разработчиков, которым нужно открыть терминал в текущей папке или создать архив.

### Скрипты и автоматизация

Для сложных сценариев можно использовать скрипты PowerShell или AutoHotkey для создания собственных сочетаний клавиш, не предусмотренных системой. Например, привязка одной кнопки к выполнению серии действий: открытие трех приложений, настройка окон и запуск скрипта.

```powershell
# Пример простого скрипта для открытия блокнота
Start-Process notepad.exe
```

> **⚠️ Предупреждение**  
> Используйте `Shift` + `Delete` с осторожностью. Файлы, удаленные таким способом, не попадают в корзину и требуют специальных средств для восстановления.

## Таблица модификаторов

Понимание роли каждой клавиши помогает запоминать новые сочетания.

| Клавиша | Основная роль | Примеры |
| :--- | :--- | :--- |
| `Ctrl` | Управление объектами | Копирование, вставка, отмена, сохранение. |
| `Alt` | Доступ к меню | Переключение вкладок, закрытие окон, вызов меню. |
| `Win` | Системный интерфейс | Запуск меню Пуск, управление окнами, виртуальные столы. |
| `Shift` | Расширение действий | Выделение диапазона, удаление без корзины, ввод заглавных букв. |
| `Fn` | Аппаратные функции | Изменение громкости, яркости, включение Wi-Fi (на ноутбуках). |

## Скорость печати

Горячие клавиши экономят время только вместе с уверенным набором текста. Полезно знать свой темп: **знаков в минуту** (зн/мин) и **слов в минуту** (в тестах одно слово = 5 символов). Пройдите короткий замер — так проще понять, стоит ли добавить ежедневную практику слепой печати.
