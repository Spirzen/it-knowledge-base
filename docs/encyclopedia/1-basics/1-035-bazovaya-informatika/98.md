## Что запомнить

### Восемь блоков одной картины

| Блок | Главная мысль | Глава |
|------|---------------|-------|
| Данные | Всё в компьютере — **числа и коды**; сжатие и архивы экономят место | [2](/encyclopedia/1-basics/1-035-bazovaya-informatika/2) → [Данные](/encyclopedia/1-basics/1-09-dannye-i-informatsiya/intro) |
| Железо | CPU, память, диск, периферия — **роли** в системе | [3](/encyclopedia/1-basics/1-035-bazovaya-informatika/3) → [Компьютер](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/intro) |
| ОС и утилиты | ОС управляет ресурсами; **файлы, антивирус, архиватор** — повседневные инструменты | [5](/encyclopedia/1-basics/1-035-bazovaya-informatika/5) |
| Интернет | Сеть + **протоколы** + сервисы (поиск, почта, RSS, стриминг) | [6](/encyclopedia/1-basics/1-035-bazovaya-informatika/6) |
| Алгоритмы | **План** задачи → блок-схема → программа на языке | [4](/encyclopedia/1-basics/1-035-bazovaya-informatika/4) → [Программа](/encyclopedia/1-basics/1-19-programma/intro) |
| Право | ПО под **авторским правом**; ПДн — 152-ФЗ; взлом и вирусы — УК РФ | [7](/encyclopedia/1-basics/1-035-bazovaya-informatika/7) |
| Рабочее место | **Эргономика**, перерывы, правила класса | [8](/encyclopedia/1-basics/1-035-bazovaya-informatika/8) |
| Инструменты | Справочник сред: парсинг, графика, игры, мобильные app | [9](/encyclopedia/1-basics/1-035-bazovaya-informatika/9) |

### Три принципа, которые связывают темы

1. **Компьютер не понимает смысл** — только данные и инструкции. «Умность» в алгоритмах и программах ([4](/encyclopedia/1-basics/1-035-bazovaya-informatika/4), [Программа](/encyclopedia/1-basics/1-19-programma/1)).
2. **Слои:** приложение → ОС → драйверы → железо ([5](/encyclopedia/1-basics/1-035-bazovaya-informatika/5), [Компьютер](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/7)).
3. **Цифровая грамотность = техника + право + привычки:** легальное ПО, аккуратность с данными, здоровье за экраном ([7](/encyclopedia/1-basics/1-035-bazovaya-informatika/7), [8](/encyclopedia/1-basics/1-035-bazovaya-informatika/8)).
