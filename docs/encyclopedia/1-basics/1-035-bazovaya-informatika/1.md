## Информатика как наука

> **Информатика** — наука об общих свойствах информации, закономерностях и способах её **создания, хранения, поиска, преобразования и использования** с помощью компьютерных систем.

В школьной и вузовской программе информатика пересекается с соседними дисциплинами, но у каждой свой фокус.

| Дисциплина | Что изучает |
|------------|-------------|
| **Теория информации** | Математические модели передачи и измерения информации (К. Шеннон) |
| **Кибернетика** | Связь и управление в машинах, живых системах, обществе |
| **Семиотика** | Знаки и знаковые системы |
| **Информатика** | Практика работы с данными на компьютере — кодирование, ПО, сети |

Для курса "Базовая информатика" достаточно помнить — информатика связывает **смысл для человека** с **правилами записи на машине**.

## Виды информации по форме представления

В учебниках для информатики выделяют виды, у которых есть **устоявшиеся способы кодирования и хранения**:

| Вид | Примеры носителей | Цифровые форматы |
|-----|-------------------|------------------|
| **Графическая (изобразительная)** | Рисунок, фото, схема | PNG, JPEG, SVG |
| **Звуковая** | Запись речи, шум улицы | WAV, MP3, AAC |
| **Текстовая** | Книга, SMS, статья | `.txt`, HTML, DOCX |
| **Числовая** | Счёт, таблица, измерение | CSV, ячейки Excel, JSON |
| **Видео** | Кино, ролик, трансляция | MP4, WebM |

Есть виды, которые человек воспринимает (запах, тактильные ощущения), но для них **общепринятых цифровых стандартов** пока нет — в школьном курсе их обычно только упоминают.

Переход от аналогового сигнала (непрерывная волна звука) к цифре называют **дискретизацией** — разбиением на отдельные отсчёты и присвоением каждому кода. Подробно — [глава 2](/encyclopedia/1-basics/1-035-bazovaya-informatika/2).

## Свойства информации

Информация в жизни и в курсе информатики описывается **свойствами**, от которых зависит, можно ли ей доверять и насколько она полезна **сейчас**.

| Свойство | Суть | Пример |
|----------|------|--------|
| **Объективность / субъективность** | Измерена прибором или выражает мнение | Термометр +23 °C — объективно; "на улице тепло" — субъективно |
| **Достоверность** | Соответствует факту | Показания исправного датчика |
| **Недостоверность** | Ошибка, устаревание, искажение при передаче | Слух в чате без источника |
| **Полнота** | Хватает данных для решения | Адрес с домом, но без номера квартиры — неполный для доставки |
| **Актуальность** | Сведения ещё верны для задачи | Курс валют "вчера" для сделки "сегодня" |
| **Старение** | Ценность падает со временем | Расписание прошлого семестра |

Самая ценная для решений информация — **объективная, достоверная, полная и актуальная**. На экзамене часто просят привести пример субъективного сообщения и объяснить, чем оно отличается от измерения.

### Количество информации в сообщении

В школьном курсе часто используют **формулу Хартли** для равновероятных исходов:

```
I = log₂(N)  бит
```

где **N** — число равновероятных вариантов, один из которых произошёл.

| Событие | N | I = log₂(N) |
|---------|---|-------------|
| Монета: орёл или решка | 2 | 1 бит |
| Игральная кость (1–6) | 6 | ≈ 2,58 бит |
| Буква русского алфавита (33, равновероятно) | 33 | ≈ 5,04 бит |
| Угадали число от 1 до 8 | 8 | 3 бита |

**Пример.** Сообщение "выпала 5 на кубике" среди шести граней даёт log₂(6) ≈ 2,58 бит — столько же, сколько нужно, чтобы закодировать один из шести равных исходов. Если исходы **не** равновероятны (зима в Москве чаще, чем +40 °C), формула Шеннона сложнее — см. [теорию информации](/encyclopedia/1-basics/1-09-dannye-i-informatsiya/1).

### Задачи на свойства — разбор

**Задача 1.** "Вчера на улице было холодно" — какие свойства нарушены или соблюдены?

| Свойство | Оценка | Почему |
|----------|--------|--------|
| Объективность | Субъективно | Нет числа, только ощущение |
| Достоверность | Неизвестно | Может быть правдой, но без даты и места не проверить |
| Полнота | Неполно | Нет температуры, города, времени суток |
| Актуальность | Устарело | "Вчера" без календарной даты бесполезно через неделю |

**Задача 2.** Датчик показал "+18,3 °C в 14:02" — объективно, измеримо, можно проверить калибровкой прибора.

## Информационные процессы

Любая работа с ПК — один или несколько процессов из списка:

```mermaid
flowchart LR
    A[Создание] --> B[Хранение]
    B --> C[Поиск]
    C --> D[Преобразование]
    D --> E[Передача]
    E --> F[Использование]
    F --> B
```

| Процесс | Бытовой пример |
|---------|----------------|
| **Создание** | Набрали текст, сняли фото |
| **Хранение** | Сохранили файл на диск или в облако |
| **Поиск** | Нашли документ по имени или через поисковик |
| **Преобразование** | Сжали фото, отформатировали таблицу |
| **Передача** | Отправили файл по почте или в мессенджере |
| **Использование** | Прочитали, распечатали, посчитали сумму |

Цепочка **кодирование → хранение → передача → декодирование** повторяется в каждой главе курса — от [данных](/encyclopedia/1-basics/1-035-bazovaya-informatika/2) до [интернета](/encyclopedia/1-basics/1-035-bazovaya-informatika/6).

## Четыре опоры, которые стоит запомнить

Типичные заблуждения новичка:

- компьютер "думает" сам по себе;
- машина оперирует чем угодно, кроме нулей и единиц;
- программа на диске и запущенный процесс — одно и то же;
- интернет, IP-адрес, порт и протокол — синонимы.

Четыре опоры курса:

- **Смысл задаёт человек или алгоритм.** Машина работает с битами по правилам программ. См. [Данные и информация](/encyclopedia/1-basics/1-09-dannye-i-informatsiya/1).
- **Любая задача на ПК** — ввод → обработка (CPU + программа + ОС) → вывод. См. [Принцип работы компьютера](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/1).
- **Интернет** — сеть сетей с общими правилами (протоколами). См. [Сеть и интернет](/encyclopedia/2-system-network/2-03-set-i-internet/1).
- **Программа, процесс и параллелизм** — алгоритм описывает шаги, **программа** фиксирует их в файле, **процесс** — живое исполнение в памяти. Один файл может породить несколько процессов; внутри процесса — **потоки выполнения**, которые ОС чередует на ядре (многозадачность) или распределяет по ядрам (параллелизм). Общая память потоков требует [мьютексов](https://ru.wikipedia.org/wiki/%D0%9C%D1%8C%D1%8E%D1%82%D0%B5%D0%BA%D1%81) и защиты от [гонок](https://ru.wikipedia.org/wiki/%D0%A1%D0%BE%D1%81%D1%82%D0%BE%D1%8F%D0%BD%D0%B8%D0%B5_%D0%B3%D0%BE%D0%BD%D0%BA%D0%B8). См. [главу 4](/encyclopedia/1-basics/1-035-bazovaya-informatika/4), [Программа](/encyclopedia/1-basics/1-19-programma/intro), [Процессы и потоки](/encyclopedia/4-code-dev/4-05-asinhronnost/1).
