## От диспетчера задач к "наблюдаемости"

Продвинутый пользователь не спрашивает "почему тормозит?" — он смотрит **метрики** — CPU, диск, память, сеть, дисковая очередь. На домашнем ПК достаточно встроенных средств; стек Prometheus/Grafana — для серверов ([2.06](/encyclopedia/2-system-network/2-06-sistemnoe-administrirovanie/92)).

## CPU-спайки и фоновые пожиратели

**CPU spike** — краткий или длительный скачок загрузки процессора. Норма: краткий всплеск при запуске приложения. Проблема: **постоянные 20–40%** в простое.

| Виновник | Симптом | Действие |
| :--- | :--- | :--- |
| Индексатор Windows | Диск + CPU после обновления | Подождать или ограничить индексацию |
| **SearchIndexer.exe** / Copilot+ фон | Диск в простое | Настройки поиска, отключение ненужного |
| Телеметрия (`CompatTelRunner`, `Device Census`) | Пики после загрузки | Параметры → Конфиденциальность (см. ниже) |
| RGB / материнка (Armoury Crate, iCUE, RGB Fusion) | RAM 200–500 МБ, CPU | Только нужные модули, не ставить на SSD системы |
| Лаунчеры (Steam, Epic, GOG, Xbox) | Память в фоне | Закрывать после игры, не "в автозагрузке" |
| **Overlays** (Discord, GeForce Experience, Xbox Game Bar) | Input lag + CPU | Отключить оверлей в игре |
| Браузер с 80 вкладками | RAM + диск (swap) | Sleep tabs, отдельный профиль |

В Process Explorer сортируйте по **CPU** и **Private Bytes**. Правый клик → Properties → Image — путь к exe (подозрительные пути в `%TEMP%` — повод для проверки).

### Диспетчер задач — вкладки по делу

| Вкладка | На что смотреть |
| :--- | :--- |
| Процессы | Имя, % CPU, память, "эффект на запуск" |
| Производительность | GPU, диск (активное время), Ethernet |
| Автозагрузка | Влияние "Высокое" — отключить лишнее |
| Подробности | PID, командная строка, пользователь |
| Службы | Только если знаете зависимость |

Включите столбцы — **GPU**, **Имя процесса**, **Командная строка** (ПКМ по заголовку).

---

### Process Monitor — сценарий "диск 100%"

1. Запустить ProcMon от администратора.
2. Фильтр: Process Name `is` `System` **или** Include процесс подозрительный.
3. Воспроизвести лаг (открыть папку, запустить игру).
4. Смотреть Operation `Write` / `Read` с большим Length.
5. Часто виновник — индексатор, антивирус, облако (OneDrive sync), торрент.

### Журнал событий — что искать

| Журнал | ID / источник | Смысл |
| :--- | :--- | :--- |
| System | Kernel-Power 41 | Неожиданная перезагрузка (питание/драйвер) |
| System | disk | Ошибки диска |
| Application | Application Error | Падение exe |
| Windows Logs → Security | 4624 | Входы (на сервере важнее) |

Фильтр "Критический" и "Ошибка" за последние 24 часа — первый шаг после BSOD.

## Память — не путать "занято" и "нехватку"

Windows кэширует файлы в RAM — высокий "Используется" **не всегда** плохо. Смотрите:

- **Committed** / ошибки нехватки памяти в журнале;
- рост **Page file** % Time при лагах;
- для игр — [отдельная глава](/encyclopedia/1-basics/1-035-bazovaya-informatika/407).

Отключение файла подкачки "потому что 32 ГБ" — частая ошибка: при пике загрузится crash.

## Папки кэша — что можно трогать

| Путь / объект | Содержимое | Безопасность очистки |
| :--- | :--- | :--- |
| `%TEMP%`, `C:\Windows\Temp` | Временные установщики | Да, при закрытых программах |
| "Временные файлы" в Параметрах → Память | Кэш обновлений, корзина | Да, встроенный мастер |
| `C:\Windows\SoftwareDistribution\Download` | Кэш Windows Update | Осторожно: только если WU завис |
| Кэш браузера | Сайты, cookies | Да, потеряете входы на сайтах |
| `shadercache` (Steam, DX, NVIDIA/AMD) | Скомпилированные шейдеры | Да, **пересоздастся** (первый запуск игры дольше) |
| `C:\Windows\Prefetch` | Prefetch | Обычно не трогать вручную |
| `hiberfil.sys` | Гибернация | `powercfg -h off` освободит GB, потеряете гибернацию |
| `C:\Users\...\AppData\Local\Packages` | UWP-приложения | Нет — сломаете Store-приложения |
| `C:\Users\<you>\AppData\Local\Discord` | Кэш Discord | Да, перелогин |
| `C:\Users\<you>\AppData\Local\NVIDIA\DXCache` | Шейдеры GPU | Да, пересборка |
| `C:\ProgramData\NVIDIA Corporation\NV_Cache` | Драйвер NVIDIA | Осторожно |
| Steam `steamapps\shadercache` | Шейдеры игр | Да |
| Epic / GOG | Кэш лаунчера | Да |

**Не удаляйте** наугад: `C:\Windows\System32`, `WinSxS` "чистильщиками" из интернета — риск незагрузки системы.

---

### WinSxS и "очистка системы"

`Dism.exe /online /Cleanup-Image /AnalyzeComponentStore` — **легальный** анализ компонентов. Панель "Очистка диска" → "Системные файлы" → Windows Update Cleanup — после стабильных обновлений. Не используйте random `.bat` "очистить WinSxS".

---

### TreeSize / WizTree

Визуализация "кто съел диск" за минуту. Типичные сюрпризы — `node_modules`, старые ВМ VirtualBox, записи OBS, дампы игр.

---

### Очистка с умом

1. `Win+I` → Система → Память → **Контроль памяти**.
2. `cleanmgr` / "Очистка диска" → "Системные файлы".
3. Перенос игр и проектов на второй диск — лучше, чем "чистка" на системном.

## Телеметрия и приватность в Windows

**Телеметрия** — диагностические данные об ОС и сбоях (не "всё, что вы печатаете"). Уровни в параметрах зависят от редакции Windows; меньший уровень — меньше отправки.

Для power user:

- пройти **Параметры → Конфиденциальность и безопасность** после установки ОС;
- отключить ненужные разрешения приложений;
- не ставить "оптимизаторы", удаляющие службы без понимания.

[O&O ShutUp10++](https://www.ooshutup10.com/) меняет сотни параметров разом — **только** после точки восстановления и с проверкой **Windows Update** и Store. Официальные настройки предпочтительнее "твик-пакетов" с форумов.

Разумный баланс: отключить лишнее, **не** ломать Update и Defender.

## Автозагрузка и службы

`Ctrl+Shift+Esc` → **Автозагрузка** — главный рычаг. Отключайте:

- обновления игр, когда не играете;
- "помощники" принтеров и драйверов;
- дубликаты облаков (OneDrive + Dropbox + …).

Службы (`services.msc`) — только с пониманием зависимости. Документация Microsoft лучше форумного "отключи всё".

### RGB, материнские платы, "геймерский" софт

| Продукт | Что делает | Рекомендация |
| :--- | :--- | :--- |
| Armoury Crate (ASUS) | RGB, драйверы, обновления | Минимальная установка |
| iCUE (Corsair) | Подсветка + макросы клавиатуры | Закрывать при игре |
| RGB Fusion / Mystic Light | LED материнки | Часто конфликтует |
| Razer Synapse | DPI, подсветка | Фоновая сеть |

Если RAM "съедено" 400 МБ "пустым" RGB — удалите модуль подсветки или отключите автозапуск.

---

### Игровые лаунчеры и оверлеи

Держите **один** лаунчер активным во время игры. Отключите Xbox Game Bar запись фона, Instant Replay NVIDIA если не пользуетесь — экономия VRAM и CPU.

### PowerShell — быстрый аудит автозагрузки

```powershell
Get-CimInstance Win32_StartupCommand |
  Select-Object Name, Command, Location |
  Format-Table -AutoSize

Get-Process | Sort-Object CPU -Descending |
  Select-Object -First 15 Name, Id, CPU, WorkingSet64
```
