## Частые путаницы

| Путают | Как различать |
|--------|----------------|
| **Интернет** и **веб** | Интернет — вся сеть; веб — только сайты в браузере. Почтовый клиент и игра онлайн используют интернет, но не "сайт" |
| **Экран** и **интернет** | Монитор показывает картинку локально; интернет — связь с удалёнными серверами |
| **Файл** и **программа** | Документ `.docx` — файл; `Word.exe` — программа. И то и другое хранится как файл на диске, но назначение разное |
| **Скачать** и **установить** | Скачали установщик — это ещё не установка. Нужно запустить `.exe` / `.msi` и пройти шаги мастера |
| **ОЗУ** и **диск** | ОЗУ быстрая, но очищается при выключении; диск медленнее, но хранит годами |
| **Удалить** и **выключить ПК** | Удаление файла не выключает компьютер; выключение не стирает документы с диска |
| **Сайт** и **поисковик** | Google — поисковик; `wikipedia.org` — сайт |
| **Пароль от Wi‑Fi** и **пароль от почты** | Разные учётные записи; не используйте один пароль везде |
| **Ярлык** и **сам файл** | Удалили ярлык с рабочего стола — файл в папке остался |
| **Перезагрузка** и **сон** | Сон экономит энергию, программы "заморожены"; перезагрузка полностью перезапускает ОС |
| **Модем** и **роутер** | Часто один корпус — модем связан с провайдером, роутер раздаёт интернет по дому |
| **Cookie** и **вирус** | Cookie — маленькие текстовые файлы от сайтов; вирус — вредная программа |
| **Кэш** и **сохранённый файл** | Кэш — временные копии для скорости; "Сохранить как" — ваш файл на диске |
| **Аккаунт Google** и **почта @gmail.com** | Один аккаунт даёт почту, Диск, YouTube — пароль общий |
| **МБ** и **Мбит/с** | МБ — размер файла; Мбит/с — скорость интернета (другая единица) |
| **Разработчик** и **пользователь** | Разработчик пишет код; пользователь нажимает кнопки в готовой программе |
