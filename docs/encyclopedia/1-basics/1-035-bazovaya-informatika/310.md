# Microsoft 365 для пользователя и IT

<span class="complexity-badge">Всем</span>

Microsoft 365 (ранее Office 365) — это главное облачное SaaS-решение от компании Microsoft, объединяющее классические офисные приложения, облачные сервисы, продвинутую систему безопасности и глубоко интегрированный искусственный интеллект Microsoft Copilot. Платформа работает по модели подписки, обеспечивая постоянное обновление функций и сквозную синхронизацию между ПК, смартфонами и веб-версиями.

**Microsoft 365 (M365)** — подписка на офисные приложения и облачные сервисы — почта, чаты, файлы, видеосовещания. Раньше говорили "Office 365"; сейчас бренд **Microsoft 365** объединяет Office, Windows (в части планов) и **Entra ID** для входа.

Офисные форматы — [1.15 Текст](/encyclopedia/1-basics/1-15-tekst/211); корпоративный контекст — [1.04 IT в организациях](/encyclopedia/1-basics/1-04-kak-vidyat-it-obychnye-lyudi/5).

## Из чего состоит M365

| Сервис | Назначение для пользователя |
|--------|---------------------------|
| **Outlook / Exchange Online** | Почта, календарь, контакты |
| **Teams** | Чаты, каналы, звонки, совместные документы |
| **OneDrive** | Личное облачное хранилище файлов |
| **SharePoint** | Сайты команд, библиотеки документов, intranet |
| **Word, Excel, PowerPoint** | Desktop, web и mobile версии |
| **Copilot** (опционально) | ИИ-помощник в приложениях — см. [ответственное использование](/encyclopedia/6-ai/6-06-primenenie-ii/3) |

Outlook и Exchange — это клиент-серверная экосистема Microsoft для организации корпоративной почты, совместных календарей, задач и контактов. Они тесно связаны, но выполняют принципиально разные роли: Outlook — это программа-клиент на вашем устройстве, а Exchange — это серверная платформа (движок и хранилище), которая обрабатывает и распределяет всю информацию на бэкенде.

![Outlook.png](https://assets.spirzen.ru/encyclopedia/1-basics/1-22-kommunikatsiya-i-obschenie/Outlook.png)

Exchange управляет корпоративной инфраструктурой коммуникаций. Он принимает, отправляет, проверяет на спам и хранит всю переписку.

SharePoint хранит документы, файлы, корпоративные вики-страницы и структурированные списки. Он отвечает за информационную архитектуру и строгое разграничение прав доступа (Copilot никогда не покажет пользователю файл, к которому у него нет прав).

Microsoft Teams — пространство для чатов, звонков, каналов и совещаний. Это основная «витрина», где команда общается друг с другом и напрямую взаимодействует с искусственным интеллектом.

Copilot — облачный ИИ-ассистент, имеющий доступ к контексту вашей организации (через Microsoft Graph). Он мгновенно находит, анализирует и генерирует информацию на стыке файлов из SharePoint и обсуждений в Teams.

Word, Excel и PowerPoint — это классическое «ядро» офисного пакета Microsoft, которое сегодня работает как единый комплекс, объединенный облаком OneDrive и сквозным искусственным интеллектом Microsoft Copilot.

Microsoft Word - текстовый процессор, инструмент для создания документов, который с помощью ИИ теперь может писать, редактировать и форматировать тексты вместо пользователя.

Microsoft Excel - электронные таблицы, платформа для анализа данных и автоматизации расчетов, где знание сложных формул больше не является обязательным.

Microsoft PowerPoint - мастер презентаций, редактор для визуализации идей, в котором создание слайдов теперь занимает минуты, а не часы.

Идентичность и лицензии управляются в **Microsoft Entra** — [глава для IT](/encyclopedia/2-system-network/2-06-sistemnoe-administrirovanie/62).

## Пользователь и администратор

**Пользователь** создаёт файлы, ходит на meetings, не настраивает тенант.

**Администратор** (IT):

- создаёт учётки, группы, политики;
- назначает лицензии E1/E3/E5 или Business;
- настраивает безопасность (MFA, DLP, запрет пересылки);
- интегрирует с on-prem AD при гибриде.

Современные стандарты безопасности требуют, чтобы даже системные администраторы в повседневной жизни (для чтения почты, просмотра сайтов) использовали обычную учетную запись пользователя. Повышенные права администратора (в Linux — через команду sudo, в Windows — через «Запуск от имени администратора») должны включаться только в момент изменения настроек. Это защищает систему: если компьютер поймает вирус из интернета под учетной записью обычного пользователя, вредоносная программа не сможет заразить глубокие системные файлы, так как у нее не будет на это прав.

## Файлы — OneDrive и SharePoint

OneDrive — это официальное облачное хранилище данных от компании Microsoft, встроенное в операционные системы Windows 10 и Windows 11. Оно работает как виртуальная флешка, позволяя сохранять файлы в интернете на серверах Microsoft и иметь к ним доступ с любого устройства.

В системе Windows служба выглядит как обычная папка со значком синего или белого облака в проводнике и на панели задач. Любой файл, перенесенный в эту папку, мгновенно отправляется в облако. Если OneDrive вам не нужен, его можно легко отключить в настройках или полностью удалить из системы.

SharePoint — это платформа Microsoft для создания внутренних корпоративных сайтов, организации совместной работы и централизованного хранения документов в компаниях. Если OneDrive — это личный рабочий портфель сотрудника, то SharePoint — это общая библиотека и информационный центр всей организации.

- **OneDrive** — "мои файлы", шаринг по ссылке; синхронизация с папкой на ПК.
- **SharePoint** — командные библиотеки, версии, метаданные, workflow.

Потеря данных при увольнении решается политикой IT (архив почты, передача OneDrive), не "флешкой на столе".

Технически OneDrive работает на базе технологий SharePoint. Когда вы открываете общую папку команды в SharePoint, вы можете нажать кнопку «Синхронизировать», и эта папка появится на вашем компьютере в проводнике Windows рядом с вашим личным OneDrive.

## Microsoft Teams

Microsoft Teams — это корпоративная платформа компании Microsoft, которая объединяет в едином цифровом пространстве чаты, видеовстречи, заметки, совместную работу с документами и интеграцию с другими бизнес-приложениями. Платформа создана как ключевой элемент экосистемы Microsoft 365 и является главным конкурентом сервисов Slack и Zoom.

Каналы привязаны к команде проекта; чаты — к людям. Встречи с записью и расшифровкой снижают "знание только в головах". Интеграции (Planner, Power BI tile) превращают Teams в **точку входа**, а не "ещё один мессенджер".

Сравнение с другими: [мессенджеры](/encyclopedia/1-basics/1-035-bazovaya-informatika/305), [видеосвязь](/encyclopedia/1-basics/1-035-bazovaya-informatika/304).

## Безопасность для обычного сотрудника

Безопасность обычного сотрудника в Microsoft 365 строится на соблюдении цифровой гигиены и правильном использовании встроенных защитных инструментов. Главная задача пользователя — не стать «входной дверью» для хакеров, так как большинство корпоративных взломов начинается с человеческого фактора.

- Не принимайте MFA-запрос, если **вы** не входите.
- Не храните единственную копию критичного файла только локально без OneDrive/SharePoint.
- Внешний sharing — только по политике компании (guest access).

## Под капотом — Entra, Graph и лицензии

Если говорить простыми словами, Entra хранит данные пользователей, Graph позволяет программам с ними общаться, а лицензии определяют, какие функции безопасности и автоматизации вам доступны.

**Вход** в M365 идёт через **Microsoft Entra ID** (бывший Azure AD) — логин → OAuth/OpenID → токены доступа к Outlook, Teams, OneDrive. MFA добавляет второй фактор (приложение, SMS, ключ) — без него украденный пароль часто бесполезен.

**Microsoft Graph** — единый HTTP API "всего Microsoft 365" — почта, файлы, календарь, пользователи. Клиенты Teams и Outlook ходят в Graph; админские скрипты PowerShell тоже.

| План (упрощённо) | Что даёт сотруднику |
|------------------|---------------------|
| **Business Basic** | Веб-офис, Teams, OneDrive |
| **Business Standard** | + десктопные Word/Excel |
| **E3/E5** (enterprise) | Exchange, compliance, расширенная безопасность |

**OneDrive sync** — клиент на ПК: файлы в `%UserProfile%\OneDrive`, конфликты — две копии с меткой. **SharePoint** — библиотека на сайте команды; версии файлов в облаке, не на диске C:.

**Teams** для звонка использует тот же медиастек, что и [видеосвязь](/encyclopedia/1-basics/1-035-bazovaya-informatika/304) (кодеки, SFU в облаке Microsoft).
