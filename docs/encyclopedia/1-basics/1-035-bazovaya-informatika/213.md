# Знакомство с Android

<div class="article-tags">
  <span class="tag tag-required">ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

<span class="complexity-badge">Всем</span>

**Android** — операционная система Google для смартфонов и планшетов. Исходный код открыт; Samsung, Xiaomi, Google Pixel и другие производители добавляют свою оболочку (One UI, MIUI, чистый Android).

**Google Play** — основной магазин приложений, аналог App Store на iPhone. На части устройств в РФ доступны RuStore и другие магазины — ставьте приложения только из **известных** источников.

Ядро Android основано на **Linux** — см. [Первые шаги в Linux](/encyclopedia/1-basics/1-035-bazovaya-informatika/212). Фото и документы с телефона — в [облаке](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7). При связке с Mac — [macOS](/encyclopedia/1-basics/1-035-bazovaya-informatika/211).

См. [мобильные устройства](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/712).

## Мини-глоссарий

| Термин | Простое объяснение |
|--------|-------------------|
| **Оболочка (launcher)** | Внешний вид меню и настроек (One UI, MIUI) |
| **Google-аккаунт** | Вход в Gmail, Play, синхронизация контактов |
| **APK** | Файл установки приложения вне магазина |
| **Разрешения** | Доступ приложения к камере, контактам, геолокации |
| **Шторка** | Панель уведомлений сверху экрана |
| **Жесты** | Управление без кнопок — свайпы с краёв |
| **MTP** | Режим USB для копирования файлов на ПК |
| **OEM** | Производитель телефона (Samsung, Xiaomi) |
| **Find My Device** | Поиск и блокировка потерянного телефона |

## Первичная настройка — пошагово

### Шаг 1. Включение и язык

1. Вставьте SIM при необходимости, включите питание.
2. Выберите язык и регион.
3. Подключитесь к **Wi‑Fi** — без интернета не настроить аккаунт и магазин.

### Шаг 2. Google-аккаунт

![accountsettings2.png](https://assets.spirzen.ru/encyclopedia/1-basics/1-035-bazovaya-informatika/accountsettings2.png)

1. Войдите в существующий Gmail или создайте новый.
2. Укажите **резервную почту** и телефон для восстановления.
3. Включите **двухфакторную аутентификацию** позже в настройках Google.

### Шаг 3. Блокировка экрана

![androidsec.png](https://assets.spirzen.ru/encyclopedia/1-basics/1-035-bazovaya-informatika/androidsec.png)

1. PIN (6 цифр), графический ключ, отпечаток или лицо.
2. PIN надёжнее простого ключа из 4 точек.
3. Настройте **Smart Lock** только если понимаете риски (разблокировка дома).

### Шаг 4. Обновления

![updateandroid.png](https://assets.spirzen.ru/encyclopedia/1-basics/1-035-bazovaya-informatika/updateandroid.png)

1. **Настройки → Обновление ПО** (название зависит от оболочки).
2. Установите все доступные патчи безопасности.
3. Периодически проверяйте раз в месяц.

### Шаг 5. Резервная копия

1. **Настройки → Google → Резервное копирование** — включить. Но учтите - это конечно восстановит ваш телефон, однако ваши данные будут в облачных серверах!
2. **Google Фото** — автозагрузка снимков. См. [бэкап](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7). Лично я не использую. Здесь на свой вкус..
3. Дождитесь завершения первой синхронизации на Wi‑Fi.

### Шаг 6. Find My Device

1. **Настройки → Безопасность → Find My Device** — включить. Но это будет отслеживать вашу позицию постоянно.
2. Проверьте на сайте google.com/android/find с ПК.

## Жесты и кнопки

Лично я не использую жесты, но это современный стиль, когда движениями пальцев можно управлять смартфоном.

| Действие | Как |
|----------|-----|
| Домой | Кнопка или жест снизу вверх |
| Назад | Жест с левого/правого края или кнопка "Назад" |
| Недавние приложения | Кнопка "Квадрат" или жест снизу с паузой |
| Уведомления | Свайп сверху вниз |
| Быстрые настройки | Второй свайп или иконки в шторке |
| Скриншот | Кнопки Питание + Уменьшение громкости (зависит от модели) |
| Google Ассистент | Удержание кнопки Home или жест с угла |

На новых Android часто **навигация жестами** без трёх кнопок. Переключение в **Настройки → Система → Жесты → Навигация**.

## Установка приложений — пошагово

### Через Google Play

1. Откройте **Play Маркет**.
2. Войдите в Google-аккаунт, если просит.
3. Поиск → выберите приложение → **Установить**.
4. После установки — **Открыть** или иконка на рабочем столе.

### Через RuStore и другие магазины

- Используйте, если Play недоступен или нужны локальные сервисы.
- Проверяйте разработчика и отзывы.
- Не ставьте "взломанные" версии платных программ.

### APK вне магазина

1. Файл `.apk` из **доверенного** источника (сайт разработчика).
2. **Настройки → Безопасность → Неизвестные источники** — разрешить для конкретного приложения (например, браузера), не для всех подряд.
3. После установки отключите лишние разрешения.

**Не включайте** установку из чатов и рекламных страниц — высокий риск вирусов и кражи данных.

Подробнее — [мобильные приложения](/encyclopedia/1-basics/1-19-programma/3).

## Память и батарея

### Внутреннее хранилище

- Фото, видео, приложения занимают гигабайты.
- При заполнении телефон **тормозит**, обновления не ставятся.
- **Настройки → Хранилище** — что занимает место.

См. [управление памятью](/encyclopedia/1-basics/1-035-bazovaya-informatika/217).

### Карта microSD

- Если есть слот — часто только для **медиа** (фото, музыка), не для всех приложений.
- Форматируйте как портативное хранилище, не как "внутреннюю память", если не уверены.

### Батарея

| Приём | Эффект |
|-------|--------|
| Уменьшить яркость | Заметная экономия |
| Ограничить фоновую работу "тяжёлых" приложений | Меньше разряд в кармане |
| Закрыть лишнее из "Недавних" | Иногда помогает при лагах |
| Режим энергосбережения | Дольше работа, меньше производительность |

**Миф:** постоянное закрытие всех приложений не всегда экономит батарею — система сама усыпляет фон.

## Связь с компьютером

### USB-кабель

1. Подключите телефон к ПК.
2. На телефоне выберите **Передача файлов (MTP)** в уведомлении USB.
3. На Windows — телефон в Проводнике. На Mac — Android File Transfer или облако.
4. На [Linux](/encyclopedia/1-basics/1-035-bazovaya-informatika/212) — файловый менеджер покажет устройство в `/run/user/...`

### Облако без провода

- **Google Drive**, **Яндекс.Диск** — документы и фото.
- См. [Облако и бэкап](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7).

### Мессенджеры на ПК

- **WhatsApp Web**, **Telegram Desktop** — после привязки по QR-коду.
- См. [мессенджеры](/encyclopedia/1-basics/1-035-bazovaya-informatika/305).

### Перенос на новый телефон

## Практические сценарии

### Сценарий 1. Новый телефон из коробки

1. Зарядить до 50 %+.
2. Wi‑Fi, Google-аккаунт, PIN.
3. Обновление системы.
4. Google Фото — автозагрузка.
5. Установить банк, мессенджер, 2ГИС/Карты с Play.
6. Удалить предустановленный мусор (игры, демо), если не нужен.

### Сценарий 2. Телефон родителя

Упростить интерфейс, крупный шрифт, белый список приложений. См. [настройка для пожилых](/encyclopedia/1-basics/1-035-bazovaya-informatika/206).

### Сценарий 3. Ребёнок и телефон

[Родительский контроль](/encyclopedia/1-basics/1-035-bazovaya-informatika/218), Family Link от Google, лимиты экранного времени.

### Сценарий 4. Потеряли телефон

1. С другого устройства — google.com/android/find.
2. Звонок, блокировка, сообщение на экран.
3. Если не вернётся — удаление данных удалённо (фото в облаке сохранятся).

### Сценарий 5. Мало места

1. Хранилище → очистить кэш мессенджеров (не удаляя чаты).
2. Google Фото — освободить место (только если оригиналы в облаке!).
3. Перенести видео на ПК или облако.
4. Удалить неиспользуемые приложения.

## Частые ошибки

### Ошибка 1. Не настроить бэкап фото

Телефон утонул или разбился — без облака фото потеряны. См. [бэкап](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7).

### Ошибка 2. APK из Telegram-чата

Поддельные банки и "бесплатные" игры крадут пароли. Только магазины и официальные сайты.

### Ошибка 3. Разрешить всё подряд

Игра просит доступ к SMS и контактам — отказать и удалить.

### Ошибка 4. "Освободить место" в Google Фото без проверки облака

Телефон удалит оригиналы, а загрузка не завершилась на Wi‑Fi. Дождитесь зелёной галочки синхронизации.

### Ошибка 5. Игнорировать обновления безопасности

Патчи закрывают дыры, через которые взламывают телефон.

### Ошибка 6. Один слабый пароль на Google и всё остальное

Взлом Gmail = доступ к фото, почте, банковским письмам. Уникальный пароль и 2FA.

### Ошибка 7. USB только зарядка

Выбрать "Передача файлов" в уведомлении при подключении к ПК.

## Устранение неполадок

### Телефон тормозит

| Причина | Решение |
|---------|---------|
| Память заполнена | Очистка, удаление приложений |
| Перегрет | Дать остыть, снять чехол |
| Старая версия Android | Обновление или сброс (с бэкапом) |
| Рекламная оболочка | Отключить рекомендации в лаунчере MIUI и др. |

### Не скачивается приложение из Play

1. Очистить кэш Play Маркета (Настройки → Приложения → Google Play).
2. Проверить место на диске.
3. Стабильный Wi‑Fi или мобильный интернет.

### Быстро садится батарея

1. **Настройки → Батарея** — какое приложение жрёт.
2. Отключить геолокацию для лишних программ.
3. Снизить яркость, отключить Always-On Display.
4. Проверить кабель и блок питания (дешёвые зарядки портят батарею).

### Не подключается Wi‑Fi

1. Забыть сеть, ввести пароль заново.
2. Перезагрузить роутер.
3. См. [сеть и интернет](/encyclopedia/2-system-network/2-03-set-i-internet/intro).

### Не видит SIM

1. Извлечь, протереть, вставить заново.
2. Режим полёта выключен.
3. APN настроены оператором автоматически — при сбое запросить у поддержки.

### Забыли графический ключ

После нескольких попыток — вход через Google-аккаунт или **сброс к заводским** (потеря локальных данных без бэкапа).

## FAQ

**Нужен ли Google-аккаунт?**

Для Play, нормального бэкапа и Find My Device — да. Без Google телефон ограничен (Huawei без GMS — отдельный случай).

**Сколько памяти выбрать в телефоне?**

64 ГБ — минимум и тесно. 128 ГБ — комфорт для фото и приложений. 256 ГБ — если много видео offline.

**Можно ли удалить предустановленные приложения?**

Часть — да. Часть только "отключить" в настройках. Не удаляйте системные без инструкции.

**Как перенести контакты?**

Синхронизация с Google-аккаунтом. На новом телефоне войти в тот же аккаунт. См. [адресная книга](/encyclopedia/1-basics/1-035-bazovaya-informatika/219).

**Безопасны ли публичные Wi‑Fi?**

Для банка и паролей — VPN или мобильный интернет. Для просмотра новостей — обычно допустимо.

**Что такое сброс к заводским?**

Удаление всех данных и возврат к состоянию из коробки. Перед сбросом — бэкап в облако.

**Как связать с Linux на ПК?**

USB MTP, KDE Connect, Syncthing. См. [Linux](/encyclopedia/1-basics/1-035-bazovaya-informatika/212).

**Почему телефон не видит SIM?**

Проверьте слот, перезагрузка, режим полёта. Возможен сбой прошивки — сервисный центр.

**Как отключить рекламу в оболочке Xiaomi?**

Настройки → Рекомендации → отключить в лаунчере, браузере, безопасности. Требует терпения — пунктов много.

**Нужен ли антивирус на Android?**

Play Protect встроен. Сторонние "антивирусы" часто сами показывают рекламу. Главное — не ставить APK из чатов.

## Пошаговая настройка Google Drive на Android

1. Установите **Google Drive** из Play.
2. Войдите в тот же аккаунт, что и для Фото.
3. Кнопка **+** → **Загрузить** — выберите PDF или фото с телефона.
4. **Настройки** → включите резервное копирование папок (если доступно в версии).
5. На ПК откройте drive.google.com — файл должен появиться.
6. Для автоматической синхронизации папки "Сканеры" — создайте папку в Drive и загружайте туда привычкой.

См. [облако и бэкап](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7).

## Пошаговая передача файла на Windows по USB

1. Подключите кабель USB-C или micro-USB к ПК.
2. На телефоне уведомление **USB** — выберите **Передача файлов** / **MTP**.
3. На Windows откройте **Проводник** → устройство → Internal storage → DCIM для фото.
4. Скопируйте в папку на диске (не только в синхронизируемую папку OneDrive без проверки места).
5. Безопасно извлеките: в трее Windows — "Извлечь устройство".

На [Mac](/encyclopedia/1-basics/1-035-bazovaya-informatika/211) — приложение Android File Transfer или облако.

## Пошаговая настройка Family Link (детский аккаунт)

1. Установите **Google Family Link** на телефон родителя.
2. Создайте детский Google-аккаунт на телефоне ребёнка.
3. Привяжите к семье, установите лимиты времени и фильтр контента.
4. Покупки в Play — только с одобрения.
5. См. [родительский контроль](/encyclopedia/1-basics/1-035-bazovaya-informatika/218).

## Дополнительные частые ошибки

### Ошибка 8. Два аккаунта Google на одном телефоне

Путаница с бэкапом — фото уходят не в тот аккаунт. Проверяйте активный аккаунт в Google Фото.

### Ошибка 9. Отключить все уведомления системы

Пропустите коды банка и важные обновления. Отключайте точечно по приложениям.

### Ошибка 10. Покупка памяти у неверified продавца

Поддельные microSD ломаются и теряют данные. Бренды SanDisk, Samsung, Kingston из официальных магазинов.

## Дополнительное устранение неполадок

### Экран не реагирует

1. Удержание питания 10–20 сек — перезагрузка.
2. Если есть — сброс кнопками громкости (инструкция к модели).
3. Разбитый экран — USB к ПК, управление мышью на ПК через scrcpy (для продвинутых).

### Приложение вылетает

1. Настройки → Приложения → [имя] → Очистить кэш (не данные, если не готовы потерять вход).
2. Обновить из Play.
3. Переустановить.

### Не приходят SMS

1. Проверить слот SIM, баланс, не блокирует ли SMS-фильтр банка.
2. Сброс сетевых настроек (крайний случай — сбросит Wi‑Fi пароли).

### Геолокация "прыгает"

Включить высокую точность (GPS + Wi‑Fi). На метро возможны ошибки — нормально.
