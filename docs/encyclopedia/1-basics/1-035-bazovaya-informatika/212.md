# Первые шаги в Linux

<div class="article-tags">
  <span class="tag tag-required">ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

<span class="complexity-badge">Всем</span>

**Linux** — семейство бесплатных операционных систем с открытым исходным кодом. Их ставят на старые ноутбуки, серверы в дата-центрах и внутри Windows через **WSL** (Windows Subsystem for Linux — подсистема Linux в Windows 11/10).

Для быстрого и безопасного старта в Linux лучше всего установить дистрибутив Linux Mint или Ubuntu на виртуальную машину (VirtualBox) или запустить его в режиме Live USB без изменения основной системы. Это убережет ваши данные от случайного удаления и позволит спокойно изучить новую среду. 

Linux полезен обычному пользователю как альтернатива Windows и будущему IT-специалисту как среда, в которой работает большинство сайтов и сервисов в интернете. На Mac многие команды терминала похожи — см. [Первые шаги в macOS](/encyclopedia/1-basics/1-035-bazovaya-informatika/211). Телефон на [Android](/encyclopedia/1-basics/1-035-bazovaya-informatika/213) тоже основан на ядре Linux.

| Термин | Простое объяснение |
|--------|-------------------|
| **Дистрибутив** | Готовая сборка Linux с программами и оформлением |
| **Ядро** | Сердце системы, управляет железом |
| **Рабочий стол** | Графическая оболочка: GNOME, KDE, XFCE |
| **Терминал** | Текстовое окно для команд |
| **sudo** | Выполнить команду от имени администратора |
| **root** | Суперпользователь с полными правами |
| **Репозиторий** | Каталог программ, откуда система ставит софт |
| **Пакет** | Установочный архив программы (.deb, .rpm) |
| **WSL** | Linux внутри Windows без перезагрузки |
| **Live USB** | Запуск Linux с флешки без установки на диск |

Главные причины, почему люди выбирают Linux вместо Windows или macOS — это полный контроль над системой, высокая безопасность, бесплатность и приватность. Linux дает пользователю свободу, которой нет в коммерческих операционных системах. Система никогда не перезагрузится сама посреди важной работы. Вы сами решаете, что и когда обновлять. 

Можно изменить абсолютно всё — от внешнего вида окон и анимаций до замены самого графического интерфейса или ядра системы. В Linux нет встроенных игр, рекламы в меню «Пуск» или неудаляемых браузеров. В отличие от Windows 11 с её функциями ИИ-скрининга и телеметрии, Linux не собирает ваши личные данные, пароли и историю поиска для отправки в корпорации. Архитектура Linux устроена так, что вредоносным программам крайне сложно получить доступ к системным файлам без явного разрешения пользователя (через ввод пароля `sudo`).

Linux потребляет в разы меньше оперативной памяти и ресурсов процессора, чем современные версии Windows. Почти все серверы в мире, облачные технологии и базы данных работают на Linux. Разработчикам удобнее писать код в той же среде, где он будет выполняться.

Установка, удаление и обновление всего софта на компьютере происходит одной командой в терминале или через единый центр приложений.

Благодаря развитию технологий Proton от компании Valve (создателей Steam и консоли Steam Deck), на Linux сейчас без проблем запускаются тысячи современных игр, созданных для Windows, зачастую с той же или даже большей производительностью.

## Несколько способов попробовать

| Способ | Для кого | Риск для данных на ПК |
|--------|----------|------------------------|
| **Live USB** | Посмотреть без установки | Нет, если не нажимать "Install" |
| **Двойная загрузка** | Linux и Windows на одном диске | Средний — нужен свободный раздел |
| **WSL2** в Windows 11 | Учёба и разработка | Низкий |
| **Виртуальная машина** | Эксперименты | Низкий |

Виртуальная машина - самый безопасный способ. Вы запускаете Linux как обычную программу внутри Windows:
1. Скачайте и установите бесплатную программу VirtualBox.
2. Скачайте `.iso` образ нужного Linux (например, Linux Mint).
3. В VirtualBox нажмите Создать, укажите имя и выберите скачанный ISO-образ.
4. Выделите под виртуалку часть оперативной памяти (минимум 4 ГБ) и ядер процессора.
5. Запустите виртуальную машину и пройдите стандартную установку внутри окна.

WSL2 (Windows Subsystem for Linux) - официальный инструмент от Microsoft, который встраивает полноценное ядро Linux прямо внутрь Windows 10/11:
1. Откройте Терминал Windows или командную строку от имени администратора.
2. Введите команду: `wsl --install`
3. Перезагрузите компьютер. После перезагрузки откроется консоль Ubuntu, где нужно будет придумать логин и пароль.

По умолчанию доступна только командная строка (терминал), графический рабочий стол нужно настраивать отдельно.

Live USB (Запуск с флешки) - это запуск полноценной Linux напрямую с флеш-накопителя без установки на жесткий диск.
1. Возьмите флешку объемом от 8 ГБ (все данные с нее сотрутся).
2. Скачайте программу Rufus или Ventoy и ISO-образ Linux.
3. Запишите образ на флешку через выбранную программу.
4. Перезагрузите ПК, во время включения зажмите клавишу вызова Boot Menu (обычно F12, F11 или Esc) и выберите вашу флешку.
5. В появившемся меню выберите пункт "Try Linux" (Попробовать без установки).

Двойная загрузка (Dual Boot) - это установка Linux полноценной второй системой рядом с Windows. При каждом включении компьютера вы будете выбирать, в какую ОС зайти.
1. В Windows откройте «Управление дисками» и «сожмите» один из дисков, освободив минимум 30–50 ГБ неразмеченного пространства.
2. Создайте загрузочную флешку (как в способе с Live USB).
3. Загрузитесь с флешки и запустите ярлык "Install Linux" на рабочем столе.
4. На этапе разметки диска критически важно выбрать пункт «Установить рядом с Windows» (Install alongside Windows).
5. Завершите установку и перезагрузите ПК.

Новичку на Windows 10/11 чаще всего достаточно **WSL** — см. [операционные системы, WSL](/encyclopedia/2-system-network/2-01-operatsionnaya-sistema/intro).

## Пошаговая установка WSL (Windows 11)

### Шаг 1. Проверка версии Windows

Для успешной установки WSL2 вам потребуется Windows 11 (любая сборка) или Windows 10 (версия 1903 или выше, с билдом системы 18362+). 

1. **Win+R** → `winver` — нужна Windows 10 (2004+) или Windows 11.
2. Включите виртуализацию в BIOS, если WSL не ставится (часто уже включена).

Если у вас установлена Windows 11, ваша система полностью готова к автоматической установке WSL2.

### Шаг 2. Установка одной командой

1. Откройте **PowerShell от имени администратора**.
2. Выполните: `wsl --install`
3. Перезагрузите ПК.
4. При первом запуске создайте **имя пользователя** и **пароль** Linux (запомните — для sudo).

Команда `wsl --install` автоматически скачивает, активирует и настраивает все необходимые компоненты для запуска Linux. Вам больше не нужно вручную заходить в панели управления или скачивать пакеты обновлений ядра. Команда:
- Включает платформу виртуальной машины (Virtual Machine Platform). Активирует встроенную в Windows технологию виртуализации, необходимую для работы изолированных систем.
- Включает компонент подсистемы Windows для Linux (WSL). Разрешает Windows запускать процессы Linux.
- Скачивает и устанавливает ядро Linux (WSL2). Загружает официальное, специально оптимизированное Microsoft ядро Linux, которое будет обновляться через Центр обновления Windows.
- Скачивает и устанавливает дистрибутив по умолчанию. Автоматически загружает из Microsoft Store и устанавливает последнюю стабильную версию Ubuntu.
- Настраивает графический сервер (WSLg). Включает поддержку запуска полноценных графических Linux-приложений (GUI) прямо внутри окон Windows.

После перезагрузки компьютера автоматически откроется черное консольное окно Ubuntu.

### Шаг 3. Выбор дистрибутива

- По умолчанию часто ставится **Ubuntu**. Если вы хотите выбрать другую операционную систему (например, Debian или Kali Linux), это нужно сделать до первой перезагрузки или в любой момент позже.
- Список: `wsl --list --online`, установка: `wsl --install -d Debian`

Обычно в список входят:
- Ubuntu (разные версии)
- Debian GNU/Linux (для любителей стабильности)
- Kali Linux (для тестирования безопасности и хакинга)
- openSUSE (Leap и Tumbleweed)
- Oracle Linux

Чтобы установить конкретную систему из списка, используйте флаг `-d` (distribution) и укажите точное имя из столбца `NAME`.

```bash
wsl --install -d Debian
```

Windows скачает выбранную систему, после чего она появится в вашем меню «Пуск» как отдельное приложение. Вы можете установить даже несколько разных дистрибутивов одновременно — они не будут мешать друг другу.

### Шаг 4. Первые команды

После создания учетной записи перед вами откроется командная строка Linux. Теперь вы управляете системой исключительно с помощью текста.

В Linux из соображений безопасности у обычного пользователя нет прав на изменение системных файлов или установку программ. `sudo` (SuperUser Do) — это команда, которая временно дает вам права администратора (суперпользователя root). Это аналог функции «Запуск от имени администратора» в Windows.

Когда вы вводите команду с `sudo`, система попросит пароль. При вводе пароля на экране не будут появляться символы, звездочки или точки. Курсор будет стоять на месте. Это нормальное поведение Linux для защиты от подглядывания. Просто введите пароль вслепую и нажмите Enter.

В Linux программы не скачивают с сайтов через браузер. Для этого есть менеджеры пакетов. `apt` (Advanced Package Tool) — это встроенный «магазин приложений» в дистрибутивах Ubuntu и Debian. С его помощью через терминал можно устанавливать, обновлять и удалять любые программы.

Прежде чем устанавливать новые программы, нужно обновить списки доступных пакетов в репозиториях (базах данных софта). Введите в терминал:

```bash
sudo apt update
```

WSL свяжется с официальными серверами и скачает актуальные «списки» доступного софта. Она проверит, не вышли ли новые версии программ. Сама команда `update` только обновляет списки, но не устанавливает новые версии. Чтобы реально обновить систему и все программы до актуального состояния, сразу после первой команды введите вторую:

```bash
sudo apt upgrade -y
```

Флаг `-y` автоматически соглашается со всеми вопросами системы в процессе.

### Шаг 5. Доступ к файлам

Одно из главных преимуществ WSL2 — это бесшовная интеграция файлов. Вам не нужно копировать данные из одной системы в другую, так как обе ОС имеют прямой доступ друг к другу.

В WSL2 все локальные диски вашего компьютера (`C:`, `D:` и т.д.) автоматически «монтируются» (подключаются) в специальную системную папку `/mnt/`.

Microsoft сделала этот процесс максимально простым. Вы можете работать с файлами Linux прямо через стандартный графический Проводник Windows.

- Файлы Windows: `/mnt/c/Users/ВашеИмя/`
- Из Проводника Windows: адрес `\\wsl$\Ubuntu\home\ваш_логин`

Ваша привычная папка «Загрузки» (Downloads) пользователя Windows будет находиться по адресу:`/mnt/c/Users/Ваше_Имя_Пользователя/Downloads/`

Linux чувствителен к регистру букв. Путь `/mnt/c/users/` выдаст ошибку, нужно писать именно с большой буквы: `/mnt/c/Users/`.

См. [настройку Windows](/encyclopedia/1-basics/1-035-bazovaya-informatika/207).

## Пошаговая установка Live USB

### Шаг 1. Подготовка

Для создания Live USB вам понадобятся три вещи: флешка, ISO-образ операционной системы и специальная программа для записи. На этапе подготовки мы соберем всё необходимое. Вам нужен USB-накопитель емкостью от 8 ГБ (для большинства современных дистрибутивов этого более чем достаточно). В процессе записи все данные с флешки будут полностью удалены. Обязательно скопируйте важные файлы на компьютер перед началом. 

ISO-образ — это слепок установочного диска. Скачивать его нужно только с официальных сайтов. Чтобы флешка стала загрузочной (компьютер смог включиться с нее), простой перенос ISO-файла на флешку не поможет.

1. USB-флешка 8 ГБ+ (все данные на ней будут стёрты).
2. Скачайте образ **Ubuntu** или **Linux Mint** с официального сайта (.iso).
3. Программа **Rufus** (Windows) или **Etcher** — запись образа на флешку.


### Шаг 2. Загрузка с флешки

Теперь ваша задача — заставить компьютер запуститься не с жесткого диска с Windows, а с созданной флешки.Для этого нужно использовать Boot Menu (Меню загрузки) вашего компьютера.

Полностью выключите компьютер или ноутбук (не используйте спящий режим). Убедитесь, что ваша загрузочная флешка вставлена в порт USB (желательно использовать быстрый порт USB 3.0 — он обычно синего цвета).

1. Перезагрузка → Boot Menu (F12, F2, Esc — зависит от ПК). Сразу же, не дожидаясь появления логотипа Windows, начинайте часто и многократно нажимать клавишу вызова Boot Menu. Клавиша зависит от производителя вашей материнской платы или ноутбука. Если всё сделано правильно, на экране откроется небольшое текстовое или графическое меню со списком всех дисков.
2. Выберите USB-накопитель. Если в списке есть два варианта вашей флешки (например, просто имя флешки и вариант с приставкой UEFI), всегда выбирайте вариант с UEFI.
3. **Try Ubuntu** / **Попробовать** — система загрузится в RAM, диск не трогается.

### Шаг 3. Оценка

После того как вы выбрали флешку в Boot Menu, перед вами откроется рабочий стол Linux. Система работает полностью из оперативной памяти компьютера — это и есть Live-режим. На этом этапе ваша задача — провести оценку (тестирование) системы, чтобы убедиться, что всё ваше оборудование работает корректно, прежде чем принимать решение об установке.

- Wi‑Fi, звук, тачпад работают?
- Если да — можно ставить рядом с Windows (раздел "Install alongside Windows").

**Не нажимайте "Erase disk"**, если не уверены на 100 %.

Если вам всё понравилось и вы хотите установить систему навсегда: найдите на рабочем столе ярлык «Install Linux» (Установить) и запустите его. Если вы просто посмотрели и хотите вернуться в Windows: нажмите «Пуск» -> «Выключить» (Shut Down). Система попросит вытащить флешку и нажать Enter. Компьютер перезагрузится в вашу привычную Windows в исходном состоянии.

## Дистрибутивы для начинающих

Дистрибутивы существуют потому, что Linux в чистом виде — это всего лишь «ядро» (двигатель), а не готовая операционная система. Чтобы компьютером мог пользоваться человек, этому двигателю нужен кузов, колеса и салон. Это готовый комплект, в который разработчики объединяют ядро Linux, графическую оболочку и набор базовых программ.

**Дистрибутив** — конкретная сборка Linux с выбранным рабочим столом и набором программ.

| Дистрибутив | Особенность |
|-------------|-------------|
| **Ubuntu** | Много русскоязычных инструкций, крупное сообщество |
| **Linux Mint** | Похож на классический рабочий стол Windows |
| **Fedora** | Свежие пакеты, близко к корпоративным серверам |
| **Debian** | Стабильность, основа Ubuntu и многих серверов |
| **Pop!_OS** | Удобен на ноутбуках с NVIDIA |
| **Zorin OS** | Интерфейс, похожий на Windows |

Arch и другие минималистичные дистрибутивы лучше отложить до появления опыта.

### Выбор рабочего стола

Выбор графической оболочки (или рабочего стола) в Linux определяет не только внешний вид системы, но и то, сколько оперативной памяти она будет потреблять. В отличие от Windows, в Linux можно легко заменить один рабочий стол на другой без переустановки системы.

| Оболочка | Ощущения |
|----------|----------|
| **GNOME** | Современный, минималистичный (Ubuntu по умолчанию) |
| **KDE Plasma** | Гибкая настройка, похожа на Windows |
| **XFCE** | Легковесная, для слабых ПК |
| **Cinnamon** | Классическое меню Пуск (Linux Mint) |

## Первый день на рабочем столе — пошагово

### Шаг 1. Обновления

Первый запуск графического рабочего стола Linux — ответственный момент. Ваша главная задача в первый день — сделать систему безопасной, стабильной и настроенной под ваше железо. В отличие от Windows, в Linux при первом запуске обновляется не только сама операционная система, но и абсолютно все предустановленные программы (браузер, плееры, офисный пакет). Это гарантирует защиту от багов и уязвимостей.

У вас есть два пути выполнения этого шага: через графический интерфейс или через Терминал.

**Графически:** Software Update / Центр обновлений.

**В терминале (Ubuntu/Debian):**

```bash
sudo apt update
sudo apt upgrade -y
```

Перезагрузка, если обновилось ядро: `sudo reboot`

### Шаг 2. Файлы

После обновления системы пора разобраться с тем, как устроено хранение данных в Linux и где искать свои документы. Файловая структура здесь сильно отличается от Windows, но графический «Проводник» (в Linux он называется Менеджер файлов) сделает этот переход безболезненным.

1. Откройте файловый менеджер (**Nautilus** в Ubuntu, **Dolphin** в KDE).
2. Домашняя папка обозначается `~` или `/home/ваш_логин`.
3. Стандартные папки: Documents, Downloads, Pictures — как на Windows/Mac.

### Шаг 3. Браузер

Браузер станет вашим главным окном в интернет, инструментом для работы и местом, где можно быстро найти ответы на любые вопросы по новой системе. В большинстве популярных дистрибутивов (Ubuntu, Linux Mint, Debian) по умолчанию уже установлен Mozilla Firefox.

- **Firefox** часто установлен.
- **Chromium** или **Chrome** — из магазина приложений.

### Шаг 4. Терминал

На этом шаге мы не будем ломать систему сложным кодом, а научимся трем вещам: как его открыть, как в нем ориентироваться и как установить полезную утилиту. Командная строка — это тот же «Проводник», но без картинок.

В любой графической оболочке Linux (Cinnamon, GNOME, KDE, XFCE) работает одна универсальная комбинация клавиш:

1. **Ctrl+Alt+T** (Ubuntu) или найти в меню приложений.
2. Базовые команды: `ls` (список файлов), `cd` (перейти в папку), `pwd` (где я).
3. См. [терминал](/encyclopedia/2-system-network/2-05-terminal/intro), [знаки в командной строке](/encyclopedia/2-system-network/2-05-terminal/11).

### Шаг 5. sudo

Команда sudo — это главный инструмент безопасности в Linux. Она расшифровывается как SuperUser Do (выполнить от имени Суперпользователя). В Linux обычный пользователь изолирован от системных файлов. Вы можете делать всё что угодно внутри своей домашней папки (удалять фото, качать фильмы), но не можете влиять на работу всего компьютера. Приставка sudo перед любой командой временно дает вам права Администратора (root).

**sudo** — команда "выполнить от имени администратора". Система спросит ваш пароль — при вводе символы **не отображаются**, это нормально. 

```bash
sudo apt install htop
```

Аналог UAC в Windows. Не работайте постоянно под root. Приставка sudo дает беспрекословную власть над компьютером. Система не будет переспрашивать «Вы уверены?», если вы прикажете ей удалиться.

Никогда не копируйте и не вставляйте в терминал огромные команды с sudo из непроверенных источников в интернете, если не понимаете, что они делают.

## Установка программ

### Магазин приложений

Магазин приложений (в разных дистрибутивах он называется Менеджер программ, Центр приложений или Software) — это графический аналог App Store или Google Play. Это самый безопасный и простой способ устанавливать софт в Linux без использования терминала.

- **Ubuntu Software** — графический каталог, как App Store.
- Поиск → Установить → введите пароль sudo.

В отличие от Windows, куда программы скачиваются со случайных сайтов в интернете, Магазин приложений в Linux берет софт из репозиториев — официальных, проверенных и защищенных хранилищ дистрибутива. Все программы там гарантированно очищены от вирусов, скрытой рекламы и майнеров.

Иногда на странице одной и той же программы в магазине в правом верхнем углу вы можете увидеть выпадающее меню «Источник» (Source). Там на выбор предлагаются разные форматы. Вот в чем разница:

### Терминал (APT — Ubuntu/Debian)

APT (Advanced Package Tool) — это командный менеджер пакетов для семейств Ubuntu и Debian. Если графический Магазин приложений завис или вам нужно быстро развернуть рабочую среду, APT сделает это за секунды одной строчкой текста.

Если вы не знаете точное название программы, её можно найти по ключевому слову в базе данных.

```bash
sudo apt update
sudo apt install vlc gimp libreoffice
```

### Flatpak и Snap

Flatpak и Snap — это современные форматы «самодостаточных» приложений. Они созданы, чтобы решить главную проблему Linux: когда программа не запускается, потому что ей не хватает системных библиотек или они слишком старые.

В отличие от классического apt, эти пакеты содержат внутри себя и саму программу, и абсолютно все необходимые для её работы зависимости. Они запускаются в изолированной «песочнице» (контейнере) и одинаково работают на любом дистрибутиве.

По умолчанию Flatpak предустановлен в Linux Mint. В Ubuntu его нужно ставить вручную. На сегодня каталог Flathub является самым богатым источником свежего графического софта для домашнего ПК.

По умолчанию Snap жестко встроен в Ubuntu. В Linux Mint он заблокирован из коробки (но его можно включить). Для обычных программ (Discord, Spotify, Telegram) он работает отлично прямо из магазина.

| Формат | Особенность |
|--------|-------------|
| **Snap** | Встроен в Ubuntu, изолированные пакеты |
| **Flatpak** | Универсальные пакеты, Flathub.org |

```bash
sudo apt install flatpak
flatpak install flathub org.mozilla.firefox
```

### Правила безопасности

Безопасность в Linux строится на принципе наименьших привилегий. Система спроектирована так, что пользователь не может случайно повредить важные файлы, если сам не предоставит программам максимальные права (через sudo).

- Берите программы **из официальных репозиториев**.
- Не копируйте команды `curl | bash` из случайных статей без понимания.
- См. [опасные скрипты](/encyclopedia/8-infra-security/8-03-zabota-o-kode-i-dannyh/101).

## Структура файловой системы

| Путь | Содержимое |
|------|------------|
| `/` | Корень всей системы |
| `/home/имя` | Ваши личные файлы |
| `/etc` | Конфигурация системы |
| `/var` | Логи, кэш |
| `/media` или `/mnt` | Подключённые USB-диски |
| `/tmp` | Временные файлы |

Нет диска **C:** — одно дерево папок. USB-диски появляются в `/media/ваш_логин/`.

## Отличия от Windows и macOS

Linux принципиально отличается от Windows и macOS своей архитектурой, философией и бизнес-моделью.

Вы — абсолютный хозяин компьютера. Система делает только то, что вы ей приказали. Никаких принудительных перезагрузок ради обновлений, рекламы в меню или неудаляемых программ. Централизованный подход. 99% софта ставится из безопасных источников — встроенного Магазина приложений или одной командой в Терминале (через репозитории). Скачивание программ с сайтов — редкое исключение.

| Тема | Linux |
|------|-------|
| Диски | Одно дерево, точки монтирования |
| Программы Windows | Не все есть нативно — игры через **Proton/Steam**, офис **LibreOffice** или веб |
| Права | `sudo` для администрирования |
| Драйверы | Большинство железа работает из коробки; NVIDIA иногда требует отдельный драйвер |
| Обновления | Часто бесплатны навсегда, без лицензии |

См. [macOS](/encyclopedia/1-basics/1-035-bazovaya-informatika/211), [Windows](/encyclopedia/1-basics/1-035-bazovaya-informatika/207).

## Облако и бэкап на Linux

Организация резервного копирования и синхронизации с облаком в Linux устроена иначе, чем в Windows или macOS. Здесь нет одного встроенного «OneDrive» или «iCloud», который незаметно собирает ваши данные. Вместо этого Linux предлагает инструменты полного контроля: вы сами решаете, что, куда и с какой частотой сохранять.

Все инструменты резервного копирования в Linux делятся на две категории: Бэкап системы (снимок настроек на случай поломки ОС) и Синхронизация файлов (ваши фото, документы и проекты в облаке).

| Задача | Инструмент |
|--------|------------|
| Google Drive / OneDrive | rclone, официальные клиенты, браузер |
| Локальный бэкап файлов | **Deja Dup** (резервное копирование) |
| Снимок системы | **Timeshift** (как точка восстановления) |
| Синхронизация папок | Syncthing, Nextcloud |

Пошагово:

1. Установите Deja Dup: `sudo apt install deja-dup`
2. Выберите папки Documents, Pictures.
3. Укажите внешний диск или облако через rclone.
4. Расписание — еженедельно.

См. [Облако и бэкап](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7).

## Связь Linux с телефоном

Связать смартфон на Android или iOS с компьютером на Linux можно даже более бесшовно, чем в Windows. В экосистеме Linux для этого есть потрясающие инструменты, которые позволяют передавать файлы, управлять воспроизведением и даже использовать телефон как мышку.

Главным и абсолютным стандартом здесь является программа KDE Connect (и её аналог для рабочего стола GNOME — GSConnect). Для работы утилиты важно, чтобы компьютер и телефон были подключены к одной домашней сети Wi-Fi.

Если вам нужно не просто связать устройства, а вывести экран Android на монитор Linux и полностью управлять телефоном с помощью мышки и клавиатуры ПК, используйте бесплатную утилиту Scrcpy.

| Способ | Описание |
|--------|----------|
| USB | Android — режим MTP, файлы в файловом менеджере |
| KDE Connect | Уведомления, буфер обмена, файлы по Wi‑Fi |
| Syncthing | Синхронизация папок с Android |
| Облако | Google Drive, Nextcloud — общий для ПК и телефона |

См. [Знакомство с Android](/encyclopedia/1-basics/1-035-bazovaya-informatika/213).
