# Первые шаги в macOS

<div class="article-tags">
  <span class="tag tag-required">ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

<span class="complexity-badge">Всем</span>

**macOS** — операционная система Apple для MacBook, iMac и Mac mini. Если вы привыкли к Windows, многие привычные элементы называются иначе, но задачи те же: открыть файл, установить программу, настроить интернет, сделать резервную копию.

Mac часто покупают вместе с iPhone — тогда удобна связка через iCloud. Если у вас Android, Mac тоже подойдёт: ставьте Google Drive, Chrome и синхронизируйте фото через [облако](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7). Альтернатива с открытым кодом — [Linux](/encyclopedia/1-basics/1-035-bazovaya-informatika/212).

| Термин | Простое объяснение |
|--------|-------------------|
| **Finder** | Программа для файлов и папок, аналог Проводника |
| **Dock** | Панель с иконками внизу экрана |
| **Spotlight** | Поиск файлов, программ и настроек по Cmd+Space |
| **Apple ID** | Аккаунт для App Store, iCloud, iMessage |
| **.dmg** | Образ диска с установщиком программы |
| **Gatekeeper** | Защита от неподписанных программ |

| **FileVault** | Шифрование всего диска |
| **Trackpad** | Сенсорная панель вместо мыши на ноутбуке |

## Соответствие с Windows


Главное отличие macOS от Windows — это философия управления окнами, файлами и логика взаимодействия с интерфейсом:
1. Крестик не закрывает программу полностью. В Windows нажатие на крестик полностью завершает процесс, но в macOS красный крестик в углу окна лишь скрывает само окно. Приложение остается работать в оперативной памяти (под его иконкой в Dock будет гореть точка). Чтобы закрыть программу полностью, нужно использовать комбинацию `Cmd + Q`.
2. Кнопка `Command` (`⌘`) вместо `Control` (`Ctrl`). Все привычные сочетания клавиш используют клавишу `Command` (`Cmd`). Копировать и вставить — это `Cmd + C` и `Cmd + V`. Сама клавиша `Ctrl` на Mac используется редко (в основном для специальных системных команд или в терминале).
3. Отсутствие функции «Вырезать» для файлов. В macOS нельзя выделить файл, нажать `Cmd + X` (вырезать), а потом вставить. Здесь логика другая: вы копируете файл через `Cmd + C`, а в нужной папке нажимаете `Cmd + Option + V` (переместить сюда). Файл исчезнет из старого места и появится в новом.
4. Единая строка меню для всех программ. В Windows у каждого окна своя строчка «Файл», «Правка», «Вид» внутри самого окна. В macOS эта строка одна на весь экран и всегда находится на самом верху. Она автоматически меняет свои пункты в зависимости от того, какое приложение открыто в данный момент.
5. Поведение клавиши `Enter` (Ввод). В Windows нажатие `Enter` на файле открывает его. В macOS нажатие `Enter` открывает режим переименования файла. Чтобы открыть документ или запустить программу, нужно нажать комбинацию `Cmd + Down` (Стрелка вниз) или `Cmd + O`.
6. Функция «Пробел» (Быстрый просмотр). На Mac не нужно открывать тяжелые программы, чтобы посмотреть фото, видео, PDF или документ Word. Достаточно один раз нажать на файл и нажать Пробел. Откроется мгновенное окно предпросмотра. Повторное нажатие Пробела закрывает его.
7. Идеальный трекпад и жесты (для MacBook). Если у вас ноутбук, мышка вам, скорее всего, больше не понадобится. Жесты трекпада в macOS невероятно плавные и глубоко интегрированы в систему: свайп тремя пальцами вверх открывает все окна, свайп в стороны переключает рабочие столы, а масштабирование работает точнее, чем на смартфонах.

| В Windows | В macOS |
|---------|---------|
| Проводник | **Finder** — файловый менеджер |
| Пуск | **Dock** (панель внизу) + меню Apple () |
| Ctrl+C / Ctrl+V | **Cmd+C / Cmd+V** |
| Alt+Tab | **Cmd+Tab** — переключение окон |
| Параметры | **System Settings** (Настройки системы) |
| Win+Печать | **Cmd+Shift+3/4** — скриншот |
| Диспетчер задач | **Мониторинг системы** или Cmd+Option+Esc |
| Win+E | **Cmd+Space** → Finder |
| Панель задач | **Dock** + строка меню сверху |

Подробнее про устройство — [ноутбуки](/encyclopedia/1-basics/1-08-kak-rabotaet-kompyuter/711), [скриншоты](/encyclopedia/1-basics/1-035-bazovaya-informatika/205), [настройка Windows](/encyclopedia/1-basics/1-035-bazovaya-informatika/207).

## Первый час — пошаговый гайд

### Шаг 1. Включение и мастер настройки

Первый запуск Mac активирует Ассистент настройки. Это пошаговый мастер, который подготавливает компьютер к работе. Процесс интуитивно понятен, но требует внимания к нескольким ключевым шагам.

1. Включите Mac, выберите язык и раскладку клавиатуры.
2. Подключите Wi‑Fi.
3. Создайте **Apple ID** или войдите в существующий. Отдельный надёжный пароль и **двухфакторная аутентификация** обязательны.
4. Настройте Touch ID (отпечаток), если есть.
5. Решите, переносить ли данные со старого Mac или Windows — для Windows нужна утилита Migration Assistant.

### Шаг 2. Обновления

Обновления в macOS происходят гораздо проще и мягче, чем в Windows: система никогда не прервет вашу работу принудительной перезагрузкой посреди дня. Apple разделяет их на небольшие обновления безопасности и крупные ежегодные апгрейды всей системы.

1. Откройте **System Settings** (иконка шестерёнки в Dock или меню ).
2. **General → Software Update** — установите все обновления безопасности.
3. Перезагрузите, если система просит.

### Шаг 3. Finder

Finder — это главный файловый менеджер macOS, выполняющий ту же роль, что и «Проводник» (Этот компьютер) в Windows. Он запущен всегда, и его иконка в виде улыбающегося лица всегда находится на первом месте в панели Dock.

1. Откройте Finder (иконка улыбающегося лица в Dock).
2. Боковая панель: Desktop, Documents, Downloads, Applications.
3. **Finder → Settings → Advanced** — включите "Показывать все расширения имени файлов", чтобы видеть `.pdf`, `.docx`.
4. Создайте папку `Работа` в Documents для личных файлов.

### Шаг 4. Dock и строка меню

Dock (панель внизу) и Строка меню (полоса вверху) — это два главных элемента управления в macOS. В отличие от Windows, где панель задач совмещает в себе всё сразу, в Mac обязанности четко разделены.

1. Перетащите в Dock часто используемые программы (Safari, Mail, Notes).
2. Уберите лишние иконки: перетащите за пределы Dock с задержкой.
3. Строка меню сверху показывает меню **активной** программы — это отличается от Windows.

### Шаг 5. Trackpad и мышь

Управление курсором в macOS — это то, за что миллионы пользователей любят компьютеры Apple. Жесты трекпада здесь настолько глубоко интегрированы в систему, что большинство владельцев MacBook полностью отказываются от мыши.

Бывшие пользователи Windows часто сталкиваются с проблемой: при прокрутке колесика мыши или трекпада страница движется «не в ту сторону». Если вам неудобно: зайдите в `Системные настройки → Трекпад (или Мышь)` и отключите тумблер «`Направление прокрутки: обычное`» (`Scroll direction: Natural`).

1. **System Settings → Trackpad** — включите "Нажатие для клика", прокрутку двумя пальцами.
2. Жесты: смахивание тремя пальцами — переключение рабочих столов.
3. Подключите мышь через Bluetooth или USB при необходимости.

### Шаг 6. Браузер

Главным браузером в macOS является Safari. Он разработан самой Apple, глубоко интегрирован в систему и установлен по умолчанию. Однако Mac никак не ограничивает вас: вы можете скачать и использовать любой привычный браузер.

- **Safari** встроен и экономит батарею на MacBook.
- **Chrome** или **Firefox** — если привычны с Windows.
- Не устанавливайте "ускорители" и "чистильщики" из рекламы.

### Шаг 7. iCloud и бэкап

В macOS работа с облаком iCloud и резервными копиями (бэкапами) организована по принципу «настрой один раз и забудь». Система берет всю рутину на себя, защищая вас от потери важных документов.

Time Machine (Машина времени) — это встроенная утилита, которая делает полный снимок всей вашей системы. Если Mac сломается, потеряется или вы купите новый, вы сможете восстановить его до последнего файла за один клик.

1. **System Settings → Apple ID → iCloud** — включите iCloud Drive.
2. Подключите внешний диск для **Time Machine** (см. раздел ниже).
3. См. [Облако и бэкап](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7).

## Интерфейс macOS

### Finder — работа с файлами

| Действие | Как сделать |
|----------|-------------|
| Копировать | Cmd+C, затем Cmd+V |
| Переместить | Cmd+C, **Cmd+Option+V** (вырезать-вставить) |
| Удалить | Cmd+Delete (в Корзину) |
| Быстрый просмотр | Пробел (Quick Look) |
| Показать путь | Cmd+Click на заголовке окна |
| Скрытые файлы | Cmd+Shift+. (точка) |

В Windows можно кликнуть правой кнопкой на пустом месте и выбрать Создать → Документ Word / Текстовый файл. В Finder так сделать нельзя. На Mac логика обратная, сначала вы открываете нужную программу (например, заметки или Pages), создаете документ, а затем сохраняете его через Cmd + S в нужную папку.


Папки по умолчанию:

| Папка | Назначение |
|-------|------------|
| Desktop | Рабочий стол |
| Documents | Документы пользователя |
| Downloads | Загрузки из браузера |
| Applications | Установленные программы |
| Library | Настройки программ (скрыта, не трогать без инструкции) |

См. [работу с проводником на Windows](/encyclopedia/1-basics/1-11-fayly-katalogi-i-puti/221) — принципы те же, названия другие.

### Dock

Панель Dock — это нижняя полоса иконок, которая служит для быстрого запуска любимых программ, переключения между ними и управления документами. Она заменяет панель задач Windows, но имеет свои уникальные правила.

Панель четко разделена на зоны тонкой вертикальной линией-разделителем:
1. Левая (большая) часть - здесь живут иконки приложений. Если под иконкой горит маленькая точка, значит, программа сейчас запущена и находится в оперативной памяти.
2. Правая часть (возле Корзины) - здесь находятся свернутые окна документов, закрепленные папки (по умолчанию папка «Загрузки») и сама Корзина.

Упрощённо:
- Иконка с точкой под ней — программа запущена.
- Правый клик (или Ctrl+клик) — контекстное меню.
- Разделитель: слева программы, справа папки и Корзина.

### Рабочие столы (Spaces)

Рабочие столы (или Spaces) в macOS — это функция, которая позволяет создать несколько независимых виртуальных экранов. Она полностью избавляет от хаоса, когда на одном мониторе открыты десятки накладывающихся друг на друга окон. Вы можете выделить один стол под работу, второй — под мессенджеры, третий — под просмотр фильма.

Чтобы управлять рабочими столами, нужно открыть режим Mission Control. 

- Ctrl+стрелка влево/вправо или жест тремя пальцами — другой рабочий стол.
- Удобно разделить "работу" и "личное".

## Установка программ — пошагово

### Способ 1. App Store

Установка из App Store — самый простой и безопасный способ, полностью аналогичный установке приложений на iPhone или iPad. Все программы здесь проходят строгую проверку Apple на вирусы и вредоносный код.

1. Откройте **App Store** из Dock.
2. Войдите Apple ID, если просит.
3. Найдите программу, нажмите "Получить" / "Установить".
4. Программа появится в Applications и Dock (если закрепите).

Аналог Microsoft Store. Программы проверены Apple.

### Способ 2. С сайта разработчика (.dmg)

Установка через .dmg-файлы — это популярный способ для программ, которых нет в официальном App Store (например, Google Chrome, Photoshop или Telegram с официального сайта).

Для пользователей Windows этот процесс поначалу кажется странным, так как здесь нет привычных «Мастеров установки» (нажатий кнопок Далее-Далее-Готово), а файлы не распаковываются из `.exe` или `.msi`.

1. Скачайте `.dmg` только с **официального сайта**.
2. Дважды кликните `.dmg` — откроется виртуальный диск.
3. Перетащите иконку программы в папку **Applications**.
4. Извлеките диск: правый клик → Извлечь, или кнопка извлечения рядом с именем диска.
5. Запустите из Applications. При первом запуске macOS может спросить подтверждение.

Многие запускают программу прямо из открывшегося окна .dmg, не перетаскивая её. В таком случае приложение будет работать медленно, а после перезагрузки компьютера просто исчезнет. Скопировать в папку Applications нужно обязательно.

Поскольку программа скачана из интернета, при первом запуске встроенная защита macOS (Gatekeeper) может показать предупреждение: «Программа скачана из интернета. Вы уверены, что хотите открыть её?». Просто нажмите «Открыть».

### Способ 3. Homebrew (для продвинутых позже)

Homebrew — это неофициальный, но самый мощный менеджер пакетов для macOS. Он заменяет графический интерфейс командной строкой. Вместо того чтобы заходить на сайты, скачивать .dmg файлы и перетаскивать их вручную, с помощью Homebrew можно устанавливать, обновлять и удалять любые программы одной короткой командой в Терминале. Этот способ обожают программисты, сисадмины и продвинутые пользователи.

Менеджер пакетов через терминал. Понадобится при разработке — [софт продвинутого пользователя](/encyclopedia/1-basics/1-035-bazovaya-informatika/intro), [терминал](/encyclopedia/2-system-network/2-05-terminal/intro).

### Gatekeeper

Gatekeeper — это встроенная система безопасности macOS. Она защищает ваш компьютер от вирусов и вредоносного софта. Система проверяет каждую программу, которую вы скачали не из App Store, а из интернета. Если разработчик не зарегистрирован в Apple или файл был изменен злоумышленниками, Gatekeeper заблокирует его запуск.

Когда вы впервые запускаете скачанное из сети приложение, система безопасности сверяет его цифровую подпись с базой данных Apple. В зависимости от статуса программы вы увидите одно из окон:
- Стандартное предупреждение: «Программа "Имя" скачана из интернета. Вы уверены, что хотите открыть её?». Это обычная проверка. Если вы сами скачали софт (например, Google Chrome с официального сайта), просто нажимайте «Открыть».
- Блокировка запуска: «Программу "Имя" не удается открыть, так как её автор является неустановленным разработчиком» или «...так как Apple не может проверить её на наличие вредоносного ПО». Кнопки «Открыть» в таком окне просто не будет — только «ОК» и «В корзину».

Встроенная защита macOS от неподписанных программ.

- Если система блокирует программу: **System Settings → Privacy & Security** → "Всё равно открыть" (после первой попытки запуска).
- Не отключайте Gatekeeper полностью без понимания риска.
- См. [опасные скрипты](/encyclopedia/8-infra-security/8-03-zabota-o-kode-i-dannyh/101).

Если вы абсолютно уверены, что программа безопасна (например, это полезная бесплатная утилита с открытым кодом от независимого автора), блокировку можно обойти за пару кликов. Никогда не отключайте защиту Gatekeeper полностью через Терминал ради скачивания пиратского софта. Это лишает macOS её главного преимущества — устойчивости к вирусам и троянам, которые могут зашифровать ваши личные файлы или украсть пароли.

## Spotlight — универсальный поиск

Spotlight — это встроенная поисковая система macOS, которая заменяет собой стандартное меню «Пуск» и избавляет от необходимости искать иконки программ на экране. Это самый быстрый способ запустить любое приложение, найти документ или сделать мгновенное вычисление. Вызов Spotlight осуществляется нажатием комбинации `Cmd + Пробел` в любой момент работы.

1. **Cmd+Space** — открыть Spotlight.
2. Введите имя файла, программы или настройки ("Wi-Fi", "Bluetooth", "Display").
3. Стрелки — выбор, Enter — открыть.
4. Можно считать простые выражения и конвертировать валюты.

Если Spotlight не находит файл — проверьте **System Settings → Siri & Spotlight → Spotlight Privacy** — папка не должна быть исключена ошибочно.

## iCloud и Time Machine

### iCloud Drive

iCloud Drive — это персональное облачное хранилище Apple, встроенное в macOS. В отличие от Windows, где OneDrive часто воспринимается как отдельная надстройка, iCloud Drive в Mac — это базовая часть файловой системы. Он работает незаметно и берет на себя синхронизацию всех ваших данных.

Вам не нужно устанавливать сторонние приложения. Откройте Finder — в левом боковом меню (в разделе iCloud) вы увидите постоянную папку iCloud Drive. Внутри этой папки автоматически создаются разделы для программ (например, Pages, Numbers, Keynote, Preview). Всё, что вы сохраняете туда, мгновенно становится доступно на вашем iPhone, iPad или через сайт icloud.com.

Во время первого включения (или позже в настройках) Mac предлагает включить синхронизацию папок «Рабочий стол» и «Документы». Если у вас базовая модель Mac с небольшим диском (например, 256 ГБ), iCloud Drive поможет не забить его до отказа.

- Синхронизация документов между Mac, iPhone и iPad.
- **System Settings → Apple ID → iCloud → iCloud Drive** — включить.
- Папка iCloud Drive появится в Finder.
- Фото — отдельный переключатель **Photos** в iCloud.

По умолчанию Apple бесплатно дает всего 5 ГБ места. Этого критически мало, если вы синхронизируете фото и документы. Подписка iCloud+ позволяет расширить место.

См. [Облако и бэкап](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7). На Android вместо iCloud — [Google Drive](/encyclopedia/1-basics/1-035-bazovaya-informatika/213).

### Time Machine — пошаговая настройка

Time Machine (Машина времени) — это встроенная утилита macOS для автоматического резервного копирования. Она делает полный снимок системы и позволяет восстановить как весь компьютер целиком (на случай поломки или покупки нового Mac), так и отдельный случайно удаленный файл или старую версию документа. Главное отличие от бэкапов в Windows — потрясающая визуализация и работа в фоновом режиме, которая совершенно не нагружает компьютер.

Вам понадобится внешний жесткий диск (HDD) или SSD, подключаемый по USB. Объем диска должен быть минимум в 2 раза больше, чем объем встроенной памяти вашего Mac. Если на Mac диск на 512 ГБ, для бэкапов лучше взять внешний накопитель на 1 ТБ.

1. Купите внешний USB-диск (объём больше, чем занято на Mac).
2. Подключите диск. macOS предложит использовать для Time Machine — согласитесь.
3. Или **System Settings → General → Time Machine → Add Backup Disk**.
4. Выберите диск, при желании включите шифрование.
5. Первый бэкап займёт часы. Дальше — инкрементально в фоне.

**Восстановление файла:** откройте Finder → Enter Time Machine (из меню или иконки в строке меню) → выберите дату → восстановить файл.

**Восстановление системы:** режим Recovery (удержание питания на Apple Silicon, Cmd+R на Intel Mac).

## Связка Mac с телефоном

Связка Mac с iPhone (экосистема Continuity или «Непрерывность») — это то, ради чего многие пользователи выбирают технику Apple. Устройства работают как единое целое без сложных настроек. Единственное условие: на Mac и iPhone должен быть выполнен вход под одним и тем же Apple ID, а также включены Wi-Fi и Bluetooth.

Вы можете выделить текст, скопировать ссылку или сохранить картинку на iPhone (Скопировать), а затем просто нажать `Cmd + V` на Mac. Скопированный элемент моментально вставится на компьютере. Это работает и в обратную сторону.

Если вы начали читать статью в Safari, писать письмо в «Почте» или редактировать заметку на iPhone, в левой части панели Dock на Mac появится специальная иконка этого приложения со значком телефона. Кликнув по ней, вы откроете то же самое приложение на компьютере ровно на том месте, где остановились на смартфоне.

| У вас iPhone | У вас Android |
|--------------|---------------|
| iCloud, AirDrop, Continuity | Google Drive, синхронизация через браузер |
| Звонки и SMS на Mac (при настройке) | WhatsApp Web, Telegram Desktop |
| Фото в общей библиотеке iCloud | Google Фото в браузере или приложении |

См. [Знакомство с Android](/encyclopedia/1-basics/1-035-bazovaya-informatika/213), [перенос данных](/encyclopedia/1-basics/1-035-bazovaya-informatika/216).

### AirDrop

AirDrop — это фирменная технология Apple для мгновенной беспроводной передачи файлов между вашими устройствами (Mac, iPhone, iPad) и компьютерами ваших друзей. Технология не использует интернет, кабели или флешки. Передача идет напрямую через защищенное соединение Wi-Fi и Bluetooth, поэтому файлы (даже тяжелые видео на несколько гигабайт) пересылаются со сверхвысокой скоростью и без потери качества.

Передача файлов между Mac и iPhone по Wi‑Fi и Bluetooth:

1. На обоих устройствах включите Wi‑Fi и Bluetooth.
2. Mac — Finder → AirDrop → "Только для контактов" или "Все".
3. На iPhone — поделиться файлом → AirDrop → выбрать Mac.

## Безопасность

Безопасность в macOS — одна из сильнейших сторон системы. Apple использует комплексный подход, защищая ваши данные как на физическом уровне (при краже устройства), так и на сетевом.

| Функция | Что делает |
|---------|------------|
| **FileVault** | Шифрует диск; на новых Mac часто включён по умолчанию |
| **Find My Mac** | Поиск и блокировка при краже (через Apple ID) |
| **Firewall** | **System Settings → Network → Firewall** — включить на публичных сетях |
| **2FA Apple ID** | Обязательна для iCloud и покупок |

FileVault — это встроенная система полного шифрования всего вашего жесткого диска (SSD). Если ваш Mac украдут или вы его потеряете, злоумышленники не смогут достать из него файлы, даже если физически извлекут SSD-диск и подключат его к другому компьютеру. Без вашего пароля диск представляет собой набор случайных символов.

Функция «Локатор» связывает компьютер с вашей учетной записью и позволяет найти его в случае утери по аналогии с iPhone. Вы можете увидеть Mac на карте, удаленно заблокировать его, вывести на экран сообщение для нашедшего (например, с вашим номером телефона) или полностью стереть все данные через интернет.

Брандмауэр контролирует все входящие сетевые подключения к вашему компьютеру из интернета или локальной сети Wi-Fi. Он блокирует несанкционированные попытки других компьютеров и вредоносных программ подключиться к вашему Mac, защищая от сетевых атак (особенно актуально при работе в публичных Wi-Fi сетях в кафе или аэропортах).

Двухфакторная аутентификация - главный рубеж защиты вашего цифрового профиля. При входе в ваш Apple ID на новом устройстве одного пароля будет недостаточно. После ввода пароля система потребует ввести шестизначный проверочный код. Этот код мгновенно всплывает в виде уведомления на ваших уже доверенных устройствах (например, на вашем iPhone) вместе с картой, показывающей, где именно совершается попытка входа.
