# Перенос данных на новый ПК и новый телефон

<div class="article-tags">
  <span class="tag tag-required">ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

<span class="complexity-badge">Всем</span>

При смене устройства перенос идёт в три слоя: **аккаунты** (почта, облако), **файлы** (документы, фото), **программы** (установить заново). Мессенджеры со сквозным шифрованием (WhatsApp) требуют **встроенного мастера переноса** — простое копирование папок не сработает.

Сначала сделайте **бэкап** старого устройства — [облако и правило 3-2-1](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7).

---

## Три слоя переноса

| Слой | Что входит | Типичный способ |
|------|------------|-----------------|
| **Аккаунты** | Google, Microsoft, Apple, Яндекс | Вход на новом устройстве |
| **Файлы** | Документы, фото, проекты | Облако, USB, мастер ОС |
| **Программы** | Браузеры, офис, IDE | Установка заново с официальных сайтов |

★ **Лицензии** часто привязаны к аккаунту (Office, Adobe, Steam), а не к "файлу программы".

---

## Общий порядок (все платформы)

1. Резервная копия на **старом** устройстве.
2. Список **критичных программ** и где их скачать.
3. Перенос **2FA** и резервных кодов **до** отключения старого телефона.
4. Вход в **аккаунты** на новом устройстве.
5. Перенос **файлов** (синхронизация облака, USB, мастер Windows/Mac).
6. Установка **программ** с официальных сайтов.
7. Перенос **мессенджеров** по инструкции каждого сервиса.
8. Проверка — почта, фото, рабочие папки, одна игра, один чат.
9. Сброс старого устройства перед продажей.

---

## Хронология — чек-лист по дням

### За 3–7 дней до смены

- [ ] Включить или проверить **автобэкап** фото в облако.
- [ ] Экспорт **закладок** браузера, если не синхронизируются.
- [ ] Список установленных программ (Windows: Параметры → Приложения; или фото экрана).
- [ ] Найти **лицензии** — ключи Office, 1С, игры вне Steam.
- [ ] Экспорт **2FA** из Google Authenticator / Authy (QR или облако Authy).
- [ ] Сохранить **seed-фразы** кошельков на бумаге — не на телефоне.

### День получения нового устройства

- [ ] Обновление системы (Windows Update / macOS / Android / iOS).
- [ ] Вход в основной аккаунт (Microsoft / Apple / Google).
- [ ] Подключение облака — OneDrive, iCloud, Google Drive, Яндекс.Диск.
- [ ] Мастер переноса ОС или USB-копирование папок.
- [ ] WhatsApp / Telegram по инструкции ниже.
- [ ] Тест: открыть 3 важных документа, 10 фото, рабочую почту.

### Через 1–2 недели

- [ ] Убедиться, что всё работает; старый ПК/телефон ещё не продавать.
- [ ] Полный **сброс** старого устройства.
- [ ] Отключить **Find My** / **Поиск устройства** на старом.

## Новый Windows-ПК

### Способ 1 — облако (рекомендуется для документов)

| Что | Как |
|-----|-----|
| Файлы OneDrive | Вход в Microsoft-аккаунт — синхронизация папок |
| Google Drive | Установить клиент Google Drive для desktop |
| Яндекс.Диск | Клиент Яндекса — выбрать папки |
| Фото | Google Фото в браузере или приложение |

См. [облако и бэкап](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7).

### Способ 2 — мастер при первой настройке Windows

При первом включении Windows 11 предложит **перенести с другого ПК**:

1. На **старом** ПК — установите приложение "Перенос Windows" из Microsoft Store (или следуйте подсказке на новом ПК).
2. Оба ПК в **одной Wi‑Fi** сети.
3. Выберите, что переносить: аккаунты, файлы, часть настроек.
4. **Программы** мастер переносит не всегда — многие нужно установить заново.

### Способ 3 — USB-диск или внешний SSD

1. На старом ПК скопируйте папки:
   - `Документы`, `Изображения`, `Рабочий стол`
   - Папки проектов (Dev, Work и т.д.)
2. Не копируйте **весь** диск C: — перенесёте Windows, драйверы чужого железа, вирусы.
3. На новом ПК вставьте носитель и скопируйте в те же папки профиля.

См. [работу с проводником](/encyclopedia/1-basics/1-11-fayly-katalogi-i-puti/221).

### Что переносится через аккаунт

| Данные | Сервис |
|--------|--------|
| Закладки Chrome/Edge | Google / Microsoft аккаунт |
| Пароли | Bitwarden, встроенный менеджер браузера |
| История (опционально) | Синхронизация браузера |
| Настройки Windows | Microsoft-аккаунт — частично |

### Программы — установить заново

- Офис — [Microsoft 365](/encyclopedia/1-basics/1-035-bazovaya-informatika/309) из аккаунта.
- Браузеры — chrome.google.com, firefox.com, microsoft.com/edge.
- Zoom, Telegram Desktop, Discord — с официальных сайтов.
- IDE (VS Code, IntelliJ) — с сайта; расширения синхронизируются через аккаунт.

**Не переносите** папку `Program Files` со старого диска — установщики заново.

### Настройка после переноса

- [Настройка Windows](/encyclopedia/1-basics/1-035-bazovaya-informatika/207)
- Windows Update, драйверы видеокарты с сайта NVIDIA/AMD/Intel
- [Цифровая безопасность](/encyclopedia/1-basics/1-035-bazovaya-informatika/112)

## Новый Mac

### Migration Assistant (основной способ)

1. При первом включении Mac выберите **Migration Assistant** (Ассистент миграции).
2. Источник:
   - **Другой Mac** — по Wi‑Fi или Thunderbolt/USB-C.
   - **Windows-ПК** — ограниченно: файлы, аккаунты; не все программы.
   - **Time Machine** — резервная копия с диска.
3. Выберите пользователя и типы данных.
4. Дождитесь окончания — часы при больших объёмах.

### iCloud

- Вход в **Apple ID** — фото (iCloud Photos), документы Desktop & Documents, ключи (Keychain).
- Проверьте место в iCloud — при нехватке синхронизация остановится.

### Программы на Mac

- App Store — повторная загрузка купленных приложений.
- Программы с сайтов — Chrome, VS Code, Office — установить заново.
- Homebrew (`brew`) — продвинутый способ массовой установки CLI.

См. [Первые шаги в macOS](/encyclopedia/1-basics/1-035-bazovaya-informatika/211).

### Mac с Apple Silicon и старый Intel

- Приложения только для Intel могут требовать **Rosetta 2** — macOS предложит установить.
- Проверьте совместимость тяжёлого софта до покупки Mac.

## Новый Android-телефон

### Шаг 1 — подготовка старого телефона

1. Обновите систему и Google Play.
2. **Google-аккаунт** — Настройки → Google → Резервная копия; проверьте дату последней копии.
3. Зарядите оба телефона **выше 50%**.
4. Подключите к **Wi‑Fi** — перенос по мобильному интернету дорог.

### Шаг 2 — при первой настройке нового

1. Включите новый телефон → язык → Wi‑Fi.
2. Войдите в **тот же Google-аккаунт**.
3. Выберите **Восстановить из резервной копии Google**.
4. Выберите **старое устройство** из списка.
5. Дождитесь загрузки приложений — может занять часы.

### Samsung и другие оболочки

- **Smart Switch** (Samsung) — кабель USB-C или Wi‑Fi; переносит больше, чем базовый Google, включая SMS на некоторых моделях.
- **Xiaomi Mi Mover**, **OnePlus Clone Phone** — аналоги от производителей.

См. [Знакомство с Android](/encyclopedia/1-basics/1-035-bazovaya-informatika/213).

### SIM и eSIM

- **SIM** — физическая карта; переставьте в новый телефон или попросите дубликат у оператора.
- **eSIM** — профиль в настройках; перенос по QR от оператора или приложению "Мой Tele2" и т.д.
- Не удаляйте eSIM на старом, пока новый не заработал.

### 2FA на Android

- **Google Authenticator** — три точки → **Экспорт аккаунтов** → QR на новый телефон (Authenticator 6.0+).
- **Authy** — облачная синхронизация при включённом бэкапе.
- **SMS-коды** — при смене SIM убедитесь, что номер тот же для банков.

См. [Passkeys](/encyclopedia/1-basics/1-035-bazovaya-informatika/113).

## Новый iPhone

### Quick Start (самый простой способ)

1. Включите новый iPhone; положите **рядом** со старым (оба с iOS актуальными).
2. На старом появится **настройка нового iPhone** — подтвердите Apple ID.
3. Сканируйте анимацию Face ID / Touch ID.
4. Выберите перенос **по Wi‑Fi** или **с iCloud**.
5. Держите оба телефона на зарядке до завершения.

### iCloud-резервная копия

1. Старый iPhone → Настройки → [имя] → iCloud → **Резервная копия iCloud** → Создать копию сейчас.
2. На новом — **Восстановить из копии iCloud** при настройке.
3. Нужен стабильный Wi‑Fi и место в iCloud.

### iTunes / Finder на Windows/Mac

- Подключите старый iPhone → **Создать резервную копию** (зашифрованная — сохранит пароли Health).
- Новый iPhone → **Восстановить из резервной копии**.

### С Android на iPhone

- Приложение Apple **Move to iOS** на Android — контакты, сообщения, фото, бесплатные приложения из App Store.
- **WhatsApp** — отдельно через "Перенос на iOS" (см. ниже).

## WhatsApp — перенос по платформам

WhatsApp хранит переписки **локально** с шифрованием; нужен официальный мастер.

### Android → Android

1. Оба телефона Android; на обоих установлен WhatsApp.
2. **Старый:** WhatsApp → Настройки → Чаты → **Перенос чатов** → **Перенос на Android**.
3. Подключите кабель **USB-C** (или OTG).
4. Следуйте мастеру; перенос может занять 10–60 минут.
5. На **новом** войдите в тот же номер — SMS-код.

### iPhone → iPhone

- **iCloud** резервная копия iPhone **включает** WhatsApp, если копия включала WhatsApp в iCloud (Настройки WhatsApp → Чаты → Резервная копия).
- Или Quick Start / локальная копия через Finder.

### Android → iPhone

1. На Android — WhatsApp актуальной версии.
2. Установите Apple **Move to iOS** или **WhatsApp Перенос на iOS** из App Store на iPhone.
3. Кабель **Lightning–USB-C** (адаптеры по инструкции Apple).
4. Перенос только при **первой** настройке iPhone или сбросе; позже сложнее.

### iPhone → Android

- Официальный перенос через кабель и WhatsApp на Android (функция появилась в новых версиях) — проверьте актуальную инструкцию на whatsapp.com.
- Старые чаты без мастера **не восстановить** копированием папок.

### Если перенос не удался

- Старый телефон **не сбрасывать** сразу.
- WhatsApp → Ежедневная резервная копия в Google Drive (Android) или iCloud (iPhone) — восстановление при переустановке на **том же** типе ОС.
- Потеря истории — обратитесь в чаты с экспортом "Отправить по email" для важных сообщений заранее.

## Telegram — перенос

### Обычные чаты и каналы

- Войдите в **тот же номер** на новом телефоне — облако Telegram подтянет историю.
- На ПК — Telegram Desktop, вход по QR с телефона.

### Secret chats (секретные чаты)

- **Только на том устройстве**, где созданы. На новый телефон **не переносятся**. Экспорта нет.

### Файлы и медиа

- **Кэш** не переносится полностью — большие файлы скачаются заново при открытии.
- **Экспорт чата** — Настройки чата → Экспорт (на ПК удобнее) для архива.

### Telegram на новом ПК

1. desktop.telegram.org — скачать клиент.
2. Вход по номеру или QR с телефона.
3. Папки загрузок — проверьте путь в настройках.

## Steam и игры

### Аккаунт и библиотека

- Установите **Steam** на новом ПК — store.steampowered.com.
- Войдите в **тот же аккаунт** — библиотека на месте.
- **Steam Guard** — код с email или приложения; перенесите Guard на новый телефон **до** удаления старого.

### Сохранения игр

| Тип | Как переносится |
|-----|-----------------|
| **Steam Cloud** | Автоматически при запуске игры |
| **Локальные сохранения** | Папка в `Documents` или `%AppData%` — скопировать вручную или через Steam → Свойства → Файлы сохранения |
| **Epic Games** | Аналогично — аккаунт + облако где есть |

### Установка игр

- Заново **скачать** из библиотеки — не копируйте папку `steamapps` без понимания (можно, но проще чистая загрузка).
- Внешний SSD — можно перенести библиотеку через Steam → Настройки → Хранилище.

### Epic, GOG, Xbox

- Тот же аккаунт на новом ПК.
- GOG Galaxy — резервные установщики игр без DRM.

## Фото и видео

### Облако

- **Google Фото** — автозагрузка; на новом телефоне войти в тот же аккаунт.
- **iCloud Photos** — на iPhone/Mac после входа в Apple ID.
- **Яндекс.Диск** — альбомы после входа.

### Локально

- USB-копирование папки `DCIM` с Android.
- iPhone — резервная копия iCloud/Finder или AirDrop на Mac по частям.

### RAW и большие проекты

- Внешний SSD + [бэкап 3-2-1](/encyclopedia/1-basics/1-14-obmen-dannymi-i-sovmestnyy-dostup/7); облако для RAW дорого по трафику.

| Gmail | Приложение Gmail + вход |

## Что легко забыть

- [ ] Экспорт **закладок** браузера, если не в облаке
- [ ] **Лицензии** игр вне Steam (ключи в email)
- [ ] **Файлы с рабочего стола** (часто не в облаке)
- [ ] **Сохранения игр** вне Steam Cloud
- [ ] **SSH-ключи** и `.env` для разработчиков — папка `.ssh`, проекты
- [ ] **Криптокошельки и seed-фразы** — только у вас; поддержка не восстановит
- [ ] **Пароли Wi‑Fi** — сохранены в роутере; на новом ПК ввести заново или экспорт из старого
- [ ] **Отключить Find My / Google Find** на старом телефоне перед продажей
- [ ] **Подписки**, привязанные к старому устройству (Some banking apps)

## Перед продажей старого устройства

### Windows-ПК

1. Скопируйте нужные данные **дважды** проверьте.
2. **Параметры → Система → Восстановление → Вернуть компьютер в исходное состояние**.
3. Выберите **Удалить файлы и очистить диск** (медленнее, безопаснее).
4. Выйдите из **Microsoft-аккаунта** до сброса, если система просит.

### Mac

1. Выйти из **iCloud** и **Find My Mac**.
2. **Стереть контент и настройки** (macOS Monterey+) или переустановка через Recovery.

### Android

1. **Настройки → Система → Сброс** → Удалить все данные.
2. Выньте **SIM и microSD**; SD можно стереть на ПК.
3. Аккаунт Google должен быть **удалён** с устройства (сброс делает это).

### iPhone

1. **Настройки → [имя] → Выйти** из iCloud; отключить **Find My iPhone**.
2. **Перенос или сброс → Стереть контент и настройки**.

См. [цифровую безопасность](/encyclopedia/1-basics/1-035-bazovaya-informatika/112).

## Устранение неполадок

### Облако не синхронизируется

- Место в облаке заполнено — удалите или расширьте тариф.
- Два аккаунта Google — проверьте, в какой вошли.
- OneDrive — файлы "только онлайн" скачиваются по клику.

### WhatsApp просит код, старый телефон недоступен

- Восстановление из **Google Drive / iCloud** резервной копии WhatsApp на **том же** типе ОС.
- Смена номера — функция в WhatsApp → Изменить номер.

### Telegram не показывает старые секретные чаты

- Ожидаемо — они не переносятся.

### Steam Guard блокирует вход

- Резервные коды Steam Guard при настройке — сохраните при первой активации.
- Письмо на почту аккаунта.

### Migration Assistant завис

- Перезагрузка обоих Mac; кабель вместо Wi‑Fi; отключить VPN.

### Windows "Перенос" не видит старый ПК

- Один Wi‑Fi; брандмауэр — разрешить приложение; обновить Windows на обоих.

### Фото частично пропали

- Проверьте **корзину** Google Фото / iCloud.
- На Android — Google Фото → "Освободить место" могло удалить локальные копии — оригинал в облаке.

### Банк не пускает с нового телефона

- Звонок в поддержку; иногда нужно отвязать старое в приложении на старом телефоне.

## Windows ↔ Mac — двойная жизнь

Если используете **оба**:

- Документы — **Google Drive / OneDrive / iCloud для Windows**.
- Закладки — синхронизация Chrome или Edge.
- Фото — Google Фото или iCloud с клиентом на Windows.
- Не ждите, что `.exe` программы заработают на Mac — ищите macOS-версию или аналог.

## Частые вопросы (FAQ)

**Можно ли клонировать весь диск на новый ПК?**

Не рекомендуется — другие драйверы, другой ключ Windows, мусор и malware. Переносите **данные** и ставите программы заново.

**Сколько времени занимает перенос телефона?**

Quick Start / Google — от 30 минут до нескольких часов при 100+ ГБ приложений.

**Потеряю ли лицензию Windows при смене ПК?**

OEM лицензия привязана к старому железу; новый ПК — новая лицензия. Retail — переносима с деактивацией на старом.

**Нужен ли кабель для WhatsApp Android → Android?**

Официальный перенос — да, USB. Без кабеля — только облачная резервная копия WhatsApp при переустановке на том же Android.

**Переносятся ли удалённые фото?**

Если были в облаке и не очищена корзина — иногда да. Локально удалённые без бэкапа — нет.

**Старый телефон сломан, экран не работает**

- WhatsApp — восстановление из Google/iCloud backup при новой установке на **той же** ОС.
- Google Authenticator без экспорта — восстановление 2FA через **резервные коды** сервисов или поддержку.

**Стоит ли платить сервису переноса в магазине?**

Для новичка с iPhone→iPhone или Google backup — обычно не нужно. Сложный Android→iPhone WhatsApp — инструкция Apple бесплатна.

**Как перенести Microsoft Office?**

Войдите в **Microsoft 365** на новом ПК — подписка активирует Office. Старые ключи коробочной версии — привязка к аккаунту Microsoft в portal.office.com.

**Как перенести закладки Firefox?**

Firefox → Закладки → Управление → Экспорт в HTML → на новом ПК импорт HTML. Или Firefox Sync через аккаунт Mozilla.

**Как перенести Bitwarden?**

Войдите в **тот же аккаунт** — хранилище в облаке. Master password тот же; 2FA Bitwarden — с нового телефона после установки приложения.

**Перенос с Linux на Windows?**

Домашняя папка `/home/user` — документы на USB или rsync. Программы — Windows-версии заново. Dual-boot не переносите — только данные.

## Microsoft 365 и OneDrive — детально

1. На старом ПК убедитесь, что файлы **синхронизированы** (зелёная галочка OneDrive).
2. На новом — установите OneDrive, войдите в Microsoft-аккаунт.
3. **Office** — portal.office.com → Установить Office или из Microsoft Store.
4. Outlook — почта подтягивается после добавления аккаунта.
5. Teams — вход тем же аккаунтом; история чатов в облаке организации.

Локальные файлы **только на диске** без OneDrive — скопируйте вручную в папку OneDrive на старом ПК и дождитесь синхронизации.

## Браузеры — закладки, пароли, расширения

### Google Chrome

1. Старый ПК — включена **Синхронизация** (Профиль → Включить синхронизацию).
2. Новый ПК — Chrome → войти в Google → синхронизация подтянет закладки, пароли, историю, расширения.
3. Без синхронизации — `chrome://bookmarks` → Экспорт → импорт на новом.

### Microsoft Edge

- Тот же аккаунт Microsoft; импорт из Chrome при первом запуске Edge.

### Firefox

- Firefox Account и Sync — или экспорт закладок HTML.

**Расширения** — часть ставится автоматически при sync; проверьте блокировщики рекламы и менеджеры паролей.

## Внешний диск как промежуточный носитель

Схема **старое → USB SSD → новое** надёжна без быстрого интернета.

1. Отформатируйте диск **exFAT** (читают Windows и Mac) или NTFS только для Windows.
2. Скопируйте папки с проверкой **размера** (сравните свойства папок).
3. **Безопасное извлечение** на обоих ПК.
4. На новом — проверка контрольной суммы для критичных архивов (7-Zip → Test).

## День D — пошаговый сценарий (телефон)

**Утро**

1. Зарядка обоих телефонов 100%.
2. Последний **Google/iCloud backup** вручную.
3. Экспорт 2FA.

**Получение нового**

4. Не удаляйте приложения на старом.
5. Quick Start / Google restore.
6. WhatsApp по инструкции **до** удаления на старом.
7. Проверка банков, Telegram, 2FA.

8. Старый телефон в ящик **7 дней** — страховка от ошибок.
9. Потом сброс и продажа.
