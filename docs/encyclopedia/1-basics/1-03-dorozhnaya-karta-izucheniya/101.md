# Где и о чём почитать

<div class="article-tags">
  <span class="tag tag-required">ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

<span class="complexity-badge">Всем</span>

Это **справочник-указатель** по всей энциклопедии. Ищете конкретное слово — откройте поиск на странице (**Ctrl+F**) или пролистайте алфавитный список ниже. Поиск текста в файлах на компьютере (папка, лог, терминал) — [отдельная статья](/encyclopedia/2-system-network/2-05-terminal/104). В колонке «Ссылки» несколько стрелок **[→]** ведут к разным материалам по теме.

<div class="callout callout--tip">
  <div class="callout-title">Как пользоваться</div>
  Нужен **Word** — найдите строку Word в [алфавитном указателе](#алфавитный-указатель). Нужен **Docker** — то же самое. Для обзора целого направления (например, «всё про сеть») используйте [указатель по разделам](#указатель-по-разделам-энциклопедии). Стартовый маршрут для новичка — [дорожная карта](./1).
</div>
