## Краткий анализ для выбора курса

| Язык | С чего начать | Главный плюс в обучении | Главный риск |
| --- | --- | --- | --- |
| **Scratch** | 8–10 лет, без установки IDE | Алгоритмы без синтаксических ошибок | Сложный переход к тексту без мостика |
| **Java** | 11+, олимпиады, Android (классика) | Строгая дисциплина, огромная документация | Много «обвязки» до первого вывода |
| **C#** | 11+, Unity, Windows | Тот же ООП, что Java, но проще entry в .NET | Путаница с версиями .NET |
| **Kotlin** | 12+, современный Android | Короче Java, null-безопасность | Нужен JDK на JVM-курсе |
| **Go** | 13+, утилиты и сервисы | Мало ключевых слов, один бинарник | `if err != nil` рано для новичка |
| **C++** | 14+, Unreal, олимпиады | Контроль и скорость | Указатели и UB — не в первый месяц |
| **Rust** | 15+, системное программирование | Безопасность без GC | Borrow checker отпугивает без объяснения «зачем» |

**Практическая лестница** (можно менять под класс): Scratch → Kotlin или Java → C# (игры) → Go (сервисы) → C++ → Rust.

Не смешивайте на одном семестре Java и C# с нуля — синтаксис похож, ученики путают `System.out` и `Console.WriteLine`. Лучше один ООП-язык за год, второй — во втором году как «второй родной».
