## Практические задания

1. Найдите `security.txt` у трёх любимых сервисов и выпишите `Contact` и `Policy`.
2. Пройдите один модуль PortSwigger (например, SQL injection) и оформите учебный мини-отчёт по [шаблону из статьи 2](./2.md).
3. Сравните scope двух программ на HackerOne и отметьте различия в запретах (DoS, социнженерия).
4. Рассчитайте CVSS 3.1 для учебного IDOR с [калькулятором FIRST](https://www.first.org/cvss/calculator/3.1).
