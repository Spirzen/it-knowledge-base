Ответы — в [шагах 1–3](./intro.md) и [итогах](./998.md). Сначала ответьте устно или письменно, затем сверьтесь со статьями.

## Блок 1 — запуск и KV

1. Почему `vault server -dev` нельзя в production?

   **Ориентир:** данные в памяти, нет HA, известный root token, нет enterprise audit/unseal.

2. Чем KV **v2** отличается от v1 (metadata и versions)?

   **Ориентир:** v2 — версии, soft delete, path `secret/data/` и `secret/metadata/`.

3. Что означают `VAULT_ADDR` и `VAULT_TOKEN`?

   **Ориентир:** адрес API и credential для CLI/API запросов.

4. Как прочитать одно поле password без вывода всего секрета?

   **Ориентир:** `vault kv get -field=password secret/demo/db`.

---

## Блок 2 — policies и AppRole

5. Какой **результат** даёт **AppRole** вместо root token в CI?

   **Ориентир:** short-lived token с ограниченной policy, secret_id одноразовый.

6. Что такое least privilege в контексте `demo-read.hcl`?

   **Ориентир:** только read на `secret/data/demo/*`, без write и prod paths.

7. Зачем разделяют role_id и secret_id?

   **Ориентир:** role_id стабилен, secret_id секретный и короткоживущий.

8. Что пишется в audit log при compliance?

   **Ориентир:** кто, когда, path, успех/отказ — [8.07/114](/encyclopedia/8-infra-security/8-07-informatsionnaya-bezopasnost/114).

## Блок 3 — приложение и Kubernetes

9. Как Pod в Kubernetes получает secret **без** YAML password в Git?

   **Ориентир:** ExternalSecret + ESO + Vault; Git только ExternalSecret manifest.

10. Что делает `refreshInterval` в ExternalSecret?

    **Ориентир:** как часто ESO перечитывает Vault и обновляет K8s Secret.

11. Почему fetch at startup лучше `.env` на диске?

    **Ориентир:** секрет в памяти процесса, не в файле в образе или volume.

12. Как GitHub Actions получает доступ к Vault без long-lived token?

    **Ориентир:** OIDC JWT + Vault jwt auth — [8.12/8](/encyclopedia/8-infra-security/8-12-aktualnye-praktiki/8).

## Блок 4 — связь с GitOps

13. Что синхронизирует Argo CD, а что Vault?

    **Ориентир:** Argo — манифесты; Vault — значения секретов; ESO мост между ними.

14. Что произойдёт после `vault kv put` с новым password?

    **Ориентир:** новая version; ESO обновит K8s Secret по refreshInterval; Pod может потребовать restart.

15. Где почитать теорию после practicum?

    **Ориентир:** [8.03/117](/encyclopedia/8-infra-security/8-03-zabota-o-kode-i-dannyh/117), [8.13 GitOps](/encyclopedia/8-infra-security/8-13-praktikum-gitops/intro), [8.12 DevSecOps](/encyclopedia/8-infra-security/8-12-aktualnye-praktiki/3).
