## Мессенджер

**Мессенджер** — приложение для **диалога и групповых чатов** в режиме, близком к реальному времени: Telegram, WhatsApp, Slack, Discord, Matrix.

| Свойство | Следствие |
|----------|-----------|
| Поток сообщений | Старые реплики «уезжают» вверх; важное теряется без закрепления |
| Короткие реплики | Нормально; длинный текст лучше в тред или документ |
| Уведомления | Каждое сообщение прерывает; злоупотребление пингом = шум |
| Каналы и роли | Модель Discord/Slack ближе к форумным **разделам** |

**В IT-команде** мессенджер — для оперативки, инцидентов, быстрых согласований. Договорённости и спецификации — в тикете, почте или wiki, иначе нет **архива по теме**.

  <div class="callout-body">
  В рунетском сленге **чят** — любой чат (IRC, игровой, канал). Не путать с «чат-ботом» в разработке. См. [Неолурк: Чят](https://neolurk.org/wiki/%D0%A7%D1%8F%D1%82).

## Соцсеть (лента)

**Соцсеть** в бытовом смысле — платформа с **лентой** подписок: ВК, Facebook, X (Twitter), частично LinkedIn. Алгоритм решает, что вы увидите; пост живёт в **потоке**, а не в ветке с фиксированным [сабжем](/glossary/С#сабж).

| Свойство | Следствие |
|----------|-----------|
| Лайки и репосты | Сигнал «успеха»; провоцирует короткие эмоциональные посты |
| Публичность по умолчанию | Ошибка в посте масштабируется; «скрин навсегда» |
| Смешение ролей | Работа, семья, мемы в одной ленте — размытые границы |
| Модерация | Жалобы, автоматические фильтры, блокировки |

Для **IT-специалиста** соцсеть — маркетинг, нетворкинг, иногда обучение (короткие посты экспертов). Технические разборы надёжнее в блоге, документации или на форуме/issue tracker.

Справочник — [Неолурк: Соцсети](https://neolurk.org/wiki/%D0%A1%D0%BE%D1%86%D0%B8%D0%B0%D0%BB%D1%8C%D0%BD%D0%B0%D1%8F_%D1%81%D0%B5%D1%82%D1%8C).

## Рунет — экосистемы поверх формата

Один и тот же **формат** (лента, чат, блог) в [Рунете](/glossary/Р#рунет) часто означает **конкретную платформу** с привычными правилами.

| Платформа | Формат | Зачем знать в IT |
|-----------|--------|------------------|
| **ВКонтакте** | лента, группы, мессенджер | аудитория, рекрутинг, утечки из открытых групп |
| **Telegram** | чаты и каналы | команды, инциденты, боты; не путать с корпоративной почтой |
| **Habr** | технический блог | туториалы, карьера, комментарии экспертов |
| **[Яндекс](/glossary/Я#яндекс)** | поиск, карты, почта, Диск, 360 | локальный поиск, SSO в компаниях, [1.21 / 4](/encyclopedia/1-basics/1-21-poisk-informatsii/4) |

<div class="callout callout--info">
  <div class="callout-title">Яндекс — не только поиск</div>

  <div class="callout-body">
  Для пользователя «Яндекс» — привычный вход в интернет: выдача, карты, такси, облако. Для разработчика — API, OAuth, метрика, хостинг в Yandex Cloud. Культурные штрихи (мемы, ожидания от «как в поиске») — [Неолурк: Яндекс](https://neolurk.org/wiki/%D0%AF%D0%BD%D0%B4%D0%B5%D0%BA%D1%81); техника поиска — в энциклопедии, не в иронической вики.
  </div>
</div>

Публичный пост о работе в соцсети переживает скриншоты; рабочие секреты и персональные данные клиентов туда не публикуют — см. [Социальные и этические нормы](./113), [1.22 / 1](/encyclopedia/1-basics/1-22-kommunikatsiya-i-obschenie/1).

## Блог

**Блог** — серия **записей** одного автора или редакции: личный сайт, Medium, корпоративный блог, Habr, Substack. Единица — **статья** с заголовком, датой, постоянным URL.

| Свойство | Следствие |
|----------|-----------|
| Авторство явное | Репутация привязана к имени или бренду |
| Длинный формат | Можно развернуть аргумент, код, диаграммы |
| Комментарии | Часто слабее форума; дискуссия уезжает в соцсети |
| RSS / подписка | Асинхронное чтение без алгоритмической ленты |

**Технический блог** в компании — часть [документации и найма](/encyclopedia/1-basics/1-28-marketing-i-rasprostranenie/intro): кейсы, культура инженерии, анонсы. По сути это **CMS** + [веб-сайт](/encyclopedia/2-system-network/2-04-kak-rabotayut-sayty-i-veb-sayty/1).

Справочник — [Неолурк: Блог](https://neolurk.org/wiki/%D0%91%D0%BB%D0%BE%D0%B3).

## Сводная таблица

| | Мессенджер | Соцсеть (лента) | Блог |
|---|------------|-----------------|------|
| **Темп** | секунды–минуты | часы | дни–недели |
| **Архив по теме** | слабый | средний (профиль) | сильный (URL статьи) |
| **Идеальный контент** | вопрос, статус, пинг | анонс, мнение, мем | туториал, разбор |
| **Тон** | разговорный | публичный перформанс | экспертный или личный |
| **IT-аналог** | Slack, Telegram-чат команды | LinkedIn, канал в TG | Habr, dev.to, docs |

**Форум** остаётся эталоном **длинной ветки по одному сабжу** — см. [Форумная культура Рунета](./120). GitHub **Discussions** и **Issues** в open-source — современная наследница форума с привязкой к коду.

## Куда писать в работе

| Задача | Канал |
|--------|--------|
| «Сервер лежит» | мессенджер дежурного + тикет |
| «Как мы решили архитектуру» | ADR, wiki, блог инженерии |
| «Нанимаем, делимся опытом» | блог / LinkedIn |
| «Баг с шагами воспроизведения» | issue tracker (не лента) |
| «Обсуждение RFC неделю» | форум, mailing list, тред в Discussions |
