## Открытый исходный код

**Open Source** (открытый исходный код) — лицензия и практика, при которых исходники доступны для чтения, форка и распространения на условиях GPL, MIT, Apache и др.

| В рунете часто путают | На деле |
|----------------------|--------|
| "бесплатно" | лицензия ≠ цена; может быть платная поддержка |
| "всё открыто" | есть проприетарные модули в "открытых" продуктах |
| "форк = воровство" | форк проекта — нормальный механизм OSS ([форк Git](/glossary/Ф#форк-git)) |

Учёба — [7.07 ИС](/encyclopedia/7-project/7-07-intellektualnye-prava/intro), [7.10 Культура кода](/encyclopedia/7-project/7-10-kultura-koda/intro), [глоссарий](/glossary/О#открытый-исходный-код). [Неолурк: Open source](https://neolurk.org/wiki/Open_source).

## GitHub

**GitHub** — хостинг **Git**-репозиториев плюс Issues, Pull Request, Actions (CI), Pages, Discussions.

| Функция | Зачем в учёбе |
|---------|----------------|
| Репозиторий | хранение кода и истории |
| Pull Request | код-ревью перед merge |
| Issues | баги и задачи |
| Actions | автосборка и тесты |
| Pages | статический сайт ([lab / GitHub Pages](/lab/Кейсы/3)) |

В мемах "GitHub" = "выложил в интернет", но в работе это инфраструктура процесса: **репозиторий, ревью, CI, релизы**. Юридически важны **лицензия** `LICENSE` и **секреты** (не коммитить `.env`). Карточка — [глоссарий: GitHub](/glossary/G#github). [Неолурк: GitHub](https://neolurk.org/wiki/GitHub). Git — [8.04 / 2](/encyclopedia/8-infra-security/8-04-devops-ci-cd/2).

## DevOps

**DevOps** — культура и практики **совместной** ответственности разработки и эксплуатации: CI/CD, инфраструктура как код, мониторинг, быстрый откат.

В чате "DevOps" иногда называют любого, кто "крутит Docker", или любую автоматизацию. В учебнике — раздел [8.04](/encyclopedia/8-infra-security/8-04-devops-ci-cd/intro): среды, пайплайн, типичные ошибки выката.

[Неолурк: DevOps](https://neolurk.org/wiki/DevOps). Эталон тона — [8.04 / 1](/encyclopedia/8-infra-security/8-04-devops-ci-cd/1). Карточка — [глоссарий: DevOps](/glossary/D#devops).
