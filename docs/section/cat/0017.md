## Справочники

Подборка из **81** документа в едином формате:

1. **Назначение** — что это за шпаргалка и ссылка на учебный раздел  
2. **Краткое пояснение** — суть в нескольких предложениях  
3. **Быстрый старт** — реальные команды (если применимо)  
4. **Справочные таблицы** — полное содержимое: синтаксис, API, параметры, значения (с оглавлением в крупных справочниках)  
5. **Ошибки** / **Совместимость** — для инфраструктуры, протоколов и инструментов  

Справочники **не дублируют** вводные курсы — для обучения используйте соответствующие разделы энциклопедии; здесь только быстрый доступ к фактам.

Полный список — в боковой панели: **Подборки → Справочники**.
