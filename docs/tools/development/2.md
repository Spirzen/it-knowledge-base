## Архиваторы и сжатие

Разные типы файлов по-разному сжимаются: текст и логи — хорошо, JPEG и шифротекст — почти нет.

### 7-Zip

- **Лицензия**: LGPL (открытый исходный код)
- **Форматы**: 7z, ZIP, RAR (распаковка), TAR, GZIP и др.
- **Особенности**: высокая степень сжатия 7z, интеграция в проводник Windows
- **Сайт**: [7-zip.org](https://www.7-zip.org/)

---

### WinRAR

- **Лицензия**: проприетарная (условно-бесплатный trial)
- **Форматы**: RAR, ZIP; восстановление повреждённых архивов, AES-128
- **Сайт**: [rarlab.com](https://www.rarlab.com/)

---

### PeaZip

- **Лицензия**: LGPL
- **Форматы**: 200+; шифрование, двухпанельный UI
- **Сайт**: [peazip.github.io](https://peazip.github.io/)

## Терминал и удалённый доступ

<TerminalEmulator />

---

### PuTTY

- **Назначение**: SSH, Telnet, Serial (классика Windows)
- **Лицензия**: MIT
- **Сайт**: [putty.org](https://www.putty.org/)

---

### FileZilla

- **Назначение**: FTP, FTPS, SFTP, двухпанельный клиент
- **Лицензия**: GPL
- **Сайт**: [filezilla-project.org](https://filezilla-project.org/)

---

### OpenSSH

- **Назначение**: `ssh`, `scp`, `sftp` в Linux/macOS и Windows 10+
- **Установка (Windows)**: "Клиент OpenSSH" в "Необязательные компоненты"

## Сеть: захват и анализ

<NetworkTrafficMonitorDemo />

---

### Wireshark

- **Назначение**: GUI-анализ пакетов (libpcap / Npcap)
- **Лицензия**: GPL
- **Сайт**: [wireshark.org](https://www.wireshark.org/)

---

### tcpdump

- **Назначение**: захват в CLI на серверах
- **Пример**: `sudo tcpdump -i eth0 port 443 -w capture.pcap`

---

### Nmap

- **Назначение**: сканирование портов, OS fingerprint, NSE-скрипты
- **Сайт**: [nmap.org](https://nmap.org/)

---

## Git, сборка, контейнеры

### Git

- **Назначение**: распределённый контроль версий
- **Установка**:
```bash
  sudo apt install git    # Debian/Ubuntu
  git --version
```
- **Документация**: [git-scm.com](https://git-scm.com/doc)

---

### CMake

- **Назначение**: кроссплатформенная генерация проектов (Makefile, Ninja, VS)
- **Сайт**: [cmake.org](https://cmake.org/)

<DockerEmulator />

---

### Docker Desktop

- **Назначение**: локальные контейнеры и Compose на рабочей станции
- **Платформы**: Windows (WSL2/Hyper-V), macOS, Linux
- **Сайт**: [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/)

---

### VirtualBox / VMware Workstation Player

- **Назначение**: полные виртуальные машины (другая ОС в гостевой системе)
- **VirtualBox**: GPL, [virtualbox.org](https://www.virtualbox.org/)

## Прочие полезные CLI

```bash
# Поиск открытых файлов процесса (Linux)
lsof -p $(pidof nginx)

# Мониторинг ресурсов
htop
glances

# Метаданные медиа
ffprobe video.mp4
exiftool photo.jpg
```
