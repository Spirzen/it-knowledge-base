## Утилиты

**7-Zip** — это бесплатный архиватор с открытым исходным кодом, предназначенный для сжатия и распаковки файлов в форматах 7z, ZIP, RAR, TAR, GZIP и других, поддерживающий высокую степень сжатия в формате 7z, доступный на платформах Windows и Linux через Wine, реализованный на языке C++ и интегрируемый в контекстное меню проводника.  

**WinRAR** — это условно-бесплатный архиватор, предназначенный для создания, извлечения и управления архивами в форматах RAR и ZIP, поддерживающий восстановление поврежденных архивов и шифрование AES-128, доступный на платформах Windows, macOS, Android и iOS, распространяемый под проприетарной лицензией.  

**VLC media player** — это бесплатный медиаплеер с открытым исходным кодом, предназначенный для воспроизведения аудио- и видеофайлов практически всех форматов без необходимости установки дополнительных кодеков, поддерживающий потоковую передачу и трансляцию, доступный на платформах Windows, macOS, Linux, Android и iOS, построенный на фреймворке libVLC.  

**Notepad++** — это бесплатный текстовый редактор с открытым исходным кодом, предназначенный для написания и редактирования кода, скриптов и конфигурационных файлов, поддерживающий подсветку синтаксиса для множества языков программирования, автозавершение и макросы, доступный на платформе Windows, реализованный на C++ с использованием библиотеки Scintilla.  

**Visual Studio Code** — это бесплатный редактор кода с открытым исходным кодом от Microsoft, предназначенный для разработки программного обеспечения с поддержкой отладки, управления версиями и интеллектуального автозавершения, доступный на платформах Windows, macOS и Linux, построенный на фреймворке Electron и интегрируемый с расширениями из централизованного магазина.  
**Sublime Text** — это условно-бесплатный текстовый редактор, предназначенный для быстрого редактирования кода и текста, поддерживающий многокурсорное редактирование, проекты и пользовательские сборки, доступный на платформах Windows, macOS и Linux, реализованный на C++ и Python, распространяемый под собственной лицензией.  

**PuTTY** — это бесплатный терминальный клиент с открытым исходным кодом, предназначенный для удалённого подключения к серверам по протоколам SSH, Telnet, Rlogin и Serial, поддерживающий сохранение сессий и настройку параметров соединения, доступный на платформе Windows, реализованный на C.  

**FileZilla** — это бесплатный FTP-клиент с открытым исходным кодом, предназначенный для передачи файлов по протоколам FTP, FTPS и SFTP, поддерживающий управление очередями загрузок и двойную панель интерфейса, доступный на платформах Windows, macOS и Linux, реализованный на C++ с использованием библиотеки wxWidgets.  

**GIMP** — это бесплатный графический редактор с открытым исходным кодом, предназначенный для обработки растровых изображений, поддерживающий слои, маски, фильтры и расширения на языке Scheme или Python, доступный на платформах Windows, macOS и Linux, реализованный на C с использованием GTK+.  

**Inkscape** — это бесплатный векторный графический редактор с открытым исходным кодом, предназначенный для создания и редактирования SVG-изображений, поддерживающий узловое редактирование, экспорт в PNG и PDF, а также расширения на Python, доступный на платформах Windows, macOS и Linux, реализованный на C++ с использованием GTK+.  

**Audacity** — это бесплатный аудиоредактор с открытым исходным кодом, предназначенный для записи, редактирования и анализа звуковых файлов, поддерживающий эффекты, плагины VST и экспорт в WAV, MP3, FLAC, доступный на платформах Windows, macOS и Linux, реализованный на C++ с использованием wxWidgets.  

**OBS Studio** — это бесплатное приложение с открытым исходным кодом, предназначенное для записи экрана и стриминга в реальном времени, поддерживающее наложение источников, сцены и кодирование через x264 или NVENC, доступное на платформах Windows, macOS и Linux, реализованное на C++ с использованием Qt.  

**qBittorrent** — это бесплатный торрент-клиент с открытым исходным кодом, предназначенный для загрузки и раздачи файлов по протоколу BitTorrent, поддерживающий поиск по трекерам, ограничение скорости и веб-интерфейс, доступный на платформах Windows, macOS и Linux, реализованный на C++ с использованием Qt.  

**Transmission** — это бесплатный торрент-клиент с открытым исходным кодом, предназначенный для легковесной загрузки торрентов, поддерживающий шифрование, приоритезацию файлов и удалённое управление через RPC, доступный на платформах macOS, Linux, BSD и других Unix-подобных системах, реализованный на C с использованием GTK+ или Cocoa.  

**Wireshark** — это бесплатный анализатор сетевого трафика с открытым исходным кодом, предназначенный для перехвата и детального анализа пакетов в реальном времени, поддерживающий сотни протоколов и фильтрацию по выражениям, доступный на платформах Windows, macOS и Linux, реализованный на C с использованием GTK+.  

**Nmap** — это бесплатная утилита с открытым исходным кодом, предназначенная для сканирования сетей, обнаружения хостов и портов, а также определения операционных систем и служб, поддерживающая скрипты на NSE, доступная на платформах Windows, macOS и Linux, реализованная на C и C++.  

**CMake** — это бесплатная система сборки с открытым исходным кодом, предназначенная для генерации файлов проекта для различных компиляторов и сред разработки, поддерживающая кроссплатформенную сборку и кэширование конфигураций, доступная на платформах Windows, macOS и Linux, реализованная на C++.  

**Git** — это бесплатная распределённая система контроля версий с открытым исходным кодом, предназначенная для отслеживания изменений в исходном коде, поддержки ветвления, слияния и совместной работы, доступная на платформах Windows, macOS и Linux, реализованная на C и распространяемая под лицензией GPLv2.  

**FFmpeg** — это бесплатный мультимедийный фреймворк с открытым исходным кодом, предназначенный для конвертации, потоковой передачи и обработки аудио- и видеофайлов, поддерживающий сотни кодеков и форматов, доступный на платформах Windows, macOS и Linux, реализованный на C.  

**HandBrake** — это бесплатный видеоконвертер с открытым исходным кодом, предназначенный для перекодирования видео в современные форматы, поддерживающий предустановки для устройств, аппаратное ускорение и пакетную обработку, доступный на платформах Windows, macOS и Linux, реализованный на C с использованием FFmpeg и x264.  

**Calibre** — это бесплатный менеджер электронных книг с открытым исходным кодом, предназначенный для организации, конвертации и синхронизации библиотеки e-book, поддерживающий форматы EPUB, MOBI, PDF и другие, доступный на платформах Windows, macOS и Linux, реализованный на Python с использованием Qt.  

**Sumatra PDF** — это бесплатный просмотрщик PDF с открытым исходным кодом, предназначенный для быстрого открытия документов в форматах PDF, ePub, MOBI, XPS и CBZ, поддерживающий минимальный интерфейс и запуск по двойному клику, доступный на платформе Windows, реализованный на C++ с использованием MuPDF.  

**Everything** — это бесплатная утилита для быстрого поиска файлов на диске, предназначенная для мгновенного индексирования имён файлов в NTFS-томах, поддерживающая регулярные выражения и экспорт результатов, доступная на платформе Windows, реализованная на C++.  

**AutoHotkey** — это бесплатный язык сценариев и среда автоматизации с открытым исходным кодом, предназначенные для создания макросов, горячих клавиш и автоматизации задач в Windows, поддерживающие взаимодействие с GUI и API, доступные на платформе Windows, реализованные на C++.  
**Rufus** — это бесплатная утилита с открытым исходным кодом, предназначенная для создания загрузочных USB-накопителей из ISO-образов, поддерживающая UEFI и BIOS, проверку целостности и запись в DD-режиме, доступная на платформе Windows, реализованная на C.  

**Docker Desktop** — это коммерческое приложение с бесплатной версией для индивидуальных разработчиков, предназначенное для локального запуска и управления контейнерами Docker, поддерживающее Kubernetes, образы и сети, доступное на платформах Windows и macOS, построенное на гипервизоре Hyper-V или WSL2 в Windows и на HyperKit в macOS.  

**VirtualBox** — это бесплатный гипервизор с открытым исходным кодом от Oracle, предназначенный для запуска виртуальных машин с различными операционными системами, поддерживающий снапшоты, общие папки и сетевые режимы, доступный на платформах Windows, macOS, Linux и Solaris, реализованный на C++.  

**VMware Workstation Player** — это условно-бесплатный гипервизор, предназначенный для запуска виртуальных машин на рабочих станциях, поддерживающий изоляцию ОС и базовые функции виртуализации, доступный на платформах Windows и Linux, распространяемый под проприетарной лицензией.  

**PeaZip** — это бесплатный архиватор с открытым исходным кодом, предназначенный для управления архивами в 200+ форматах, поддерживающий шифрование, двухпанельный интерфейс и интеграцию в контекстное меню, доступный на платформах Windows и Linux, реализованный на Free Pascal с использованием Lazarus.  

**LibreOffice** — это бесплатный офисный пакет с открытым исходным кодом, предназначенный для работы с текстами, таблицами, презентациями и базами данных, поддерживающий форматы ODF, DOCX, XLSX и другие, доступный на платформах Windows, macOS и Linux, реализованный на C++ и Java с использованием VCL и UNO.  

**Apache OpenOffice** — это бесплатный офисный пакет с открытым исходным кодом, предназначенный для создания документов, электронных таблиц и презентаций, поддерживающий совместимость с форматами Microsoft Office, доступный на платформах Windows, macOS и Linux, реализованный на C++ и Java.  

**KeePass** — это бесплатный менеджер паролей с открытым исходным кодом, предназначенный для безопасного хранения учётных данных в зашифрованной базе, поддерживающий плагины, автозаполнение и экспорт в различные форматы, доступный на платформе Windows с портами для других ОС, реализованный на C#.  

**Bitwarden** — это условно-бесплатный менеджер паролей с открытым исходным кодом, предназначенный для синхронизации и защиты паролей между устройствами, поддерживающий двухфакторную аутентификацию и расширения для браузеров, доступный на платформах Windows, macOS, Linux, Android, iOS и веб, реализованный на TypeScript и .NET.  

**Malwarebytes** — это коммерческий антивирус с бесплатной версией, предназначенный для обнаружения и удаления вредоносного ПО, рекламных программ и потенциально нежелательных приложений, поддерживающий сканирование по запросу и защиту в реальном времени в платной версии, доступный на платформах Windows, macOS, Android и iOS.  

**CCleaner** — это условно-бесплатная утилита для очистки системы, предназначенная для удаления временных файлов, исправления реестра и управления автозагрузкой, доступная на платформах Windows и macOS, распространяемая под проприетарной лицензией.  

**HWiNFO** — это бесплатная утилита с открытым исходным кодом для мониторинга оборудования, предназначенная для сбора информации о процессоре, памяти, дисках, температуре и напряжении, поддерживающая логирование и экспорт данных, доступная на платформе Windows.  

**Speccy** — это условно-бесплатная утилита для диагностики системы, предназначенная для отображения подробной информации об аппаратных компонентах компьютера, поддерживающая мониторинг температур и обновления драйверов, доступная на платформе Windows, распространяемая под проприетарной лицензией.  

**ShareX** — это бесплатная утилита с открытым исходным кодом, предназначенная для захвата экрана, записи GIF и автоматической загрузки контента в облачные сервисы, поддерживающая аннотации, OCR и пользовательские рабочие процессы, доступная на платформе Windows, реализованная на C#.  

**Greenshot** — это бесплатная утилита с открытым исходным кодом, предназначенная для создания скриншотов с последующим редактированием и экспортом в файл, буфер обмена или принтер, поддерживающая плагины и горячие клавиши, доступная на платформе Windows, реализованная на C#.  

**Balena Etcher** — это бесплатная утилита с открытым исходным кодом, предназначенная для записи образов дисков на USB-накопители и SD-карты, поддерживающая проверку целостности и кроссплатформенный запуск, доступная на платформах Windows, macOS и Linux, реализованная на JavaScript с использованием Electron.  

**DiskGenius** — это условно-бесплатная утилита для управления разделами диска, предназначенная для создания, изменения, восстановления и клонирования томов, поддерживающая RAID, MBR/GPT и восстановление данных, доступная на платформе Windows.  

**IrfanView** — это бесплатный просмотрщик изображений с закрытым исходным кодом, предназначенный для быстрого просмотра и базового редактирования графических файлов, поддерживающий плагины, пакетную обработку и множество форматов, доступный на платформе Windows.  
**foobar2000** — это бесплатный аудиоплеер с закрытым исходным кодом, предназначенный для воспроизведения музыки с высокой точностью и минимальным потреблением ресурсов, поддерживающий компоненты, темы и форматы FLAC, APE, WV, доступный на платформе Windows.  

**MediaInfo** — это бесплатная утилита с открытым исходным кодом, предназначенная для отображения технической информации о медиафайлах, включая кодеки, битрейт, разрешение и метаданные, поддерживающая GUI и CLI, доступная на платформах Windows, macOS и Linux.  

**ExifTool** — это бесплатная командная утилита с открытым исходным кодом, предназначенная для чтения, записи и редактирования метаданных в изображениях, видео и документах, поддерживающая сотни форматов и тегов, доступная на платформах Windows, macOS и Linux, реализованная на Perl.  

**Process Explorer** — это бесплатная утилита от Microsoft, предназначенная для детального мониторинга запущенных процессов, дескрипторов и DLL, заменяющая стандартный Диспетчер задач, доступная на платформе Windows, реализованная на C.  

**Sysinternals Suite** — это бесплатный набор утилит от Microsoft, предназначенный для администрирования, диагностики и мониторинга систем Windows, включающий Autoruns, PsTools, ProcMon и другие, доступный на платформе Windows.  

**CrystalDiskInfo** — это бесплатная утилита с открытым исходным кодом, предназначенная для мониторинга состояния жёстких дисков и SSD по SMART-атрибутам, поддерживающая уведомления и температурный контроль, доступная на платформе Windows.  

**CrystalDiskMark** — это бесплатная утилита с открытым исходным кодом, предназначенная для тестирования скорости чтения и записи накопителей, поддерживающая различные режимы и размеры блоков, доступная на платформе Windows.  

**Recuva** — это условно-бесплатная утилита для восстановления удалённых файлов, предназначенная для поиска и возврата данных с жёстких дисков, флешек и карт памяти, поддерживающая глубокое сканирование и предварительный просмотр, доступная на платформе Windows.
