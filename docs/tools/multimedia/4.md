**Аудиоинструменты** — от записи голоса для скринкаста до полноценного музыкального продакшена. Для IT чаще всего нужны: подкаст, озвучка видео, шумоподавление в созвонах и нормализация громкости.

## DAW (цифровые аудиостанции)

| Инструмент | Платформы | Лицензия | Особенности |
|------------|-----------|----------|-------------|
| **Reaper** | Win, macOS, Linux | Trial / недорогая | ReaScript, лёгкий дистрибутив |
| **Ardour** | Linux, macOS, Win | Pay-what-you-want | JACK, LV2/VST, студийный уровень |
| **LMMS** | Кроссплатформа | Open source | Электроника, без записи живого вокала "из коробки" |
| **Cakewalk** | Windows | Free (BandLab) | Бывший Sonar, VST3 |
| **FL Studio** | Win, macOS | Коммерция | Паттерны, электроника |
| **Ableton Live** | Win, macOS | Коммерция | Live-выступления, Session View |
| **Logic Pro** | macOS | Коммерция | Экосистема Apple, AU |
| **Pro Tools** | Win, macOS | Подписка | Студии, AAX, Dolby Atmos |
| **Bitwig Studio** | Кроссплатформа | Коммерция | The Grid, модульный синтез |
| **Studio One** | Win, macOS | Коммерция | Drag-and-drop, PreSonus |
| **Qtractor** | Linux, macOS | GPL | JACK + LV2 |

## Утилиты и CLI

```bash
# Извлечь дорожку из видео
ffmpeg -i input.mp4 -vn -acodec copy audio.m4a

# Нормализация громкости (пример)
ffmpeg -i loud.wav -af loudnorm output.wav
```

| Утилита | Назначение |
|---------|------------|
| **FFmpeg** | Транскод, extract, stream |
| **SoX** | Эффекты и конвертация в терминале |
| **Spek** | Спектрограмма файла |
| **ExifTool** | Теги в метаданных |
| **Voicemeeter** | Виртуальный микшер (Windows) |
| **Equalizer APO** | Системный EQ (Windows) |
