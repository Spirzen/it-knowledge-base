# Редакторы

Мультимедиа редакторы — программные средства, предназначенные для создания, обработки и модификации аудио-, видео- и графических материалов. В данном разделе приведены инструменты, разделённые по категориям: аудиоредакторы, видеоредакторы, графические редакторы и универсальные мультимедийные пакеты.

---

### 1. Аудиоредакторы

| Название | Описание | Установка / Ссылка |
|----------|----------|---------------------|
| **Audacity** | Кроссплатформенный аудиоредактор с поддержкой записи, редактирования, обработки и анализа звука. Поддерживает плагины (VST, LADSPA). | [https://www.audacityteam.org/](https://www.audacityteam.org/) (скачать) |
| **Ocenaudio** | Простой и быстрый аудиоредактор с интуитивным интерфейсом, поддержкой реального времени при обработке. | [https://www.ocenaudio.com/](https://www.ocenaudio.com/) |
| **Ardour** | Профессиональная DAW (Digital Audio Workstation) с поддержкой записи, редактирования, микширования и мастеринга. | `sudo apt install ardour` (Linux), [https://ardour.org/](https://ardour.org/) |
| **LMMS** | DAW для создания музыки, включает синтезаторы, семплеры, MIDI-редактор. Подходит для электронной музыки. | `sudo apt install lmms`, [https://lmms.io/](https://lmms.io/) |
| **Reaper** | Коммерческая DAW с высокой степенью настраиваемости и поддержкой скриптов (ReaScript). Имеет бесплатный пробный период. | [https://www.reaper.fm/](https://www.reaper.fm/) |
| **Clementine** | Аудиоплеер с базовыми возможностями редактирования метаданных и организации коллекции. | `sudo apt install clementine`, [https://www.clementine-player.org/](https://www.clementine-player.org/) |

### 2. Видеоредакторы

| Название | Описание | Установка / Ссылка |
|----------|----------|---------------------|
| **DaVinci Resolve** | Профессиональный видеоредактор с мощными инструментами цветокоррекции, монтажа, звукового дизайна и VFX. Имеет бесплатную и Studio-версии. | [https://www.blackmagicdesign.com/products/davinciresolve/](https://www.blackmagicdesign.com/products/davinciresolve/) |
| **Shotcut** | Кроссплатформенный открытый видеоредактор с поддержкой 4K, множеством форматов и фильтров. | [https://shotcut.org/](https://shotcut.org/) |
| **OpenShot** | Простой в освоении видеоредактор с поддержкой анимации, ключевых кадров и базовых эффектов. | `sudo apt install openshot-qt`, [https://openshot.org/](https://openshot.org/) |
| **Kdenlive** | Видеоредактор на базе MLT Framework. Подходит как для начинающих, так и для продвинутых пользователей. | `sudo apt install kdenlive`, [https://kdenlive.org/](https://kdenlive.org/) |
| **Blender** | 3D-редактор с развитыми возможностями видеопостобработки и композитинга, включая нелинейный видеомонтаж. | `sudo apt install blender`, [https://www.blender.org/](https://www.blender.org/) |
| **OBS Studio** | Инструмент для записи и потоковой трансляции видео. Поддерживает наложение источников, фильтры, сцены. | [https://obsproject.com/](https://obsproject.com/) |
| **FFmpeg** | Консольная утилита для преобразования, обработки и анализа аудио- и видеоданных. Используется как библиотека и как CLI-инструмент. | `sudo apt install ffmpeg`, [https://ffmpeg.org/](https://ffmpeg.org/) |

### 3. Графические редакторы

| Название | Описание | Установка / Ссылка |
|----------|----------|---------------------|
| **GIMP** | Растровый графический редактор с функциональностью, сопоставимой с Adobe Photoshop. | `sudo apt install gimp`, [https://www.gimp.org/](https://www.gimp.org/) |
| **Inkscape** | Векторный редактор, поддерживающий SVG. Подходит для иллюстраций, логотипов, типографики. | `sudo apt install inkscape`, [https://inkscape.org/](https://inkscape.org/) |
| **Krita** | Растровый редактор, ориентированный на цифровую живопись и анимацию. | `sudo apt install krita`, [https://krita.org/](https://krita.org/) |
| **Darktable** | RAW-процессор и фоторедактор с неразрушающими настройками. Аналог Lightroom. | `sudo apt install darktable`, [https://www.darktable.org/](https://www.darktable.org/) |
| **RawTherapee** | Ещё один RAW-конвертер с продвинутыми возможностями цветокоррекции и шумоподавления. | [https://rawtherapee.com/](https://rawtherapee.com/) |
| **Pinta** | Простой растровый редактор, вдохновлённый Paint.NET. | [https://www.pinta-project.com/](https://www.pinta-project.com/) |
| **Photopea** | Веб-редактор с поддержкой PSD, XCF, Sketch и других форматов. Работает в браузере. | [https://www.photopea.com/](https://www.photopea.com/) |

### 4. Универсальные и специализированные инструменты

| Название | Описание | Установка / Ссылка |
|----------|----------|---------------------|
| **VLC media player** | Медиаплеер с возможностями конвертации, записи, стриминга и базовой обработки видео. | `sudo apt install vlc`, [https://www.videolan.org/vlc/](https://www.videolan.org/vlc/) |
| **HandBrake** | Конвертер видео с поддержкой пресетов, фильтров и пакетной обработки. | [https://handbrake.fr/](https://handbrake.fr/) |
| **Avidemux** | Простой видеоредактор для обрезки, фильтрации и перекодирования. | `sudo apt install avidemux2.7-qt`, [http://avidemux.sourceforge.net/](http://avidemux.sourceforge.net/) |
| **ExifTool** | Утилита командной строки для чтения, записи и редактирования метаданных изображений и видео. | `sudo apt install libimage-exiftool-perl`, [https://exiftool.org/](https://exiftool.org/) |
| **ImageMagick** | Набор утилит для конвертации, редактирования и анализа изображений в терминале. | `sudo apt install imagemagick`, [https://imagemagick.org/](https://imagemagick.org/) |

### Примечания

- Большинство перечисленных инструментов доступно под лицензиями с открытым исходным кодом (GPL, MIT, Apache и др.).
- Для Linux-систем предпочтительный способ установки — через пакетный менеджер (`apt`, `dnf`, `pacman`), что обеспечивает автоматическое разрешение зависимостей.
- Некоторые коммерческие инструменты (например, DaVinci Resolve, Reaper) предоставляют бесплатные версии с ограничениями или полнофункциональные пробные периоды.
