**Мультимедиа-редакторы** создают и изменяют звук, видео и изображения. Для IT-специалиста они нужны не реже кода: скринкасты для документации, обложки к статьям, подкасты, демо для презентаций. Ниже — интерактивный каталог и полные таблицы по категориям.

## Аудиоредакторы

| Название | Описание | Установка / ссылка |
|----------|----------|-------------------|
| **Audacity** | Запись, нарезка, шумоподавление, VST/LADSPA | [audacityteam.org](https://www.audacityteam.org/) |
| **Ocenaudio** | Быстрые правки, превью эффектов в реальном времени | [ocenaudio.com](https://www.ocenaudio.com/) |
| **Ardour** | Студийная DAW: запись, микш, мастер | `sudo apt install ardour`, [ardour.org](https://ardour.org/) |
| **LMMS** | Электронная музыка, синты, MIDI | `sudo apt install lmms`, [lmms.io](https://lmms.io/) |
| **Reaper** | Настраиваемая DAW, ReaScript, щедрый trial | [reaper.fm](https://www.reaper.fm/) |

---

## Видеоредакторы

| Название | Описание | Установка / ссылка |
|----------|----------|-------------------|
| **DaVinci Resolve** | Монтаж, цвет, Fairlight, Fusion | [blackmagicdesign.com](https://www.blackmagicdesign.com/products/davinciresolve/) |
| **Shotcut** | Открытый NLE, 4K, MLT | [shotcut.org](https://shotcut.org/) |
| **OpenShot** | Простой монтаж, ключевые кадры | `sudo apt install openshot-qt`, [openshot.org](https://openshot.org/) |
| **Kdenlive** | Прокси, стабилизация, Linux-first | `sudo apt install kdenlive`, [kdenlive.org](https://kdenlive.org/) |
| **OBS Studio** | Запись и стрим, сцены, виртуальная камера | [obsproject.com](https://obsproject.com/) |
| **FFmpeg** | CLI: транскод, обрезка, стрим | `sudo apt install ffmpeg`, [ffmpeg.org](https://ffmpeg.org/) |

## Графические редакторы

| Название | Описание | Установка / ссылка |
|----------|----------|-------------------|
| **GIMP** | Растр, слои, аналог Photoshop | `sudo apt install gimp`, [gimp.org](https://www.gimp.org/) |
| **Inkscape** | Вектор SVG, логотипы | `sudo apt install inkscape`, [inkscape.org](https://inkscape.org/) |
| **Krita** | Живопись, анимация кадров | `sudo apt install krita`, [krita.org](https://krita.org/) |
| **darktable** | RAW, каталог съёмки | `sudo apt install darktable`, [darktable.org](https://www.darktable.org/) |
| **Photopea** | PSD в браузере | [photopea.com](https://www.photopea.com/) |

## Утилиты конвертации и метаданных

| Название | Описание | Установка / ссылка |
|----------|----------|-------------------|
| **VLC** | Плеер + базовая конвертация и запись | `sudo apt install vlc`, [videolan.org](https://www.videolan.org/vlc/) |
| **HandBrake** | Пресеты под устройства, H.264/H.265 | [handbrake.fr](https://handbrake.fr/) |
| **ImageMagick** | Пакетная обработка изображений в CLI | `sudo apt install imagemagick`, [imagemagick.org](https://imagemagick.org/) |
| **ExifTool** | Метаданные фото и видео | `sudo apt install libimage-exiftool-perl`, [exiftool.org](https://exiftool.org/) |

## Примечания

- Большинство open-source инструментов — **GPL/MIT**; коммерческие (Reaper, Resolve Studio) дают бесплатные или trial-версии.
- На Linux удобнее ставить через **apt/dnf/Flatpak** — зависимости подтянутся автоматически.
- Связанные разделы: [Видео](/tools/multimedia/3), [Аудио](/tools/multimedia/4), [Стриминг](/tools/multimedia/5).
