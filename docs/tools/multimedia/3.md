**Видеоинструменты** охватывают монтаж, цвет, конвертацию, стриминг и совместную работу над роликами. В IT они нужны для обучающих скринкастов, демо продукта, записи встреч и маркетинговых роликов.

## Плеер и просмотр (демо)

Многие задачи начинаются с проверки файла без перекодирования — **VLC** и **MPV** воспроизводят почти любой контейнер.

## Десктоп: монтаж и постпродакшн

| Инструмент | Платформы | Модель | Кратко |
|------------|-----------|--------|--------|
| **DaVinci Resolve** | Win, macOS, Linux | Free + Studio | Монтаж, цвет, Fairlight, Fusion |
| **Adobe Premiere Pro** | Win, macOS | Подписка CC | Стандарт индустрии, связка с AE |
| **Final Cut Pro** | macOS | Покупка | Оптимизация под Apple Silicon |
| **Shotcut** | Кроссплатформа | Open source | MLT, широкие форматы |
| **Kdenlive** | Linux, Win, macOS | Open source | Прокси, эффекты MLT |
| **OpenShot** | Кроссплатформа | Open source | Простой UI, Python/Qt |
| **Blender (VSE)** | Кроссплатформа | Open source | Монтаж внутри 3D-пакета |
| **Lightworks** | Кроссплатформа | Free + Pro | История кино, лимит экспорта в free |
| **Avid Media Composer** | Win, macOS | Подписка | Крупные студии, совместная работа |
| **Sony Vegas Pro** | Windows | Лицензия | Многодорожечный монтаж |
| **VSDC Free Video Editor** | Windows | Free | NLE, маски, 4K |

## Захват, стрим и конвертация

| Инструмент | Назначение |
|------------|------------|
| **OBS Studio** | Запись экрана, RTMP-стрим, сцены |
| **FFmpeg** | CLI: транскод, нарезка, HLS, RTMP |
| **HandBrake** | GUI-конвертация с пресетами |
| **LosslessCut** | Обрезка без перекода (FFmpeg) |
| **VLC** | Воспроизведение, базовая конвертация |
| **MPV** | Минималистичный плеер, скрипты Lua |

Подробнее про эфир — в разделе [Стриминг](/tools/multimedia/5).

## Веб и "лёгкий" монтаж

| Сервис | Сильная сторона |
|--------|----------------|
| **CapCut** | Shorts, шаблоны, TikTok |
| **Clipchamp** | Встроен в Windows 11, стоки |
| **VEED.IO** | Субтитры, озвучка в браузере |
| **Canva Video** | Маркетинг, графика + клип |
| **Descript** | Монтаж по тексту транскрипта |
| **InVideo / Lumen5** | Текст → ролик, AI-шаблоны |
