## Стриминг

**OBS Studio** — это бесплатное приложение с открытым исходным кодом для записи видео и трансляции в реальном времени, предназначенное для стриминга на платформы вроде Twitch, YouTube и Facebook, поддерживающее захват экрана, камер, микрофонов и источников через плагины, доступное на Windows, macOS и Linux, построенное на фреймворке Qt и использующее FFmpeg для обработки медиа.

**Streamlabs Desktop** — это условно-бесплатное приложение для стриминга, основанное на OBS Studio, расширенное встроенной поддержкой донатов, алертов, тем оформления и интеграций с социальными платформами, доступное на Windows и macOS, работающее поверх Electron и требующее учётной записи Streamlabs для полного функционала.

**XSplit Broadcaster** — это коммерческое приложение для записи и трансляции видео, ориентированное на профессиональных стримеров и производителей контента, предлагающее простой интерфейс перетаскивания, встроенные переходы, поддержку зелёного экрана и удалённого управления, доступное только на Windows, распространяемое по подписке с ограниченной бесплатной версией.

**Twitch Studio** — это бесплатное приложение для начинающих стримеров, разработанное компанией Twitch, предоставляющее автоматическую настройку оборудования, встроенные советы, шаблоны сцен и алерты, доступное на Windows и macOS, работающее на собственном движке и оптимизированное исключительно для трансляции на Twitch.

**Restream** — это веб-сервис для одновременной трансляции на несколько платформ, такой как YouTube, Twitch, Facebook, LinkedIn и другие, предоставляющий единый RTMP-вход, аналитику, чат-агрегатор и базовые инструменты управления эфиром, доступный через браузер на любых устройствах, функционирующий по модели freemium с расширенными возможностями в платных тарифах.

**VLC media player** — это бесплатное мультимедийное приложение с открытым исходным кодом, способное не только воспроизводить, но и транслировать видео и аудио по сети через протоколы HTTP, RTSP, RTP и UDP, поддерживающее широкий набор форматов и кодеков, доступное на Windows, macOS, Linux, Android и iOS, построенное на фреймворке LibVLC.

**FFmpeg** — это бесплатная консольная утилита с открытым исходным кодом для обработки, преобразования и потоковой передачи аудио и видео, поддерживающая запись, транскодирование, наложение водяных знаков, изменение битрейта и отправку потоков через RTMP, HLS и другие протоколы, доступная на Windows, macOS, Linux, Android и iOS, основанная на библиотеках libavcodec, libavformat и других компонентах проекта FFmpeg.

**Wirecast** — это коммерческое приложение для профессионального живого вещания, позволяющее работать с несколькими камерами, графикой, титрами, переходами и виртуальными студиями, поддерживающее вывод на RTMP-серверы и CDN, доступное на Windows и macOS, распространяемое по подписке или perpetual-лицензии.

**vMix** — это коммерческое программное обеспечение для видеомикширования и стриминга, предлагающее функции многокамерного переключения, записи, хромакея, реплеев, NDI-поддержки и виртуальной студии, доступное только на Windows, работающее на DirectX и требующее мощного оборудования для работы с 4K-потоками.

**Zoom** — это коммерческое приложение для видеоконференций, которое также используется для стриминга встреч и вебинаров на YouTube или Facebook через функцию Custom Live Streaming, поддерживающее до 1000 участников в зависимости от тарифа, доступное на Windows, macOS, Linux, Android и iOS, работающее через проприетарный протокол и облачную инфраструктуру Zoom.

**YouTube Live Streaming** — это встроенный веб-инструмент платформы YouTube, позволяющий транслировать видео напрямую из браузера или через внешний RTMP-источник, поддерживающий чат, модерацию, автоматические субтитры и архивацию эфиров, доступный через любой современный браузер на всех платформах, требующий верифицированного канала и соответствия требованиям к оборудованию.

**Twitch** — это веб-платформа и мобильное приложение для просмотра и проведения стримов, включающее встроенный энкодер на базе WebRTC для трансляции с камеры устройства, доступное через браузер, а также на Android и iOS, предоставляющее чат, подписки, донаты и партнерскую программу, работающее на проприетарной инфраструктуре Amazon.

**Elgato Stream Deck** — это аппаратно-программный комплекс, состоящий из физического устройства с программируемыми кнопками и сопутствующего ПО, предназначенного для управления сценами, источниками, микшером, чатом и другими действиями во время стрима, совместимый с OBS Studio, Streamlabs, XSplit и другими приложениями, доступный на Windows и macOS, работающий через USB и требующий установки фирменного клиента.

**NVIDIA Broadcast** — это бесплатное приложение от NVIDIA, использующее ИИ-ускорение на видеокартах серии RTX для улучшения качества микрофона, веб-камеры и фона (шумоподавление, автофрейминг, замена фона), интегрируемое как виртуальное устройство в OBS, Zoom, Teams и другие программы, доступное только на Windows, требующее GPU с Tensor Core.

**Discord** — это бесплатное приложение для голосового и текстового общения, включающее функцию Go Live для трансляции экрана или игры друзьям без записи, поддерживающее до 50 зрителей в голосовом канале, доступное на Windows, macOS, Linux, Android и iOS, работающее через WebRTC и проприетарные серверы Discord.

**Lightstream** — это облачный сервис для стриминга, позволяющий транслировать напрямую из браузера без локального ПО, используя ресурсы серверов Lightstream для кодирования, с поддержкой наложений, алертов и нескольких платформ, доступный через веб-интерфейс на любых устройствах, функционирующий по модели freemium.

**Ecamm Live** — это коммерческое приложение для стриминга и записи, разработанное специально для macOS, предлагающее многокамерный режим, гостевые звонки через Skype и Zoom, встроенные титры, переходы и экспорт в высоком качестве, работающее на AVFoundation и доступное только на macOS, распространяемое по подписке или perpetual-лицензии.

**Loola TV** — это мобильное приложение для стриминга с телефона, позволяющее транслировать на YouTube, Twitch и Facebook, добавлять наложения, музыку и гостей, доступное на Android и iOS, работающее через RTMP и требующее подключения к Wi-Fi или мобильному интернету.

**CameraFi Live** — это мобильное приложение для Android и iOS, предназначенное для трансляции с внешних USB-камер и микрофонов, поддерживающее RTMP, HLS, YouTube, Twitch и другие платформы, предоставляющее ручные настройки экспозиции, фокуса и битрейта, работающее на MediaCodec и AVCapture.

**Teradek VidiU Go** — это портативное аппаратное устройство с сопутствующим ПО для надёжной трансляции с камеры через Wi-Fi или Ethernet на RTMP-серверы, используемое в новостных и спортивных трансляциях, управляемое через мобильное приложение или веб-интерфейс, совместимое с iOS и Android, работающее на собственной прошивке.

**ManyCam** — это условно-бесплатное приложение для виртуальных камер и стриминга, позволяющее накладывать маски, фильтры, изображения и переключаться между источниками, интегрируемое с Zoom, Skype, OBS и другими программами, доступное на Windows и macOS, работающее через DirectShow и AVFoundation.

**Be.Live** — это веб-платформа для проведения интерактивных стримов с гостями, включающая инструменты для приглашения участников, показа слайдов, алертов и записи эфира, доступная через браузер на всех платформах, функционирующая по модели freemium с ограничениями в бесплатной версии.

**Switcher Studio** — это мобильное приложение для многокамерного стриминга, позволяющее использовать несколько iPhone или iPad как источники видео, переключаться между ними в реальном времени и транслировать на Facebook, YouTube и другие платформы, доступное только на iOS, работающее через Wi-Fi Direct и NDI|HX.

**Castr** — это облачный RTMP-сервис для одновременной трансляции на до 30 платформ, включая YouTube, Twitch, TikTok и LinkedIn, предоставляющий статистику, архивацию и API, доступный через веб-интерфейс и совместимый с любым RTMP-энкодером, функционирующий по подписке.

**Melon** — это облачное приложение для записи и стриминга, запускающееся в браузере и использующее удалённые серверы для обработки видео, позволяющее работать без нагрузки на локальное оборудование, доступное на всех платформах через Chrome или Edge, работающее на WebRTC и требующее аккаунта Melon.

**Prism Live Studio** — это мобильное приложение для Android, предназначенное для одновременной трансляции на несколько платформ, включая YouTube, Twitch, AfreecaTV и другие, поддерживающее добавление изображений, текста, фильтров и гостей, работающее через RTMP и требующее стабильного интернет-соединения.

**Open Broadcaster Software Classic** — это устаревшая версия OBS с закрытым исходным кодом, предшественник OBS Studio, больше не поддерживаемая разработчиками, доступная только на Windows, использовавшая DirectX и DirectShow для захвата и вывода.

**Raspberry Pi + Picamera + FFmpeg** — это конфигурация на базе одноплатного компьютера Raspberry Pi с камерой Picamera и утилитой FFmpeg, используемая для создания бюджетного стримингового устройства, транслирующего видео через RTMP или HLS, работающая под управлением Raspberry Pi OS (Linux).

**WebcamStudio** — это бесплатное приложение с открытым исходным кодом для Linux, позволяющее создавать виртуальные веб-камеры с наложениями, текстом, изображениями и эффектами, используемое для стриминга через другие программы, работающее на GStreamer и Java.

**Livestream Studio** — это коммерческое программное обеспечение от Vimeo для профессионального многокамерного вещания, включающее функции микширования, графики, хромакея и записи, доступное на Windows и macOS, требующее подписки на Vimeo Premium.

**StreamYard** — это веб-платформа для проведения интервью и панельных стримов с гостями, подключающимися через браузер, предоставляющая разделение экрана, брендированный фон, алерты и запись, доступная на всех устройствах через браузер, функционирующая по модели freemium.

**Mux** — это облачная платформа для разработчиков, предоставляющая API для потоковой передачи, записи, транскодирования и доставки видео, используемая для создания собственных стриминговых решений, доступная через REST API и SDK, работающая на глобальной CDN и требующая технической интеграции.

**Wowza Streaming Engine** — это коммерческий серверный продукт для организации собственного стримингового сервера, поддерживающий RTMP, HLS, WebRTC, MPEG-DASH и другие протоколы, доступный на Windows, macOS и Linux, распространяемый по лицензии и требующий развертывания на выделенном сервере или в облаке.

**Red5 Pro** — это коммерческая платформа для низколатентного стриминга в реальном времени на основе WebRTC и HLS, ориентированная на интерактивные приложения, онлайн-казино и аукционы, доступная как облачный сервис или on-premise решение, требующая интеграции через SDK.

**Janus Gateway** — это бесплатный сервер с открытым исходным кодом для WebRTC-стриминга, поддерживающий публикацию, просмотр, запись и ретрансляцию потоков, доступный на Linux и macOS, написанный на C и использующий GStreamer для медиаобработки.

**Ant Media Server** — это серверное ПО с открытым исходным кодом для WebRTC и HLS-стриминга, обеспечивающее сверхнизкую задержку и масштабируемость, доступное на Linux, распространяемое в Community Edition (бесплатно) и Enterprise Edition (коммерчески).

**SRS (Simple Realtime Server)** — это бесплатный сервер с открытым исходным кодом для RTMP, WebRTC, HLS и SRT, предназначенный для высокопроизводительного стриминга, доступный на Linux, написанный на C++ и оптимизированный для работы в облаке.

**Haivision SRT Gateway** — это коммерческое решение для безопасной передачи видео по ненадёжным сетям с использованием протокола SRT, применяемое в вещательных и корпоративных средах, доступное как аппаратное устройство или виртуальная машина, работающее на Linux.

**Telestream Wirecast Gear** — это аппаратное устройство на базе Windows с предустановленным Wirecast, предназначенное для автономного стриминга без ПК, поддерживающее HDMI-входы, кодирование и отправку на RTMP-серверы, управляемое через веб-интерфейс.

**Epiphan Pearl** — это аппаратный энкодер для профессионального стриминга и записи, поддерживающий HDMI, SDI, NDI, RTMP, HLS и SRT, управляемый через веб-интерфейс, работающий на собственной ОС на базе Linux.

**Blackmagic ATEM Mini** — это аппаратный видеомикшер с возможностью стриминга через USB-C как виртуальная камера или через Ethernet на RTMP-серверы, используемый в студийных и полевых условиях, совместимый с OBS, vMix и другими ПО, управляемый через физические кнопки и веб-панель.

**Magewell USB Capture** — это серия USB-устройств для захвата HDMI и SDI сигнала, используемых в связке с OBS, vMix и другими стриминговыми приложениями, совместимых с Windows, macOS и Linux, работающих через драйверы UVC.

**AverMedia Live Gamer** — это серия PCIe и USB-карт захвата видео для стриминга с консолей и камер, совместимых с OBS, Streamlabs и XSplit, доступных на Windows и macOS, работающих через проприетарные драйверы и обеспечивающих аппаратное кодирование.

**Logitech StreamCam** — это USB-камера с двумя объективами, автоматической стабилизацией и поддержкой вертикальной ориентации, предназначенная для стриминга в социальных сетях, совместимая с OBS, Streamlabs и другими ПО, работающая через UVC на Windows и macOS.

**Rode RODECaster Video** — это аппаратно-программное решение для стриминга с интеграцией аудиоинтерфейса RODECaster Pro, позволяющее управлять камерами, источниками и аудио из одного интерфейса, доступное на Windows и macOS, работающее через USB и NDI.

**NDI Tools** — это бесплатный набор утилит с открытым исходным кодом от NewTek для работы с протоколом NDI, включающий NDI Scan, NDI Studio Monitor, NDI Virtual Input и другие компоненты, используемые для передачи видео по сети без кабелей, доступный на Windows, macOS и Linux.

**VMix Call** — это веб-сервис от разработчиков vMix, позволяющий подключать гостей в эфир через браузер с качеством до 1080p, интегрируемый с основным ПО vMix, доступный на всех платформах через Chrome, работающий на WebRTC.

**Twitch Creator Camp** — это образовательный веб-ресурс от Twitch, содержащий руководства, шаблоны и инструменты для начинающих стримеров, включая рекомендации по оборудованию, настройке OBS и взаимодействию с аудиторией, доступный через браузер на всех платформах, не являющийся программным обеспечением, но входящий в экосистему стриминга.
