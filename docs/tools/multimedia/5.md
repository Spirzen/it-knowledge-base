**Стриминг** — передача видео и звука в реальном времени: игры, вебинары, корпоративные эфиры, камеры наблюдения. На стороне автора — энкодер (OBS, vMix); на стороне зрителя — CDN с **адаптивным битрейтом** (HLS/DASH).

<ObsStreamStudioPlay />

---

## Как зритель получает поток (ABR)

Плеер на YouTube или в корпоративном портале скачивает **манифест** с несколькими профилями качества и переключает чанки по скорости канала.

## Программы для ведущего

| Инструмент | Платформы | Модель | Сильная сторона |
|------------|-----------|--------|-----------------|
| **OBS Studio** | Кроссплатформа | Open source | Сцены, плагины, RTMP, запись |
| **Streamlabs Desktop** | Win, macOS | Freemium | Алерты, донаты, темы (на базе OBS) |
| **Twitch Studio** | Win, macOS | Free | Автонастройка под Twitch |
| **XSplit Broadcaster** | Windows | Подписка | Простой UI, хромакей |
| **Wirecast** | Win, macOS | Коммерция | Профи-вещание, титры |
| **vMix** | Windows | Коммерция | Микшер, NDI, 4K |
| **Ecamm Live** | macOS | Коммерция | Гости, интеграция Zoom |
| **ManyCam** | Win, macOS | Freemium | Виртуальная камера, маски |
| **Restream** | Браузер | Freemium | Один RTMP → много платформ |
| **StreamYard / Be.Live** | Браузер | Freemium | Интервью, гости по ссылке |

## Серверная доставка

| Продукт | Протоколы | Примечание |
|---------|-----------|------------|
| **Wowza Streaming Engine** | RTMP, HLS, WebRTC | On-prem / облако |
| **Ant Media Server** | WebRTC, HLS | Community + Enterprise |
| **SRS** | RTMP, WebRTC, HLS, SRT | Open source, C++ |
| **Janus Gateway** | WebRTC | Запись, ретрансляция |
| **Red5 Pro** | WebRTC, низкая задержка | Интерактив, аукционы |
| **Mux** | API + CDN | SaaS для продуктов с видео |

# Пример публикации в RTMP (FFmpeg → ingest сервера)
