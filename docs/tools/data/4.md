Облачное хранилище — это не только "папка в браузере": клиент синхронизирует файлы, API позволяет автоматизировать выгрузку бэкапов, а **self-hosted** варианты (Nextcloud) возвращают контроль над данными на свой сервер.

## Публичные SaaS

| Сервис | Бесплатно | Сильная сторона |
| --- | --- | --- |
| **Google Drive** | 15 ГБ* | Docs/Sheets, Workspace |
| **OneDrive** | 5 ГБ | Интеграция с Windows и M365 |
| **Dropbox** | 2 ГБ | Простота, Smart Sync |
| **Mega** | 20 ГБ | E2E-шифрование по умолчанию |
| **Box** | 10 ГБ | Enterprise, compliance |
| **pCloud** | 10 ГБ | Пожизненные тарифы, Crypto |
| **Yandex Disk** | 10 ГБ | Экосистема Яндекса |
| **Tresorit** | 3 ГБ (trial) | Zero-knowledge, GDPR |

\* Общий квотный пул с Gmail/Google Photos у Google.

### Установка клиентов

```bash
# rclone — один CLI для многих облаков
curl https://rclone.org/install.sh | sudo bash
rclone config

# Linux: неофициальный клиент Яндекс.Диска
sudo apt install yandex-disk
```

Ссылки: [Google Drive](https://www.google.com/drive/download/) · [OneDrive](https://www.microsoft.com/ru-ru/microsoft-365/onedrive/download) · [Dropbox](https://www.dropbox.com/install) · [Mega Desktop](https://mega.io/desktop)

## Self-hosted

| Платформа | Отличие |
| --- | --- |
| **Nextcloud** | Форк-эволюция экосистемы; Talk, OnlyOffice, LDAP |
| **ownCloud** | Корпоративная поддержка, интеграции |

```bash
# Nextcloud в Docker (демо, не для продакшена без TLS и томов)
docker run -d --name nextcloud -p 8080:80 nextcloud:latest
```

Документация: [docs.nextcloud.com](https://docs.nextcloud.com) · [doc.owncloud.com](https://doc.owncloud.com)

## WebDAV и монтирование

Многие сервисы отдают **WebDAV** — можно подключить как сетевой диск:

- **Windows**: "Подключить сетевой диск" → `https://cloud.example.com/remote.php/dav/files/user/`
- **macOS**: Finder → "Подключиться к серверу"
- **Linux**: `davfs2` или `rclone mount`

## Безопасность

| Уровень | Что это значит |
| --- | --- |
| **Шифрование в транзите** | HTTPS — у всех крупных провайдеров |
| **Шифрование на сервере** | Доступ у провайдера к файлам при subpoena |
| **E2E / zero-knowledge** | Ключ у клиента (Mega, Tresorit, pCloud Crypto) |
