# Облачные хранилища

<div class="article-tags">
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

Облачные хранилища — сервисы для хранения, синхронизации и совместного доступа к файлам через интернет. Они предоставляют клиентские приложения для ПК и мобильных устройств, веб-интерфейсы, а также программные интерфейсы (API/CLI) для интеграции в автоматизированные процессы. Некоторые решения допускают развёртывание собственного экземпляра (self-hosted). Ниже перечислены наиболее значимые сервисы и платформы.

---

### 1. Google Drive

- **Бесплатный объём**: 15 ГБ (общий с Gmail и Google Photos)
- **Особенности**: Интеграция с Google Workspace (Docs, Sheets), совместное редактирование, версионирование, веб-интерфейс.
- **Клиенты**:
  - **Backup and Sync** (устаревший)
  - **Drive for desktop** (текущий клиент, Windows/macOS)
- **Установка**:
  - Windows/macOS: [официальный установщик](https://www.google.com/drive/download/)
  - CLI (сторонние): `rclone`, `gdrive`
- **Сайт**: [https://drive.google.com](https://drive.google.com)

---

### 2. Microsoft OneDrive

- **Бесплатный объём**: 5 ГБ
- **Особенности**: Глубокая интеграция с Windows и Microsoft 365, Files On-Demand, совместная работа с Office Online.
- **Клиенты**:
  - Встроен в Windows 10/11
  - Отдельный клиент для macOS
- **Установка**:
  - Windows: предустановлен; обновление через Microsoft Store
  - macOS: [скачать с официального сайта](https://www.microsoft.com/Рu/microsoft-365/onedrive/download)
  - CLI (сторонние): `rclone`, `onedrive` (open-source клиент)
    ```bash
    # Пример для Ubuntu (open-source CLI-клиент)
    sudo apt install onedrive
    ```
- **Сайт**: [https://onedrive.live.com](https://onedrive.live.com)

---

### 3. Dropbox

- **Бесплатный объём**: 2 ГБ (с возможностью увеличения через рефералы)
- **Особенности**: Простота интерфейса, Paper (совместные заметки), Smart Sync, интеграции с Zapier, Slack и др.
- **Клиенты**: Windows, macOS, Linux, мобильные ОС
- **Установка**:
  - Windows/macOS: [официальный установщик](https://www.dropbox.com/install)
  - Linux (Debian/Ubuntu):  
    ```bash
    cd ~ && wget -O - "https://www.dropbox.com/download?plat=lnx.x86_64" | tar xzf -
    ~/.dropbox-dist/dropboxd
    ```
  - CLI: официальный `dropbox` CLI (входит в пакет), а также `rclone`
- **Сайт**: [https://www.dropbox.com](https://www.dropbox.com)

---

### 4. Mega

- **Бесплатный объём**: 20 ГБ
- **Особенности**: **End-to-end шифрование**, встроенный чат, совместные папки, проигрывание видео в браузере.
- **Клиенты**: Windows, macOS, Linux, мобильные ОС
- **Установка**:
  - Универсальный установщик: [https://mega.io/desktop](https://mega.io/desktop)
  - Linux (AppImage/DEB/RPM): доступны на сайте
  - CLI: `megatools` (сторонний)
    ```bash
    sudo apt install megatools
    ```
- **Сайт**: [https://mega.io](https://mega.io)

---

### 5. Nextcloud (self-hosted)

- **Бесплатный объём**: Ограничен только дисковым пространством сервера
- **Особенности**: Полный контроль над данными, расширения (календарь, почта, видеоконференции, OnlyOffice), WebDAV, end-to-end шифрование, интеграция с LDAP/SAML.
- **Клиенты**: Windows, macOS, Linux, Android, iOS
- **Установка**:
  - **Сервер**:
    - Docker:  
      ```bash
      docker run -d --name nextcloud -p 8080:80 nextcloud:latest
      ```
    - Скрипт установки: [Nextcloud All-in-One](https://github.com/nextcloud/all-in-one)
    - Вручную: [официальная документация](https://docs.nextcloud.com)
  - **Клиент ПК**:  
    - Windows/macOS/Linux: [официальный клиент](https://nextcloud.com/install/#install-clients)
  - **CLI**: `rclone` с поддержкой WebDAV
- **Сайт**: [https://nextcloud.com](https://nextcloud.com)

---

### 6. ownCloud (self-hosted)

- **Бесплатный объём**: Ограничен дисковым пространством
- **Особенности**: Альтернатива Nextcloud (Nextcloud — форк ownCloud), корпоративная поддержка, интеграция с Microsoft и OnlyOffice.
- **Клиенты**: Windows, macOS, Linux, мобильные ОС
- **Установка**:
  - **Сервер**:
    - Docker: `docker run -d --name owncloud -p 8080:8080 owncloud/server`
    - Установка из пакетов: [официальный гид](https://doc.owncloud.com)
  - **Клиент**: [https://owncloud.com/products/desktop-clients/](https://owncloud.com/products/desktop-clients/)
- **Сайт**: [https://owncloud.com](https://owncloud.com)

---

### 7. Box

- **Бесплатный объём**: 10 ГБ
- **Особенности**: Ориентирован на enterprise-сектор, строгая безопасность, соответствие GDPR/HIPAA, интеграция с Salesforce, Slack.
- **Клиенты**: Windows, macOS, Linux (через Box Drive или CLI)
- **Установка**:
  - Windows/macOS: [Box Drive](https://www.box.com/resources/downloads/drive)
  - CLI: `boxcli` (официальный, требует регистрации приложения)
    ```bash
    npm install -g @box/cli
    ```
- **Сайт**: [https://www.box.com](https://www.box.com)

---

### 8. Sync.com

- **Бесплатный объём**: 5 ГБ
- **Особенности**: Zero-knowledge шифрование, совместные папки, водяные знаки на документах, аудит доступа.
- **Клиенты**: Windows, macOS, мобильные ОС
- **Установка**:
  - Установщик: [https://www.sync.com/download/](https://www.sync.com/download/)
- **Сайт**: [https://www.sync.com](https://www.sync.com)

---

### 9. pCloud

- **Бесплатный объём**: 10 ГБ
- **Особенности**: Клиентское шифрование (pCloud Crypto — платно), пожизненные тарифы, медиаплеер, интеграция с Zoom.
- **Клиенты**: Windows, macOS, Linux, мобильные ОС
- **Установка**:
  - Linux: [официальный .tar.gz или .AppImage](https://www.pcloud.com/how-to-install-pcloud-drive-linux.html)
  - Windows/macOS: установщик с [сайта](https://www.pcloud.com/download.html)
- **Сайт**: [https://www.pcloud.com](https://www.pcloud.com)

---

### 10. Yandex Disk

- **Бесплатный объём**: 10 ГБ
- **Особенности**: Интеграция с сервисами Яндекса, автоматическая загрузка фото с мобильных устройств, веб-интерфейс с предпросмотром.
- **Клиенты**: Windows, macOS, Linux (неофициальный), мобильные ОС
- **Установка**:
  - Windows/macOS: [официальный клиент](https://disk.yandex.ru)
  - Linux (неофициальный):  
    ```bash
    # Через GitHub (например, yandex-disk-indicator)
    sudo add-apt-repository ppa:atareao/atareao
    sudo apt update && sudo apt install yandex-disk-indicator
    ```
- **Сайт**: [https://disk.yandex.ru](https://disk.yandex.ru)

---

### 11. Tresorit

- **Бесплатный объём**: 3 ГБ (пробный период с 14 днями и 3 ТБ)
- **Особенности**: End-to-end шифрование, соответствие GDPR, аудит активности, «безопасные ссылки».
- **Клиенты**: Windows, macOS, Linux (ограниченная поддержка), мобильные ОС
- **Установка**:
  - Windows/macOS: [официальный установщик](https://tresorit.com/download)
- **Сайт**: [https://tresorit.com](https://tresorit.com)

---

### 12. Rclone (универсальный CLI-клиент)

- **Тип**: Консольный инструмент для работы с облачными хранилищами
- **Поддержка**: Более 70 провайдеров (включая все вышеупомянутые через WebDAV/S3/API)
- **Особенности**: Снхронизация, монтирование (через FUSE), шифрование, кэширование.
- **Установка**:
  - Linux:  
    ```bash
    sudo apt install rclone
    # или
    curl https://rclone.org/install.sh | sudo bash
    ```
  - macOS: `brew install rclone`
  - Windows: [скачать .exe](https://rclone.org/downloads/)
- **Настройка**: `rclone config`
- **Сайт**: [https://rclone.org](https://rclone.org)

---

### 13. WebDAV-совместимые хранилища

Многие системы (Nextcloud, ownCloud, Yandex Disk, Box, 4shared) поддерживают **WebDAV**, что позволяет подключать их как сетевые диски:
- **Windows**: «Подключить сетевой диск» → URL вида `https://cloud.example.com/remote.php/dav/files/user/`
- **Linux**: через `davfs2` или `rclone`
- **macOS**: Finder → «Подключиться к серверу»
