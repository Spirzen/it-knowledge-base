# Файловые менеджеры

<div class="article-tags">
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

Файловый менеджер — программное средство для навигации по файловой системе, выполнения операций копирования, перемещения, удаления, просмотра и редактирования файлов и каталогов. Современные менеджеры часто включают расширенные функции: встроенные FTP/SFTP-клиенты, архиваторы, превьющики, плагины, поддержку скриптов и сетевых протоколов. Ниже приведён перечень наиболее распространённых и функциональных решений, сгруппированных по типу интерфейса и платформе.

---

### 1. Графические файловые менеджеры

#### Windows Explorer (Проводник Windows)
- **Платформа**: Windows
- **Особенности**: Интеграция с системой, поддержка OneDrive, ZIP-архивов, быстрый просмотр, лента действий.
- **Установка**: Входит в состав ОС.
- **Сайт**: [https://support.microsoft.com](https://support.microsoft.com)

#### Total Commander
- **Платформа**: Windows (есть неофициальные сборки под Linux/macOS через Wine)
- **Особенности**: Двухпанельный интерфейс, встроенные FTP/SFTP/HTTP-клиенты, архивация (ZIP, 7z и др.), поддержка плагинов, макросы.
- **Установка**:  
  Скачать установщик с [официального сайта](https://www.ghisler.com/download.htm)
- **Сайт**: [https://www.ghisler.com](https://www.ghisler.com)

#### Double Commander
- **Платформа**: Windows, Linux, macOS
- **Особенности**: Открытый аналог Total Commander, поддержка Unicode, вкладки, встроенный редактор, архивы, FTP/SFTP.
- **Установка**:
  - Windows: установщик с [официального сайта](https://doublecmd.sourceforge.io)
  - Linux (Debian/Ubuntu):  
    ```bash
    sudo add-apt-repository ppa:alexx2000/doublecmd
    sudo apt update && sudo apt install doublecmd-qt6
    ```
  - macOS: через Homebrew Cask: `brew install --cask double-commander`
- **Сайт**: [https://doublecmd.sourceforge.io](https://doublecmd.sourceforge.io)

#### FreeCommander
- **Платформа**: Windows
- **Особенности**: Двухпанельный интерфейс, вкладки, быстрый фильтр, встроенный просмотрщик, поддержка архивов.
- **Установка**: Бесплатная версия (XE) — [скачать](https://freecommander.com/en/downloads/)
- **Сайт**: [https://freecommander.com](https://freecommander.com)

#### XYplorer
- **Платформа**: Windows
- **Особенности**: Однопанельный с древовидным представлением, табы, скриптовый язык, превьющики, тегирование файлов.
- **Установка**: Портативная или инсталлируемая версия — [официальный сайт](https://www.xyplorer.com/download.php)
- **Сайт**: [https://www.xyplorer.com](https://www.xyplorer.com)

#### Directory Opus (Opus)
- **Платформа**: Windows
- **Особенности**: Высоко настраиваемый, замена Проводнику, мощные макросы, поддержка сетевых протоколов, визуальные фильтры.
- **Установка**: Пробная версия — [скачать](https://www.gpsoft.com.au/DOWNLOADS/Download-DOPUS.aspx)
- **Сайт**: [https://www.gpsoft.com.au](https://www.gpsoft.com.au)

#### Dolphin
- **Платформа**: Linux (KDE)
- **Особенности**: Интеграция с KDE, двухпанельный режим (опционально), вкладки, встроенный терминал, превьющики.
- **Установка**:
  - Ubuntu/Debian: `sudo apt install dolphin`
  - Fedora: `sudo dnf install dolphin`
- **Сайт**: [https://apps.kde.org/dolphin](https://apps.kde.org/dolphin)

#### Nautilus (Files)
- **Платформа**: Linux (GNOME)
- **Особенности**: Стандартный менеджер GNOME, простой интерфейс, интеграция с облачными сервисами.
- **Установка**: Входит в состав GNOME; в Ubuntu: `sudo apt install nautilus`
- **Сайт**: [https://wiki.gnome.org/Apps/Files](https://wiki.gnome.org/Apps/Files)

#### Thunar
- **Платформа**: Linux (XFCE)
- **Особенности**: Лёгкий, быстрый, поддержка плагинов, вкладки.
- **Установка**: `sudo apt install thunar` (Debian/Ubuntu)
- **Сайт**: [https://docs.xfce.org/xfce/thunar/start](https://docs.xfce.org/xfce/thunar/start)

#### Finder
- **Платформа**: macOS
- **Особенности**: Интеграция с iCloud, Quick Look, теги, Smart Folders.
- **Установка**: Входит в состав macOS.
- **Сайт**: [https://support.apple.com/guide/mac-help](https://support.apple.com/guide/mac-help)

#### ForkLift
- **Платформа**: macOS
- **Особенности**: Двухпанельный интерфейс, поддержка SFTP/WebDAV/S3, синхронизация папок, архивы.
- **Установка**: [Mac App Store](https://apps.apple.com/app/forklift/id412448059) или [официальный сайт](https://binarynights.com)
- **Сайт**: [https://binarynights.com](https://binarynights.com)

#### Path Finder
- **Платформа**: macOS
- **Особенности**: Расширенный заменитель Finder, двухпанельный режим, терминал, сравнение файлов.
- **Установка**: [официальный сайт](https://cocoatech.com/pathfinder/)
- **Сайт**: [https://cocoatech.com](https://cocoatech.com)

### 2. Консольные файловые менеджеры

#### Midnight Commander (mc)
- **Платформа**: Linux, macOS, Windows (через WSL/Cygwin)
- **Особенности**: Классический двухпанельный текстовый интерфейс, встроенный редактор (mcedit), FTP/SFTP, архивы, подсветка синтаксиса.
- **Установка**:
  - Linux: `sudo apt install mc` (Debian/Ubuntu), `sudo dnf install mc` (Fedora)
  - macOS: `brew install mc`
  - Windows: через WSL или Cygwin
- **Сайт**: [https://midnight-commander.org](https://midnight-commander.org)

#### ranger
- **Платформа**: Linux, macOS
- **Особенности**: Консольный менеджер с превьющиками (изображения, PDF, видео через внешние утилиты), Vim-подобные хоткеи, расширяемость на Python.
- **Установка**:
  - Linux: `sudo apt install ranger`  
  - macOS: `brew install ranger`
  - Или через pip: `pip install ranger-fm`
- **Сайт**: [https://ranger.github.io](https://ranger.github.io)

#### nnn
- **Платформа**: Linux, macOS, BSD, Windows (через WSL)
- **Особенности**: Минималистичный, сверхбыстрый, поддержка плагинов, FZF-интеграция, мультипанельность через флаги.
- **Установка**:
  - Linux: `sudo apt install nnn`
  - macOS: `brew install nnn`
  - Исходники: [GitHub](https://github.com/jarun/nnn)
- **Сайт**: [https://github.com/jarun/nnn](https://github.com/jarun/nnn)

#### vifm
- **Платформа**: Linux, macOS, Windows (через WSL/Cygwin)
- **Особенности**: Vim-подобное управление, двухпанельный режим, поддержка сессий, интеграция с редакторами.
- **Установка**:
  - Linux: `sudo apt install vifm`
  - macOS: `brew install vifm`
- **Сайт**: [https://vifm.info](https://vifm.info)

#### lf
- **Платформа**: Linux, macOS, Windows (через WSL)
- **Особенности**: Написан на Go, конфигурируется на shell, минималистичный, поддержка кастомных команд.
- **Установка**:
  - Linux/macOS:  
    ```bash
    go install github.com/gokcehan/lf@latest
    ```
  - Или через релизы: [GitHub Releases](https://github.com/gokcehan/lf/releases)
- **Сайт**: [https://github.com/gokcehan/lf](https://github.com/gokcehan/lf)

### 3. Гибридные и специализированные менеджеры

#### QDirStat / WinDirStat / Baobab
- **Назначение**: Визуализация использования дискового пространства.
- **Платформы**:
  - **QDirStat**: Linux/Windows — [https://github.com/jeromerobert/qdirstat](https://github.com/jeromerobert/qdirstat)
  - **WinDirStat**: Windows — [https://windirstat.net](https://windirstat.net)
  - **Baobab**: Linux (GNOME) — `sudo apt install gnome-disk-usage`
- **Установка**: Через пакетные менеджеры или установщики.

#### fman
- **Платформа**: Windows, Linux, macOS
- **Особенности**: Двухпанельный, Python-плагины, Vim/Emacs-режимы, поддержка S3/SFTP.
- **Установка**: [https://fman.io/download](https://fman.io/download)
- **Сайт**: [https://fman.io](https://fman.io)

#### Krystal File Manager
- **Платформа**: Windows (на .NET)
- **Особенности**: Открытый, модульный, поддержка плагинов, FTP, архивы.
- **Установка**: [GitHub Releases](https://github.com/0x7c13/Krystal/releases)
- **Сайт**: [https://github.com/0x7c13/Krystal](https://github.com/0x7c13/Krystal)
