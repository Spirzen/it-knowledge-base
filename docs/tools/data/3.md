# Файловые менеджеры

<div class="article-tags">
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

Файловый менеджер закрывает задачи, которые в терминале делают `cd`, `cp`, `mv`, `rm` и `ls`, но с **двумя панелями**, превью, FTP/SFTP и пакетными операциями. Для администратора и разработчика это ускоритель рутины; для новичка — наглядная карта диска.

## Графические (GUI)

### Встроенные в ОС

| Менеджер | Платформа | Особенности |
| --- | --- | --- |
| **Проводник** | Windows | OneDrive, ZIP, Quick Access |
| **Finder** | macOS | iCloud, Quick Look, теги |
| **Dolphin** | Linux (KDE) | Вкладки, встроенный терминал |
| **Nautilus (Files)** | Linux (GNOME) | Простой UI, облака |
| **Thunar** | Linux (XFCE) | Лёгкий, плагины |

---

### Двухпанельные и продвинутые

| Менеджер | Платформа | Зачем |
| --- | --- | --- |
| **Total Commander** | Windows | Классика: FTP, архивы, плагины |
| **Double Commander** | Win/Linux/macOS | Open-source аналог TC |
| **FreeCommander** | Windows | Бесплатный XE с вкладками |
| **XYplorer** | Windows | Теги файлов, скрипты |
| **Directory Opus** | Windows | Замена Проводника, макросы |
| **ForkLift** | macOS | SFTP, WebDAV, S3 |
| **Path Finder** | macOS | Две панели + терминал |

```bash
# Double Commander — Ubuntu
sudo add-apt-repository ppa:alexx2000/doublecmd
sudo apt update && sudo apt install doublecmd-qt6
```

---

## Консольные (TUI)

Удобны по SSH и на серверах без GUI.

| Менеджер | Стиль | Установка |
| --- | --- | --- |
| **Midnight Commander (mc)** | Классические F-клавиши | `apt install mc` |
| **ranger** | Vim-подобный, превью | `apt install ranger` |
| **nnn** | Минимализм, плагины | `apt install nnn` |
| **vifm** | Vim-бинды | `apt install vifm` |
| **lf** | Конфиг на shell, Go | `go install github.com/gokcehan/lf@latest` |

```bash
# Быстрый старт mc
mc
# F5 — копировать, F6 — переместить, F3 — просмотр
```

## Специализированные

| Инструмент | Назначение |
| --- | --- |
| **WinDirStat / QDirStat / Baobab** | Кто съел место на диске (treemap) |

| **Krystal** | Open-source на .NET, модульный |
