## Утилиты

**7-Zip** — это бесплатный архиватор с открытым исходным кодом, предназначенный для сжатия и распаковки файлов в форматах 7z, ZIP, RAR, TAR, GZIP и других, доступный на платформах Windows и Linux через Wine, использующий собственный алгоритм сжатия LZMA и поддерживающий шифрование AES-256.  

**Advanced IP Scanner** — это бесплатная утилита для сканирования локальной сети, определяющая активные устройства, их IP-адреса, MAC-адреса и открытые порты, работающая на Windows и не требующая установки.  

**AnyDesk** — это коммерческое приложение для удалённого доступа к компьютеру, обеспечивающее низкую задержку и передачу файлов, доступное на Windows, macOS, Linux, Android и iOS, построенное на проприетарной технологии DeskRT.  

**AutoHotkey** — это бесплатный язык сценариев и среда автоматизации для Windows, позволяющая создавать макросы, переназначать клавиши и автоматизировать повторяющиеся задачи, распространяемый с открытым исходным кодом.  

**Bandizip** — это условно-бесплатный архиватор для Windows и macOS, поддерживающий чтение и запись в форматы ZIP, 7Z, RAR, TAR, ISO и другие, включающий функции предварительного просмотра и восстановления повреждённых архивов.  

**CCleaner** — это условно-бесплатная утилита для очистки системы от временных файлов, исправления ошибок реестра и управления автозагрузкой, доступная на Windows и macOS, разрабатываемая компанией Piriform (часть Avast).  

**Cheat Engine** — это бесплатная программа с открытым исходным кодом, предназначенная для анализа и модификации памяти запущенных процессов, в основном применяемая в игровых целях, работающая на Windows и частично на Linux через Wine.  

**CrystalDiskInfo** — это бесплатная утилита для мониторинга состояния жёстких дисков и SSD по SMART-атрибутам, предоставляющая информацию о температуре, износе и потенциальных сбоях, доступная на Windows и распространяемая с закрытым исходным кодом.  

**Daemon Tools Lite** — это условно-бесплатная программа для монтирования образов дисков, поддерживающая форматы ISO, MDS, MDX и другие, работающая на Windows и позволяющая эмулировать до четырёх виртуальных приводов.  

**Everything** — это бесплатная утилита для мгновенного поиска файлов и папок по имени на NTFS-томах в Windows, использующая индексирование метаданных файловой системы, распространяемая с закрытым исходным кодом.  

**FastStone Image Viewer** — это бесплатная программа для просмотра, редактирования и управления изображениями, поддерживающая форматы JPEG, PNG, BMP, TIFF, GIF и RAW, доступная на Windows и включающая базовые инструменты цветокоррекции и аннотаций.  

**FileZilla** — это бесплатный FTP-клиент с открытым исходным кодом, предназначенный для передачи файлов по протоколам FTP, FTPS и SFTP, доступный на Windows, macOS и Linux, построенный на библиотеке wxWidgets.  

**GIMP** — это бесплатный графический редактор с открытым исходным кодом, предназначенный для обработки растровых изображений, поддерживающий слои, маски, фильтры и плагины, доступный на Windows, macOS и Linux.  

**HandBrake** — это бесплатная утилита с открытым исходным кодом для конвертации видео в форматы MP4 и MKV, поддерживающая аппаратное ускорение кодирования и предустановки для различных устройств, доступная на Windows, macOS и Linux.  

**HWiNFO** — это бесплатная утилита для детального сбора информации об аппаратных компонентах компьютера, включая процессор, видеокарту, материнскую плату и датчики температуры, работающая на Windows и DOS.  

**IrfanView** — это бесплатный просмотрщик изображений для Windows, поддерживающий сотни графических форматов, включая основные функции пакетной обработки и плагины для расширения возможностей.  

**KeePass** — это бесплатный менеджер паролей с открытым исходным кодом, хранящий учётные данные в локальной зашифрованной базе данных, доступный на Windows, с официальными и неофициальными портами для других платформ.  

**LibreOffice** — это бесплатный офисный пакет с открытым исходным кодом, включающий текстовый процессор, таблицы, презентации и базы данных, совместимый с форматами Microsoft Office, доступный на Windows, macOS и Linux.  

**Malwarebytes** — это условно-бесплатный антивирусный сканер, ориентированный на обнаружение и удаление рекламного ПО, троянов и других вредоносных программ, доступный на Windows, macOS, Android и iOS.  

**Notepad++** — это бесплатный текстовый редактор с открытым исходным кодом для Windows, предназначенный для программистов, поддерживающий подсветку синтаксиса множества языков, макросы и плагины, построенный на библиотеке Scintilla.  

**OBS Studio** — это бесплатная программа с открытым исходным кодом для записи экрана и трансляции в реальном времени, поддерживающая захват окон, веб-камер и аудиоустройств, доступная на Windows, macOS и Linux.  

**Paint.NET** — это бесплатный графический редактор для Windows, сочетающий простоту интерфейса с поддержкой слоёв и эффектов, распространяемый с закрытым исходным кодом и расширяемый через плагины.  

**PuTTY** — это бесплатный терминальный клиент с открытым исходным кодом, поддерживающий протоколы SSH, Telnet, Rlogin и Serial, предназначенный для удалённого администрирования серверов, доступный на Windows и Linux.  

**qBittorrent** — это бесплатный торрент-клиент с открытым исходным кодом, реализующий функции поиска, планировщика скорости и веб-интерфейса, доступный на Windows, macOS и Linux, написанный на C++ с использованием Qt.  

**Rufus** — это бесплатная утилита для создания загрузочных USB-накопителей из ISO-образов, поддерживающая UEFI и Legacy BIOS, работающая на Windows и распространяемая в виде портативного исполняемого файла.  

**ShareX** — это бесплатная утилита с открытым исходным кодом для захвата экрана, записи видео и автоматической загрузки результатов на облачные сервисы, доступная на Windows и включающая мощную систему настраиваемых действий.  

**Sumatra PDF** — это бесплатный просмотрщик PDF-документов с открытым исходным кодом, отличающийся минимальным потреблением ресурсов и поддержкой форматов PDF, ePub, MOBI, CHM, DjVu и XPS, доступный только на Windows.  

**TeamViewer** — это коммерческое приложение для удалённого управления компьютерами и проведения онлайн-встреч, работающее на Windows, macOS, Linux, Android и iOS, использующее проприетарный протокол передачи данных.  

**Telegram Desktop** — это бесплатный мессенджер с открытым исходным кодом, обеспечивающий сквозное шифрование в секретных чатах и синхронизацию сообщений между устройствами, доступный на Windows, macOS и Linux, построенный на фреймворке Qt.  

**Total Commander** — это условно-бесплатный файловый менеджер для Windows, выполненный в двухпанельном интерфейсе, поддерживающий архивы, FTP, плагины и пользовательские команды, распространяемый с закрытым исходным кодом.  

**Transmission** — это бесплатный торрент-клиент с открытым исходным кодом, ориентированный на простоту и низкое потребление ресурсов, доступный на macOS, Linux и других Unix-подобных системах, включая веб-интерфейс.  

**Universal USB Installer** — это бесплатная утилита для записи дистрибутивов Linux и других ОС на USB-накопители, работающая на Windows и поддерживающая автоматическое скачивание ISO-образов.  
**VLC media player** — это бесплатный медиаплеер с открытым исходным кодом, способный воспроизводить практически любые аудио- и видеоформаты без необходимости установки кодеков, доступный на Windows, macOS, Linux, Android и iOS.  

**WinDirStat** — это бесплатная утилита для визуализации использования дискового пространства на Windows, отображающая файлы в виде древовидной карты и позволяющая удалять ненужные данные напрямую из интерфейса.  

**Windows Terminal** — это бесплатный терминальный клиент от Microsoft с открытым исходным кодом, объединяющий PowerShell, Command Prompt, WSL и SSH-сессии в одной вкладчатой среде, доступный на Windows 10 и новее.  

**Wireshark** — это бесплатный анализатор сетевого трафика с открытым исходным кодом, позволяющий перехватывать и детально исследовать пакеты в реальном времени, доступный на Windows, macOS и Linux.  

**WizTree** — это бесплатная утилита для быстрого анализа дискового пространства на NTFS-томах в Windows, использующая прямое чтение мастер-файла MFT для мгновенного отображения самых крупных файлов и папок.  

**XnView MP** — это условно-бесплатный просмотрщик и конвертер изображений, поддерживающий более 500 графических форматов, включая пакетную обработку и базовое редактирование, доступный на Windows, macOS и Linux.  

**Zoom** — это коммерческое приложение для видеоконференций, обеспечивающее хостинг встреч, вебинаров и чатов, доступное на Windows, macOS, Linux, Android и iOS, работающее через облачную инфраструктуру Zoom Video Communications.  

**Ableton Live** — это коммерческая цифровая аудиостанция для создания, записи и исполнения музыки, ориентированная на электронную музыку и живые выступления, доступная на Windows и macOS.  

**Audacity** — это бесплатный аудиоредактор с открытым исходным кодом, предназначенный для записи, редактирования и обработки звука, поддерживающий плагины VST и LADSPA, доступный на Windows, macOS и Linux.  

**Blender** — это бесплатная программа с открытым исходным кодом для 3D-моделирования, анимации, симуляции и рендеринга, используемая в кино, играх и визуальных эффектах, доступная на Windows, macOS и Linux.  

**Calibre** — это бесплатный менеджер электронных книг с открытым исходным кодом, позволяющий организовывать библиотеку, конвертировать форматы и синхронизировать с устройствами чтения, доступный на Windows, macOS и Linux.  

**Docker Desktop** — это условно-бесплатная среда для запуска контейнеров Docker на рабочих станциях, включающая интеграцию с Kubernetes и WSL2, доступная на Windows и macOS, требующая регистрации для коммерческого использования. 
 
**EagleFiler** — это коммерческий архиватор документов и веб-страниц для macOS, позволяющий импортировать, индексировать и искать содержимое файлов, включая PDF, HTML и изображения.  

**ExifTool** — это бесплатная консольная утилита с открытым исходным кодом для чтения, записи и редактирования метаданных в изображениях, аудио и документах, поддерживающая сотни форматов, доступная на Windows, macOS и Linux.  

**FFmpeg** — это бесплатный набор библиотек и утилит с открытым исходным кодом для обработки аудио- и видеофайлов, включая конвертацию, стриминг и фильтрацию, доступный на всех основных платформах.  

**Greenshot** — это бесплатная утилита с открытым исходным кодом для создания скриншотов и их последующего редактирования или экспорта, доступная на Windows и интегрирующаяся с буфером обмена и облачными сервисами.  

**Inkscape** — это бесплатный векторный графический редактор с открытым исходным кодом, поддерживающий стандарт SVG, предназначенный для создания иллюстраций, логотипов и печатной продукции, доступный на Windows, macOS и Linux.  

**Joplin** — это бесплатное приложение с открытым исходным кодом для ведения заметок и управления задачами, поддерживающее синхронизацию через Dropbox, OneDrive и WebDAV, доступное на Windows, macOS, Linux, Android и iOS.
