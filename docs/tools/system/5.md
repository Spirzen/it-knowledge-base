# Утилиты

<div class="article-tags">
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>

Раздел собирает **вспомогательное ПО** для повседневной работы на ПК: сжатие файлов, просмотр медиа, очистка диска, удалённый доступ, скриншоты и офисные задачи. Полный рынок утилит бесконечен — ниже каталог с акцентом на **проверенные** имена; интерактивная панель помогает быстро сориентироваться.

## Архивы и файлы

| Утилита | Назначение |
|---------|------------|
| **7-Zip** | 7z/LZMA2, ZIP, RAR (распаковка), AES-256 |
| **Bandizip** | Архивы, предпросмотр, восстановление |
| **Everything** | Мгновенный поиск по NTFS (Windows) |
| **Total Commander** | Двухпанельный файловый менеджер |

---

## Система и диагностика

| Утилита | Назначение |
|---------|------------|
| **HWiNFO**, **CrystalDiskInfo** | Железо, SMART дисков |
| **WinDirStat**, **WizTree** | Что занимает место на диске |
| **Process Explorer** (Sysinternals) | Процессы, DLL, автозагрузка |
| **CCleaner** | Очистка (осторожно с "чисткой реестра") |
| **AutoHotkey** | Макросы Windows |
| **ShareX**, **Greenshot** | Скриншоты и запись |
| **Rufus**, **Universal USB Installer** | Загрузочные флешки из ISO |
| **KeePass** | Менеджер паролей (локальная БД) |
| **Ditto** | Расширенный буфер обмена |
