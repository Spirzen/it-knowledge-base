# Видеосвязь

<div class="article-tags">
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

Инструменты **видеосвязи** строятся на **WebRTC** (браузерные звонки), **SIP** (VoIP-телефония) или гибридах. Для внутренних встреч выбирают между **облаком** (быстрый старт, подписка) и **self-host** (контроль данных, администрирование сервера). Отдельно идут **запись и стриминг** — OBS, FFmpeg, Restream.

## Open-source и self-hosted

| Инструмент | Сценарий | Ссылка / установка |
|------------|----------|-------------------|
| **Jitsi Meet** | Встречи в браузере, Docker, LDAP | [jitsi.org](https://jitsi.org/jitsi-meet/) |
| **BigBlueButton** | Вебинары, доска, breakout rooms | [bigbluebutton.org](https://bigbluebutton.org) (Ubuntu) |
| **Matrix + Jitsi** | Чат + видео через мост | [matrix.org](https://matrix.org) |
| **Galène** | Лёгкий сервер на Go для малых команд | [galene](https://git.sr.ht/~whynothugo/galene) |
| **LiveKit** | SFU для кастомных приложений | [livekit.io](https://livekit.io) |

## Запись и трансляция

| Инструмент | Назначение |
|------------|------------|
| **OBS Studio** | Сцены, RTMP на YouTube/Twitch, виртуальная камера |
| **FFmpeg** | Консоль: кодирование, RTMP, нарезка |
| **vMix / Wirecast** | Профессиональный live-продакшен (Windows) |
| **Restream** | Мультистрим в несколько платформ |

```bash
sudo apt install obs-studio ffmpeg   # Linux
```

**Виртуальная камера OBS** подключается в Zoom/Teams как обычная webcam. На Windows для маршрутизации звука часто используют **Voicemeeter**; на Linux — **PulseAudio** / **PipeWire**.

## Протоколы

| Протокол | Роль |
|----------|------|
| **WebRTC** | P2P аудио/видео в браузере |
| **SIP** | Инициация VoIP-звонков |
| **RTMP** | Поток от OBS к серверу (уступает HLS/WebRTC) |
| **H.264 / VP9 / AV1** | Видеокодеки |
