# Браузеры

Веб-браузер — программное приложение для просмотра и взаимодействия с веб-контентом. Помимо базового отображения HTML-страниц, современные браузеры включают инструменты разработчика, поддержку расширений, режимы приватности и средства автоматизации. Ниже приведён перечень актуальных веб-браузеров с описанием их назначения, особенностей и способов установки.

---

### 1. Google Chrome
- **Назначение**: самый распространённый веб-браузер с акцентом на скорость и совместимость.
- **Движок**: Blink (на базе Chromium).
- **Особенности**: синхронизация с аккаунтом Google, расширения из Chrome Web Store, встроенные инструменты разработчика, поддержка PWA.
- **Установка**:
  - Windows/macOS: [https://www.google.com/chrome/](https://www.google.com/chrome/)
  - Linux (Debian/Ubuntu):
    ```bash
    wget -q -O - https://dl.google.com/linux/linux_signing_key.pub | sudo apt-key add -
    echo "deb [arch=amd64] http://dl.google.com/linux/chrome/deb/ stable main" | sudo tee /etc/apt/sources.list.d/google-chrome.list
    sudo apt update && sudo apt install google-chrome-stable
    ```
  - Fedora:
    ```bash
    sudo dnf install fedora-workstation-repositories
    sudo dnf config-manager --set-enabled google-chrome
    sudo dnf install google-chrome-stable
    ```

---

### 2. Mozilla Firefox
- **Назначение**: независимый браузер с упором на приватность и открытость.
- **Движок**: Gecko.
- **Особенности**: строгая политика приватности, поддержка контейнеров (Multi-Account Containers), открытый исходный код, расширения через addons.mozilla.org.
- **Установка**:
  - Официальный сайт: [https://www.mozilla.org/firefox/](https://www.mozilla.org/firefox/)
  - Linux (официальная сборка):
    ```bash
    wget "https://download.mozilla.org/?product=firefox-latest-ssl&os=linux64&lang=ru" -O firefox.tar.bz2
    tar xjf firefox.tar.bz2 -C /opt/
    sudo ln -sf /opt/firefox/firefox /usr/local/bin/firefox
    ```
  - Через пакетный менеджер:
    ```bash
    sudo apt install firefox          # Ubuntu
    sudo dnf install firefox          # Fedora
    ```

---

### 3. Microsoft Edge
- **Назначение**: браузер от Microsoft на базе Chromium.
- **Движок**: Blink.
- **Особенности**: интеграция с Windows, режим Internet Explorer (для legacy-сайтов), сборка для предприятий, синхронизация с Microsoft Account.
- **Установка**:
  - Windows: предустановлен или [https://www.microsoft.com/edge](https://www.microsoft.com/edge)
  - macOS/Linux: [https://www.microsoft.com/edge/download](https://www.microsoft.com/edge/download)

---

### 4. Brave
- **Назначение**: браузер с блокировкой рекламы и трекеров по умолчанию.
- **Движок**: Blink (на базе Chromium).
- **Особенности**: встроенная защита от отслеживания, поддержка Web3, криптовалютная модель вознаграждения (BAT).
- **Установка**:
  - Официальный сайт: [https://brave.com/](https://brave.com/)
  - Linux:
    ```bash
    sudo curl -fsSLo /usr/share/keyrings/brave-browser-archive-keyring.gpg https://brave.com/brave-browser-archive-keyring.gpg
    echo "deb [signed-by=/usr/share/keyrings/brave-browser-archive-keyring.gpg] https://brave-browser-apt-release.s3.brave.com/ stable main" | sudo tee /etc/apt/sources.list.d/brave-browser-release.list
    sudo apt update && sudo apt install brave-browser
    ```

---

### 5. Vivaldi
- **Назначение**: гибкий браузер для продвинутых пользователей.
- **Движок**: Blink.
- **Особенности**: настраиваемый интерфейс, встроенные заметки, почтовый клиент, веб-панели, поддержка команд.
- **Установка**:
  - Официальный сайт: [https://vivaldi.com/](https://vivaldi.com/)
  - Linux:
    ```bash
    wget -qO- https://repo.vivaldi.com/archive/linux_signing_key.pub | sudo gpg --dearmor -o /usr/share/keyrings/vivaldi-browser.gpg
    echo "deb [signed-by=/usr/share/keyrings/vivaldi-browser.gpg] https://repo.vivaldi.com/archive/deb/ stable main" | sudo tee /etc/apt/sources.list.d/vivaldi-archive.list
    sudo apt update && sudo apt install vivaldi-stable
    ```

---

### 6. Opera
- **Назначение**: лёгкий браузер с дополнительными функциями.
- **Движок**: Blink.
- **Особенности**: встроенный VPN (ограниченный), блокировщик рекламы, рабочие пространства, мессенджер.
- **Установка**:
  - Официальный сайт: [https://www.opera.com/](https://www.opera.com/)
  - Linux:
    ```bash
    sudo apt install software-properties-common
    wget -qO- https://deb.opera.com/archive.key | sudo gpg --dearmor -o /usr/share/keyrings/opera-browser.gpg
    echo "deb [signed-by=/usr/share/keyrings/opera-browser.gpg] https://deb.opera.com/opera-stable/ stable non-free" | sudo tee /etc/apt/sources.list.d/opera.list
    sudo apt update && sudo apt install opera-stable
    ```

---

### 7. Safari
- **Назначение**: официальный браузер Apple.
- **Движок**: WebKit.
- **Особенности**: глубокая интеграция с экосистемой Apple, энергоэффективность, защита приватности (IPR, блокировка трекеров).
- **Установка**:
  - Только в macOS и iOS. Обновляется через App Store или системные обновления.

---

### 8. Tor Browser
- **Назначение**: браузер для анонимного доступа к интернету.
- **Движок**: Gecko (форк Firefox ESR).
- **Особенности**: весь трафик проходит через сеть Tor, отключена загрузка шрифтов и WebRTC, усиленная изоляция.
- **Установка**:
  - Официальный сайт: [https://www.torproject.org/download/](https://www.torproject.org/download/)
  - Linux:
    ```bash
    wget https://www.torproject.org/dist/torbrowser/<версия>/tor-browser-linux64-<версия>_ru.tar.xz
    tar -xJf tor-browser-linux64-*.tar.xz
    ./tor-browser/Browser/start-tor-browser
    ```

### 9. Waterfox
- **Назначение**: форк Firefox с упором на производительность и классический интерфейс.
- **Движок**: Gecko.
- **Особенности**: поддержка устаревших расширений (в Waterfox Classic), отсутствие телеметрии.
- **Установка**:
  - [https://www.waterfox.net/](https://www.waterfox.net/)
  - Linux:
    ```bash
    wget https://download.waterfox.net/waterfox-<версия>.tar.bz2
    tar xjf waterfox-*.tar.bz2 -C /opt/
    sudo ln -sf /opt/waterfox/waterfox /usr/local/bin/waterfox
    ```

---

### 10. LibreWolf
- **Назначение**: безопасная и приватная сборка Firefox.
- **Движок**: Gecko.
- **Особенности**: отключена телеметрия, ужесточённые настройки приватности по умолчанию, автоматические обновления.
- **Установка**:
  - Официальный сайт: [https://librewolf.net/](https://librewolf.net/)
  - Linux (через репозиторий):
    ```bash
    sudo apt install gpg
    curl -sS https://deb.librewolf.net/keyring.gpg | sudo gpg --dearmor --output /usr/share/keyrings/librewolf.gpg
    echo "deb [arch=amd64 signed-by=/usr/share/keyrings/librewolf.gpg] https://deb.librewolf.net $(lsb_release -sc) main" | sudo tee /etc/apt/sources.list.d/librewolf.list
    sudo apt update && sudo apt install librewolf
    ```

---

### 11. Falkon
- **Назначение**: лёгкий браузер на Qt WebEngine.
- **Движок**: Blink (через Qt WebEngine).
- **Особенности**: минимализм, низкое потребление памяти, подходит для слабых систем.
- **Установка**:
  - Официальный сайт (часть KDE): [https://apps.kde.org/falkon/](https://apps.kde.org/falkon/)
  - Linux:
    ```bash
    sudo apt install falkon          # Debian/Ubuntu
    sudo dnf install falkon          # Fedora
    ```

### 12. Epiphany (GNOME Web)
- **Назначение**: официальный браузер среды GNOME.
- **Движок**: WebKitGTK.
- **Особенности**: интеграция с GNOME, поддержка Web Extensions, минималистичный интерфейс.
- **Установка**:
  - Linux:
    ```bash
    sudo apt install epiphany-browser    # Debian/Ubuntu
    sudo dnf install epiphany            # Fedora
    ```

### 13. Pale Moon
- **Назначение**: независимый браузер на собственном движке Goanna.
- **Движок**: Goanna (форк Gecko).
- **Особенности**: поддержка старых расширений, классический UI, низкие системные требования.
- **Установка**:
  - [https://www.palemoon.org/](https://www.palemoon.org/)
  - Linux:
    ```bash
    wget https://linux.palemoon.org/Данные/main/palemoon-<версия>.linux-x86_64.tar.xz
    tar -xJf palemoon-*.tar.xz -C /opt/
    sudo ln -sf /opt/palemoon/palemoon /usr/local/bin/palemoon
    ```

### 14. Arc Browser
- **Назначение**: экспериментальный браузер с акцентом на организацию вкладок и командную работу.
- **Движок**: Blink.
- **Особенности**: вертикальные вкладки, Spaces, Split View, интеграция с Notion и Slack.
- **Установка**:
  - macOS: [https://arc.net/](https://arc.net/) (требуется инвайт или ожидание в очереди)
  - Windows (ограниченный релиз через Windows Store)

### 15. Microsoft Edge (Enterprise)
- **Назначение**: версия Edge для корпоративного развёртывания.
- **Особенности**: управление через Intune/SCCM, политики безопасности, режим IE.
- **Установка**:
  - [https://www.microsoft.com/edge/business/download](https://www.microsoft.com/edge/business/download)

### 16. Yandex Browser
- **Назначение**: браузер от Яндекса с интеграцией сервисов компании.
- **Движок**: Blink.
- **Особенности**: защита от мошенничества, Турбо-режим, встроенный переводчик, облачные закладки.
- **Установка**:
  - Официальный сайт: [https://browser.yandex.ru/](https://browser.yandex.ru/)
  - Linux:
    ```bash
    wget https://repo.yandex.ru/yandex-browser/yandex-browser-stable_current_amd64.deb
    sudo dpkg -i yandex-browser-stable_current_amd64.deb

    ```

### 17. Orion Browser
- **Назначение**: браузер на WebKit с поддержкой расширений Chrome и Firefox.
- **Движок**: WebKit.
- **Особенности**: совместимость с расширениями, ориентация на macOS.
- **Установка**:
  - [https://browser.kagi.com/](https://browser.kagi.com/) (требуется бета-доступ)

### 18. Ungoogled Chromium
- **Назначение**: полностью де-гуглена версия Chromium.
- **Движок**: Blink.
- **Особенности**: удалена вся телеметрия и сервисы Google, поддержка стандартных расширений.
- **Установка**:
  - GitHub Releases: [https://github.com/ungoogled-software/ungoogled-chromium](https://github.com/ungoogled-software/ungoogled-chromium)
  - Linux (через репозиторий):
    ```bash
    # Debian/Ubuntu (пример для пакета из релизов)
    wget <ссылка на .deb из релизов>
    sudo dpkg -i ungoogled-chromium_*.deb
    ```

---

### Примечания:
- Все браузеры на Blink (Chromium) совместимы с расширениями из Chrome Web Store, при условии поддержки загрузки расширений из внешних источников.
- Для разработчиков рекомендуется использовать как минимум два браузера: один на Blink, другой на Gecko или WebKit — для кросс-браузерного тестирования.
- На Linux дистрибутивах некоторые браузеры доступны только через сторонние репозитории или flatpak/snap.

Рекомендуется устанавливать браузеры только из официальных источников или проверенных репозиториев, чтобы избежать подмены бинарных файлов и вредоносных сборок.
