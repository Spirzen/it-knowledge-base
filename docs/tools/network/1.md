**Веб-браузер** — клиент для HTTP/HTTPS: рендерит HTML/CSS/JS, хранит cookies, выполняет запросы к API и открывает инструменты разработчика (DevTools). Для работы и обучения достаточно одного "основного" браузера; для **кросс-браузерной проверки** сайтов держите минимум два движка — **Chromium (Blink)** и **Gecko** или **WebKit**.

## Движки и совместимость

| Движок | База | Примеры браузеров |
|--------|------|-------------------|
| **Blink** | Chromium | Chrome, Edge, Brave, Vivaldi, Opera, Yandex |
| **Gecko** | Firefox | Firefox, LibreWolf, Tor Browser, Waterfox |
| **WebKit** | Safari / GTK | Safari, Epiphany (GNOME Web) |

Браузеры на **Blink** часто поддерживают расширения Chrome Web Store (если разрешена установка из внешних источников). Расширения Firefox — через [addons.mozilla.org](https://addons.mozilla.org/).

## Установка на Linux

**Google Chrome (Debian/Ubuntu):**

```bash
wget -q -O - https://dl.google.com/linux/linux_signing_key.pub | sudo gpg --dearmor -o /usr/share/keyrings/google-chrome.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/google-chrome.gpg] http://dl.google.com/linux/chrome/deb/ stable main" | sudo tee /etc/apt/sources.list.d/google-chrome.list
sudo apt update && sudo apt install google-chrome-stable
```

**Firefox** — чаще из репозитория: `sudo apt install firefox` или официальная сборка с [mozilla.org](https://www.mozilla.org/firefox/).

**LibreWolf** — репозиторий [deb.librewolf.net](https://librewolf.net/installation/debian/).

На многих дистрибутивах удобны **Flatpak** и **Snap** — единый способ обновления без ручных `.deb`.

## Для разработчиков

- **DevTools** (F12): сеть, консоль, Lighthouse, эмуляция мобильных устройств.
- Тестируйте в **Chrome + Firefox** (или Safari на macOS) перед релизом.
- **Профили** и контейнеры (Firefox) изолируют рабочие и личные сессии.
