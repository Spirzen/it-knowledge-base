# Мессенджеры

<div class="article-tags">
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>

**Мессенджер** доставляет сообщения, файлы и звонки в реальном времени. Отличайте **личные** приложения (Telegram, WhatsApp, Signal), **командные** (Slack, Teams, Mattermost) и **саморазмещаемые** (Matrix/Element, Zulip). Критично понимать модель **шифрования**: E2EE "по умолчанию", только в "секретных чатах" или только TLS до сервера.

<MessengersCatalogPlay />

:::tip Критерии выбора
| Вопрос | Если "да" — смотрите |
|--------|----------------------|
| Нужен свой сервер данных? | Mattermost, Zulip, Matrix (Synapse) |
| Максимум приватности? | Signal, Session, Threema |
| Интеграции с Jira/GitHub? | Slack, Teams |
| Каналы и боты? | Telegram, Discord |
:::

## Личные и массовые

| Мессенджер | Шифрование | Desktop / особенности |
|------------|------------|------------------------|
| **Telegram** | E2EE в секретных чатах; облачные чаты на серверах | [desktop.telegram.org](https://desktop.telegram.org/), `apt install telegram-desktop` |
| **WhatsApp** | E2EE (Signal Protocol); привязка к телефону | [whatsapp.com/download](https://www.whatsapp.com/download) |
| **Signal** | E2EE по умолчанию, open-source | [signal.org](https://signal.org/download/) |
| **Viber** | E2EE в сообщениях и звонках | [viber.com](https://www.viber.com/ru/download/) |
| **Discord** | Не E2EE в DM; голосовые каналы, боты | [discord.com/download](https://discord.com/download) |

## Корпоративные и командные

| Мессенджер | Назначение | Установка |
|------------|----------|-----------|
| **Slack** | Каналы, интеграции, поиск по истории | [slack.com/downloads](https://slack.com/downloads) |
| **Microsoft Teams** | M365, видео, SharePoint | [microsoft.com/microsoft-teams](https://www.microsoft.com/microsoft-teams/download-app) |
| **Mattermost** | Self-host альтернатива Slack | [mattermost.com/download](https://mattermost.com/download/#mattermostApps) |

---

## Приватность и децентрализация

| Мессенджер | Модель |
|------------|--------|
| **Element (Matrix)** | Федерация серверов, E2EE, мосты в IRC/Slack |
| **Session** | Без номера телефона, децентрализованная сеть |
| **Jami** | P2P, GNU, без центрального сервера |
| **Wire** | E2EE, GDPR, бизнес-сценарии |
| **Threema** | Без привязки к номеру; desktop через [web.threema.ch](https://web.threema.ch/) |

## Агрегаторы (несколько сервисов в одном окне)

**Franz** / **Ferdi** / **Rambox** — обёртки над веб-версиями Telegram, Slack, WhatsApp и др. Удобно для рабочего стола, но учитывайте **политику телеметрии** (Ferdi — open-source форк Franz без телеметрии).

```bash
flatpak install flathub com.getferdi.Ferdi
```

## IRC (классика)

Для сетей IRC подойдут **WeeChat** (консоль), **HexChat** (GUI), **Kiwi IRC** (веб): `sudo apt install weechat hexchat`.
