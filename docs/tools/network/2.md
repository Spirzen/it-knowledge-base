# Мессенджеры

<div class="article-tags">
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

Мессенджер — программное приложение для обмена текстовыми, аудио-, видео- и файловыми сообщениями в режиме реального времени. Современные мессенджеры также включают функции групповой работы, видеоконференций, интеграции с другими сервисами и API для автоматизации. Ниже приведён перечень наиболее распространённых мессенджеров с описанием их назначения, особенностей и способов установки на рабочие станции.

---

### 1. Telegram
- **Назначение**: облачный мессенджер с акцентом на скорость, безопасность и масштабируемость.
- **Особенности**: каналы, боты, облачные файлы до 2 ГБ, секретные чаты с E2EE, кроссплатформенность.
- **Установка**:
  - Официальный сайт: [https://telegram.org/](https://telegram.org/)
  - Windows/macOS/Linux: [https://desktop.telegram.org/](https://desktop.telegram.org/)
  - Linux (через пакетный менеджер):
    ```bash
    sudo apt install telegram-desktop      # Debian/Ubuntu
    sudo dnf install telegram-desktop      # Fedora
    sudo pacman -S telegram-desktop        # Arch
    ```
  - Flatpak:
    ```bash
    flatpak install flathub org.telegram.desktop
    ```

---

### 2. WhatsApp
- **Назначение**: мобильный мессенджер с поддержкой настольных клиентов через привязку к телефону.
- **Особенности**: E2EE по умолчанию, голосовые и видеозвонки, групповые чаты до 1024 участников.
- **Установка**:
  - Веб-версия: [https://web.whatsapp.com/](https://web.whatsapp.com/)
  - Настольное приложение:
    - Windows/macOS: [https://www.whatsapp.com/download](https://www.whatsapp.com/download)
  - Linux: официальный .deb/.rpm доступен с [https://www.whatsapp.com/desktop](https://www.whatsapp.com/desktop)

---

### 3. Signal
- **Назначение**: приватный мессенджер с открытым исходным кодом и сквозным шифрованием.
- **Особенности**: E2EE по умолчанию, исчезающие сообщения, минимальная телеметрия, аудит безопасности.
- **Установка**:
  - Официальный сайт: [https://signal.org/](https://signal.org/)
  - Windows/macOS: [https://signal.org/download/](https://signal.org/download/)
  - Linux (через репозиторий):
    ```bash
    curl -s https://updates.signal.org/desktop/apt/keys.asc | sudo gpg --dearmor -o /usr/share/keyrings/signal-desktop-keyring.gpg
    echo "deb [arch=amd64 signed-by=/usr/share/keyrings/signal-desktop-keyring.gpg] https://updates.signal.org/desktop/apt xenial main" | sudo tee /etc/apt/sources.list.d/signal.list
    sudo apt update && sudo apt install signal-desktop
    ```
  - Flatpak:
    ```bash
    flatpak install flathub org.signal.Signal
    ```

### 4. Slack
- **Назначение**: корпоративный мессенджер для командной работы.
- **Особенности**: интеграция с GitHub, Jira, Google Drive, Zoom; каналы, потоки, поиск по истории.
- **Установка**:
  - Официальный сайт: [https://slack.com/downloads](https://slack.com/downloads)
  - Linux:
    - .deb/.rpm: [https://slack.com/downloads/linux](https://slack.com/downloads/linux)
    - Через snap:
      ```bash
      sudo snap install slack --classic
      ```
    - Через Flatpak:
      ```bash
      flatpak install flathub com.slack.Slack
      ```

### 5. Microsoft Teams
- **Назначение**: платформа для совместной работы в экосистеме Microsoft 365.
- **Особенности**: видеоконференции, совместное редактирование документов, интеграция с Outlook и SharePoint.
- **Установка**:
  - Официальный сайт: [https://www.microsoft.com/Рu/microsoft-teams/download-app](https://www.microsoft.com/Рu/microsoft-teams/download-app)
  - Windows: предустановлен в Windows 11 / через Microsoft Store
  - macOS/Linux: доступен .dmg и .deb/.rpm
    ```bash
    wget -O teams.deb https://teams.microsoft.com/downloads/desktopurl?env=production&plat=linux&arch=x64&download=true
    sudo dpkg -i teams.deb
    sudo apt --fix-broken install
    ```

### 11. Threema
- **Назначение**: приватный мессенджер без привязки к номеру или email.
- **Особенности**: полная анонимность, E2EE, open-source клиент (Threema Web/Open).

### 13. Franz / Ferdi
- **Назначение**: агрегатор мессенджеров (мультиклиент).
- **Особенности**: объединяет Telegram, WhatsApp, Slack, Discord и др. в одном окне.
- **Franz**: проприетарный (с телеметрией)
- **Ferdi**: форк Franz с открытым исходным кодом и без телеметрии
- **Установка Ferdi**:
  - Официальный сайт: [https://getferdi.com/](https://getferdi.com/)
  - Linux:
    ```bash
    # Через репозиторий (Debian/Ubuntu)
    wget -O ferdi.deb https://github.com/getferdi/ferdi/releases/latest/download/ferdi_amd64.deb
    sudo dpkg -i ferdi.deb
    ```
  - Flatpak:
    ```bash
    flatpak install flathub com.getferdi.Ferdi
    ```

---

### 14. Jami (ранее GNU Ring)
- **Назначение**: полностью децентрализованный мессенджер и VoIP-клиент.
- **Особенности**: P2P, без серверов, E2EE, open-source (GNU Project).
- **Установка**:
  - Официальный сайт: [https://jami.net/](https://jami.net/)
  - Linux:
    ```bash
    sudo apt install jami              # Debian/Ubuntu (начиная с 21.10)
    ```
  - Или через репозиторий:
    ```bash
    sudo sh -c "echo 'deb https://dl.jami.net/nightly/debian debian main' > /etc/apt/sources.list.d/jami.list"
    wget -qO - https://dl.jami.net/gpg.key | sudo apt-key add -
    sudo apt update && sudo apt install jami
    ```
