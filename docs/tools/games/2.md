## Полезные инструменты для геймера

**OBS Studio** — это бесплатное приложение с открытым исходным кодом для записи экрана и трансляции видео в реальном времени, поддерживающее захват окон, устройств захвата, аудиоинтерфейсов и наложение источников, доступное на платформах Windows, macOS и Linux, построенное на фреймворке Qt и использующее FFmpeg для кодирования.

**Streamlabs Desktop** — это условно-бесплатное приложение для стриминга и записи игрового процесса, включающее встроенные виджеты, алерты, темы и интеграцию с Twitch и YouTube, доступное на Windows и macOS, работающее поверх Electron и требующее учетной записи Streamlabs для полного функционала.

**Discord** — это бесплатное коммуникационное приложение с поддержкой текстового, голосового и видеочата, созданный для геймеров, но активно используемый в других сообществах, доступный на Windows, macOS, Linux, Android и iOS, построенный на Electron и включающий функции совместного использования экрана, ботов и серверов.

**Steam** — это коммерческая платформа цифровой дистрибуции игр и программного обеспечения от Valve, предоставляющая магазин, облачные сохранения, античит VAC, форумы и инструменты для разработчиков, доступная на Windows, macOS и Linux, основанная на собственном клиентском движке и поддерживающая модификации через Steam Workshop.

**Epic Игры Launcher** — это бесплатный клиент цифровой дистрибуции игр и движка Unreal Engine, предлагающий бесплатные еженедельные игры, облачные сохранения и интеграцию с Fortnite и Rocket League, доступный на Windows и macOS, построенный на C++ и Qt.

**GeForce Experience** — это бесплатное приложение от NVIDIA для автоматической оптимизации игровых настроек, записи видео, трансляции и обновления драйверов, доступное только на Windows, работающее в связке с графическими картами NVIDIA и использующее NVENC для аппаратного кодирования.

**Razer Cortex** — это бесплатная утилита для оптимизации системы перед запуском игр, включающая очистку ОЗУ, отключение фоновых процессов и трекер достижений, доступная на Windows, разработанная Razer и интегрированная с их экосистемой периферии.

**MSI Afterburner** — это бесплатная утилита с открытым исходным кодом для разгона видеокарт, мониторинга температуры, напряжения и частот, а также наложения оверлея в играх, доступная на Windows, поддерживающая оборудование большинства производителей GPU и использующая API Rivatuner Statistics Server.

**Fraps** — это коммерческое приложение для измерения FPS, записи видео и создания скриншотов в играх, работающее на уровне DirectX и OpenGL, доступное только на Windows, не обновлявшееся с 2013 года, но остающееся совместимым с множеством старых и новых игр.

**Bandicam** — это условно-бесплатное приложение для записи экрана и игрового процесса с поддержкой аппаратного ускорения, рисования поверх кадра и планировщика задач, доступное на Windows, использующее кодеки H.264 и AVI и ограничивающее длительность записи в бесплатной версии.

**Xbox Game Bar** — это встроенное в Windows 10 и 11 приложение для записи клипов, снимков экрана, мониторинга производительности и управления музыкой, доступное только на Windows, построенное на UWP и интегрированное с сервисами Xbox Live.

**NVIDIA ShadowPlay** — это компонент драйвера NVIDIA, входящий в GeForce Experience, обеспечивающий запись последних минут игрового сессии, моментальные скриншоты и трансляцию без значительной нагрузки на CPU, доступный только на Windows с поддержкой GPU NVIDIA.

**AMD ReLive** — это встроенный в драйверы AMD Radeon Software инструмент для записи видео, стриминга и создания GIF-анимаций, использующий аппаратное кодирование VCE/VCN, доступный на Windows и Linux, не требующий сторонних приложений.

**EVGA Precision X1** — это бесплатная утилита для разгона и мониторинга видеокарт NVIDIA, включающая графический интерфейс, профили настроек и поддержку RGB-подсветки, доступная на Windows и работающая только с оборудованием EVGA.

**Parsec** — это бесплатное приложение для удаленного доступа к компьютеру с низкой задержкой, ориентированное на стриминг игр и совместную работу, доступное на Windows, macOS, Linux, Android и iOS, использующее WebRTC и P2P-соединения.

**Moonlight** — это бесплатное приложение с открытым исходным кодом для потоковой передачи игр с ПК с NVIDIA GPU через протокол GameStream, доступное на Windows, macOS, Linux, Android, iOS и Raspberry Pi, не зависящее от облачных сервисов NVIDIA.

**VoiceMeeter** — это бесплатный виртуальный микшер аудиоустройств для маршрутизации звука между приложениями и внешними интерфейсами, используемый стримерами для разделения аудиодорожек, доступный на Windows, работающий на уровне WASAPI и ASIO.

**Voicemod** — это условно-бесплатное приложение для изменения голоса в реальном времени с набором пресетов и интеграцией в Discord, OBS и игры, доступное на Windows, требующее подписки для разблокировки всех эффектов.

**Logitech G HUB** — это бесплатное приложение для настройки периферии Logitech, включая макросы, профили DPI, подсветку и управление медиа, доступное на Windows и macOS, работающее через облачную синхронизацию и требующее регистрации.

**Corsair iCUE** — это бесплатное приложение для управления устройствами Corsair, объединяющее настройку RGB-подсветки, профилей мыши, клавиатурных макросов и систем охлаждения, доступное на Windows и macOS, поддерживающее интеграцию с другими брендами через плагины.

**Elgato Stream Deck** — это коммерческое приложение для управления действиями через программируемые кнопки физического устройства Stream Deck, включая запуск сцен, переключение сцен в OBS, управление аудио и автоматизацию, доступное на Windows и macOS, поддерживающее плагины и API.

**Reshade** — это бесплатный постобработочный шейдерный фреймворк с открытым исходным кодом для добавления эффектов в игры, таких как SMAA, HDR, цветокоррекция и глубина резкости, совместимый с DirectX 9–12 и Vulkan, работающий на Windows и не требующий модификации игры.

**Mod Organizer 2** — это бесплатное приложение с открытым исходным кодом для управления модификациями в играх Bethesda и других студий, позволяющее изолировать файлы модов, разрешать конфликты и создавать профили, доступное на Windows и построенное на Qt.

**Vortex** — это бесплатное приложение от Nexus Mods для установки и управления модами, поддерживающее автоматическое развертывание, профили и интеграцию с сайтом, доступное на Windows, работающее на Electron и требующее учетной записи Nexus Mods.

**Lutris** — это бесплатный менеджер игровых запусков с открытым исходным кодом для Linux, упрощающий установку и запуск игр из Steam, GOG, Battle.net и других платформ через Wine, Proton и эмуляторы, построенный на Python и GTK.

**Wine** — это бесплатный совместимый слой с открытым исходным кодом, позволяющий запускать Windows-приложения и игры на Unix-подобных системах, включая Linux и macOS, реализующий Windows API поверх POSIX и X11/Wayland.

**Proton** — это модифицированная версия Wine от Valve с интеграцией DXVK, VKD3D и других компонентов для запуска Windows-игр в Steam на Linux, распространяемая бесплатно и встроенная в клиент Steam.

**DXVK** — это открытый проект, реализующий DirectX 9–11 поверх Vulkan, используемый в Proton и Wine для повышения производительности и совместимости игр на Linux, доступный как отдельная библиотека для ручной интеграции.

**MangoHud** — это бесплатный инструмент с открытым исходным кодом для отображения оверлея производительности (FPS, температура, загрузка GPU/CPU) в играх на Linux, совместимый с Vulkan и OpenGL, настраиваемый через конфигурационный файл.

**GameMode** — это демон с открытым исходным кодом для Linux, автоматически повышающий приоритет процессов игр, настраивающий параметры ядра и энергопрофиль для максимизации производительности, интегрируемый с Lutris и Steam.

**GOverlay** — это бесплатное приложение с открытым исходным кодом для Linux, предоставляющее графический интерфейс для настройки MangoHud и других оверлеев, доступное на базе GTK и поддерживающее экспорт профилей.

**Unity Hub** — это бесплатное приложение для управления версиями движка Unity, проектами и лицензиями, позволяющее переключаться между LTS и экспериментальными сборками, доступное на Windows, macOS и Linux, работающее на Electron.

**Unreal Engine Launcher** — это бесплатный клиент Epic Игры для управления проектами и версиями движка Unreal Engine, включающий Marketplace, Samples и документацию, доступный на Windows и macOS, требующий учетной записи Epic.

**Godot Engine** — это бесплатный игровой движок с открытым исходным кодом, поддерживающий 2D и 3D разработку, скриптинг на GDScript, C# и VisualScript, экспорт на Windows, macOS, Linux, Android, iOS, HTML5 и другие платформы, построенный на C++ и OpenGL/Vulkan.

**Construct** — это условно-бесплатный визуальный игровой движок для создания 2D-игр без программирования, доступный на Windows и macOS, экспортирующий в HTML5, Windows, Android и другие форматы, использующий JavaScript и WebGL.

**GameMaker Studio** — это коммерческий игровой движок с поддержкой визуального программирования и языка GML, ориентированный на 2D-разработку, экспортирующий на Windows, macOS, Linux, Android, iOS, HTML5, PlayStation, Xbox и Nintendo Switch, работающий на собственном рендерере.

**RPG Maker** — это коммерческий конструктор ролевых игр с визуальным редактором карт, событий и диалогов, использующий JavaScript (в версиях MV и MZ) для расширения функционала, доступный на Windows и macOS, экспортирующий только в Windows, macOS, Android, iOS и HTML5.

**Blender** — это бесплатное приложение с открытым исходным кодом для 3D-моделирования, анимации, симуляции и рендеринга, включающее игровой движок (до версии 2.79), поддержку Python-скриптов и экспорт в игровые форматы FBX, glTF и OBJ, доступное на Windows, macOS и Linux.

**Audacity** — это бесплатный аудиоредактор с открытым исходным кодом для записи, обрезки, фильтрации и экспорта звука в форматах WAV, MP3, OGG и других, используемый разработчиками игр для подготовки ассетов, доступный на Windows, macOS и Linux.

**Bosca Ceoil** — это бесплатный музыкальный трекер для создания чиптюн-саундтреков и фоновой музыки для игр, экспортирующий в WAV и MIDI, доступный на Windows, macOS и Linux, разработанный на Java.

**Tiled** — это бесплатный редактор тайловых карт с открытым исходным кодом, поддерживающий ортогональные, изометрические и шестиугольные сетки, слои объектов и экспорт в JSON, CSV и другие форматы, используемый в 2D-движках, доступный на Windows, macOS и Linux.

**Aseprite** — это коммерческий пиксель-арт редактор с поддержкой слоев, анимации, палитр и экспорт в PNG, GIF и Sprite Sheets, доступный на Windows, macOS и Linux, имеющий открытый исходный код, но продаваемый через Steam и официальный сайт.

**Piskel** — это бесплатный веб-редактор пиксель-арта и анимации с возможностью экспорта в PNG и GIF, доступный онлайн и как автономное приложение на базе Electron, не требующий установки.

**LMMS** — это бесплатная цифровая аудиорабочая станция с открытым исходным кодом для создания музыки и звуковых эффектов, включающая синтезаторы, семплеры и MIDI-поддержку, доступная на Windows, macOS и Linux.

**Open Broadcaster Software Classic** — это устаревшая версия OBS, замененная OBS Studio, больше не поддерживаемая, но иногда используемая в специфических сценариях на старых системах.

**Playnite** — это бесплатный менеджер игровых библиотек с открытым исходным кодом для Windows, объединяющий игры из Steam, GOG, Epic, Battle.net, Origin и других платформ в одном интерфейсе, поддерживающий эмуляторы и пользовательские скрипты.

**Heroic Игры Launcher** — это бесплатный клиент с открытым исходным кодом для запуска игр из Epic Игры Store и GOG на Windows и Linux, построенный на Electron и использующий Wine/Proton для совместимости.

**Itch.io App** — это бесплатное приложение с открытым исходным кодом для загрузки и запуска игр с платформы Itch.io, доступное на Windows, macOS и Linux, поддерживающее автоматические обновления и метаданные.

**GDevelop** — это бесплатный визуальный игровой движок с открытым исходным кодом для создания 2D и 3D игр без кода, экспортирующий в HTML5, Windows, macOS, Linux, Android и iOS, работающий на C++ и JavaScript.

**Ren'Py** — это бесплатный визуальный новелл-движок с открытым исходным кодом, использующий Python для скриптов, поддерживающий экспорт на Windows, macOS, Linux, Android и iOS, ориентированный на создание интерактивных рассказов.
