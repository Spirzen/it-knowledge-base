Современные инструменты видеосвязи позволяют организовывать как простые звонки между двумя участниками, так и масштабные конференции с десятками участников, виртуальными фонами, записью, совместным редактированием и интеграцией с календарями. Ниже приведены наиболее распространённые решения, сгруппированные по типу размещения и лицензированию.

---

### 1. Open-source и self-hosted решения

| Инструмент | Описание | Установка / Ссылка |
|------------|----------|--------------------|
| **Jitsi Meet** | Полностью open-source видеоконференц-система. Поддержка WebRTC, без установки клиентов (браузер), интеграция с LDAP, JWT, Docker-развёртывание. | [https://jitsi.org/jitsi-meet/](https://jitsi.org/jitsi-meet/) Docker: [github.com/jitsi/docker-jitsi-meet](https://github.com/jitsi/docker-jitsi-meet) |
| **BigBlueButton** | Платформа для вебинаров и онлайн-обучения. Поддержка чата, презентаций, whiteboard, breakout rooms, запись. | [https://bigbluebutton.org](https://bigbluebutton.org) Только на Ubuntu 20.04/22.04, установка через скрипт |
| **Matrix + Element + Jitsi bridge** | Децентрализованная система мессенджинга с возможностью подключения видеозвонков через Jitsi или нативный VoIP (на базе WebRTC). | [https://matrix.org](https://matrix.org) Self-hosted: [github.com/matrix-org/synapse](https://github.com/matrix-org/synapse) |
| **Galène** | Лёгкая альтернатива Jitsi на Go. Поддержка групп, модерации, записи. Подходит для небольших команд. | [https://git.sr.ht/~whynothugo/galene](https://git.sr.ht/~whynothugo/galene) Бинарник или из исходников |
| **LiveKit** | Масштабируемая платформа на WebRTC для создания кастомных видеоприложений (вебинары, телемедицина). Поддержка SFU-архитектуры. | [https://livekit.io](https://livekit.io) GitHub: [livekit/livekit](https://github.com/livekit/livekit) Docker или Go-бинарник |
| **Mediasoup** | Высокопроизводительная WebRTC-библиотека для построения кастомных видеосервисов. | [https://mediasoup.org](https://mediasoup.org) Node.js + C++ worker |
| **OpenVidu** | Платформа поверх Kurento Media Server для разработки видеоприложений. REST API + SDK (JavaScript, Java, React). | [https://openvidu.io](https://openvidu.io) Docker или AWS Marketplace |

| Инструмент | Описание | Ссылка |
|------------|----------|--------|

### 4. Инструменты для записи и трансляции

| Инструмент | Назначение | Установка / Ссылка |
|------------|------------|--------------------|
| **OBS Studio** | Open-source программа для записи экрана и стриминга в YouTube, Twitch, RTMP-серверы. Поддержка виртуальных камер. | [https://obsproject.com](https://obsproject.com) `sudo apt install obs-studio` (Linux), установщик для Windows/macOS |
| **vMix** | Профессиональное ПО для live-продакшена: многокамерные переключения, титры, chroma key. | [https://www.vmix.com](https://www.vmix.com) (Windows-only) |
| **FFmpeg** | Консольный инструмент для обработки, записи и потоковой передачи аудио/видео. Может использоваться как RTMP-клиент. | `sudo apt install ffmpeg` или [https://ffmpeg.org](https://ffmpeg.org) |
| **Restream** | Платформа для одновременной трансляции в несколько сервисов (YouTube, Twitch, Facebook и др.). | [https://restream.io](https://restream.io) |
| **Wirecast** | Коммерческий аналог vMix от Telestream. Поддержка IP-камер, ISO-записи, удалённых гостей. | [https://www.telestream.net/wirecast](https://www.telestream.net/wirecast) |

### 6. Протоколы и стандарты

| Протокол | Назначение |
|----------|-----------|
| **WebRTC** | Открытый стандарт для P2P-видео/аудио в браузере. Используется в Jitsi, Google Meet, Discord и др. |
| **SIP (Session Initiation Protocol)** | Стандарт для VoIP-звонков. Поддерживается в Asterisk, Linphone, некоторых корпоративных АТС. |
| **RTMP (Real-Time Messaging Protocol)** | Протокол для потоковой передачи от источника к серверу (OBS → YouTube). Устаревает в пользу HLS/WebRTC. |
| **H.264 / VP8 / VP9 / AV1** | Кодеки сжатия видео. H.264 — наиболее совместимый; AV1 — перспективный open-source кодек. |
