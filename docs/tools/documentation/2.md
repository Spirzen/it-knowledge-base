# 🔍 Подборка документации

## 🌐 Универсальные агрегаторы и библиотеки

- **[Metanit.com](https://metanit.com/)** — масштабный сайт: C#, Java, Python, Go, Kotlin, Dart/Flutter, C/C++, SQL, MongoDB, HTML/JS, React, Rust, PHP, даже NASM.  
- **[DevDocs.io](https://devdocs.io/)** — агрегатор документации по десяткам технологий с offline-режимом и быстрым поиском.  
- **[MDN Web Docs (Mozilla)](https://developer.mozilla.org/ru/)** — эталонная документация по веб-стандартам (HTML, CSS, JavaScript, XML, Web APIs); русский язык поддерживается.  
- **[JetBrains — русскоязычные Wiki и справочные материалы](https://www.jetbrains.com/Рu/)** — PyCharm, IntelliJ IDEA, Kotlin и др. (встроено в IDE и онлайн).

## 💻 Языки программирования

### C / C++
- **[ISO C++](https://isocpp.org/)** — официальный сайт, ссылки на стандарт, FAQ, лучшие практики.  
- **[Metanit: C/C++](https://metanit.com/cpp/)** — учебные руководства на русском.  

### C#
- **[Официальная документация Microsoft на русском](https://learn.microsoft.com/ru/dotnet/csharp/tour-of-csharp/)** — учебный тур, справочник, примеры.  
- **[Metanit: C# и .NET](https://metanit.com/sharp/)** — подробные курсы и примеры.  
- **[Справочник C#](https://docs.microsoft.com/Рu/dotnet/csharp/)** — полный технический справочник.  

### Java
- **[Oracle Java SE Документация](https://docs.oracle.com/javase/8/docs/)** — официальная документация (EN, но структурирована и стабильна).  
- **[Metanit: Java](https://metanit.com/java/)** — актуальные статьи на русском (включая `CompletableFuture`, `ProcessBuilder`, volatile, atomics).  

### Python
- **[Официальная документация, русская версия](https://docs.python.org/3/ru/)** — полный перевод (стабильно обновляется).  
- **[Metanit: Python](https://metanit.com/python/)**  
- **[PythonRu](https://pythonru.com/)** — практические примеры и статьи.  
- **[Django Docs](https://docs.djangoproject.com/)** — официальная документация (EN).  

### JavaScript / TypeScript
- **[Современный учебник JavaScript](https://learn.javascript.ru/)** — один из самых полных русскоязычных ресурсов.  
- **[MDN: JavaScript](https://developer.mozilla.org/ru/docs/Web/JavaScript)** — каноничная справка.  
- **[TypeScript Документация](https://www.typescriptlang.org/docs/)** — официальная документация (EN, но с интерактивными примерами).  
- **[Metanit: JS/TS](https://metanit.com/web/)**  

### Go
- **[Go Документация](https://go.dev/doc/)** — туры, эффективные гайды, стандартная библиотека (EN).  

### Kotlin
- **[Kotlin Docs (JetBrains)](https://kotlinlang.org/docs/)** — есть русский интерфейс и часть статьей (переводы сообщества).  

### Rust
- **[«The Rust Programming Language» на русском](https://doc.rust-lang.ru/book/)** — полный перевод «The Book».  

### PHP, Ruby, Swift, Groovy
- **[PHP Manual (русский)](https://www.php.net/manual/ru/)**  
- **[Ruby (официальный сайт, русский)](https://www.ruby-lang.org/ru/Документация/)**  
- **[Swift Документация](https://www.swift.org/Документация/)** (EN)  
- **[Groovy Документация](https://groovy-lang.org/Документация.html)** (EN)
