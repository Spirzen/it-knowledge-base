# Microsoft Learn — навигатор

<div class="article-tags">
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>
</div>

**Microsoft Learn** — официальная платформа пошагового обучения продуктам Microsoft: Azure, .NET, Power Platform, безопасность, Copilot и др. Вселенная IT даёт **нейтральную теорию** на русском; Learn даёт **интерактивную практику** и подготовку к сертификациям. Тексты модулей сюда не копируются — только ссылки и метаданные (длительность, роль, продукт), как рекомендует [Catalog API](https://learn.microsoft.com/en-us/training/support/catalog-api-faq).

## Как пользоваться

1. Пройдите связанную главу энциклопедии (ссылка в карточке навигатора).
2. Откройте схему обучения или модуль на Learn и выполните задания в браузере.
3. Вернитесь в проект для углубления и перекрёстных ссылок.
