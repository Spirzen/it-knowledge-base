# Заметки

Современные инструменты для заметок варьируются от простых текстовых редакторов до сложных систем управления знаниями (PKM). Ниже приведены популярные приложения и платформы, сгруппированные по типу архитектуры и функциональности.

---

### 1. Локальные и оффлайн-ориентированные приложения

| Инструмент | Описание | Установка / Ссылка |
|------------|----------|--------------------|
| **Joplin** | Open-source менеджер заметок с поддержкой Markdown, сквозным шифрованием, синхронизацией (WebDAV, S3, Dropbox и др.). | [https://joplinapp.org](https://joplinapp.org) Docker, Flatpak, AppImage, или `snap install joplin-desktop` |
| **Zettlr** | Markdown-редактор с акцентом на академическую работу, цитирование, Zettelkasten и LaTeX. | [https://www.zettlr.com](https://www.zettlr.com) Доступен как AppImage, dmg, exe |
| **Obsidian (оффлайн-режим)** | Граф знаний поверх локальных Markdown-файлов. Поддерживает плагины, backlinking, граф связей. Без обязательной облачной привязки. | [https://obsidian.md](https://obsidian.md) Скачать установщик для Windows/macOS/Linux |
| **CherryTree** | Иерархический редактор заметок с поддержкой rich text, кода, изображений и таблиц. Данные хранятся в одном файле (SQLite или XML). | [https://www.giuspen.com/cherrytree/](https://www.giuspen.com/cherrytree/) `sudo apt install cherrytree` |
| **Tauon Notebook** | Минималистичный менеджер заметок с поддержкой Markdown и локального хранения. | [https://tauon.app](https://tauon.app) Flatpak: `flatpak install flathub com.github.tauon.tauon` |
| **Turtl** | Зашифрованный менеджер заметок (аналог Evernote с приватностью). Хранение локальное или на собственном сервере. | [https://turtlapp.com](https://turtlapp.com) Исходный код: GitHub `turtl` |

### 3. Self-hosted и open-source решения

| Инструмент | Описание | Установка |
|------------|----------|-----------|
| **Trilium Notes** | Иерархический менеджер заметок с поддержкой скриптов, связей, математики (KaTeX), а также self-hosted сервера. | [https://github.com/zadam/trilium](https://github.com/zadam/trilium) Docker: `docker run -d -p 8080:8080 zadam/trilium` |
| **Logseq** | Приложение в стиле Roam Research с поддержкой блоков, daily notes, bidirectional links. Работает с локальными Markdown-файлами. Возможен self-hosted синхронизатор. | [https://logseq.com](https://logseq.com) GitHub Releases или через `brew install --cask logseq` |
| **Outline** | Современный вики-подобный инструмент с Markdown, совместным редактированием и RBAC. Ориентирован на команды. | [https://www.getoutline.com](https://www.getoutline.com) Self-hosted: [https://github.com/outline/outline](https://github.com/outline/outline) Docker или Yarn |
| **BookStack** | Простая система документации в виде книг/глав/страниц. Подходит для внутренней базы знаний. | [https://www.bookstackapp.com](https://www.bookstackapp.com) Docker: `docker run -d -p 8080:8080 solidnerd/bookstack` |
| **Wiki.js** | Мощная wiki-платформа с поддержкой Markdown, WYSIWYG, LDAP, Git backend и множеством источников аутентификации. | [https://wiki.js.org](https://wiki.js.org) `npm install -g wiki.js` или Docker |
| **TiddlyWiki** | Однофайловая нелинейная система заметок. Полностью автономна, расширяема через плагины. | [https://tiddlywiki.com](https://tiddlywiki.com) Скачать HTML-файл или `npm install -g tiddlywiki` для сервера |

| Инструмент | Особенности | Установка |
|------------|-------------|-----------|
| **Typora** | WYSIWYG-редактор Markdown. Простой интерфейс, экспорт в PDF/HTML. | [https://typora.io](https://typora.io) |

| **Visual Studio Code + плагины** | Редактор с расширениями: **Markdown Preview Enhanced**, **Foam**, **Dendron** — для организации заметок по принципу Zettelkasten. | [https://code.visualstudio.com](https://code.visualstudio.com) Плагины: Marketplace |
| **Neovim / Vim + vimwiki** | Текстовый редактор с вики-режимом: быстрое создание связанных страниц в формате wiki или Markdown. | `sudo apt install neovim` + `Plug 'vimwiki/vimwiki'` |

### 5. Форматы хранения заметок

| Формат | Преимущества |
|--------|--------------|
| **Markdown (.md)** | Человекочитаемый, кроссплатформенный, совместим с Git, легко преобразуется в HTML/PDF. |
| **HTML** | Полная визуальная выразительность, но менее удобен для редактирования вручную. |
| **SQLite** | Используется в CherryTree, Joplin (опционально) — компактное хранение с поддержкой запросов. |
| **JSON / YAML** | Часто используется для метаданных, настроек, синхронизации (например, в Logseq, Obsidian). |
| **Папки с файлами** | Простой и прозрачный подход (Obsidian, Logseq) — заметки остаются под контролем пользователя. |

### 6. Снхронизация и резервное копирование

| Метод | Описание | Поддержка |
|-------|----------|-----------|
| **Git** | Версионирование заметок в Markdown. Подходит для Obsidian, Logseq, Vimwiki. | Ручная настройка или через **Obsidian Git**, **Dendron Publish** |
| **WebDAV** | Протокол для синхронизации файлов. Поддерживается Joplin, CherryTree. | Требует сервер (Nextcloud, ownCloud, Apache) |
| **Dropbox / Google Drive / OneDrive** | Облачное хранение папки с заметками. Подходит для Obsidian, Logseq. | Ручная настройка |
| **End-to-end шифрование** | Защита содержимого на стороне клиента. | Standard Notes, Turtl, Joplin (с опцией шифрования блокнотов) |
