Инструменты для заметок — от **быстрых стикеров** до **баз знаний** с графом связей (PKM). Выбор зависит от того, работаете ли вы один в Markdown, в команде в Notion или на своём сервере.

## Локальные и офлайн

| Инструмент | Описание | Ссылка |
|------------|----------|--------|
| **Joplin** | Markdown, E2E, sync WebDAV/S3 | [joplinapp.org](https://joplinapp.org) |
| **Obsidian** | Локальные `.md`, граф, плагины | [obsidian.md](https://obsidian.md) |
| **Logseq** | Блочные заметки, daily notes, backlinks | [logseq.com](https://logseq.com) |
| **Zettlr** | Академические цитаты, Zettelkasten | [zettlr.com](https://www.zettlr.com) |
| **CherryTree** | Иерархия, rich text, один файл SQLite | [giuspen.com/cherrytree](https://www.giuspen.com/cherrytree/) |

---

## Облачные сервисы

| Инструмент | Сильная сторона |
|------------|----------------|
| **Notion** | Базы данных, шаблоны, коллаборация |
| **OneNote** | Рукопись, Office, бесплатно |
| **Google Keep** | Скорость, напоминания |
| **Simplenote** | Минимализм, open-source клиенты |
| **Standard Notes** | E2E, расширения |
| **Bear** | Markdown на Apple-платформах |

---

## Self-hosted и вики

| Инструмент | Установка |
|------------|-----------|
| **Trilium Notes** | Docker: `zadam/trilium` |
| **Outline** | Команда, RBAC, Markdown |
| **BookStack** | Книги / главы / страницы |
| **Wiki.js** | LDAP, Git backend |
| **TiddlyWiki** | Один HTML-файл или Node |

---

## Редакторы и форматы

| Формат | Плюсы |
|--------|-------|
| **Markdown** | Git, diff, экспорт PDF/HTML |
| **Папки файлов** | Прозрачность (Obsidian, Logseq) |
| **SQLite** | Один файл (CherryTree, Joplin) |

**Синхронизация:** Git, Syncthing, WebDAV, Dropbox — или встроенное облако сервиса. Для секретов — **E2E** (Standard Notes, Joplin с шифрованием).
