# Скриншотеры

**Скриншотер** фиксирует экран или область — для документации, тикетов в Jira, учебных материалов и отчётов об ошибках. Хороший инструмент добавляет **аннотации**, **горячие клавиши** и при необходимости **загрузку по ссылке**.

## Встроенные в ОС

| ОС | Инструмент | Как вызвать |
|----|------------|------------|
| **Windows** | Ножницы / Snipping Tool | `Win + Shift + S` |
| **macOS** | Снимок экрана | `Cmd + Shift + 4` (область), `5` (панель) |
| **Linux (GNOME)** | gnome-screenshot | `PrtSc` / настройки DE |
| **Linux** | Flameshot, Ksnip | `sudo apt install flameshot ksnip` |

---

## Кроссплатформенные

| Инструмент | Сильная сторона | Лицензия |
|------------|-----------------|----------|
| **ShareX** | OCR, GIF, 80+ хостингов, workflow | GPLv3 (Windows) |
| **Flameshot** | Аннотации, CLI, лёгкий GUI | GPL-3.0 |
| **Ksnip** | Редактор, PDF-экспорт | Apache-2.0 |
| **Greenshot** | Быстрый захват Windows | MIT |
| **Lightshot** | Мгновенная ссылка в облако | Проприетарная |

## CLI и автоматизация

```bash
# Linux — scrot
scrot 'shot_%Y-%m-%d.png' -e 'mv $f ~/Screenshots/'

# macOS
screencapture -i ~/Desktop/screenshot.png

# ImageMagick — выбор области

import -window root screenshot.png

```

**PowerShell** (полный экран без стороннего ПО) — через `System.Drawing` и `CopyFromScreen` (см. примеры в разделе автоматизации Windows).
