Раздел собирает **вспомогательное ПО**, которое не попало в узкие категории энциклопедии: архивы, плееры, диагностика, SSH, виртуализация, графика. Ниже — интерактивный каталог; полный список рынка бесконечен, поэтому акцент на проверенных именах.

## Архивы и файлы

| Инструмент | Назначение |
|------------|------------|
| **7-Zip** | 7z/LZMA2, распаковка RAR/ZIP |
| **PeaZip** | Много форматов, шифрование |
| **WinRAR** | RAR (проприетарный формат) |
| **Bulk Rename Utility** | Массовое переименование (Windows) |

---

## Медиа и запись

| Инструмент | Назначение |
|------------|------------|
| **VLC** | Воспроизведение без кодеков, стрим |
| **OBS Studio** | Сцены, стрим, запись экрана |
| **HandBrake** | Перекодирование видео |
| **Audacity** | Аудиомонтаж, эффекты |
| **DaVinci Resolve** | Монтаж и цвет (freemium) |

---

## Система и железо

| Инструмент | Назначение |
|------------|------------|
| **Everything** | Поиск по NTFS (Windows) |
| **Process Explorer / Sysinternals** | Процессы, DLL, автозагрузка |
| **HWiNFO / CrystalDiskInfo** | Датчики, SMART дисков |
| **VirtualBox / VMware Player** | Виртуальные машины |
| **Rufus / Balena Etcher** | Загрузочные USB из ISO |
| **CCleaner** | Очистка (осторожно с реестром) |
| **Ditto** | Расширенный буфер обмена |
| **AutoHotkey** | Макросы и горячие клавиши (Windows) |
| **f.lux** | Цветовая температура экрана |
