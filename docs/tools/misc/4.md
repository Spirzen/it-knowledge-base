# Геоинформационные системы

<div class="article-tags">
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>
  <span class="tag tag-beginner">ДЛЯ НОВИЧКОВ</span>

**ГИС** (геоинформационные системы) собирают, хранят и анализируют пространственные данные: карты, координаты, зоны, маршруты. Стек обычно делится на **десктоп**, **сервер публикации**, **веб-клиент** и **скрипты обработки**.

## Десктоп open-source

| Инструмент | Назначение | Установка |
|------------|------------|-----------|
| **QGIS** | Универсальная ГИС, плагины Python | [qgis.org](https://qgis.org) · `sudo apt install qgis` |
| **GRASS GIS** | Гидрология, рельеф, моделирование | [grass.osgeo.org](https://grass.osgeo.org) |
| **gvSIG** | CAD/GIS, 3D | [gvsig.com](https://www.gvsig.com) |

---

## Коммерция и веб-платформы

| Инструмент | Назначение |
|------------|------------|
| **ArcGIS Pro** | Esri: 2D/3D, ML, ArcGIS Online |
| **Global Mapper** | LiDAR, 3D, дроны |
| **Mapbox / CARTO** | Кастомные карты и аналитика |
| **Kepler.gl** | Визуализация больших GeoJSON/CSV |
| **Google Earth Engine** | Спутниковые ряды, JavaScript/Python API |

---

## Серверы и библиотеки

| Компонент | Роль |
|-----------|------|
| **GeoServer / MapServer** | WMS, WFS, публикация слоёв |
| **PostGIS** | Геометрия в PostgreSQL |
| **Leaflet / OpenLayers** | Карта в браузере |
| **GDAL / PROJ** | Конвертация и проекции |
| **GeoPandas / Folium** | Анализ и карты в Python |

---

## Форматы

| Формат | Комментарий |
|--------|-------------|
| **GeoPackage (.gpkg)** | Рекомендуемый OGC-контейнер (SQLite) |
| **GeoJSON** | Веб, простой обмен |
| **Shapefile** | Устарел, но повсеместен |
| **GeoTIFF** | Растры, ДЗЗ |
| **MBTiles** | Тайлы для Mapbox/TileServer |

**ETL:** FME, WhiteboxTools, Orfeo Toolbox — для тяжёлой обработки растров и LiDAR.
