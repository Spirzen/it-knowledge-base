# Офис

<div class="article-tags">
  <span class="tag tag-notrequired">НЕ ОБЯЗАТЕЛЬНО</span>

Офисные приложения предназначены для создания, редактирования, форматирования и совместной работы с текстовыми документами, таблицами, презентациями, базами данных и другими типами офисной документации. Ниже приведены основные категории и инструменты.

---

### 1. Полнофункциональные офисные пакеты

| Название | Описание | Установка / Ссылка |
|----------|----------|---------------------|
| **Microsoft Office** | Коммерческий офисный пакет: Word (текст), Excel (таблицы), PowerPoint (презентации), Outlook (почта), Access (БД), OneNote (заметки). | [https://www.microsoft.com/office](https://www.microsoft.com/office) |
| **LibreOffice** | Свободный офисный пакет с открытым исходным кодом: Writer, Calc, Impress, Draw, Base, Math. Поддерживает форматы Microsoft Office. | `sudo apt install libreoffice`, [https://www.libreoffice.org/](https://www.libreoffice.org/) |
| **Apache OpenOffice** | Бесплатный офисный пакет с аналогичными компонентами (Writer, Calc и др.). Активность проекта снижена, но он остаётся стабильным. | [https://www.openoffice.org/](https://www.openoffice.org/) |
| **OnlyOffice Desktop Editors** | Современный офисный пакет с высокой совместимостью с MS Office, поддержкой совместного редактирования и интеграцией с облаками. | `sudo apt install onlyoffice-desktopeditors` (через репозиторий), [https://www.onlyoffice.com/](https://www.onlyoffice.com/) |
| **WPS Office** | Коммерческий (с бесплатной версией) пакет с интерфейсом, максимально приближённым к Microsoft Office. Доступен для Windows, Linux, macOS, Android, iOS. | [https://www.wps.com/](https://www.wps.com/) |

### 2. Текстовые редакторы и процессоры

| Название | Описание | Установка / Ссылка |
|----------|----------|---------------------|
| **Microsoft Word** | Стандарт де-факто для создания и редактирования текстовых документов. | Входит в состав Microsoft Office |
| **LibreOffice Writer** | Мощный текстовый процессор с поддержкой стилей, оглавлений, шаблонов и макросов. | Входит в LibreOffice |
| **AbiWord** | Лёгкий текстовый процессор с поддержкой RTF, DOC, ODT. | `sudo apt install abiword`, [http://www.abisource.com/](http://www.abisource.com/) |
| **FocusWriter** | Минималистичный редактор для писателей с режимом полного экрана и таймером. | `sudo apt install focuswriter`, [https://gottcode.org/focuswriter/](https://gottcode.org/focuswriter/) |
| **Typora** | Markdown-редактор с живым предпросмотром (до версии 1.0 — бесплатный). | [https://typora.io/](https://typora.io/) |
| **Zettlr** | Открытый Markdown-редактор для исследователей и академических писателей. | [https://www.zettlr.com/](https://www.zettlr.com/) |

### Примечания

- Все перечисленные open-source решения (LibreOffice, OnlyOffice, AbiWord и др.) доступны для установки в Linux через системные репозитории или Flatpak/Snap.
- Microsoft Office официально не поддерживается в Linux, но может запускаться через Wine или в виртуальной машине.
- Для максимальной совместимости с документами в формате `.docx`, `.xlsx`, `.pptx` рекомендуется использовать OnlyOffice или LibreOffice версии 7.0+.
- Облачные решения требуют постоянного подключения к интернету, тогда как локальные приложения работают автономно.
