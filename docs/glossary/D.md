## DWG

DWG - бинарный формат файла, используемый для хранения двухмерных (2D) и трёхмерных (3D) проектных данных и метаданных.
Является основным форматом для некоторых САПР-программ (прямая поддержка — например, AutoCAD, CorelCAD, BricsCAD, nanoCAD, IntelliCAD и его вариации, Caddie).

## DXF

DXF - открытый формат файлов для обмена графической информацией между приложениями САПР. Был создан фирмой Autodesk для системы AutoCAD.
