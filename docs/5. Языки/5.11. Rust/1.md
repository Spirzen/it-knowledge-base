Какие возможности предоставляет Rust?
	- *писать код, который работает почти так же быстро, как C/C++, но с современными абстракциями*;
	- *обеспечивать безопасность памяти на уровне компиляции: отсутствие дублированных ссылок, использование после освобождения, гонки данных*;
	- *использовать модель владения (ownership) и заимствования (borrowing), чтобы автоматически управлять временем жизни объектов*;
	- *использовать для написания драйверов, ядер, микроконтроллеров, firmware и других низкоуровневых решений*;
	- *взаимодействовать с C/C++, Python, JavaScript, Ruby и другими через FFI (Foreign Function Interface)*;
	- *использовать для создания сетевых протоколов, серверов, клиентов, API, транспортных слоёв*;
	- *использовать в блокчейне, криптографии, безопасных коммуникациях благодаря своей предсказуемости и отсутствию runtime-угроз*;
	- *собирать под разные архитектуры и операционные системы без изменения логики*;
	- *использовать в Kubernetes, контейнерах, serverless-архитектурах, Docker, WebAssembly*.

## Знаки препинания

Два важных вопроса, которые мучают начинающих программистов:
1. Когда использовать кавычки двойные (`"`), одинарные (`'`), а когда апострофы (`’`)?
2. Когда использовать точки (`.`), запятые (`,`) и точку с запятой (`;`)?

Двойные (`"`) — строки (`&str` или `String`):
```
let name = "Alice";
```
Одинарные (') — для литералов типа char:
```
let c = 'A';
```
Апострофы (`’`) — не поддерживаются.
Точка (`.`) используется для доступа к методам и полям структур:
```
struct Point { x: i32, y: i32 }
let p = Point { x: 1, y: 2 };
println!("x: {}", p.x);
```
Запятая (`,`) для разделения полей, аргументов, элементов массива:
```
let arr = [1, 2, 3];
fn greet(name: &str, age: u8) {}
```
Точка с запятой (;) обязательна после большинства выражений:
```
let x = 5;
println!("Hello");
```

В Rust нижние подчеркивания имеют больше применений.
`_name` - соглашение, что переменная не используется, предотвращая предупреждение компилятора:
```
let _logger = "unused";
```
Приватность в Rust обозначается через pub/pub(crate), не через `_`.
`_` может использоваться для полного игнорирования:
```
let (x, _, z) = (1, 2, 3);
```
в числах:
```
let million = 1_000_000;
```
и как плейсхолдер в матчинге совпадений:
```
match value {
    1 => println!("one"),
    _ => println!("something else"), // default
}
```
В Rust у символа «`|`» есть две роли:

1. Побитовое ИЛИ:
```
let x = 5 | 3; // 7
```
2. Замыкания (closures) - параметры прячут в `|…|` :
```
vec.iter().map(|x| x * 2)
```
Здесь `|x|` является началом и концом списка параметров замыкания.

`||` же обычное логическое ИЛИ:
```
if a || b {
    ...
}
```
