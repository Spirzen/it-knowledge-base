# 5.14. Старые языки

# Раздел в разработке

# Ассемблер

## История языка

```
Ассемблер
История языка
Появился в 1940–50-х годах как прямой способ управления процессором.
Первый уровень абстракции над машинным кодом (0 и 1).
Разные диалекты для разных архитектур (x86, ARM, MIPS и т.д.).
Используется там, где нужен максимальный контроль над железом: ОС, драйверы, embedded, оптимизация.
Как у него дела сейчас?

```

## Основы языка

```
Что собой представляет Ассемблер?
Основы языка
Синтаксис
Символические мнемоники вместо байтов (MOV, ADD, JMP и т.п.).
Прямое соответствие инструкциям процессора.
Нет высокоуровневых конструкций: всё — регистры, память, метки.
```

## Архитектура
```
Архитектура языка и среды Ассемблера
Тесно связана с архитектурой CPU.
Регистры (AX, BX, CX, DX и т.д.), стек, флаги.
Сегментированная или плоская модель памяти.
```

## Типы данных
```
Блоки памяти
Нет типов в классическом смысле.
Байты, слова, двойные слова — как блоки памяти.
Интерпретация зависит от контекста (например, MOV может работать с числами, адресами, символами).

```

## Управляющие конструкции и операторы

```
Управляющие конструкции и операторы
Условные переходы (JZ, JNZ, JE, JNE).
Циклы через метки и декремент с проверкой.
Вызовы подпрограмм (CALL/RET).

```

## Функции

```
Функции
Подпрограммы
Подпрограммы реализуются через CALL и RET.
Передача параметров — через регистры или стек.
Сохранение контекста (PUSH/POP) — вручную.

```

# Си

## История языка Си
```
История языка Си
Разработан Деннисом Ритчи в Bell Labs (1972) для создания UNIX.
Эволюция из B и BCPL.
ANSI C (1989), C99, C11, C17 — стандарты.
Фундамент для C++, Objective-C, Rust, Go и многих других.
```

## Основы языка
```
Основы языка Си
Что собой представляет Си?
Синтаксис
Процедурный, компилируемый, низкоуровневый.
Минимализм: мало ключевых слов, максимум контроля.
Ручное управление памятью (malloc/free).

```

## Архитектура

```
Архитектура Си
Линейная компиляция: препроцессор → компилятор → линковщик.
Модульность через .h и .c файлы.
Прямой доступ к памяти через указатели.

```

## Типы данных
```
Типы данных Си
Примитивы: int, char, float, double, void.
Производные: массивы, указатели, структуры (struct), объединения (union).
Нет строк — только массивы символов.

```

## Управляющие конструкции и операторы

```
Управляющие конструкции и операторы Си
if, else, switch, for, while, do-while.
Операторы: арифметические, логические, побитовые, условные (?:).

```

## Функции

```
Функции Си
Все функции глобальные.
Поддержка рекурсии.
Параметры передаются по значению (по указателю — для изменения).
Нет перегрузки.

```

# Fortran

## История языка Fortran

```
История языка Fortran
Первый высокоуровневый язык (1957, IBM).
Сокращение от FORmula TRANslation.
Ключевой язык в научных вычислениях, физике, инженерии.
Версии: FORTRAN I, IV, 77, 90, 95, 2003, 2008, 2018.

```

## Основы языка

```
Основы языка Fortran
Что собой представляет Fortran
Синтаксис
Ориентирован на математические вычисления.
Поддержка многомерных массивов «из коробки».
Процедурный, с элементами ООП (с Fortran 2003).

```

## Архитектура

```
Архитектура Fortran
Программа состоит из программных единиц: PROGRAM, SUBROUTINE, FUNCTION, MODULE.
Модули — способ организации кода и инкапсуляции данных.

```

## Типы данных

```
Типы данных Fortran
Числовые: INTEGER, REAL, DOUBLE PRECISION, COMPLEX.
Логический: LOGICAL.
Символьный: CHARACTER(len=...).
Поддержка пользовательских типов (TYPE).

```

## Управляющие конструкции и операторы

```
Управляющие конструкции и операторы Fortran
IF-THEN-ELSE, DO цикл (счётчик), DO WHILE.
Современный синтаксис (с Fortran 90): END IF, END DO.
Операторы: математические, логические, операции с массивами.

```

## Функции

```
Функции Fortran
Подпрограммы: FUNCTION (возвращает значение), SUBROUTINE (нет возврата).
Поддержка рекурсии (с RECURSIVE).
Передача параметров по ссылке.

```

# Visual Basic

## История языка

```
BASIC (1964, Dartmouth College) — создан для обучения.
как BASIC стал VB.
Microsoft адаптировала его: QuickBASIC, QBasic, затем Visual Basic (VB) в 1991 — GUI-революция.
VB.NET — часть .NET Framework (2002), полностью переработан, объектно-ориентированный.
VB6 остался популярным в legacy-системах.
```

## Основы языка

```

Основы языка
Basic
Visual Basic
VB.NET
Простой синтаксис, ориентированный на новичков.
Визуальное программирование (drag-and-drop форм).
VB.NET — полноценный ООП, сборка мусора, работа с .NET.
```

## Архитектура

```
Архитектура
VB6: COM-ориентированная, событийная модель.
VB.NET: объектно-ориентированная, работает на CLR (.NET).
WinForms, WPF, ASP.NET — фреймворки для UI.
```

## Типы данных

```

Типы данных
Integer, String, Double, Boolean, Date, Object.
В VB.NET — полная типизация, Nullable, Generics.

```

## Управляющие конструкции и операторы

```
Управляющие конструкции и операторы
If...Then...Else, Select Case, For...Next, While...End While, Do...Loop.
Операторы: арифметические, сравнения, конкатенации (&).

```

## Функции

```
Функции
Function (возвращает значение), Sub (не возвращает).
Поддержка событий (Event, RaiseEvent).
В VB.NET — ООП: классы, наследование, интерфейсы.

```

#Cobol

## История языка

```
История языка Cobol
Создан в 1959 году (COmmon Business-Oriented Language).
Разработан для бизнеса, финансов, административных систем.
До сих пор используется в банках, правительствах (legacy-системы).
Очень много строк кода на COBOL — миллиарды.
```

## Основы языка

```
Основы языка Cobol
Англоязычный синтаксис (почти как текст).
Четыре основных раздела: IDENTIFICATION, ENVIRONMENT, DATA, PROCEDURE.
Процедурный, сильно структурированный.

```

## Архитектура

```
Архитектура Cobol
Программа делится на логические отделы.
Работает в основном на мейнфреймах (IBM z/OS).
Обработка больших объёмов данных (batch processing).

```

## Типы данных

```
Типы данных
PIC (PICTURE) — описание формата данных: цифры, символы, десятичные.
Пример: PIC 9(5) — целое из 5 цифр, PIC X(20) — строка из 20 символов.
Групповые записи (GROUP ITEM).

```

## Управляющие конструкции и операторы

```
Управляющие конструкции и операторы
IF, PERFORM (циклы и вызовы), EVALUATE (аналог switch).
READ, WRITE, OPEN, CLOSE — работа с файлами.
Очень много глаголов: MOVE, ADD, SUBTRACT, MULTIPLY, DIVIDE.

```

## Функции

```

Функции
Параграфы и секции (PARAGRAPH, SECTION) — аналоги функций.
PERFORM позволяет вызывать параграфы.
Нет настоящих функций с возвратом значения (в старых версиях).

```

# Pascal

## История языка

```
История языка Pascal
Создан Никлаусом Виртом (1970) как учебный язык.
Назван в честь Блеза Паскаля.
Турбо Паскаль (Borland, 1983) — популяризировал его.
Delphi (Object Pascal) — развитие для Windows-приложений.

```

## Основы языка
```
Основы языка Pascal
Строгая типизация, чёткая структура.
Хорош для обучения алгоритмам и структурам данных.
Поддержка модулей, процедур, функций.

```

## Архитектура

```
Архитектура Pascal
Программа: program, uses, var, begin...end.
Разделение на объявления и тело.
Delphi — компонентно-ориентированное программирование (VCL).

```

## Типы данных

```
Типы данных Pascal
Простые: integer, real, boolean, char.
Составные: array, record, set, file.
Перечисления, диапазоны (1..10).
Указатели (но безопаснее, чем в C).

```

## Управляющие конструкции и операторы

Управляющие конструкции и операторы Pascal

## Функции

Функции Pascal
function (возвращает значение), procedure (не возвращает).
Поддержка рекурсии.

# Lisp
## История языка

```
История языка Lisp
Создан Джоном Маккарти (1958) — один из первых языков ИИ.
Сокращение от LISt Processor.
Влияние на функциональное программирование, REPL, метапрограммирование.
Разновидности: Common Lisp, Scheme, Clojure (современный).
Как Lisp повлиял на Clojure, Haskell

```

## Основы языка
```
Основы языка Lisp
Все данные и код — списки (S-выражения).
Префиксная нотация: (+ 1 2).
Homoiconicity: код = данные.
REPL — интерактивная среда.

```

## Архитектура

```
Архитектура Lisp
Основа — список, состоящий из атомов и других списков.
Функции — это данные (first-class citizens).
Макросы позволяют писать код, генерирующий код.

```

## Типы данных

```
Типы данных Lisp
Атомы: числа, символы, строки, nil.
Списки: (a b c), вложенные списки.
Конс-ячейки (cons cells) — базовая структура.
Динамическая типизация.

```

## Управляющие конструкции и операторы

```
Управляющие конструкции и операторы Lisp
if, cond (многоусловие), let (локальные переменные).
Циклы: loop, do, dolist, или через рекурсию.
Операторы: +, -, *, /, eq, equal, car, cdr, cons.

```

## Функции

```
Функции Lisp
defun — определение функции.
Анонимные функции: lambda.
Функции высшего порядка: mapcar, apply, funcall.
Замыкания.

```
