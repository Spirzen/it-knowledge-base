# 1.13. Софт продвинутого пользователя

```
Внимание! Легкотня!	
Скорее всего, вы уже знакомы со всем, что здесь перечислено, и вряд ли подчеркнёте для себя что-то новое. Но если найдёте новинки – значит, читали не зря!

```

Продвинутые пользователи, разработчики, системные администраторы и IT-специалисты используют узкоспециализированные программы для работы. Мы разберём мощные инструменты для управления системой, разработки, анализа данных и автоматизации. Продвинутыми пользователями можно считать тех, кто не просто использует компьютер для повседневных задач, таких как просмотр сайтов или работа с документами, но и активно применяет специализированные инструменты для выполнения сложных операций. 

Их задачи варьируются от написания кода и управления серверами до создания 3D-моделей, автоматизации бизнес-процессов и защиты данных. 

Чтобы решать эти задачи, им нужны мощные программы, которые предлагают больше контроля, гибкости и функциональности, чем стандартный софт.

## Файловые менеджеры и утилиты

Файловые менеджеры и утилиты — это инструменты для эффективной работы с файлами и дисками. Продвинутые пользователи часто выбирают Total Commander за его двухпанельный интерфейс, который позволяет быстро перемещаться между папками, работать с FTP-серверами и управлять архивами. 

Задачи могут быть разными - управление каталогами и файлами, поиск данных и использование дискового пространства.

- Total Commander – альтернатива Проводнику Windows, обладает двухпанельным интерфейсом, FTP-клиентом, и позволяет работать с архивами;
- FileSeek – позволяет выполнять быстрый поиск по содержимому файлов (включая текстовые документы);
- TreeSize Free – анализирует занятое место на диске и показывает, Какие папки «съедают» больше всего места в хранилище.

```
Практическое задание
Проанализируйте свой жесткий диск при помощи TreeSize.
Попробуйте установить Total Commander.
```

## Разработка и программирование

Для разработчиков часто есть выбор правильного инструмента, с учётом привычек и используемых технологий. VS Code сталодним из самых популярных редакторов благодаря своей лёгкости, поддержке множества языков программирования и расширений. Однако расширения требуют ресурсов, а в части ресурсов полегче может быть Notepad++ - отлично подходит для работы с большими текстовыми файлами, такими как логи и дампы. Но это лишь редакторы текста, которые лишь оснащены автодополнением и подсветкой синтаксиса. 

Для полноценной разработки используют IDE - интегрированные среды разработки, которые предоставляют все необходимые инструменты для создания сложных проектов. Можно выделить и СУБД, которые позволяют работать с базами данных через графический интерфейс, но мы отдельно изучим это всё - и СУБД, и IDE. Сейчас просто приведём примеры такого софта:

- VS Code (Visual Studio Code) – лёгкий, мощный редактор кода от Microsoft, поддерживает кучу языков и расширений (Python, JavaScript, C++);
- Notepad++ - улучшенный блокнот с подсветкой синтаксиса, позволяет работать даже с большими файлами, логами, дампами;
- Visual Studio – IDE (интегрированная среда разработки) для C#;
- NetBeans – IDE для Java;
- DB Browser for SQLite – графический интерфейс для работы с базами SQLite.

```
Практическое задание
Установите себе Notepad++.
Важно - его не так просто достать, как кажется.
```

## Графика, дизайн и 3D

Профессионалы в области графики и дизайна используют специализированные программы, которые позволяют воплощать их творческие идеи в жизнь, или выполнять задачи по заказу. Все мы помним «фотошоп» — это Adobe Photoshop, один из самых популярных профессиональных графических редакторов, и он является частью Adobe Creative Cloud. Вообще, профессиональное программное обеспечение характерно своей целевой аудиторией - людьми, которые будут зарабатывать на использовании этих программ. Поэтому они в основном платные, или распространяются по подписке, к примеру, тот же Adobe или Visio для построения схем и диаграмм. 

Но есть и бесплатные альтернативы, такие как Draw.io. 3D-модели формируются в различных программах, но сейчас самой популярной является Blender.


Скриншотеры - отдельная история. В Windows есть стандартный инструмент «Ножницы», а Яндекс.Браузер предоставляет свой скриншотер. Но среди подобного софта рекомендуется использовать Greenshot - очень удобная программа со встроенным графическим редактором, позволяющим красиво оформить итоговое изображение.

- Adobe Creative Cloud – собирательный пакет инструментов Adobe – Photoshop, Illustrator, Premiere Pro – профессиональные инструменты для дизайнеров;
- Blender – бесплатный 3D-редактор для моделирования, анимации и рендеринга;
- Greenshot – удобный скриншотер со встроенным графическим редактором;
- Visio – инструмент для создания схем, диаграмм и блок-схем;
- Draw.io – альтернатива Visio.

```
Практическое задание
Установите себе Greenshot.
Попробуйте сделать скриншот области экрана.
Добавьте стрелочку во встроенном редакторе.

```

## Сетевые и системные утилиты

Сетевые и системные утилиты — это инструменты, которые помогают анализировать и управлять сетевыми соединениями, а также тестировать API. Wireshark позволяет заглянуть внутрь сетевого трафика, выявляя проблемы с подключением или уязвимости безопасности. PuTTY и KiTTY используются для удалённого управления серверами через SSH, что особенно важно для системных администраторов. Postman помогает тестировать API, отправляя HTTP-запросы и проверяя ответы. Nmap сканирует сеть, находя открытые порты и активные устройства. 

Существуют и прочие комплексные решения, но концепция общая - диагностика проблем, настройка серверов и обеспечение безопасности сети.

- Wireshark – анализатор сетевого трафика (для диагностики соединений);
- PuTTY / KiTTY – SSH-клиент для удалённого управления серверами;
- Postman – тестирование API и отправка HTTP-запросов;
- Nmap – сканирование сети, поиск открытых портов.

## Автоматизация и бизнес-процессы

Автоматизация неразрывно связана со сферой IT, и является ключом к повышению эффективности в современном мире. Стандартные операции в системе можно автоматизировать, сделав автоматический запуск программ (скриптов) по расписанию через планировщики задач - к примеру, скрипты резервного копирования - полезно для регулярных задач. 

Автоматизированные сценарии между различными сервисами, к примеру, отправка уведомлений на сервер, позволяют упростить управление этими сервисами. В части автоматизации мы ещё поговорим о сферах применения. Главная особенность современного бизнеса - создание платформ для автоматизации бизнес-процессов, таких как обработка обращений, регистрация документов, оформление отпусков. 

Такие бизнес-процессы формируются и проектируются в специальных схемах, используя нотации, такие как BPMN - их создают через специальные программы, вроде Camunda. Об этом мы тоже поговорим позднее.

- Camunda – платформа для автоматизации по BPMN;
- Task Sheduler (Планировщик задач Windows) – настройка автоматического запуска скриптов и программ;
- Power Automate (Microsoft) – создание автоматизированных сценариев между сервисами.

## Безопасность и администрирование

Защита данных и управление системой включают в себя несколько категорий. Менеджеры паролей хранят учётные данные в зашифрованном виде, предотвращая утечки. Продвинутые аналоги диспетчеров задач позволяют глубже анализировать процессы и ресурсы системы. 
А шифрование — это ключевой аспект безопасности, позволяя таким образом обеспечивать защиту конфиденциальной информации файлов.

- KeePass и Bitwarden – менеджеры паролей с шифрованием;
- Process Hacker – продвинутый аналог диспетчера задач;
- Gpg4win – шифрование файлов и электронной почты.

```
Практическое задание
Установите себе KeePass.
Попробуйте создать базу данных с паролями.
Установите для базы мастер-пароль.
```

## Виртуализация и работа с ОС

Виртуализация позволяет запускать несколько операционных систем на одном компьютере, что полезно для тестирования программ и разработки. Существуют программные решения для создания виртуальных машин (ВМ). 

Контейнеризация приложений - сложная тема, мы её обсудим отдельно. 

В части операционной системы, особенно касаясь установки, нельзя пройти мимо инструментов для создания загрузочных USB-накопителей, что необходимо знать. Всё это - программы для оптимизации рабочего процесса и экспериментов с различными средами без риска повредить основную систему. 

Можно установить виртуальную машину на свою основую систему без риска её повреждения.

- VirtualBox / VMware Workstation / Hyper-V – запуск виртуальных машин;
- Docker – контейнеризация приложений для разработки и деплоя;
- Rufus – создание загрузочных USB для установки ОС.

## Дополнительные полезные инструменты

Помимо специализированного софта, существуют универсальные инструменты, которые упрощают работу. Их множество, и это даже без рассмотрения отдельного прикладного ПО, вроде геоинформационных систем или средств проектирования. Хотелось бы отметить приложения для создания профессиональных руководств и документации, что может пригодиться для разработчиков и технических писателей, а также приложение для записи экрана и стриминга, что может пригодиться для создания обучающих видео или трансляций. 

Кроме этого, для ускорения работы с большими объемами данных можно использовать программу для мгновенного поиска файлов по имени.

- DrExplain – создание документаций и руководств;
- Everything – мгновенный поиск файлов на компьютере (по имени);
- OBS Studio – запись экрана и стриминг.

У вас список такого ПО может расширяться, вы можете находить новые аналоги, и это самое важное - чем больше программ вы освоите, тем более «продвинутый» вы будете пользователь.
