# 1.12. Итоги 

Безопасность:
	- Установка программ только с официальных источников;
	- Регулярное резервное копирование данных;
	- Использование антивирусной защиты.
 
Производительность:
	- Контроль автозагрузки программ;
	- Регулярная очистка системы;
	- Обновление программного обеспечения.
 
Три основных правила хорошего пользователя:
1. Поддерживайте порядок в файлах и папках.
2. Регулярно делайте backup важной информации.
3. Избегайте потенциально опасных действий.

Три фундаментальных момента:
	- Правильная организация файловой системы экономит время;
	- Горячие клавиши значительно ускоряют работу;
	- Регулярное обслуживание системы предотвращает проблемы.
