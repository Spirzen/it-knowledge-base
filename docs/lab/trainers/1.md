## JSX-песочница

Ниже — встроенный редактор **live-кода** на React: можно быстро проверить идею на JavaScript и увидеть результат под блоком кода.

---

### Правила и ограничения

- Общий принцип: всё, что укажем в `return`, будет выведено ниже. Примеры — **React-компоненты**, потому что так работает режим `live`: нужна функция, возвращающая JSX, строку, число или массив.

- Работает: `React`, `useState`, `useEffect`, `window`, `location`, `URL`, `Date`, `Math`, `JSON`, `Intl`, `Array.prototype.*`, `String.prototype.*`.

- Не работает: `console.log()` (не отображается), `import` / `require`, `fetch` (ограничен CORS), специфика Node.js.

- Код исполняется только у вас — в браузере.

#### 4. Парсинг URL-параметров

```jsx live
function URLParams() {
  const search = new URLSearchParams(window.location.search);
  const params = {};
  for (let [key, value] of search) {
    params[key] = value;
  }
  return Object.keys(params).length > 0 ? (
    <div>
      <b>Параметры URL:</b>
      <pre>{JSON.stringify(params, null, 2)}</pre>
    </div>
  ) : (
    <div>Нет параметров в URL (попробуйте: <code>?debug=true&lang=ru</code>)</div>
  );
}
```

#### 6. Работа с массивами

```jsx live
function ArrayDemo() {
  const numbers = [3, 1, 4, 1, 5, 9];
  return (
    <div>
      <p>Исходный: <code>[{numbers.join(', ')}]</code></p>
      <p>Отсортирован: <code>[{[...numbers].sort((a, b) => a - b).join(', ')}]</code></p>
      <p>Квадраты: <code>[{numbers.map(x => x * x).join(', ')}]</code></p>
      <p>Сумма: <b>{numbers.reduce((s, x) => s + x, 0)}</b></p>
    </div>
  );
}
```

#### 7. Счётчик (состояние)

```jsx live
function Counter() {
  const [count, setCount] = React.useState(0);
  return (
    <div style={{ fontFamily: 'sans-serif' }}>
      <p style={{ fontSize: '1.2em', margin: '8px 0' }}>
        Счётчик: <b style={{ color: '#7B68EE' }}>{count}</b>
      </p>
      <button
        style={{
          padding: '6px 16px',
          margin: '4px',
          backgroundColor: '#7B68EE',
          color: 'white',
          border: 'none',
          borderRadius: '6px',
          cursor: 'pointer',
        }}
        onClick={() => setCount(c => c + 1)}
      >
        +1
      </button>
      <button
        style={{
          padding: '6px 16px',
          margin: '4px',
          backgroundColor: '#ccc',
          border: 'none',
          borderRadius: '6px',
          cursor: 'pointer',
        }}
        onClick={() => setCount(0)}
      >
        Сброс
      </button>
    </div>
  );
}
```
