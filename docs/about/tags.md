# Система тегов в статьях

На многих страницах энциклопедии вы увидите блок с тегами, который помогает быстро понять статус и целевую аудиторию материала.

## ОБЯЗАТЕЛЬНО {#required}

Тег **ОБЯЗАТЕЛЬНО** означает, что материал критически важен для понимания темы и рекомендуется к прочтению каждому, кто изучает соответствующий раздел.

## ДЛЯ НОВИЧКОВ {#beginner}

Тег **ДЛЯ НОВИЧКОВ** помечает материалы, которые особенно полезны на старте: они написаны проще, дают базовый уровень, помогают сформировать интуицию.

## НЕ ДЛЯ НОВИЧКОВ {#advanced}

Тег **НЕ ДЛЯ НОВИЧКОВ** означает, что текст предполагает уже знакомство с основами и может быть сложен при первом знакомстве с темой.

## НЕ ОБЯЗАТЕЛЕН {#notrequired}

Тег **НЕ ОБЯЗАТЕЛЕН** помечает дополнительные материалы: они расширяют кругозор и дают полезный контекст, но не являются строго обязательными для понимания основ.

## В РАЗРАБОТКЕ {#inprogress}

Тег **В РАЗРАБОТКЕ** означает, что статья или раздел ещё дополняется и может меняться: структура и формулировки не окончательные.
