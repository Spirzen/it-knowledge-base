# 3.04. Итоги 

Основные категории форматов:
	- XML: сложный и структурированный;
	- JSON: простой и универсальный;
	- YAML: свободный синтаксис с отступами;
	- Markdown: легкий язык разметки для форматирования текста.

Три основных правила работы с конфигурациями:
1. Следуйте правилам форматирования.
2. Используйте валидаторы для проверки.
3. Документируйте сложные конфигурации.

Три фундаментальных момента:
	- Каждый формат имеет свои правила синтаксиса;
	- Правильное форматирование критически важно для работы;
	- Читаемость конфигураций влияет на поддерживаемость кода.
