# Раздел в разработке

```
Анализ данных
Данные в аналитике
Диаграммы и сводка
OLTP (On-Line Transaction Processing)
OLTP — это система обработки транзакций в режиме реального времени. Она предназначена для работы с операционными данными, то есть теми данными, которые постоянно изменяются и используются в повседневной деятельности бизнеса.
OLAP (On-Line Analytical Processing)
OLAP — это система аналитической обработки данных. Она предназначена для выполнения сложных аналитических запросов и работы с большими объемами данных.

Power BI
```
