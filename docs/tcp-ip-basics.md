# Основы TCP/IP

TCP/IP — это стек протоколов, используемый в интернете. Он состоит из четырёх уровней:

1. **Сетевой интерфейс** (физический и канальный)
2. **Интернет-уровень** (IP)
3. **Транспортный уровень** (TCP, UDP)
4. **Прикладной уровень** (HTTP, FTP, DNS)

## Пример: Как работает HTTP-запрос

1. Браузер определяет IP по доменному имени через DNS.
2. Устанавливается TCP-соединение (three-way handshake).
3. Отправляется HTTP-запрос.
4. Сервер отвечает.
5. Соединение закрывается.
