# Вселенная IT  
**Открытая образовательная энциклопедия по информационным технологиям**

> Статический сайт-база знаний, реализованный на [Docusaurus 2](https://docusaurus.io/).  
> Цель проекта — систематизировать знания по IT в единую, непротиворечивую и проверяемую модель, пригодную как для обучения, так и для профессионального справочного использования.

---

## Технологическая основа

- **Сборка**: Docusaurus 2 (React-based, SSR, SSG)  
- **Источник контента**: Markdown/MDX файлы, расположенные в `/docs`  
- **Рендеринг**: клиентский (hydration) + предварительная генерация HTML (SSG)  
- **Деплой-таргет**: статический хостинг (GitHub Pages, Vercel, Netlify и др.)  
- **Сборка**: `@docusaurus/core`, с кастомизацией через `docusaurus.config.js`, `sidebars.js`, CSS Modules и собственные React-компоненты  

### Используемые компоненты и расширения

| Категория               | Используемые средства                                          |
|-------------------------|----------------------------------------------------------------|
| **Кастомизация UI**     | `src/css/custom.css`, `src/pages/index.module.css`, CSS Modules |
| **Главная страница**    | `src/pages/index.js` + компоненты: `HomepageHeader`, `HomepageTabs`, `HomepageFeatures`, `HomepageStats` |
| **Интерактив**          | `details/summary` для спойлеров, `clsx` для условных классов |
| **Анимация фона**       | `AnimatedBackground` — SVG с динамическим градиентным шумом (без внешних библиотек) |
| **Метаданные статей**   | Front Matter YAML в Markdown-файлах (`sidebar_label`, `tags`, `complexity`, и т.д.) |
| **Стилизация кода**     | Prism.js + темизация под Light/Dark режимы, с поддержкой синтаксиса основных языков (C#, Java, Python, SQL и др.) |
| **Документационная структура** | Hierarchical sidebar, autogenerated table of contents (через `toc.md`) |

## Структура проекта

```
it-knowledge-base/
├── docusaurus.config.js      # Главная конфигурация Docusaurus (мета, темы, плагины)
├── sidebars.js               # Структура боковой панели навигации
├── src/
│   ├── components/           # Переиспользуемые React-компоненты (AnimatedBackground и др.)
│   ├── css/                  # Глобальные CSS-переменные и кастомизация тем
│   └── pages/                # Страницы уровня маршрутизации (включая index.js)
├── docs/                     # Все статьи и структурные файлы
│   ├── section/              # Обзорные страницы разделов (для /section/* маршрутов)
│   ├── encyclopedia/         # Статьи энциклопедии, сгруппированные по главам (1–9)
│   ├── about/                # О проекте, авторе, манифесте
│   ├── tools/                # Практические гайды по инструментам
│   ├── lab/                  # Упражнения, кейсы, планы обучения
│   └── ...                   # glossary, context, philosophy и др.
├── static/                   # Статические ресурсы (изображения, favicon, CNAME и др.)
└── package.json              # Зависимости и скрипты сборки
```

> 💡 Все содержимое генерируется из `docs/`, без внешних CMS. Навигация управляется декларативно через `sidebars.js`.

## Архитектура знаний

Энциклопедия построена на принципе **иерархической декомпозиции и сквозной терминологии**:

1. **Основы** — фундаментальные понятия (информация, программа, интерфейс, сеть)  
2. **Система и сеть** — аппаратура, ОС, сетевой стек, администрирование  
3. **Данные и разметка** — модели данных, СУБД (SQL/NoSQL), форматы (XML/JSON/Markdown/HTML)  
4. **Код и разработка** — инженерное мышление: парадигмы, архитектура, память, отладка  
5. **Языки** — 15+ языков с акцентом на сравнительный анализ и переносимость знаний  
6. **Проект** — ЖЦПО, управление требованиями, документация (в т.ч. по ГОСТ), анализ и тестирование  
7. **Инфраструктура и безопасность** — DevOps, облака, контейнеры, ИБ как сквозной атрибут  
8. **Спин-офф** — смежные дисциплины: исторические фигуры, игры, блокчейн, ИИ, этика  
9. **Для детей (8–16 лет)** — адаптированный ввод в IT без упрощений, с игровой мотивацией и фокусом на мышление разработчика  

Каждый раздел содержит:
- Теоретическую базу (без избыточной формализации)
- Практические гайды и примеры
- Чек-листы самопроверки
- Межразделовые перекрёстные ссылки для навигации по концепциям

## Установка и разработка

### Требования
- Node.js ≥ 18.x  
- npm ≥ 9.x  

### Сборка и запуск

```bash
# Установка зависимостей
npm install

# Локальный dev-сервер (hot-reload)
npm start

# Сборка production-версии
npm run build

# Локальный preview собранного сайта
npm run serve
```

Результат сборки — папка `build/`, содержащая полностью автономный статический сайт (HTML/CSS/JS/изображения), не требующий backend-инфраструктуры.

## Деплой

Поддерживается любой хостинг статики. Настроены CI-скрипты для:

- **GitHub Pages** (`npm run deploy`)  
- **Vercel / Netlify** — через привязку ветки `main` и команду сборки `npm run build`

> Для GitHub Pages необходимо указать `baseUrl: '/'` и `organizationName` / `projectName` в `docusaurus.config.js`.

## Стилизация и дизайн

- **Цветовая схема**:  
  - Light mode: `#7B68EE` (MediumSlateBlue) — акценты  
  - Dark mode: `#9370DB` (MediumPurple) — акценты  
  - Фон: `#FFFFFF` / `#1A1A1A`  
  - Текст: `#2C3E50` / `#E8E8E8`

- **Типографика**: система Docusaurus по умолчанию (системные шрифты + fallback), с включённой лигатурой в коде  
- **Адаптивность**: mobile-first, поддержка экранов от 320px  
- **Доступность**: базовый уровень WCAG (контраст, семантические теги, `aria-*` в компонентах)

CSS вынесен в `src/css/custom.css`, используется CSS-переменные (`--ifm-*`) для переопределения темы Docusaurus.

## Работа с контентом

### Создание статьи

1. Разместите Markdown-файл в нужной подпапке `docs/`  
2. Используйте front matter для управления метаданными:

```md
---
title: Операционная система
sidebar_label: ОС
tags: [ОС, Unix, Windows]
complexity: intermediate
---

# Операционная система

Базовое программное обеспечение...
```

Поддерживаемые метаданные:
- `sidebar_label` — отображаемое имя в сайдбаре  
- `tags` — массив тегов (для фильтрации/индексации)  
- `complexity` — `beginner` | `intermediate` | `advanced` (визуально отображается в интерфейсе)

> Стилизация тегов и сложности реализована через CSS-классы `.tag-*`, `.complexity-badge`.

### Обновление навигации

- Структура сайдбара управляется файлом `sidebars.js`  
- Главное меню — в `docusaurus.config.js` (`navbar.items`)  
- Footer — `footer.links` в том же файле

## Технические ограничения и особенности

- **Нет клиентского поиска** (Algolia отключён; поиск не входит в текущий этап проекта)  
- **Одноязычный контент** (только русский; локализация свёрнута)  
- **Нет авторизации и пользовательских данных** — проект полностью read-only  
- **Все ссылки проверены на актуальность** — использованы relative paths (`/section/basics`) вместо абсолютных  
- **SEO-оптимизация** — мета-теги (`title`, `description`) задаются для каждой страницы через front matter или в компоненте `Layout`
