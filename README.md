# 🌌 Вселенная IT

Красивый и стильный сайт-база знаний "Вселенная IT" на русском языке, созданный с помощью Docusaurus.

## ✨ Особенности

- **🎨 Современный дизайн** с нежными цветами (белый фон, темный шрифт, MediumSlateBlue кнопки)
- **📚 Структурированная база знаний** с 8 основными разделами
- **🔍 Поиск по сайту** (готов к настройке Algolia)
- **🌍 Многоязычность** (русский и английский)
- **🛡️ Безопасность** - только чтение для пользователей
- **📱 Адаптивный дизайн** для всех устройств
- **⚡ Быстрая загрузка** благодаря статической генерации

## 🎨 Кастомизация

### Цветовая схема
Основные цвета определены в `src/css/custom.css`:
- **Основной цвет**: #7B68EE (MediumSlateBlue)
- **Фон**: #FFFFFF (белый)
- **Текст**: #2C3E50 (темно-серый)

### Навигация
Настройка навигации в `docusaurus.config.js`:
- Главное меню
- Сайдбар
- Футер

### Содержание
Структура сайдбара настраивается в `sidebars.js`

## 🔍 Настройка поиска

Для включения поиска необходимо настроить Algolia:

1. Создайте аккаунт на [Algolia](https://www.algolia.com/)
2. Создайте новый индекс
3. Обновите настройки в `docusaurus.config.js`:

```javascript
algolia: {
  appId: 'YOUR_APP_ID',
  apiKey: 'YOUR_SEARCH_API_KEY',
  indexName: 'it-knowledge-base',
  contextualSearch: true,
  searchParameters: {},
  searchPagePath: 'search',
},
```

## 🌍 Локализация

Проект поддерживает русский и английский языки. Файлы локализации находятся в папке `i18n/`.

### Добавление нового языка

1. Создайте папку для языка в `i18n/`
2. Скопируйте файлы из существующей локализации
3. Переведите содержимое
4. Обновите `docusaurus.config.js`

## 📝 Добавление контента

### Новая статья
1. Создайте файл `.md` в соответствующем разделе
2. Добавьте метаданные в начало файла:

```markdown
---
title: Название статьи
sidebar_label: Краткое название
---

# Содержание статьи
```

### Новый раздел
1. Создайте папку в `docs/`
2. Обновите `sidebars.js`
3. Добавьте статьи в раздел
