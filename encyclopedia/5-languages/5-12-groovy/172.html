Встроенные функции в Groovy​

В таблицах ниже — не отдельные "глобальные функции" языка, а методы GDK (Groovy Development Kit): они добавляются к стандартным классам Java (List, String, File, Map) при запуске в среде Groovy. В чистой Java вызов [1,2,3].each { } не скомпилируется.

Полный список: справочник § GDK. Метапрограммирование (metaClass, AST): основы, особенности.

Интерактивное демо — вызов функции и стек на примере JavaScript. В Groovy объявление другое, но вызов, локальные переменные и возврат устроены так же. Обобщённо: функции в коде.
