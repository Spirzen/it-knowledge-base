map, filter и reduce — краткий обзор​

map принимает функцию и итерируемый объект, возвращает итератор с результатами применения функции к каждому элементу:

list(map(lambda x: x ** 2, [1, 2, 3, 4, 5]))  # [1, 4, 9, 16, 25]

filter принимает функцию-предикат и итерируемый объект, возвращает итератор только с теми элементами, для которых предикат истинен:

list(filter(lambda x: x % 2 == 0, range(1, 11)))  # [2, 4, 6, 8, 10]

reduce (модуль functools, не встроенная функция) последовательно сворачивает итератор в одно значение:

from functools import reduce

reduce(lambda x, y: x * y, [1, 2, 3, 4, 5])  # 120

Первый аргумент map и filter может быть любой вызываемый объект — встроенная функция (str, int), обычная def или lambda. Для суммирования и поиска min/max чаще используют встроенные sum(), max(), min().
