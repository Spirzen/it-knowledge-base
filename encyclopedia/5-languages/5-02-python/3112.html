Справочник по Tkinter — элементы UI

СПРАВОЧНИК

Назначение​

Пошаговые рецепты: импорт → создать → разместить → обработчик. Каркас приложения — в Первая программа на Tkinter, теория — 311.md. Готовые примеры с построчным разбором — Tkinter — окна и виджеты. Общие названия элементов — Архитектура десктопных приложений; UI-поток и потоки — 112.md.

Как пользоваться​

  1. Создайте root = tk.Tk() и контейнер (frame = tk.Frame(root)), как в 3111.md.
  2. Найдите нужный элемент ниже, скопируйте блок в свой frame (или root).
  3. В конце файла оставьте root.mainloop().
  4. Для учебных мини-проектов (калькулятор, блокнот, список задач) см. галерею Tkinter в Lab.

Правило: в одном родителе используйте один менеджер — только pack, только grid или только place.

Главное окно​

import tkinter as tk

root = tk.Tk()
root.title("Моё приложение")
root.geometry("640x480")
root.minsize(400, 300)
root.mainloop()

Закрыть программуroot.destroy()
Обработчик крестикаroot.protocol("WM_DELETE_WINDOW", on_close)
Отложенный вызовroot.after(1000, func)

Контейнер (Frame)​

Куда: в root или во вложенный Frame.

frame = tk.Frame(root, padx=12, pady=12)
frame.pack(fill=tk.BOTH, expand=True)

# Группа с рамкой и заголовком
group = tk.LabelFrame(frame, text="Параметры", padx=8, pady=8)
group.grid(row=0, column=0, sticky="ew")

Label (метка)​

Куда: в frame. Импорт: tk.Label.

label = tk.Label(frame, text="Имя пользователя:")
label.grid(row=0, column=0, sticky="w", padx=4, pady=4)

# Динамический текст
status_var = tk.StringVar(value="Готово")
status = tk.Label(frame, textvariable=status_var)
status.pack()
status_var.set("Сохранено")

TextBox — однострочный (Entry)​

Куда: рядом с подписью в frame.

entry = tk.Entry(frame, width=30)
entry.grid(row=0, column=1, padx=4, pady=4)
entry.focus_set()

text = entry.get().strip()
entry.delete(0, tk.END)
entry.insert(0, "значение по умолчанию")

Enter в поле:

entry.bind("<Return>", lambda e: on_submit())

ScrollPane (прокрутка)​

canvas = tk.Canvas(frame)
scrollbar = tk.Scrollbar(frame, orient=tk.VERTICAL, command=canvas.yview)
scroll_frame = tk.Frame(canvas)
scroll_frame.bind("<Configure>", lambda e: canvas.configure(scrollregion=canvas.bbox("all")))
canvas.create_window((0, 0), window=scroll_frame, anchor="nw")
canvas.configure(yscrollcommand=scrollbar.set)
canvas.pack(side=tk.LEFT, fill=tk.BOTH, expand=True)
scrollbar.pack(side=tk.RIGHT, fill=tk.Y)
# Виджеты добавляйте в scroll_frame

Для Text/Listbox часто достаточно scrollbar.config(command=widget.yview) и widget.config(yscrollcommand=scrollbar.set).

Tooltip (подсказка)​

def create_tooltip(widget, text):
    tip = {"win": None}

    def enter(_):
        x, y, _, h = widget.bbox("insert") or (0, 0, 0, 0)
        x += widget.winfo_rootx() + 20
        y += widget.winfo_rooty() + h + 4
        tip["win"] = tw = tk.Toplevel(widget)
        tw.wm_overrideredirect(True)
        tw.geometry(f"+{x}+{y}")
        tk.Label(tw, text=text, bg="#ffffe0", relief=tk.SOLID, borderwidth=1).pack()

    def leave(_):
        if tip["win"]:
            tip["win"].destroy()
            tip["win"] = None

    widget.bind("<Enter>", enter)
    widget.bind("<Leave>", leave)

create_tooltip(btn, "Сохранить документ на диск")
