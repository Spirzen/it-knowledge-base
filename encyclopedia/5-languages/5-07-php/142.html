Встроенные функции в PHP​

Сначала: функции в коде, если вы ещё не разбирали, что такое функция в программе в целом.

Как работать с этим справочником​

Эта статья выглядит как энциклопедический каталог, и это полезный формат для практики. Рабочий подход:

  1. Определите задачу: строки, массивы, сеть, файлы, безопасность.
  2. Возьмите 2-3 функции из нужного раздела.
  3. Сразу соберите маленький пример и проверьте поведение на своих данных.

Полезный порядок изучения для новичка:

  • Синтаксис, операторы и пунктуация в PHP
  • Ключевые слова языка PHP
  • затем уже этот справочник функций

$raw = file_get_contents("php://input");

    echo json_encode(["error" => "email is required"]);
    exit;

if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    http_response_code(422);
    echo json_encode(["error" => "invalid email"]);
    exit;
}

echo json_encode(["ok" => true, "email" => $email]);
