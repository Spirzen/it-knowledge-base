Windows на рабочей станции — жизненный цикл

ОБЯЗАТЕЛЬНОДЛЯ НОВИЧКОВ
Разработчику Инженеру

Зачем эта статья​

Клиентская Windows (10, 11) — массовая ОС на ноутбуках и ПК в офисах и дома. Windows Server — другая линейка: роли AD, DNS, лицензии по ядрам — см. 63 и настройку серверов.

Здесь — жизненный цикл рабочей станции: от образа до переустановки, с акцентом на то, что админ и продвинутый пользователь делают на практике. Пошаговая установка, UEFI и Rufus — в главе 2. Культурные шутки про "переустанови Windows" — в 131, не вместо runbook.

Данные и разделы — контраст с Linux​

На Windows пользовательские файлы по умолчанию живут в C:\Users\<имя> вместе с профилем, AppData и реестром. Отдельного "домашнего раздела", как /home в Linux, обычно нет — поэтому переустановка с форматированием диска C: без бэкапа часто означает потерю документов.

ПодходWindows (типично)Linux (типично)
СистемаОдин том C: или раздел EFI + C:/ на отдельном разделе
ПользовательC:\Users\.../home/<user>
Сохранить данные при переустановкеБэкап на внешний носитель / облакоЧасто достаточно не трогать раздел /home — 93
Метаданные ОСРеестр, SIDФайлы в /etc, домашние dotfiles
"Сохранить личные файлы" в установщике

Режим Keep personal files в установщике Windows не заменяет полноценный бэкап: часть настроек и AppData сбрасывается, повреждённые файлы могут не перенестись. Перед чистой установкой копируйте важное вне диска C: — см. 2 — резервное копирование.

Активация и лицензия​

После установки Windows нужна легальная лицензия:

  • OEM — ключ вшит в UEFI ноутбука или готового ПК; при смене материнской платы активация может слететь.
  • Цифровая лицензия — привязка к учётной записи Microsoft; повторная активация на том же железе часто проходит автоматически.
  • Корпоративная (VL, KMS) — через IT-отдел, не "ключ с форума".

Установка с официального образа Microsoft возможна без ключа на этапе setup; ограничения неактивированной системы — водяной знак, ограничение персонализации. "Сборки" с торрентов несут риск вредоносного ПО и непредсказуемых обновлений — в мемах это высмеивают, в эксплуатации это инцидент безопасности.

Диагностика перед переустановкой​

Когда система ещё загружается, имеет смысл пройти официальный путь восстановления:

sfc /scannow
DISM /Online /Cleanup-Image /RestoreHealth

Команды проверяют и подменяют повреждённые системные файлы из хранилища компонентов. Они не заменяют антивирусную зачистку rootkit и не убирают годы "мусора" в реестре — поэтому в рунете шутку "сначала перезагрузи, потом переустанови" ставят рядом с реальным опытом, когда repair install не помогает.

Полный разбор команд — в конце главы 2. Культура формулы — 131, Неолурк.
