Microsoft 365 для пользователя и IT

НЕ ОБЯЗАТЕЛЬНОДЛЯ НОВИЧКОВ
Всем

Microsoft 365 (M365) — подписка на офисные приложения и облачные сервисы: почта, чаты, файлы, видеосовещания. Раньше говорили "Office 365"; сейчас бренд Microsoft 365 объединяет Office, Windows (в части планов) и Entra ID для входа.

Офисные форматы — 1.15 Текст; корпоративный контекст — 1.04 IT в организациях.

Из чего состоит M365​

СервисНазначение для пользователя
Outlook / Exchange OnlineПочта, календарь, контакты
TeamsЧаты, каналы, звонки, совместные документы
OneDriveЛичное облачное хранилище файлов
SharePointСайты команд, библиотеки документов, intranet
Word, Excel, PowerPointDesktop, web и mobile версии
Copilot (опционально)ИИ-помощник в приложениях — см. ответственное использование

Идентичность и лицензии управляются в Microsoft Entra — глава для IT.

Пользователь и администратор​

Пользователь создаёт файлы, ходит на meetings, не настраивает тенант.

Администратор (IT):

  • создаёт учётки, группы, политики;
  • назначает лицензии E1/E3/E5 или Business;
  • настраивает безопасность (MFA, DLP, запрет пересылки);
  • интегрирует с on-prem AD при гибриде.

Ошибка: "M365 = только Word" — в enterprise ценность часто в Teams + SharePoint + почте.

Файлы — OneDrive и SharePoint​

  • OneDrive — "мои файлы", шаринг по ссылке; синхронизация с папкой на ПК.
  • SharePoint — командные библиотеки, версии, метаданные, workflow.

Потеря данных при увольнении решается политикой IT (архив почты, передача OneDrive), не "флешкой на столе".

Teams как хаб работы​

Каналы привязаны к команде проекта; чаты — к людям. Встречи с записью и расшифровкой снижают "знание только в головах". Интеграции (Planner, Power BI tile) превращают Teams в точку входа, а не "ещё один мессенджер".

Сравнение с другими: мессенджеры, видеосвязь.

Безопасность для обычного сотрудника​

  • Не принимайте MFA-запрос, если вы не входите.
  • Не храните единственную копию критичного файла только локально без OneDrive/SharePoint.
  • Внешний sharing — только по политике компании (guest access).

Практика​

Модуль Возможности Microsoft 365 (~30 мин).

Сертификат обзора: MS-900 (если актуален в вашей программе) — рядом с PL-900 / M365.

Навигатор Learn.

Под капотом — Entra, Graph и лицензии​

Вход в M365 идёт через Microsoft Entra ID (бывший Azure AD): логин → OAuth/OpenID → токены доступа к Outlook, Teams, OneDrive. MFA добавляет второй фактор (приложение, SMS, ключ) — без него украденный пароль часто бесполезен.

Microsoft Graph — единый HTTP API "всего Microsoft 365": почта, файлы, календарь, пользователи. Клиенты Teams и Outlook ходят в Graph; админские скрипты PowerShell тоже.

План (упрощённо)Что даёт сотруднику
Business BasicВеб-офис, Teams, OneDrive
Business Standard+ десктопные Word/Excel
E3/E5 (enterprise)Exchange, compliance, расширенная безопасность

OneDrive sync — клиент на ПК: файлы в %UserProfile%\OneDrive, конфликты — две копии с меткой. SharePoint — библиотека на сайте команды; версии файлов в облаке, не на диске C:.

Teams для звонка использует тот же медиастек, что и видеосвязь (кодеки, SFU в облаке Microsoft).

Опыт, мнение и истории​

MFA-спам. Ночью три запроса "подтвердите вход" — кто-то перебирал пароль. Смена пароля + только приложение Authenticator, SMS отключили. С тех пор любой неожиданный push — повод сразу писать в IT.

"Файл только на ноутбуке". Коллега уволился; OneDrive отключили через 30 дней — преемник не успел забрать папку "Проект X". В корпоративной среде критичное — в SharePoint команды, не в личном OneDrive.

Teams vs Telegram. Вне работы — Telegram; внутри — Teams, потому что там календарь и запись совещаний. Дублировать всё в два мессенджера — выгорание от уведомлений.

Мнение. Обычному сотруднику не нужно знать Entra, но нужно понимать: M365 — облако компании, не "бесплатный диск". Политики IT (sharing, MFA) защищают и фирму, и вас от утечки клиентских данных.

Итоги​

M365 — рабочая среда организации в облаке Microsoft. Пользователь осваивает Teams и файлы; IT — Entra, лицензии и политики. Copilot добавляет ИИ поверх уже знакомых приложений.
