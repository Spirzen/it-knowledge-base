Документация в Microsoft Learn

ОБЯЗАТЕЛЬНОДЛЯ НОВИЧКОВ
Всем

Энциклопедия Вселенной IT даёт теорию на русском и вендорно-нейтральную базу.

Microsoft Learn — официальная практика по стеку Microsoft. Там вы можете много чего найти, почитать, потренироваться дополнительно, если считаете, что Вселенной IT вам недостаточно.

Это официальная бесплатная образовательная платформа от Microsoft, предназначенная для изучения технологий, продуктов и сервисов компании. Там есть качественные интерактивные модули с пошаговыми инструкциями и возможностью выполнения практических заданий в песочнице, есть схемы обучения (последовательности модулей для освоения темы от базового до продвинутого уровня), очные и виртуальные курсы с инструктором для углублённого изучения.

Ну и конечно там вы найдёте хорошую документацию по продуктам Azure, .NET, Microsoft 365, Dynamics 365, Power Platform, GitHub, Windows Server и другим (более 4600 единиц контента). Материалы структурированы по профессиональным ролям, поэтому можно выбрать траекторию обучения в соответствии с карьерными целями. Также есть возможность отслеживания прогресса, получения цифровых значков и подтверждения квалификации.

А эта страница — приложение к дорожной карте, демонстрирующая, что проходить на Learn и после каких глав.

Интерактивный фильтр: Microsoft Learn — навигатор.

Правило порядка​

  1. Прочитать главу энциклопедии (понять зачем).
  2. Пройти модуль или схему Learn (понять как в продукте).
  3. Закрепить pet-проектом или задачей на работе.

Копировать тексты модулей в свои статьи нельзя — только ссылки (Catalog API FAQ).

Learn всё равно полезен для облачных моделей, ИИ-основ и Playwright. Для AWS/GCP/Linux-first используйте параллельно подборку документации — MDN, Kubernetes, Postgres Pro и др.

Итоги​

Дорожная карта Вселенной IT + таблица выше + навигатор = теория и практика без дублирования контента Microsoft.
