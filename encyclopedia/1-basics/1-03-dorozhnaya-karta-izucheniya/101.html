Указатель

Где и о чём почитать в энциклопедии — алфавитный справочник тем и разделов.

ОБЯЗАТЕЛЬНОДЛЯ НОВИЧКОВ
Всем

Здравствуйте! Это аналог оглавления, но предназначен для быстрого поиска по разным критериям:

  • по самому важному в виде быстрых якорей;
  • основные технологии и инструменты по алфавиту;
  • по разделам энциклопедии;
  • по разным темам в виде подборок.

Ищете конкретное слово — Ctrl+F на странице или поиск по сайту в шапке (по заголовкам и тексту статей). Поиск текста в файлах на компьютере (папка, лог, терминал) — отдельная статья. В колонке «Ссылки» несколько ссылок [→ название] ведут к разным материалам по одной теме.

Как пользоваться

Нужен Word — найдите строку Word в алфавитном указателе. Нужен Docker — то же самое. Для обзора целого направления (например, «всё про сеть») — указатель по разделам; готовые цепочки — в тематических подборках. Стартовый маршрут для новичка — дорожная карта; по интересам с оценкой тем — Навигатор.
