Глава 1 — окно редактора​

После запуска Photoshop и открытия документа рабочая область складывается из пяти зон:

  1. Строка меню (File … Help) — команды файла, правки, изображения, слоёв, фильтров.
  2. Панель параметров (Options Bar) — под меню; набор полей зависит от активного инструмента.
  3. Панель инструментов (Tools) — слева; вертикально, один или два столбца.
  4. Окно документа — по центру; вкладки при нескольких файлах.
  5. Палитры (Panels) — справа; набор меняется под задачу (ретушь, типографика, анимация).

Строка состояния — внизу окна документа: масштаб, размер файла, профиль, эффективность RAM (Efficiency).

Меню — краткий ориентир​

МенюЗадачи
FileСоздать, открыть, сохранить, экспорт, печать
EditUndo, буфер, трансформация, Preferences
ImageРежимы, размер, кадрирование, коррекция
LayerСлои, стили, маски, сведение
SelectВыделения, Modify, Color Range
FilterГалереи фильтров, Camera Raw
ViewМасштаб, сетка, направляющие, Proof Colors
WindowПалитры, Workspace, список документов

Подменю открывается у команд с треугольником; выполнение — щелчок по пункту.

Интерфейс и workspace​

  • Тема UI — Edit → Preferences → Interface (Color Theme); тёмная тема по умолчанию снижает отвлечение от холста.
  • Язык — там же; для стабильности меню часто ставят English (в русской локали команды ниже даны как English (Русский)).
  • Window → Workspace — пресеты (Essentials, Photography…); Reset … возвращает рабочую область.
  • Учебный пресет Basic-1: палитры Navigator, History, Layers; светлая тема; Window → Workspace → New Workspace для сохранения.

Горячие клавиши интерфейса (из гл. 1)​

Палитры перетаскивают за заголовок; Collapse to Icons сворачивает столбец в иконки. Сброс хаоса — Window → Workspace → Reset ….

Палитры — что держать под рукой​

Частые в курсе: Layers, History, Navigator, Color, Swatches, Brush / Brush Presets, Properties, Channels, Adjustments. Вызов — Window → … или щелчок по вкладке.

Строка состояния (меню треугольника справа) может показывать Document Sizes, Profile, Scratch Sizes, Efficiency, Layer Count и др. — удобно при «тормозах» (Efficiency ниже 100 % — Photoshop ушёл на диск подкачки).

Упражнение 1.1​

  1. File → Open — файл Урок 1 / Дизайн.jpg (после скачивания набора уроков).
  2. При предложении Creative Cloud выбрать локальный диск.
  3. Осмотреть зоны интерфейса; при необходимости собрать workspace Basic-1 и сохранить.

Глава 2 — растровый документ​

Теория PPI/DPI и масштабирования растра — в Вектор и растр. В Photoshop важно различать пиксели файла и физический размер при печати.

Размер и разрешение​

ПонятиеСмысл
Размер в пикселяхШирина × высота массива (логическое разрешение файла)
ResolutionПикселей на дюйм (ppi) или на см — связывает пиксели с сантиметрами при печати
Битовая глубинаБит на пиксель → объём файла и цветовой режим

300 ppi — типичный ориентир для печати; экран часто 72–96 ppi логически, Retina — отдельные @2x ассеты (см. 2.md).

File → New​

Пресеты: Photo, Print, Web, Mobile… Параметры:

  • Width / Height — px, cm, mm, in…
  • Resolution — pixels/inch или pixels/cm
  • Color Mode — RGB, CMYK, Grayscale…
  • Background Contents — White, Transparent, Background Color…

Упражнение 2.1 — 15×10 cm, 300 ppi, RGB, белый фон.

Сохранение (гл. 2.3)​

КомандаНазначение
SaveРабочий формат (часто .psd)
Save AsВыбор формата и копии
Save for Web (Legacy)JPEG/PNG/GIF с предпросмотром веса

Для публикации в веб — PNG/JPEG/WebP; мастер — PSD со слоями (растровые форматы). Подробные таблицы сжатия — сравнение форматов.

Навигация по документу​

ИнструментДействие

View → Rulers (Ctrl+R), перетаскивание с линейки — направляющие. View → Show → Grid — сетка для симметрии (упражнение с орнаментом, гл. 2.8). Единицы линейки — Edit → Preferences → Units & Rulers.

Чек-лист по главе 2​

  • Создать документ 15×10 cm @ 300 ppi в RGB.
  • Сохранить копию в PSD и экспорт в PNG.
  • Измерить отрезок инструментом Ruler на направляющих.
  • Собрать простой узор по сетке (Урок 2).

Глава 3 — обработка изображения​

Ключевая пара команд — не путать:

КомандаЧто меняется
Image → Canvas SizeТолько холст — поля или обрезка краёв; пиксели картинки те же
Image → Image SizeСамо изображение — число пикселей и/или ppi

Canvas Size​

  • Anchor — с какой стороны «прирастает» или обрезается поле.
  • Relative — прибавить N см к текущему размеру, а не задать абсолют.
  • Canvas extension color — цвет новых полей.

Упражнение с Луна.jpg (Урок 3) — расширить холст до 23×18 cm, якорь в углу.

Image Size и Resample​

ResampleПоведение
ВключёнПересчёт пикселей (интерполяция) — меняется и размер в px, и вес файла
ВыключенЧисло пикселей фиксировано — меняется только «размер пикселя» в см/ppi

При уменьшении с Resample качество обычно терпимое; при увеличении в несколько раз детали не восстанавливаются — наглядно на дубликате Луна.jpg (150 px vs 1575 px).

Методы интерполяции (при увеличении):

МетодКогда
BicubicУниверсальный по умолчанию
Preserve DetailsМелкая текстура, резкость
Bicubic SmootherПлавные градиенты
Nearest NeighborПиксель-арт, без сглаживания

Практическое правило: избегать сильного upscale; для печати лучше снимать/сканировать с запасом ppi.

Кадрирование и геометрия​

  • Crop — обрезка и выпрямление (в т. ч. Straighten для башни в Пизе).
  • Image → Trim — автообрезка по прозрачности или угловому цвету.
  • Image → Image Rotation — 90°/180°, отражение; Arbitrary — горизонт с направляющей.

Палитра History​

ПриёмКоманда
Одна отменаCtrl+Z / Edit → Undo
Много шаговПалитра History, щелчок по строке
Шаг назад/вперёдEdit → Step Backward / Forward (Alt+Ctrl+Z)
СнимокNew Snapshot или кнопка камеры внизу палитры
Лимит шаговPreferences → Performance → History States (по умолчанию 20)

Снимки не съедают слоты истории так же жадно, как сотни мелких шагов. Erase to History у ластика (гл. 9) опирается на ту же палитру.

Упражнение 3.8 — Река.jpg, откаты и снимки.

Чек-лист по главе 3​

  • Расширить холст у Луна.jpg без изменения пикселей (Canvas Size).
  • Уменьшить и снова увеличить копию (Image Size) — сравнить Bicubic и Nearest Neighbor.
  • Выровнять горизонт кадрированием.
  • Сделать Snapshot перед рискованным фильтром.

Глава 4 — слои​

Модель: прозрачные «листы» друг на друге. Без слоёв ретушь гл. 9 и вставка из буфера работают хуже.

Палитра Layers​

ЭлементНазначение
«Глаз»Видимость слоя
OpacityПрозрачность всего слоя
FillПрозрачность заливки (без эффектов слоя)
ModeРежим наложения
Замок / цепочкаБлокировка правок; связанное перемещение

Background — нижний слой без прозрачности; не двигается как обычный слой. Переименовать (двойной щелчок + Alt) — превратить в обычный слой с альфой.

Выбор слоя: щелчок в палитре или Move + правый щелчок по объекту на холсте.

Операции со слоями​

ЗадачаКак в Photoshop
Новый слойИконка «+», Layer → New, вставка из буфера
ПорядокПеретаскивание строк
СвязатьИконка цепочки внизу палитры
ГруппаПапка слоёв (набор)
ВыровнятьMove Tool + опции Align/Distribute
Layer CompsСохранённые варианты видимости/позиций
Фильтр спискаKind, эффекты, текст…
СвестиLayer → Merge Down / Flatten Image

Вставка выделения (Ctrl+V) из другого файла — новый слой автоматически (натюрморт в гл. 9).

Стили слоя (гл. 4.9)​

Тень, обводка, градиент, свечение — неразрушающие эффекты вокруг содержимого слоя. Масштабируются вместе с Image Size, если включён Scale Styles.

Чек-лист по главе 4​

  • Разложить композицию минимум на 3 слоя + выключить «глаз».
  • Скопировать объект на отдельный слой через буфер.
  • Связать два слоя и сдвинуть вместе.
  • Сохранить PSD и проверить слои после повторного открытия.

Глава 5 — цветовые модели​

Теория RGB/CMYK и PPI — в Вектор и растр. В Photoshop цвет задаётся режимом документа и каналами.

Модели и каналы​

МодельГдеЗаметка
RGBЭкран, веб, фотоАддитивная; охват шире CMYK
CMYKПечатьСубтрактивная; перевод из RGB — перед печатью, яркие тона могут «потускнеть»
LabПромежуточный переводВизуально стабильнее при конвертации
HSB/HLSColor Picker, коррекцияОттенок, насыщенность, яркость — удобно для человека

Image → Mode — Bitmap, Grayscale, Duotone, Indexed, RGB, CMYK, Lab, Multichannel. Цепочка: цветное → сначала Grayscale, потом Bitmap (1 бит). Indexed Color — палитра до 256 цветов, компактный GIF-стиль; Color Table для тонирования (упражнение «Закат»).

Палитра Channels — просмотр R/G/B по отдельности (серые полутона). Edit → Preferences → Interface → Show Channels in Color — каналы в цвете (для учёбы; для ретуши часто отключают).

Упражнение​

Цветок.jpg — дубликат, просмотр каналов RGB → Image → Mode → CMYK (4 канала, файл тяжелее) → Lab → Multichannel. Закат.jpg — Grayscale → Indexed → градиент в Color Table.

Чек-лист по главе 5​

  • Открыть Channels и включить только Red.
  • Конвертировать копию в CMYK и сравнить жёлтые тона с RGB.
  • Построить тонированный «закат» через Indexed + Color Table.

Глава 6 — выделение​

Почти все правки и кисти действуют только внутри выделения («марширующие муравьи»).

Marquee и Lasso​

ИнструментПриём
Rectangular / Elliptical MarqueeShift — квадрат/круг; Alt — из центра; пробел — сдвинуть незаконченное выделение
Single Row / ColumnЛиния высотой/шириной 1 px
LassoСвободный контур; Del — откат последней точки
Polygonal LassoЩелчки по вершинам
Magnetic LassoWidth, Contrast, Frequency — контрастный фон

Options Bar — New / Add / Subtract / Intersect; Feather — мягкий край (вставка на новый слой, упражнение «Крыля»); Fixed Ratio / Fixed Size.

Цветовое выделение​

ИнструментПараметры
Magic WandTolerance 0–255; Contiguous; Sample All Layers
Quick Selection«Кисть» добавления; Alt — вычитание

Select → Modify — Expand, Contract, Smooth, Border, Feather. Select → Inverse — выделить фон однородного цвета. Grow / Similar — как Wand с Contiguous on/off.

Select → Save Selection / Load Selection — альфа как выделение (связь с гл. 12).

Копирование фрагмента​

  • Перетащить выделение — «дырка» заливается фоном.
  • Move + Alt — копия без нового слоя.
  • Edit → Copy / Paste — новый слой (натюрморт, самолёт).

Упражнение «Куб Неккера» — заплаты фона через Move+Alt.

Чек-лист по главе 6​

  • Квадрат и круг marquee с Shift+Alt.
  • Feather 20 px → Copy/Paste → сдвинуть слой.
  • Magic Wand с разным Tolerance и Inverse.
  • Object Selection на сложном фоне.

Глава 7 — трансформация выделения​

Edit → Transform (или Free Transform Ctrl+T) — до Enter это превью; Esc отмена. Точка-мишень — центр масштаба/поворота.

КомандаДействие
ScaleУглы + Shift или цепочка W/H — пропорции
RotateЗа пределами рамки — угол; поле угла на Options Bar
SkewСредние маркеры — сдвиг сторон
DistortЛюбой угол — произвольная форма
PerspectiveСходящиеся стороны (самолёт)
WarpСетка деформации (текст на бокале «Тархун»)
Puppet WarpОпорные «булавки» на сетке
Flip Horizontal / VerticalИли W = −100 %

Select → Transform Selection — меняется контур, не пиксели.

Интерполяция на Options Bar при применении — те же принципы, что в Image Size.

Творческое задание — коллаж из Роза.jpg / букетов (Урок 7), Smart Guides.

Чек-лист по главе 7​

  • Скопировать объект (Alt+Move), Scale+Rotate, Enter.
  • Perspective на отдельном слое.
  • Попробовать Warp на тексте.

Глава 8 — цвет и заливка​

Foreground / Background и Color Picker​

  • Eyedropper — цвет пикселя; Sample Size 3×3 … 101×101.
  • Щелчок по Foreground — Color Picker (HSB, RGB, Lab, CMYK).
  • Предупреждения: вне CMYK gamut; не web-safe (исторически).
  • Color Libraries — Pantone и др. для печати.

Палитры Color и Swatches — шкала, каталоги RGB/CMYK, Restore Default Swatches.

Заливка и обводка​

СпособНазначение
Edit → FillВыделение: цвет, Pattern, Content-Aware, 50 % Gray… + Mode (blend)
Paint BucketЗаливка смежных пикселей (как Wand + Tolerance)
GradientЛинейный/радиальный/угловой градиент
Edit → StrokeОбводка контура выделения

Режимы наложения​

Работают в Fill, кистях, слоях:

ГруппаПримерыЭффект
БазовыеNormal, DissolveЗамена или «шум»
ЗатемнениеMultiply, Color BurnТемнее
ОсветлениеScreen, Color DodgeСветлее
КонтрастOverlay, Soft/Hard LightКонтраст и насыщенность
РазностьDifference, ExclusionИнверсии, психоделика
КомпонентыHue, Saturation, Color, LuminosityМеняют оттенок/сатурацию/яркость отдельно

Упражнение 8.3 — два прямоугольника, Fill эллипса розовым в разных Mode (откат по History между вариантами).

Paint Bucket — Tolerance, Opacity, Mode; Gradient — пресеты, прозрачность, Reverse, Dither.

Чек-лист по главе 8​

  • Задать чистый RGB green и сравнить с CMYK green в Picker.
  • Залить прямоугольник Fill с Mode Multiply и Screen.
  • Градиент на отдельном слое поверх фото.

Глава 9 — рисование и удаление​

Инструменты рисования работают основным цветом (Foreground); линия повторяет движение мыши/пера. Общие приёмы — для Brush, Pencil и частично Eraser.

Приём Shift — прямые и «ломаные» линии​

  • Отпустить кнопку мыши в начале отрезка, зажать Shift, щелкнуть в конце — прямая между двумя точками.
  • Многоугольник — серия щелчков с зажатым Shift.
  • При рисовании с зажатой Shift линия фиксируется по горизонтали/вертикали; отпуск Shift возвращает свободное следование (упражнение «ископаемая рыба»).

Рисование внутри выделения ограничивает мазок контуром marquee.

Палитра кистей​

ЭлементНазначение
Brush Preset Picker (Options Bar)Быстрый размер и пресет
Window → BrushesПолная настройка
Size, Hardness, Spacing, Angle, RoundnessФорма оттиска (овальная кисть — тянуть точки на превью)
Mode, Opacity, FlowРежим наложения, сила, «подача краски»
AirbrushНакопление краски в одной точке
SymmetryЗеркальное рисование

Pencil — жёсткие края; Auto-Erase — повторный штрих по своей линии рисует фоновым цветом (как ластик).

Сохранить кисть — меню палитры New Brush. Наборы — General, Special Effects, Calligraphic…; Restore Default Brushes.

Edit → Preferences → Cursors — показывать контур мазка вместо крестика (удобно для больших кистей).

Мазки — динамика (Brush panel)​

ПараметрЭффект
Shape Dynamics → Fade«Хвост» мазка — размер затухает за N шагов
Transfer → FadeПрозрачность затухает к концу
Color Dynamics → FadeПереход Foreground → Background («грязная кисть»); галочка Apply Per Tip
Wet EdgesКрая как на мокрой бумаге

Упражнение 9.3 — четыре линии: сплошная, Fade размера, Fade цвета, Fade opacity.

Своя кисть из контура​

Edit → Define Brush Preset — из выделенного контура (пример «двуглавый орел» в гл. 9). Кисть появится в конце списка пресетов.

Color Replacement (замена цвета)​

Кисть перекрашивает захваченные оттенки в основной цвет.

ПараметрВарианты
ModeHue, Saturation, Color, Luminosity
SamplingContinuous, Once, Background Swatch
LimitsDiscontiguous, Contiguous, Find Edges
ToleranceШирина диапазона оттенков

Упражнение с «голубыми помидорами» — Mode Color, Limits Contiguous, Tolerance ~50 %.

Mixer Brush (смешивающая кисть)​

Имитирует масляную/акварельную смесь на холсте. Wet, Load, Mix — откуда берётся краска (холст vs резервуар). Пресеты от Dry до Very Wet. Оптимален с графическим планшетом.

Ластики​

ИнструментПоведение
EraserНа одном слое — фоновый цвет; на прочих — прозрачность. Режимы Brush / Pencil / Block
Background EraserПрозрачность внутри кисти; сохраняет края объекта; Sampling Continuous / Once / Background Swatch; Protect Foreground Color
Magic EraserКак Magic Wand — щелчок по цвету; Tolerance, Contiguous, Sample All Layers

Erase to History (Options Bar) + снимок в History — стереть до состояния из протокола (восстановление фона после вставки цветов на слой).

Типовой приём из упражнения 9.6–9.7: скопировать объект на новый слой → обычный Eraser снять фон → Background Eraser подчистить кайму → Magic Eraser для однородных полей.

Чек-лист по главе 9​

  • Провести контур с Shift и без — понять разницу «привязки» направления.
  • Сравнить Brush, Pencil и Airbrush на одной кисти.
  • Собрать Fade-мазок (Size + Opacity + Color Dynamics).
  • Создать кисть через Define Brush Preset.
  • Перекрасить объект Color Replacement с разными Mode.
  • Удалить фон тремя ластиками на многослойном файле.

Глава 10 — тоновая коррекция​

Тон — яркость и контраст без смены оттенка. Старт с гистограммы (Window → Histogram, Expanded View).

ПонятиеСмысл
Диапазон 0–255Уровни яркости пикселей
Узкая гистограмма«Серая», плоский контраст
«Гребёнка» после LevelsПровалы — допустимо при умеренном растяжении

Levels и Curves​

КомандаНазначение
Image → Adjustments → LevelsЧёрная/белая/серая точка; Input и Output levels
Image → Adjustments → CurvesТочечная кривая вход→выход; пресеты
Image → Shadows/HighlightsОтдельно тени и света

Levels — ползунки Input (чёрный 25, белый 220 в упражнении «Дворец»); Auto; пипетки чёрного/белого/серого на изображении; Alt → Reset.

Curves — диагональ X=Y; сдвиг углов = контраст; сближение углов к центру = плоское изображение. Урок 10 — Дворец.jpg, Набережная.jpg, Коррекция кривой.jpg.

Разрушающая коррекция

Image → Adjustments меняет активный слой навсегда. Для гибкости в работе — корректирующие слои (глава 11, Layer → New Adjustment Layer).

Чек-лист по главе 10​

  • Прочитать гистограмму «серого» снимка.
  • Levels с Preview — растянуть диапазон.
  • Curves — осветлить света и затемнить тени точками на кривой.

Глава 11 — цветовая коррекция​

Цветовая коррекция — оттенок, насыщенность, баланс каналов. Теория колеса — упражнение «цветовое колесо» (Урок 11).

Инструмент / командаЗадача
Color BalanceСдвиг теней/средних/светов к R/G/B
Hue/SaturationПерекрасить волосы, объекты
Selective ColorТонкая настройка CMYK-компонентов
Channel Mixer«Роза или капуста» — смена восприятия каналов
Replace ColorЗамена диапазона оттенков
Match ColorПодогнать цвет одного слоя под другой
Photo FilterТёплый/холодный фильтр

Серая точка — нейтраль на Color Balance (упражнение 11.3). Selective Color — таблетки/импрессионист (11.5).

Корректирующие слои​

Layer → New Adjustment Layer — Levels/Curves/Hue Saturation как отдельные слои с маской. Книга вводит их в конце гл. 11 (упражнение 11.8). Это предпочтительный путь в продакшене.

16/32 bit — коррекция с ограничениями; для HDR-фото отдельные правила (11.11–11.12).

Чек-лист по главе 11​

  • Color Balance + серая пипетка.
  • Hue/Saturation на выделенной области.
  • Создать Adjustment Layer Curves и включить/выключить «глаз».

Глава 12 — маски и альфа-каналы​

Выделение временное; маска в файле — постоянная. Альфа-канал — ч/б карта: белый = активно, чёрный = скрыто, серый = частично.

ПриёмКоманда
Сохранить выделениеSelect → Save Selection или кнопка в Channels
ЗагрузитьSelect → Load Selection / Load channel as selection
Новый альфаCreate New Channel
Quick MaskQ — редактировать маску кистью (красная вуаль)
Layer MaskИконка маски у слоя — скрыть части слоя без удаления пикселей
Clipping MaskСлой обрезается по форме слоя ниже
Masked groupГруппа слоёв с общей маской

Select → Color Range — выделение по цветовому диапазону (12.3). Упражнение Маска.jpg — фон + причёска в Alpha 1/2; рамка (12.4).

Связь с гл. 6: Select and Mask доводит края (волосы, полупрозрачность).

Чек-лист по главе 12​

  • Сохранить выделение в Alpha 1, загрузить после Deselect.
  • Отредактировать маску в Quick Mask.
  • Добавить Layer Mask и закрасить чёрным/белым кистью.

Глава 13 — векторные контуры​

Photoshop хранит векторные контуры (Paths) отдельно от растра. См. также Векторные форматы.

ИнструментНазначение
PenБезье-точки, точные контуры
Freeform PenСвободный контур
Curvature PenУпрощённое перо
Rectangle/Ellipse/Line/Custom ShapeПримитивы и фигуры из набора
Path Selection / Direct SelectionВесь контур / отдельные точки

Контур можно залить, обвести, превратить в выделение (Load path as selection), растеризовать (Rasterize).

Упражнения — контуры, «Заяц в тигровой шкуре» (магнитное перо + контур).

Чек-лист по главе 13​

  • Обвести объект пером и сохранить Path.
  • Залить контур цветом на новом слое.
  • Конвертировать контур в выделение и скопировать фрагмент.

Глава 14 — текст​

ТипОсобенность
Point TypeЩелчок — строка заголовка
Paragraph TypeРамка — многострочный блок
Type MaskТекст как выделение (коллаж)

Палитры Character и Paragraph — шрифт, кегль, интерлиньяж, выравнивание. Warp text — дуга надписи. Type → Convert to Shape — вектор для правки.

Текст на контуре — выделить Path → Type on a path (упражнение 14.4).

Текстовый слой растреризуют при необходимости фильтров на буквах.

Чек-лист по главе 14​

  • Заголовок Point Type и абзац в рамке.
  • Надпись вдоль кривой Path.
  • Сохранить PSD с редактируемым текстом.

Глава 15 — ретушь​

«Корректирующие инструменты» в Photoshop — локальные кисти, не только Adjustment Layers.

ГруппаИнструменты
РезкостьBlur, Sharpen, Smudge
Тон локальноDodge, Burn, Sponge
КлонированиеClone Stamp, Pattern Stamp
РетушьSpot Healing, Healing Brush, Patch, Content-Aware Move/Fill
НастраиваемоеClone Source — несколько источников

Упражнения — Синди (родинка), реставрация фото, Klimt-покрывало, картофель, «невидимая рыбка».

Пайплайн портрета: дубликат слоя → Healing → Dodge/Burn → Sharpen на глазах (умеренно).

Чек-лист по главе 15​

  • Spot Healing на пыль и мелкие дефекты.
  • Healing Brush с выбором источника Alt.
  • Clone Stamp на текстуре фона при 100 % совпадении.

Глава 16 — фильтры​

Filter — пиксельные эффекты (часто разрушающие; Smart Object сохраняет откат).

Группа (меню Filter)Примеры
BlurGaussian, Motion, Radial
SharpenUnsharp Mask, Smart Sharpen
NoiseAdd Noise, Reduce Noise
DistortRipple, Spherize, Liquify
StylizeEmboss, Find Edges, Oil Paint
RenderClouds, Lens Flare
PixelateMosaic, Crystallize

Filter Gallery — художественные пресеты. Liquify — деформация лица/фигуры. В гл. 9 «рыба» использует рельеф (Emboss).

Перед фильтром на важном слое — Convert to Smart Object (в CC) или дубликат слоя.

Чек-лист по главе 16​

  • Gaussian Blur на копии слоя + маска.
  • Emboss или Stylize на учебном файле.
  • Откат через History или Smart Filter.

Глава 17 — вывод на печать​

Полиграфия в целом — макет (InDesign и др.) + CMYK + TIFF/EPS. В Photoshop — подготовка растра.

ШагДействие
1Финальная коррекция в RGB
2Image → Mode → CMYK (перед печатью, с просмотром gamut)
3Image → Image Size — разрешение под печать (часто 300 ppi)
4Сохранить TIFF CMYK для типографии или PDF
5Офисная печать — File → Print (принтер, масштаб, поля)

File → Print — выбор принтера, ориентация, Scale to Fit, количество копий, цветовой профиль принтера (soft proof — View → Proof Colors).

Веб-экспорт — обратно в sRGB и JPEG/WebP (форматы), не CMYK.

Чек-лист по главе 17​

  • Конвертировать копию в CMYK и сравнить с RGB.
  • Print Preview на домашнем принтере.
  • Сохранить мастер PSD + отдельный TIFF/PDF для печати.

После курса

Для веб-макетов чаще смотрят Figma; Photoshop остаётся силён в фото, ретуши, коллаже и подготовке растра. Альтернатива без подписки — GIMP, Affinity Photo (7.md).
